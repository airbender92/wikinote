这里只讲**四个新知识点**，精简到一眼能记住：

---

## 1. 把 String 转成 int
```java
Integer.parseInt("3");
```
- `Integer` 是 Java 自带的类
- `parseInt(字符串)` 把 `"3"` 变成数字 `3`

---

## 2. 增强 for 循环（for-each）
```java
for (int cell : locationCells) { }
```
- 读作：**for each int cell in locationCells**
- 作用：从头到尾**遍历数组**，每次拿一个元素放进 `cell`

---

## 3. 后自增 ++
```java
numOfHits++;
```
- 等于：`numOfHits = numOfHits + 1;`
- 意思：**加 1**

---

## 4. break 语句
```java
break;
```
- 直接**跳出当前循环**
- 不继续跑，立刻结束循环

---

简单记：
**字符串转 int → parseInt
遍历数组 → for(:)
加一 → ++
跳出循环 → break**
