## 我们要测什么？
1. 猜中 → 返回 `"hit"`
2. 三次猜中 → 返回 `"kill"`
3. 没猜中 → 返回 `"miss"`

测试步骤：
1. 创建 SimpleDotCom 对象
2. 给它设置位置：比如 `{2,3,4}`
3. 假装用户猜：`"2"` → 应该 hit
4. 再猜 `"3"` → hit
5. 再猜 `"4"` → kill
6. 猜 `"0"` → miss

---

## 测试代码（TestSimpleDotCom.java）
```java
public class TestSimpleDotCom {
    public static void main(String[] args) {

        // 1. 创建对象
        SimpleDotCom dot = new SimpleDotCom();

        // 2. 设置位置
        int[] locations = {2, 3, 4};
        dot.setLocationCells(locations);

        // 3. 测试第一次猜中：应该 hit
        String guess1 = "2";
        String result1 = dot.checkYourself(guess1);
        String testResult1 = result1.equals("hit") ? "passed" : "failed";
        System.out.println("Test 1 (hit): " + testResult1);

        // 4. 第二次猜中：hit
        String guess2 = "3";
        String result2 = dot.checkYourself(guess2);
        String testResult2 = result2.equals("hit") ? "passed" : "failed";
        System.out.println("Test 2 (hit): " + testResult2);

        // 5. 第三次猜中：kill
        String guess3 = "4";
        String result3 = dot.checkYourself(guess3);
        String testResult3 = result3.equals("kill") ? "passed" : "failed";
        System.out.println("Test 3 (kill): " + testResult3);

        // 6. 测试没猜中：miss
        String guess4 = "0";
        String result4 = dot.checkYourself(guess4);
        String testResult4 = result4.equals("miss") ? "passed" : "failed";
        System.out.println("Test 4 (miss): " + testResult4);
    }
}
```

## 对应的 SimpleDotCom 类（填空版）
```java
public class SimpleDotCom {
    int[] locationCells;
    int numOfHits = 0;

    public void setLocationCells(int[] locs) {
        locationCells = locs;
    }

    public String checkYourself(String userGuess) {
        // 转成 int
        int guess = Integer.parseInt(userGuess);
        String result = "miss";

        // 遍历每个位置
        for (int cell : locationCells) {
            if (guess == cell) {
                result = "hit";
                numOfHits++;
                // 已经命中全部 3 格
                if (numOfHits == 3) {
                    result = "kill";
                }
                break; // 中了就不用再比
            }
        }
        return result;
    }
}
```
