# 更强力的方法
是时候给我们的方法加点“肌肉”了。
我们之前摆弄过变量、玩过几个对象、写过一点简单代码，但都太基础了。
我们需要更多工具：

- 更多**运算符**，好做比“狗叫”更有意思的逻辑
- **循环**，别只用弱弱的 while 了，要玩就用 for 循环
- **随机数生成**
- **把字符串转成 int** 这类实用技巧

与其零散学习，不如**从头写一个真实项目**来实战——
比如写一个**战舰游戏（Battleships）**。

这个项目分量很足，所以会用**两章**完成：
- 本章：做一个**简单版**
- 第 6 章：升级成**更强大的豪华版**
