# SimpleDotCom 类的伪代码（prepcode）

这是介于**自然语言**和**Java 代码**之间的逻辑草稿，重点是先把思路写清楚，不纠结语法。

---

## 实例变量声明
- 声明一个 `int` 数组，保存位置，叫做 **locationCells**
- 声明一个 `int` 记录命中次数，叫做 **numOfHits**，初始值为 **0**

## 方法声明
1. **checkYourself(String userGuess)**
   接收用户猜测，返回结果："hit" / "miss" / "kill"
2. **setLocationCells(int[] cellLocations)**
   设置 DotCom 的位置（3 个格子）

---

## 方法逻辑

### METHOD: checkYourself(String userGuess)
- 拿到用户输入的字符串猜测
- **把字符串转成 int**
- 遍历 locationCells 里的每一个位置
  - 如果用户猜的数字 == 当前位置
    - 命中数 +1
    - 如果命中数 == 3
      → 返回 **"kill"**
    - 否则
      → 返回 **"hit"**
  - 否则
    → 返回 **"miss"**

---

### METHOD: setLocationCells(int[] cellLocations)
- 拿到传入的位置数组
- 把它赋值给实例变量 `locationCells`
