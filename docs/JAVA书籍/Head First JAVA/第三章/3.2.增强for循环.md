# Java 增强for循环（for-each循环）完整解析
## 一、基础语法
```java
for (String name : nameArray) {
    // 循环体
}
```
### 两段核心组成
1. **迭代变量声明（`String name`）**
    定义一个变量，用来临时存放数组/集合里**单个元素**；
    变量类型必须和数组元素类型完全兼容，类型不匹配直接编译报错。
    例：`String[]`数组不能用`int name`遍历。
2. **待遍历集合/数组（`nameArray`）**
    只能是数组，或是实现了`Iterable`的集合（`ArrayList`等）。

## 二、通俗含义
对数组`nameArray`里**每一个元素**，依次把元素赋值给变量`name`，然后执行循环体内代码。

## 三、底层执行逻辑（编译器视角）
1. 创建`String`类型变量`name`，初始为空；
2. 取出数组**第1个元素**，赋值给`name`；
3. 执行大括号内循环代码；
4. 取出数组**下一个元素**，覆盖`name`；
5. 重复步骤3、4，直到数组所有元素遍历完毕，循环结束。

## 四、关键特性与限制
### 1. 优势
- 代码极简，不需要手动定义计数器、自增、下标；
- 不用关心数组长度，自动遍历全部元素。

### 2. 核心局限（重点）
1. **无法获取元素下标**
    增强for循环没有索引，如果你需要拿到当前元素的位置，只能用普通for循环。
2. **无法修改数组原始元素**
    `name`只是数组元素的副本，修改`name`的值不会改变原数组内容。
    ```java
    String[] arr = {"A", "B"};
    for (String s : arr) {
        s = "test"; // 仅修改局部变量，原数组不变
    }
    ```
3. **无法反向遍历、控制遍历步长**
    只能从头到尾顺序遍历，不能跳过、倒序读取元素。
4. **循环内无法删除/新增集合元素**
    遍历集合时增删元素会抛出并发修改异常。

## 五、普通for循环 vs 增强for循环 对比示例
```java
String[] nameArray = {"Alice", "Bob", "Cathy"};

// 1. 增强for（只读取元素，无需下标）
for (String name : nameArray) {
    System.out.println(name);
}

// 2. 普通for（需要下标、修改数组、倒序时使用）
for (int i = 0; i < nameArray.length; i++) {
    System.out.println(nameArray[i]);
}
```

## 六、使用场景总结
### ✅ 适合用增强for
仅**读取遍历**数组/集合全部元素，不需要下标、不需要修改原始容器。
### ❌ 不适合用增强for
1. 需要获取元素索引；
2. 需要修改数组中原有元素；
3. 需要跳过部分元素、倒序遍历；
