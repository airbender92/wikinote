# SimpleDotComGame main 方法伪代码

```
public static void main(String[] args)

1. 声明一个 int 变量 numOfGuesses，记录玩家猜了多少次，初始为 0
2. 创建一个 SimpleDotCom 对象
3. 生成一个 0~4 之间的随机数，作为 DotCom 的起始位置
4. 创建一个长度为 3 的 int 数组，存放三个连续位置
   例：随机数是 3 → 位置 {3,4,5}
5. 调用 SimpleDotCom 的 setLocationCells()，设置它的位置
6. 声明一个布尔变量 isAlive，表示游戏是否继续，初始为 true

7. 当 isAlive 为 true 时，循环：
   a. 获取玩家在命令行输入的猜测
   b. 调用 dotCom.checkYourself() 检查结果
   c. 猜测次数 numOfGuesses +1
   d. 如果结果是 "kill"：
       - 把 isAlive 设为 false（退出循环）
       - 打印玩家一共猜了多少次
```

# 关键点说明
- 所有逻辑**都在 main 里**
- 随机位置只能从 **0~4** 开始，这样加 2 才不会超过 6（总网格 0~6）
- 用 `while(isAlive)` 实现游戏循环
- 玩家输入暂时先当“黑箱”，后面会用 Java 的 Scanner 实现
- 最后击沉时输出总猜测数
