# 简易版 Dot Com 游戏（入门版）

为了降低难度，我们先做**简化版**，掌握核心逻辑后，下一章再扩展成完整版。

## 一、简化版规则
- 只有 **1 个 DotCom**（不是 3 个）
- 不是 7×7 网格，只有**一行 7 个格子**：`0 1 2 3 4 5 6`
- DotCom 占**连续 3 格**，比如 `1,2,3`
- 用户输入数字猜测
- 三次命中 → 击沉，游戏结束
- 最后显示一共猜了多少次

## 二、游戏流程
1. 程序启动
2. 创建 1 个 DotCom 对象，随机分配 3 个连续位置
3. 循环：
   - 提示用户输入数字
   - 判断：命中 / 没命中
   - 统计命中次数
4. 命中 3 次 → 结束，显示总猜测数

## 三、关键设计
- 不需要真的画一个 7 格数组
- 只需要一个**存 3 个位置的数组**，表示 DotCom 占据的格子
- 每中一次，就把那个位置“清空”或标记
- 累计命中 == 3 → 击沉

## 四、运行示例
```
%java SimpleDotComGame
enter a number 2
hit
enter a number 3
hit
enter a number 4
miss
enter a number 1
kill
You took 4 guesses
```
