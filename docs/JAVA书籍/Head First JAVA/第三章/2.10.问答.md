# 1. 两个问答重点
### Q：`Integer.parseInt()` 不能解析什么？
- 只能解析**数字字符串**：`"0"`～`"9"`
- 不能解析英文单词：`"three"` → 运行时报错（崩溃）
- 乱传非数字内容（`"blurp"`）也会直接报错

### Q：Java 有两种 for 循环？
对：
1. **普通 for 循环**（从 Java 一开始就有）
   ```java
   for (int i = 0; i < 10; i++)
   ```
2. **增强 for 循环（for-each）**（Java 5 以后才有）
   ```java
   for (int cell : locationCells)
   ```
   专门用来**遍历数组/集合**，更简单。

# 2. 最终完整代码
## SimpleDotCom.java
```java
public class SimpleDotCom {
    int[] locationCells;
    int numOfHits = 0;

    public void setLocationCells(int[] locs) {
        locationCells = locs;
    }

    public String checkYourself(String stringGuess) {
        int guess = Integer.parseInt(stringGuess);
        String result = "miss";

        for (int cell : locationCells) {
            if (guess == cell) {
                result = "hit";
                numOfHits++;
                break;
            }
        }

        if (numOfHits == locationCells.length) {
            result = "kill";
        }

        System.out.println(result);
        return result;
    }
}
```

public class SimpleDotComTestDrive {

        dot.checkYourself(userGuess);
    }
}

# 4. 书中提到的小 bug（伏笔）
