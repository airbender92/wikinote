# GameHelper 工具类完整解析（预制代码）
## 一、作用
专门封装**控制台键盘输入**逻辑，对外只提供一个简单方法 `getUserInput(String prompt)`，游戏主类直接调用即可拿到用户输入的字符串，不用处理底层 IO 复杂代码。
底层 IO 流、异常相关知识第14章才讲解，现阶段直接复制使用。

## 二、完整可运行代码
```java
import java.io.*;

public class GameHelper {
    public String getUserInput(String prompt) {
        String inputLine = null;
        // 打印提示文字，等待用户输入
        System.out.print(prompt + " ");
        try {
            // 构建控制台读取流
            BufferedReader is = new BufferedReader(new InputStreamReader(System.in));
            // 读取用户输入一整行，回车结束
            inputLine = is.readLine();
            // 如果用户直接回车、无内容，返回null
            if (inputLine.length() == 0 ) 
                return null;
        } catch (IOException e) {
            // 捕获IO异常，打印错误信息
            System.out.println("IOException: " + e);
        }
        // 返回用户输入的字符串
        return inputLine;
    }
}
```

## 三、逐段拆解说明
1. **导包 `import java.io.*;`**
    代码用到了输入流、IO异常相关类，必须导入IO包。
2. **方法入参 `String prompt`**
    传入提示文本，调用时写 `"enter a number"`，控制台就会打印这句话引导用户输入。
3. `System.out.print(prompt + " ");`
    `print` 不会自动换行，提示文字和输入光标在同一行。
4. `BufferedReader + InputStreamReader(System.in)`
    Java 读取控制台标准输入的标准组合，`System.in` 代表键盘输入。
5. `is.readLine()`
    读取用户输入的完整一行内容，按下回车键后结束读取，返回字符串。
6. 空输入判断
    如果用户什么都不写直接回车，字符串长度为0，返回`null`。
7. `try-catch` 异常捕获
    IO操作会抛出`IOException`，必须捕获处理，否则编译报错；出现异常时打印错误信息。

## 四、使用要求
1. 新建文件命名为 `GameHelper.java`，完整复制上面代码；
2. 和另外两个类 `SimpleDotCom.java`、`SimpleDotComGame.java` 放在**同一个文件夹**；
3. 编译运行游戏时三个类会一起生效。

## 五、调用示例（游戏主类里）
```java
GameHelper helper = new GameHelper();
String guess = helper.getUserInput("enter a number");
```
控制台输出效果：
```
enter a number 3
```
变量`guess`会拿到字符串 `"3"`。
