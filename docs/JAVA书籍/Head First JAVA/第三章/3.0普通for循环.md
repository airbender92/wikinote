# Java 普通for循环完整解析（对应Head First Java图示）
## 一、完整语法结构
```java
for(初始化表达式; 布尔判断条件; 迭代更新表达式) {
    // 循环体：需要重复执行的代码
}
```
对应图中示例：
```java
for(int i = 0; i < 100; i++) {}
```

## 二、三段表达式逐段拆解
### 1. 初始化表达式 `int i = 0`
标注：`initialization`
1. **执行时机**：**整个循环只运行1次**，循环开始前执行，后续循环不再触发。
2. **作用**：声明并初始化循环计数器变量，变量作用域仅在`for()`和循环体内。
3. 拓展：可同时定义多个同类型变量，用逗号分隔
```java
for(int i=0, j=10; i<j; i++){}
```

### 2. 布尔判断条件 `i < 100`
标注：`boolean test`
1. **执行时机**：每一轮循环**先执行判断**，再决定是否运行循环体。
2. **规则**：结果必须是`true/false`布尔值
   - `true`：执行大括号内循环体代码
   - `false`：立刻终止整个for循环，跳出执行后续代码
3. 拓展：可以调用返回`boolean`的方法作为条件
```java
for(int i=0; checkContinue(i); i++){}
```

### 3. 迭代更新表达式 `i++`
标注：`iteration expression`；`i++`是**后置自增运算符 post-increment operator**
1. **执行时机**：**一轮循环体全部执行完毕后**，才会运行这段更新代码。
2. 执行顺序记忆：
   `初始化 → 判断条件 → 循环体 → 迭代更新 → 判断条件 → 循环体 → 迭代更新...`
3. 常见写法：
   - `i++` 每次+1
   - `i--` 每次-1
   - `i += 2` 每次+2（步长2）

## 三、示例代码执行流程（`for(int i=0; i<100; i++)`）
通俗翻译：循环执行100次
1. 第一步（仅一次）：创建变量`i`，赋值`i=0`
2. 检查 `i < 100`：
   - 成立(true)：执行`{}`循环体
   - 循环体跑完 → 执行`i++`，i自增1
   - 回到第二步重新判断
3. 当`i=100`时，`100 < 100`结果为false，循环直接结束

## 四、关键易错点
1. **三段表达式之间必须用分号`;`分隔**，末尾第三段后不能加分号
   错误：`for(int i=0; i<100; i++;)`
2. 迭代表达式**在循环体之后运行**，不是循环开头
   例：i=99时进入循环体，执行完代码才会`i++`变成100，下一轮判断直接退出
3. 初始化里定义的变量`i`，循环结束后外部无法访问
```java
for(int i=0; i<5; i++){}
System.out.println(i); // 编译报错，i作用域仅循环内
```
4. 三段表达式全部可以省略（两个分号必须保留）
```java
for(;;){} // 无限死循环，布尔条件省略默认视为true
```

## 五、和增强for循环（enhanced for loop）区分
本文讲的是**普通计数for循环**，适合需要下标、控制步长、倒序遍历场景；
增强for循环（`for(int num : 数组/集合)`）只用来快速遍历全部元素，无法获取索引、自定义循环次数。
