# 翻译 + 游戏规则清晰版

# 我们来做一个类似战舰的游戏：
## **「干掉互联网公司」（Sink a Dot Com）**

规则很简单：
你 vs 电脑，但你不用放自己的船，
你的目标是**用最少的猜测次数，击沉电脑的所有“互联网公司”**。

---

## 游戏目标
用最少的步数击沉电脑的 **3 个互联网公司**，
最后根据步数给你评级。

---

## 游戏设置
- 网格是 **7×7**
  - 行：A ~ G
  - 列：0 ~ 6（和 Java 数组一样从 0 开始）
- 程序启动后，电脑自动放 **3 个互联网公司**
- 每个公司占 **3 个连续格子**

---

## 怎么玩
- 命令行输入猜测坐标，比如：
  **A3、B2、D4**
- 电脑返回三种结果：
  - **miss** 没打中
  - **hit** 击中一格
  - **You sunk ...** 击沉整个公司
- 当你把 **3 个公司全部击沉**，游戏结束，显示你的评分

---

## 示例对局
```
%java DotComBust
Enter a guess A3
miss
Enter a guess B2
miss
Enter a guess C4
miss
Enter a guess D2
hit
Enter a guess D3
hit
Enter a guess D4
Ouch! You sunk Pets.com :(
Enter a guess B4
miss
...
```

---

简单说：
**这是一个用命令行玩的、7×7 网格、打 3 个长度为 3 的“虚拟战舰”小游戏。**
