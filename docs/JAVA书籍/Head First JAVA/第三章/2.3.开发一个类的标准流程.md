# 开发一个类的标准流程（书中学习版）

这是本书教你写 Java 类的固定步骤，专门用来学习，不是真实公司强制规范，但非常好用：

## 1. 先搞清楚这个类**要做什么**
明确职责：它负责哪部分功能？

## 2. 列出**实例变量 + 方法**
它需要记住什么？（变量）
它能做什么？（方法）

## 3. 写 **prep code（伪代码）**
不用管语法，只写逻辑，专注思路。

## 4. 写 **test code（测试代码）**
先写怎么调用、怎么验证功能，再写实现。

## 5. 写 **real code（真正 Java 代码）**
按伪代码翻译成可运行的类。

## 6. 测试、调试、重写
跑测试 → 看结果 → 修 bug → 再跑

# 本次要写的两个类

## 1. SimpleDotCom 类
- 目标：表示一个“DotCom”，记录位置、判断是否命中
- 要写三样：
  - prep code
  - test code
  - real code

## 2. SimpleDotComGame 类
- 目标：游戏主控，创建对象、接收用户输入、玩游戏
- 只写：
  - prep code
  - real code
  - 不写 test code

# 页面提示条含义
```
prep code  test code  real code
```
表示当前正在讲哪一步：
- 涂黑 = 正在这一步
- 白色 = 还没到 / 不需要

# 脑力题
写程序时，**应该先写哪个类？**

答案思路：
**先写被别人使用的类 → 再写使用它的类。**
比如先写 SimpleDotCom，再写 SimpleDotComGame。
因为游戏类要依赖 SimpleDotCom，不能反过来。
