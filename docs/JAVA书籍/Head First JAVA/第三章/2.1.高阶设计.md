# 高阶设计（游戏流程 + 类规划）

## 一、游戏整体流程
1. **启动游戏**
   - 创建 3 个 DotCom（每个占 3 格）
   - 把它们随机放到 7×7 网格里

2. **开始游戏循环**
   直到所有 DotCom 被击沉：
   - 提示用户输入猜测（如 A2、C0）
   - 检查结果：
     - **Miss** 没中
     - **Hit** 击中一格
     - **Kill** 击沉整个 DotCom（删掉它）

3. **游戏结束**
   - 根据猜测次数给出评分

先想**程序里有哪些“东西”**，而不是先想步骤：
