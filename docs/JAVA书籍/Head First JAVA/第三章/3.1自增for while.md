# Java 自增/自减运算符 + for/while 循环对比完整解析
## 一、++ / -- 自增、自减运算符
### 1. 基础等价写法（单独一行时，前后无区别）
```java
x++;  // 等价 x = x + 1;
x--;  // 等价 x = x - 1;
```
单独语句 `x++;` / `++x;` 效果完全一样，都是给变量±1。
**只有运算符嵌入赋值、打印等复合表达式时，前置/后置才会产生差异。**

### 2. 前置自增 `++x`（Pre-increment）
规则：**先自增，再使用新值参与运算**
```java
int x = 0;
int z = ++x;
// 步骤：
// 1. x = x + 1 → x = 1
// 2. 把新的x赋值给z → z = 1
// 最终：x=1，z=1
```

### 3. 后置自增 `x++`（Post-increment）
规则：**先使用变量当前旧值运算，运算结束后再自增**
```java
int x = 0;
int z = x++;
// 步骤：
// 1. 先用旧值x=0赋值给z → z=0
// 2. 再执行 x = x + 1 → x = 1
// 最终：x=1，z=0
```

### 4. 同理前置/后置自减 `--x` / `x--`
- `--x`：先减1，再取值计算
- `x--`：先取原值计算，再减1

## 二、for 循环执行流程（示例：循环打印0~7）
```java
for (int i = 0; i < 8; i++) {
    System.out.println(i);
}
System.out.println("done");
```
### 固定执行顺序（全程仅初始化执行1次）
1. 初始化：`int i = 0`（仅循环最开头执行1次）
2. 布尔判断：`i < 8`
   - 结果 `true`：进入循环体，打印 `i`
   - 循环体执行完毕 → 执行迭代表达式 `i++`
   - 回到第2步重新判断
   - 结果 `false`：直接跳出循环，执行打印`done`
### 输出结果
```
0
1
2
3
4
5
6
7
done
```
循环一共执行8次（i=0~7），i=8时条件不成立结束。

## 三、for 循环 vs while 循环 核心区别
### 1. while 循环结构特点
while 只保留**布尔判断条件**，没有内置初始化、迭代更新语句；
计数器的声明、初始化、自增都要手动写在循环外部/循环体内。

把上面for循环等价改写为while：
```java
// 手动在循环外声明+初始化计数器
int i = 0;
while (i < 8) {
    System.out.println(i);
    // 手动在循环末尾写迭代自增
    i++;
}
System.out.println("done");
```
两段代码输出完全一致。

### 2. 适用场景对比
| 循环 | 适用场景 | 优势 |
|------|--------|------|
| for循环 | 已知循环次数（遍历数组、固定循环N次、带计数器） | 代码紧凑，初始化/判断/更新集中在一行，可读性高 |
| while循环 | 未知循环次数，仅依赖条件是否成立（等待输入、文件读取、直到满足某个退出条件） | 结构简单，只关注终止条件，无需计数器 |

### 补充：死循环写法对照
```java
// for死循环（两个分号不能省略）
for(;;){}

// while死循环
while(true){}
```

## 四、高频易错点总结
1. 自增运算符只有在**复合表达式**（赋值、打印、传参）里才有前后之分，单独一行 `x++;` 和 `++x;` 无差别；
2. for循环第三段迭代表达式 `i++` **在循环体执行完后才运行**，不是循环开头；
3. for循环初始化中定义的变量`i`，作用域仅限`for()`括号和循环大括号内部，循环外无法访问；while循环在外定义的计数器循环结束后仍可使用；
4. while循环容易忘记在循环体内写`i++`，导致**无限死循环**。
