# Java API 库使用知识点总结
## 一、API 核心结构：包（package）
1. **定义**：Java 标准库（API）的所有类都会按功能分组，收纳在不同**包**中，包拥有专属名称。
2. 典型包举例
    - `java.util`：工具类包，本章用到的 `ArrayList` 就在此包；后续集合、日期工具都存放于此；
    - `javax.swing`：图形界面 Swing 相关类；
    - `java.lang`：基础核心包，是特殊内置包。
3. 完整类标识：**包名 + 类名**，例如 `java.util.ArrayList` 是 ArrayList 的全限定名。

## 二、使用API类的两种方式
想要调用库中类，必须指明它所属的包，分两种写法：
1. **完整全限定名（不导入，直接写）**
    每次使用类时，完整写出包+类名，示例：
    ```java
    java.util.ArrayList list = new java.util.ArrayList();
    ```
    缺点：代码冗长，重复书写繁琐。
2. **import 导入（推荐写法）**
    在文件顶部通过 `import` 引入包/类，后续代码可直接简写类名，不用带包名。

## 三、特殊包：java.lang（自动隐式导入）
所有属于 `java.lang` 的类**无需手动 import**，编译器会自动导入，你之前已经一直在用：
- `System`：控制台输出 `System.out.println()`
- `String`：字符串类
- `Math`：数学工具类 `Math.random()`

## 四、本章应用场景回顾
前文海战游戏 `DotComBust` 依靠 `java.util.ArrayList` 动态存储站点数据，本章正式讲解如何查找、引入、使用 Java 内置工具类，不用从零手写容器等基础功能；第16章会深入讲解**自定义包**（把自己写的类归类打包）。

## 核心要点
1. Java API 以包为单位划分所有内置类；
2. 调用外部库类必须标明所属包，`import` 简化代码；
3. `java.lang` 自动导入，其余包必须手动导入或写全限定名；
4. 标准库提供大量现成工具，开发优先复用 API，避免重复造轮子。
