# Java HTML 官方API文档完整使用指南
## 一、API文档基础介绍
1. **版本归属**
文档全称：**Java 5（Java 2 5.0）标准版文档**，Sun（现Oracle）官方配套手册，和JDK安装包分开，需要单独下载；
两种查阅途径：
- 本地离线：推荐下载解压到硬盘，访问速度快；
- 在线浏览：Sun官网（java.sun.com），需要稳定网络。
2. **核心价值**
普通参考书只能简单介绍方法名、入参、返回值；**HTML官方文档会补充方法行为细节、边界情况、异常、特殊返回规则**，是开发唯一权威参考。
示例：`ArrayList.indexOf(Object o)`
- 参考书仅说明：传入对象，返回int下标；
- API文档补充：**找不到目标元素时返回-1**，我们可以利用这个特性同时完成「判断是否存在」+「获取下标」两个需求，若只看书很容易误以为找不到会报错。

## 二、经典三栏HTML文档操作步骤
文档分为3个框架面板，操作流程：
1. **左上框：包列表**
滚动浏览所有包，点击某个包，下方类列表仅展示该包下所有类，快速过滤目标类（如点击`java.util`只显示工具类）。
2. **左下框：类/接口列表**
选中包后，滚动查找目标类（如`Calendar`、`ArrayList`），点击类名。
3. **右侧主框：类完整详情（核心阅读区）**
- 概览：快速滚动浏览全部方法摘要；
- 详情：点击任意方法名，展开完整说明（参数含义、返回规则、特殊场景、废弃标记）。

## 三、两种学习API方式对比
| 方式 | 优势 | 局限 |
|------|------|------|
| 纸质参考书籍 | 适合漫无目的翻阅，偶然发现实用类 | 缺少方法边界、异常、特殊返回值细节 |
| HTML官方API文档 | 信息完整权威，精准查询细节 | 适合明确目标、针对性查阅，不适合泛读 |

## 四、核心使用场景
当你通过书籍初步了解某个类（如`java.util.Calendar`），但不清楚方法完整行为、边界逻辑时，打开API文档查阅，避免踩坑。
以`indexOf`为例关键细节：
```java
int indexOf(Object o)
// 存在元素：返回从0开始的下标
// 不存在元素：固定返回 -1（不会抛出异常）
```
依托这条规则，可一行代码完成存在判断：
```java
if(list.indexOf(target) != -1) {
    // 元素存在
}
```

## 五、补充关键知识点
1. API文档会标注`Deprecated`（过时）方法，不建议业务代码使用；
2. 文档清晰区分构造器、普通实例方法、静态方法、接口实现方法、重写Object的方法；
3. 本地离线文档是开发必备工具，在线版受网络限制，生产环境优先本地使用。
