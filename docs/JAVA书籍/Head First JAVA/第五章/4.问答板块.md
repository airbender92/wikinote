# 问答板块知识点总结
## Q1：import 会增大类文件、编译导入的代码到我的程序里吗？
### 答案：不会
1. Java 的 `import` ≠ C 语言的 `#include`；
2. `import` 唯一作用：**简化书写**，让你不用每次写完整类名；
3. 不会把被导入类的代码嵌入当前类，不会增大 `.class` 文件，也不会拖慢程序运行，多写 import 无性能负担。
底层逻辑：编译时编译器仅靠 import 识别类的完整限定名，运行时JVM按需加载对应类。

## Q2：为什么 String、System 不需要手动 import？
### 答案：`java.lang` 包自动隐式导入
`java.lang` 是Java最基础核心包，编译器会默认全部引入，不用手动写 import；
程序会自动识别 `java.lang.String`、`java.lang.System`、`java.lang.Math` 等，无需写全限定名。

## Q3：我必须把自己写的类放进包吗？怎么操作？
1. 实际项目开发**强烈建议**将自定义类划分到包中，方便管理、避免类名冲突；
2. 本书现阶段示例代码暂时不使用包；
3. 完整包创建、打包、编译运行的操作会在第16章详细讲解。

## 核心一句话区分
`import` 只是**语法简写工具**，不参与代码合并、不影响程序体积与性能；只有 `java.lang` 包无需手动导入。
