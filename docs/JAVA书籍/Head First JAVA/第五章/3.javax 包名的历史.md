# 本段知识点完整总结
## 一、`java` / `javax` 包名的历史由来与含义
### 1. 早期Java包命名规则
Java 1.02、1.1时代：
- **`java.*`**：标准内置核心库，随JDK自带，如`java.lang`、`java.util`、`shturl.`、`java.awt`；
- **`javax.*`**：`x`代表extension（扩展包），属于标准扩展，最初不内置，需要额外安装，规范约定扩展包前缀加`x`。

### 2. Swing 改名历史事件
1. Swing最初是GUI扩展库，包名`javax.swing`；
2. Java 1.2（Java 2）计划将Swing升级为标准内置库，按规则本应去掉`x`，改为`java.swing`；
3. 大量开发者已有海量`javax.swing`业务代码，改名会造成全部代码失效；
4. Sun最终妥协，**保留`javax`前缀**。
### 3. 结论
如今看到`javax.xxx`包，代表该组件**最初是扩展包，后来升级为Java标准内置库**。

## 二、ArrayList 核心特性与常用方法（java.util.ArrayList）
### 1. 基础API方法
- `add()`：向集合添加元素
- `remove()`：删除指定元素/下标元素
- `indexOf()`：查找元素下标，不存在返回-1
- `isEmpty()`：判断集合是否为空，返回布尔值
- `size()`：获取当前存储元素数量
### 2. 动态扩容特性
普通数组长度固定；**ArrayList是动态数组**，新增元素自动扩容、删除元素自动收缩。
### 3. 泛型（类型参数 `<>`）
声明时指定尖括号内类型，限定集合只能存放该类/其子类对象：
示例 `ArrayList<Button>`：仅允许存储Button及其子类实例。
### 4. 基础类型自动装箱
ArrayList**不能直接存八大基本类型**，编译器自动完成装箱/拆箱：
存入时自动把`int`→`Integer`、`boolean`→`Boolean`等包装类对象；取出时自动转回基础类型。
### 5. 与普通数组区别
数组：获取长度用**成员变量 `.length`**
ArrayList：获取元素数量用**方法 `.size()`**

## 三、包与类导入核心要点回顾
1. Java所有内置类按功能划分到不同包；类完整标识 = 包名.类名（例`java.util.ArrayList`）；
2. `java.lang`自动导入，其余包的类必须二选一：
   - 代码全程书写完整限定名；
   - 文件头部使用`import`语句导入，简写类名；
3. 包两大区分标识：
   - `java.*`：原生标准核心库；
   - `javax.*`：起源扩展、后纳入标准的库。
