# 如何学习、查阅Java标准API文档
## 一、核心问题：如何自主找到需要的API类？
开发中两大核心疑问：
1. Java库中存在哪些可用类？
2. 找到目标类后，它有哪些构造方法、成员方法、功能？

## 二、两种查阅API的途径
### 途径1：翻阅Java参考书籍
适合**漫无目的地探索**，随便翻书就能偶然发现实用工具类，适合初学者拓宽知识面。
### 途径2：官方HTML在线API文档（最常用、精准）
Java官方提供网页版完整类库手册，是开发标配查询工具。

## 三、API文档标准页面结构（以`java.util.Date`举例）
一份完整类文档包含固定板块：
1. **基础标识**
    - 所属包名（`java.util`）
    - 类名（`Date`）
    - 类的继承/实现关系（`implements Cloneable, Comparable, Serializable`）
    - 类整体功能描述
2. **构造方法 Public Constructors**
    所有创建该对象的重载构造器，例如无参构造、long时间戳构造、年月日时分秒构造等。
3. **属性存取方法 Property Accessor Methods**
    读写类内部数据的get/set方法：`getTime()`、`setTime(long time)`。
4. **普通实例方法 Public Instance Methods**
    对象可调用业务方法：`after()`、`before()`、`compareTo()`，用于日期比较。
5. **接口实现方法 Methods Implementing Comparable**
    实现接口必须重写的方法（`compareTo(Object)`）。
6. **重写Object的方法 Public Methods Overriding Object**
    所有类都继承自Object，重写后的通用方法：`clone()`、`equals()`、`hashCode()`、`toString()`。
7. **废弃方法 Deprecated Public Methods**
    标记过时、不推荐使用的旧API（如`getYear()`、`getMonth()`等日期获取方法），官方不再建议调用，后续版本可能移除。

## 四、学习价值
1. 不用从零编写工具逻辑，先查API确认是否已有现成实现；
2 文档清晰区分构造器、普通方法、重写方法、废弃API，规避过时代码；
3. 明确类所属包，配合`import`语法完成代码引入。
