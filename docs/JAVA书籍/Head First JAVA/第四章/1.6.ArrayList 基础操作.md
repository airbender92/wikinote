# ArrayList 基础操作完整讲解（搭配示例 Egg 对象）
## 一、泛型简单说明 `<Egg>`
`ArrayList<Egg>` 里尖括号代表**泛型**：限定这个集合**只能存放 Egg 类型对象**，暂时不用深究底层，只需记住它用来约束集合存储的数据类型。

## 二、8 个基础操作分步演示
### 1. 创建空 ArrayList 对象
```java
ArrayList<Egg> myList = new ArrayList<Egg>();
```
堆内存生成一个空集合，内部无任何元素，尺寸很小。

### 2. 添加第一个元素
```java
Egg s = new Egg();
myList.add(s);
```
新建 Egg 对象`s`，调用`add()`存入集合；集合自动扩容，开辟空间存储这个对象引用。

### 3. 添加第二个元素
```java
Egg b = new Egg();
myList.add(b);
```
再存入`b`，集合再次自动扩容，现在内部存放`s`、`b`两个元素。

### 4. 获取当前元素数量 `size()`
```java
int theSize = myList.size();
```
集合现有2个元素，`size()` 返回 **2**。
> 对比普通数组：数组用`.length`获取固定长度；ArrayList用`size()`获取**实际存放元素个数**。

### 5. 判断集合是否包含指定元素 `contains()`
```java
boolean isIn = myList.contains(s);
```
集合存在对象`s`，返回布尔值 `true`。

### 6. 判断集合是否为空 `isEmpty()`
```java
boolean empty = myList.isEmpty();
```
集合里有2个元素，不是空集合，返回 `false`。

### 7. 查询元素下标 `indexOf()`
```java
int idx = myList.indexOf(b);
```
ArrayList**下标从0开始（零基）**：
`s` 下标0，`b` 下标1，所以变量`idx`结果为 `1`；
如果集合不存在该对象，返回 `-1`。

### 8. 删除元素 `remove()`
```java
myList.remove(s);
```
移除对象`s`，集合自动收缩，仅剩`b`，size 变为1。

## 三、ArrayList 核心特性（和普通数组对比）
1. **自动伸缩**
add()自动扩容，remove()自动收缩，不用手动新建、复制数组；
2. **动态长度**
size()实时返回当前真实元素数量，不像数组长度固定不变；
3. 便捷查询工具：
`contains`快速判断是否存在、`indexOf`直接获取位置，数组需要手写循环遍历；
4. 零基索引规则：和数组下标规则完全一致，第一个元素下标为0。
