# Java API（Java标准类库）核心知识点总结
## 一、什么是Java API
Java API = Java Application Programming Interface，也就是**Java标准内置类库**，JDK自带海量已经写好、经过测试的成熟类，无需我们从零开发重复基础功能。

核心理念：**不要重复造轮子**
通用基础功能（数组容器、字符串处理、IO、数学运算、GUI、网络等）官方全部封装好，开发只需要编写项目专属业务代码，大幅减少开发量、提升稳定性。

## 二、API的价值
1. **节省开发时间**
不用手动实现排序、随机数、字符串转换、集合存储等通用逻辑，直接调用现成类和方法；熟练使用API的程序员效率更高。
2. **代码健壮可靠**
官方类经过大量测试，边界场景、性能、安全都做了完善处理，自己手写容易出现bug、性能缺陷。
3. **统一规范**
所有Java开发者共用同一套标准库，代码可读性、兼容性更强，团队协作成本更低。

## 三、本书中的“现成代码” vs Java API
1. **Ready-bake（书中预制代码片段）**
书中提供的完整示例代码（比如控制台输入工具、游戏基础逻辑），仍然需要手动抄写/导入才能使用；
2. **Java API类库**
无需手写实现，仅通过`import`导入对应包，直接实例化类、调用方法即可使用完整功能（例如`ArrayList`、`Math`、`Integer`）。

## 四、使用API的基础步骤
1. 通过`import`导入目标类所在包（如`import java.util.ArrayList`）；
2. 查阅官方API文档，了解类的构造方法、可用成员方法、入参/返回值；
3. 在代码中创建对象（或直接调用静态方法），复用内置逻辑。

## 五、书中举例的常用API模块
- `java.util`：集合`ArrayList`、随机数、日期工具；
- `java.lang`：`String`、`Integer`、`Math`（默认自动导入，无需写import）；
- `java.awt/swing`：图形界面GUI组件；
- `shturl.`：文件读写；
- `java.net`：网络Socket编程。

## 六、核心学习目标
学会查找、读懂官方API文档，识别场景下对应的内置类，优先复用标准库而非手动重复实现基础逻辑。当前文件内容过长，豆包只阅读了前 90%。
