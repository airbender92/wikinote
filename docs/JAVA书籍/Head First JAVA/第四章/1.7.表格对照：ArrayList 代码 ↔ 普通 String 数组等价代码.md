# 表格对照：ArrayList 代码 ↔ 普通String数组等价代码
## 左侧 ArrayList 完整代码
```java
ArrayList<String> myList = new ArrayList<String>();
String a = new String("whoohoo");
myList.add(a);
String b = new String("Frog");
myList.add(b);
int theSize = myList.size();
Object o = myList.get(1);
myList.remove(1);
boolean isIn = myList.contains(b);
```

## 右侧 等价普通 String 数组实现（逐行对应）
```java
// 1. 创建固定长度数组（最多存2个元素）
String[] myList = new String[2];
String a = new String("whoohoo");
// 2. add(a) 数组写法：存入下标0
myList[0] = a;
String b = new String("Frog");
// 3. add(b) 数组写法：存入下标1
myList[1] = b;

// 4. int theSize = myList.size();
// 数组无size()，只能手动统计非null元素个数
int theSize = 0;
for(String s : myList) {
    if(s != null) theSize++;
}

// 5. Object o = myList.get(1);
String o = myList[1];

// 6. myList.remove(1);
// 数组长度固定，无法直接删除，只能置空占位
myList[1] = null;

// 7. boolean isIn = myList.contains(b);
// 数组无contains，必须循环遍历判断
boolean isIn = false;
for(String s : myList) {
    if(b.equals(s)) {
        isIn = true;
        break;
    }
}
```

## 逐项功能对比总结
| 操作 | ArrayList写法 | 普通数组等价操作 | 数组痛点 |
|------|--------------|----------------|---------|
| 创建容器 | `new ArrayList<String>()` 自动伸缩 | `new String[2]` 长度写死，上限2 | 提前必须预估容量 |
| 添加元素 `add()` | `myList.add(a)` 直接追加尾部 | `myList[0] = a` 手动写下标 | 容易下标越界 |
| 获取元素数量 `size()` | 一行 `myList.size()` | 循环统计非空元素 | 额外循环代码 |
| 根据下标取值 `get(index)` | `myList.get(1)` | `myList[1]` | 语法简单，但数组长度固定 |
| 删除指定下标元素 `remove(1)` | 一行删除，数组自动缩短 | 只能赋值`null`占位，无法真正移除 | 残留空值，后续遍历要过滤 |
| 判断是否包含元素 `contains(b)` | 一行内置方法 | 手写循环逐个对比 | 大量重复模板代码 |

## 核心结论
普通数组**没有内置增删、查询工具方法**，实现同等功能需要手动写循环、下标控制；
`ArrayList` 封装好全部常用操作，代码简洁，动态长度，解决数组长度固定、操作繁琐的短板。当前文件内容过长，豆包只阅读了前 81%。
