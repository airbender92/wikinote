# ArrayList 核心知识点总结（来自Head First Java）
## 一、核心概念：ArrayList 是什么
1. **归属**：JDK 标准 Java API（核心类库）内置现成类，属于`java.util`包，无需我们自己编写、编译代码，直接导入就能使用。
2. **对比普通数组 int[]**
    - 普通数组：**长度固定**，创建后不能增删元素；删除元素只能手动新建数组复制，代码繁琐低效。
    - ArrayList：**动态可变集合**，长度自动伸缩，内置现成方法完成增、删、查、判空，完美解决 DotCom 游戏数组Bug问题。
3. 优势：API类已经预编译好，不用手写底层逻辑，一行方法调用就能完成数组需要几十行代码的功能。

## 二、ArrayList 常用核心方法（基础版）
| 方法 | 作用说明 |
|------|--------|
| `add(Object elem)` | 向列表末尾添加元素 |
| `remove(int index)` | 根据下标删除对应位置元素 |
| `remove(Object elem)` | 直接删除匹配的元素对象 |
| `contains(Object elem)` | 判断集合是否包含该元素，返回`true/false` |
| `indexOf(Object elem)` | 返回元素下标；不存在则返回`-1` |
| `size()` | 获取当前集合**真实元素个数**（等同于数组`length`） |
| `isEmpty()` | 判断集合是否为空（元素数量为0） |
| `get(int index)` | 根据下标取出对应元素 |

## 三、为什么 ArrayList 完美修复游戏Bug
游戏需求：命中坐标后永久移除，避免重复计数
1. 用`indexOf(玩家输入数字)`快速查找坐标；
2. 匹配到直接调用`remove()`删除该元素；
3. 删除后集合自动缩短，再次输入该数字时`indexOf`返回`-1`，不会判定命中；
4. `isEmpty()`可直接判断站点是否全部击沉，无需手动维护`numOfHits`计数器。

## 四、和三种纯数组方案对比
1. 标记双数组、-1占位数组、手动新建缩小数组：都需要大量额外循环、判断、复制代码，笨重易出错；
2. ArrayList：封装全部底层扩容/缩容逻辑，代码极简，复用官方成熟工具，符合“不要重复造轮子”的Java API思想。

## 五、补充说明
1. 使用前提：代码顶部写 `import java.util.ArrayList;` 导入包；
