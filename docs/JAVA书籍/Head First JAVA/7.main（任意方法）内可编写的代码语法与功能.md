# 文档：main（任意方法）内可编写的代码语法与功能
## 核心总述
进入 `main` 或者任意方法内部后，就能编写各类指令控制JVM执行逻辑，绝大多数编程语言具备的基础语法Java都支持，整体分为三大类代码：**语句、循环、分支判断**，同时配套基础语法规范。

## 一、三大核心代码功能
### 1. 执行基础操作：语句（Statements）
作用：定义变量、赋值、调用方法、运算、打印输出等基础操作。
示例代码：
```java
int x = 3;                // 声明并赋值整型变量
String name = "Dirk";     // 字符串变量
x = x * 17;               // 算术运算，重新赋值
System.out.print("x is " + x); // 控制台打印
double d = Math.random(); // 调用随机数工具方法
// this is a comment      // 单行注释，不会执行
```

### 2. 重复执行代码：循环（Loops）
两种主流循环 `while`、`for`，满足重复执行需求
1）while循环（满足条件就重复）
```java
while (x > 12) {
    x = x - 1;
}
```
2）for循环（已知循环次数时使用）
```java
for (int x = 0; x < 10; x = x + 1) {
    System.out.print("x is now " + x);
}
```

### 3. 条件分支：if/else 判断
根据条件真假执行不同代码块
基础示例：
```java
if (x == 10) {
    System.out.print("x must be 10");
} else {
    System.out.print("x isn’t 10");
}
```
多条件组合判断：
```java
if ((x < 3) & (name.equals("Dirk"))) {
    System.out.println("Gently");
}
// 无论上面条件成立与否，该行代码一定会执行
System.out.print("this line runs no matter what");
```

## 二、Java基础语法强制规范
1. **每条语句必须以分号 `;` 结尾**
正确：`x = x + 1;`
2. **单行注释使用双斜杠 `//`**
`x = 22; // this line disturbs me`
3. 大部分空格、换行无语法约束，编译器会忽略
`x = 3 ;` 空格不影响编译运行
4. 变量声明格式：**类型 + 变量名**，第3章会完整讲解所有数据类型
`int weight; // int是类型，weight是变量名`
5. 类、方法的全部代码必须包裹在一对大括号 `{}` 内
```java
public void go() {
    // 业务代码写在这里
}
```

## 三、分类总结
方法内可编写三类逻辑：
1. statements 基础语句（变量、运算、打印、方法调用）
2. loops 循环（重复执行代码）
