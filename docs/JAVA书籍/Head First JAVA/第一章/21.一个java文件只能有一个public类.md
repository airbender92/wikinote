## 1. 为什么 `Movie` 不用写 `public`？
在**同一个源文件（.java）**里：
- **只能有一个类用 `public`**
- 这个 `public` 类的名字**必须和文件名一样**

所以：
- 如果文件名叫 **`MovieTestDrive.java`**
- 那么只能 `public class MovieTestDrive`
- 另一个类 `Movie` 就**不能加 public**，只能写成：
  ```java
  class Movie {
      ...
  }
  ```

这叫**默认访问权限（包访问权限）**，同一文件里可以直接用。

```java
// 文件名必须是: MovieTestDrive.java

class Movie {
    String title;
    String genre;
    int rating;

    void playIt() {
        System.out.println("Playing the movie");
    }
}

public class MovieTestDrive {
    public static void main(String[] args) {
        Movie one = new Movie();
        one.title = "Gone with the Stock";
        one.genre = "Tragic";
        one.rating = -2;

        Movie two = new Movie();
        two.title = "Lost in Cubicle Space";
        two.genre = "Comedy";
        two.rating = 5;
        two.playIt();

        Movie three = new Movie();
        three.title = "Byte Club";
        three.genre = "Tragic but ultimately uplifting";
        three.rating = 127;
    }
}
```

## 4. 关键规则小结（考试 / 编译常考）
1. 一个 `.java` 文件里 **最多一个 public 类**
2. public 类名 **必须 = 文件名**
3. 同一个文件里的其他类 **不能写 public**
4. 但它们之间可以**互相直接使用**（就像这里 MovieTestDrive 用 Movie）
