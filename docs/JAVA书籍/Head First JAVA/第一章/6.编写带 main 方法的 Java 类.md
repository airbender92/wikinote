# 文档：编写带 main 方法的 Java 类
## 一、核心规则：Java 所有代码都写在类中
1. 代码载体流程
   - 手写源码：保存后缀为 `.java` 的文本文件（源文件）；
   - 编译：使用 `javac` 编译器，生成 `.class` 字节码文件；
   - 运行：执行 `java` 命令启动 JVM，加载 `.class` 文件运行程序。
2. 程序运行本质
运行程序 = 通知 JVM：加载指定类，执行该类内部的 `main()` 方法，直至 `main` 内所有代码执行完毕。
3. `main()` 的核心地位
无论项目规模大小、包含多少个类，**整个程序必须有且仅有一个入口 `main()` 方法**，程序从这里开始执行。第2章会深入讲解类相关知识，本章仅掌握可运行代码基础写法。

## 二、完整可运行示例代码
```java
public class MyFirstApp {
    public static void main (String[] args) {
        System.out.println("I Rule!");
        System.out.println("The World");
    }
}
```

## 三、三步完整操作流程
### 1. 保存源码
将上述代码保存为 `MyFirst.java` 规则：公共类名与文件名必须完全一致。
### 2. 编译（终端命令）
```bash
javac MyFirstApp.java
```
编译成功后，目录中生成 `MyFirstApp.class` 字节码文件，文件内存储JVM可识别的字节码指令（文中展示了 `main` 方法、类构造器对应的字节码片段）；代码存在语法错误时，编译失败，不会生成class文件。
### 3. 运行程序（终端命令）
```bash
java MyFirstApp
```
输出结果：
```
I Rule!
The World
```

## 四、关键语法区分：print 与 println
- `System.out.print("内容")`：打印文字，**不自动换行**；
- `System.out.println("内容")`：打印文字后自动换行。
示例单行打印代码：
```java
public class MyFirstApp {
    public static void main (String[] args) {
        System.out.print("I Rule!");
    }
}
```

## 五、字节码补充说明
编译生成的 `MyFirstApp.class` 内部是二进制字节码指令，文中节选片段：
```
Method Party()
0 aload_0
1 invokespecial #1 <Method java.lang.Object()>
4 return

Method void main(java.lang.String[])
0 getstatic #2 <Field ...>
```
字节码是平台无关的中间指令，由JVM翻译成当前系统机器码执行，也是Java跨平台的核心基础。

## 六、流程简图总结
1 编写 `.java` 源码文件
↓ `javac` 编译
2 生成 `.class` 字节码文件
↓ `java` 启动JVM
3 JVM执行main方法，控制台输出结果当前文件内容过长，豆包只阅读了前 27%。
