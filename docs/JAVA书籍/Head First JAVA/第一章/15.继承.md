# 故事结局：继承登场，Brad 完胜，拿下椅子
## Larry 发动反击：你这是重复代码！
Larry 抓到 Brad 设计的“漏洞”，想翻盘赢下椅子：
- 四个图形类里都写了一模一样的 `rotate()` 和 `playSound()`
- 代码重复，维护起来要改四处，太蠢了

## Brad 淡定亮出最终设计：**继承（Inheritance）**
Brad 根本没把重复代码当问题，他早就用面向对象的核心特性解决了。

### 步骤 1：抽取共性
所有图形都是**形状（Shape）**，都有旋转和播放声音的行为。
他把共同的方法抽出来，单独做一个父类：

```java
class Shape {
    rotate() { }
    playSound() { }
}
```

### 步骤 2：建立继承关系
让 `Triangle`、`Square`、`Circle`、`Amoeba` 都**继承自 Shape**：

- **Shape**：父类（superclass）
- **Triangle / Square / Circle / Amoeba**：子类（subclasses）

### 步骤 3：消除重复
子类会**自动拥有父类的方法**，不用再各自写一遍 `rotate()` 和 `playSound()`。
以后只需要维护 **一份代码**，而不是四份。

---

## 关键概念总结
1. **继承 = 代码复用 + 统一结构**
2. 父类（超类）：存放所有子类共同的属性和方法
3. 子类：继承父类功能，还能再加自己独有的逻辑
4. 读作：
   - Square inherits from Shape
   - Circle inherits from Shape

## 结局
Larry 彻底无话可说。
**Brad 赢下了 Aeron 椅子。**

这就是面向对象的真正威力：
**可扩展、易维护、不重复、应对需求变更如喝水。**
