## 三、脑力思考题：设计 Java 类要考虑什么？
根据本章故事，如果你要做一个**类设计检查表**，至少要包含这些问题：

1. 这个类代表**现实/程序中的什么东西**？
2. 它有哪些**状态/特征**（颜色、大小、位置、点数…）→ 对应成员变量
3. 它能**做什么行为**（旋转、发声、移动…）→ 对应方法
4. 哪些东西是**多个类共有的**，可以抽到父类里用继承？
5. 哪些子类需要**重写**父类的方法，实现特殊行为？
6. 数据和方法是否**封装在一起**，而不是散在各处？
7. 以后加新功能时，是否**不用改旧类，只加新类**？

这些就是面向对象设计最核心的思路。
