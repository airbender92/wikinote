# Java while循环完整示例+知识点问答文档
## 一、完整示例代码 Loopy
```java
public class Loopy {
    public static void main (String[] args) {
        int x = 1;
        System.out.println("Before the Loop");
        while (x < 4) {
            System.out.println("In the loop");
            System.out.println("Value of x is " + x);
            x = x + 1;
        }
        System.out.println("This is after the loop");
    }
}
```
### 程序运行输出
```
Before the Loop
In the loop
Value of x is 1
In the loop
Value of x is 2
In the loop
Value of x is 3
This is after the loop
```
### 执行流程拆解
1. 定义整型变量 `x = 1`，打印循环前文字；
2. 判断 `x < 4`：
   - x=1：条件成立，执行循环体，打印内容，x自增为2；
   - x=2：条件成立，执行循环体，打印内容，x自增为3；
   - x=3：条件成立，执行循环体，打印内容，x自增为4；
   - x=4：`4<4` 结果为false，退出循环；
3. 执行循环外最后一行打印语句。

## 二、核心要点（BULLET POINTS）
1. 所有语句必须以分号 `;` 结尾；
2. 代码块（循环、类、方法）用一对大括号 `{}` 包裹；
3. 声明变量格式：数据类型 + 变量名，例 `int x;`；
4. 单个等号 `=` 是赋值运算符；
5. 双等号 `==` 是相等判断运算符；
6. `while` 循环：条件为true时，重复执行大括号内全部代码；
7. 若条件初始为false，循环体一次都不会执行，直接执行循环后方代码；
8. 循环的布尔判断表达式必须写在圆括号 `()` 内，示例 `while (x == 4) { }`。

## 三、常见疑问解答（there are no Dumb Questions）
### Q1：为什么Java所有代码都必须写在类里面？
A：Java是完全面向对象语言，不同于老式纯过程式编程语言。第2章会讲解：类是对象的模板，Java中几乎一切事物都属于对象，所有代码依托类存在。

### Q2：我写的每一个类都需要main方法吗？
A：不需要。一个完整程序只需要**一个带main的启动类**，其余业务类无需main。你也可以给普通类临时写main，用来单独测试该类功能。

### Q3：别的语言可以直接写 while(整数)，Java能写 `int x=1; while(x){}` 吗？
A：**不可以**。Java中布尔类型和数字类型完全不兼容，循环条件只能是布尔值（true/false）。
合法写法只能直接使用布尔变量：
```java
boolean isHot = true;
while(isHot) { }
```
