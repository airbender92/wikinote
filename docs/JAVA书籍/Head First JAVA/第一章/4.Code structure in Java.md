# Java源码、类、方法层级结构 文档
## 一、三层结构总览
Java代码分为三层容器，由外到内依次：**源文件(.java) → 类(class) → 方法(method)**，每层都由大括号`{}`包裹内容。

## 1. 源文件（Source File）存放什么？
### 规则
后缀为`.java`的源码文件，存放**一个类的定义**；小型程序只需要单个类，复杂项目会有多个独立源码文件。
类的全部代码必须写在一对大括号`{}`内部。
### 示例代码
```java
public class Dog {
}
```
文件：Dog.java，内部只包裹Dog类。

## 2. 类（Class）存放什么？
### 规则
一个类中可以包含**一个或多个方法**；所有方法都必须写在类的大括号内部，不能游离在类外面。
### 示例代码
```java
public class Dog {
    void bark() {
    }
}
```
Dog类内部定义了bark()方法。

## 3. 方法（Method）存放什么？
### 规则
方法大括号内部写程序执行指令，每一条指令称为**语句(statement)**；可以把方法简单理解成其他编程语言里的函数/过程。
### 示例代码
```java
public class Dog {
    void bark() {
        statement1;
        statement2;
    }
}
```
bark方法内包含两条执行语句。

## 层级关系总结
1. 外层：`.java`文件 → 容纳类
2. 中层：`class`类 → 容纳多个方法
3. 内层：`method`方法 → 容纳执行语句
所有层级内容均被成对大括号包裹，层级不能颠倒（方法不能写在类外部，语句不能写在方法外部）。当前文件内容过长，豆包只阅读了前 27%。
