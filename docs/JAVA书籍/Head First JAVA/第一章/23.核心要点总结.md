# 第2章核心要点总结（中英对照+极简记忆）

## 必背核心知识点
- **面向对象编程**可以在**不修改原有已测试代码**的前提下扩展程序。
- 所有 Java 代码都定义在**类（class）**中。
- **类 = 蓝图**，描述如何创建该类型的对象。
- **对象 = 实例**，由类创建，能自己处理自己的行为，外部无需关心内部实现。
- 对象有两种成员：
  - **实例变量（instance variables）**：对象知道的东西 → 代表**状态（state）**
  - **方法（methods）**：对象能做的事情 → 代表**行为（behavior）**
- 写类时通常再写一个**测试类（TestDrive）**，里面放 `main()` 来创建和使用对象。
- 类可以从更抽象的**父类（superclass）**继承变量和方法。
- 运行时，Java 程序就是一堆对象在**互相调用方法**。

# Dumb Questions 重点翻译
**Q：我需要全局变量和方法怎么办？**
A：Java 没有真正的“全局”，但可以用 **`public static`** 实现类似全局的效果：
- `public static` 方法 → 随处可调用
- `public static final` 变量 → 全局常量

**Q：那还叫面向对象吗？**
A：这些依然属于某个类（比如 `Math.random()` 属于 `Math` 类），只是**特殊情况**，不是常态。

**Q：什么是 Java 程序？最终交付什么？**
A：一个 Java 程序就是**一堆类**。
其中一个类必须有 `main()` 作为入口。
交付给用户的就是这些类，通常打包成 **`.jar`** 文件。

**Q：几百个类怎么交付？**
A：用 **JAR 文件**（类似 zip）打包，里面可以指定哪个类带 `main()` 作为启动入口。
