# Java while循环基础讲解文档
## 一、Java三种循环总览
Java标准提供3种循环结构：`while`、`do-while`、`for`。本章先讲解最简单的`while`循环，剩余两种后续章节详解。

## 二、while循环核心逻辑
### 1. 执行规则
只要**条件结果为`true`**，就持续执行大括号`{}`内所有循环代码；条件为`false`时，直接跳出循环，执行循环后的代码。
大括号包裹的内容称为**循环体**，需要重复执行的代码必须写在`{}`内部。

### 2. 循环核心：布尔条件判断
循环括号内的表达式最终只能得到**布尔值（true / false）**，只有真假两种结果，不能是数字、字符串等其他类型。
举例通俗理解：
`while (桶里有冰淇淋)` → 条件为true，持续舀冰淇淋；
错误写法`while (Bob)`，无法判定真假，不能作为循环条件，必须改成`while(Bob在打鼾)`这类可判断的描述。

## 三、常用比较运算符（构建布尔判断）
用于对比数值，产出true/false：
1. `<` 小于
2. `>` 大于
3. `==` 判断相等（两个等号，对比值是否一致）

### 重点区分易混淆符号
- `=`：赋值运算符，作用是**把右边值赋予左边变量**
  `int x = 4;` 将数字4赋值给变量x
- `==` 相等判断运算符，仅用于比较，不能赋值
新手极易写错，把`==`写成`=`，会直接造成逻辑/编译错误。

## 四、while代码示例解析
### 示例1：条件成立，循环执行
```java
int x = 4;
while (x > 3) {
    // 初始x=4 > 3，条件true，进入循环
    x = x - 1; // x自减，避免无限循环
}
```
执行流程：
1. x初始值4，`4>3`结果true，执行循环体，x变为3；
2. 再次判断`3>3` → false，循环结束。

### 示例2：条件不成立，循环一次都不执行
```java
int z = 27;
while (z == 17) {
    // z是27，不等于17，条件false，循环体完全跳过
}
```

## 五、关键注意点
1. 循环内务必修改判断用到的变量（如示例`x = x - 1`），否则条件永远为true，触发**死循环**，程序卡死；
2. 判断相等必须用`==`，单等号`=`是赋值，不能用于条件判断；
3. 循环体多行代码必须包裹`{}`，只有一行代码可省略大括号（规范写法仍建议保留）；
4. 所有循环条件只能是布尔结果，数字、对象不能直接放`while()`括号内。当前文件内容过长，豆包只阅读了前 25%。
