# 类（Class）和对象（Object）的区别

## 一句话总结
- **类 = 蓝图 / 模板**
- **对象 = 根据蓝图造出来的真实个体**

---

## 详细解释
### 1. 类（Class）
- 不是对象本身
- 告诉 JVM **如何创建一个对象**
- 定义了这类对象**有哪些变量（状态）**和**有哪些方法（行为）**

比如：`Button` 类
定义了按钮可以有颜色、标签，能按下、弹起。

### 2. 对象（Object）
- 根据类**真正创建出来的实例**
- 每个对象可以有**自己独有的状态**
  比如同一个 Button 类可以做出：
  - 红色、写着“确定”的按钮
  - 蓝色、写着“取消”的按钮
  它们是不同对象，但来自同一个类。

---

## 生活类比

### 类比 1：房子蓝图
- **类 = 建筑图纸**
- **对象 = 按图纸盖出来的真实房子**

图纸不是房子，但能造出无数栋房子，每栋装修、颜色可以不同。

### 类比 2：通讯录卡片
- **类 = 一叠空白名片模板**（都有姓名、电话字段）
- **对象 = 一张张填好的名片**
  每张卡片格式一样，但上面的信息各不相同。

### 类比 3：饼干模具
- **类 = 饼干模具**
- **对象 = 压出来的真实饼干**

模具不是饼干，但能做出很多饼干，每个饼干可以有不同装饰。

---

## 超简记忆
- **Class：模板，不是实物**
- **Object：实物，是模板的一个实例**
