# 文档：综合实战程序——啤酒歌谣 + 营销短语生成器
## 一、实战1：99 Bottles of Beer 啤酒歌谣程序
### 完整代码
```java
public class BeerSong {
    public static void main (String[] args) {
        int beerNum = 99;
        String word = "bottles";
        while (beerNum > 0) {
            if (beerNum == 1) {
                word = "bottle"; // 单数：一瓶啤酒
            }
            System.out.println(beerNum + " " + word + " of beer on the wall");
            System.out.println(beerNum + " " + word + " of beer.");
            System.out.println("Take one down.");
            System.out.println("Pass it around.");
            beerNum = beerNum - 1;
            if (beerNum > 0) {
                System.out.println(beerNum + " " + word + " of beer on the wall");
            } else {
                System.out.println("No more bottles of beer on the wall");
            } // end else
        } // end while loop
    } // end main method
} // end class
```
### 使用到的知识点汇总
1. `main` 程序入口、整型变量 `int`、字符串 `String`；
2. `while` 循环做重复输出；
3. `if` 条件判断区分单复数 `bottle / bottles`；
4. 字符串拼接 `+`、控制台打印 `println`。

### 代码缺陷（书中指出bug）
当只剩1瓶酒，拿走后`beerNum=0`，但`word`变量依然是`bottle`（单数），最后一行会错误输出：
`No more bottle of beer on the wall`
正确应为复数`bottles`。
#### 修复方案
在`beerNum = beerNum - 1;`后重置单词：
```java
beerNum = beerNum - 1;
// 新增：剩余0瓶强制改为复数
if (beerNum == 0) {
    word = "bottles";
}
```

## 三、实战2：PhraseOMatic 营销短语随机生成器
### 功能说明
内置3组营销词汇数组，随机各抽取一个单词拼接成商务黑话短语，适合职场话术演示，完整贴合数组、随机数、字符串综合知识点。
### 完整代码
```java
public class PhraseOMatic {
    public static void main (String[] args) {
        // 三组词汇数组
        String[] wordListOne = {"24/7","multi-Tier","30,000 foot","B-to-B","win-win","front-end", "web-based","pervasive", "smart", "six-sigma","critical-path", "dynamic"};
        String[] wordListTwo = {"empowered", "sticky", "value-added", "oriented", "centric", "distributed", "clustered", "branded","outside-the-box", "positioned", "networked", "focused", "leveraged", "aligned", "targeted", "shared", "cooperative", "accelerated"};
        String[] wordListThree = {"process", "tipping-point", "solution", "architecture", "core competency", "strategy", "mindshare", "portal", "space", "vision", "paradigm", "mission"};

        // 获取每个数组长度
        int oneLength = wordListOne.length;
        int twoLength = wordListTwo.length;
        int threeLength = wordListThree.length;

        // 生成随机下标：Math.random()返回[0,1)小数，强转int取整数下标
        int rand1 = (int) (Math.random() * oneLength);
        int rand2 = (int) (Math.random() * twoLength);
        int rand3 = (int) (Math.random() * threeLength);

        // 拼接短语
        String phrase = wordListOne[rand1] + " " + wordListTwo[rand2] + " " + wordListThree;
        // 打印结果
        System.out.println("What we need is a " + phrase);
    }
}
```
### 代码分步解析
1. **数组定义**：`String[]` 字符串数组存储多组词汇；
2. `.length`：数组内置属性，获取数组元素总个数；
3. `Math.random()`：Java内置随机方法，生成`0 ≤ 数值 < 1`的浮点数；
4. 强制类型转换 `(int)`：小数转整数，得到合法数组下标；
5. 数组取值：`数组[下标]` 获取对应字符串；
6. 字符串拼接：`+` 拼接三段词汇，控制台输出。

### 编码注意事项
书写字符串时，**引号内不能手动换行**，否则编译报错；单词间连字符直接写在字符串内即可，不要中途回车拆分字符串。

### 运行示例输出
```
What we need is a pervasive targeted process
What we need is a six-sigma networked strategy
```
