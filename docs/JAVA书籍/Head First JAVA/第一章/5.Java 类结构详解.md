# Java类结构详解（Anatomy of a class）
## 一、程序入口规则
JVM运行程序时的执行逻辑：
1. 你在命令行指定一个类，JVM加载该类；
2. 在类中寻找**固定格式的`main`方法**，这是Java程序唯一启动入口；
3. 找到`main`后，执行方法大括号`{}`内部所有代码；
4. 硬性要求：任何完整Java应用**至少包含1个类 + 1个main方法**，整个程序只需要一个main，不需要每个类都写main。

### 标准main方法固定格式
```java
public static void main (String[] args) {
    // 所有业务代码写在这里
}
```

## 二、main方法逐段拆解（各关键字含义）
以完整示例类做讲解：
```java
public class MyFirstApp {
    public static void main (String[] args) {
        System.out.println("I Rule!");
    }
}
```
1. `public`：访问修饰符，代表公开，所有人都能访问这个类/方法；
2. `class`：关键字，标识这是一个类；
3. `MyFirstApp`：类名，文件名称必须和类名一致（MyFirstApp.java）；
4. `static`：静态修饰符，该方法不依赖对象，JVM无需创建实例就能直接调用；
5. `void`：方法返回类型，表示此方法**无返回值**；
6. `main`：程序入口固定方法名，JVM硬性识别名称，不能修改；
7. `String[] args`：方法参数，代表字符串数组args，用于接收命令行传入参数；
8. `{ }`：成对大括号，分别是类、方法的代码边界，内部包裹对应内容；
9. `System.out.println("I Rule!");`
    - `System.out`：标准控制台输出；
    - `println`：打印并自动换行；
    - 所有代码语句**必须以分号`;`结尾**，少分号会编译报错。

## 三、代码层级分隔
- 内层`}`：main方法结束标记；
- 外层`}`：整个MyFirstApp类结束标记。
