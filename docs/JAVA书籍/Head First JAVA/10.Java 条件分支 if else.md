# Java 条件分支 if / else 完整学习文档
## 一、if 基础分支语句
### 核心原理
`if` 的判断逻辑和 `while` 的布尔条件完全一致；区别：
- `while`：条件成立就**循环重复执行**代码块
- `if`：条件成立**仅执行1次**代码块，不重复

### 示例 1：仅 if 无 else
```java
class IfTest {
    public static void main (String[] args) {
        int x = 3;
        if (x == 3) {
            System.out.println("x must be 3");
        }
        System.out.println("This runs no matter what");
    }
}
```
运行输出：
```
x must be 3
This runs no matter what
```
逻辑说明：
1. `x == 3` 条件为 true，执行 if 内部打印；
2. if 代码块执行完毕后，**无论条件真假**，都会执行 if 外面的打印语句。

## 二、if-else 双分支结构
else 代表「否则」，条件不成立时执行 else 内部代码。
```java
class IfTest2 {
    public static void main (String[] args) {
        int x = 2;
        if (x == 3) {
            System.out.println("x must be 3");
        } else {
            System.out.println("x is NOT 3");
        }
        System.out.println("This runs no matter what");
    }
}
```
运行输出：
```
x is NOT 3
This runs no matter what
```

## 三、print 与 println 关键区别
1. `System.out.println("内容")`
打印内容后**自动换行**，后续输出会另起一行；
2. `System.print("内容")`
打印后**不换行**，后续文字直接跟在同一行末尾。

## 四、练习题：DooBee 代码填空
### 需求
程序运行输出：`DooBeeDooBeeDo`
完整待补代码：
```java
public class DooBee {
    public static void main (String[] args) {
        int x = 1;
        while (x < _____ ) {
            System.out._________("Doo");
            System.out._________("Bee");
            x = x + 1;
        }
        if (x == ______ ) {
            System.out.print("Do");
        }
    }
}
```
### 填空答案推导
输出拆分：`Doo Bee Doo Bee Do`
1. 循环需要打印两组 `DooBee`，循环执行2次：`x < 3`
   x初始=1：第一次循环、x=2：第二次循环，x=3退出循环
2. 循环内不能换行，使用 `print`：`System.out.print("Doo")`、`System.out.print("Bee")`
3. 循环结束 x=3，判断 `if(x == 3)` 打印最后的 Do

### 补全完整代码
```java
public class DooBee {
    public static void main (String[] args) {
        int x = 1;
        while (x < 3) {
            System.out.print("Doo");
            System.out.print("Bee");
            x = x + 1;
        }
        if (x == 3) {
            System.out.print("Do");
        }
    }
}
```
运行输出：`DooBeeDooBeeDo`当前文件内容过长，豆包只阅读了前 24%。
