# 封装后的 GoodDog 类（完整讲解）

## 1. 封装要点
- **实例变量 `private`**：外部不能直接碰 `size`
- **提供 `public` 的 `getter` 和 `setter`**
- 外部只能通过方法来**读/写** `size`
- 以后想加校验、修改逻辑，**不会破坏别人代码**

---

## 2. 完整代码
```java
class GoodDog {
    // 1. 实例变量私有化
    private int size;

    // 2. public getter
    public int getSize() {
        return size;
    }

    // 3. public setter
    public void setSize(int s) {
        size = s;
    }

    // 方法根据 size 表现不同行为
    void bark() {
        if (size > 60) {
            System.out.println("Wooof! Wooof!");
        } else if (size > 14) {
            System.out.println("Ruff! Ruff!");
        } else {
            System.out.println("Yip! Yip!");
        }
    }
}

class GoodDogTestDrive {
    public static void main(String[] args) {
        GoodDog one = new GoodDog();
        one.setSize(70);       // 只能通过 setter 设置

        GoodDog two = new GoodDog();
        two.setSize(8);

        // 只能通过 getter 获取
        System.out.println("Dog one: " + one.getSize());
        System.out.println("Dog two: " + two.getSize());

        one.bark();
        two.bark();
    }
}
```

---

## 3. 运行输出
```
Dog one: 70
Dog two: 8
Wooof! Wooof!
Yip! Yip!
```

---

## 4. 关键好处
1. **安全**：以后可以在 `setSize` 里加校验，防止错误值
2. **可维护**：内部想怎么改 `size` 的逻辑都行，外部不受影响
3. **方法可以当值用**
   可以直接写：
   ```java
   int x = 3 + one.getSize();
   ```
   就像用普通变量一样。

---

# 一句话记住封装规则
**变量私有，方法公开；
外部不能直接改，只能通过 getter/setter 访问。**
