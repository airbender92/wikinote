# 变量命名规则 + 关键字禁区（翻译+要点）

## 远离那些关键字！
你已经知道变量需要**类型 + 名字**。
基本类型你也学过了。
那**名字可以怎么起**？规则很简单：

### 命名规则（安全版）
- 必须以 **字母、下划线（_）或美元符号（$）** 开头
  **不能以数字开头**
- 第一个字符之后，可以使用字母和数字
- 只要符合上面两条，名字随便起，**但不能是 Java 关键字**

---

## 什么是关键字？
关键字是 Java 编译器“认识”的专用词，
你**绝对不能**拿来当类名、方法名、变量名。

你已经见过的关键字：
`public`、`static`、`void`
还有基本类型：
`boolean`、`char`、`byte`、`short`、`int`、`long`、`float`、`double`

---

## Java 关键字完整禁区表
下面这些单词**一律不能用作名字**，否则编译器直接报错：

```
boolean   byte      char      double    float     int       long      short
public    private   protected abstract  final     native    static    strictfp
synchronized transient volatile
if        else      do        while     switch    case      default
for       break     continue  assert
class     extends   implements import    instanceof interface
new       package   super     this
catch     finally   try       throw     throws    return    void
const     goto      enum
```
