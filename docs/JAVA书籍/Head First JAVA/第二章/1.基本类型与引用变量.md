## 原文翻译
### 第3章：基本类型与引用
开启全新章节 · 第49页
变量分为两大类：**基本类型（primitive）** 和**引用类型（reference）**。
到目前为止，你已经在两处场景使用过变量：
1. **实例变量**：作为对象的状态，定义在类中；
2. **局部变量**：在方法内部声明的变量。

后续章节我们还会见到另外两种变量用法：
- **方法参数**：调用代码传给方法的值；
- **返回值**：方法执行完返回给调用方的值。

你已经见过简单的基本类型变量，比如整型 `int`；也见过更复杂的引用类型，例如 `String`、数组。但Java的类型体系远不止整数、字符串、数组这么简单。
举个例子：你有一个 `PetOwner`（宠物主人）对象，里面包含 `Dog` 类型的实例变量；或是一个 `Car` 对象，内部持有 `Engine`（发动机）对象。

本章将解开Java数据类型的核心谜团：
- 你能声明哪些类型的变量；
- 变量里能存放什么内容；
- 变量可以执行哪些操作。

同时我们会彻底讲清**可垃圾回收堆（garbage-collectible heap）** 的内存运行机制。

---

## 一、变量的4种使用场景（书中划分）
1. **实例变量**
写在类里、方法外面，属于每个对象独有的状态，存在堆内存。
例：`Dog` 类里的 `String name; int size;`
2. **局部变量**
写在方法/代码块内部，仅当前方法可用，存在栈内存。
例：`main` 里 `int x = 3; Dog d = new Dog();`
3. **方法参数（形参）**
方法括号里定义，接收外部传入的值，属于局部变量的一种。
例：`void setName(String n) {}` 中的 `n`
4. **方法返回值**
方法定义开头声明，代表执行完毕后向外输出的数据类型。
例：`int getAge() { return 5; }`

## 二、本章核心学习目标
1. 分清 **基本类型变量** 和 **引用类型变量** 的本质区别；
2. 搞懂栈（Stack）、堆（Heap）分工：
   - 基本类型值直接存栈；
   - `new` 创建的对象全部存堆，栈只存对象的内存地址（引用）；
3. 理解对象嵌套关系：一个类的实例变量可以是另一个自定义类（比如主人持有狗、汽车持有发动机）；
4. 吃透堆内存与垃圾回收GC：对象无人引用时自动被回收释放内存；
5. 掌握两种变量的赋值、比较、参数传递行为差异。

## 三、前置概念铺垫（承接前两章）
前两章只用到简单 `int`、`String`，本章升级到**自定义对象互相包含**的真实OO场景：
```java
class PetOwner {
    Dog pet; // 引用另一个自定义类，引用类型实例变量
}
class Dog {
    int age; // 基本类型实例变量
}
```
这种“对象里包含其他对象”是真实业务代码最常见的结构，也是本章重点。

## 四、关键字释义
1. **primitive 基本类型**
Java固定8种：`byte/short/int/long/float/double/char/boolean`，变量直接存真实数值，不指向堆对象。
2. **reference 引用类型**
类、数组、`String` 都属于引用；变量不存对象本身，只存堆内对象的地址编号。
3. Garbage-Collectible Heap 可垃圾回收堆
所有`new`出来的对象统一存放的内存区域；JVM自动识别不再使用的对象，清理释放内存，无需程序员手动释放。
