# 原文翻译 + 核心要点（杯子类比超清晰版）

## “我要一杯双份摩卡……不，还是换成 int 吧。”

你可以把 Java 变量想象成**杯子**：
咖啡杯、茶杯、装爆米花的大杯、带把手的杯、不能进微波炉的金属杯……

变量就是一个**容器**，用来装东西。
它有**大小**，也有**类型**。

本章我们先看装**基本类型（primitive）**的杯子，
稍后再看装**对象引用**的杯子。
这个杯子类比虽然简单，但后面讨论复杂内容时会非常有用。

---

# 基本类型就像咖啡店的杯子
就像星巴克有小杯、中杯、大杯、超大杯，
Java 的基本类型也有不同**尺寸（位数）**和名字。

声明变量时，你必须明确指定类型：
> “给我一个 int 型杯子，装 90。”
> “给我一个 long 型大杯子，装一个很大的数。”

而且在 Java 里，你还必须**给杯子起名字**：
> “来一个 int，值是 2486，变量名叫 height。”

# Java 基本类型一览

## 整数类型（整型）
- **byte**：8 位
- **short**：16 位
- **int**：32 位（最常用）
- **long**：64 位（超大整数）

## 浮点类型（小数）
- **float**：32 位
- **double**：64 位（默认浮点类型）

## 布尔与字符
- **boolean**：true / false
- **char**：16 位，存单个字符（如 'a' '7' '中'）

---

# 位数与范围（简要）
- byte：8 位 → -128 ~ 127
- short：16 位
- int：32 位 → -2147483648 ~ 2147483647
- long：64 位 → 极大范围
- float：32 位小数
- double：64 位小数
- char：16 位 → 0 ~ 65535

---

# 基本类型声明示例

```java
int x;          // 先声明
x = 234;        // 再赋值

byte b = 89;
boolean isFun = true;
double d = 3456.98;
char c = 'f';

int z = x;      // 把 x 的值赋给 z

boolean isPunkRock;
isPunkRock = false;

long big = 3456789;
float f = 32.5f;  // 注意必须加 f！
```

---

# 超级重点：float 必须加 **f**
Java 默认把带小数点的数字当成 **double**。
如果你要赋值给 float，必须在数字后面加 **f**：

```java
float f = 32.5;   // ❌ 编译错误
float f = 32.5f;  // ✅ 正确
```

# 一句话记住
**基本类型 = 杯子里直接装数值**
不是装地址，不是装对象，就是**实实在在的数字 / true/false / 字符**。
