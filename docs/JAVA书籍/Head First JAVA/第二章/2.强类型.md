# Declaring a variable 变量声明
（翻译 + 核心要点）

Java 非常**在意类型（type）**。
它不会允许你做奇怪又危险的事，比如把一个 **Giraffe（长颈鹿）引用** 塞进一个 **Rabbit（兔子）变量** 里——不然当你试图让这只所谓的“兔子”去 hop() 跳的时候会发生什么？

它也不允许你把浮点数直接塞进整型变量，除非你明确告诉编译器：你知道自己可能会丢失精度（比如小数点后面的所有内容都会被丢掉）。

编译器能发现绝大多数问题：
```java
Rabbit hopper = new Giraffe();
```
别指望这行代码能编译通过。谢天谢地。

为了让这种**类型安全**生效，你**必须声明变量的类型**。
它是整数？一只 Dog？一个单个字符？

变量有两种：
- **primitive（基本类型）**
- **object reference（对象引用类型）**

基本类型保存的是**基础值**（可以理解成：简单的二进制位），包括整数、布尔值、浮点数等。
对象引用保存的是——嗯，**指向对象的引用**。

我们先看基本类型，再搞清楚对象引用到底是什么。

但不管哪种类型，变量都必须遵守两条声明规则：

1. **变量必须有类型**
2. **变量必须有名字**

```java
int count;
```
类型   名字

### 一句话记住
**Java 是强类型语言：什么类型的变量，只能装什么类型的值/对象。**
兔子变量 = 只能放兔子
长颈鹿变量 = 只能放长颈鹿
int 变量 = 只能放整数
