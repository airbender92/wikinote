# 实例变量 vs 局部变量（核心区别必背）

## 1. 定义位置不一样
- **实例变量**：在**类里面、方法外面**
  ```java
  class Horse {
      private double height = 15.2; // 实例变量
  }
  ```
- **局部变量**：在**方法里面**
  ```java
  public int add() {
      int total = a + b; // 局部变量
  }
  ```

---

## 2. 默认值完全不同
### ✅ 实例变量
**自动给默认值，不用手动初始化**
- 数字 → 0
- boolean → false
- 引用 → null

### ❌ 局部变量
**完全没有默认值！**
必须**手动赋值**才能用，否则编译报错。

```java
public void go() {
    int x;
    int z = x + 3; // 编译报错：x 未初始化
}
```

---

## 3. 方法参数（小知识点）
- 参数本质上也是**局部变量**
- 但**永远不会未初始化**
- 因为调用方法时必须传参，Java 会自动把实参赋值给参数

---

# 一句话终极总结
**实例变量自带默认值，局部变量必须手动赋值。**
