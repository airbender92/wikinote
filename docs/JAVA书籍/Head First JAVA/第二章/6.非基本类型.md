# 控制你的 Dog 对象（核心翻译 + 终极理解）

你已经知道怎么声明和赋值基本类型变量了。
但**非基本类型**（也就是对象）到底是怎么回事？

## 三个关键真相
1. **根本不存在“对象变量”这东西。**
2. 只有 **对象引用变量（object reference variable）**。
3. 引用变量里存的，是**找到对象的地址信息**，而不是对象本身。

---

## 引用变量到底是什么？
- 它不装对象本身
- 它装的是一个**指针 / 地址 / 定位方式**
- 你不需要知道具体地址长什么样
- 但 JVM 知道怎么通过它找到堆里的真实对象

**对象永远不会被塞进变量里。**

---

## 基本类型 vs 引用变量
- **基本类型变量**：杯子里直接装**数值本身**
- **引用变量**：杯子里装的是**通往对象的“地图”**

---

## 对象住在哪里？
唯一地点：
**垃圾回收堆（Garbage Collectible Heap）**

对象永远在堆里，
引用变量只是**遥控器**。

---

## 点运算符（.）= 按遥控器按钮
```java
myDog.bark();
```

意思是：
> **用 myDog 这个遥控器，让堆里那只狗执行 bark() 方法。**

你可以把引用变量想象成**电器遥控器**：
- 遥控器不是电器本身
- 但你能用它操控电器做事

**Dog 引用 = Dog 遥控器**

---

# 最简总结
```java
Dog d = new Dog();
d.bark();
```

- `d` 是**遥控器**（引用）
- `new Dog()` 在堆里造出**真狗**
- `d.bark()` 用遥控器让狗叫

**变量不装对象，只装对象的地址。**
