# 这段代码的核心：**引用切换 → 对象被抛弃 → 垃圾回收**

## 第一步
```java
Book b = new Book();
Book c = new Book();
```
- 创建 **2 个引用**：b、c
- 创建 **2 个对象** 在堆上
- 每个引用各指向一个对象

**活跃引用：2**
**可达对象：2**

---

## 第二步
```java
b = c;
```
- 把 c 的**引用（遥控器）复制给 b**
- 现在 **b 和 c 都指向同一个对象（Object 2）**
- 原来 b 指向的 **Object 1 彻底没有引用了**
  → 被抛弃，**符合 GC 回收条件**

**活跃引用：2**
**可达对象：1**
**被弃对象：1**

---

## 第三步
```java
c = null;
```
- 把 c 设为 null → 不再指向任何对象
- 但 **b 还在指向 Object 2**
  → Object 2 仍然安全，不会被回收

**活跃引用：1**
**null 引用：1**
**可达对象：1**
**被弃对象：1**

---

# 最关键的一句话
**引用赋值只是换遥控器，不是复制对象。
当一个对象没有任何引用指向它时，就会被 GC 清理。**
