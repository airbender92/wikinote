# 比较变量：== 和 equals() 核心区别

## 1. 用 `==` 比较
**`==` 永远只比较变量里的**二进制位**。**

### ① 比较基本类型（int、byte、boolean 等）
```java
int a = 3;
byte b = 3;
if (a == b) → true
```
- 只要数值一样，位模式一样 → **true**

### ② 比较引用类型（对象、数组）
```java
Foo a = new Foo();
Foo b = new Foo();
Foo c = a;

a == b → false（两个不同对象）
a == c → true（同一个对象）
```
- `==` 看的是：**两个引用是不是指向堆上同一个对象**
- 不看对象内容，只看地址

---

## 2. 用 `equals()` 比较
**比较两个不同对象的“内容是否相等”。**

```java
String s1 = new String("Hello");
String s2 = new String("Hello");

s1 == s2 → false（不同对象）
s1.equals(s2) → true（内容一样）
```

- `==`：比地址
- `equals()`：比内容（具体怎么才算相等，由类自己定义）

---

# 终极口诀
- **基本类型比数值：用 `==`**
- **引用比是否同一个对象：用 `==`**
- **两个不同对象比内容：用 `equals()`**
