# 引用赋值的核心：赋值 = 复制遥控器，不复制对象

```java
Book b = new Book();
Book c = new Book();
Book d = c;
```

### 第一步
- 声明 `b` 和 `c` 两个引用
- 在堆上**创建 2 个 Book 对象**
- `b` 指向第一个对象
- `c` 指向第二个对象

**引用数：2**
**对象数：2**

---

### 第二步
```java
Book d = c;
```

- 声明第三个引用变量 `d`
- **没有创建新对象**
- 只是把 `c` 里的**遥控器地址复制了一份给 `d`**

结果：
**`c` 和 `d` 指向同一个堆对象**
就像**两个遥控器操控同一台电视**

**引用数：3**
**对象数：2**

---

### 第三步
```java
c = b;
```

- 把 `b` 的遥控器地址复制给 `c`
- 现在 `b` 和 `c` 指向同一个对象
- 原来 `c` 指向的对象现在**只有 `d` 还在引用它**

**引用数：3**
**对象数：2**

---

# 终极结论
- **引用之间赋值（d = c）**
  → 只复制**地址（遥控器）**
  → **不会创建新对象**
- 多个引用可以指向**同一个对象**
- 对象本身永远在堆里，不会被复制

一句话记忆：
**Java 只有赋值，没有克隆；赋值 = 复制遥控器，不造新电视。**
