# Java 是按值传递（pass-by-value）
意思就是：**传递的是副本，是拷贝**。

---

## 步骤 1
```java
int x = 7;
```
变量 `x` 里存的是二进制 `00000111`（也就是 7）。

## 步骤 2
声明一个带参数的方法：
```java
void go(int z) { }
```

## 步骤 3
调用方法，把 `x` 传进去：
```java
foo.go(x);
```
- **把 x 的值复制一份**
- 副本送进方法，赋值给 `z`
- **x 和 z 现在是两个独立的变量**

## 步骤 4
在方法里修改 `z`：
```java
void go(int z) {
    z = 0;
}
```
- `z` 变成 0
- **原来的 x 完全不受影响！**

---

# 核心结论
- Java 传参永远是 **传值 = 传拷贝**
- 方法内部改参数变量，**不会改变外面原来的变量**
- 两个变量互不关联，只是一开始值相同

一句话记住：
**Java 只传复印件，不改原件。**
