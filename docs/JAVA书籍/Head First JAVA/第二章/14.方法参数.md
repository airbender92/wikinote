# 核心翻译 + 方法传参极简理解

你可以**给方法传东西**。
就像其他语言一样，Java 允许把值传给方法。

比如你想让一只狗叫 3 声，可以这样调用：
```java
d.bark(3);
```

---

## 术语简单区分（不用纠结）
- **调用者传进去的叫：arguments（实参）**
- **方法里接收的叫：parameters（形参）**

简单记：
**参数 = 方法里的局部变量，用来接收外面传进来的值。**

---

## 重要规则
如果一个方法**声明了参数**，你就**必须传对应类型的值**，不能少、不能类型错。

---

## 示例代码
```java
void bark(int numOfBarks) {
    while (numOfBarks > 0) {
        System.out.println("ruff");
        numOfBarks = numOfBarks - 1;
    }
}
```

调用：
```java
Dog d = new Dog();
d.bark(3);
```

---

## 执行过程
1. 调用 `bark(3)`，把 **3** 作为实参传进去
2. 3 进入方法，赋值给参数 `numOfBarks`
3. `numOfBarks` 就像普通局部变量一样在方法里使用
4. 循环 3 次，输出 3 声 ruff

---

# 一句话记住
**参数 = 方法的“入口变量”
实参给值，形参接收，类型必须匹配。**
