# 核心翻译 + 要点

你可以**从方法里拿回东西**。

方法可以**返回值**。
每个方法都有一个**返回类型**，只不过我们之前一直用的是 **`void`**，表示什么都不返回。

```java
void go() {
}
```

但你也可以声明方法返回一个具体类型的值，比如：

```java
int giveSecret() {
    return 42;
}
```

## 重要规则
如果你声明方法要返回一个值，
就**必须返回对应类型的值**！

- 声明返回 `int` → 必须 return 一个 int
- 声明返回 `Dog` → 必须 return 一个 Dog 对象
编译器绝不允许返回错误类型。

---

## 调用与接收
```java
int theSecret = life.giveSecret();
```

- 方法返回代表 42 的二进制值
- 这个值被接收进变量 `theSecret` 中
- **两边类型必须匹配**

---

# 一句话记住
**方法声明返回什么类型，就必须返回什么类型，调用方要用同类型变量接收。**
