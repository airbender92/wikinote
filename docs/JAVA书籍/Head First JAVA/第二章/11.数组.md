# Java 数组完整翻译+核心知识点（Head First 原文解读）
## 一、数组定位与优势
Java 标准库提供集合（Map、Tree、Set）等复杂数据结构，但**数组**适合快速、有序、高效存储一组同类型数据：
1. 依靠**索引下标**实现极速随机访问；
2. 内存连续，性能远高于集合容器。

## 二、数组元素本质
数组里每一个位置都是一个变量，分两类：
1. **基本类型数组（int[] / char[] / boolean[]）**
   每个元素直接存**真实数值**（int、小数、字符等）；
2. **对象引用数组（Dog[] / Book[]）**
   每个元素存**对象引用（遥控器）**，**不存对象本身**。
   `Dog[] dogs` 数组里只能放 Dog 的引用，想要真正的狗，必须单独 `new Dog()` 创建对象。

## 三、重中之重：数组永远是对象
**无论数组存基本类型还是引用，数组本体一定是堆中的对象**：
- `int[] nums`：数组对象存堆，内部7个格子放int数值；
- `Dog[] dogs`：数组对象存堆，内部格子存Dog引用（null或对象地址）；
- 8种基本类型不能叫对象，但**承载它们的数组一定是对象**。

## 四、创建int数组的三步流程
```java
int[] nums;
nums = new int[7];
nums[0] = 6;
nums[1] = 19;
nums[2] = 44;
nums[3] = 42;
nums[4] = 10;
nums[5] = 20;
nums[6] = 1;
```
### 步骤1：声明数组引用变量
```java
int[] nums;
```
栈中创建数组遥控器 `nums`，此时值为 `null`，不指向任何堆数组对象。

### 步骤2：在堆创建数组对象并绑定引用
```java
nums = new int[7];
```
1. `new int[7]` 在堆开辟**连续7个int空间**，int默认初始值为0；
2. 返回数组对象地址，赋值给 `nums`；
3. 数组长度固定为7，运行中不可修改。

### 步骤3：逐个给数组元素赋值
```java
nums[0] = 6;
```
数组下标从 **0** 开始，`nums[下标]` 本质就是一个普通int变量，可以读写数值。

## 五、内存模型极简区分
1. **基本类型数组 int[]**
   堆上数组对象内部直接存放数字（0、6、19…）；
2. **引用类型数组 Dog[]**
   堆上数组对象内部存放一堆遥控器（引用），默认全是 `null`，需要手动 `new Dog()` 再赋值给数组格子。

## 六、关键考点总结
1. 数组是**引用类型、堆对象**，和普通类对象规则一致；
2. 数组变量只是引用（遥控器），数组本体在堆；
3. 定长，创建时必须指定长度；
4. 元素只能是同一种类型；
5. 基本数组存数值，对象数组存引用；
6. 下标从0开始，通过索引快速随机访问。
