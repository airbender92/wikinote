# 原文核心翻译 + 习题答案

## 你可千万别洒出来……
必须确保**值能装进变量里**。
你不能把一个大杯子里的东西，倒进一个小杯子。

好吧，其实硬要做也可以，但你会**损失数据**，也就是所谓的 **溢出（spillage）**。
编译器会尽量阻止这种事，只要它从代码里看出来：
这个东西放不进你用的容器（变量/杯子）。

比如：你不能把一个 int 倒进 byte 里：
```java
int x = 24;
byte b = x; // 不行！！
```

你会问：x 明明是 24，完全装得下 byte 啊？
问题在于：
**编译器只看类型大小，不看具体数值。**
它只知道：int 比 byte 大，可能会溢出，所以直接禁止。

## 给变量赋值的几种方式
- 直接写字面值：`x = 12;`
- 把一个变量赋给另一个：`x = y;`
- 用表达式：`x = y + 43;`

# Sharpen your pencil 答案
下面哪些是**合法（legal）**的？

1. `int x = 34.5;`
   → ❌ 不合法
   小数不能直接放进 int

2. `boolean boo = x;`
   → ❌ 不合法
   布尔和数字不能互相赋值

3. `int g = 17;`
   → ✅ 合法

4. `int y = g;`
   → ✅ 合法

5. `y = y + 10;`
   → ✅ 合法

6. `short s;`
   → ✅ 合法（只是声明）

7. `s = y;`
   → ❌ 不合法
   int 比 short 大，不能直接放

8. `byte b = 3;`
   → ✅ 合法

9. `byte v = b;`
   → ✅ 合法

10. `short n = 12;`
    → ✅ 合法

11. `v = n;`
    → ❌ 不合法
    short 比 byte 大

12. `byte k = 128;`
    → ❌ 不合法
    byte 最大只能到 127

# 最终合法列表
**3、4、5、6、8、9、10**
