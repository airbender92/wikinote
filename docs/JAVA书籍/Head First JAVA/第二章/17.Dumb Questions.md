# Dumb Questions + 核心要点（精简版）

## Q：如果传的是对象而不是基本类型呢？
A：Java **永远按值传递**，一切都是拷贝。
对象变量存的是**引用（遥控器）**，所以传过去的是**遥控器的拷贝**。
两个遥控器控制**同一个对象**。

## Q：方法能返回多个值吗？
A：只能直接返回**一个**值。
但可以把多个值装进**数组 / 集合**，一次性返回。

## Q：必须返回声明的 exact 类型吗？
A：可以返回能**自动向上转换**的类型，比如 byte → int。
大类型转小类型必须**强转**。

## Q：可以不理会返回值吗？
A：可以。
不一定非要接收或使用返回值，只执行方法的逻辑也可以。

# BULLET POINTS（必背）
- 类 = 对象的**状态（实例变量）+ 行为（方法）**
- 方法用实例变量，让同类对象表现不同
- 方法参数：数量、类型、顺序必须匹配
- 传参可以是字面量或变量
- 返回值类型必须兼容声明类型
- `void` 表示不返回
- Java 严格检查类型，绝不允许乱传乱返

一句话记住：
**Java 只传拷贝，严格控类型，方法靠状态表现不同行为。**
