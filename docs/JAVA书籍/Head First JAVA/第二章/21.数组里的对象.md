# 数组里的对象怎么调用方法？

**数组里的对象，行为和普通对象完全一样。**
唯一区别是：**拿到遥控器（引用）的方式不同**。

普通对象：
```java
Dog d = new Dog();
d.bark();
```

数组里的对象：
```java
Dog[] pets = new Dog[7];
pets[0] = new Dog();

// 直接用 数组[下标] 当引用调用方法
pets[0].bark();
```

---

# 完整过程

1. 创建数组对象
   ```java
   Dog[] pets = new Dog[7];
   ```
   → 得到 7 个 `null` 的 Dog 引用，**没有真狗**。

2. 创建真实 Dog 对象并放进数组
   ```java
   pets[0] = new Dog();
   pets[1] = new Dog();
   ```

3. 调用方法
   ```java
   pets[0].bark();
   pets[1].setSize(30);
   ```

---

# 关键点
- `pets[0]` 本身就是一个 **Dog 引用**
- 所以可以直接用：
  ```java
  数组[下标].方法()
  数组[下标].变量
  ```
- 数组只是**装遥控器的盒子**，不是装狗本身

---

# 一句话总结
**数组里的对象，用 数组[下标] 当引用，
后面直接加点 `.` 调用方法就行。**
