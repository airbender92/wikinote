# 引用变量 vs 基本类型变量（图解+核心翻译）

## 一句话
**对象引用只是变量里的另一种值——一个遥控器。**

- 基本类型变量：值就是**数据本身**（7、true、'a'）
- 引用变量：值是**找到堆中对象的地址**（遥控器）

你不需要关心 JVM 内部怎么实现引用，
反正它只能用来**找到并操作对象**。

---

# 创建对象的 3 个步骤
```java
Dog myDog = new Dog();
```

## 1 声明引用变量
```java
Dog myDog;
```
- 分配一个引用变量空间
- 类型永远是 `Dog`
- 相当于造一个**只能控制 Dog 的遥控器**

## 2 创建对象
```java
new Dog();
```
- 在 **堆（heap）** 上给新 Dog 对象分配空间
- 创建真实的对象本身

## 3 把引用赋值给变量
```java
myDog = new Dog();
```
- 将新对象的地址交给 `myDog`
- 相当于**把遥控器和真实狗狗配对**

---

# 内存对比

## 基本类型：byte x = 7;
变量里直接存二进制值：
`00000111`

## 引用类型：Dog myDog = new Dog();
- 变量里存：**指向 Dog 对象的地址（遥控器）**
- **对象本身并不在变量里！**
- 对象永远在堆里

---

# 终极对比

| 基本类型变量 | 引用类型变量 |
|------------|-------------|
| 存**实际数值** | 存**对象地址/遥控器** |
| 大小固定（8/16/32/64位） | 大小与对象无关，JVM 决定 |
| 变量 = 数据 | 变量 = 指向堆中对象的入口 |

一句话记住：
**基本类型装值，引用类型装地址；对象永远在堆里。**
