# 核心翻译 + 运行结果讲解

## 大小影响叫声
小狗和大狗的叫声完全不一样。
Dog 类里有一个实例变量 **size**，
`bark()` 方法会根据它来决定发出什么样的叫声。

---

## Dog 类
```java
class Dog {
    int size;
    String name;

    void bark() {
        if (size > 60) {
            System.out.println("Wooof! Wooof!");
        } else if (size > 14) {
            System.out.println("Ruff! Ruff!");
        } else {
            System.out.println("Yip! Yip!");
        }
    }
}
```

- 大于 60 → 低沉的 Wooof
- 14 ~ 60 → 普通的 Ruff
- 14 以下 → 尖细的 Yip

---

## 测试类
```java
class DogTestDrive {
    public static void main (String[] args) {
        Dog one = new Dog();
        one.size = 70;

        Dog two = new Dog();
        two.size = 8;

        Dog three = new Dog();
        three.size = 35;

        one.bark();
        two.bark();
        three.bark();
    }
}
```

---

## 运行输出
```
Wooof! Wooof!
Yip! Yip!
Ruff! Ruff!
```

---

# 核心思想
**同一个方法 bark()，
因为每个狗的 size 不同，
运行结果完全不一样。**

这就是：
**状态（size）影响行为（bark）。**
