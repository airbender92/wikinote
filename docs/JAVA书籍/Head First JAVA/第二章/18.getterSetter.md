# 核心翻译 + 要点

这就是 Java 里最常用的 **Getter 和 Setter**（规范叫法：Accessor & Mutator）。

## 作用
- **Getter**：获取实例变量的值（返回值）
- **Setter**：设置实例变量的值（带参数）

好处：
- 控制对实例变量的访问
- 符合 Java 规范
- 方便后期加验证逻辑

---

## 命名规范
- 取：`getXxx()`
- 改：`setXxx(参数)`
- 布尔类型也可以用 `isXxx()`

---

## 示例类
```java
class ElectricGuitar {
    String brand;
    int numOfPickups;
    boolean rockStarUsesIt;

    // Getter
    String getBrand() {
        return brand;
    }
    // Setter
    void setBrand(String aBrand) {
        brand = aBrand;
    }

    int getNumOfPickups() {
        return numOfPickups;
    }
    void setNumOfPickups(int num) {
        numOfPickups = num;
    }

    boolean getRockStarUsesIt() {
        return rockStarUsesIt;
    }
    void setRockStarUsesIt(boolean yesOrNo) {
        rockStarUsesIt = yesOrNo;
    }
}
```

---

# 一句话记住
**Getter 负责读，Setter 负责写，统一命名，规范安全。**
