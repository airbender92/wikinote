# 离开 main，真正进入面向对象

## 核心观点
只要代码还堆在 `main()` 里，你就不算真正在 **Objectville（对象世界）**。

- `main()` 只是**测试或启动入口**
- 真正的 OO 程序是：**对象之间互相调用方法、互相协作**
- 而不是靠静态的 main 去操控一切

## main 的两个正确用途
1. **测试类**：创建对象、调用方法、验证功能
2. **启动类**：程序入口，创建初始对象，然后把“接力棒”交给对象去跑

---

# 示例：猜数字游戏（OO 版）
## 三个类分工
1. **GameLauncher**
   - 包含 `main()`
   - 只做一件事：启动游戏

2. **GuessGame**
   - 游戏核心逻辑
   - 生成随机数
   - 创建玩家
   - 让玩家猜、判断输赢

3. **Player**
   - 每个玩家有自己猜的数字
   - 有 `guess()` 方法自己出一个猜测值

## 流程（真正的 OO 交互）
1. `GameLauncher.main()` 启动
2. 创建 `GuessGame` 对象
3. 调用 `game.startGame()`
4. 游戏对象内部：
   - 创建 3 个 Player
   - 生成随机目标数字
   - 让每个玩家调用 `guess()`
   - 比较、宣布结果

## 类结构简图
### Player
- knows: `number`（自己猜的数）
- does: `guess()`

### GuessGame
- knows: 目标数字、3 个玩家
- does: `startGame()`、控制整个流程

### GameLauncher
- does: `main()` → 启动游戏

---

# 关键点
- **main 只负责启动，不负责业务**
- 启动之后，全部逻辑由**对象之间互相调用**完成
- 这才是真实 Java 应用的运行方式

## 1. Player 类
```java
public class Player {
    // 玩家猜的数字
    int number = 0;

    // 玩家自己猜一个 0~9 的随机数
    public void guess() {
        number = (int) (Math.random() * 10);
        System.out.println("I'm guessing " + number);
    }
}
```

---

## 2. GuessGame 类（核心游戏逻辑）
```java
public class GuessGame {
    // 三个玩家对象
    Player p1;
    Player p2;
    Player p3;

    public void startGame() {
        // 1. 创建三个玩家
        p1 = new Player();
        p2 = new Player();
        p3 = new Player();

        int guessp1 = 0;
        int guessp2 = 0;
        int guessp3 = 0;

        boolean p1isRight = false;
        boolean p2isRight = false;
        boolean p3isRight = false;

        // 生成 0~9 的随机目标数字
        int targetNumber = (int) (Math.random() * 10);
        System.out.println("I'm thinking of a number between 0 and 9...");

        // 死循环，直到有人猜对
        while (true) {
            System.out.println("Number to guess is " + targetNumber);

            // 让每个玩家猜
            p1.guess();
            p2.guess();
            p3.guess();

            // 取出每个玩家猜的数字
            guessp1 = p1.number;
            guessp2 = p2.number;
            guessp3 = p3.number;

            System.out.println("Player one guessed " + guessp1);
            System.out.println("Player two guessed " + guessp2);
            System.out.println("Player three guessed " + guessp3);

            // 判断是否猜对
            if (guessp1 == targetNumber) {
                p1isRight = true;
            }
            if (guessp2 == targetNumber) {
                p2isRight = true;
            }
            if (guessp3 == targetNumber) {
                p3isRight = true;
            }

            // 只要有一个人对，游戏结束
            if (p1isRight || p2isRight || p3isRight) {
                System.out.println("We have a winner!");
                System.out.println("Player one got it right? " + p1isRight);
                System.out.println("Player two got it right? " + p2isRight);
                System.out.println("Player three got it right? " + p3isRight);
                System.out.println("Game is over.");
                break; // 退出循环
            } else {
                System.out.println("Players will have to try again.");
            }
        }
    }
}
```

---

## 3. GameLauncher 启动类（含 main）
```java
public class GameLauncher {
    public static void main(String[] args) {
        // 创建游戏对象，开始游戏
        GuessGame game = new GuessGame();
        game.startGame();
    }
}
```

# 顺便讲一下垃圾回收（书上小知识点）
- 所有对象都存在 **Heap（堆）**
- 当对象再也用不到时，JVM 自动回收
- 程序员不用手动 free / delete
- Java 有 **Garbage Collector（GC）** 自动管理内存
