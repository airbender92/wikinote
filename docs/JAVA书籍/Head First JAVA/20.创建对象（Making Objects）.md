# 创建对象（Making Objects）完整讲解

## 1. 先写一个类：定义对象长什么样
以 `Dog` 类为例：

```java
class Dog {
    // 实例变量（对象的状态）
    int size;
    String breed;
    String name;

    // 方法（对象的行为）
    void bark() {
        System.out.println("Ruff! Ruff!");
    }
}
```

- 这个类只是**模板**，不是真正的狗
- 规定了狗有：大小、品种、名字
- 规定了狗会：叫（bark）

---

## 2. 再写一个测试类（TestDrive）
用来运行程序、创建对象、测试对象。
**只有测试类有 main 方法**。

```java
class DogTestDrive {
    public static void main(String[] args) {
        // 在这里创建和使用 Dog 对象
    }
}
```

---

## 3. 在 main 里创建对象并使用
### ① 创建对象
```java
Dog d = new Dog();
```

### ② 使用 **点运算符（.）** 访问对象
- 访问变量：`d.size`
- 调用方法：`d.bark()`

完整测试代码：
```java
class DogTestDrive {
    public static void main(String[] args) {
        // 创建一只狗对象
        Dog d = new Dog();

        // 给它设置大小
        d.size = 40;

        // 让它叫
        d.bark();
    }
}
```

运行输出：
```
Ruff! Ruff!
```

---

## 核心知识点

### 类 vs 对象
- **Dog 类**：蓝图
- **d 引用**：指向一只真实的狗对象

### 点运算符（.）
作用：**访问对象的变量和方法**
- `d.size` → 读/改大小
- `d.bark()` → 让狗执行叫的行为

### 本书惯例
以后几乎所有例子都会有两个类：
1. 真实业务类：`Dog`、`Cat`、`Alarm`…
2. 测试类：`DogTestDrive`，里面只有 main 方法，用来跑代码
