# 思考对象：对象有什么？能做什么？

## 核心思想
设计一个类时，只需要想两件事：
1. **对象知道什么（knows）** → 状态 = **实例变量（instance variables）**
2. **对象能做什么（does）** → 行为 = **方法（methods）**

---

## 几个示例对照

### ShoppingCart（购物车）
- **knows（实例变量）**
  - cartContents（购物车内容）
- **does（方法）**
  - addToCart()
  - removeFromCart()
  - checkOut()

### Button（按钮）
- **knows**
  - label（标签文字）
  - color（颜色）
- **does**
  - setColor()
  - setLabel()
  - dePress()
  - unDepress()

### Alarm（闹钟）
- **knows**
  - alarmTime（闹钟时间）
  - alarmMode（闹钟模式）
- **does**
  - setAlarmTime()
  - setAlarm()
  - isAlarmSet()
  - snooze()

### Song（歌曲）
- **knows**
  - title（歌名）
  - artist（歌手）
- **does**
  - setTitle()
  - setArtist()
  - play()

---

## 关键概念
- **实例变量（instance variables）**
  对象自己保存的数据，代表它的**状态**。
  每个对象可以有自己独特的值。

- **方法（methods）**
  对象能执行的行为，通常用来读取或修改实例变量。

# 练习：Television（电视机）
按照同样模式，一个电视对象可以这样设计：

## Television
- **knows（实例变量）**
  - currentChannel（当前频道）
  - currentVolume（当前音量）
  - isPoweredOn（是否开机）
- **does（方法）**
  - turnOn()
  - turnOff()
  - changeChannel()
  - increaseVolume()
  - decreaseVolume()
  - mute()
