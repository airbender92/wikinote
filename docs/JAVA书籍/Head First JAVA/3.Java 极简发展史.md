# Java 极简发展史
## 版本演进 & 核心特性、类库规模
### 1. Java 1.02
- 标准类库：250 个类
- 优缺点与特点：运行速度缓慢、存在大量 Bug；拥有辨识度高的名称与图标，使用体验有趣
- 标志性技术：Applet（网页小程序）是该版本核心亮点

### 2. Java 1.1
- 标准类库：500 个类
- 升级改进：运行速度小幅提升，功能更完善、易用性更强，市场热度快速上涨
- 重点优化：图形界面（GUI）代码大幅优化

### 3. Java 2（对应版本 1.2 ~ 1.4）
- 标准类库：2300 个类
- 性能与定位：运行速度大幅提升，部分场景可接近原生程序性能；语言正式走向成熟、功能强大
- 三大分支体系：
  - J2ME（微型版）：移动端开发
  - J2SE（标准版）：桌面通用程序
  - J2EE（企业版）：企业、Web 服务开发
- 行业地位：成为企业项目、移动端开发首选编程语言

### 4. Java 5.0（内部版本号 1.5，代号 Tiger 老虎）
- 标准类库：3500 个类
- 核心变革：新增超千个工具类，同时对**语言语法本身做大规模革新**
- 价值：吸收其他编程语言的优秀特性，大幅降低开发难度，开发能力全面升级
