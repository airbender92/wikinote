# Code Magnets 代码重组习题完整解答
## 需求说明
零散代码片段打乱，需要按Java语法重新排序，程序运行输出：`a-b c-d`

## 完整正确可运行代码
```java
class Shuffle1 {
    public static void main(String [] args) {
        int x = 3;
        while (x > 0) {
            if (x > 2) {
                System.out.print("a");
            }
            x = x - 1;
            System.out.print("-");
            if (x == 2) {
                System.out.print("b c");
            }
            if (x == 1) {
                System.out.print("d");
                x = x - 1;
            }
        }
    }
}
```

## 逐行执行推演（验证输出 `a-b c-d`）
初始值：`x = 3`
### 第1轮循环（x=3）
1. `x>2` → true，打印 `a`
2. `x = 3 - 1 = 2`
3. 打印 `-` → 当前输出：`a-`
4. `x==2` → true，打印 `b c` → 当前输出：`a-b c`
5. `x==1` → false，无操作
循环结束，回到`while(x>0)`判断，x=2继续循环

### 第2轮循环（x=2）
1. `x>2` → false，不打印
2. `x = 2 - 1 = 1`
3. 打印 `-` → 当前输出：`a-b c-`
4. `x==2` → false
5. `x==1` → true，打印 `d`，`x=0` → 当前输出：`a-b c-d`
循环结束，回到`while(x>0)`判断，x=0退出循环

### 最终控制台输出
`a-b c-d` 与题目要求完全匹配

## 代码排序核心规则
1. Java程序最外层必须是 `class 类 {}`；
2. 类内部必须包含 `main()` 入口方法；
3. 变量声明 `int x = 3;` 写在main方法最开头；
4. `while` 循环包裹所有分支if判断；
5. 循环内执行顺序：先判断`x>2`打印a → x自减 → 打印分隔符`-` → 依次判断x=2、x=1打印对应字符；
6. 所有`if`、`while`都配套成对大括号`{}`包裹代码块。当前文件内容过长，豆包只阅读了前 71%。
