这句代码就是：**创建一个最简单的 TCP 服务器**，核心行为只有一句话：

# 代码作用
```js
const server = net.createServer(socket => {
  // 每当有客户端连上来，就会执行这里
  socket.end('hello from single-thread server \n');
});
```

1. **`net.createServer`**
   创建一个 TCP 服务端，监听端口，等待客户端连接。

2. **传入的回调函数 = 【连接事件】处理函数**
   - 每有一个客户端**成功建立 TCP 连接**
   - 就会触发一次这个回调
   - 参数 `socket` 代表**当前这条客户端连接**（可读可写）

3. **`socket.end(data)`**
   - 先把字符串发给客户端
   - 然后**正常关闭这个连接**

等价于：
```js
socket.write('hello ...');
socket.end();
```

---

# 关键点（和你前面知识串起来）
- 整个服务**只有一个主线程**
- 来 1 个连接 → 跑一次回调
- 来 1000 个连接 → 还是这一个线程在跑
- 靠**IO 多路复用**（epoll/kqueue）实现，**不创建新线程**

这就是 Node 高并发网络模型的核心。

----

`server.listen(...)` 就是：
**让这个 TCP 服务器**开始监听端口、接受客户端连接。

---

## 你代码里的写法
```js
server.listen(0, '127.0.0.1', () => {
  const port = server.address().port;
  // ...
});
```

### 1. 参数含义
- **`0`**
  不指定固定端口，让操作系统**自动分配一个空闲端口**。

- **`127.0.0.1`**
  只在本机监听，外部机器连不进来。

- **回调函数**
  服务器**成功启动、开始监听**之后才执行。

---

## 2. 执行后发生什么
1. 操作系统给当前程序开辟一个 **socket 监听**
2. 开始在 `127.0.0.1` 上等待客户端连接
3. 有客户端连上来时，才触发你之前的：
   ```js
   net.createServer((socket) => { ... })
   ```

---

## 3. 常用完整形式
```js
server.listen(端口, IP地址, 启动成功回调);
```

---

## 4. 和你这段测试逻辑的关系
1. `listen(0)` 随机开端口
2. 拿到端口后，立刻批量建立 50 个客户端连接
3. 测试单线程服务器能同时处理多少连接
4. 验证 **IO 多路复用** 高并发能力

---

### 一句话总结
`server.listen` = **启动服务器，开始监听连接请求**。
