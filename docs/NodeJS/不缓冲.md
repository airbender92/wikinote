# “不缓冲”是什么意思？
**不缓冲 = 不等攒满，有一点就立刻吐出来。**

---

# 对比一下你就懂了

## 1. 缓冲（exec 这种）
- 命令执行完**所有输出先放内存里攒着**
- 等整个命令结束，**一次性全部给你**
- 就像：**先装满一桶水，再整桶倒给你**

问题：
- 输出特别大时，内存会爆
- 要等很久才能看到结果

## 2. 不缓冲（spawn 这种）
- 命令**一边运行，一边实时输出**
- 产生一点数据，就立刻通过流发给你
- 就像：**水龙头打开，水直接流过来**

特点：
- 不用等结束
- 不会占大量内存
- 实时看到日志、进度

---

# 一句话总结
**不缓冲 = 实时输出，不攒数据，有就发。**

- 大输出、长任务 → 必须用 **spawn 不缓冲**
- 小命令、短结果 → 用 **exec 缓冲** 更方便
