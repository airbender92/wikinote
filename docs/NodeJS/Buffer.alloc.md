```javascript
Buffer.alloc(20 * 1024 * 1024, 0)
```

这句话的意思是：

### 1. 大小
- `20 * 1024 * 1024` = **20,971,520 字节**
- 也就是 **20 MB** 的 Buffer

### 2. 含义
- `Buffer.alloc(size, fill)`
- 创建一个**长度固定**的 Node.js 二进制缓冲区
- 并用 `0`（二进制 `0x00`）**全部填充初始化**

### 3. 特点
- 安全：会**清零内存**，不会残留旧数据
- 同步、阻塞：创建 20MB 很快，基本无感
- 常用于：
  - 大文件读写缓存
  - 二进制协议打包
  - 内存池、预分配缓冲区

### 等价简写
```javascript
Buffer.alloc(20 * 1024 * 1024)
```
因为 `fill` 默认就是 `0`，可以不写。
