你这是在 **PowerShell** 里跑，**不能直接用 Linux/macOS 那种写法**，语法不一样。

## PowerShell 正确写法
```powershell
$env:UV_THREADPOOL_SIZE=10; node demo.js
```

## CMD 里的写法（如果你用 cmd.exe）
```cmd
set UV_THREADPOOL_SIZE=10 && node demo.js
```

## 为什么你报错？
- `UV_THREADPOOL_SIZE=10 node app.js` 是 **Linux / macOS 终端**语法
- Windows PowerShell 不认，会把它当成一个命令，所以提示“不是可执行程序”

---

## 最简单：写在 JS 顶部（最稳）
在你的 `demo.js` **最开头**加一行：
```javascript
process.env.UV_THREADPOOL_SIZE = '10';

// 下面再写你的 crypto、pbkdf2、测试代码
```
然后直接运行：
```powershell
node demo.js
```
一样生效，还不用记命令行语法。

- 线程池变成 10
- 并发 8 个 pbkdf2
- 总耗时 ≈ **1 倍单次耗时**，而不是 2 倍
- 证明并行数真的变大了
