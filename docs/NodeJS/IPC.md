# IPC 是什么？
**IPC = Inter-Process Communication**
中文：**进程间通信**

简单说：
**让两个独立的 Node.js 进程，能互相发消息、传数据。**

---

# 用最通俗的话讲
你打开两个独立的 Node 程序：
- 一个是**父进程**（主程序）
- 一个是**子进程**（fork 出来的）

它们本来是**完全隔离**的，内存不共享、变量不互通。

IPC 就是在它们之间**搭了一条专用通道**：
- 父进程 send → 子进程收到
- 子进程 send → 父进程收到

就像：
- 两个独立房间的人
- 中间拉了一根**内部电话线**
- 只能它们俩用，安全、快速

---

# 在 Node.js 集群里，IPC 用来干嘛？
1. **发指令**
   主进程告诉子进程：重启、关闭、状态上报

2. **传数据**
   日志、配置、任务信息

3. **最关键：传递服务句柄**
   把服务器“钥匙”发给子进程，让大家共用一个端口

---

# 代码里长这样
父进程：
```javascript
child.send('hello 子进程')
```

子进程：
```javascript
process.on('message', (msg) => {
  console.log(msg) // hello 子进程
})
```

这就是 IPC 在工作。

---

# 一句话总结
**IPC 就是父子进程之间的专用通信通道，
让它们能发消息、传数据、甚至传递服务器句柄，实现集群多进程协作。**
