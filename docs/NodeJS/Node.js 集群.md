用最直白、好懂的方式说：

# Node.js 集群（Cluster）是什么
**Node.js 集群 = 一个主进程 + 多个子进程，一起监听同一个端口，充分利用电脑多核 CPU。**

---

## 为什么需要它？
Node.js 默认是**单线程、单进程**的：
- 再强的 CPU，它也只用**一个核心**
- 并发高一点就容易阻塞、变慢
- 多核 CPU 完全浪费了

Cluster 就是为了解决这个问题。

---

## 集群到底干了啥？
1. 启动一个**主进程（master）**
2. 主进程根据 CPU 核心数，`fork` 出多个**工作进程（worker）**
3. 主进程创建服务器，把**服务句柄**通过 IPC 发给所有子进程
4. 所有子进程**共享同一个端口**（比如 3000）
5. 新请求进来时，操作系统自动把连接分给空闲的子进程

结果就是：
**一个应用，多进程同时干活，性能成倍提升。**

---

## 一句话总结
> Node.js 集群，就是让 Node.js 能用上电脑所有 CPU 核心，用多进程并行处理请求，解决单线程性能瓶颈。
