## 一、估值的本质：一句话理解

估值的本质就是回答一个问题：**"这家公司到底值多少钱？"**

但"值多少钱"不是拍脑袋，而是有科学方法的。核心思路有两个方向：

| 方向 | 方法 | 核心逻辑 | 类比 |
|------|------|---------|------|
| **绝对估值** | DCF 现金流折现 | 公司价值 = 未来能赚的钱折算到今天 | 买一只母鸡，算它一辈子能下多少蛋 |
| **相对估值** | PE/PB 等乘数法 | 同行类似的鸡卖多少钱，这只也差不多 | 菜市场比价，别人买多少我买多少 |
| **分红估值** | DDM 股利折现 | 公司价值 = 未来分红折算到今天 | 买一只母鸡，算它每年下蛋卖多少钱 |

**核心心法**：
- 估值永远是一个**区间**，不是一个精确的数字
- 多种方法**交叉验证**，不要只信一种
- 先看懂公司，再算数字；数字只是工具，不是结论

|------|------------|------|------|

## 三、方法一：DCF 现金流折现法（绝对估值）

### 3.1 核心原理

**一家公司的价值 = 未来所有年份自由现金流的现值总和。**

通俗理解：如果你把公司当成一台"印钞机"，那它的价值就是你未来能从它手里拿到的所有现金，折算成今天的钱。

### 3.2 四个步骤

```
  ① 预测5年FCF          ② 折现到现值           ③ 永续终值          ④ 求和
┌────────┬────────┬────────┬────────┬────────┐
│  Y1    │  Y2    │  Y3    │  Y4    │  Y5    │
│ FCF₁   │ FCF₂   │ FCF₃   │ FCF₄   │ FCF₅   │
└───┬────┴───┬────┴───┬────┴───┬────┴───┬────┘
    │        │        │        │        │
    ▼        ▼        ▼        ▼        ▼
 ÷(1+r)¹  ÷(1+r)²  ÷(1+r)³  ÷(1+r)⁴  ÷(1+r)⁵
    │        │        │        │        │
    ▼        ▼        ▼        ▼        ▼
  PV₁      PV₂      PV₃      PV₄      PV₅      TV终值
    └────────┴────────┴────────┴────────┴───┬────┘
                                            │
                    ┌───────────────────────┤
                    ▼                       ▼
        企业价值 = PV₁+PV₂+PV₃+PV₄+PV₅ + 终值现值
                    减净负债 = 股权价值
                    ÷ 总股本 = 每股价值
```

#### 第一步：预测未来5年自由现金流（FCF）

```
FCF（自由现金流）= 经营现金流 - 资本支出
```

- **经营现金流**：公司经营活动实际收到的现金（赚钱的"含金量"）
- **资本支出 CapEx**：维持和扩大经营必须花的钱（买设备、建厂房）
- **预测方法**：预测营收增长率 × 预测FCF利润率，逐年推算

新手参考：FCF/净利润 比值建议 >80%，说明利润是"真金白银"而不是纸面数字。

#### 第二步：计算折现率（WACC）

```
Ke（股权成本）= 无风险利率 + β × 风险溢价
```

| 参数 | 含义 | 参考取值 |
|------|------|---------|
| 无风险利率 | 10年期国债收益率 | 中国约2.5-3%，美国约4% |
| 风险溢价 ERP | 股票市场平均超额收益 | 5-7%，新兴市场7-8% |
| 贝塔 β | 股票相对大盘的波动性 | β=1 跟随大盘，>1 更激进，<1 更稳 |

**为什么需要折现？**
今天的100元比明年的100元更值钱，因为你可以拿今天的100元去买国债赚利息。折现率 r 就是这种"机会成本"的量化。

#### 第三步：计算永续终值（Terminal Value）

```
TV = 第5年FCF × (1 + 永续增长率) / (折现率 - 永续增长率)
终值现值 = TV / (1 + r)^5
```

- 永续增长率 g 通常取 **2-4%**，不应超过GDP增速
- 现实中 5 年之后公司依然存在，但无法逐年预测，所以用这个公式一次性估算
- **注意**：终值通常占企业价值的一半以上，所以 g 和 r 的取值对结果影响巨大

#### 第四步：汇总估值

```
企业价值 = 5年FCF现值之和 + 终值现值
股权价值 = 企业价值 - 净负债（总负债 - 货币资金）
每股价值 = 股权价值 / 总股本
```

### 3.3 适用与局限

- ✅ 适合：现金流稳定、可预测的成熟公司（消费品、公用事业、基础设施）
- ❌ 不适合：初创公司（无历史数据）、强周期行业（盈利大起大落）、高杠杆金融公司
- ⚠️ 局限：对折现率 r 和永续增长率 g 极其敏感 → 必须做敏感性分析

## 四、方法二：相对估值法（乘数法）

### 4.1 核心原理

**找几家"差不多的同行"，看市场给它们的估值倍数，套用到目标公司。**

这是券商和投行最常用的方法，因为简单、直观、贴近市场情绪。

### 4.2 四大核心指标

| 指标 | 公式 | 含义 | 适用场景 | 示例 |
|------|------|------|---------|------|
| **PE 市盈率** | 市值 ÷ 净利润 | 花多少年赚回投资 | 盈利稳定的消费、制造 | PE=20 → 20年回本 |
| **PB 市净率** | 市值 ÷ 净资产 | 股价是净资产的几倍 | 银行、地产等重资产 | PB=1.5 → 贵50% |
| **PS 市销率** | 市值 ÷ 营业收入 | 市值是营收的几倍 | 亏损但营收高的互联网 | 适合初创企业 |
| **EV/EBITDA** | 企业价值 ÷ 息税折旧前利润 | 剔除资本结构影响 | 跨国/跨资本结构对比 | 投行最常用 |

**行业指标选择速查**：
- 白酒、食品饮料、家电 → **PE**
- 银行、保险、地产 → **PB**
- 互联网、云计算、SaaS → **PS / PE**
- 钢铁、煤炭、有色等周期股 → **EV/EBITDA**（周期低谷 PE 反而虚高）
- 医药、科技高成长 → **PEG = PE / 增速**（越低越好，<1 有吸引力）

### 4.3 操作四步

```
① 选可比公司 → ② 收集乘数数据 → ③ 算行业均值 → ④ 均值 × 目标指标
```

**选可比公司的标准**：
1. 同行业（细分领域尽量一致）
2. 类似规模（市值、营收量级相近）
3. 同商业模式（如都是"自营+加盟"，不要一家自营一家纯加盟）

### 4.4 完整示例：给某白酒公司估值

```
背景：目标公司去年净利润 20亿，总股本 10亿股，当前股价 40元

找到4家同行白酒公司，它们的 PE 分别为：25、28、30、27
→ 行业平均 PE = (25+28+30+27) / 4 = 27.5

目标公司合理市值 = 行业PE × 目标净利润 = 27.5 × 20 = 550亿元
目标公司每股合理价 = 550 / 10 = 55元/股

对比：当前股价 40元 < 合理价 55元 → 低估 27%（值得关注）
```

### 4.5 注意事项

- 可比公司要真的"可比"，选错参照物结果就全错
- 去掉极端值再平均（避免个别亏损公司污染均值）
- 相对估值反映的是"市场情绪定价"，市场整体泡沫时所有公司都会被高估

## 五、方法三：DDM 股利折现模型

### 5.1 核心公式（Gordon 增长模型）

```
P = D₁ / (r - g) = D₀ × (1 + g) / (r - g)
```

| 符号 | 含义 |
|------|------|
| P | 合理股价 |
| D₀ | 当前每股股利 |
| D₁ | 下一期每股股利 = D₀ × (1+g) |
| r | 要求回报率（折现率，可用 CAPM 算出的 Ke） |
| g | 股利永续增长率 |

**条件**：r 必须 > g，否则公式无意义。

### 5.2 适用场景

- ✅ 适合：分红稳定、分红率高的公司（银行、高速公路、电力、公用事业）
- ❌ 不适合：不分红、分红不稳定、高成长的科技公司

### 5.3 示例

```
某银行当前每股股利 0.5元，历史股利增速 5%，要求回报率 10%
P = 0.5 × (1+5%) / (10% - 5%) = 0.525 / 0.05 = 10.5元/股
```

## 六、实操六步走（从0到1）

```
┌─────┐   ┌─────┐   ┌─────┐   ┌─────────┐   ┌─────┐   ┌─────┐
│ 1    │ → │ 2    │ → │ 3    │ → │ 4        │ → │ 5    │ → │ 6    │
│ 看懂 │   │ 看行 │   │ 扒财 │   │ 算估值   │   │ 敏感 │   │ 对比 │
│ 公司 │   │ 业   │   │ 报   │   │ (交叉验证)│   │ 性   │   │ 市价 │
└─────┘   └─────┘   └─────┘   └─────────┘   └─────┘   └─────┘
```

### 第1步：看懂公司
- 主营业务是什么？用一句话说清赚钱模式
- 核心竞争力（护城河）：品牌？渠道？成本？技术？牌照？
- 主要风险点有哪些？

### 第2步：看行业
- 行业规模多大？增速快慢？（判断天花板）
- 竞争格局：集中度高不高？（CR3/CR5）
- 进入壁垒：新玩家容易进来吗？
- 政策环境：利好还是受限？

### 第3步：扒财报（近3年）
- **利润表**：营收、净利润、毛利率、净利率 → 看赚钱能力
- **资产负债表**：总资产、总负债、净资产 → 看家底和风险
- **现金流量表**：经营现金流、资本支出、自由现金流 → 看利润含金量
- **关键比率**：
  - ROE（净资产收益率）> 15% 优秀；8-15% 中等；<8% 较差
  - FCF/净利润 > 80% 说明利润是现金
  - 资产负债率 < 60% 较稳健

### 第4步：算估值（多种方法交叉验证）
- 用 DCF 算绝对价值
- 用相对估值（PE/PB）算市场价值
- 若分红稳定，再用 DDM 验证
- 三种结果取合理区间（建议按 DCF 50% + 相对估值 35% + DDM 15% 加权）

### 第5步：做敏感性分析
- 折现率 ±1%、永续增长率 ±0.5%，观察估值波动范围
- 找出"最坏情况"和"最好情况"的估值区间
- 只有你对参数的信心区间内，估值才有意义

### 第6步：对比市价，做判断

| 情况 | 判断 | 参考动作 |
|------|------|---------|
| 估值 > 市价 20%+ | 偏低估 | 值得深入研究 |
| 偏差在 ±20% 内 | 基本合理 | 继续跟踪 |
| 估值 < 市价 20%+ | 偏高估 | 保持谨慎 |

## 七、新手常见误区

1. **只用一种方法就下结论**
   → 至少交叉验证2种，DCF 和相对估值互相校验

2. **把"预测"当"事实"**
   → DCF 的假设（增长率、折现率）都会错，所以必须看区间而不是精确数字

3. **忽略定性因素**
   → 管理层、品牌护城河、行业趋势无法量化但极其重要，估值数字再好，管理层不行也白搭

4. **为了估值而估值**
   → 先看懂公司再看数字。对不理解的公司，算出再漂亮的估值也没有意义

5. **拿周期股的 PE 说事**
   → 周期股在盈利高点 PE 最低（看似便宜实则最贵），要结合行业周期位置判断

6. **忽视负债结构**
   → 同样 PE 的公司，高负债公司风险大得多，要用 EV/EBITDA 或结合负债看

## 九、术语速查表

| 术语 | 全称 | 含义 |
|------|------|------|
| FCF | 自由现金流 | 经营现金流 - 资本支出，公司真正能支配的钱 |
| CapEx | 资本支出 | 维持/扩大经营的投资（设备、厂房） |
| WACC | 加权平均资本成本 | 公司融资的综合成本，用作折现率 |
| Ke | 股权成本 | 股东要求的回报率 = Rf + β×ERP |
| β (Beta) | 贝塔系数 | 股票相对大盘的波动程度 |
| ERP | 股权风险溢价 | 股票相对无风险资产的超额回报 |
| TV | 永续终值 | 预测期之后公司价值的估算 |
| DCF | 现金流折现 | 绝对估值法 |
| DDM | 股利折现 | 分红折现估值法 |
| PE | 市盈率 | 市值 ÷ 净利润 |
| PB | 市净率 | 市值 ÷ 净资产 |
| PS | 市销率 | 市值 ÷ 营业收入 |
| EV | 企业价值 | 市值 + 净负债（收购一家公司要花的钱） |
| EBITDA | 息税折旧摊销前利润 | 剔除利息、税、折旧、摊销的利润 |
| ROE | 净资产收益率 | 净利润 ÷ 净资产，衡量股东资金赚钱效率 |
| CAGR | 复合年增长率 | 多年平均年增速 |
| TTM | 滚动12个月 | 最近连续12个月的数据 |
