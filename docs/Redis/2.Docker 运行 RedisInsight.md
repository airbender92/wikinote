# Docker 运行 RedisInsight（官方Web可视化客户端）

> 新版镜像：`redis/redisinsight`，Web端口 **5540**

## 1. 直接docker run启动

### 简单版（配置不持久，删容器丢失连接配置）

```bash
docker run -d --name redisinsight -p 5540:5540 redis/redisinsight:latest
```

### 推荐持久化版本（保存连接列表、配置）

```bash
# 创建数据卷
docker volume create redisinsight-data

# 启动
docker run -d \
  --name redisinsight \
  -p 5540:5540 \
  -v redisinsight-data:/data \
  --restart unless-stopped \
  redis/redisinsight:latest
```

浏览器访问：**http://127.0.0.1:5540**

## 2. 重点：RedisInsight 连接 docker 内的 Redis（坑点）

> ❗ 容器内部的 `127.0.0.1` 是 redisinsight 自己，**不是宿主机redis**

你之前启动的redis容器名字叫 `redis-server`

### 方案A：同一自定义docker网络（最稳，推荐）

```bash
# 创建网络
docker network create redis-net

# 把redis加入网络（你已启动就执行connect）
docker network connect redis-net redis-server

# 启动redisinsight也加入这个网络
docker run -d \
  --name redisinsight \
  --network redis-net \
  -p 5540:5540 \
  -v redisinsight-data:/data \
  --restart unless-stopped \
  redis/redisinsight:latest
```

Web界面添加数据库：

- **Host：redis-server**（直接填redis容器名字，docker DNS自动解析）
- Port：`6379`
- Password：你的redis密码（没有就留空）

### 方案B：填宿主机局域网IP

Host填你电脑本机局域网IP，不要填127.0.0.1。

> Windows/Mac docker desktop 可用 `host.docker.internal`；Linux不支持这个域名。

## 3. docker‑compose.yml 一键同时启动 Redis + RedisInsight

新建 `docker-compose.yml`

```yaml
version: "3.8"

networks:
  redis-net:
    driver: bridge

volumes:
  redis-data:
  redisinsight-data:

services:
  redis-server:
    image: redis
    container_name: redis-server
    ports:
      - "6379:6379"
    volumes:
      - redis-data:/data
    command: redis-server --requirepass 123456 --appendonly yes
    restart: unless-stopped
    networks:
      - redis-net

  redisinsight:
    image: redis/redisinsight:latest
    container_name: redisinsight
    ports:
      - "5540:5540"
    volumes:
      - redisinsight-data:/data
    restart: unless-stopped
    networks:
      - redis-net
```

启动：

```bash
docker compose up -d
```

访问：http://127.0.0.1:5540
添加数据库 Host填：`redis-server`，端口6379，密码`123456`

## 常用管理命令

```bash
# 查看容器
docker ps | grep redis

# 查看日志
docker logs -f redisinsight

# 停止
docker stop redisinsight

# 删除
docker rm -f redisinsight
```

## 常见报错

1. **Connection refused**：不要填127.0.0.1，用容器名，保证两个容器在同一个docker网络。
2. **密码错误**：redis启动的`--requirepass`要和web填写完全一致。
3. 页面打不开：确认宿主机防火墙放行5540端口。

> 补充：还有一个镜像 `redis/redis-stack`，里面内置redis+redisinsight，端口8001，适合快速玩，但生产一般分开部署redis‑server和insight。

### 报错含义

容器名字 `redisinsight` 已经存在，不能再新建同名容器。两种处理方案：

## 方案1：删掉旧容器（最常用）

```bash
# 删除旧的 redisinsight 容器
docker rm -f redisinsight
```

> `-f` 强制删除，不管容器正在运行还是停止。

删除完成后，再执行你之前的 run 命令或者 `docker compose up -d` 即可。

## 方案2：重命名旧容器，保留不删

```bash
docker rename redisinsight redisinsight-old
```

重命名之后，就可以正常新建 `redisinsight`。

## 快速排查命令

```bash
# 查看所有容器(包含停止的)
docker ps -a | grep redisinsight
```

可以看到容器ID、状态。

### 完整示例流程（直接复制执行）

```bash
# 强制清理旧容器
docker rm -f redisinsight

# 重新启动（持久化版本）
docker volume create redisinsight-data
docker run -d \
  --name redisinsight \
  -p 5540:5540 \
  -v redisinsight-data:/data \
  --restart unless-stopped \
  redis/redisinsight:latest
```

浏览器访问：`http://127.0.0.1:5540`

> 如果你是用 docker‑compose，执行：

```bash
docker compose down
docker compose up -d
```

`down` 会销毁compose管理的容器，再重建。
