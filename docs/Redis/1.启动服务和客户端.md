# Docker 启动 Redis 服务 + 客户端

## 1. 拉取 redis 镜像

```bash
docker pull redis
```

默认拉取最新版，也可以指定版本如 `redis:7.4`

## 2. 启动 Redis 服务端容器

### 方式1：简单运行（无密码，数据容器内，删除容器数据丢失）

```bash
docker run -d --name redis-server -p 6379:6379 redis
```

参数说明：

- `-d`：后台守护运行
- `--name redis-server`：容器名字
- `-p 6379:6379`：把宿主机6379端口映射到容器6379
- `redis`：使用的镜像

### 方式2：带密码、持久化（生产推荐）

```bash
docker run -d \
  --name redis-server \
  -p 6379:6379 \
  -e REDIS_PASSWORD=123456 \
  -v /data/redis:/data \
  redis redis-server --requirepass 123456 --appendonly yes
```

- `--requirepass 123456` 设置访问密码
- `--appendonly yes` 开启AOF持久化
- `-v /data/redis:/data` 数据挂载到宿主机，容器删除数据不丢

## 3. 使用 redis‑cli 客户端连接

### 方式A：进入容器内部使用 redis‑cli

```bash
# 无密码
docker exec -it redis-server redis-cli

# 如果设置了密码
docker exec -it redis-server redis-cli -a 123456
```

进入后就可以执行 redis 命令：`set key value`、`get key`

### 方式B：宿主机本地redis-cli连接（需要宿主机安装redis客户端）

```bash
# 本地连接
redis-cli -h 127.0.0.1 -p 6379 -a 123456
```

### 方式C：临时启动一个redis客户端容器连接（不安装redis客户端）

```bash
# 连接本机docker的redis服务
docker run --rm -it redis redis-cli -h host.docker.internal -p 6379 -a 123456
```

> Linux环境 `host.docker.internal` 不一定生效，可以填宿主机局域网IP

## 4. 常用管理命令

```bash
# 查看容器状态
docker ps |grep redis-server

# 停止redis
docker stop redis-server

# 启动已停止容器
docker start redis-server

# 删除容器
docker rm -f redis-server
```

## 小测试验证是否可用

进入cli后执行：

```redis
set name test
get name
```

返回 `test` 代表部署成功。

> ⚠️注意：如果设置密码，每次连接都需要 `-a 密码`，登录后也可以 `auth 123456` 认证。
