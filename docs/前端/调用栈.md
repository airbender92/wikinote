简单用**最通俗、不绕弯**的方式给你讲清楚：

# 调用栈（Call Stack）
可以理解成**程序执行时的“任务记录本”**，遵循 **后进先出（LIFO）** 规则。

## 它是干嘛的？
- 记录当前**正在执行的函数**
- 保存每个函数的**局部变量、参数、返回地址**
- 函数调用时入栈，执行完出栈

## 特点
- 空间小、速度快
- 自动分配、自动释放
- 栈满了会爆：**栈溢出（Stack Overflow）**
- 线程独有，每个线程一个调用栈

## 举个例子
```js
function a() { b(); }
function b() { c(); }
function c() {}

a();
```
调用顺序：
`a 入栈 → b 入栈 → c 入栈 → c 出栈 → b 出栈 → a 出栈`

---

# 堆内存（Heap）
就是程序的**大仓库**，用来放**大块、长期存在的数据**。

## 它是干嘛的？
- 存放对象、数组、动态创建的数据
- 生命周期由开发者/垃圾回收控制
- 不限制大小（受限于系统内存）

## 特点
- 空间大、速度比栈慢
- 手动分配 / 自动 GC 回收
- 不会“栈溢出”，但可能**内存泄漏**
- 多线程共享堆内存

---

# 一句话区别
- **调用栈**：管函数执行流程，小而快，自动生死。
- **堆**：管数据存储，大而灵活，手动/GC 生死。
