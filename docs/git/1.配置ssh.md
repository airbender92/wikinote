明白了，你需要从**私有仓库**进行 `git clone` 或相关操作。私有仓库需要身份认证，常见有两种方式：**SSH 密钥**（推荐） 或 **HTTPS + 个人访问令牌**。

下面给你一步步配置说明（以 GitLab / GitHub 为例）。

---

## 一、推荐方式：SSH 密钥（一次配置，长期使用）

### 1. 生成 SSH 密钥（如果还没有）
```bash
ssh-keygen -t ed25519 -C "你的邮箱@example.com"
```
一路回车即可（不设密码也行）。  
生成后密钥位置：`~/.ssh/id_ed25519`（私钥）和 `~/.ssh/id_ed25519.pub`（公钥）

### 2. 查看公钥并添加到 Git 平台
```bash
cat ~/.ssh/id_ed25519.pub
```
复制输出的全部内容（以 `ssh-ed25519` 开头）。

- **GitLab**：登录 → 右上角头像 → Preferences → SSH Keys → 粘贴公钥 → Add key
- **GitHub**：Settings → SSH and GPG keys → New SSH key → 粘贴 → Add

### 3. 测试连接
```bash
ssh -T git@gitlab.com   # 如果是 GitLab
ssh -T git@github.com   # 如果是 GitHub
```
看到类似 `Welcome to GitLab, @你的用户名!` 即成功。

### 4. 克隆私有仓库（使用 SSH 地址）
在仓库页面点击 **Clone → SSH** 复制地址，例如：
```bash
git clone git@gitlab.com:组织名/项目名.git
```

---

## 二、备选方式：HTTPS + 个人访问令牌（适合短期或环境受限）

### 1. 生成个人访问令牌（Personal Access Token, PAT）
- **GitLab**：Settings → Access Tokens → 勾选 `read_repository` / `write_repository` → 创建 → 复制令牌（只显示一次）
- **GitHub**：Settings → Developer settings → Personal access tokens → Tokens (classic) → 勾选 `repo` → 生成

### 2. 使用令牌克隆
```bash
git clone https://gitlab.com/组织名/项目名.git
```
此时会提示输入用户名和密码：
- 用户名：你的 Git 平台用户名
- 密码：**粘贴刚才生成的令牌**（不是登录密码）

### 3. （可选）避免每次输令牌 – 缓存凭据
```bash
git config --global credential.helper cache
```

---

## 三、常见注意事项

- **仓库存在但克隆时 404 / Permission denied**：
  - 请确认你的账号对该私有仓库有访问权限（至少 Reporter 或 Developer）
  - 检查克隆地址是否与平台显示的 SSH/HTTPS 地址完全一致
- **公司内网私有仓库**：
  - 可能需要先连接 VPN
  - 可能使用自签证书，可配置 `git config --global http.sslVerify false`（不推荐长期，仅临时测试）
