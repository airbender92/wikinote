很好，仓库已经克隆成功。现在切换到指定分支，步骤如下：

## 一、先查看所有可用分支（包括远程）

进入项目目录：
```powershell
cd istorm-bcms-business-ui
```

查看远程分支（全量，不受Web页面20个限制）：
```powershell
git branch -r
```
这会列出所有远程分支，例如 `origin/3.3.0-cs`、`origin/4.0.0-dev` 等。

如果分支太多，可以过滤搜索（比如找包含 `3.3.0` 的）：
```powershell
git branch -r | findstr "3.3.0"
```

## 二、切换到目标分支

假设你要切换到 `3.3.0-cs` 分支（之前 merge 信息里出现过）：

```powershell
git checkout 3.3.0-cs
```
如果提示本地没有该分支，会自动基于远程创建跟踪分支。

或者更明确地基于远程分支创建本地分支：
```powershell
git checkout -b 3.3.0-cs origin/3.3.0-cs
```

## 三、确认当前分支

```powershell
git branch
```
当前所在的分支前面会有 `*` 号。

---

**注意**：如果你需要切换到的是 `4.0.0-dev` 这类分支，把命令中的分支名替换一下即可。

如果你不确定要切换的分支具体叫什么名字，可以执行 `git branch -r` 把输出发给我，我帮你找出你要的分支名。
