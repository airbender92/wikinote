# git 查看提交代码地址
## 1、查看远程仓库地址
```bash
git remote -v
```
输出示例：
```
origin  shturl.cc/YvMIu9lUXzThOf3BT6gf (fetch)
origin  shturl.cc/YvMIu9lUXzThOf3BT6gf (push)
```
fetch：拉取地址；push：推送提交代码的地址

## 2、查看当前仓库配置的远程url
```bash
git remote get-url origin
```

## 3、看某次提交是来自哪个远程（一般不常用）
> git commit 本身不记录提交者推送的远程地址，commit只记录作者、邮箱、时间、哈希；推送地址存在本地git配置里，不在commit对象。

## 4、查看提交人信息（commit里的作者邮箱用户名）
```bash
# 简洁日志
git log --pretty=format:"%h %an %ae %s"
```
- `%an` 提交作者名字
- `%ae` 提交作者邮箱

## 5、修改推送远程地址
```bash
git remote set-url origin https://new-url.git
```

## 区分两个容易混淆概念
1. **remote url**：你本地git往哪里push代码（上面命令查看）
2. **commit author**：代码提交人的名字邮箱，写在commit记录内，和推送仓库地址无关

如果你想看**某一条commit记录对应的仓库地址**：git本身做不到，commit对象不含远程仓库地址，只能看你当前本地配置的远程地址。
