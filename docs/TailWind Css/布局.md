## Tailwind CSS 布局工具类详解

Tailwind 提供了一套完整、低级别的布局工具类，覆盖 CSS 盒模型、定位、显示类型等所有基础布局属性，让你无需离开 HTML 就能构建任意复杂的布局。

---

### 1. Display（显示类型）

| 类名 | CSS 值 | 适用场景 |
|------|--------|----------|
| `block` | `display: block` | 块级元素，独占一行，宽高生效 |
| `inline-block` | `display: inline-block` | 行内块，不换行但可设宽高 |
| `inline` | `display: inline` | 行内元素，宽高无效 |
| `flex` | `display: flex` | 弹性容器（子元素使用 Flex 布局） |
| `inline-flex` | `display: inline-flex` | 行内弹性容器 |
| `grid` | `display: grid` | 网格容器 |
| `inline-grid` | `display: inline-grid` | 行内网格容器 |
| `table` | `display: table` | 表格布局（慎用） |
| `hidden` | `display: none` | 隐藏元素（不占空间） |

**响应式变体示例**：

```html
<div class="block md:flex lg:grid">
  <!-- 移动端 block，平板 flex，桌面 grid -->
</div>
```

**注意**：`hidden` 与 `invisible` 的区别：`invisible` 隐藏但占据空间（`visibility: hidden`）。

---

### 2. Position（定位类型）

| 类名 | CSS 值 | 定位基准 |
|------|--------|----------|
| `static` | `position: static` | 默认值，忽略偏移属性 |
| `relative` | `position: relative` | 相对于自身正常位置偏移，不脱离文档流 |
| `absolute` | `position: absolute` | 相对于最近的非 static 祖先元素 |
| `fixed` | `position: fixed` | 相对于视口，滚动时不移动 |
| `sticky` | `position: sticky` | 基于滚动位置在 relative 和 fixed 之间切换 |

**典型用法**：

```html
<div class="relative">
  <!-- 父容器作为定位参考 -->
  <div class="absolute top-0 right-0">角标</div>
</div>

<nav class="sticky top-0 bg-white shadow">
  <!-- 滚动到顶部时固定 -->
</nav>
```

---

### 3. 定位偏移（inset / top / right / bottom / left）

Tailwind 使用简洁的类名控制偏移量，支持预定义比例尺和任意值。

#### 单边偏移

| 类名 | 含义 | 示例 |
|------|------|------|
| `top-{size}` | `top: {size}` | `top-4`（16px） |
| `right-{size}` | `right: {size}` | `right-2`（8px） |
| `bottom-{size}` | `bottom: {size}` | `bottom-0`（0px） |
| `left-{size}` | `left: {size}` | `left-1/2`（50%） |

#### 四边同时设置（inset）

| 类名 | CSS 值 |
|------|--------|
| `inset-0` | `top:0; right:0; bottom:0; left:0` |
| `inset-x-0` | `left:0; right:0`（水平方向） |
| `inset-y-0` | `top:0; bottom:0`（垂直方向） |

**负值偏移**：使用 `-top-4`、`-inset-x-2` 等（仅支持部分预定义值）。

**任意值示例**：

```html
<div class="absolute top-[10px] left-[calc(50%+2rem)] right-[var(--offset)]">
  <!-- 任意 CSS 值 -->
</div>
```

**常用技巧**：结合 `inset-0` 和 `m-auto` 实现绝对居中：

```html
<div class="relative h-64 w-64 bg-gray-200">
  <div class="absolute inset-0 m-auto w-32 h-32 bg-blue-500">
    <!-- 完全居中 -->
  </div>
</div>
```

### 4. Z-Index（层叠顺序）

Tailwind 提供从 `0` 到 `50` 的整数级别，以及 `auto`：

| 类名 | CSS 值 |
|------|--------|
| `z-0` | `z-index: 0` |
| `z-10` | `z-index: 10` |
| `z-20` … `z-50` | `20`, `30`, `40`, `50` |
| `z-auto` | `z-index: auto` |

**注意**：默认步长为 10，最高 `z-50`。如需更高值，可使用任意值：`z-[100]`。

**使用场景**：

```html
<div class="relative">
  <div class="absolute z-10">浮在上层</div>
  <div class="absolute z-0 bg-white">背景层</div>
</div>
```

---

### 5. 盒模型（box-sizing）

Tailwind 提供两个类来控制盒模型：

| 类名 | CSS 值 | 说明 |
|------|--------|------|
| `box-border` | `box-sizing: border-box` | 宽度/高度包含内边距和边框（推荐） |
| `box-content` | `box-sizing: content-box` | 宽度/高度仅指内容区域（传统 W3C 盒模型） |

Tailwind **默认启用** `box-border`（通过 Preflight 重置），所以一般情况下无需显式添加。如需特定元素切换为 `content-box`：

```html
<div class="box-content w-64 p-4 border">
  <!-- 实际宽度 = 64px + 左右 padding + 左右 border -->
</div>
```

---

### 6. 浮动与清除（float & clear）

#### 浮动（float）

| 类名 | CSS 值 |
|------|--------|
| `float-left` | `float: left` |
| `float-right` | `float: right` |
| `float-none` | `float: none` |

**注意**：在现代开发中，浮动主要用于文字环绕图片等少数场景，布局推荐使用 Flexbox 或 Grid。

#### 清除浮动（clearfix）

Tailwind 不直接提供 `.clearfix` 类，但可以通过以下方式清除浮动：

- **手动清除**：`clear-left` / `clear-right` / `clear-both`
- **使用 `after` 伪类**（自定义工具类）：
  ```css
  .clearfix::after {
    content: "";
    display: table;
    clear: both;
  }
  ```
  然后用 `@apply clearfix` 或直接扩展插件。

**实用技巧**：替代浮动的更优方案是 Flexbox：

```html
<div class="flex justify-between">
  <!-- 避免浮动 -->
</div>
```

### 完整示例：综合使用布局类

```html
<!-- 固定导航栏 + 内容区滚动 -->
<nav class="fixed top-0 left-0 w-full z-50 bg-white/90 backdrop-blur p-4 shadow">
  Logo
</nav>

<main class="relative pt-20">
  <!-- 卡片网格 -->
  <div class="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-6">
    <div class="bg-white rounded-lg shadow p-4">
      <div class="relative">
        <img src="..." class="w-full h-48 object-cover rounded">
        <span class="absolute top-2 right-2 bg-red-500 text-white text-xs px-2 py-1 rounded-full z-10">
          热卖
        </span>
      </div>
      <h3 class="text-lg font-bold mt-2 box-border">商品名称</h3>
    </div>
  </div>
</main>

<!-- 悬浮按钮 -->
<button class="fixed bottom-4 right-4 z-50 bg-blue-600 text-white p-3 rounded-full shadow-lg">
  ↑
</button>
```

---

### 总结

| 类别 | 关键类 | 核心技巧 |
|------|--------|----------|
| Display | `flex`, `grid`, `hidden` | 结合响应式前缀实现自适应 |
| Position | `relative`, `absolute`, `fixed`, `sticky` | `relative` + `absolute` 创建局部定位 |
| 偏移 | `inset-0`, `top-4`, `left-1/2` | `inset-0`+`m-auto` 居中；任意值突破限制 |
| Z-Index | `z-10` ~ `z-50`, `z-auto` | 默认步长 10，可任意值 `z-[100]` |
| 盒模型 | `box-border`（默认） | 通常无需配置，除非特殊需求 |
| 浮动 | `float-left/right` | 仅用于文字环绕，现代布局用 Flex/Grid |

Tailwind 的布局类设计遵循“单一职责、自由组合”原则，让你能快速搭建任何布局模式，同时保持可维护性。
