## Tailwind CSS 配置文件 (`tailwind.config.js`)

### 创建与初始化

在项目根目录下运行以下命令生成基础配置文件：

```bash
npx tailwindcss init
```

这会在当前目录创建 `tailwind.config.js`，默认内容为：

```javascript
/** @type {import('tailwindcss').Config} */
module.exports = {
  content: [],
  theme: {
    extend: {},
  },
  plugins: [],
}
```

如需生成带注释的完整配置文件（展示所有默认配置），可以运行：

```bash
npx tailwindcss init --full
```

---

### 配置项结构详解

#### 1. `content`（必需）

指定 Tailwind 扫描哪些文件以提取使用的类名（用于生产环境清除未使用的样式）。支持通配符。

```javascript
content: [
  './index.html',
  './src/**/*.{js,ts,jsx,tsx,vue}',
  // 可以排除某些文件
  '!./src/ignore/**/*',
],
```

**替代了 v2 中的 `purge` 选项**。

#### 2. `theme`

定义项目的设计系统：颜色、间距、字体、断点等。可以完全覆盖或扩展默认主题。

```javascript
theme: {
  // 完全覆盖默认主题
  screens: {
    'tablet': '640px',
    'desktop': '1280px',
  },
  colors: {
    'primary': '#1a73e8',
    'secondary': '#fbbc04',
  },
  extend: {
    // 扩展默认主题（保留默认值）
    spacing: {
      '128': '32rem',
    },
    borderRadius: {
      '4xl': '2rem',
    },
  },
},
```

常用主题键：`colors`, `spacing`, `fontFamily`, `fontSize`, `screens`, `animation`, `transitionDuration` 等。

#### 3. `plugins`

引入第三方插件或自定义插件来扩展功能（如添加新工具类、组件等）。

```javascript
plugins: [
  require('@tailwindcss/forms'),
  require('@tailwindcss/typography'),
  require('@tailwindcss/aspect-ratio'),
  function({ addUtilities }) {
    addUtilities({
      '.rotate-45': {
        transform: 'rotate(45deg)',
      },
    });
  },
],
```

#### 4. `corePlugins`

控制是否启用某些**核心插件**（即默认提供的工具类集合）。传入 `false` 可禁用，节省体积或避免命名冲突。

```javascript
corePlugins: {
  preflight: false,      // 禁用浏览器默认样式重置
  container: false,      // 禁用 .container 类
  float: false,          // 禁用 float 工具类
  // 或者使用数组形式保留部分（v3 风格较少用）
},
```

也可传入数组（仅保留列出的插件）：

```javascript
corePlugins: ['margin', 'padding', 'backgroundColor'],
```

#### 5. `presets`

允许继承其他配置（自定义预设），可合并多个配置。

```javascript
presets: [
  require('./my-base-config.js'),
  require('@acme/tailwind-preset'),
],
```

#### 6. `prefix`

给所有 Tailwind 生成的类名添加前缀（防止与现有类名冲突）。

```javascript
prefix: 'tw-',
// 现在要使用 .tw-text-center 而不是 .text-center
```

#### 7. `important`

让 Tailwind 的工具类优先级更高。可设为 `true`（添加 `!important`）或指定一个选择器（如 `'#app'`）。

```javascript
important: true,                 // 每个类后加 !important
important: '#app',               // 仅当元素在 #app 内时优先级提升
```

#### 8. `separator`

自定义类名中分隔符的字符（默认是 `:`，用于状态和响应式前缀）。

```javascript
separator: '_',
// 用法：hover_bg-red-500 而不是 hover:bg-red-500
```

#### 9. `darkMode`

配置暗色模式的启用方式。

```javascript
darkMode: 'media',   // 跟随系统（默认）
darkMode: 'class',   // 手动使用 .dark 类（适合切换主题）
darkMode: ['class', '[data-mode="dark"]'], // 自定义选择器
```

#### 10. `safelist`

防止某些类在生产环境被清除（即使未在 content 文件中检测到）。

```javascript
safelist: [
  'bg-red-500',
  'text-center',
  {
    pattern: /bg-(red|green|blue)-[0-9]+/,
    variants: ['hover', 'focus'],
  },
],
```

#### 11. `blocklist`

禁止生成特定的工具类（通常用于解决冲突）。

```javascript
blocklist: ['container', 'collapse'],
```

#### 12. `variants`（v2 中的概念，v3 已移除）

在 Tailwind CSS v3 中，`variants` 配置项**不再需要**。所有变体（`hover`, `focus`, `responsive` 等）都由核心插件根据 `theme` 自动生成，且默认启用。如果你正在升级旧项目，可以忽略此选项。

---

### 典型配置文件示例

```javascript
module.exports = {
  content: ['./index.html', './src/**/*.{vue,js,ts,jsx,tsx}'],
  theme: {
    extend: {
      colors: {
        brand: '#0f766e',
      },
      fontFamily: {
        sans: ['Inter', ...defaultTheme.fontFamily.sans],
      },
      animation: {
        'spin-slow': 'spin 3s linear infinite',
      },
    },
  },
  plugins: [require('@tailwindcss/forms')],
  corePlugins: {
    preflight: true,
    float: false,
  },
  darkMode: 'class',
  prefix: '',
  important: false,
};
```

配置文件的灵活性使 Tailwind 能够完美适配不同项目的设计约束，同时保持原子类的可预测性和生产效率。
