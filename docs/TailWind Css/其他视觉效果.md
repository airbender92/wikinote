## Tailwind CSS 其他视觉效果

Tailwind 提供了一套强大的视觉效果工具类，涵盖透明度、混合模式、滤镜、过渡动画和 2D/3D 变换。这些工具类让开发者无需编写自定义 CSS 即可实现丰富的视觉增强效果，同时保持与设计系统的一致性。

---

## 一、透明度（Opacity）

使用 `opacity-{value}` 控制元素的整体不透明度。取值范围从 0 到 100（步长为 5）。

| 类名 | CSS 值 | 说明 |
|------|--------|------|
| `opacity-0` | `0` | 完全透明 |
| `opacity-5` | `0.05` | 5% 不透明度 |
| `opacity-10` | `0.1` | 10% |
| `opacity-20` | `0.2` | 20% |
| `opacity-25` | `0.25` | 25% |
| `opacity-30` | `0.3` | 30% |
| `opacity-40` | `0.4` | 40% |
| `opacity-50` | `0.5` | 半透明 |
| `opacity-60` | `0.6` | 60% |
| `opacity-70` | `0.7` | 70% |
| `opacity-75` | `0.75` | 75% |
| `opacity-80` | `0.8` | 80% |
| `opacity-90` | `0.9` | 90% |
| `opacity-95` | `0.95` | 95% |
| `opacity-100` | `1` | 完全不透明（默认） |

**应用场景**：悬停效果、加载状态、图片淡化等。

```html
<!-- 半透明按钮，悬停时完全不透明 -->
<button class="bg-blue-500 text-white opacity-75 hover:opacity-100 transition-opacity">
  提交
</button>

<!-- 淡入淡出的图片 -->
<img src="image.jpg" class="opacity-50 hover:opacity-100 transition duration-300">
```

**注意**：`opacity` 会影响元素的所有子内容。如果只想改变背景透明度，应该使用背景色配合 `/` 语法或 `bg-opacity-*`。

## 二、混合模式（Blend Mode）

混合模式控制元素与其下方元素颜色的混合方式。Tailwind 提供两类混合模式工具：`mix-blend-*`（元素与背景混合）和 `bg-blend-*`（元素的多个背景层之间混合）。

### 1. 元素混合模式（`mix-blend-*`）

| 类名 | CSS 值 | 效果 |
|------|--------|------|
| `mix-blend-normal` | `normal` | 正常（默认） |
| `mix-blend-multiply` | `multiply` | 正片叠底（变暗） |
| `mix-blend-screen` | `screen` | 滤色（变亮） |
| `mix-blend-overlay` | `overlay` | 叠加 |
| `mix-blend-darken` | `darken` | 变暗 |
| `mix-blend-lighten` | `lighten` | 变亮 |
| `mix-blend-color-dodge` | `color-dodge` | 颜色减淡 |
| `mix-blend-color-burn` | `color-burn` | 颜色加深 |
| `mix-blend-hard-light` | `hard-light` | 强光 |
| `mix-blend-soft-light` | `soft-light` | 柔光 |
| `mix-blend-difference` | `difference` | 差值 |
| `mix-blend-exclusion` | `exclusion` | 排除 |
| `mix-blend-hue` | `hue` | 色相 |
| `mix-blend-saturation` | `saturation` | 饱和度 |
| `mix-blend-color` | `color` | 颜色 |
| `mix-blend-luminosity` | `luminosity` | 亮度 |

### 2. 背景混合模式（`bg-blend-*`）

当元素有多个背景（如背景色+背景图）时，控制它们的混合方式。类名与 `mix-blend-*` 类似：`bg-blend-normal`、`bg-blend-multiply` 等。

**示例：文字与背景的叠加效果**

```html
<!-- 正片叠底：让文字与背景融合变暗 -->
<div class="bg-blue-500">
  <h1 class="mix-blend-multiply text-white">暗色融合标题</h1>
</div>

<!-- 多背景混合 -->
<div class="bg-gradient-to-r from-red-500 to-blue-500 bg-blend-multiply">
  <!-- 内容 -->
</div>
```

> **使用建议**：混合模式常用于创意设计、图片叠加文字等场景。注意浏览器兼容性。

## 三、滤镜（Filters）

Tailwind 提供两种滤镜工具集：**标准滤镜**（`filter`）和**背投滤镜**（`backdrop-filter`）。每个滤镜类都需要配合相应的工具类使用。默认情况下，滤镜类不会自动生效，需要显式添加 `filter` 或 `backdrop-filter` 类来启用。

### 1. 标准滤镜（Filter）

| 类别 | 类名 | 说明 |
|------|------|------|
| **启用** | `filter` | 启用滤镜效果（必须） |
| **禁用** | `filter-none` | 清除所有滤镜 |
| **模糊** | `blur-none`, `blur-sm`, `blur`, `blur-md`, `blur-lg`, `blur-xl`, `blur-2xl`, `blur-3xl` | 模糊程度递增 |
| **亮度** | `brightness-0`, `brightness-50`, `brightness-75`, `brightness-90`, `brightness-100`, `brightness-105`, `brightness-110`, `brightness-125`, `brightness-150`, `brightness-200` | 亮度百分比（0 = 全黑，100 = 正常，>100 更亮） |
| **对比度** | `contrast-0`, `contrast-50`, `contrast-75`, `contrast-100`, `contrast-125`, `contrast-150`, `contrast-200` | 对比度百分比 |
| **饱和度** | `saturate-0`, `saturate-50`, `saturate-100`, `saturate-150`, `saturate-200` | 饱和度百分比（0 = 灰阶，>100 更鲜艳） |
| **灰度** | `grayscale-0`, `grayscale`（100%） | 灰度效果 |
| **色相旋转** | `hue-rotate-0`, `hue-rotate-15`, `hue-rotate-30`, `hue-rotate-60`, `hue-rotate-90`, `hue-rotate-180` | 色相旋转角度（度） |
| **反色** | `invert-0`, `invert`（100%） | 颜色反转 |
| **不透明度** | `backdrop-opacity-*`（见背投滤镜） | 滤镜的不透明度（较少直接用） |
| **投影** | `drop-shadow-sm`, `drop-shadow`, `drop-shadow-md`, `drop-shadow-lg`, `drop-shadow-xl`, `drop-shadow-2xl`, `drop-shadow-none` | 给元素添加阴影（不同于 box-shadow） |

**使用示例**：

```html
<!-- 模糊图片：悬停时增加模糊度 -->
<img class="filter blur-sm hover:blur-md transition" src="...">

<!-- 亮度调节：模拟悬停高亮 -->
<button class="filter brightness-90 hover:brightness-100 transition">
  悬停变亮
</button>

<!-- 组合多个滤镜 -->
<div class="filter grayscale contrast-125 blur-none">
  黑白且提高对比度的图像
</div>

<!-- 投影（drop-shadow）可以为透明图像（如 PNG 图标）添加阴影 -->
<img class="filter drop-shadow-lg" src="logo.png">
```

**注意**：每个滤镜类都是独立的，可以组合使用。但需注意性能，避免过多滤镜叠加。

### 2. 背投滤镜（Backdrop Filter）

背投滤镜作用于元素**后方**的区域（即透过元素看背景），不影响元素本身内容。类名与标准滤镜类似，加上 `backdrop-` 前缀。

| 启用 | `backdrop-filter` |
|禁用 | `backdrop-filter-none` |
|模糊 | `backdrop-blur-sm`, `backdrop-blur` 等 |
|亮度 | `backdrop-brightness-50` 等 |
|对比度 | `backdrop-contrast-125` 等 |
|饱和度 | `backdrop-saturate-150` 等 |
|灰度 | `backdrop-grayscale` |
|色相旋转 | `backdrop-hue-rotate-30` |
|反色 | `backdrop-invert` |
|不透明度 | `backdrop-opacity-50` |

**典型应用：毛玻璃效果（Glassmorphism）**

```html
<div class="relative h-64 bg-cover bg-center" style="background-image: url('bg.jpg')">
  <div class="absolute inset-0 backdrop-blur-md bg-white/30 flex items-center justify-center">
    <p class="text-white text-2xl font-bold">毛玻璃卡片</p>
  </div>
</div>
```

## 四、过渡与动画（Transition & Animation）

### 1. 过渡（Transitions）

过渡让 CSS 属性变化时产生平滑的动画效果。Tailwind 提供了控制过渡属性、持续时间和缓动函数的工具类。

| 类别 | 类名 | 说明 |
|------|------|------|
| **过渡属性** | `transition-none` | 无过渡 |
| | `transition-all` | 所有属性变化都过渡 |
| | `transition` | 常用属性（`background-color`, `border-color`, `color`, `fill`, `stroke`, `opacity`, `box-shadow`, `transform`） |
| | `transition-colors` | 仅颜色相关 |
| | `transition-opacity` | 仅透明度 |
| | `transition-shadow` | 仅阴影 |
| | `transition-transform` | 仅变换 |
| **持续时间** | `duration-75`, `duration-100`, `duration-150`, `duration-200`, `duration-300`, `duration-500`, `duration-700`, `duration-1000` | 毫秒数 |
| **缓动函数** | `ease-linear` | 线性 |
| | `ease-in` | 加速 |
| | `ease-out` | 减速 |
| | `ease-in-out` | 先加速后减速（默认） |
| **延迟** | `delay-75`, `delay-100`, `delay-150`, `delay-200`, `delay-300`, `delay-500`, `delay-700`, `delay-1000` | 毫秒数 |

**使用示例**：

```html
<!-- 按钮悬停时背景色和缩放平滑过渡 -->
<button class="bg-blue-500 hover:bg-blue-700 hover:scale-105 transition-all duration-300 ease-in-out">
  悬停效果
</button>

<!-- 仅透明度过渡，延迟 150ms -->
<div class="opacity-0 hover:opacity-100 transition-opacity duration-500 delay-150">
  淡入内容
</div>
```

### 2. 动画（Animations）

Tailwind 内置了几个预设动画，也可以配合自定义关键帧扩展。

| 类名 | 效果 | CSS 关键帧 |
|------|------|------------|
| `animate-none` | 无动画 | – |
| `animate-spin` | 持续旋转（常用于加载图标） | `spin { from { transform: rotate(0deg); } to { transform: rotate(360deg); } }` |
| `animate-ping` | 脉冲扩散（类似广播波） | 缩放 + 透明度 |
| `animate-pulse` | 呼吸灯效果（透明度循环） | 透明度 1 → 0.5 → 1 |
| `animate-bounce` | 上下弹跳 | 移动 0% → 100% |

```html
<!-- 加载中图标 -->
<svg class="animate-spin h-5 w-5 text-white" ...>...</svg>

<!-- 消息通知小红点，脉冲吸引注意 -->
<span class="relative flex h-3 w-3">
  <span class="animate-ping absolute inline-flex h-full w-full rounded-full bg-red-400 opacity-75"></span>
  <span class="relative inline-flex rounded-full h-3 w-3 bg-red-500"></span>
</span>
```

**自定义动画**：在 `tailwind.config.js` 的 `theme.extend.animation` 和 `keyframes` 中添加。

## 五、变换（Transforms）

变换允许 2D 或 3D 空间中对元素进行平移、旋转、缩放、倾斜等操作。Tailwind 通过 `transform` 工具类启用，并提供丰富的具体变换类。

### 1. 启用与禁用

| 类名 | CSS 值 |
|------|--------|
| `transform` | `transform: translateX(var(--tw-translate-x)) /* ... */` （启用所有变换） |
| `transform-gpu` | 使用 GPU 加速（强制 3D 渲染） |
| `transform-none` | 禁用变换 |

**重要**：大多数变换类（如 `translate-*`, `rotate-*`）需要配合 `transform` 类才能生效。不过 Tailwind 的实用类已经内置了假设，如果你使用 `translate-x-4`，它会自动设置 `transform` 属性，无需手动添加 `transform` 类（但推荐显式加上以确保最佳兼容性）。

### 2. 平移（Translate）

使用 `translate-x-{size}` 和 `translate-y-{size}` 控制平移，支持负值。

| 类名 | CSS 值 |
|------|--------|
| `translate-x-0` | `--tw-translate-x: 0px` |
| `translate-x-px` | `1px` |
| `translate-x-0.5` | `0.125rem` |
| `translate-x-1` | `0.25rem` |
| … | 一直延伸到 `translate-x-96` |
| `translate-x-full` | `100%` |
| `translate-x-1/2` | `50%` |
| `-translate-x-full` | `-100%` |
| `-translate-y-1/2` | `-50%` |

**常用场景**：垂直居中、滑动菜单、tooltip。

```html
<!-- 居中技巧：父元素 relative，子元素绝对定位加平移 -->
<div class="relative h-64">
  <div class="absolute top-1/2 left-1/2 transform -translate-x-1/2 -translate-y-1/2">
    完全居中
  </div>
</div>

<!-- 悬停时向右移动 -->
<div class="transform transition-transform hover:translate-x-2">
  向右微移
</div>
```

### 3. 缩放（Scale）

使用 `scale-{value}`、`scale-x-{value}`、`scale-y-{value}` 控制缩放。值可以是 `0`、`50`、`75`、`90`、`95`、`100`、`105`、`110`、`125`、`150` 等（百分比）。

```html
<!-- 悬停放大图片 -->
<img class="transform transition-transform hover:scale-105" src="...">

<!-- 仅水平方向拉伸 -->
<div class="scale-x-150">宽度放大 1.5 倍</div>
```

### 4. 旋转（Rotate）

使用 `rotate-{deg}` 控制旋转角度。

| 类名 | CSS 值 |
|------|--------|
| `rotate-0` | `0deg` |
| `rotate-1` | `1deg` |
| `rotate-2` | `2deg` |
| `rotate-3` | `3deg` |
| `rotate-6` | `6deg` |
| `rotate-12` | `12deg` |
| `rotate-45` | `45deg` |
| `rotate-90` | `90deg` |
| `rotate-180` | `180deg` |
| `-rotate-45` | `-45deg` |

```html
<!-- 悬停旋转 -->
<button class="transform transition-transform hover:rotate-12">旋转图标</button>
```

### 5. 倾斜（Skew）

使用 `skew-x-{deg}` 和 `skew-y-{deg}` 控制倾斜。

| 类名 | CSS 值 |
|------|--------|
| `skew-x-0` | `0deg` |
| `skew-x-1` | `1deg` |
| `skew-x-2` | `2deg` |
| `skew-x-3` | `3deg` |
| `skew-x-6` | `6deg` |
| `skew-x-12` | `12deg` |
| 负值同样支持 | `-skew-x-12` |

```html
<div class="transform skew-y-6 bg-gray-200 p-4">
  倾斜的卡片
</div>
```

### 6. 变换原点（Transform Origin）

控制变换的中心点。

| 类名 | CSS 值 |
|------|--------|
| `origin-center` | `center` |
| `origin-top` | `top` |
| `origin-top-right` | `top right` |
| `origin-right` | `right` |
| `origin-bottom-right` | `bottom right` |
| `origin-bottom` | `bottom` |
| `origin-bottom-left` | `bottom left` |
| `origin-left` | `left` |
| `origin-top-left` | `top left` |

```html
<!-- 从左上角放大 -->
<div class="transform origin-top-left hover:scale-110">...</div>
```

## 六、组合示例

```html
<!-- 1. 毛玻璃导航栏 -->
<nav class="sticky top-0 backdrop-blur-lg bg-white/70 shadow-sm z-50">
  <div class="container mx-auto px-4 py-3 flex justify-between items-center">
    <h1 class="text-xl font-bold">品牌</h1>
    <button class="transform transition-transform hover:scale-105 active:scale-95">
      菜单
    </button>
  </div>
</nav>

<!-- 2. 加载动画 -->
<div class="flex space-x-2 justify-center items-center h-32">
  <div class="w-3 h-3 bg-blue-500 rounded-full animate-bounce" style="animation-delay: 0s"></div>
  <div class="w-3 h-3 bg-blue-500 rounded-full animate-bounce" style="animation-delay: 0.2s"></div>
  <div class="w-3 h-3 bg-blue-500 rounded-full animate-bounce" style="animation-delay: 0.4s"></div>
</div>

<!-- 3. 图片悬停组合效果 -->
<div class="group relative w-64 h-64 overflow-hidden rounded-lg">
  <img src="image.jpg" class="w-full h-full object-cover transition-all duration-500 group-hover:scale-110 group-hover:blur-sm">
  <div class="absolute inset-0 bg-black/40 flex items-center justify-center opacity-0 group-hover:opacity-100 transition-opacity duration-300">
    <span class="text-white font-bold text-lg transform translate-y-4 group-hover:translate-y-0 transition-transform duration-300">
      查看详情
    </span>
  </div>
</div>

<!-- 4. 提示框箭头（带旋转和偏移） -->
<div class="relative">
  <div class="absolute -top-2 left-4 w-4 h-4 bg-white transform rotate-45 border-t border-l border-gray-200"></div>
  <div class="bg-white border border-gray-200 rounded-lg p-4 shadow-lg">
    提示内容
  </div>
</div>
```

## 七、总结

| 类别 | 关键工具 | 用途 |
|------|----------|------|
| **透明度** | `opacity-50`, `hover:opacity-100` | 淡入淡出，加载状态 |
| **混合模式** | `mix-blend-multiply`, `bg-blend-screen` | 创意叠加，照片滤镜 |
| **滤镜** | `filter blur-md`, `backdrop-blur` | 模糊图片、毛玻璃、亮度调节 |
| **过渡** | `transition-all duration-300 ease-in-out` | 让交互更平滑 |
| **动画** | `animate-spin`, `animate-pulse` | 加载、通知、吸引注意 |
| **变换** | `transform translate-x-2 rotate-45 scale-110` | 移动、旋转、缩放、倾斜 |

掌握这些工具类，你可以不写一行自定义 CSS 就实现现代 Web 应用中绝大部分视觉效果，同时保持代码的高度可维护性。
