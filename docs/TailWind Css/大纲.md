学习 Tailwind CSS 需要系统掌握从基础配置到高级定制的各类知识。以下是完整的知识清单，分为核心概念、实用工具、响应式与状态、自定义与扩展、优化与工具链五个部分。

---

### 一、核心概念
1. **原子化 CSS 思想**  
   - 为什么使用原子类（vs 语义化 CSS）  
   - 类名的可组合性与重复利用原则

2. **工具类（Utility Classes）命名规则**  
   - 属性简写规则（如 `p-` 表示 padding，`bg-` 表示 background）  
   - 数值比例尺（`0`, `px`, `0.5`, `1`, `2`, … `96`，以及任意值 `[14px]`）  
   - 负值（`-m-2`）和自动（`m-auto`）

3. **配置文件 `tailwind.config.js`**  
   - 创建与初始化（`npx tailwindcss init`）  
   - 所有配置项结构（`theme`, `plugins`, `variants`, `content`, `corePlugins` 等）

4. **与构建工具的集成**  
   - PostCSS 插件方式（Vite、Webpack、Gulp、Laravel Mix 等）  
   - 通过 CDN 引入（仅限快速原型，不推荐生产）

---

### 二、所有核心工具类（按类别划分）

#### 布局
- Display（`block`, `flex`, `grid`, `inline-block`, `hidden` 等）
- Position（`static`, `relative`, `absolute`, `fixed`, `sticky`）
- 定位偏移（`inset-0`, `top-4`, `left-[10px]` 等）
- Z-Index（`z-0` ~ `z-50`，`z-auto`）
- 盒模型（`box-border`, `box-content`）
- 浮动与清除（`float-left`, `clearfix`）

#### 间距（Margin & Padding）
- 单边与对称（`m-`, `mt-`, `mr-`, `mb-`, `ml-`；`p-`, `px-`, `py-`）
- 负边距（`-mt-4`）
- 间距比例尺与任意值

#### 尺寸（Width & Height）
- 宽度（`w-0` ~ `w-96`，`w-auto`, `w-full`, `w-screen`, `w-min`, `w-max`, `w-fit`）
- 高度（类似 `h-`, `h-screen` 等）
- 最小/最大尺寸（`min-w-0`, `max-w-screen-xl`, `min-h-full`）

#### 弹性盒子（Flexbox）
- 容器（`flex`, `inline-flex`）
- 方向（`flex-row`, `flex-col`, `flex-row-reverse`）
- 换行（`flex-wrap`, `flex-nowrap`）
- 对齐（`justify-start`, `items-center`, `align-content-between` 等）
- 子项（`flex-1`, `flex-grow`, `flex-shrink`, `flex-none`, `order-1`）

#### 网格（CSS Grid）
- 容器（`grid`, `inline-grid`）
- 模板列/行（`grid-cols-1`, `grid-rows-2`）
- 跨列/行（`col-span-2`, `row-span-full`）
- 起始与结束（`col-start-2`, `col-end-4`）
- 自动填充与流（`grid-flow-row`, `auto-cols-max`）

#### 背景与边框
- 背景色（`bg-red-500`，透明度 `bg-red-500/50`）
- 背景图片（`bg-none`, `bg-gradient-to-r`, `from-`, `to-`）
- 背景位置/大小（`bg-center`, `bg-cover`, `bg-no-repeat`）
- 边框宽度（`border`, `border-2`, `border-t`）
- 边框颜色（`border-gray-200`, `border-opacity-25`）
- 边框圆角（`rounded`, `rounded-lg`, `rounded-full`, `rounded-tl-md`）
- 轮廓与阴影（`outline-none`, `ring`, `ring-offset-2`）

#### 文本与字体
- 字体族（`font-sans`, `font-mono`）
- 字号（`text-xs` ~ `text-9xl`）
- 粗细（`font-thin` ~ `font-black`）
- 行高（`leading-none`, `leading-tight`, `leading-loose`）
- 对齐（`text-left`, `text-center`）
- 颜色（`text-gray-800`，透明度）
- 装饰（`underline`, `line-through`, `no-underline`）
- 转换（`uppercase`, `capitalize`, `normal-case`）
- 换行（`truncate`, `whitespace-normal`, `break-words`）

#### 其他视觉效果
- 透明度（`opacity-0` ~ `opacity-100`）
- 混合模式（`mix-blend-multiply`）
- 滤镜（`filter`, `blur-md`, `brightness-150`, `drop-shadow`）
- 过渡与动画（`transition-all`, `duration-300`, `ease-in-out`, `animate-pulse`）
- 变换（`transform`, `scale-110`, `rotate-45`, `translate-x-2`）

### 三、响应式设计
1. **断点前缀**（默认 `sm` `md` `lg` `xl` `2xl`）  
   - 用法：`class="text-base md:text-lg lg:text-xl"`
2. **自定义断点**（在 `theme.screens` 中修改）
3. **移动优先原则**（不加前缀 = 手机样式，大屏覆盖）
4. **容器查询**（Tailwind CSS v3.2+ 的 `@container` 支持）

---

### 四、状态变体（Hover / Focus / Active 等）
- 常用伪类：`hover:`, `focus:`, `active:`, `disabled:`, `visited:`
- 表单状态：`checked:`, `invalid:`, `required:`
- 组与父级：`group-hover:`, `peer-focus:`
- 子元素：`first:`, `last:`, `odd:`, `even:`
- 响应式与状态的组合：`md:hover:bg-red-500`

---

### 五、暗色模式
- 策略：`media`（跟随系统）或 `class`（手动切换）
- 启用：`darkMode: 'class'` 在配置中
- 使用：`class="bg-white dark:bg-gray-800"`

---

### 六、自定义主题与扩展
1. **覆盖默认主题**（在 `theme.extend` 中添加）
   - 增加颜色（`colors: { brand: '#1da1f2' }`）
   - 增加间距比例（`spacing: { 128: '32rem' }`）
   - 自定义字体、动画、边框圆角、盒阴影等

2. **任意值语法**  
   - `w-[117px]`，`bg-[#3a6ea5]`，`top-[calc(100%+1rem)]`

3. **插件编写**  
   - 创建自定义工具类（`addUtilities`）  
   - 创建组件类（`addComponents`）  
   - 注册新变体（`addVariant`）  
   - 使用官方插件（`@tailwindcss/forms`, `@tailwindcss/typography`, `@tailwindcss/aspect-ratio` 等）

---

### 七、优化与生产部署
1. **内容扫描**（`content` 配置明确模板文件路径，避免漏扫类名）
2. **未使用样式清除**（使用 `@tailwind base/components/utilities` 后通过 CSS 清理工具或内置的 `--minify`）
3. **控制生成的变体数量**（在 `variants` 中关闭不需要的变体）
4. **选择性导入**（通过 `@layer` 覆盖基础样式）
5. **使用 PostCSS 处理嵌套**（配合 `tailwindcss/nesting` 插件）

---

### 八、开发工具与技巧
- VS Code 插件（Tailwind CSS IntelliSense）
- 浏览器 DevTools 查看生成类名
- 使用 `@apply` 指令抽取重复类到自定义 CSS（适度使用）
- 配置 PurgeCSS 或直接信任 Tailwind 的内容扫描（v3+ 内置）
- 查看官方 Playground 快速试验

### 九、常见模式与反模式
- 条件类名最佳实践（结合 `clsx` 或 `class-variance-authority`）
- 避免过于冗长的类名（使用组件或 `@apply` 维护）
- 如何与 CSS-in-JS 一起使用（如 Emotion、styled-components）
- 在 React/Vue/Angular 框架中的事件类名绑定
