## Tailwind CSS 背景与边框

Tailwind 提供了丰富的背景与边框工具类，涵盖颜色、渐变色、图像控制、边框样式、圆角以及现代 UI 中常用的轮廓与阴影（环效果）。所有类都支持响应式变体、状态变体（hover, focus 等）以及暗色模式。

---

## 一、背景（Background）

### 1. 背景色（Background Color）

使用 `bg-{color}` 设置背景色，Tailwind 默认包含丰富的颜色调色板（每种颜色有 50–950 共 8–11 个色阶）。

| 类名 | CSS 值示例 |
|------|-------------|
| `bg-red-500` | `background-color: #ef4444` |
| `bg-blue-100` | `background-color: #dbeafe` |
| `bg-gray-900` | `background-color: #111827` |
| `bg-white` | `background-color: #ffffff` |
| `bg-black` | `background-color: #000000` |
| `bg-transparent` | `background-color: transparent` |
| `bg-current` | `background-color: currentColor` |

**透明度控制**：支持通过 `/` 语法直接添加透明度（Tailwind v3+）。也可以使用独立的 `bg-opacity-{value}` 类。

```html
<!-- 使用斜杠语法设置半透明背景 -->
<div class="bg-red-500/50">半透明红色背景</div>
<div class="bg-blue-600/25">25% 透明度蓝色</div>

<!-- 分离的透明度类（传统方式，仍然有效） -->
<div class="bg-red-500 bg-opacity-50">同样效果</div>
```

可用的透明度值：`0`, `5`, `10`, `20`, `25`, `30`, `40`, `50`, `60`, `70`, `75`, `80`, `90`, `95`, `100`。

---

### 2. 背景图片（Background Image）

#### 2.1 基本背景图

| 类名 | CSS 值 | 说明 |
|------|--------|------|
| `bg-none` | `background-image: none` | 清除背景图 |
| `bg-gradient-to-{dir}` | 线性渐变 | 需配合 `from-*`、`to-*` 使用 |
| `bg-[url('...')]` | 任意值 | 自定义背景图片 |

```html
<!-- 使用自定义图片（任意值方式） -->
<div class="bg-[url('/img/hero.jpg')] bg-cover">
  英雄区
</div>
```

#### 2.2 线性渐变（Gradients）

Tailwind 提供快捷的渐变类，无需编写复杂的 CSS。

- **方向类**：`bg-gradient-to-t`（上）、`to-r`（右）、`to-b`（下）、`to-l`（左）、`to-tr`（右上）等。
- **颜色类**：`from-{color}`（起始色）、`via-{color}`（中间色，可选）、`to-{color}`（结束色）。

```html
<!-- 从上到下的红色到蓝色渐变 -->
<div class="bg-gradient-to-b from-red-500 to-blue-500">
  渐变背景
</div>

<!-- 从左到右，带中间色 -->
<div class="bg-gradient-to-r from-green-400 via-yellow-300 to-red-500">
  彩虹渐变
</div>

<!-- 对角线渐变：从左上到右下 -->
<div class="bg-gradient-to-br from-purple-600 via-pink-500 to-orange-400">
  背景
</div>
```

**注意**：渐变工具类只生成 `background-image`，背景色类（`bg-red-500`）会被覆盖。可以同时使用 `bg-red-500` 作为后备色（当渐变不支持时）。

## 二、边框（Border）

### 1. 边框宽度（Border Width）

使用 `border-{side?}-{width}` 控制边框宽度。默认边框颜色为 `currentColor`。

| 类名 | CSS 值 | 说明 |
|------|--------|------|
| `border` | `border-width: 1px` | 四边 1px 边框 |
| `border-0` | `border-width: 0px` | 无边框 |
| `border-2` | `2px` | 2px 边框 |
| `border-4` | `4px` | 4px 边框 |
| `border-8` | `8px` | 8px 边框 |
| `border-t` | `border-top-width: 1px` | 上边框 |
| `border-r` | `border-right-width: 1px` | 右边框 |
| `border-b` | `border-bottom-width: 1px` | 下边框 |
| `border-l` | `border-left-width: 1px` | 左边框 |
| `border-x` | 左右边框宽度 | `border-left/right-width: 1px` |
| `border-y` | 上下边框宽度 | `border-top/bottom-width: 1px` |

同样支持 `border-t-0`、`border-l-2`、`border-x-4` 等变体。

```html
<!-- 底部粗边框 -->
<div class="border-b-4 border-blue-500">强调线</div>

<!-- 卡片周围轻边框 -->
<div class="border border-gray-200 rounded-lg p-4">卡片</div>
```

---

### 2. 边框颜色（Border Color）

使用 `border-{color}` 设置边框颜色，也可以单独某个方向的边框颜色。

| 类名 | CSS 值示例 |
|------|-------------|
| `border-gray-200` | `border-color: #e5e7eb` |
| `border-red-500` | `#ef4444` |
| `border-transparent` | `transparent` |
| `border-current` | `currentColor` |

**支持单边颜色**：`border-t-red-500`、`border-r-blue-300` 等。

**边框透明度**：使用 `border-opacity-{value}`。

```html
<!-- 半透明红色边框 -->
<div class="border border-red-500 border-opacity-50 p-2">半透明边框</div>
<!-- 或者使用 / 语法（v3） -->
<div class="border border-red-500/50">更简洁</div>
```

---

### 3. 边框圆角（Border Radius）

使用 `rounded-{size}` 设置圆角。可以单独控制每个角。

#### 统一圆角

| 类名 | CSS 值 |
|------|--------|
| `rounded-none` | `border-radius: 0px` |
| `rounded-sm` | `0.125rem` (2px) |
| `rounded`（默认） | `0.25rem` (4px) |
| `rounded-md` | `0.375rem` (6px) |
| `rounded-lg` | `0.5rem` (8px) |
| `rounded-xl` | `0.75rem` (12px) |
| `rounded-2xl` | `1rem` (16px) |
| `rounded-3xl` | `1.5rem` (24px) |
| `rounded-full` | `9999px`（圆形/椭圆） |

#### 单独角圆角

| 类名 | 说明 |
|------|------|
| `rounded-tl-{size}` | 左上角（top-left） |
| `rounded-tr-{size}` | 右上角 |
| `rounded-br-{size}` | 右下角 |
| `rounded-bl-{size}` | 左下角 |
| `rounded-t-{size}` | 左上+右上 |
| `rounded-r-{size}` | 右上+右下 |
| `rounded-b-{size}` | 右下+左下 |
| `rounded-l-{size}` | 左上+左下 |

```html
<!-- 圆形头像 -->
<img class="w-12 h-12 rounded-full" src="avatar.jpg">

<!-- 只给左上和右上圆角 -->
<div class="rounded-t-lg bg-white p-4">顶部圆角卡片</div>

<!-- 不同角不同大小 -->
<div class="rounded-tl-md rounded-br-xl bg-gray-100 p-2">不规则圆角</div>
```

## 三、轮廓与阴影（Outline & Ring）

### 1. 轮廓（Outline）

`outline-*` 用于控制轮廓线（通常用于聚焦时的可见指示，但会影响布局，推荐使用 `ring`）。

| 类名 | CSS 值 |
|------|--------|
| `outline-none` | `outline: 2px solid transparent; outline-offset: 2px`（完全移除轮廓，但会保留浏览器焦点指示？实际上 Tailwind 的 outline-none 移除了默认轮廓，但为了可访问性，建议配合 `ring` 使用） |
| `outline-white` | `outline-color: white` |
| `outline-black` | `outline-color: black` |
| `outline-0` | `outline-width: 0px` |
| `outline-1` | `1px` |
| `outline-2` | `2px` |
| `outline-offset-0` | `outline-offset: 0px` |
| `outline-offset-1` | `1px` |
| `outline-offset-2` | `2px` |
| `outline-offset-4` | `4px` |

```html
<button class="outline-none focus:ring-2 focus:ring-blue-500">
  无轮廓但使用 ring 效果
</button>
```

---

### 2. 环效果（Ring）

Tailwind 的 `ring` 是一组基于 `box-shadow` 实现的现代焦点样式工具，不占用布局空间，优于 `outline`。

#### 基础环

| 类名 | 说明 |
|------|------|
| `ring-0` | 无环 |
| `ring-1` | 1px 环 |
| `ring-2` | 2px 环 |
| `ring-4` | 4px 环 |
| `ring-8` | 8px 环 |
| `ring` | 默认 3px 环（相当于 `ring-3`，但预设是 3px） |

#### 环颜色

| 类名 | 说明 |
|------|------|
| `ring-blue-500` | 环颜色为蓝色 |
| `ring-red-300` | 环颜色为红色 300 |
| `ring-white` | 白色环 |

#### 环偏移（Ring Offset）

环偏移会在环和元素之间产生一个间隙，使环看起来像外发光且有间隔。

| 类名 | 说明 |
|------|------|
| `ring-offset-0` | 无偏移 |
| `ring-offset-1` | 1px 偏移 |
| `ring-offset-2` | 2px 偏移 |
| `ring-offset-4` | 4px 偏移 |
| `ring-offset-8` | 8px 偏移 |

偏移颜色：`ring-offset-{color}`（默认是白色）。

```html
<!-- 带偏移的聚焦环 -->
<button class="focus:ring-2 focus:ring-blue-500 focus:ring-offset-2 focus:ring-offset-gray-100">
  可访问的按钮
</button>

<!-- 输入框聚焦环 -->
<input class="border border-gray-300 rounded-md focus:outline-none focus:ring-2 focus:ring-indigo-500">
```

## 四、组合示例

### 示例 1：卡片组件

```html
<div class="max-w-sm rounded-xl bg-white shadow-md border border-gray-100 overflow-hidden">
  <div class="bg-gradient-to-r from-purple-500 to-indigo-600 h-32"></div>
  <div class="p-6">
    <h3 class="text-xl font-bold mb-2">标题</h3>
    <p class="text-gray-600 mb-4">描述内容...</p>
    <button class="px-4 py-2 bg-blue-600 text-white rounded-lg hover:bg-blue-700 focus:ring-2 focus:ring-blue-500 focus:ring-offset-2">
      按钮
    </button>
  </div>
</div>
```

### 示例 2：带背景图片的 Hero

```html
<div class="h-96 bg-[url('https://picsum.photos/id/1015/1200/400')] bg-cover bg-center relative">
  <div class="absolute inset-0 bg-black/40"></div>
  <div class="relative flex items-center justify-center h-full text-white text-center">
    <h1 class="text-4xl font-bold">欢迎光临</h1>
  </div>
</div>
```

### 示例 3：圆形头像带环（聚焦效果）

```html
<img class="w-16 h-16 rounded-full ring-2 ring-white ring-offset-2 ring-offset-gray-800" src="avatar.jpg">
```

### 示例 4：虚线边框区域

```html
<div class="border-2 border-dashed border-gray-300 rounded-lg p-8 text-center text-gray-400">
  拖拽文件到此区域
</div>
```

## 五、最佳实践总结

| 类别 | 推荐用法 |
|------|----------|
| **背景色** | 使用语义颜色（`bg-primary-500` 等），结合透明度 `/` 语法 |
| **渐变** | `bg-gradient-to-*` + `from-*` `via-*` `to-*`，适合按钮、头部区域 |
| **背景图** | 通常配 `bg-cover` 和 `bg-center` 实现全铺效果；小图标用 `bg-no-repeat` |
| **边框** | 使用 `border` 加 `border-gray-200` 轻描淡写；强调时用 `border-b-2 border-blue-500` |
| **圆角** | `rounded-lg` 适合卡片；`rounded-full` 做头像/徽章 |
| **焦点样式** | 弃用 `outline-none` 单独使用，总要搭配 `focus:ring` 保证可访问性 |
| **环偏移** | 当环与背景对比不足时，使用 `ring-offset-{color}` 增加间距 |

Tailwind 的背景与边框工具类让 UI 样式编写变得极其高效，同时保持设计系统的约束。只需组合这些原子类，即可构建现代、美观、可访问的界面。
