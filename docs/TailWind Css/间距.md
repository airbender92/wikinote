## Tailwind CSS 间距（Margin & Padding）

Tailwind 的间距系统是其原子化设计的基石，提供了从 `0` 到 `96` 共 24 级预定义比例尺，以及 `px`（1px）、`auto`（自动）和任意值支持，覆盖了所有常用的内外边距需求。

---

### 1. 单边与对称

Tailwind 为 margin 和 padding 分别提供了**完整单边控制**和**轴对称控制**两类工具类。

#### Margin（外边距）— 前缀 `m-`

| 类别 | 类名格式 | 示例 | CSS 输出 |
|------|----------|------|----------|
| **四边相同** | `m-{size}` | `m-4` | `margin: 1rem` |
| **上边距** | `mt-{size}` | `mt-2` | `margin-top: 0.5rem` |
| **右边距** | `mr-{size}` | `mr-0` | `margin-right: 0` |
| **下边距** | `mb-{size}` | `mb-6` | `margin-bottom: 1.5rem` |
| **左边距** | `ml-{size}` | `ml-auto` | `margin-left: auto` |
| **水平对称** | `mx-{size}` | `mx-3` | `margin-left: 0.75rem; margin-right: 0.75rem` |
| **垂直对称** | `my-{size}` | `my-8` | `margin-top: 2rem; margin-bottom: 2rem` |

#### Padding（内边距）— 前缀 `p-`

| 类别 | 类名格式 | 示例 | CSS 输出 |
|------|----------|------|----------|
| **四边相同** | `p-{size}` | `p-3` | `padding: 0.75rem` |
| **上内边距** | `pt-{size}` | `pt-1` | `padding-top: 0.25rem` |
| **右内边距** | `pr-{size}` | `pr-5` | `padding-right: 1.25rem` |
| **下内边距** | `pb-{size}` | `pb-4` | `padding-bottom: 1rem` |
| **左内边距** | `pl-{size}` | `pl-2` | `padding-left: 0.5rem` |
| **水平对称** | `px-{size}` | `px-6` | `padding-left: 1.5rem; padding-right: 1.5rem` |
| **垂直对称** | `py-{size}` | `py-10` | `padding-top: 2.5rem; padding-bottom: 2.5rem` |

#### 使用建议

- **优先使用对称类**（`mx-`、`px-`、`my-`、`py-`）能够减少代码量并保持对称性
- **单边类**用于不对称布局，例如 `ml-auto` 将元素推到右侧
- Tailwind 的间距类可以与响应式前缀配合：`md:mx-4 lg:pl-8`

---

### 2. 负边距（Negative Margin）

Tailwind 支持大多数 margin 类的**负值版本**，只需在类名前加连字符 `-`。

| 正边距 | 负边距 | CSS 输出 |
|--------|--------|----------|
| `mt-4` | `-mt-4` | `margin-top: -1rem` |
| `mr-2` | `-mr-2` | `margin-right: -0.5rem` |
| `mb-6` | `-mb-6` | `margin-bottom: -1.5rem` |
| `ml-1` | `-ml-1` | `margin-left: -0.25rem` |
| `mx-3` | `-mx-3` | `margin-left: -0.75rem; margin-right: -0.75rem` |
| `my-8` | `-my-8` | `margin-top: -2rem; margin-bottom: -2rem` |

#### 典型应用场景

```html
<!-- 1. 元素重叠 -->
<div class="relative">
  <div class="h-24 bg-blue-500"></div>
  <div class="-mt-12 bg-white shadow rounded-lg p-4">
    卡片向上重叠 3rem（12px 对应 48px）
  </div>
</div>

<!-- 2. 吸顶导航栏去除上方间距 -->
<nav class="-mt-4">...</nav>

<!-- 3. 网格中制造不对称效果 -->
<div class="grid grid-cols-3 gap-4">
  <div class="-ml-4">向左突出</div>
  <div>正常</div>
  <div>正常</div>
</div>
```

**注意**：
- 负边距**不会使父容器高度塌陷**（元素仍然占据原始位置），常用于微调视觉位置。
- 并非所有 margin 方向都支持负值，但 Tailwind 针对所有方向都生成了负值版本（基于比例尺中的正值）。
- 负边距无法与 `auto` 结合（`-mt-auto` 无效）。

### 3. 间距比例尺与任意值

#### 3.1 预定义比例尺（基于 rem，基准 1rem = 16px）

| 值 | CSS 值 | 常用场景 |
|----|--------|----------|
| `0` | `0px` | 移除边距 |
| `px` | `1px` | 精细分割线或边框间距 |
| `0.5` | `0.125rem` ≈ 2px | 极小间距 |
| `1` | `0.25rem` ≈ 4px | 紧凑元素之间 |
| `2` | `0.5rem` ≈ 8px | 文本与边缘小间距 |
| `3` | `0.75rem` ≈ 12px | 小按钮内边距 |
| `4` | `1rem` ≈ 16px | 标准卡片内边距 |
| `5` | `1.25rem` ≈ 20px | 列表项间距 |
| `6` | `1.5rem` ≈ 24px | 段落间距 |
| `8` | `2rem` ≈ 32px | 区块间距 |
| `10` | `2.5rem` ≈ 40px | 大间距 |
| `12` | `3rem` ≈ 48px | 章节分隔 |
| `16` | `4rem` ≈ 64px | 页面内大块间距 |
| … | … | … |
| `96` | `24rem` ≈ 384px | 超大间距（如全身布局） |

**响应式比例尺**：所有间距值都可配合断点使用，例如 `md:p-8`、`lg:mt-12`。

#### 3.2 任意值（Arbitrary Values）

当预定义比例尺无法满足需求时，使用方括号语法直接写入任意 CSS 值。

```html
<!-- 精确像素 -->
<div class="mt-[13px] p-[2px] mb-[1.5rem]">
  完全自定义间距
</div>

<!-- 使用 calc() -->
<div class="ml-[calc(50%+1rem)]">
  复杂计算
</div>

<!-- CSS 变量 -->
<div class="p-[var(--card-padding)]">
  动态主题间距
</div>

<!-- 百分比 -->
<div class="mb-[5%]">
  相对于父容器高度
</div>
```

**注意**：任意值不会生成响应式变体（如需响应式，必须手动添加断点前缀，如 `md:ml-[13px]`）。另外，任意值中的空格需要用下划线或转义（但通常直接写即可）。

#### 3.3 特殊值 `auto`

`auto` 是 margin 独有的值，用于让浏览器自动计算边距（常用于水平居中）。

```html
<!-- 块级元素水平居中 -->
<div class="mx-auto w-64">居中块</div>

<!-- 弹性布局中将元素推到右侧 -->
<div class="flex">
  <div>左侧</div>
  <div class="ml-auto">右侧（自动左边距）</div>
</div>

<!-- 垂直居中（需要父容器 flex/h 等） -->
<div class="flex flex-col h-screen">
  <div class="mt-auto">底部吸附</div>
</div>
```

Padding 不支持 `auto`（因为内边距自动计算没有意义）。

### 综合示例

```html
<!-- 典型卡片组件，展示多种间距组合 -->
<div class="max-w-md mx-auto bg-white rounded-xl shadow-md overflow-hidden">
  <!-- 注意：mx-auto 用于卡片居中，负边距用于图片突破边框 -->
  <div class="relative">
    <img class="w-full h-48 object-cover" src="...">
    <div class="absolute -mt-8 ml-4 px-2 py-1 bg-blue-600 text-white text-sm rounded">
      推荐
    </div>
  </div>
  
  <div class="p-6 pt-4"> <!-- pt-4 覆盖部分 p-6 的上内边距 -->
    <h2 class="text-xl font-bold mb-2">产品名称</h2>
    <p class="text-gray-700 mb-4">描述文字...</p>
    <div class="flex justify-between items-center">
      <span class="text-green-600 font-bold">¥299</span>
      <button class="px-4 py-2 bg-blue-500 text-white rounded hover:bg-blue-600">
        购买
      </button>
    </div>
  </div>
</div>
```

### 最佳实践总结

| 原则 | 说明 |
|------|------|
| **优先使用语义化尺寸** | 依靠比例尺（如 `p-4`）而非固定像素，保证设计一致性 |
| **负边距慎用** | 主要用于重叠效果，常规布局尽量用 flex/grid 或正边距 |
| **mx-auto 的局限性** | 仅对块级元素且宽度不满父容器时有效；Flex/Grid 中可用 `justify-self: center` 替代 |
| **任意值的权衡** | 任意值破坏了设计系统的约束，应在必要时使用，同时可考虑扩展 `theme.spacing` |
| **响应式间距** | 善用断点前缀，例如 `md:py-8 lg:px-12` |

Tailwind 的间距系统通过有限、一致的数值集，让你在保证设计一致性的同时，拥有极大的表达灵活性。
