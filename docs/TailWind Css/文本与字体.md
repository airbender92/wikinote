## Tailwind CSS 文本与字体

Tailwind 提供了一套完整的文本排版工具类，涵盖字体族、字号、字重、行高、对齐、颜色、装饰、大小写转换以及换行控制等。所有类都支持响应式前缀和状态变体（`hover:`、`focus:` 等）。

---

## 一、字体族（Font Family）

使用 `font-{family}` 设置字体系列。Tailwind 默认提供了三个预置字体栈：

| 类名 | CSS 值 | 说明 |
|------|--------|------|
| `font-sans` | `ui-sans-serif, system-ui, ...` | 无衬线字体（默认） |
| `font-serif` | `ui-serif, Georgia, ...` | 衬线字体 |
| `font-mono` | `ui-monospace, SFMono-Regular, ...` | 等宽字体 |

```html
<p class="font-sans">这是一段无衬线文本（默认）</p>
<p class="font-serif">这是一段衬线文本，适合印刷风格</p>
<p class="font-mono">等宽字体，常用于代码</p>
```

**自定义字体族**：在 `tailwind.config.js` 中扩展 `theme.fontFamily`。

---

## 二、字号（Font Size）

使用 `text-{size}` 设置字体大小。Tailwind 提供了一套基于 `rem` 的比例尺，同时也包含行高的预设（默认与字号成比例）。

| 类名 | 字号 | 行高（默认） | 说明 |
|------|------|--------------|------|
| `text-xs` | 0.75rem (12px) | 1rem (16px) | 极小 |
| `text-sm` | 0.875rem (14px) | 1.25rem (20px) | 小 |
| `text-base` | 1rem (16px) | 1.5rem (24px) | 基准（默认） |
| `text-lg` | 1.125rem (18px) | 1.75rem (28px) | 大 |
| `text-xl` | 1.25rem (20px) | 1.75rem (28px) | 特大 |
| `text-2xl` | 1.5rem (24px) | 2rem (32px) | |
| `text-3xl` | 1.875rem (30px) | 2.25rem (36px) | |
| `text-4xl` | 2.25rem (36px) | 2.5rem (40px) | |
| `text-5xl` | 3rem (48px) | 1 | |
| `text-6xl` | 3.75rem (60px) | 1 | |
| `text-7xl` | 4.5rem (72px) | 1 | |
| `text-8xl` | 6rem (96px) | 1 | |
| `text-9xl` | 8rem (128px) | 1 | |

**注意**：从 `text-5xl` 开始，Tailwind 默认行高为 `1`（即与字号相同），以避免超大标题行高过大。

```html
<h1 class="text-4xl font-bold">主标题</h1>
<p class="text-sm text-gray-600">小号辅助文字</p>
<p class="text-base">正文</p>
```

**任意值**：`text-[14px]`、`text-[2rem]` 等。

## 三、字体粗细（Font Weight）

使用 `font-{weight}` 控制字体粗细。数值从 100 到 900，以及对应的命名。

| 类名 | CSS 值 | 常见用途 |
|------|--------|----------|
| `font-thin` | `100` | 极细 |
| `font-extralight` | `200` | 特细 |
| `font-light` | `300` | 细 |
| `font-normal` | `400` | 正常（默认） |
| `font-medium` | `500` | 中等 |
| `font-semibold` | `600` | 半粗 |
| `font-bold` | `700` | 粗体 |
| `font-extrabold` | `800` | 特粗 |
| `font-black` | `900` | 黑体 |

```html
<p class="font-light">细体文字</p>
<p class="font-semibold">半粗强调</p>
<p class="font-black">最粗标题</p>
```

## 四、行高（Line Height）

使用 `leading-{size}` 控制文本行高。可以独立于字号设置。

### 4.1 相对行高（基于当前字号倍数）

| 类名 | CSS 值 | 说明 |
|------|--------|------|
| `leading-none` | `1` | 无额外间距，紧凑 |
| `leading-tight` | `1.25` | 紧密（标题常用） |
| `leading-snug` | `1.375` | 较紧凑 |
| `leading-normal` | `1.5` | 正常（默认） |
| `leading-relaxed` | `1.625` | 宽松（正文易读） |
| `leading-loose` | `2` | 很宽松（注释） |

### 4.2 固定行高（使用间距比例尺）

`leading-{size}` 也接受与 `spacing` 比例尺相同的值（如 `leading-3` = `0.75rem` = 12px），此时为绝对行高，不随字号变化。

```html
<p class="text-base leading-relaxed">
  宽松行高的正文，适合长篇阅读。
</p>
<p class="text-xs leading-4">
  极小文本，固定行高12px。
</p>
```

**最佳实践**：正文使用 `leading-normal` 或 `leading-relaxed`；标题使用 `leading-tight` 或 `leading-none`。

## 六、文本颜色（Text Color）

使用 `text-{color}` 设置文字颜色。支持完整的调色板以及透明度控制。

| 类名 | 示例值 |
|------|--------|
| `text-gray-800` | `#1f2937` |
| `text-red-500` | `#ef4444` |
| `text-blue-600` | `#2563eb` |
| `text-white` | `#ffffff` |
| `text-black` | `#000000` |
| `text-transparent` | `transparent` |
| `text-current` | `currentColor` |

**透明度控制**：使用 `/` 语法或 `text-opacity-{value}`。

```html
<p class="text-gray-900/75">75% 不透明度文字</p>
<p class="text-red-500 text-opacity-50">半透明红色文字</p>
```

透明度值：`0`, `5`, `10`, `20`, `25`, `30`, `40`, `50`, `60`, `70`, `75`, `80`, `90`, `95`, `100`。

## 七、文本装饰（Text Decoration）

### 7.1 装饰线

| 类名 | CSS 值 |
|------|--------|
| `underline` | `text-decoration: underline` |
| `overline` | `overline` |
| `line-through` | `line-through` |
| `no-underline` | `none` |

```html
<a href="#" class="underline hover:no-underline">悬停移除下划线</a>
<del class="line-through">原价 199</del> 现价 99
```

### 7.2 装饰颜色与样式（Tailwind v3+）

- 装饰颜色：`decoration-{color}`
- 装饰样式：`decoration-solid`（实线）、`decoration-double`、`decoration-dotted`、`decoration-dashed`、`decoration-wavy`
- 装饰厚度：`decoration-{width}`（`0`、`1`、`2`、`4`、`8`）

```html
<a href="#" class="underline decoration-blue-500 decoration-wavy decoration-2">
  波浪蓝色下划线
</a>
```

## 九、文本换行与溢出（Text Wrap & Overflow）

### 9.1 换行控制

| 类名 | CSS 值 | 说明 |
|------|--------|------|
| `whitespace-normal` | `white-space: normal` | 正常换行（默认） |
| `whitespace-nowrap` | `nowrap` | 不换行，文本在一行 |
| `whitespace-pre` | `pre` | 保留空格和换行 |
| `whitespace-pre-line` | `pre-line` | 合并空格但保留换行 |
| `whitespace-pre-wrap` | `pre-wrap` | 保留空格和换行，且自动换行 |
| `break-normal` | `overflow-wrap: normal; word-break: normal` | 默认换行行为 |
| `break-words` | `overflow-wrap: break-word` | 长单词/URL 换行 |
| `break-all` | `word-break: break-all` | 任意字符间断行（中英文都断） |
| `break-keep` | `word-break: keep-all` | 保持单词完整（适用于 CJK） |

```html
<!-- 长 URL 自动换行 -->
<p class="break-words">https://very-long-url-that-would-normally-overflow.com</p>

<!-- 不换行，超出隐藏 -->
<p class="whitespace-nowrap overflow-hidden text-ellipsis">...</p>
```

### 9.2 文本溢出（截断）

| 类名 | CSS 值 | 说明 |
|------|--------|------|
| `truncate` | `overflow: hidden; text-overflow: ellipsis; white-space: nowrap` | 单行文本超出显示省略号 |
| `text-ellipsis` | `text-overflow: ellipsis` | 配合其他溢出方式使用 |
| `text-clip` | `text-overflow: clip` | 直接裁剪 |

```html
<div class="truncate w-48">
  这是一段很长的文本，超出部分会被截断并显示省略号...
</div>
```

多行截断（无内置工具类，需自定义或使用任意值）：

```html
<p class="overflow-hidden line-clamp-3">
  <!-- line-clamp-3 需要插件 @tailwindcss/line-clamp -->
  多行文本超出三行显示省略号...
</p>
```

## 十、其他文本工具

### 10.1 文本缩进

使用 `indent-{size}`（基于间距比例尺）：

```html
<p class="indent-8">首行缩进 2rem（32px）</p>
```

### 10.2 垂直对齐

| 类名 | CSS 值 | 用途 |
|------|--------|------|
| `align-baseline` | `vertical-align: baseline` | 默认 |
| `align-top` | `top` | 顶部对齐 |
| `align-middle` | `middle` | 垂直居中（常用于表格或内联元素） |
| `align-bottom` | `bottom` | 底部对齐 |
| `align-text-top` | `text-top` | 文本顶部对齐 |
| `align-text-bottom` | `text-bottom` | 文本底部对齐 |

```html
<span>文字 <img class="inline align-middle" src="icon.png"> 图标居中</span>
```

### 10.3 空白处理（空格）

`space-x-{size}` 和 `space-y-{size}` 用于控制子项之间的间距（属于布局工具，但常与文本组合使用）。

## 十一、完整示例

```html
<article class="max-w-prose mx-auto p-6">
  <!-- 标题 -->
  <h1 class="text-3xl font-bold leading-tight text-gray-900 mb-4">
    探索 Tailwind 排版
  </h1>
  
  <!-- 元信息 -->
  <div class="text-sm text-gray-500 uppercase tracking-wide mb-6">
    发布于 2025年1月 • 5分钟阅读
  </div>
  
  <!-- 正文 -->
  <p class="text-base leading-relaxed text-gray-700 mb-4">
    Tailwind 提供了丰富的文本工具类，让你可以<span class="font-semibold text-blue-600">不写 CSS</span> 
    就能实现精美的排版效果。例如，这段文字使用了 <code class="bg-gray-100 rounded px-1 font-mono text-sm">leading-relaxed</code> 
    行高，并包含<u class="decoration-dotted">点状下划线</u>的强调。
  </p>
  
  <!-- 引用 -->
  <blockquote class="border-l-4 border-blue-400 pl-4 italic text-gray-600 my-6">
    “原子化 CSS 不是银弹，但它确实改变了我们的工作流。”
  </blockquote>
  
  <!-- 长链接换行演示 -->
  <p class="break-words text-sm text-gray-500">
    参考文档：https://tailwindcss.com/docs/typography-platform/very-long-url-automatically-breaks
  </p>
  
  <!-- 按钮中的文本转换 -->
  <button class="mt-6 px-4 py-2 bg-indigo-600 text-white rounded-lg uppercase tracking-wider text-sm font-semibold hover:bg-indigo-700">
    了解更多
  </button>
</article>
```

## 十二、最佳实践总结

| 类别 | 推荐用法 |
|------|----------|
| **字体族** | 使用 `font-sans`（网页应用）、`font-serif`（文章）、`font-mono`（代码） |
| **字号** | 正文用 `text-base`，标题用 `text-2xl` 及以上，辅助信息 `text-sm` |
| **粗细** | 标题用 `font-bold`，强调用 `font-semibold`，正文 `font-normal` |
| **行高** | 正文 `leading-relaxed`，标题 `leading-tight`，紧凑 `leading-none` |
| **对齐** | 按需使用 `text-left/center/right` |
| **颜色** | 结合透明度（`/75`）实现层次感；避免纯黑（`text-gray-900`）更柔和 |
| **装饰** | 链接用 `underline`，删售价用 `line-through` |
| **转换** | 按钮文字用 `uppercase tracking-wider` 增强可读性 |
| **换行** | 长内容用 `break-words`，限定宽度配合 `truncate` 显示省略号 |

Tailwind 的文本工具类让你能够快速构建具有良好可读性的排版系统，同时保持与设计系统的一致性。
