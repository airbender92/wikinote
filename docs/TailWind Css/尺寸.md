## Tailwind CSS 尺寸（Width & Height）

Tailwind 提供了一套完整的尺寸工具类，涵盖宽度、高度以及最小/最大尺寸约束。其设计遵循与间距系统一致的比例尺（基于 `rem`），并扩展了 `auto`、`full`、`screen`、`min-content`、`max-content`、`fit-content` 等特殊值，满足各种布局需求。

---

### 1. 宽度（Width）

宽度类以 `w-` 为前缀，支持预定义比例尺、百分比分数、视口单位、内容自适应关键字以及任意值。

#### 1.1 固定宽度（基于比例尺）

与间距比例尺相同，`w-{size}` 的值对应 `theme.width` 中的预定义尺寸（默认继承自 `theme.spacing`）：

| 类名 | CSS 值 | 说明 |
|------|--------|------|
| `w-0` | `0px` | 无宽度 |
| `w-px` | `1px` | 1 像素 |
| `w-0.5` | `0.125rem` (2px) | 极小宽度 |
| `w-1` | `0.25rem` (4px) | |
| `w-2` | `0.5rem` (8px) | |
| `w-3` | `0.75rem` (12px) | |
| `w-4` | `1rem` (16px) | 常用基础单位 |
| `w-5` | `1.25rem` (20px) | |
| `w-6` | `1.5rem` (24px) | |
| `w-8` | `2rem` (32px) | |
| `w-10` | `2.5rem` (40px) | |
| `w-12` | `3rem` (48px) | |
| `w-16` | `4rem` (64px) | |
| … | … | 一直延伸到 `w-96`（24rem, 384px） |

#### 1.2 分数宽度（百分比）

使用 `w-{fraction}` 形式，表示相对于父容器宽度的百分比：

| 类名 | CSS 值 | 常用场景 |
|------|--------|----------|
| `w-1/2` | `width: 50%` | 两列布局 |
| `w-1/3` | `33.333333%` | 三列等分 |
| `w-2/3` | `66.666667%` | |
| `w-1/4` | `25%` | 四列 |
| `w-3/4` | `75%` | |
| `w-1/5` | `20%` | 五列 |
| `w-2/5` | `40%` | |
| `w-3/5` | `60%` | |
| `w-4/5` | `80%` | |
| `w-1/6` | `16.666667%` | 六列栅格 |
| `w-5/6` | `83.333333%` | |
| `w-full` | `100%` | 填满父容器宽度 |

#### 1.3 视口宽度

| 类名 | CSS 值 | 说明 |
|------|--------|------|
| `w-screen` | `width: 100vw` | 视口宽度（可能包含滚动条宽度，谨慎使用） |

#### 1.4 内容自适应关键字（CSS 内在尺寸）

| 类名 | CSS 值 | 说明 |
|------|--------|------|
| `w-min` | `width: min-content` | 根据内容最小宽度（不断行的情况下） |
| `w-max` | `width: max-content` | 根据内容最大宽度（不换行） |
| `w-fit` | `width: fit-content` | 根据内容宽度，但不超过父容器（相当于 `min(max-content, 100%)`） |

**注意**：`w-min`、`w-max`、`w-fit` 在现代浏览器中有良好支持，常用于让容器宽度自适应内容。

#### 1.5 特殊值

| 类名 | CSS 值 | 说明 |
|------|--------|------|
| `w-auto` | `width: auto` | 浏览器默认宽度（块级元素填满父级，行内/内联块由内容撑开） |

---

### 2. 高度（Height）

高度类以 `h-` 为前缀，与宽度类似的命名规则，但**不支持分数宽度**（因为百分比高度依赖父容器明确高度，容易产生意外，Tailwind 不提供预设分数高度，但可以用任意值实现）。

#### 2.1 固定高度（比例尺）

与 `w-` 相同，`h-{size}` 使用相同的间距比例尺：

- `h-0`、`h-px`、`h-0.5`、`h-1`、`h-2`……`h-96`（24rem, 384px）

#### 2.2 视口高度

| 类名 | CSS 值 | 说明 |
|------|--------|------|
| `h-screen` | `height: 100vh` | 全视口高度（常用于整页背景、全屏区域） |

#### 2.3 内容自适应关键字

| 类名 | CSS 值 |
|------|--------|
| `h-min` | `height: min-content` |
| `h-max` | `height: max-content` |
| `h-fit` | `height: fit-content` |

#### 2.4 自动高度

| 类名 | CSS 值 |
|------|--------|
| `h-auto` | `height: auto`（默认，由内容撑开） |

#### 2.5 百分比高度

Tailwind 没有预置 `h-1/2` 等百分比高度，但可以通过**任意值**实现：

```html
<div class="h-[50%]">...</div>
<div class="h-[33.333%]">...</div>
```

注意：父元素必须有明确高度，否则百分比无效。

---

### 3. 最小/最大尺寸

Tailwind 提供了以 `min-w-`、`max-w-`、`min-h-`、`max-h-` 为前缀的工具类，用于设置约束。

#### 3.1 最小宽度（`min-w-`）

| 类名 | CSS 值 | 说明 |
|------|--------|------|
| `min-w-0` | `min-width: 0px` | 允许弹性元素缩小到零（防止溢出） |
| `min-w-full` | `min-width: 100%` | 强制至少填满父容器宽度 |
| `min-w-min` | `min-width: min-content` | 最小宽度为内容最小宽度 |
| `min-w-max` | `min-width: max-content` | 最小宽度为内容最大宽度 |
| `min-w-fit` | `min-width: fit-content` | 最小宽度为适应内容 |

**关键用途**：在 Flex 或 Grid 中，默认 `min-width: auto` 会阻止子元素缩小到小于内容尺寸，添加 `min-w-0` 可允许溢出滚动或缩小。

```html
<div class="flex overflow-auto">
  <div class="min-w-0 truncate">很长的文本会被截断...</div>
</div>
```

#### 3.2 最大宽度（`max-w-`）

Tailwind 提供了一套丰富的最大宽度比例尺（通常用于容器约束），与间距比例尺不同，它面向排版和布局：

| 类名 | CSS 值 | 典型用法 |
|------|--------|----------|
| `max-w-none` | `none`（无限制） | |
| `max-w-xs` | `20rem` (320px) | 小卡片 |
| `max-w-sm` | `24rem` (384px) | 普通卡片 |
| `max-w-md` | `28rem` (448px) | 中等卡片 |
| `max-w-lg` | `32rem` (512px) | 对话框 |
| `max-w-xl` | `36rem` (576px) | 宽卡片 |
| `max-w-2xl` | `42rem` (672px) | 文章正文 |
| `max-w-3xl` | `48rem` (768px) | 大文章 |
| `max-w-4xl` | `56rem` (896px) | 宽布局 |
| `max-w-5xl` | `64rem` (1024px) | 页面容器 |
| `max-w-6xl` | `72rem` (1152px) | 超大容器 |
| `max-w-7xl` | `80rem` (1280px) | |
| `max-w-full` | `100%` | 无约束（但不超过父容器） |
| `max-w-min` | `min-content` | |
| `max-w-max` | `max-content` | |
| `max-w-fit` | `fit-content` | |
| `max-w-prose` | `65ch`（约 65 字符宽度） | 优化阅读体验 |
| `max-w-screen-sm` | `640px` | 响应式断点宽度 |
| `max-w-screen-md` | `768px` | |
| `max-w-screen-lg` | `1024px` | |
| `max-w-screen-xl` | `1280px` | |
| `max-w-screen-2xl` | `1536px` | |

#### 3.3 最小高度（`min-h-`）

常用类：

- `min-h-0`：允许缩小
- `min-h-full`：至少占满父容器高度
- `min-h-screen`：至少占满整个视口高度（经典用法：让页面底部 footer 贴底）

```html
<div class="min-h-screen flex flex-col">
  <header>导航</header>
  <main class="flex-1">主要内容</main>
  <footer>底部始终在页面底部</footer>
</div>
```

#### 3.4 最大高度（`max-h-`）

- `max-h-{size}`：使用间距比例尺（`max-h-96` 等）
- `max-h-full`：不超过父容器高度
- `max-h-screen`：不超过视口高度（用于溢出滚动区域）

```html
<div class="max-h-64 overflow-y-auto">
  <!-- 限定最大高度 16rem，超出滚动 -->
</div>
```

---

### 4. 任意值与响应式

所有尺寸类都支持**任意值**和**响应式变体**：

```html
<!-- 任意宽度/高度 -->
<div class="w-[375px] h-[200px]"></div>

<!-- 响应式宽度 -->
<div class="w-full md:w-1/2 lg:w-1/3"></div>

<!-- 任意值 + 响应式 -->
<div class="max-w-[90vw] lg:max-w-[1200px]"></div>
```

---

### 5. 常见布局模式示例

#### 5.1 全屏 Flex 列布局（Footer 贴底）

```html
<div class="min-h-screen flex flex-col">
  <header class="h-16 bg-gray-800">Header</header>
  <main class="flex-1">Main content</main>
  <footer class="h-12 bg-gray-900">Footer</footer>
</div>
```

#### 5.2 响应式卡片网格定宽

```html
<div class="grid grid-cols-1 sm:grid-cols-2 lg:grid-cols-3 gap-4">
  <div class="max-w-sm w-full bg-white rounded shadow">卡片1</div>
  <!-- 卡片最大宽度 sm，宽度自适应 -->
</div>
```

#### 5.3 弹窗居中（固定尺寸）

```html
<div class="fixed inset-0 flex items-center justify-center bg-black/50">
  <div class="w-96 max-w-full bg-white rounded-lg p-6">
    弹窗内容（宽 24rem，小屏上不超过父容器）
  </div>
</div>
```

#### 5.4 横向滚动区域

```html
<div class="flex overflow-x-auto space-x-4 p-4">
  <div class="w-64 h-32 bg-gray-200 flex-shrink-0">卡片</div>
  <div class="w-64 h-32 bg-gray-200 flex-shrink-0">卡片</div>
  <!-- 允许横向滚动，每个卡片固定宽度 -->
</div>
```

---

### 总结

| 类别 | 主要类 | 关键特性 |
|------|--------|----------|
| 宽度 `w-` | `w-{size}`, `w-1/2`, `w-full`, `w-screen`, `w-auto`, `w-min/max/fit` | 支持比例尺、分数、视口、内在尺寸 |
| 高度 `h-` | `h-{size}`, `h-screen`, `h-auto`, `h-min/max/fit` | 同宽度，但无分数（需任意值） |
| 最小宽度 | `min-w-0`, `min-w-full`, `min-w-min/max/fit` | 控制弹性元素最小宽度 |
| 最大宽度 | `max-w-{size}`, `max-w-screen-*`, `max-w-prose` | 布局约束，排版利器 |
| 最小高度 | `min-h-0`, `min-h-full`, `min-h-screen` | 常见于全屏布局 |
| 最大高度 | `max-h-{size}`, `max-h-full`, `max-h-screen` | 限制滚动区域高度 |

Tailwind 的尺寸系统兼顾了约束与灵活，通过比例尺保持一致性，同时通过内在尺寸关键字和任意值覆盖特例需求。牢记 `min-w-0` 解决 flex 溢出、`max-w-prose` 优化阅读体验，以及 `min-h-screen` 实现全屏粘性布局，你将能高效构建任何复杂的界面尺寸。
