# 一句话说清原型是什么
JavaScript 里**所有对象都有一个隐藏引用**，指向另一个对象，这个被指向的对象就叫**原型（prototype）**。
作用只有一个：
**共享方法、共享属性，省内存，实现继承。**

---

# 最简单的例子（现实开发真这么写）
```js
function Person(name) {
  this.name = name
}

// 方法挂在原型上，所有实例共享
Person.prototype.sayHi = function() {
  console.log('我是' + this.name)
}

const p1 = new Person('张三')
const p2 = new Person('李四')

p1.sayHi() // 我是张三
p2.sayHi() // 我是李四
```

这里：
- `p1.__proto__ === Person.prototype`
- `sayHi` 只存**一份**，不是每个对象一份
→ 这就是原型最真实的用途：**共享方法，节省内存**

---

# 原型链查找规则（最重要）
当你访问：
```js
p1.sayHi()
```

引擎会这样找：
1. 先看 `p1` 自己有没有 `sayHi`
2. 没有 → 去 `p1.__proto__`（即 Person.prototype）找
3. 还没有 → 去 `Person.prototype.__proto__`（Object.prototype）找
4. 再没有 → undefined

这一条链，就是**原型链**。

# 现实开发里原型到底用来干嘛？
## 1. 共享方法（最常用）
如果不挂原型，每个对象都创建一遍方法，浪费内存：
```js
// 垃圾写法：每个实例都创建一个新函数
function Person(name) {
  this.name = name
  this.sayHi = function() {} 
}
```

```js
// 正确写法：共享一个方法
Person.prototype.sayHi = function() {}
```

## 2. 实现继承
```js
function Student() {}

// 让 Student 继承 Person
Student.prototype = Object.create(Person.prototype)
Student.prototype.constructor = Student

Student.prototype.study = function() {}
```

现在 Student 实例既能用 `study`，也能用 `sayHi`。

## 3. 扩展内置对象（慎用但真实存在）
```js
Array.prototype.last = function() {
  return this[this.length - 1]
}

;[1,2,3].last() // 3
```

很多老项目、工具库这么干。

## 4. class 本质就是原型语法糖
```js
class Person {
  sayHi() {}
}
```
等价于：
```js
function Person() {}
Person.prototype.sayHi = function() {}
```

**你天天写 class，本质就是在写原型。**

---

# 三个关键名词别搞混
1. **`prototype`**：函数才有，是**将来实例的原型**
2. **`__proto__`**：对象才有，指向它的原型
3. **`constructor`**：原型上有，指回构造函数

关系一句话：
```js
p1.__proto__ === Person.prototype
Person.prototype.constructor === Person
```

---

# 现实开发总结
- 你写 `class` → 底层就是原型
- 你用数组方法 `forEach / map / filter` → 全在 `Array.prototype` 上
- 你用对象方法 `toString / hasOwnProperty` → 全在 `Object.prototype` 上

**原型不是面试题，是 JS 设计根基。
你不用刻意写 prototype，但你每时每刻都在用它。**
