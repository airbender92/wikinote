作用域我用**最简单、最贴近你刚才防抖代码**的方式讲，一句话抓住本质：

# 一句话
**作用域 = 变量的可访问范围 + 生存周期**
你在哪能读到它、在哪能改它，就是作用域。

---

# 三种作用域（现实开发就这三个）
## 1. 全局作用域
在任何函数、任何块外面定义的变量。
整个文件都能访问。

```js
var a = 1
let b = 2
const c = 3
```

缺点：容易被覆盖、变量污染。

---

## 2. 函数作用域
函数内部的变量，**只有函数里面能访问**。

```js
function fn() {
  let x = 10
  console.log(x) // 可以
}

console.log(x) // 报错，访问不到
```

`var` 也是函数作用域。

---

## 3. 块级作用域（let / const）
`{}` 包裹的区域：if、for、while 等。

```js
if (true) {
  let y = 20
}
console.log(y) // 访问不到
```

`var` 没有块级作用域，这就是为什么以前循环出问题。

---

# 作用域链（你刚才防抖里的核心）
当你在一个函数里用变量：

1. 先在**自己作用域**找
2. 找不到 → 去**父级作用域**找
3. 再找不到 → 往上继续找
4. 直到全局

这条查找路径就是**作用域链**。

---

# 用你刚才的防抖，一眼看懂作用域 & 闭包
```js
function debounce(fn, delay) {
  // 作用域 A
  let timer = null

  return function (...args) {
    // 作用域 B
    clearTimeout(timer)
    timer = setTimeout(...)
  }
}
```

- `timer` 在 **A 作用域**
- 内部函数 B 能访问到 A → 这就形成**闭包**
- 外部永远访问不到 `timer` → 作用域保护
- 多次执行 B，用的都是**同一个 A 里的 timer**

这就是：
**作用域 + 作用域链 = 闭包的底层原理**

---

# 最直白总结
- 作用域：**变量在哪能被访问**
- 作用域链：**找不到就往上找**
- 闭包：**子函数保留了父级作用域，不让它销毁**

你现在理解的防抖，本质就是：
**靠作用域私有化变量，靠闭包让变量一直活着不被回收。**

这三个东西你已经串通了：
作用域 → 作用域链 → 闭包 → 防抖实际应用
