函数式编程，我用**前端开发最实用、最不玄学**的方式讲，
一句话抓住核心：

# 一句话
**把业务逻辑写成一连串纯函数，
不依赖外部状态，不修改数据，只做输入 → 输出。**

它不是语法，是**写代码的风格**。

---

# 核心 4 个特点（现实开发就看这 4 个）
## 1. 纯函数（最重要）
- 相同输入 → 永远相同输出
- 不依赖外部变量
- 不修改外部变量（无副作用）

```js
// 纯函数
function add(a, b) {
  return a + b
}

// 不纯
let count = 0
function inc() {
  count++
}
```

**好处：好测试、好缓存、不乱跑 bug、并发安全。**

---

## 2. 不可变数据
不修改原对象/数组，**永远返回新的**。

```js
// 不好（修改原数组）
arr.push(1)

// 函数式风格（返回新数组）
const newArr = [...arr, 1]
```

Vue3、React、Redux、Immutable 全是这一套。

---

## 3. 函数是一等公民
- 函数可以当参数
- 可以当返回值
- 可以存在变量里

也就是：**高阶函数**。

你天天用的这些都是函数式：
```js
arr.map(v => v * 2)
arr.filter(v => v > 10)
arr.reduce((sum, v) => sum + v, 0)
```

---

## 4. 组合大于嵌套
把小函数拼起来，实现复杂逻辑。

```js
const f = x => x + 1
const g = x => x * 2
const fg = x => f(g(x))

fg(10) // 21
```

 you write like this, code is very clear.

---

# 现实开发里，函数式到底长啥样？
## 普通写法（命令式）
告诉你**一步步怎么做**：
```js
let total = 0
for (let n of numbers) {
  if (n > 10) {
    total += n
  }
}
```

## 函数式写法（声明式）
告诉你**要做什么**：
```js
const total = numbers
  .filter(n => n > 10)
  .reduce((a, b) => a + b, 0)
```

**这就是你日常写的真实业务代码。**

---

# 函数式编程的好处（前端最实用）
- 少 bug（不随便改数据，不乱依赖外部）
- 可读性强（链式调用一眼看懂）
- 好复用（小函数随便拼）
- 好缓存（纯函数可以 memoize）
- React/Vue 生态都吃这一套

---

# 最简单总结
- 命令式：**怎么做**（循环、变量、一步步）
- 函数式：**做什么**（map/filter/reduce/纯函数/不可变）

你现在写的
`arr.map().filter().reduce()`
**就是标准函数式编程。**
