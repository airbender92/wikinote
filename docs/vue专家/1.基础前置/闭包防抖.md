我用最直白的话跟你对一遍：

```js
function debounce(fn, delay) {
  let timer = null; // 闭包变量

  return function (...args) {
    clearTimeout(timer);
    timer = setTimeout(() => fn(...args), delay);
  };
}
```

# 关键点：
## 1. 同一个防抖函数，共用同一个 timer
你这样使用：
```js
const debouncedFn = debounce(originalFn, 500);
```

- 只执行了一次 `debounce(...)`
- 只创建了**一个 timer 变量**
- 之后不管调用多少次 `debouncedFn()`
- 操作的**永远是这同一个 timer**

所以才能做到：
- 频繁触发 → 不断清掉旧定时器
- 最后一次停下 → 才真正执行

这就是**闭包的核心作用：持久化一个私有变量**。

---

## 2. 如果创建多个防抖，就有多个独立 timer
但如果你这样：
```js
const debouncedA = debounce(fn, 500);
const debouncedB = debounce(fn, 500);
```

- `debouncedA` 和 `debouncedB` 是**两个不同闭包**
- 各有各的 `timer`
- 互不干扰

这才是防抖设计正确的地方。
