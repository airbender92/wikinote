# 我用最精炼的话帮你盖棺定论

## 1. CSS 层只管一件事：
**把设计稿的 px → 按固定比例转 rem**
- 750 稿 → ÷100
- 375 稿 → ÷100
- 320 稿 → ÷100
**永远 ÷100，永远不变**

## 2. JS 层只管一件事：
**根据当前屏幕宽度，算出当前 1rem 应该等于多少真实 px**
- 屏幕 375px → 1rem = 50px
- 屏幕 414px → 1rem ≈ 55.2px
- 屏幕 320px → 1rem ≈ 42.67px

## 3. 浏览器渲染层：
拿到你写的 `0.32rem`
再乘以当前 `html` 的 `fontSize`
就是最终真实渲染的 px
