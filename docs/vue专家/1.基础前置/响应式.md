# 前端响应式（Responsive）核心精讲
一句话：**一套代码，适配电脑、平板、手机，自动变布局。**

---

## 一、核心三件套
1. **viewport  meta 标签**（必须）
2. **媒体查询 @media**（断点适配）
3. **弹性布局 + 相对单位**（% / rem / vw）

---

# 1. 必加：viewport
```html
<meta name="viewport" content="width=device-width, initial-scale=1.0">
```
作用：
- 让页面宽度 = 设备屏幕宽度
- 禁止默认缩放
- 移动端不写这个，响应式等于白做

---

# 2. 媒体查询 @media（灵魂）
```css
/* 默认样式：桌面优先 */
.container {
  display: flex;
}

/* 平板 */
@media (max-width: 992px) {
  .container {
    flex-direction: column;
  }
}

/* 手机 */
@media (max-width: 768px) {
  .container {
    padding: 10px;
  }
}
```

常用断点（通用）
- ≥1200px 大屏
- 992~1199px 小屏电脑
- 768~991px 平板
- ≤767px 手机

---

# 3. 相对单位
- **%**：相对于父级
- **vw / vh**：相对于屏幕宽度/高度
  - 1vw = 屏幕宽度的1%
- **rem**：相对于根元素 html 的 font-size
  - 适合做整屏等比缩放

---

# 4. 完整可运行响应式 Demo
```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>完整响应式 Demo</title>
<style>
  * {
    margin: 0;
    padding: 0;
    box-sizing: border-box;
  }
  .container {
    max-width: 1200px;
    margin: 0 auto;
    display: flex;
    gap: 20px;
    padding: 20px;
  }
  .box {
    flex: 1;
    height: 200px;
    background: lightblue;
    display: flex;
    align-items: center;
    justify-content: center;
  }

  /* 平板 */
  @media (max-width: 992px) {
    .container {
      flex-wrap: wrap;
    }
    .box {
      flex: 1 1 calc(50% - 20px);
    }
  }

  /* 手机 */
  @media (max-width: 768px) {
    .container {
      flex-direction: column;
    }
  }
</style>
</head>
<body>
  <div class="container">
    <div class="box">1</div>
    <div class="box">2</div>
    <div class="box">3</div>
    <div class="box">4</div>
  </div>
</body>
</html>
```

效果：
- 电脑：一行4个
- 平板：一行2个
- 手机：一列4个

---

# 5. 常用布局方案
- **Flex 响应式**（最常用）
- **Grid 响应式**（更强大）
  ```css
  .container {
    display: grid;
    grid-template-columns: repeat(auto-fill, minmax(250px, 1fr));
  }
  ```
  自动换行，完全不用写 @media 都能适配
