# 1. 单例模式（Singleton）
**核心：一个类只允许创建唯一一个实例。**

## 现实用途
- 全局弹窗
- 全局消息提示
- 全局请求封装
- 全局状态管理

## 最简代码
```js
class Singleton {
  constructor() {
    this.data = '我是唯一实例'
  }

  static getInstance() {
    if (!Singleton.instance) {
      Singleton.instance = new Singleton()
    }
    return Singleton.instance
  }
}

const a = Singleton.getInstance()
const b = Singleton.getInstance()

console.log(a === b) // true
```

**永远只有一个对象。**

# 2. 策略模式（Strategy）
**核心：把一堆 if / else 抽成独立策略，按需调用。**

## 现实用途
- 表单多种校验规则
- 不同支付方式
- 不同权限逻辑
- 不同计算规则

## 最简代码
```js
const strategies = {
  A: (score) => score >= 90,
  B: (score) => score >= 80,
  C: (score) => score >= 70,
}

function getResult(type, score) {
  return strategies[type](score)
}

getResult('A', 95) // true
```

**干掉大量 if else，代码极清爽。**

# 3. 观察者模式（Observer）
**核心：一个对象变化，自动通知所有订阅它的对象。**
也叫 **发布-订阅模式**。

## 现实用途
- 事件总线 eventBus
- Vue 响应式
- 跨组件通信
- 消息推送

## 最简代码
```js
class EventBus {
  constructor() {
    this.events = {}
  }

  on(type, fn) {
    this.events[type] = this.events[type] || []
    this.events[type].push(fn)
  }

  emit(type, ...args) {
    this.events[type]?.forEach(fn => fn(...args))
  }
}

const bus = new EventBus()

bus.on('msg', (data) => console.log(data))
bus.emit('msg', 'hello')
```

**一对多通知，解耦极强。**

---

# 4. 装饰器模式（Decorator）
**核心：不修改原函数/类，给它动态添加功能。**

## 现实用途
- 日志埋点
- 权限校验
- 防抖节流
- 缓存增强

## 最简代码
```js
function log(fn) {
  return (...args) => {
    console.log('调用前')
    const res = fn(...args)
    console.log('调用后')
    return res
  }
}

function test() {
  console.log('执行')
}

const fn = log(test)
fn()
```

**不改动原函数，直接增强它。**

---

# 一句话总结（超好记）
- **单例**：只造一个对象
- **策略**：干掉 if else，换策略
- **观察者**：一个变，通知一堆
- **装饰器**：不改动原代码，增强功能

这 4 个是**前端最常用、面试最高频、项目最实用**的设计模式。
