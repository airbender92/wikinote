# 核心一句话
**设计稿上写 100px → 我们写成 1rem → 在手机上实际显示 50px**
原因是：**手机屏幕比设计稿小一半，所以根字体自动缩成了 50px**

---

# 一步一步拆

## 1. 先看设计稿
咱们移动端常用设计稿宽度：**750px**
约定规则：
```
设计稿 100px = 1rem
```

所以：
- 设计稿里量出 **100px**
- 我们代码里就写 **1rem**

这一步只是**单位换算**，跟屏幕无关。

---

## 2. 再看 JS 怎么设置根字体
你之前看到的这段 JS：
```js
html.style.fontSize = 屏幕宽度 / 7.5 + 'px'
```

### 手机屏幕宽度常见是 375px（iPhone 标准屏）
```
html 的 font-size = 375 / 7.5 = 50px
```

也就是说：
```
1rem = 50px
```

---

# 3. 合起来就是你那句看不懂的话

- 设计稿量：**100px**
- 代码写成：**1rem**（因为约定 100px=1rem）
- 手机上：**1rem = 50px**

所以：
```
设计稿 100px
→ 代码 1rem
→ 实际渲染 50px
```

完美缩放到手机大小。

---

# 4. 为什么要这么麻烦？
因为：
- 设计稿是 750px 宽
- 手机是 375px 宽，**小了一倍**
- 所以所有尺寸都要**整体缩小一倍**

rem 就是干这个的：
**统一按比例缩放整个页面**。

---

# 5. 再举个例子巩固
设计稿 20px 字体：

- 设计稿：20px
- 代码：0.2rem
- 手机上：0.2rem × 50px = **10px**

小了一倍，刚好适配手机。

---

# 终极总结（记住这句就行）
- **设计稿 100px = 代码 1rem**（方便换算）
- **手机上 html 字体变成 50px**
- 所以 **1rem 实际渲染 50px**
- 整个页面按比例缩小，完美适配
