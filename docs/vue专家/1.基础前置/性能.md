# 先记 4 个核心指标（Web Vitals）
- **FCP**：页面开始渲染的速度（白屏时间）
- **LCP**：最大内容渲染速度（页面核心体验）
- **CLS**：布局偏移（页面稳不稳定）
- **Long Task**：长任务（卡不卡、交互顺不顺）

---

# 1. FCP（First Contentful Paint）
首次内容绘制
> 页面从白屏 → 出现第一个文字/图片的时间

## 优化方向
- 减少 HTML 体积
- 关键 CSS 内联（critical CSS）
- 不要阻塞渲染的 JS/CSS
- 服务端渲染 SSR / 静态生成 SSG
- 启用 HTTP 缓存

---

# 2. LCP（Largest Contentful Paint）
最大内容绘制（**最重要的体验指标**）
> 页面里最大块的内容（图、标题、段落）什么时候渲染出来

目标：**≤2.5s 优秀**

## 优化
- 图片懒加载
- 图片压缩、WebP/AVIF
- 给图片固定宽高
- 重要图片加 `priority`
```html
<img fetchpriority="high" src="hero.jpg">
```
- 减少大体积字体
- 避免慢接口阻塞渲染
- 骨架屏 + 关键内容优先渲染

---

# 3. CLS（Cumulative Layout Shift）
累计布局偏移
> 页面会不会突然跳动、乱跳（体验很差）

目标：**≤0.1**

## 优化
- 图片、视频**必须设 width/height** 或 `aspect-ratio`
- 字体不抖动：`font-display: swap`
- 动态插入内容**预留空间**
- 不要无预告地在顶部弹广告/弹窗

---

# 4. Long Task 长任务优化
长任务：**执行时间 > 50ms 的 JS**
会导致：
- 页面卡顿
- 点击延迟
- 渲染卡住
- FID / INP 变差

## 优化方案（最实用）
1. **代码分割**
   路由懒加载、组件懒加载
2. **延迟执行非关键 JS**
   `setTimeout` / `requestIdleCallback`
3. **长任务拆分**
   把大计算切成小块，用 `setTimeout` 或 `MessageChannel` 让出主线程
4. **Web Worker**
   大量计算丢 Worker，不卡主线程
5. **减少重复渲染**
   React / Vue 避免不必要 re-render
6. **防抖节流**
   scroll/resize/input 用
7. **大列表虚拟滚动**
   只渲染可视区域
8. **清理内存、避免内存泄漏**
   定时器、事件监听、闭包滥用
