# 核心一句话
因为：
- **设计稿 750px = 物理像素（2倍图）**
- **页面实际用的是逻辑像素（375px）**
- **我们又规定了 1rem = 100 逻辑像素**

所以最终公式是：
> **设计稿px ÷ 2 ÷ 100 = rem**

---

# 一步步拆开

## 1. 为什么要 ÷2？
因为 UI 给的 **750px 设计稿是 2 倍图**。

- 手机逻辑宽度（CSS 用的）：**375px**
- 手机物理像素（屏幕真实点）：**750px**
- 比例：**2 倍（DPR=2）**

所以：
**设计稿上的 px = 真实物理像素**
你要转成 CSS 能用的，必须先 **÷2**。

例：
设计稿标 200px
→ 实际 CSS 应该用 100px（逻辑像素）

---

## 2. 为什么再 ÷100？
因为你**人为规定了：1rem = 100px（逻辑像素）**

```css
html {
  font-size: 100px; /* 逻辑像素 */
}
```

所以：
- 100 逻辑 px = 1rem
- 50 逻辑 px = 0.5rem
- 14 逻辑 px = 0.14rem

也就是：
**rem = 逻辑px ÷ 100**

---

## 3. 合起来就是
设计稿 px → 逻辑 px → rem

- 200（设计稿） ÷2 = 100（逻辑px）
- 100（逻辑px） ÷100 = 1rem

所以最终：
> **设计稿px ÷ 2 ÷ 100 = rem**

---

# 你问的这句：
> 这里的 100 对应的是750px设计稿里的fontSize-100px？

**不是。**

- **100 对应的是：逻辑像素 375px 体系下的 html{font-size:100px}**
- 不是设计稿 750px 里的 100px

750px 里的 100px
= 实际逻辑像素 50px
= 0.5rem

---

# 最清晰总结
- **÷2**：把 2 倍设计稿 → 还原成逻辑像素（CSS 真实尺寸）
- **÷100**：把逻辑像素 → 转成你定义的 rem（1rem=100px）

这样你开发时**不用心算、不用计算器**，设计稿标多少直接丢进去就行。
