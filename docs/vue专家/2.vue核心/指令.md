# Vue 内置指令（核心）

## 1. 内容渲染
- `{{ }}` 插值表达式  
- `v-text` 纯文本  
- `v-html` 渲染 HTML（慎用 XSS）

```vue
<div v-text="msg"></div>
<div v-html="rawHtml"></div>
```

## 2. 属性绑定
- `v-bind:属性` → 简写 `:属性`

```vue
<img :src="url" :alt="title">
<div :class="{ active: isActive }"></div>
<div :style="{ color: textColor }"></div>
```

## 3. 事件绑定
- `v-on:事件` → 简写 `@事件`

```vue
<button @click="fn">点击</button>
<input @input="handleInput">
```

常用修饰符：
- `.stop` 阻止冒泡
- `.prevent` 阻止默认行为
- `.once` 只执行一次
- `.self` 只有点击自身才触发
- `.capture` 捕获模式
- `.enter / .esc` 键盘按键

## 4. 双向绑定
- `v-model`

```vue
<input v-model="val">
<input v-model.number="num">
<input v-model.trim="str">
<input v-model.lazy="str">
```

## 5. 条件渲染
- `v-if`
- `v-else-if`
- `v-else`
- `v-show`

区别：
- `v-if`：真正销毁/重建，切换成本高
- `v-show`：始终渲染，只是 `display: none`，频繁切换用它

## 6. 列表渲染
- `v-for="(item, index) in list"`
- 必须 `:key`

```vue
<div v-for="item in list" :key="item.id">
  {{ item.name }}
</div>
```

## 7. DOM 控制
- `v-pre` 跳过编译（原样输出）
- `v-once` 只渲染一次，提升性能
- `v-cloak` 解决插值闪烁（配合 `[v-cloak] { display: none }`）

```vue
<div v-pre>{{ 不编译 }}</div>
<div v-once>{{ msg }}</div>
<div v-cloak>{{ msg }}</div>
```

# 自定义指令（非常高频）
## 1. 全局定义
```js
app.directive('focus', {
  mounted(el) {
    el.focus()
  }
})
```

使用：
```vue
<input v-focus />
```

## 2. 局部定义（script setup）
```vue
<script setup>
const vFocus = {
  mounted(el) { el.focus() }
}
</script>
```

## 3. 常用钩子
- `created`
- `beforeMount`
- `mounted` DOM 插入后
- `beforeUpdate`
- `updated`
- `beforeUnmount`
- `unmounted`

## 4. 获取指令值
```vue
<div v-color="red"></div>
```
```js
const vColor = {
  mounted(el, binding) {
    el.style.color = binding.value
  }
}
```
