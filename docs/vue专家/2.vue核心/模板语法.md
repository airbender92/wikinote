# Vue 模板语法（最常用、最实用版）
直接按你平时写项目会用到的来，不废话，一看就会。

## 1. 插值渲染（显示数据）
```vue
<!-- 文本 -->
<div>{{ msg }}</div>

<!-- 表达式 -->
<div>{{ count + 1 }}</div>
<div>{{ isOk ? '是' : '否' }}</div>
<div>{{ list.length }}</div>
```

## 2. 指令：v-bind 绑定属性
简写 `:`
```vue
<div :id="id"></div>
<img :src="imgUrl" :alt="title">

<!-- class 对象语法 -->
<div :class="{ active: isActive }"></div>

<!-- class 数组语法 -->
<div :class="[cls1, cls2]"></div>

<!-- style -->
<div :style="{ color: textColor, fontSize: '14px' }"></div>
```

## 3. 指令：v-on 绑定事件
简写 `@`
```vue
<button @click="handleClick">点击</button>
<button @click="count++">自增</button>

<!-- 传参 -->
<button @click="handleClick(id)">传id</button>

<!-- 事件对象 -->
<button @click="handleClick($event)">事件对象</button>

<!-- 修饰符 -->
<button @click.stop="fn">阻止冒泡</button>
<button @click.prevent="fn">阻止默认</button>
<input @keyup.enter="fn">回车
```

常用修饰符：
- `.stop`
- `.prevent`
- `.once`
- `.capture`
- `.self`
- `.enter / .esc`

## 4. 双向绑定 v-model
```vue
<input v-model="value" />
<textarea v-model="desc"></textarea>
<input type="checkbox" v-model="checked" />

<!-- 修饰符 -->
<input v-model.number="num" />   转数字
<input v-model.trim="str" />     去空格
<input v-model.lazy="str" />     失焦同步
```

## 5. 条件渲染
```vue
<div v-if="type === 1">类型1</div>
<div v-else-if="type === 2">类型2</div>
<div v-else>其他</div>

<!-- v-show 始终渲染，只是 display: none -->
<div v-show="isShow">显示隐藏</div>
```

区别：
- `v-if`：切换开销大，不渲染
- `v-show`：初始化开销大，频繁切换用它

## 6. 列表渲染 v-for
```vue
<div v-for="item in list" :key="item.id">
  {{ item.name }}
</div>

<!-- 带索引 -->
<div v-for="(item, index) in list" :key="index">
  {{ index }} - {{ item }}
</div>

<!-- 遍历对象 -->
<div v-for="(val, key) in obj" :key="key">
  {{ key }}: {{ val }}
</div>
```
**key 必须加**，用于 Vue 高效更新 DOM。

## 7. 渲染不渲染 / 保留占位
```vue
<template v-if="show">
  这里可以包多个元素，不渲染额外标签
</template>
```

## 8. v-once 只渲染一次
```vue
<div v-once>{{ msg }}</div>
```

## 9. v-html 渲染 HTML
```vue
<div v-html="htmlStr"></div>
```
注意：容易 XSS，别用在用户输入内容。

## 10. v-pre 跳过编译
```vue
<div v-pre>{{ 不会被编译 }}</div>
```

---

# 一句话总结常用组合
```vue
<template>
  <div>
    <!-- 文本 -->
    <p>{{ msg }}</p>

    <!-- 属性 -->
    <div :class="{ active: isActive }"></div>

    <!-- 表单 -->
    <input v-model="val" />

    <!-- 点击 -->
    <button @click="add">+1</button>

    <!-- 循环 -->
    <div v-for="item in list" :key="item.id">{{ item }}</div>

    <!-- 条件 -->
    <div v-if="ok">显示</div>
  </div>
</template>
```
