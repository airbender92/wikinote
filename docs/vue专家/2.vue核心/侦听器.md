# 侦听器（watch）
一句话：
**监听某个响应式数据变化，一旦变了，就执行一段逻辑。**
适合做**异步操作、副作用**。

---

# 基本写法（script setup）
```vue
<script setup>
import { ref, watch } from 'vue'

const keyword = ref('')

// 监听 keyword
watch(keyword, (newVal, oldVal) => {
  // 数据变了就进来
  console.log('新值：', newVal, '旧值：', oldVal)
})
</script>
```

---

# 最常用场景
1. 搜索框**联想请求**
2. 路由参数变化**重新获取数据**
3. 表单值变化**校验/联动**
4. 数据变化**操作 DOM**
5. 复杂状态**异步处理**

计算属性做不了的，都用 watch。

---

# 监听多个数据源
```js
watch([foo, bar], ([newFoo, newBar], [oldFoo, oldBar]) => {
  // 任意一个变了都触发
})
```

---

# 深度监听（对象/数组）
```js
const user = ref({ name: 'zs', age: 18 })

watch(user, () => {
  // 对象内部属性变了，默认监听不到
}, {
  deep: true // 开启深度监听
})
```

更推荐：**直接监听属性**，性能更好
```js
watch(() => user.value.age, () => {})
```

---

# 立即执行（immediate）
一进页面就执行一次，不用等变化：
```js
watch(keyword, () => {
  // 首次加载 + 每次变化都执行
}, { immediate: true })
```

---

# 监听 getter（精确监听）
监听对象某个属性、计算表达式：
```js
watch(
  () => obj.age,
  (newVal) => { ... }
)
```

---

# 计算属性 vs 侦听器（最重要）
- **computed**：
  - 算出一个新值
  - 有缓存
  - **不能异步**
  - 无副作用

- **watch**：
  - 监听变化，做事情
  - 无缓存
  - **支持异步（请求、定时器）**
  - 适合副作用

一句话区分：
**想得到一个值 → computed
想做一件事 → watch**

---

# 高级：watchEffect
自动收集依赖，不用写要监听谁：
```js
watchEffect(() => {
  // 里面用到了谁，就监听谁
  console.log(keyword.value)
})
```

适合：
- 依赖多、懒得一个个写
- 一创建就需要执行的逻辑

---

# 极简总结
- `watch`：监听数据变化，做**异步/副作用**
- `deep: true`：监听对象内部
- `immediate: true`：一开始就执行
- `watchEffect`：自动收集依赖，更省事
