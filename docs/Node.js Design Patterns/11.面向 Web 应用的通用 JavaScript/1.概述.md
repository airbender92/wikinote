# 第10章 面向 Web 应用的通用 JavaScript（Universal JavaScript）
这一章的核心就是一句话：
**一套代码，既能在 Node.js 服务端跑，也能在浏览器客户端跑 —— 这就是 Universal / Isomorphic JavaScript。**

## 本章要讲的内容
- 什么是**通用 JavaScript**，为什么能前后端共用代码
- **模块打包工具**（webpack）的原理与用法
- 跨环境代码复用模式：
  - 环境判断分支
  - 模块替换（module swapping）
  - 避免环境依赖的通用写法
- **React 基础**
- 用 React + Node.js 搭建完整通用应用：
  - 通用渲染（SSR）
  - 通用路由
  - 通用数据加载

## 核心价值
- 大幅减少重复代码
- 前后端同构渲染，利于 SEO 和首屏速度
- 一套架构、一套模式，降低维护成本

这一章是现代前端框架（Next.js、Nuxt、Remix 等）**同构渲染**的底层原理，非常实用。
