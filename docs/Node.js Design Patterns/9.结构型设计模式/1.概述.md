# 结构型设计模式（Structural Design Patterns）
结构型模式关注**如何组织类与对象、搭建组件关系**，核心是用灵活的方式组合对象，实现更强大、可复用的结构。

本章会重点讲 3 种在 Node.js 中极常用的结构型模式，并配合响应式编程、LevelDB 等实战场景：

## 要学习的模式
1. **Proxy（代理模式）**
   - 控制对另一个对象的访问
   - 可做拦截、校验、缓存、日志、权限控制

2. **Decorator（装饰器模式）**
   - 动态给对象**添加行为/功能**
   - 不修改原对象、不使用继承，灵活扩展

3. **Adapter（适配器模式）**
   - 把一个对象的接口**转换成另一种接口**
   - 让不兼容的组件可以一起工作（新旧库、不同 API 封装）

## 额外延伸知识点
- **响应式编程（RP）**思想
- **LevelDB** 在 Node.js 中的实际应用
