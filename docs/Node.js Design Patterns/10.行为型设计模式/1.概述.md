# 行为型设计模式（本章概览）
前面学习了**创建型**（对象怎么生成）和**结构型**（对象怎么组合/包装），现在进入**行为型**：
关注**对象如何协作、通信、分工、控制流程**，让行为可扩展、可替换、可复用。

## 本章要学习的 6 个核心模式
1. **Strategy 策略模式**
   动态切换算法/策略，同一接口，不同实现。

2. **State 状态模式**
   对象根据内部**状态**自动改变行为。

3. **Template 模板模式**
   定义算法骨架，子类实现可变步骤，实现**代码复用+扩展**。

4. **Iterator 迭代器模式**
   统一遍历接口，不用关心集合内部结构。

5. **Middleware 中间件模式**
   链式处理请求/数据，典型如 Express/Koa，类似职责链但在 Node.js 中自成标准。

6. **Command 命令模式**
   把“执行动作”封装成对象，方便传递、排队、撤销、日志。

## 本章重要特点
- 你已经见过一个：**Observer 观察者模式**（第三章，事件驱动核心）
- JS/Node.js 实现和传统 OOP 语言差异极大
  - 迭代器不需要复杂类继承
  - 中间件是职责链的“本土化进化版”
- 全部围绕：**可扩展、动态改行为、解耦调用与实现**
