# Iterator 迭代器模式
迭代器模式：**为遍历不同数据结构提供统一接口**，不用关心内部是数组、树、流还是异步序列。

在 JS 里它是**语言内置标准**，基于迭代器协议实现，不用继承。

---

## 1. 迭代器协议（Iterator Protocol）
一个对象是迭代器，只要实现 `next()` 方法，返回：
```js
{
  done: boolean, // 是否遍历结束
  value: any     // 当前值
}
```

- `done: true` → 遍历结束
- `done: false` → 还有值，`value` 为当前项

迭代器通常是**有状态**的，会记录当前位置。

---

## 2. 简单示例：字母迭代器
```js
const A_CHAR_CODE = 65
const Z_CHAR_CODE = 90

function createAlphabetIterator() {
  let currCode = A_CHAR_CODE

  // 返回迭代器对象
  return {
    next() {
      if (currCode > Z_CHAR_CODE) {
        return { done: true }
      }

      const currChar = String.fromCodePoint(currCode)
      currCode++
      return { value: currChar, done: false }
    }
  }
}
```

### 手动使用
```js
const iter = createAlphabetIterator()
let result = iter.next()

while (!result.done) {
  console.log(result.value)
  result = iter.next()
}
```

---

## 3. 核心要点（书中重点）
- **统一遍历接口**
  数组、Map、Set、树、流、生成器都能用同一套方式遍历
- **解耦**
  使用者只管 `next()`，不用知道数据结构长啥样
- **可同步可异步**
  JS 同时支持同步迭代器 & 异步迭代器（`Symbol.asyncIterator`）
- **天生状态ful**
  迭代进行到哪一步，由迭代器自己维护

---

## 4. 和 JS 原生语法的关系
实现迭代器后，就能直接用：
- `for...of`
- 展开运算符 `[...iter]`
- `Array.from()`
- 解构赋值

这也是为什么说它是**语言内置模式**。

# 可迭代协议（Iterable Protocol）
可迭代协议：让一个对象**能被迭代遍历**，标准是实现 `[Symbol.iterator]()` 方法，返回一个**迭代器**。

- **Iterable（可迭代对象）**：实现了 `Symbol.iterator`
- **Iterator（迭代器）**：有 `next()` 方法，返回 `{ done, value }`

---

## 示例：Matrix 二维矩阵（可迭代类）
```js
export class Matrix {
  constructor(inMatrix) {
    this.data = inMatrix
  }

  get(row, column) {
    if (row >= this.data.length || column >= this.data[row].length) {
      throw new RangeError('Out of bounds')
    }
    return this.data[row][column]
  }

  set(row, column, value) {
    if (row >= this.data.length || column >= this.data[row].length) {
      throw new RangeError('Out of bounds')
    }
    this.data[row][column] = value
  }

  // 可迭代协议核心
  [Symbol.iterator]() {
    let nextRow = 0
    let nextCol = 0

    // 返回迭代器
    return {
      next: () => {
        // 遍历结束
        if (nextRow === this.data.length) {
          return { done: true }
        }

        // 当前值
        const currVal = this.data[nextRow][nextCol]

        // 移动指针
        if (nextCol === this.data[nextRow].length - 1) {
          nextRow++
          nextCol = 0
        } else {
          nextCol++
        }

        return { value: currVal }
      }
    }
  }
}
```

---

## 使用方式
```js
import { Matrix } from './matrix.js'

const matrix2x2 = new Matrix([
  ['11', '12'],
  ['21', '22']
])

// 手动迭代
const iterator = matrix2x2[Symbol.iterator]()
let result = iterator.next()

while (!result.done) {
  console.log(result.value) // 11, 12, 21, 22
  result = iterator.next()
}
```

输出顺序：
`11 → 12 → 21 → 22`

---

# 关键知识点（书中重点）
1. **Iterable vs Iterator**
   - **Iterable**：能产生迭代器的对象（有 `Symbol.iterator`）
   - **Iterator**：真正执行遍历的对象（有 `next()`）

2. 内置可迭代对象
   - `Array`、`String`、`Map`、`Set`、`arguments`、`NodeList`

3. 语法糖支持
   实现 `Symbol.iterator` 后，可直接用：
   - `for...of`
   - `[...iterable]`
   - `Array.from()`
   - 解构赋值

4. 可选扩展方法（极少用）
   - `return()`：提前终止迭代
   - `throw()`：通知迭代出错

---

## 一句话总结
**迭代器协议定义怎么遍历；可迭代协议定义谁能被遍历。**
这是 JS 统一遍历所有数据结构的基石。


----

# 迭代器作为 JS 原生接口的威力
一旦实现了迭代器 / 可迭代协议，**整个 JS 生态的语法和 API 都能直接用**，这就是标准化的价值。

## 1. 原生语法支持
### for...of
```js
for (const el of matrix2x2) {
  console.log(el)
}
```

### 展开运算符
```js
const flat = [...matrix2x2]
```

### 解构赋值
```js
const [a, b, c, d] = matrix2x2
```

## 2. 原生 API 支持
这些 JS 内置函数**都接受可迭代对象**：
- `Array.from(iterable)`
- `new Set(iterable)`
- `new Map(iterable)`
- `Promise.all(iterable)`
- `Promise.race(iterable)`

## 3. Node.js 里的支持
- `stream.Readable.from(iterable)`
  直接把可迭代对象变成可读流

## 4. JS 内置的可迭代对象
- `Array`
- `String`
- `Map` / `Set`
- `arguments`
- `NodeList`
- `Buffer`（Node.js）

---

# 一句话总结
**迭代器模式在 JS 里不是设计模式，是原生基础设施。
只要实现统一协议，所有语法、API、库都能无缝配合。**

下一个模式：**Middleware 中间件模式**，也是 Node.js / Web 开发里最核心的模式之一。
