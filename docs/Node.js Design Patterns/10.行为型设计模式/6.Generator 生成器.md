# Generator 生成器
Generator 是 ES6 专门为**简化迭代器写法**而生的语法糖，本质是**可暂停、可恢复的函数**。

它返回的对象**既是迭代器、也是可迭代对象**，可以直接用于 `for...of`、`...` 展开等。

---

## 1. 基本语法
```js
// 生成器函数：function*
function* myGenerator() {
  yield 1
  yield 2
  return 3
}
```

- 调用函数不执行，返回**生成器对象**
- 每次 `.next()` 执行到下一个 `yield` 并暂停
- `yield x` → 返回 `{ value: x, done: false }`
- `return x` → 返回 `{ value: x, done: true }`

---

## 2. 示例：水果生成器
```js
function* fruitGenerator() {
  yield 'peach'
  yield 'watermelon'
  return 'summer'
}

const gen = fruitGenerator()

console.log(gen.next()) // { value: 'peach', done: false }
console.log(gen.next()) // { value: 'watermelon', done: false }
console.log(gen.next()) // { value: 'summer', done: true }
```

### 直接用在 for...of
```js
for (const fruit of fruitGenerator()) {
  console.log(fruit)
}
// 输出：
// peach
// watermelon
```
> 注意：for...of **不会获取 return 的值**，只取 yield。

---

## 3. 核心特点（书中重点）
- **多个入口/暂停点**：普通函数只有一个入口，生成器可以暂停多次
- **惰性生成**：用到才计算，适合无限序列
- **既是迭代器也是可迭代对象**
  - 有 `.next()` → 迭代器
  - 有 `[Symbol.iterator]` → 可迭代

---

## 4. 对比：手动迭代器 vs 生成器
### 手动写字母迭代器（之前的例子）
```js
function createAlphabetIterator() {
  let currCode = 65
  return {
    next() {
      if (currCode > 90) return { done: true }
      return { value: String.fromCodePoint(currCode++), done: false }
    }
  }
}
```

### 用生成器重写（极简）
```js
function* alphabetGenerator() {
  for (let code = 65; code <= 90; code++) {
    yield String.fromCodePoint(code)
  }
}
```

**代码量直接减半，逻辑更清晰。**

---

## 5. 一句话总结
**Generator = 迭代器的语法糖，用 yield 简化遍历逻辑，
自动实现迭代器 + 可迭代协议，代码更短更直观。**

# 生成器的双向控制
生成器不只是迭代器，还支持**外部往内部传值、抛错、提前终止**，实现双向控制。

## 1. 外部给生成器传值
`next(value)` 传入的值，会作为**上一个 yield 的返回值**。

```js
function* twoWayGenerator() {
  // what = 外部传入的 'world'
  const what = yield null
  yield 'Hello ' + what
}

const gen = twoWayGenerator()

gen.next()        // 启动，执行到 yield null
gen.next('world') // 传入 'world'，赋值给 what，走到下一个 yield
```

结果：
```js
{ value: 'Hello world', done: false }
```

---

## 2. 给生成器抛错：`.throw(err)`
在**上一个 yield 位置**抛出异常，内部可以 `try/catch` 捕获。

```js
function* twoWayGenerator() {
  try {
    const what = yield null
    yield 'Hello ' + what
  } catch (err) {
    yield 'Hello error: ' + err.message
  }
}

const gen = twoWayGenerator()
gen.next()
gen.throw(new Error('Boom!'))
```

结果：
```js
{ value: 'Hello error: Boom!', done: false }
```

---

## 3. 提前终止：`.return(value)`
强制结束生成器，直接返回 `{ done: true, value: ... }`。

```js
const gen = twoWayGenerator()
gen.next()
gen.return('myReturnValue')
```

结果：
```js
{ value: 'myReturnValue', done: true }
```

---

# 核心总结（书中要点）
- **`next(value)`**：恢复执行，并给生成器传值
- **`throw(err)`**：在暂停点抛错，可被内部捕获
- **`return(value)`**：立即终止迭代

这让生成器不只是遍历工具，还能做：
- 异步流程控制（co、早期 Redux Saga）
- 协程（coroutine）
- 双向通信的状态机

# 用 Generator 简化可迭代对象实现
生成器本身就是迭代器，所以可以直接把 `[Symbol.iterator]` 写成 `function*` 生成器方法，**代码大幅简化、逻辑更直观**。

## 改造后的 Matrix 迭代器（生成器版）
```js
export class Matrix {
  constructor(inMatrix) {
    this.data = inMatrix
  }

  get(row, column) { /* ... */ }
  set(row, column, value) { /* ... */ }

  // 直接用生成器实现可迭代协议
  *[Symbol.iterator]() {
    let nextRow = 0
    let nextCol = 0

    while (nextRow !== this.data.length) {
      // 直接 yield 当前值
      yield this.data[nextRow][nextCol]

      // 移动指针
      if (nextCol === this.data[nextRow].length - 1) {
        nextRow++
        nextCol = 0
      } else {
        nextCol++
      }
    }
  }
}
```

## 为什么这样更爽？
1. **不用手动写 next() 与 { done, value }**
   生成器自动帮你实现迭代器协议

2. **状态直接用局部变量保存**
   `nextRow`、`nextCol` 就是普通局部变量，
   生成器会自动保留暂停前后的状态，不用闭包

3. **用熟悉的循环写遍历逻辑**
   while / for 循环一目了然，比手动控制 next() 好读太多

4. **用法完全不变**
   照样支持：
   - `for...of`
   - `[...matrix]`
   - `Array.from(matrix)`

---

# 核心结论
**生成器 = 写迭代器的最佳方式**
- 代码更少
- 可读性更高
- 功能一样甚至更强
- 完全兼容 JS 所有可迭代语法与 API

# 异步迭代器 Async Iterators
异步迭代器就是 **next() 返回 Promise 的迭代器**，专门用来遍历**异步产生的数据序列**。

## 核心规范
- 异步可迭代对象：实现 `[Symbol.asyncIterator]()`
- 异步迭代器：`next()` 是 async 函数，返回 `Promise<{ done, value }>`
- 遍历语法：`for await (const item of iterable)`

---

## 示例：批量检测 URL 状态
```js
import superagent from 'superagent'

export class CheckUrls {
  constructor(urls) {
    this.urls = urls
  }

  // 异步可迭代协议
  [Symbol.asyncIterator]() {
    // 内部用同步迭代器遍历 URL 列表
    const urlsIterator = this.urls[Symbol.iterator]()

    return {
      // next 是 async 方法
      async next() {
        const { done, value: url } = urlsIterator.next()
        if (done) return { done: true }

        try {
          const res = await superagent.head(url).redirects(2)
          return {
            done: false,
            value: `${url} is up, status: ${res.status}`
          }
        } catch (err) {
          return {
            done: false,
            value: `${url} is down, ${err.message}`
          }
        }
      }
    }
  }
}
```

### 使用：for await...of
```js
async function main() {
  const checkUrls = new CheckUrls([
    'https://nodejsdesignpatterns.com',
    'https://example.com',
    'https://probably-down.com'
  ])

  for await (const status of checkUrls) {
    console.log(status)
  }
}

main()
```

---

# 关键点（书中重点）
1. **异步迭代 = 串行异步流程**
   `for await...of` 会等一个请求完成再走下一个。

2. **适用场景**
   - 分页 API
   - 数据库游标（cursor）
   - 日志/事件流
   - 大量文件逐行读取
   - 消息队列消费

3. **等价展开写法**
   ```js
   const iter = checkUrls[Symbol.asyncIterator]()
   let res = await iter.next()

   while (!res.done) {
     console.log(res.value)
     res = await iter.next()
   }
   ```

4. **也支持普通数组（里面是 Promise）**
   ```js
   const promises = [fetch(u1), fetch(u2)]
   for await (const res of promises) { ... }
   ```

---

# 一句话总结
**异步迭代器 = 能异步取值的迭代器
asyncIterator + next() 异步 + for await...of 遍历
专门优雅处理流式、序列式异步数据。**

# 异步生成器 Async Generators
异步生成器 = **async + generator**
可以在内部用 `await`，并且自动实现**异步迭代器 + 异步可迭代协议**。

---

## 改造 URL 检测类（异步生成器版）
对比上一版手动写 `next()`，代码直接大幅简化：
```js
export class CheckUrls {
  constructor(urls) {
    this.urls = urls
  }

  // 直接 async * 实现异步可迭代
  async *[Symbol.asyncIterator]() {
    for (const url of this.urls) {
      try {
        // 内部可以直接 await
        const checkResult = await superagent
          .head(url)
          .redirects(2)

        yield `${url} is up, status: ${checkResult.status}`
      } catch (err) {
        yield `${url} is down, error: ${err.message}`
      }
    }
  }
}
```

### 使用方式完全不变
```js
for await (const status of checkUrls) {
  console.log(status)
}
```

---

# 为什么异步生成器更强？
1. **不用手动实现 next() / 状态管理**
   生成器自动处理迭代状态、暂停、恢复、返回格式

2. **内部直接写 for 循环 + await**
   逻辑像同步代码一样直观

3. **自动符合异步迭代器规范**
   返回的对象就是标准异步迭代器

4. **代码量更少、更易读**
   去掉了闭包、手动迭代器对象、状态判断

---

# 一句话总结（书中核心）
**异步生成器 = 实现异步迭代器的终极简化方案**
- 内部支持 `await`
- 外部支持 `for await...of`
- 代码最简洁、意图最清晰

# 异步迭代器与 Node.js 流
Node.js **可读流天生就是异步可迭代对象**，实现了 `Symbol.asyncIterator`，可以直接用 `for await...of` 读取。

## 示例：逐行读取标准输入
```js
import split from 'split2'

async function main() {
  const stream = process.stdin.pipe(split())

  // 流直接用于 for await...of
  for await (const line of stream) {
    console.log(`You wrote: ${line}`)
  }
}

main()
```

---

## 双向互转
- **流 → 异步迭代器**
  ```js
  for await (const chunk of stream) { ... }
  ```
- **异步迭代器 → 流**
  ```js
  const stream = Readable.from(asyncIterable)
  ```

这本质就是**适配器模式**。

---

## 流 vs 异步迭代器（核心区别）
|  | Streams 流 | Async Iterators 异步迭代器 |
|----|----|----|
| **数据模式** | **Push** 数据主动推入缓冲区 | **Pull** 消费者按需拉取 |
| **二进制处理** | 原生支持缓冲、背压、编码 | 需要自己处理 |
| **组合方式** | `.pipe()` / `pipeline()` 标准易用 | 无标准组合方式 |
| **适用场景** | 文件 I/O、网络、二进制数据 | 遍历数据行、数据库游标、事件流 |

---

## 实际应用（In the wild）
- 数据库库 `@databases/pg/mysql/sqlite`
  ```js
  for await (const record of db.queryStream(SQL)) {
    // 处理每条记录
  }
  ```
- `events.on(emitter, event)` 把事件转为异步迭代器
- ZeroMQ 等消息库大量使用迭代器风格 API

---

两者高度互通，在 Node.js 里已经融为一体。**
