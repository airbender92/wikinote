# State 状态模式
状态模式是**策略模式的特殊版本**：
**策略会随着对象内部状态自动切换，从而自动改变行为。**

## 核心区别
- **Strategy**：策略一般**外部指定、运行中基本不变**
- **State**：策略（状态）**随内部状态自动切换**，行为随之改变

## 经典场景：酒店预订（Reservation）
一个订单有多个状态：
- 新建（New）
- 已确认（Confirmed）
- 已过期/不可取消（Expired）

每个状态下，`confirm()`、`cancel()`、`delete()` 的行为完全不同：
- 新建：可确认、可删除、不可取消
- 已确认：不可重复确认、可取消、不可删除
- 过期：都不可操作

如果不用状态模式，会写出**巨量 if-else**，代码难以维护。

## 状态模式的解决方案
- 每个状态对应一个**状态对象**
- 每个状态对象实现同一套接口：`confirm`、`cancel`、`delete`
- 上下文（Reservation）持有当前状态
- 状态切换时，直接**替换状态对象**，行为自动变化

## 一句话记忆
**状态模式 = 自动切换策略的策略模式，让对象“随状态变脸”。**

# 状态模式实战：断线自动重连的 FailsafeSocket
这是**状态模式最经典、最实用的 Node.js 案例**：
一个 TCP 客户端 socket，在线 / 离线时行为完全不同，并且**状态自动切换**。

## 整体结构
- **Context（上下文）**：`FailsafeSocket`
- **States（状态）**：
  - `OfflineState`：离线 → 数据入队，不断重连
  - `OnlineState`：在线 → 立即发送，断线切离线
- 行为统一接口：`send(data)`、`activate()`

---

## 1. 上下文：FailsafeSocket（failsafeSocket.js）
```js
import { OfflineState } from './offlineState.js'
import { OnlineState } from './onlineState.js'

export class FailsafeSocket {
  constructor(options) {
    this.options = options
    this.queue = []          // 离线时缓存数据
    this.currentState = null
    this.socket = null

    // 所有状态实例
    this.states = {
      offline: new OfflineState(this),
      online: new OnlineState(this)
    }

    this.changeState('offline') // 初始状态：离线
  }

  // 切换状态
  changeState(state) {
    console.log(`Activating state: ${state}`)
    this.currentState = this.states[state]
    this.currentState.activate() // 执行状态激活逻辑
  }

  // 核心方法：委托给当前状态处理
  send(data) {
    this.currentState.send(data)
  }
}
```

---

## 2. 离线状态：OfflineState（offlineState.js）
- send：只入队，不发送
- activate：每秒重试连接
- 连上后自动切到 online

```js
import jsonOverTcp from 'json-over-tcp-2'

export class OfflineState {
  constructor(failsafeSocket) {
    this.failsafeSocket = failsafeSocket
  }

  // 离线时发送 → 入队
  send(data) {
    this.failsafeSocket.queue.push(data)
  }

  // 激活：循环重连
  activate() {
    const retry = () => {
      setTimeout(() => this.activate(), 1000)
    }

    console.log('Trying to connect...')
    this.failsafeSocket.socket = jsonOverTcp.connect(
      this.failsafeSocket.options,
      () => {
        console.log('Connection established')
        this.failsafeSocket.socket.removeListener('error', retry)
        this.failsafeSocket.changeState('online') // 连上切在线
      }
    )
    this.failsafeSocket.socket.once('error', retry)
  }
}
```

---

## 3. 在线状态：OnlineState（onlineState.js）
- send：立即发送
- activate：清空队列
- 出错自动切 offline

```js
export class OnlineState {
  constructor(failsafeSocket) {
    this.failsafeSocket = failsafeSocket
    this.hasDisconnected = false
  }

  // 在线发送：入队并尝试写出
  send(data) {
    this.failsafeSocket.queue.push(data)
    this._safeWrite(data)
  }

  // 安全写入：成功则出队
  _safeWrite(data) {
    this.failsafeSocket.socket.write(data, (err) => {
      if (!this.hasDisconnected && !err) {
        this.failsafeSocket.queue.shift()
      }
    })
  }

  // 激活：发送积压数据，监听错误
  activate() {
    this.hasDisconnected = false

    // 发送离线期间积压的数据
    for (const data of this.failsafeSocket.queue) {
      this._safeWrite(data)
    }

    this.failsafeSocket.socket.once('error', () => {
      this.hasDisconnected = true
      this.failsafeSocket.changeState('offline') // 断线切离线
    })
  }
}
```

## 4. 测试用服务端 & 客户端
### server.js
```js
import jsonOverTcp from 'json-over-tcp-2'

const server = jsonOverTcp.createServer({ port: 5000 })
server.on('connection', socket => {
  socket.on('data', data => {
    console.log('Client data', data)
  })
})

server.listen(5000, () => console.log('Server started'))
```

### client.js
```js
import { FailsafeSocket } from './failsafeSocket.js'

const failsafeSocket = new FailsafeSocket({ port: 5000 })

// 每秒发送内存信息
setInterval(() => {
  failsafeSocket.send(process.memoryUsage())
}, 1000)
```

# 核心知识点总结（书中重点）
## 1）State 模式 vs Strategy 模式
- **Strategy**：策略由外部指定，一般**运行时不变**
- **State**：状态由对象内部自动切换，**行为随状态自动变**

## 2）状态模式的优点
- 消灭巨量 `if (state === xxx)` 判断
- 每个状态逻辑独立，易维护、易扩展
- 状态切换逻辑内聚，上下文干净

## 3）这个示例的亮点
- 离线 → 自动重连 → 上线自动补发队列
- 完全符合真实工程场景（监控上报、日志发送、消息队列客户端）
- 是 Node.js 网络组件里**状态模式的教科书写法**
