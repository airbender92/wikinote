# 代码逐行完整解释
```js
import staticHandler from 'serve-handler'
const server = createServer((req, res) => {
    return staticHandler(req, res, {public: 'www'})
})
```
> 前置说明：
> 1. `createServer` 来自 Node.js 内置模块 **`http`**，代码完整写法一般开头会带上：
> ```js
> import { createServer } from 'http'
> ```
> 2. `serve-handler` 是一个轻量静态文件服务库，常用来实现本地静态资源托管（前端打包产物、html、js、图片等）

## 1. `import staticHandler from 'serve-handler'`
导入 `serve-handler` 库，导出的核心函数 `staticHandler`。
作用：接收请求、响应对象，**自动读取本地文件并返回给浏览器**，处理静态资源：
- 自动解析 url，查找对应文件
- 处理 `index.html` 默认首页
- 设置正确 MIME 类型（css/js/png/html 等）
- 404 文件不存在处理

## 2. `createServer((req, res) => { ... })`
`http.createServer` 创建原生 Node.js HTTP 服务。
回调就是**请求监听器**：
- `req`：客户端请求对象（请求地址、请求头、method）
- `res`：响应对象，用来向浏览器返回数据

浏览器每发起一次 HTTP 请求，这个回调就执行一次。

## 3. `return staticHandler(req, res, {public: 'www'})`
把原生 http 请求交给 `serve-handler` 处理。
### 参数拆解
```js
staticHandler(request, response, options)
```
- `req, res`：直接透传 Node 原生请求响应对象
- `{ public: 'www' }` ✅ **最重要配置**
> `public`：指定**静态资源根目录**

含义：
当浏览器访问 `http://localhost:3000/index.html`
程序会去本地 **`./www/index.html`** 读取文件返回。

## 整体功能一句话总结
启动一个 Node.js HTTP 服务，所有请求全部交给 `serve-handler`，
以项目下 `www` 文件夹作为静态资源根目录，提供网页、图片、js、css 等静态文件访问。

## 最简完整可运行示例
```js
import { createServer } from 'http'
import staticHandler from 'serve-handler'

const server = createServer((req, res) => {
  return staticHandler(req, res, { public: 'www' })
})

server.listen(3000, () => {
  console.log('静态服务启动：http://localhost:3000')
})
```
目录结构：
```
项目根目录
├─ www
│  └─ index.html  # 访问首页就是这个文件
└─ 你的服务脚本
```

## 常用扩展配置（顺便补充）
`serve-handler` 支持更多参数，举几个高频用法：
```js
staticHandler(req, res, {
  public: 'www',
  cleanUrls: true,    // 访问 /home 自动映射 /home.html
  rewrites: [         // 路由重写（SPA单页应用必备）
    { source: '**', destination: '/index.html' }
  ]
})
```
> `rewrites` 配置非常适合 Vue/React 打包后的 spa 项目，防止刷新页面404。
