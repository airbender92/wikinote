## 第11章 高级实用方案（Advanced Recipes）
本章采用「问题+落地解决方案」的讲解模式，像技术菜谱一样提供一批可直接复用的代码方案，解决 Node.js 开发中的高频疑难问题。

你会发现本章大部分场景都围绕异步编程展开。正如前文反复讲解的：同步代码里简单的逻辑，放到异步模型中往往会变得复杂。典型例子：组件需要异步初始化，我们必须等待初始化完成后才能调用它，这里存在使用时序难题，本章会给出优雅解法。

除异步相关方案外，本章还会讲解 Node.js 中 CPU 密集型任务的最优处理方式。

本章覆盖四大核心实战方案：
1. 处理**异步初始化组件**的时序问题
2. 异步请求合并 + 缓存策略
3. 异步操作的取消机制
4. CPU 密集型任务的多种执行方案

## 核心知识点
### 本章核心定位
全书实战落地章节，聚焦线上生产环境高频痛点，提供开箱即用的标准化实现，不堆砌理论，全部是业务可直接复制的工程方案。
### 四大模块业务价值
1. **异步初始化组件**
场景：数据库连接池、消息队列客户端、第三方 SDK（异步建立连接）；
痛点：初始化未完成就调用接口直接报错；方案：初始化队列、延迟启动、预加载机制。
2. **请求批处理 + 缓存**
场景：高频重复接口请求；
价值：减少下游服务压力、降低 IO 耗时、防缓存击穿。
3. **可取消异步任务**
场景：超时接口、用户取消操作（前端取消请求、终止数据库查询）；
解决无效异步逻辑持续占用资源的问题。
4. **CPU 密集任务处理**
Node.js 单线程事件循环天然不适合大量计算，三种方案：
- `setImmediate` 分片穿插事件循环，不阻塞服务；
- 外部子进程分离计算；
- Worker 线程池专门处理运算。
