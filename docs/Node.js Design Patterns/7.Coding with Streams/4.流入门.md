# 翻译
## 流入门
上一节我们了解了流强大的特性，同时也发现流遍布 Node.js 核心模块中。举几个例子：`fs` 模块提供`createReadStream`读取文件、`createWriteStream`写入文件；HTTP 请求与响应对象本质都是流；`zlib`模块提供流式接口完成数据压缩和解压；`crypto`模块也暴露了`createCipheriv`、`createDecipheriv`这类流式基础工具。

明白了流的重要性后，我们回过头，细致深入地学习流。

# 核心解读
1. Node 内置大量原生流，文件、网络、压缩、加密等底层 IO 操作全部提供流式 API；
2. 流是官方标准通用接口，不同模块的流可无缝通过`pipe`拼接；
3. 下文将系统拆解四类基础流、底层运行机制。
