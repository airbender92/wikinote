# DBeaver打开之后第一步

> DBeaver只是客户端，**第一件事：新建数据库连接**，不连库什么都干不了。

### 方式1（点图标，最常用）

左上角工具栏，点**插头图标（新建连接）**

### 方式2（菜单）

顶部菜单：**数据库 → 新建连接**

### 方式3（右键）

左侧「数据库导航」空白处右键 → 创建 → 连接

---

## 接下来完整流程

1. 弹出窗口，选你的数据库类型（MySQL / Oracle / PostgreSQL等），点下一步
2. 填：主机IP、端口、用户名、密码
3. 点**测试连接**（首次会自动下载驱动，点确认下载）
4. 测试显示「已连接」→点完成，左侧就出现你的数据库，就可以写SQL了

### 首次打开软件还会弹几个弹窗

1. 统计收集：勾选**不共享数据**，关闭即可
2. 是否创建示例数据库：练手选是；要连自己业务库直接点**否**
