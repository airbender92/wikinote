# DBeaver新建连接参数说明

> **不能随便填！这些是你数据库真实服务的连接信息，填错连不上数据库**
> 弹窗选择数据库类型（MySQL/Oracle/PostgreSQL）之后，第二页就是这几项：主机、端口、用户名、密码。

## 1、MySQL（最常用）

| 参数            | 含义                                                            | 示例                                              |
| --------------- | --------------------------------------------------------------- | ------------------------------------------------- |
| 主机(Host)      | 数据库服务器IP地址 数据库装本机填：`127.0.0.1` 或者 `localhost` | `127.0.0.1`（本机） `192.168.1.100`（内网服务器） |
| 端口(Port)      | MySQL默认端口 `3306`，如果改了端口就填修改后的                  | `3306`                                            |
| 数据库/数据库名 | 可选，指定默认打开哪个库，可以留空                              | `test_db`                                         |
| 用户名(User)    | 数据库账号，本机默认root                                        | `root`                                            |
| 密码(Password)  | 数据库账号对应的密码，安装mysql时设置的密码                     | 你的数据库密码                                    |

> ⚠️注意：如果数据库在另外一台服务器，**服务器要开放端口3306防火墙，账号要允许外部IP访问，否则连不上**

## 2、PostgreSQL

- 主机：`127.0.0.1`本机，服务器填对应IP
- 端口：默认`5432`
- 用户名：默认`postgres`
- 密码：安装PG设置的密码
- 数据库：默认库一般`postgres`

##3、Oracle

- 主机：数据库IP
- 端口：默认`1521`
- SID/服务名：必须填（Oracle关键）
- 用户名/密码：oracle账号密码

## 快速区分：本机数据库 vs 远程服务器数据库

1. **数据库装在自己电脑本机**
   主机写 `127.0.0.1`，端口用默认，账号密码是你本地数据库安装时设置的，不是随便写。
2. **数据库在公司/云服务器上**
   主机填服务器真实IP，端口确认防火墙放行，向运维要：IP、端口、账号、密码、库名。

## 小技巧

填完不要直接点完成，点 **测试连接**，DBeaver会立刻告诉你是否连通。

- 测试成功：再点下一步、完成。
- 测试报错：说明IP/端口/账号密码/防火墙其中一项错了。

### 常见报错

1. Connection refused：IP错 / 端口错 / 数据库没启动 / 防火墙拦截
2. Access denied：用户名密码错误
3. Unknown host：主机IP地址写错
