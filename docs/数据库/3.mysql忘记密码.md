# ERROR 1045 (28000) Access denied …(using password: NO)

含义：**root账号有密码，但是你直接回车没输入密码，登录被拒绝**。现在服务已经正常启动了（不再报10061），就是密码不对。

> using password: NO 代表你这次没提供密码，不是密码输错。

## 执行重置root密码完整步骤（适配你的环境：程序C盘，my.ini/data在D盘）

1. 管理员身份打开CMD
   停止mysql服务

```cmd
net stop MySQL97
```

2. 进入bin目录

```cmd
cd "C:\Program Files\MySQL\MySQL Server 9.7\bin"
```

3. 前台跳过权限启动，**必须指定D盘的my.ini，不能省略！**

```cmd
mysqld --defaults-file="D:\MySQL\MySQL Server 9.7\my.ini" --skip-grant-tables --shared-memory --console
```

> ✔执行完，**这个cmd窗口保持打开，不要关闭**，这就是临时mysql服务。
> 如果这里报错，把报错贴出来。

4. **再新开一个管理员CMD窗口**，同样切到bin目录

```cmd
cd "C:\Program Files\MySQL\MySQL Server 9.7\bin"
mysql -uroot
```

👉此时不需要密码，直接进入 `mysql>`

5. 执行下面SQL重置密码，把 `NewPass@123` 换成你自己设置的密码（MySQL9.7要求有大小写+符号+数字）

```sql
FLUSH PRIVILEGES;
ALTER USER 'root'@'localhost' IDENTIFIED BY 'NewPass@123';
exit;
```

6. 回到第一个运行mysqld的窗口，按 `Ctrl + C` 终止进程，关闭该窗口。

7. 重新启动系统mysql服务

```cmd
net start MySQL97
```

8. 测试登录

```cmd
mysql -uroot -p
```

输入刚才设置的新密码，即可登录。

---

### 常见坑

1. 忘记写 `--defaults-file="D:\MySQL\MySQL Server 9.7\my.ini"`：会读取错误data目录，重置完全无效。
2. MySQL9.7禁止简单弱密码，`123456`这种会报错，密码要包含字母数字特殊符号。
3. 做完之后不要再带`--skip-grant‑tables`参数，正常用windows服务运行。

> 如果重置后想查看本机全部账号，登录成功后执行：

```sql
select user,host from mysql.user;
```
