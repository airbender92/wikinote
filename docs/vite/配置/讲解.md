## Vite 配置详解

### 插件配置

```typescript
plugins: [
  vue(),                                    // Vue3 SFC 支持
  AutoImport({                             // 自动导入 API
    imports: ['vue', 'vue-router', 'pinia'], // 无需手动 import { ref, computed } from 'vue'
  }),
  Components({                              // 自动导入组件
    resolvers: [ElementPlusResolver()],     // Element Plus 组件自动导入
  }),
]
```

**效果示例：**
```vue
<!-- 不需要手动 import -->
<script setup>
// ref, computed, watch 等自动导入
// ElButton, ElInput 等组件自动导入
</script>
```

### 路径别名

```typescript
resolve: {
  alias: {
    '@': resolve(__dirname, 'src'),  // @ 等价于 src/
  },
}
```

### 全局 SCSS 变量

```typescript
css: {
  preprocessorOptions: {
    scss: {
      additionalData: `@use "@/styles/variables.scss" as *;`,
    },
  },
}
```

**效果：** 所有 `.scss` 文件自动注入 variables.scss，无需手动 `@use`

### 开发服务器代理

```typescript
server: {
  port: 3000,
  proxy: {
    '/api': {
      target: 'http://localhost:8080',  // 请求 /api/* 转发到后端
      changeOrigin: true,
    },
  },
}
```

## 技术栈概览

| 层级 | 技术 | 作用 |
|------|------|------|
| 框架 | Vue 3.4 | 组合式 API + `<script setup>` |
| 语言 | TypeScript 5.4 | 类型安全 |
| 构建 | Vite 5 | 快速热更新 |
| 路由 | Vue Router 4 | SPA 路由管理 |
| 状态 | Pinia 2.1 | 轻量状态管理 |
| UI | Element Plus 2.6 | 企业级组件库 |
| 样式 | SCSS + Tailwind | SCSS 变量 + Tailwind 工具类 |
| 请求 | Axios | HTTP 请求封装 |
| 自动导入 | unplugin-auto-import/components | 减少样板代码 |

## 环境变量

| 文件 | 用途 |
|------|------|
| `.env` | 通用配置 |
| `.env.development` | 开发环境 |
| `.env.production` | 生产环境 |
