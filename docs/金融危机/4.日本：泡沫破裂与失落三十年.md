# 4. 日本：泡沫破裂与失落三十年

> 日本是研究"资产泡沫破裂后遗症"的全球最完整标本：1989年见顶后，日经225跌了 **13年**、跌掉 **80%**，用了 **34年** 才在2024年收复失地。
> 主线规律：**慢跌长熊、资产负债表衰退、通缩固化**——危机不止是股市的，是整个经济系统的。

---

| **1989.12.29** | **历史大顶 38957点** | 38957 |

## 二、泡沫是如何吹起来的

### 2.1 背景链条

```
1985广场协议：日元升值 → 出口竞争力下降
    ↓
1985-1989超低利率（1987年官方贴现率2.5%）→ 货币宽松
    ↓
银行资金涌入地产与股市 + 金融自由化（企业直接融资转向）
    ↓
"土地神话"：日本地价永远涨 → 银行以地价放贷 → 贷更多钱炒地
    ↓
股市与地价互相推升（交叉持股、财阀关联交易）
```

### 2.2 泡沫有多疯狂

- 1989年东京银座土地单价：1平米 = **1亿日元**（约700万人民币/平米）
- 日本土地市值一度是美国的 **4倍**
- 日经225市盈率高达 **60-70倍**
- 全民炒股炒地，"财技"（zaitech）成为企业主流盈利方式——**企业靠金融投资收益撑利润**

> 📌 这一幕与2007年A股、2008年美国次贷、2021年核心资产牛高度相似：**资产价格自我强化到脱离现金流**。

## 三、崩盘与"失去的三十年"

### 3.1 崩盘过程（为何是慢刀子）

| 阶段 | 内容 |
| --- | --- |
| 1990年 | 日经从38957跌至2.4万，-38%，市场认为"正常回调" |
| 1991-1992 | 地产开始下跌，银行坏账浮出水面，日经跌破1.5万 |
| 1993-1995 | 反复阴跌+反弹，政府始终不愿承认问题严重性 |
| 1997-1998 | 亚洲金融危机+金融机构倒闭潮（山一证券、北海道拓殖、长银） |
| 2000-2003 | 互联网泡沫破灭+通缩加剧，2003年4月见底 **7607点** |

**为什么反弹失败**：每次反弹（1993/1995/2000）都因**坏账未处置+通缩延续**而夭折——这就是"资产负债表衰退"（详见[第1篇](1.底层逻辑：危机与股市的关系.md)）。

### 3.2 失去的三十年（1990-2020）

- **GDP停滞**：名义GDP 30年几乎零增长
- **通缩固化**：CPI长期为负或零，工资不涨
- **企业"三无"**：无投资、无加薪、无创新（防御性存钱还债）
- **人口老龄化**：劳动力萎缩，内需长期疲弱
- **股市**：日经1990-2012年长期在8000-20000区间，2008年一度跌至 **6994点**（比1989年低82%）

### 3.3 日本的"痛苦抉择"为何失败

| 政策 | 效果 |
| --- | --- |
| 1990年代早期加息戳破泡沫 | 刺破过晚、过猛 |
| 银行坏账"掩盖"（不暴露） | 僵尸企业存续，资源错配10年+ |
| 1997年提高消费税 | 经济雪上加霜 |
| 1990年代零利率+财政刺激 | 货币传导失灵（企业不愿借） |
| **2001年QE（全球首个）** | 为后来者提供了模板，但当时力度不足 |

> 💡 教训：**处置坏账的速度 = 复苏的速度**。日本拖延了10年（1997年才开始重组银行），美国2008年两年内果断注资+压力测试，恢复快得多。

## 四、安倍经济学与2024年的"重见天日"

### 4.1 安倍经济学（2013-2020）

```
"三支箭"：QQE（质化量化宽松）+ 财政刺激 + 结构改革
    ↓
日元大幅贬值（120→125+）→ 出口企业盈利大增
    ↓
日经2013年单年+57%，2015年达20952点
```

### 4.2 2024年创34年新高

- 2024.02.22 日经突破 **39000点**，正式收复1989年大顶
- 驱动：东京证交所治理改革（要求上市公司提升ROE、回购）、巴菲特加仓五大商社、日元贬值利好出口、全球AI/半导体景气
- **注意**：收复的是"点数"而非"财富"——同期日元贬值近半，以美元计的实际购买力远未恢复；日经成分股已换血（优衣库、索尼、信越化学等替代了老银行地产）

### 4.3 2024.08.05 套息交易"黑色星期一"

- 日本央行7月31日意外加息 → 日元急升 → **日元套息交易（借低息日元买全球资产）大规模平仓**
- 8.5日经单日 **-12.4%**（历史最大单日跌幅），韩国KOSPI、A股、美股期货同步大跌
- 日本央行紧急安抚（副行长表态不加息），市场8.6快速反弹

> 💡 这是**日本不再只是"失落的受害者"，而是全球流动性的"总闸门"之一**的标志性事件——详见[第6篇](6.危机传导：跨市场的千丝万缕.md)的套息交易机制。

## 五、日本的启示：给A股的镜像参考

| 日本教训 | 对A股/中国政策的映射 |
| --- | --- |
| 地产泡沫破裂后遗症漫长 | 2021年后中国地产下行，须防"资产负债表衰退" |
| 通缩比通胀更可怕 | 中国2023-2024也出现CPI低迷，政策转向"物价温和回升" |
| 坏账处置拖延=复苏拖延 | 中国化债、重组地产、处置地方平台 |
| 财政必须持续发力 | 日本1997年过早财政紧缩是败笔，中国2024转向"更加积极" |
| 股市可率先见底 | 日经2003年见底，经济2012年后才真正企稳——股市领先9年 |
