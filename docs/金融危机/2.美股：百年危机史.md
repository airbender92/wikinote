# 2. 美股：百年危机史

> 美股是全球金融危机的"策源地"与"风向标"。一百年来，美股经历了七次大级别危机，每次都改变了全球金融格局。
> 主线规律：**牛长熊短，急跌快涨**——美股危机往往是"脉冲式"的，但每一次崩盘都伴随着监管与制度的重构。

---

## 一、危机全景时间轴

| 危机 | 时间 | 标普/道指最大跌幅 | 核心导火索 | 修复用时 |
| --- | --- | --- | --- | --- |
| 1929大萧条 | 1929-1932 | 道指 **-89%** | 保证金泡沫+银行挤兑 | 25年 |
| 1987黑色星期一 | 1987.10 | 道指单日 **-22.6%** | 程序化交易+估值过高 | 2年 |
| 2000互联网泡沫 | 2000-2002 | 纳指 **-78%** | 科技股估值泡沫 | 15年(纳指) |

| 2018 Q4暴跌 | 2018.10-12 | 标普 **-20%** | 加息+缩表过快 | 5个月 |
| 2020疫情闪崩 | 2020.02-03 | 标普 **-34%**（23天） | 疫情+流动性危机 | 5个月 |
| 2022加息熊市 | 2022.01-10 | 标普 **-25%** | 40年最高通胀+激进加息 | 1.5年 |

## 二、逐场危机复盘

### 2.1 1929 大萧条：人类史上最深的股市深渊

**背景**：1920年代"柯立芝繁荣"，保证金交易盛行（最低只需10%保证金），全民炒股。

**崩盘过程**：
- 1929.10.24 "黑色星期四"：道指暴跌，银行家护盘失败
- 1929.10.29 "黑色星期二"：单日-12%，史上最惨单日之一
- 1932年7月：道指从381点跌至 **41点**，跌幅89%

**为什么跌得这么深**：
- 美联储错误地**收紧货币**（为保卫金本位），加剧通缩
- 银行大量破产 → 存款消失 → 消费/投资崩塌（债务-通缩螺旋教科书）

**遗产**：
- 1933年《格拉斯-斯蒂格尔法》（银行分业，1999年废除——又为2008年埋下伏笔）
- 1934年SEC（证监会）成立
- 存款保险制度（FDIC）

> 💡 启示：**政策失误是危机的放大器**。1929年的教训是"危机中紧缩货币"，后来的美联储学会了反向操作。

### 2.2 1987 黑色星期一：一天跌掉一个时代

**背景**：计算机化程序交易（"投资组合保险"）盛行，市场高估。

**崩盘过程**：1987.10.19 道指单日 **-508点（-22.6%）**，至今仍是道指单日最大跌幅纪录。全球股市同日崩盘（日经、恒指、A股均遭重创）。

**直接机制**：
```
股指下跌 → 组合保险触发卖出 → 期货暴跌 → 现货跟随 → 继续触发卖出（正反馈螺旋）
```

**为何快速修复**：
- 美联储**承诺无限流动性**（"我们做一切必要的事"）
- 引入熔断机制（防止程序化踩踏）

> 💡 启示：**技术性卖出可以引发与基本面无关的崩盘**；央行果断提供流动性是止血第一针。

### 2.3 2000 互联网泡沫：估值透支的典型

**背景**：互联网革命叙事 + 低利率 + 散户狂热，纳斯达克1995-2000涨5倍。

**顶点与崩盘**：
- 2000.3.10 纳指见顶 **5048点**
- 2002.10 跌至 **1114点**，跌幅 **78%**（腰斩再腰斩）
- 大量"XX.com"公司归零，思科、英特尔等巨头跌去80%+市值

**特点**：没有引发系统性金融危机（因为家庭杠杆低、银行敞口小），但摧毁了大量财富，911事件加速下行。

> 💡 启示：**"新叙事"不等于新估值**。当股价按"用户数×每用户估值"而非现金流定价时，泡沫已成熟。

### 2.4 2008 次贷危机：全球金融海啸的震中

**背景**：
- 2000年后美联储长期低利率 → 地产繁荣
- 次级贷款 → 打包成MBS/CDO → 杠杆放大（投资银行30倍+）
- 评级机构给出错误AAA评级

**崩盘过程**：
| 时间 | 事件 |
| --- | --- |
| 2007.08 | 法国巴黎银行冻结基金，危机公开化 |
| 2008.03 | 贝尔斯登被摩根大通收购 |
| 2008.09.15 | **雷曼兄弟破产**（恐慌顶点） |
| 2008.10 | 标普单月-17%，史上最惨单月 |
| 2009.03 | 标普见底 **666点**（-57%） |

**传导链条**：次贷违约 → CDO贬值 → 投行杠杆崩塌 → 货币市场冻结 → 全球信贷冻结 → 实体经济衰退 → 全球股市联动暴跌（详见[第6篇](6.危机传导：跨市场的千丝万缕.md)）。

**拯救**：
- TARP 7000亿美元救助计划
- 美联储QE1/QE2/QE3（资产负债表从0.9万亿扩张到4.5万亿）
- 零利率维持7年

> 💡 启示：**影子银行+衍生品可以绕过一切监管**。危机后《多德-弗兰克法》出台，但华尔街很快又找到新玩法。

### 2.5 2020 疫情闪崩：最快的熊市与最猛的反转

**过程**：
- 2020.02.19 标普见顶3393
- 2020.03.23 跌至2237，**23个交易日跌34%**，史上最快熊市
- 四天四次熔断（历史上仅此一次）

**关键转折**：美联储3月23日宣布"无限量QE"+ 零利率 + 2万亿美元财政刺激 → **V型反转**，全年标普反而 **+16%**。

> 💡 启示：**当危机源于外部冲击（而非内生泡沫）时，放水可以快速修复**。流动性才是美股牛市的真正引擎。

### 2.6 2022 加息熊市：利率重定价

**背景**：2020-2021大放水 → 2022年通胀创40年新高（9.1%）→ 美联储史上最快加息（0→5.25%）。

**过程**：标普2022.01见顶4796 → 2022.10见底3577（**-25%**），纳指 **-33%**，"漂亮50"式抱团股（ARK、特斯拉、Meta等）腰斩。

**特点**：
- 这是"估值压缩型"熊市：无系统性违约，纯因折现率上升
- 加息末期，2023年AI叙事（ChatGPT）点燃新牛市

> 💡 启示：**利率是股市估值之锚**。加息周期中"抱团高估值成长股"最受伤；危机未必是"崩盘"，阴跌同样杀人。

### 2.7 2018 Q4 快熊（补充）：缩表的威力

2018年10-12月，美联储加息+缩表引发标普 **-20%** 快熊，特朗普炮轰鲍威尔，随后美联储转向"耐心"并停止缩表，市场5个月修复。

> 这一轮提醒我们：**即使没有泡沫，紧缩过快也能制造熊市**——也是A股2018年的大背景（详见[第3篇](3.A股：牛熊与股灾.md)）。

## 三、美股的"危机免疫力"为什么强

| 因素 | 说明 |
| --- | --- |
| 美元霸权 | 危机时全球资金涌入美元资产避险 |
| 美联储独立性 | 快速、果敢、工具充足（QE/互换/贴现） |
| 直接融资主导 | 股权市场深度大，银行危机向实体传导弱 |
| 制度护城河 | 熔断、CDS市场、破产重整成熟 |
| 科技与全球企业 | 美股=全球利润中心，盈利韧性最强 |

但也别迷信：1929年美股也曾跌89%。**"美股永远涨"是1980年代后全球化+放水时代的产物**。

---

## 四、美股危机对全球的"灯塔效应"

- **美股跌 → 全球风险资产联动跌**（2018、2020、2022均是）
- **美股恐慌指数VIX飙升 → 新兴市场资金外流**
- **美联储政策转向 → 全球流动性拐点**（详见[第6篇](6.危机传导：跨市场的千丝万缕.md)）
