# 金融危机 × 股市：千丝万缕的关系

> 股市是金融危机的"震中"与"震波"。几乎每一次重大金融危机，都以股市的暴跌为最醒目的注脚；而每一次史诗级牛市，又往往是下一场危机的温床。
> 本系列笔记以 **美股、A股、韩日股市** 为主角，梳理危机与股市之间层层缠绕的因果链。

## 🌐 四市场一句话速览

- **美股**：牛长熊短，危机是"脉冲式"的（急跌快涨），股市是危机的制造者也是解药。
- **A股**：牛短熊长，政策是最大的变量，危机往往由"杠杆+情绪"内生引爆，由政策收场。
- **日本**：危机是"资产负债表衰退式"的（慢跌长熊），跌了 13 年、用了 34 年才收复失地。
- **韩国**：危机是"外生传导式"的（美元潮汐+出口链），散户高杠杆，汇率是股市的先行指标。
