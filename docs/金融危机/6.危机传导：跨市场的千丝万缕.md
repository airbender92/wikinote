# 6. 危机传导：跨市场的千丝万缕

> 四大市场（美股、A股、日韩）并非孤岛。金融危机的可怕之处在于**传染性**——一条产业链、一次加息、一笔套息交易平仓，都能让大洋两岸的股市同步暴跌。
> 本章梳理危机传导的 **六大管道**，并复盘三次"全球同步危机"。

---

## 一、六大传导管道

### 管道1：美元潮汐（最根本）

```
美联储降息/放水 → 全球流动性泛滥 → 新兴市场资产泡沫
        ↓
美联储加息/缩表 → 美元回流 → 新兴市场美元荒 → 货币贬值 → 股市暴跌
```

| 美联储周期 | 后果 |
| --- | --- |
| 1994-1995加息 | 墨西哥比索危机 |
| 1997-1998加息+美元走强 | **亚洲金融危机**（韩国、泰国、印尼） |
| 2004-2006加息 | 引爆2008次贷（高利率刺破地产） |
| 2022-2023激进加息 | 全球股市普跌，韩股/日股/港股重挫 |

> 美国作为"全球央行"，其利率是全球资产价格的**总锚**。加息周期里没有哪个市场能独善其身。

### 管道2：日元套息交易（carry trade）

```
借低息日元 → 换成美元/韩元等 → 买入全球高收益资产
        ↓
日本央行加息/日元升值 → 套息成本上升 → 集体平仓
        ↓
卖出全球资产 → 还日元 → 全球股市、汇市同步暴跌
```

- 1998年俄罗斯违约+日元升值 → 长期资本管理公司(LTCM)爆仓 → 全球危机
- **2024.08.05**：日本央行加息 → 日经-12.4%、KOSPI-8.8%、纳指期货大跌（详见[第4篇](4.日本：泡沫破裂与失落三十年.md)）
- 日元成为"全球杠杆的血液"，日本央行的每一次动作都是全球风险事件

### 管道3：贸易链传导（对出口导向市场最关键）

```
美国/欧洲需求萎缩 → 亚洲出口订单骤降 → 企业盈利下修 → 股市下跌
```

- 2008年：中国出口增速从20%+跌至负值，A股跟随全球崩盘
- 2018-2019：中美贸易战直接打击A股与韩国（三星出口链）
- 2025年：特朗普关税战 → 韩国、A股、日股出口链集体承压

### 管道4：情绪与风险偏好（最快，以小时计）

- 恐慌是"快变量"：美股暴跌 → 亚太开盘恐慌低开（时差机制）
- VIX恐慌指数是全球风险偏好的"体温计"
- 亚洲交易时间（日→韩→A→欧→美）逐级接力传导：**美股收盘决定亚洲开盘，亚洲收盘影响美股开盘**

### 管道5：机构资金流动（被动传导）

- 全球配置型基金（养老金、主权基金）按权重配置 → 美股跌→赎回→被迫卖出所有市场持仓
- 美元升值 → 新兴市场基金资金外流（"资本外逃"）
- 2022年全球股市无差别下跌（-20%~-30%），就是资金"卖一切"的结果

### 管道6：资产负债表与货币联动

- 韩元、人民币贬值 → 输入性通胀 → 央行被迫加息 → 股市承压
- 各国央行"竞争性宽松/紧缩"的联动（2020全球放水、2022全球紧缩）

## 二、三次全球同步危机的复盘

### 2.1 1997-1998 亚洲金融危机

**传导链**：泰国泰铢失守 → 区域货币危机 → 韩元、印尼盾崩盘 → 亚洲股市普跌 → 俄罗斯违约 → 冲击欧美（LTCM爆仓）→ 全球避险。

| 市场 | 跌幅 |
| --- | --- |
| 韩国KOSPI | -60%+ |
| 泰国SET | -75% |
| 印尼 | -60%+ |
| 香港恒指 | -60%（1997.10-1998.08） |
| 日本日经 | -30%（1997-1998） |
| 美股 | 相对抗跌（后受LTCM冲击） |

> 有意思的是：**A股1997-1998几乎未受影响**（资本管制+未开放），是中国金融防火墙的早期验证。

### 2.2 2008 全球金融危机

**传导链**：美国次贷 → 雷曼破产 → 全球信贷冻结 → 全球股市同步崩盘 → 新兴市场（韩、中、印）出口骤降。

| 市场 | 最大跌幅 |
| --- | --- |
| 美股标普 | -57% |
| A股上证 | -73% |
| 韩国KOSPI | -57% |
| 日本日经 | -60%（2007-2009） |

> 中国例外中的例外：**跌幅比危机发源地还深**——因为A股2007年自身就是全球最大泡沫之一（6124点），全球危机只是"压垮骆驼的最后一根稻草"。

### 2.3 2020 疫情危机（非金融危机的全球同步）

- 美股23天跌34%，全球股市平均-30%
- 但**救市同步性史上最强**：各国央行联合降息+无限QE
- 结论：**外生冲击（疫情）的危机，全球同步性极高，但恢复也同步**——放水即可修复

### 2.4 2022 全球紧缩熊市

- 美联储暴力加息 → 全球无差别下跌（美股-25%、日经-10%、KOSPI-35%、A股-25%、港股-35%）
- 唯一例外：A股2022.4-10有独立行情（疫情+政策），但仍无法完全脱钩

## 三、A股的"防火墙"与"导火索"之争

### A股为什么有时能"脱钩"

| 防火墙 | 机制 |
| --- | --- |
| 资本管制 | 外资占比低（约3-4%市值），热钱进出受限 |
| 汇率管控 | 人民币有管理浮动，不随波逐流 |
| 政策独立性 | 央行以国内目标为主（"以我为主"） |
| 流动性独立 | 场内资金主要来自境内居民存款搬家 |

### A股为什么最终仍会"补跌"

| 导火索 | 机制 |
| --- | --- |
| 情绪传导 | 美股暴跌→A股次日低开（涨跌停制度放大恐慌） |
| 出口链 | 全球衰退→出口订单降→盈利下修（2018、2025） |
| 北上资金 | 外资经陆股通撤离→核心资产承压 |
| 港股联动 | AH溢价收敛压力→蓝筹估值锚下移 |
| 大宗商品 | 全球衰退→油价/铜价跌→周期股杀跌 |

> 结论：A股的"脱钩"是**短期的、结构性的**，长期看仍与全球风险周期高度相关——只是**跌得比美股晚、跌得比美股多**（因为散户化+波动大）。

## 四、传导的"时间差"与"节奏表"

```
美股暴跌（隔夜）
    ↓ 0-8小时
亚太开盘：日经 → KOSPI → A股（恐慌低开）
    ↓ 数小时
欧洲开盘（跟随美股期货）
    ↓
美股当晚开盘（决定次日亚洲）
```

**关键联动指标**：
1. **VIX** > 30 = 全球风险模式开启
2. **美元指数** 走强 = 新兴市场承压
3. **美债收益率** 飙升 = 成长股杀估值
4. **日元** 升值 = 套息平仓警报（对日韩股市尤其）
5. **韩元/人民币** 贬值 = 本市场资金外流信号

## 六、结论：危机时代如何看全球股市

1. **看美元与美联储**，不看任何单一市场——流动性是全球股市的共同母题
2. **看日元**（套息）、**看韩元**（先行）、**看VIX**（情绪）——三大警报器
3. **美股是"因"，新兴市场是"果"**：美股见底通常领先新兴市场见底
4. **A股的独立性有限**：防火墙挡得住资金，挡不住情绪与出口
5. **危机传导有顺序**：日→韩→A→欧→美，可利用时间差但不可依赖
