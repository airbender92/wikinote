# 3. A股：牛熊与股灾

> A股是"政策市"与"情绪市"的极致样本：散户主导、杠杆凶猛、政策是最大的基本面。
> 每一次大牛市的顶点都是杠杆堆出来的，每一次大熊市的底部都是政策托出来的。
> 主线规律：**牛短熊长，暴涨暴跌，政策底 → 市场底 → 经济底的三段式**。

## 二、逐轮复盘

### 2.1 2007-2008：6124点的疯狂与崩落

**背景**：
- 2005年股权分置改革 → 全流通预期
- 人民币升值 + 贸易顺差 → 热钱涌入
- 全民炒股：2007年新开户数达到前五年总和

**疯狂顶点**：
- 2007.10.16 上证 **6124点**，市盈率超60倍（部分银行股100倍+）
- 中石油上市首日48元（此后一路跌至4-8元，成为"最大绞肉机"）

**崩盘过程**：
- 2008年：次贷危机从华尔街传导（详见[第2篇](2.美股：百年危机史.md)）
- 2008.10.28 上证见底 **1664点**，跌幅 **73%**
- 下跌无抵抗：政策当时忙于"防止通胀"，直到9月才转向

**拯救**：
- 2008.11 国务院"**四万亿**"刺激计划 → 2009年上证翻倍到3478点

> 💡 启示：A股对全球危机的传导主要是**出口链+情绪**（2008年中国金融体系相对封闭，没有银行系统性危机，但股市照跌73%——因为估值太贵+信心崩塌）。

### 2.2 2015 杠杆牛崩盘：A股自己的"金融危机"

**背景**：
- 2014年底央行降息降准 → 改革牛叙事（"一带一路"、国企改革）
- 杠杆工具全面开花：**两融**（2015年6月达2.27万亿）、**场外配资**（估计1.5-2万亿）、**伞形信托**、**分级基金B**

**疯狂顶点**：
- 2015.06.12 上证 **5178点**，创业板市盈率100倍+
- 日成交2万亿+，全民加杠杆炒股

**崩盘过程（股灾1.0/2.0/3.0）**：
| 阶段 | 时间 | 事件 |
| --- | --- | --- |
| 股灾1.0 | 2015.06-07 | 监管清查配资 → 千股跌停，三周跌35% |
| 救市 | 2015.07 | 国家队2万亿入场、禁止大股东减持、21家券商救市 |
| 股灾2.0 | 2015.08 | 汇率贬值+全球动荡，8.24单日-8.5% |
| 股灾3.0 | 2016.01 | **熔断机制4天4次触发**，1.4单日-6.9%提前收盘，1.7再次熔断，仅实施4天即被取消 |
| 见底 | 2016.01.27 | 2638点，总跌幅 **-49%** |

**核心机制——去杠杆螺旋**：
```
监管查配资 → 配资盘强平 → 股价跌 → 两融平仓线被触及
→ 更多强平 → 千股跌停 → 基金巨额赎回 → 流动性枯竭
→ 国家队救市 → 反弹后散户出逃 → 二次探底
```

> 💡 启示：**杠杆牛必然以踩踏收场**。杠杆把牛市从"快牛"变成"疯牛"，也把调整变成"股灾"。这是A股最深刻的一课。

### 2.3 2018 贸易战熊市：外部冲击+内部去杠杆

**背景**：
- 2017年"去杠杆、防风险"金融严监管（资管新规）
- 2018年3月中美贸易战开打

**过程**：
- 2018.01 见顶3587 → 2019.01 见底2440，跌幅 **-32%**
- 全年阴跌+闪崩并存：10月一度出现"千股跌停+质押爆仓"恐慌
- **股权质押危机**：大股东质押爆仓风险成为最大隐患（股价跌→质押平仓→抛售→再跌）

**转折**：2018年10月政策转向（民企座谈会、"纾困基金"），2019年初贸易缓和+降准 → 2440成为牛市起点。

> 💡 启示：**质押盘是A股特有的"隐性杠杆"**，跌到一定位置会自我强化；政策底（2018.10）早于市场底（2019.01）约3个月。

### 2.4 2021-2024：地产下行与流动性危机

**背景**：2021年核心资产（茅指数、宁组合）泡沫破灭 + 2021下半年地产暴雷（恒大）→ 居民资产负债表受损 → 消费疲弱 → 2022-2023持续阴跌。

**2024年初流动性危机（"小股灾"）**：
- 2024.01-02 微盘股+量化DMA（多空收益互换）强平踩踏
- 雪球产品集中敲入 → 期货贴水 → 量化被迫卖出小微盘股 → 小微盘股崩盘
- 2024.02.05 上证盘中 **2635点**（2021年以来新低），全市场"千股跌停"再现
- 国家队（中央汇金）大举买入沪深300/中证500ETF护盘

**2024.9.24 政策大逆转（924行情）**：
- 央行+证监会+金融监管总局联合发布：**降准降息、创设证券基金保险互换便利(SFISF)、股票回购增持再贷款**
- 政治局会议罕见强调"促进房地产市场止跌回稳"
- 上证5天暴涨，9.30单日成交破2.6万亿创纪录，10.8开盘一度冲高3674点
- 单周涨幅（+21%以上）创1996年以来纪录，被称"政策牛/闪电牛"

> 💡 启示：A股是**强政策驱动市场**。当估值处于历史低位+政策全力转向时，会出现"戴维斯双击"式的脉冲行情；但2015年教训表明——若行情再次被杠杆放大，监管会再度干预。

### 2.5 2025年至今（补充）

- 2025.04 中美关税摩擦升级 → 上证4.7单日 **-7.3%**（仅次于2008/2015/2016的极端日），国家队+汇金再度护盘
- 政策持续宽松（降准降息、稳股市楼市），市场在3300-3600区间宽幅震荡
- 全球视角下，A股估值仍处历史中低位，但赚钱效应依赖基本面兑现（地产、内需、科技）

## 三、A股的危机特质（与美股对比）

| 维度 | 美股 | A股 |
| --- | --- | --- |
| 驱动主体 | 机构+全球资金 | 散户（交易占比60%+） |
| 危机根源 | 金融创新+杠杆 | 政策松紧+杠杆+情绪 |
| 下跌形态 | 脉冲式急跌快涨 | 反复震荡阴跌+急跌 |
| 见底信号 | 流动性救助 | **政策底 → 市场底** |
| 波动率 | 年化15-20% | 年化25-30%+ |
| 涨跌停/熔断 | 单日无限制 | ±10%涨跌停、2024年后无熔断 |

## 四、A股"政策底→市场底→经济底"三段式

```
【政策底】高层定调+货币财政宽松（例：2018.10、2024.9.24）
     ↓ （1-3个月）
【市场底】恐慌出清、国家队护盘、成交地量（例：2019.01、2024.02）
     ↓ （3-6个月）
【经济底】信贷/PMI/地产企稳回升（例：2016年中、2024Q4后）
```

**关键识别指标**：
1. 政策：降准降息、汇金增持、暂停IPO、限制减持
2. 资金：两融余额见底回升、新发基金回暖、ETF净申购
3. 估值：沪深300市盈率跌破历史20%分位
4. 情绪：破净率>10%、换手率地量、股基发行冰点
