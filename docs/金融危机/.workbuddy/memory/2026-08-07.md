## 沪深主板50标的危机情景分析（HTML研报）

追加产出：`A股沪深主板优质标的-金融危机情景分析.html`（浅底研报风 + ECharts散点图）

### 方法与流程（可复用）
1. **数据**：westock-tool 筛选候选池（高ROE/高股息/低估值 preset + strategy buffet），westock-data quote 批量拉取 60+ 只沪深主板标的实时行情（PE/PB/股息/市值/52周高低/ROE）
2. **评分模型**（Python，`assets/build_crisis_report.py`）：
   - 防御分 = 行业防御40% + 估值20% + 股息20% + ROE20%（抗跌性）
   - 弹性分 = 政策受益40% + 超跌修复30% + ROE15% + Beta15%（反弹力）
   - 风险分 = Beta40% + 估值泡沫30% + 周期波动30%（大跌风险）
   - 综合分 = 防御35% + 弹性40% + (100-风险)25%
3. **分类**（按防御/弹性/风险阈值）：避险核心 / 稳健防御 / 攻守兼备 / 高弹性反弹 / 高波动弹性（五类）
4. **低吸区间**：按分类设回撤深度（避险10-18%…高波动22-38%），上沿=现价×(1-浅回撤)，下沿=现价×(1-深回撤)，参考52周低点兜底
5. **分层精选**：必选龙头（茅台/中信/平安/长电等12只）+ 五类配额（10/14/12/8/6）保证类别全覆盖
6. **HTML生成**（`assets/gen_html.py`）：ECharts 散点图（X=防御分,Y=弹性分），JS 必须 `node --check` 自检通过

### 关键结论
- 避险核心：长江电力/华能国际/招行/兴业/神华/紫金/茅台
- 高弹性反弹：片仔癀、东鹏、汾酒、券商（政策底后弹性先锋）
- 数据时点：2026-08-07 收盘（腾讯自选股接口）

## 科技成长板块补充专题（HTML）
