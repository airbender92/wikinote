## `$emit` 在组件中的使用

### 一、基础概念

`$emit` 是 Vue 实例方法，用于**子组件向父组件发送自定义事件**，实现子 → 父的通信。

```
父组件                    子组件
  │                        │
  │  <attribute-dialog     │
  │    @change="handler"   │
  │    @changeData="handler2" │
  │  >                     │
  │                        │
  │  ◄─────────────────────┤  this.$emit('change', data)
  │                        │
```

在该组件中，`$emit` 出现在两个地方：

### 三、使用方式详解

#### 3.1 语法格式

```javascript
this.$emit(eventName, ...args)
```

| 参数 | 说明 |
|-----|------|
| `eventName` | 自定义事件名称（字符串） |
| `...args` | 传递给父组件的数据（可选，可传多个） |

#### 3.2 本组件中的调用

```javascript
this.$emit('change', newData);
//      ↑事件名    ↑传递的数据
```

**含义**：告诉父组件"属性数据已变更"，并把 `newData` 传给父组件。

### 六、为什么要发两个事件

代码中同时发送了 `change` 和 `changeData`：

```javascript
this.$emit('change', newData);
this.$emit('changeData', newData);
```

**可能的原因**：

| 事件名 | 用途推测 |
|-------|---------|
| `change` | 通用变更事件，父组件统一监听 |
| `changeData` | 专门的数据变更事件，可能有不同的处理逻辑 |

**实际建议**：如果两个事件传递的数据完全相同，可以合并为一个事件，简化代码。

### 八、简单示例帮助理解

**子组件（Child.vue）**：
```vue
<template>
  <button @click="sendMessage">发送消息</button>
</template>

<script>
export default {
  methods: {
    sendMessage() {
      this.$emit('message', 'Hello 父组件!');
    },
  },
};
</script>
```

**父组件**：
```vue
<template>
  <child @message="handleMessage" />
  <!-- 点击按钮后，msg 变成 "Hello 父组件!" -->
  <p>{{ msg }}</p>
</template>

<script>
export default {
  data() {
    return { msg: '' };
  },
  methods: {
    handleMessage(text) {
      this.msg = text;  // text = 'Hello 父组件!'
    },
  },
};
</script>
```

### 九、总结

`$emit` 的核心作用就是**子组件通知父组件"某事发生了"**，并可以附带数据。

在本组件中：
- 子组件（attributeDialog）完成属性保存/更新后
- 通过 `$emit('change', newData)` 通知父组件
- 父组件监听 `change` 事件，获取最新数据并更新界面
