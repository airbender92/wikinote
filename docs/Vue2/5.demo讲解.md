## 七、计算属性与方法

### **方法定义**

```javascript
methods: {
  // 递归查找ID
  getSameId(list, id) {
    if (list.length > 0) {
      for (let o of list || []) {
        if (o.id == id) return true;
        if (o.__config__.children) {
          const o_ = this.getSameId(o.__config__.children, id);
          if (o_) return true;
        }
      }
    }
    return false;
  },
  
  // 克隆组件并生成新ID
  cloneComponent(origin) {
    const clone = deepClone(origin);
    this.createIdAndKey(clone);
    return clone;
  }
}
```

2. **中间画布**：展示已配置的属性组，支持拖拽排序和编辑
3. **属性弹窗**：新增/编辑属性字段配置
4. **保存机制**：支持单组保存和批量保存

## 技术亮点

1. **递归组件结构**：`drawingList` 支持嵌套的 children 结构
2. **拖拽状态管理**：通过 `EleDisabled` 标记防止重复拖拽
3. **响应式更新优化**：使用 `$set` 和 `renderKey` 强制组件更新
4. **异步流程控制**：使用 `Promise.all` 批量保存
