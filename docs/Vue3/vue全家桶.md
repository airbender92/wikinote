### 📦 核心组合：现代化 Web 应用的三件套

这三大件是构建一个完整 Vue 3 单页应用（SPA）的基石。

| 功能 | 推荐工具与版本 | 为何选择及核心说明 |
| :--- | :--- | :--- |
| **⚡️ 构建工具** | **Vite 8** (当前最新版本，基于 Rust 重写) | 新一代的前端构建工具，由 Vue 作者尤雨溪打造。相比传统的 Webpack，它在开发环境实现了**毫秒级的冷启动和热更新**。<br>Vite 8 最大的变化是**用 Rust 编写的 Rolldown 统一了开发和生产环境的打包器**，这不仅带来了 **10-30倍** 的构建性能提升（例如，大型项目的生产构建时间从 46 秒降至 6 秒），更重要的是解决了以往开发和生产环境行为不一致的问题。 |
| **🚦 官方路由** | **Vue Router 5** | 管理单页应用中的页面跳转和导航。Vue Router 5 是一个“无聊的”过渡版本，它的亮点是**将文件系统路由插件（unplugin-vue-router）直接集成进核心库**。现在你可以像 Nuxt 一样，通过 `pages/` 目录的结构**自动生成路由**，无需手动配置，并享受完整的 TypeScript 支持，体验极佳。 |
| **🍍 官方状态管理** | **Pinia 3** | Pinia 已**正式取代 Vuex**，成为 Vue 官方推荐的状态管理库。它拥有极简的 API，**移除了 Vuex 中饱受诟病的 Mutations**，对 TypeScript 的支持非常友好。Pinia 3 在此前基础上，进一步与 Vue 3 的响应式系统深度集成，是管理跨组件/页面共享状态的唯一首选。 |

### 🌳 UI 组件库：快速搭建界面的核心

基于 Vue 3 的 UI 库生态非常繁荣，以下是几个主流且积极维护的选择：

| UI 库 | 核心特点与适用场景 |
| :--- | :--- |
| **Element Plus** | **广受欢迎、成熟稳定**的桌面端组件库。它是 Vue 2 时代 Element UI 的直接升级版，文档和社区生态非常完善，非常适合快速搭建企业级后台管理系统。 |
| **TDesign Vue Next** | 腾讯开源的企业级设计体系，技术实力雄厚，**维护非常积极**。它提供完整的跨端、跨技术栈解决方案，适合追求长期稳定性和大厂背书的大型项目。 |
| **Ant Design Vue** | 阿里 Ant Design 的 Vue 实现，设计风格偏商务和专业。但需要注意的是，其近期维护**显著放缓**，可能存在“半弃坑”状态，选型时需要谨慎评估。 |
| **Vuetify 3** | 严格遵循 **Material Design** 规范的组件库，功能强大，生态成熟，是谷歌设计风格的忠实拥趸的首选。 |
| **Naive UI** | 以 **TypeScript 友好、主题系统灵活**和清新的 UI 风格著称，深受追求极致开发体验的开发者喜爱。 |
| **Headless UI** | **不提供任何预设样式**的组件库，你将获得完整的组件逻辑和无障碍访问支持，但**样式完全由你控制**。代表库有 `shadcn-vue` 和 `reka-ui`，最适合定制化要求极高、搭配 Tailwind CSS 使用的项目。 |

### 🧩 辅助工具库：提升开发效率与体验

这些库并非必需，但能极大地优化特定场景下的开发。

#### 组合式工具集
*   **VueUse**: 可以说是 Vue 3 开发者的**瑞士军刀**。它是一套基于 Composition API 的**实用组合式函数（composables）集合**，覆盖了从防抖、节流到监听窗口大小、使用本地存储等几乎所有常见的逻辑需求，即插即用。

#### 状态管理增强
*   **Pinia Colada**: 一个专门用于**数据获取和缓存**的轻量级库（约 2KB）。它紧密集成 Pinia，提供 `useQuery` 和 `useMutation` 等组合式 API，能**自动处理**加载状态、请求去重、缓存、后台刷新和错误重试等复杂逻辑，是处理服务端状态的最佳拍档。

#### 特殊场景集成
*   **TresJS**: 如果你想在 Vue 应用中构建 3D 场景，这个库是绝佳选择。它让你能用**声明式**的 Vue 组件语法来编写 Three.js，将复杂的 3D 开发变得像写普通 Vue 模板一样简单。

### 💻 开发环境与测试

*   **IDE 支持**: **Volar**（现已更名为 **Vue - Official**）是必装的 VS Code 扩展，它提供了针对 Vue 3 的语法高亮、智能提示、类型检查等特性，比 Vue 2 时代的 Vetur 体验有了质的提升。
*   **测试工具**:
    *   **Vitest**: 由 Vite 团队打造，与 Vite 配置无缝集成。它极快、原生支持 TypeScript/JSX，API 兼容 Jest，是目前测试 Vue 组件的首选。
    *   **Vue Test Utils**: Vue 官方的单元测试实用工具库，通常配合 Vitest 或 Jest 一起使用。
