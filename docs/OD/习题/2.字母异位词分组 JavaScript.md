# 字母异位词分组 JavaScript
## 核心思路
**字母相同、顺序不同的字符串，排序之后得到的 key 完全一致**
1. 建立 Map：`key = 排序后的字符串`，value = 异位词数组
2. 遍历每一个单词：
   - 将单词拆成字符数组 → 排序 → 拼接成唯一标识 key
   - 如果 map 存在该 key，push 进去；不存在则新建数组
3. 最后把 map 的全部 value 转为数组返回

时间复杂度：$O(nk\log k)$
$n$ = 字符串数量，$k$ = 单个字符串最大长度（排序耗时 $k\log k$）

## 代码（LeetCode可直接提交）
```javascript
/**
 * @param {string[]} strs
 * @return {string[][]}
 */
var groupAnagrams = function(strs) {
    const map = new Map();
    for (const s of strs) {
        // 生成唯一排序key
        const key = s.split('').sort().join('');
        if (!map.has(key)) {
            map.set(key, []);
        }
        map.get(key).push(s);
    }
    return [...map.values()];
};
```

## 测试用例
```js
console.log(groupAnagrams(["eat","tea","tan","ate","nat","bat"]));
// [["eat","tea","ate"],["tan","nat"],["bat"]]
console.log(groupAnagrams([""])); // [[""]]
console.log(groupAnagrams(["a"])); // [["a"]]
```

## 进阶优化方案（计数法，避免排序，$\(O(nk)\)$）
因为只有26个小写字母，用**字母出现次数拼接字符串当key**
```javascript
var groupAnagrams = function(strs) {
    const map = new Map();
    for (const s of strs) {
        const count = new Array(26).fill(0);
        for (const c of s) {
            count[c.charCodeAt() - 'a'.charCodeAt()]++;
        }
        const key = count.join(',');
        if (!map.has(key)) map.set(key, []);
        map.get(key).push(s);
    }
    return [...map.values()];
};
```

### 两种方案对比
1. 排序法：代码简短好写，面试优先写这个，容易一次写对
2. 计数法：效率更高，字符串很长时优势明显，代码稍长
