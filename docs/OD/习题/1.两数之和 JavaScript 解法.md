# 两数之和 JavaScript 解法
## 思路
暴力双重循环时间复杂度 $O(n^2)$；
**哈希表（Map）优化到 $\(O(n)\)$**：遍历数组，用 `target - 当前值` 作为去查找的差值，如果哈希表里存在这个差值，直接返回两个下标；不存在就把「值:下标」存入哈希表。
> 保证不会取到同一个元素：先查再存。

## 代码实现
```javascript
/**
 * @param {number[]} nums
 * @param {number} target
 * @return {number[]}
 */
var twoSum = function(nums, target) {
    const map = new Map();
    for(let i = 0; i < nums.length; i++){
        const diff = target - nums[i];
        if(map.has(diff)){
            return [map.get(diff), i];
        }
        map.set(nums[i], i);
    }
    return [];
};
```

## 测试用例
```js
console.log(twoSum([2,7,11,15],9)); // [0,1]
console.log(twoSum([3,2,4],6));     // [1,2]
console.log(twoSum([3,3],6));       // [0,1]
```

## 复杂度分析
- 时间复杂度：$\(O(n)\)$，数组只遍历一次，哈希查找是 $\(O(1)\)$
- 空间复杂度：$\(O(n)\)$，最坏情况存储全部元素

## 暴力写法（不推荐，仅理解）
```javascript
var twoSum = function(nums, target) {
    for(let i = 0; i < nums.length; i++){
        for(let j = i + 1; j < nums.length; j++){
            if(nums[i] + nums[j] === target){
                return [i,j];
            }
        }
    }
    return [];
};
```
