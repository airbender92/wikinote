# 最长连续序列 JavaScript（\(\boldsymbol{O(n)}\)解法）
## 思路要求：严格 \(\boldsymbol{O(n)}\)
1. 先用 **Set 去重**，查询元素是否存在是 O(1)
2. 遍历集合中的每个数字 `x`：
   - 只有当 **`x-1` 不在集合里**，才作为一段连续序列的起点（避免重复计算）
   - 从起点不断往后找 `x+1, x+2...`，统计当前连续长度
   - 更新全局最大长度

> 每个数字只会被访问一次，整体时间复杂度 \(\boldsymbol{O(n)}\)

## 完整可提交代码
```javascript
/**
 * @param {number[]} nums
 * @return {number}
 */
var longestConsecutive = function(nums) {
    const set = new Set(nums);
    let maxLen = 0;

    for (const num of set) {
        // 判断是否是连续序列的起点：num-1不存在
        if (!set.has(num - 1)) {
            let current = num;
            let curLen = 1;
            // 不断向后延伸
            while (set.has(current + 1)) {
                current++;
                curLen++;
            }
            maxLen = Math.max(maxLen, curLen);
        }
    }
    return maxLen;
};
```

## 测试用例
```js
console.log(longestConsecutive([100,4,200,1,3,2])); // 4
console.log(longestConsecutive([0,3,7,2,5,8,4,6,0,1])); //9
console.log(longestConsecutive([1,0,1,2])); //3
console.log(longestConsecutive([])); //0
```

## 复杂度分析
- 时间复杂度：$\boldsymbol{\(\boldsymbol{O(n)}\)}$，每个元素最多进入 while 循环一次
- 空间复杂度：$\boldsymbol{\(\boldsymbol{O(n)}\)}$，Set存储全部数字

## 对比暴力排序法（不满足\(\boldsymbol{O(n)}\)，仅作对比）
排序复杂度 $O(n\log n)$，题目不允许：
```javascript
var longestConsecutive = function(nums) {
    if(nums.length === 0) return 0;
    nums = [...new Set(nums)].sort((a,b)=>a-b);
    let max = 1, cur =1;
    for(let i=1;i<nums.length;i++){
        if(nums[i] === nums[i-1]+1){
            cur++;
            max = Math.max(max,cur);
        }else cur=1;
    }
    return max;
};
```
