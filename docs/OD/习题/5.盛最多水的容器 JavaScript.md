# 盛最多水的容器 JavaScript（双指针）
## 思路
容器面积公式：`面积 = 两条垂线之间距离 × 较低的那条高度`
`area = (right - left) * Math.min(height[left], height[right])`

**双指针核心逻辑：**
- left 左边界，right 右边界，初始分别在数组两端
- 每次计算当前面积，更新最大值
- **移动高度更小的那一侧指针**：
  > 如果左边矮，向右移动 left；右边矮，向左移动 right。
  > 原因：短板决定高度。移动长板，宽度减少，高度不会变大，面积一定变小；移动短板，才有可能找到更高的柱子，面积变大。

时间复杂度：$\(O(n)\)$，只遍历一次
空间复杂度：$\(O(1)\)$

## 可直接提交代码
```javascript
/**
 * @param {number[]} height
 * @return {number}
 */
var maxArea = function(height) {
    let left = 0;
    let right = height.length - 1;
    let max = 0;
    while(left < right) {
        const w = right - left;
        const h = Math.min(height[left], height[right]);
        const area = w * h;
        max = Math.max(max, area);
        // 移动短板
        if(height[left] < height[right]) {
            left++;
        } else {
            right--;
        }
    }
    return max;
};
```

## 测试用例
```js
console.log(maxArea([1,8,6,2,5,4,8,3,7])); // 49
console.log(maxArea([1,1])); // 1
```

## 面试重点
- ❌ 暴力两层循环 $O(n^2)$ 会超时，数组长度可达 $10^5$
- ✅ 双指针 $\(O(n)\)$，关键：**移动短板**
- 面积由较短的柱子决定
