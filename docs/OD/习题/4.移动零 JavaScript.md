# 移动零 JavaScript（原地修改，双指针）
## 思路
快慢指针：
- `slow`：指向**下一个要放置非零元素**的位置
- `fast`：遍历数组，寻找非零数字
1. fast遇到非零，把值赋值给 slow，slow++
2. fast遍历完后，slow 往后全部置0
原地操作，不新建数组，保持非零元素相对顺序。
时间：$\(O(n)\)$，空间：$\(O(1)\)$

## 代码（可直接提交）
```javascript
/**
 * @param {number[]} nums
 * @return {void} Do not return anything, modify nums in-place instead.
 */
var moveZeroes = function(nums) {
    let slow = 0;
    // fast遍历，把所有非零挪到前面
    for(let fast = 0; fast < nums.length; fast++){
        if(nums[fast] !== 0){
            nums[slow] = nums[fast];
            slow++;
        }
    }
    // slow之后全部填0
    for(let i = slow; i < nums.length; i++){
        nums[i] = 0;
    }
};
```

### 另一种写法：交换（减少赋值操作，对应进阶要求）
遇到非零，直接交换 slow 和 fast，不用二次循环置0：
```javascript
var moveZeroes = function(nums) {
    let slow = 0;
    for(let fast = 0; fast < nums.length; fast++){
        if(nums[fast] !== 0){
            // 避免自己和自己交换（slow===fast时）
            if(slow !== fast){
                [nums[slow], nums[fast]] = [nums[fast], nums[slow]];
            }
            slow++;
        }
    }
};
```

## 测试
```js
let arr = [0,1,0,3,12];
moveZeroes(arr);
console.log(arr); // [1,3,12,0,0]

let arr2 = [0];
moveZeroes(arr2);
console.log(arr2); // [0]
```

## 要点（面试口述）
- 要求**原地修改**，不能新建数组返回
- 保持非零元素**相对顺序不变**
- 双指针，快慢指针，一次遍历
