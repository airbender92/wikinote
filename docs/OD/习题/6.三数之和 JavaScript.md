# 三数之和 JavaScript（排序+双指针，去重是面试重点）
## 思路
题目要求：找出所有不重复三元组，三数之和=0。不能暴力三层循环（$O(n^3)$超时）
1. **数组先排序**，方便双指针 + 跳过重复数字
2. 固定第一个数 `nums[i]`，剩下区间用左右双指针 `left=i+1`，`right = n-1`
3. 三数求和：
   - sum = 0：收集结果，**左右指针都要跳过重复值**
   - sum < 0：太小，left++
   - sum > 0：太大，right--
4. **外层i也要去重**：如果 `nums[i] === nums[i-1]`，直接continue，避免产生重复三元组

> 边界：`nums[i]>0` 时直接break，数组升序，后面全部正数，和不可能为0

时间复杂度：$O(n^2)$，排序$O(n\log n)$，外层循环$\(O(n)\)$，内层双指针$\(O(n)\)$
空间：$O(\log n)$ 排序栈空间（取决于排序实现）

## 可提交代码
```javascript
/**
 * @param {number[]} nums
 * @return {number[][]}
 */
var threeSum = function(nums) {
    const res = [];
    nums.sort((a,b) => a - b);
    const n = nums.length;
    for(let i = 0; i < n; i++){
        // 当前数字>0，后面全正数，不可能凑0
        if(nums[i] > 0) break;
        // 外层去重：和上一个元素相同，跳过
        if(i > 0 && nums[i] === nums[i-1]) continue;

        let left = i + 1;
        let right = n - 1;
        while(left < right){
            const sum = nums[i] + nums[left] + nums[right];
            if(sum === 0){
                res.push([nums[i], nums[left], nums[right]]);
                // left指针去重
                while(left < right && nums[left] === nums[left+1]) left++;
                // right指针去重
                while(left < right && nums[right] === nums[right-1]) right--;
                // 找到一组，收缩窗口
                left++;
                right--;
            } else if(sum < 0){
                left++;
            } else {
                right--;
            }
        }
    }
    return res;
};
```

## 测试用例
```js
console.log(threeSum([-1,0,1,2,-1,-4])); // [[-1,-1,2],[-1,0,1]]
console.log(threeSum([0,1,1])); // []
console.log(threeSum([0,0,0])); // [[0,0,0]]
```

## 面试踩坑点（重点）
1. 忘记**去重**：会返回重复三元组，直接报错
2. 排序函数必须写 `(a,b)=>a-b`，js默认字典序排序，负数会出错
3. while内部去重判断条件必须带上 `left<right`，防止越界
4. 不能用Set简单去重，三元组是数组，引用类型无法直接去重
