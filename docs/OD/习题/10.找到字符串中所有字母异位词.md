# LCR 015. 找到字符串中所有字母异位词（原LeetCode438）

> 
> 核心思路：**滑动窗口 + 字符计数数组**。因为只有小写英文字母，开长度26数组统计字母出现次数。
> 异位词条件：窗口内每个字母计数，和p的计数完全相等。

## JS 代码

```
/**
 * @param {string} s
 * @param {string} p
 * @return {number[]}
 */
var findAnagrams = function(s, p) {
    const res = [];
    const sCount = new Array(26).fill(0);
    const pCount = new Array(26).fill(0);
    const aCode = 'a'.charCodeAt(0);
    const pLen = p.length;

    // 初始化p的字符统计
    for(const char of p) {
        pCount[char.charCodeAt(0) - aCode]++;
    }

    // 先填充s前pLen个字符
    for(let i = 0; i < pLen; i++) {
        sCount[s.charCodeAt(i) - aCode]++;
    }
    // 判断第一个窗口
    if(arrEqual(sCount, pCount)) {
        res.push(0);
    }

    // 滑动窗口：右边界i，左边界 i-pLen+1
    for(let i = pLen; i < s.length; i++) {
        // 移入新字符
        sCount[s.charCodeAt(i) - aCode]++;
        // 移出窗口最左侧旧字符
        sCount[s.charCodeAt(i - pLen) - aCode]--;

        if(arrEqual(sCount, pCount)) {
            res.push(i - pLen + 1);
        }
    }
    return res;
};

// 判断两个长度26数组是否全部相等
function arrEqual(arr1, arr2) {
    for(let i = 0; i < 26; i++) {
        if(arr1[i] !== arr2[i]) return false;
    }
    return true;
}
```

### 优化版本（减少每次比较26个字母，用`diff`差异计数，面试推荐）

不用每次循环对比26位，维护一个变量记录**字符数量不一致的种类数**，diff=0时就是异位词

```
var findAnagrams = function(s, p) {
    const res = [];
    const count = new Array(26).fill(0);
    const aCode = 'a'.charCodeAt(0);
    const pLen = p.length;
    let diff = 0;

    for(const c of p) {
        count[c.charCodeAt(0)-aCode]++;
    }
    for(let i=0;i<pLen;i++){
        count[s.charCodeAt(i)-aCode]--;
    }
    // 统计有多少个字母数量不一致
    for(let num of count){
        if(num!==0) diff++;
    }
    if(diff===0) res.push(0);

    for(let i=pLen;i<s.length;i++){
        // 进窗口字符
        const inIdx = s.charCodeAt(i)-aCode;
        if(count[inIdx] === 0) diff++;
        count[inIdx]--;
        if(count[inIdx] === 0) diff--;

        // 出窗口字符
        const outIdx = s.charCodeAt(i-pLen)-aCode;
        if(count[outIdx] ===0) diff++;
        count[outIdx]++;
        if(count[outIdx] ===0) diff--;

        if(diff ===0){
            res.push(i - pLen + 1);
        }
    }
    return res;
};
```

## 测试用例

| s | p | 预期输出 |
| --- | --- | --- |
| `"cbaebabacd"` | `"abc"` | `[0,6]` |
| `"abab"` | `"ab"` | `[0,1,2]` |
| `"abc"` | `"abcd"` | `[]` |
| `"baa"` | `"aa"` | `[1]` |

## 测试代码

```
console.log(findAnagrams("cbaebabacd", "abc")); // [0,6]
console.log(findAnagrams("abab", "ab"));        // [0,1,2]
console.log(findAnagrams("abc", "abcd"));       // []
console.log(findAnagrams("baa", "aa"));         // [1]
```

## 复杂度

- 基础版：时间 O(n*26)=O(n)，空间 O(26)=O(1)
- diff优化版：时间 O(n)，只遍历一次，面试最优解

> 
> 关键点：窗口大小固定等于p的长度，属于**固定长度滑动窗口**，和前面不定长窗口（最长无重复子串、最小子数组）区分开。

要不要继续下一题？

固定窗口/不定长窗口简单区分口诀：

- 窗口长度不固定 → 双指针while收缩（最长无重复、最小子数组）
- 窗口长度固定 → 每次右移一格，出去最左边（异位词这题）
