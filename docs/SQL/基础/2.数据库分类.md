数据库最常见、最实用的分类方式，主要按**数据模型**和**存储结构**来分，下面给你一份清晰好记的版本。

# 一、按数据模型（最主流分类）
## 1. 关系型数据库（RDBMS）
最常用，像 Excel 表格一样，行和列存储，用 SQL 操作。
- 代表：MySQL、Oracle、SQL Server、PostgreSQL、SQLite
- 特点：结构固定、事务安全、强一致性、适合业务系统

## 2. 非关系型数据库（NoSQL）
不严格遵循表结构，灵活、高并发、适合大数据。
常见四类：
1. **键值数据库（Key-Value）**
   - Redis、Memcached
   - 快，适合缓存、排行榜、会话存储
2. **文档数据库**
   - MongoDB、CouchDB
   - 存 JSON/文档，结构灵活
3. **列族数据库（列存储）**
   - HBase、Cassandra
   - 海量数据、高可用，适合大数据分析
4. **图数据库**
   - Neo4j、NebulaGraph
   - 存关系网络：社交关系、知识图谱、推荐系统

---

# 二、按存储方式
- **磁盘数据库**：数据存在硬盘，容量大，如 MySQL、Oracle
- **内存数据库**：数据放内存，极快，如 Redis、MemSQL

---

# 三、按使用场景
- **OLTP（联机事务）**：日常增删改查，如订单、支付 → MySQL、PostgreSQL
- **OLAP（联机分析）**：大数据统计、报表、数据仓库 → Hive、ClickHouse、Doris
- **时序数据库**：存时间序列数据，监控、IoT → InfluxDB、Prometheus
- **搜索引擎数据库**：全文检索 → Elasticsearch、Solr

---

# 四、极简总结（面试常考）
- 要稳定、事务、结构化 → **关系型（MySQL）**
- 要快、缓存、高并发 → **键值（Redis）**
- 要灵活、存文档 → **文档型（MongoDB）**
- 要大数据、分析 → **列存 / 时序 / 搜索引擎**
