# 一句话结论
MySQL 的 SQL **关键字不区分大小写**，但标识符（库名/表名/字段名）分平台有区别，字符串内容严格区分。

## 1. 关键字（SELECT / insert / FROM / where 等）完全不区分
下面三条效果一模一样，全部能正常执行：
```sql
insert into student(name) values('张三');
INSERT INTO STUDENT(NAME) VALUES('张三');
InSeRt iNtO Student(Name) VaLuEs('张三');
```

## 2. 库名、表名、字段名（标识符）分系统
- Windows：不区分大小写，`Student` 和 `student` 是同一张表
- Linux/macOS：**区分大小写**，`Student` 和 `student` 是两张不同表
开发规范建议统一小写，避免跨环境出错。

## 3. 字符串内容（引号包裹的值）严格区分大小写
```sql
-- 两条查询结果不一样
select * from student where name='Zhang';
select * from student where name='zhang';
```
你当前排序规则 `utf8mb4_0900_ai_ci` 里 `ci` 代表大小写不敏感，这条特殊：`Zhang` 和 `zhang` 会匹配到同一行；如果是 `cs` 规则就会区分。

## 4. 开发规范建议
关键字统一大写（可读性更好），表/字段名全部小写：
```sql
INSERT INTO testdb.student (`name`, age, gender) VALUES ('李四', 22, '女');
```
