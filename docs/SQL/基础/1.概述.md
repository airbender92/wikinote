# SQL 基础入门（超通俗版）
SQL 是**结构化查询语言**，用来操作数据库（增、删、改、查数据），是后端、数据分析必备基础。

## 1. 核心概念
- **数据库（DB）**：存放数据的仓库
- **表（Table）**：数据库里的表格，行=记录，列=字段
- **关键字**：`SELECT`、`FROM`、`WHERE`、`INSERT`、`UPDATE`、`DELETE` 等

---

## 2. 最常用 6 大语句
### ① 查询数据（最常用）
```sql
-- 查询指定列
SELECT 姓名, 年龄 FROM 学生;

-- 查询所有列
SELECT * FROM 学生;

-- 带条件查询
SELECT * FROM 学生 WHERE 年龄 > 18;

-- 排序
SELECT * FROM 学生 ORDER BY 年龄 DESC;
```

### ② 新增数据
```sql
INSERT INTO 学生(姓名,年龄) VALUES('张三',20);
```

### ③ 修改数据
```sql
UPDATE 学生 SET 年龄=21 WHERE 姓名='张三';
```

### ④ 删除数据
```sql
DELETE FROM 学生 WHERE 姓名='张三';
```

### ⑤ 分组统计
```sql
SELECT 班级, COUNT(*) FROM 学生 GROUP BY 班级;
```

### ⑥ 模糊查询
```sql
SELECT * FROM 学生 WHERE 姓名 LIKE '张%';
```

---

## 3. 常用子句
- `WHERE`：条件过滤
- `ORDER BY`：排序（ASC 升序 / DESC 降序）
- `GROUP BY`：分组
- `HAVING`：分组后过滤
- `LIMIT`：限制返回条数

---

## 4. 简单示例表
假设有表 `user`：
| id  | name  | age |
|-----|-------|-----|
| 1   | 小明  | 19  |
| 2   | 小红  | 20  |

查询年龄≥20：
```sql
SELECT * FROM user WHERE age >= 20;
```
