# 两种方法查看刚创建的 testdb 数据库
## 方法1：左侧刷新（最直观）
1. 看左边面板，找到 `localhost:3306` 这一行，它左边有个**刷新小圆圈按钮**
2. 点一下刷新，展开「数据库」文件夹，就能看到新增的 `testdb`
### 操作示意图对应你截图：
左侧连接栏：
`localhost:3306` → 右键 / 点刷新图标 → 展开数据库列表，出现 testdb

## 方法2：用SQL查询所有数据库（代码查看）
在SQL编辑器里输入这条语句，执行：
```sql
show databases;
```
执行后下方结果区会列出本机所有数据库，里面会包含 `testdb`，证明创建成功。

## 补充：你截图里已经执行成功的标志
下方统计面板 `Updated Rows: 1`，代表**成功新增1个数据库**，语句本身没有报错，已经创建完成，只是左侧列表没自动刷新所以暂时看不到。

## 额外小操作
找到 testdb 后右键可以：
- 新建表
- 删除数据库
- 打开SQL脚本单独操作这个库
