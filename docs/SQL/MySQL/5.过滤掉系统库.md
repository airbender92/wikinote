# 两种方法只看自己建的库，过滤掉系统库
## 方法1：SQL语句筛选（直接查，推荐）
### 1. 模糊匹配（只显示自定义库，系统库名字固定，不会匹配）
如果你自己的库都带统一前缀，比如 `test`、`shop`、`blog`，可以用模糊查询：
```sql
-- 查询名字包含test的数据库
show databases like '%test%';
```
执行后只会出现 `testdb`。

### 2. 排除所有4个系统库（精准过滤）
```sql
SELECT SCHEMA_NAME 
FROM information_schema.SCHEMATA 
WHERE SCHEMA_NAME NOT IN ('information_schema','mysql','performance_schema','sys');
```
这条语句会**彻底隐藏4个系统内置库**，只输出你手动创建的所有数据库。

## 方法2：DBeaver左侧面板筛选（可视化，不用写SQL）
1. 左侧连接栏找到 `localhost:3306` 下的「数据库」文件夹
2. 文件夹上方有个**漏斗筛选图标**
3. 点开筛选，输入排除关键词：
    `information_schema,mysql,performance_schema,sys`
4. 确认后列表只会显示你自己建的库，界面更干净。

## 补充小知识
- `show databases;` 是简易查询，没有复杂过滤功能；
- 从 `information_schema.SCHEMATA` 查询是标准方式，支持 `where` 条件做高级筛选。
