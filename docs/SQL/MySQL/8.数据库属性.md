# 红框内数据库属性逐行通俗讲解
## 1. 模式名称：testdb
就是你这个数据库的名字，对应执行语句 `create database testdb;` 里的 `testdb`，一个连接里不能重名。

## 2. 默认字符集：utf8mb4
字符集决定数据库**能存什么文字**：
- `utf8` 旧版：只能存普通汉字、英文，**不能存emoji表情**（😀👍）
- `utf8mb4` 完整版：兼容所有汉字、生僻字、微信/抖音表情，现在开发统一用这个，避免存表情报错。

## 3. 默认排序规则：utf8mb4_0900_ai_ci
排序规则配套字符集，控制文字**对比、排序、查询是否区分大小写**：
- `utf8mb4`：对应上面的字符集
- `0900`：MySQL8.0新版排序规则，汉字排序更标准
- `ai` = accent insensitive：不区分重音（中文无影响）
- `ci` = case insensitive：大小写不敏感
  例：查询 `User` 和 `user`、`A` 和 `a` 会被当成同一个内容。
如果后缀是 `cs` 就是大小写敏感。

## 4. 数据库大小：0
当前库里**没有任何数据表、没有任何数据**，占用磁盘空间为0，和你下方 `No items`（无表）对应。
等你建表、插入数据后，这个数字会变大。

## 5. SQL路径
这里是空的，作用是：给这个数据库绑定一个本地SQL脚本文件夹，方便统一存放该库的建表、初始化脚本，一般新手不用填。

## 下方表格表头（表信息栏）
- **表名**：库里每张数据表的名字
- **引擎**：MySQL存储引擎，开发默认 `InnoDB`（支持事务、外键）
- **自增**：表里是否有自增主键（比如id自动1、2、3递增）
- **数据长度**：这张表占用的存储空间
- **已分区**：是否做了分表（百万级大数据才用，新手忽略）
- **描述**：给表写备注，方便看懂表用途

# 新手重点总结
1. 字符集 `utf8mb4` 是现在标准，能存表情，不要改成旧utf8；
2. 排序规则 `utf8mb4_0900_ai_ci` 不用修改，适配中文业务；
3. 大小0代表现在是空库，还没创建任何数据表。
