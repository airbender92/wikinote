### 完整排查+修正方案
#### 1. 优先加反引号包裹字段名（解决`Invalid column reference`核心方案）
```sql
DELETE FROM testdb.student WHERE `name` = '张三';
```
MySQL中`name`属于内置类关键字，不加反引号会识别异常，用`` ` ``把字段包起来即可。

#### 2. 确认符号全为英文半角
- 引号 `' '`、等号 `=`、分号 `;` 不能是中文输入法打出的符号
- 语句中间不能藏中文空格，建议手动重输一遍

#### 3. 分步验证（定位问题根源）
先执行查询，检查表和字段是否正常：
```sql
SELECT * FROM testdb.student WHERE `name` = '张三';
```
- 查询报错：表名/字段名拼写错误，核对左侧DBeaver里的表名、列名
- 查询正常、删除报错：存在**外键约束**，有其他表关联student的id，要先删关联表数据才能删学生数据

#### 4. 简化写法（提前切换数据库，减少解析错误）
```sql
USE testdb;
DELETE FROM student WHERE `name` = '张三';
```

#### 补充风险提醒
用name删除会批量删除所有叫“张三”的学生，更安全的做法是用唯一主键id删除：
```sql
DELETE FROM testdb.student WHERE id = 1;
```
