# student表列结构完整解读
## 一、表头每一列含义
| 表头 | 解释 |
| ---- | ---- |
| 列名 | 字段名称，存储数据的分项 |
| # | 字段排序序号 |
| 数据类型 | 规定该列能存什么格式数据 |
| 非空 | [v]代表必填，[]代表允许为空 |
| 自增 | [v]开启自动数字递增，仅数字主键可用 |
| 键 | PRI=主键（唯一标识一行数据） |
| 默认 | 新增数据不填该字段时自动填充的值 |
| 额外的 | 附加属性，如`auto_increment`自增 |
| 表达式 | 计算列专用，普通字段留空 |
| 注释 | 字段说明文字 |

---
## 二、4个字段逐行解析
### 1. id
- 序号：1
- 类型：`int` 整数
- 非空：√ 必填
- 自增：√ 开启自动递增
- 键：PRI 主键
- 额外：auto_increment
作用：学生唯一编号，新增学生自动生成1、2、3…，每条记录不会重复。

### 2. name
- 序号：2
- 类型：`varchar(20)` 字符串，最多存20个字符
- 非空：× 可以不填姓名
作用：存储学生姓名。

### 3. age
- 序号：3
- 类型：`int` 整数
- 非空：× 允许为空
作用：存储学生年龄数字。

### 4. gender
- 序号：4
- 类型：`varchar(10)` 字符串，最多10字符
- 非空：× 允许为空
作用：存储性别（男/女/未知）。

## 三、对应建表SQL
```sql
USE testdb;
CREATE TABLE student (
  id INT PRIMARY KEY AUTO_INCREMENT COMMENT '学生ID主键',
  name VARCHAR(20) COMMENT '学生姓名',
  age INT COMMENT '学生年龄',
  gender VARCHAR(10) COMMENT '学生性别'
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

---
## 💡优化小建议（新手常用规范）
1. `name` 建议勾选**非空**，学生姓名不能为空；
2. `gender` 可以加默认值 `未知`，避免空数据；
3. `age` 可增加检查约束，限制数值0~120，防止非法年龄。
