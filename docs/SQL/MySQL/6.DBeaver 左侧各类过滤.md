# DBeaver 左侧各类过滤分别是什么意思（大白话拆解）
先记住核心：**过滤 = 隐藏/只显示你想看的东西，减少界面杂乱**，每个过滤对应左侧导航里不同层级的内容。

## 1. 过滤连接
### 含义
最顶层，控制左侧「所有数据库连接」的显示。
你现在只有1个 `localhost:3306` 连接；如果以后加了多个（线上服务器、本地另一个库），这里可以筛选：
- 只显示名字含 `local` 的本地连接
- 隐藏不用的远程服务器连接
### 作用
快速切换只看某一台数据库服务，不干扰其他连接。

## 2. 过滤表容器
### 含义
「表容器」= 数据库（Database/Schema），就是你看到的 `testdb`、`sys`、`mysql` 这一层。
对应你刚才想过滤系统库的需求，在这里设置后：
- 自动隐藏 `information_schema`/`mysql` 等系统库
- 左侧只展示你自己建的业务库（testdb、shop、blog…）
### 对应场景
就是你之前想要的：清理左侧数据库列表，看不到系统自带库。

## 3. 过滤表
### 含义
进入某一个数据库（比如点开 testdb）后，里面所有**数据表**的筛选。
举例子：
- 表很多：`user_info`、`order`、`log_2025`、`log_2026`
- 过滤输入 `log` → 只显示日志表；输入 `user` 只显示用户相关表
- 也可以隐藏临时表、备份表，界面清爽
### 作用
库里面表成百上千时，快速找到目标表。

## 4. 过滤存储过程
### 前置知识
存储过程：写好的一段可重复执行的SQL代码，存在数据库里，类似数据库自带函数。
### 过滤含义
筛选当前库下所有存储过程：
- 只显示名字带 `pay` 的支付相关存储过程
- 隐藏废弃不用的旧存储过程

## 5. 过滤文件
### 含义
这里的文件指 DBeaver 侧边栏「项目」里的本地脚本文件（`.sql` 脚本），不是数据库里的数据。
比如你本地存了一堆SQL脚本：
`新建脚本.sql`、`shop初始化.sql`、`备份脚本.sql`
过滤输入 `shop`，就只显示商城相关脚本，其他隐藏。

# 层级从上到下完整对应关系（方便记忆）
1. 过滤连接 → 筛选**整台数据库服务**（localhost、远程服务器）
2. 过滤表容器 → 筛选**单个数据库**（testdb、sys）
3. 过滤表 → 筛选库里的**数据表**
4. 过滤存储过程 → 筛选库里的**存储过程代码**
5. 过滤文件 → 筛选你电脑本地保存的 **SQL脚本文件**

# 简单使用建议
你现在开发只用本地 testdb，只用两个过滤就够：
1. 过滤表容器：排除4个系统库，左侧只留自己的库
2. 过滤表：表多的时候快速检索目标表
