## 💡解答
### 一、先分两类理解这些数据库
你看到的列表分为**MySQL系统自带库**和**你新建的业务库**：
1. **系统内置数据库（前4个，MySQL安装就自带，用来维持数据库自身运行）**
- `information_schema`：信息统计库，只读的虚拟库，存着所有数据库、表、权限的元数据信息，我们查库结构、表详情时数据都从这里取。
- `mysql`：权限核心库，存放账号（比如root）、密码、访问权限、角色配置这些安全相关的数据。
- `performance_schema`：性能监控库，记录数据库运行的性能指标、等待事件、资源消耗，用来排查慢查询、优化性能。
- `sys`：简化监控视图库，基于`performance_schema`封装了更易懂的视图，方便DBA快速看数据库运行状态。

2. **你自己创建的业务库（最后一个`testdb`）**
就是你之前执行`create database testdb;`新建的、用来存放自己项目业务数据的数据库。

### 二、为什么会一次性全部展示？
`show databases;`这条SQL的作用是**列出当前MySQL实例里所有存在的数据库**，不管是系统自带的、还是你手动新建的，都会全部查询出来。
MySQL必须保留这4个系统库才能正常工作，所以只要你的MySQL服务正常运行，它们就会一直存在、被查询展示出来。

### 三、日常使用小提示
平时做开发只需要操作自己新建的`testdb`这类业务库就行，系统内置库一般不用修改、不用往里存业务数据，避免破坏数据库的正常运行。
