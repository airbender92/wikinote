# student 表下所有文件夹通俗详解
这是一张名为 `student` 的数据表内部所有组成模块，按开发使用频率从高到低讲解：
## 1. 列（最核心）
对应表里面的每一个字段，比如学生表会有 `id`、`姓名`、`年龄`、`班级` 等。
每条学生数据都由这些列组成，是存储真实数据的载体。

## 2. 约束
限制字段填写规则，保证数据合法：
- 主键约束：唯一标识一条学生记录（如学生id）
- 非空约束：姓名不能为空
- 唯一约束：学号不能重复
- 默认值约束：默认年龄18

## 3. 外键
用来多张表关联，比如 `student` 表的 `class_id` 关联班级表 `class` 的主键，保证班级编号真实存在，避免填不存在的班级。

## 4. 引用
反向查看：**哪些其他表通过外键关联了当前student表**。
比如成绩表score里存了学生id，点开引用就能看到score表。

## 5. 触发器
给这张表设置自动执行逻辑，例如：删除学生时自动删除他的成绩记录。

## 6. 索引
给列建立查询加速目录，比如经常按学号查学生，给学号列建索引，百万条数据查询速度大幅提升。

## 7. 分区
大数据场景专用，一张表数据量几百万、上千万时，按年份/班级拆分存储，新手学习阶段基本不会用到。
