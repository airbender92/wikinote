# 两种操作方式：可视化界面修改（DBeaver）+ SQL语句修改
## 方式一：DBeaver图形界面操作（新手推荐，不用写代码）
### 1. 给 name 勾选「非空」
1. 左侧展开 `student` → 双击「列」，打开你截图里的字段表格
2. 找到 `name` 这一行，双击「非空」单元格，打上 √（勾选）
3. 界面底部点**保存**按钮（软盘图标），应用修改

### 2. 给 gender 设置默认值「未知」
1. 同一列表格找到 `gender` 行
2. 双击「默认」这一列的输入框，输入：`'未知'`
3. 底部保存生效

### 3. age 添加检查约束（限制0~120）
1. 左侧找到 `student` 下的「约束」文件夹，右键 → 新建 → 检查约束
2. 约束名称填：`chk_age_range`
3. 条件表达式填写：`age BETWEEN 0 AND 120`
4. 确定后保存表结构

---
## 方式二：直接执行SQL语句（快速一键修改）
打开SQL编辑器，执行下面整套语句，一次性完成全部优化：
```sql
USE testdb;

-- 1. 修改name字段为非空
ALTER TABLE student MODIFY COLUMN name VARCHAR(20) NOT NULL COMMENT '学生姓名';

-- 2. 给gender设置默认值 未知
ALTER TABLE student MODIFY COLUMN gender VARCHAR(10) DEFAULT '未知' COMMENT '学生性别';

-- 3. 添加年龄检查约束，限制0~120
ALTER TABLE student ADD CONSTRAINT chk_age_range CHECK (age BETWEEN 0 AND 120);
```

### 执行后效果说明
1. 新增学生时**必须填写name**，不填会直接报错；
2. 不填写gender时，数据库自动填充文字「未知」；
3. 如果填写age小于0或大于120，插入/修改数据会被拦截，无法保存。

## 补充：如果想直接重建一张符合规范的完整表
```sql
USE testdb;
DROP TABLE IF EXISTS student;
CREATE TABLE student (
  id INT PRIMARY KEY AUTO_INCREMENT COMMENT '学生唯一ID',
  name VARCHAR(20) NOT NULL COMMENT '学生姓名',
  age INT COMMENT '学生年龄',
  gender VARCHAR(10) DEFAULT '未知' COMMENT '学生性别',
  CONSTRAINT chk_age_range CHECK (age BETWEEN 0 AND 120)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```
适合刚建表、表里还没有数据的场景，一步到位符合规范。
