# 报错 ERROR 1045 (28000): Access denied for user 'ODBC'@'localhost' (using password: NO)

## 原因

你直接敲 `mysql`，没指定用户名，MySQL 默认拿 Windows 当前系统用户名 `ODBC` 去登录，**不是root账号，又没带密码，直接拒绝访问**。

---

## ✅正确登录命令（PowerShell）

```powershell
mysql -uroot -p
```

- `-uroot`：指定用户是 root
- `-p`：回车之后，再输入你的root密码（输入的时候屏幕不显示字符，正常现象）

> ❌不要直接写 `mysql`，会自动拿系统当前Windows用户去登录，就出现这个ODBC报错。

### 示例完整操作

```powershell
PS C:\Users\yambo> mysql -uroot -p
Enter password: 【这里输入你安装MySQL设置的root密码，看不见，输完回车】
```

## 如果忘记root密码（Windows MySQL8.4）

1. 停止MySQL服务

```powershell
net stop MySQL84
```

> 把MySQL84换成你的真实服务名

2. 跳过权限验证启动，重置密码，需要的话我给你完整步骤。

## 补充区分

- `mysql` 不带参数 → 使用Windows登录用户(ODBC)，**几乎都会报错1045**
- `mysql -uroot -p` → 使用数据库root账号，这才是我们安装设置的管理员账号

你先执行 `mysql -uroot -p`，输入安装时候设置的密码试试。
如果密码忘了，告诉我，我给你Windows下重置root密码全套命令。
