下面给你一份 **Windows 系统 MySQL 8.0 超详细安装教程**，一步一步照着做就能装好。

# 一、下载 MySQL
1. 打开官网：
   https://dev.mysql.com/downloads/mysql/
2. 选择：
   - Operating System：**Microsoft Windows**
   - 下载 **MySQL Installer for Windows**（带 MSI 那个）
3. 不用登录，点 **No thanks, just start my download**

# 二、安装步骤
1. 双击安装包，一路下一步
2. 选择安装类型：**Developer Default**（默认开发版）
3. 检查需求页面：点 **Execute** 安装缺失依赖
4. 下一步 → 下一步 → 安装
5. 安装完成后进入 **配置向导**

# 三、关键配置（非常重要）
1. **Type and Networking**
   - 默认即可，端口 **3306**
2. **Authentication Method**
   选：**Use Legacy Authentication Method**
   （方便 Navicat、DBeaver 等工具连接）
3. **设置 root 密码**
   自己记好，比如：`123456`
4. 下一步到底，完成配置

# 四、测试是否安装成功
1. 打开 **MySQL 8.0 Command Line Client**
2. 输入你设置的 root 密码
3. 出现 `mysql>` 说明成功

常用命令：
```sql
show databases;
```
能列出数据库就没问题。

# 五、配置环境变量（可选，推荐）
1. 找到安装路径，默认：
   ```
   C:\Program Files\MySQL\MySQL Server 8.0\bin
   ```
2. 把这个路径加到系统 **Path** 里
3. 新开 cmd，输入：
   ```bash
   mysql -uroot -p
   ```
能直接进入就是配置成功。
