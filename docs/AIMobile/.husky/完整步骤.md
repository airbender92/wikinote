# 问题原因
你现在装的是 **husky v9+**
`husky install`、`husky add` 已经彻底废弃，**不要再用**。
新版唯一初始化命令：`npx husky init`

# Husky v9 完整可用流程（PowerShell / Git Bash 通用）
## 1. 安装依赖
```bash
# npm
npm install husky lint-staged @commitlint/cli @commitlint/config-conventional -D

# pnpm（推荐）
pnpm add husky lint-staged @commitlint/cli @commitlint/config-conventional -D
```

## 2. 初始化 husky（唯一正确命令）
```bash
npx husky init
```
执行后自动完成两件事：
1. 创建 `.husky/` 文件夹
2. 在 `package.json` 自动添加脚本：
```json
"scripts": {
  "prepare": "husky"
}
```
> ⚠️ 旧写法 `"prepare": "husky install"` 会报 deprecation，必须改成 `"husky"`

## 3. 配置钩子（不再有 husky add，直接写入文件）
### ① pre-commit（提交前执行 lint-staged）
初始化生成了 `.husky/pre-commit`，打开文件，替换内容：
```sh
npx lint-staged
```

### ② 创建 commit-msg（校验commit规范）
PowerShell 执行：
```powershell
echo "npx --no -- commitlint --edit `$1" > .husky/commit-msg
```
> Git Bash 使用：
```bash
echo "npx --no -- commitlint --edit \$1" > .husky/commit-msg
```

# 完整项目 Demo 片段
## 1. package.json
```json
{
  "name": "markdownProject",
  "scripts": {
    "prepare": "husky",
    "lint": "eslint .",
    "format": "prettier --write ."
  },
  "devDependencies": {
    "@commitlint/cli": "^19.5.0",
    "@commitlint/config-conventional": "^19.5.0",
    "eslint": "^8.57.0",
    "husky": "^9.1.6",
    "lint-staged": "^15.2.10",
    "prettier": "^3.3.3"
  },
  "lint-staged": {
    "*.{js,ts,jsx,tsx}": [
      "eslint --fix",
      "prettier --write"
    ],
    "*.{json,md}": [
      "prettier --write"
    ]
  }
}
```

## 2. 根目录新建 commitlint.config.js
```js
module.exports = {
  extends: ['@commitlint/config-conventional']
}
```

## 3. .husky/pre-commit 文件内容
```sh
npx lint-staged
```

## 4. .husky/commit-msg 文件内容
```sh
npx --no -- commitlint --edit $1
```

# 重要注意事项
1. **提交代码时需要把 `.husky` 目录纳入 git 版本控制**
```bash
git add .husky
```
2. 紧急跳过校验（慎用）
```bash
git commit --no-verify -m "xxx"
```
3. Windows PowerShell 创建钩子文件时 `$1` 需要反引号转义 `` `$1 ``
4. 不要混用旧文档的 `husky install` / `husky add`
