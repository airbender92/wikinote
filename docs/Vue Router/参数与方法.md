接下来我们深入 **路由参数与方法**，系统学习 `params` 和 `query` 的传递与接收、两种路由实例的使用方式，以及 `history` 与 `hash` 模式的区别。

---

## 1. 路由参数：`params` 与 `query`

### 1.1 基本区别

| 特性         | `params` (路径参数)                     | `query` (查询字符串)             |
| ------------ | --------------------------------------- | -------------------------------- |
| **位置**     | URL 路径的一部分，如 `/user/123`        | URL 问号后面，如 `/user?id=123`  |
| **定义方式** | 路由配置中声明 `path: '/user/:id'`      | 无需预定义，任意键值对           |
| **是否必需** | 通常必需（除非用 `?` 设为可选）         | 可选，不出现也可                 |
| **数据特点** | 一般都是必需标识（如 ID）               | 一般是筛选、分页等辅助信息       |
| **刷新保留** | 保留                                 | 保留                           |
| **路由匹配** | 不同参数值表示不同路由（可复用组件）    | 相同路径，不同查询参数视为同一页面 |

### 1.2 传递参数

#### 声明式（`<RouterLink>`）
```html
<!-- params：需要配合命名路由 -->
<RouterLink :to="{ name: 'user', params: { id: 123 } }">用户123</RouterLink>

<!-- query：可以与 path 或 name 配合 -->
<RouterLink :to="{ path: '/user', query: { id: 123, page: 1 } }">用户查询</RouterLink>
<RouterLink :to="{ name: 'user', query: { tab: 'profile' } }">用户资料</RouterLink>
```

#### 编程式（`router.push`）
```javascript
// params 必须配合 name，不能与 path 同时使用
router.push({ name: 'user', params: { id: 123 } })

// query 可以和 path 或 name 一起使用
router.push({ path: '/user', query: { id: 123, page: 1 } })
router.push({ name: 'user', query: { tab: 'profile' } })

// 直接字符串写法（只能带 query）
router.push('/user?id=123')
```

### 1.3 接收参数

#### 在模板中（选项式 API）
```vue
<template>
  <div>
    <p>路径参数 id: {{ $route.params.id }}</p>
    <p>查询参数 page: {{ $route.query.page }}</p>
  </div>
</template>
```

#### 在组合式 API 中（`<script setup>`）
```vue
<script setup>
import { useRoute } from 'vue-router'

const route = useRoute()
console.log(route.params.id)   // 路径参数
console.log(route.query.page)  // 查询参数
</script>
```

#### 高级：将 `params` 作为组件 props
```javascript
// 路由配置中开启 props: true
{ path: '/user/:id', name: 'user', component: UserView, props: true }
```
```vue
<!-- UserView.vue 直接通过 props 接收 -->
<script setup>
const props = defineProps(['id'])   // id 自动从 params.id 注入
</script>
```

> **注意**：由于组件可能复用，当 `params` 变化（如从 `/user/1` 到 `/user/2`）时，需要 `watch` 响应变化或使用 `onBeforeRouteUpdate` 导航守卫。

## 2. `$router` 与 `$route` 及组合式 API

### 2.1 两个核心对象

| 对象       | 含义                                   | 常用属性/方法                                   |
| ---------- | -------------------------------------- | ----------------------------------------------- |
| `$router`  | **路由实例**（整个应用只有一个）        | `push()`, `replace()`, `go()`, `back()`, `currentRoute` |
| `$route`   | **当前路由信息**（响应式，随路由变化）   | `params`, `query`, `path`, `name`, `fullPath`, `meta` |

在**选项式 API** 中，可直接通过 `this.$router` 和 `this.$route` 访问。  
在**模板**中可直接使用 `$router` 和 `$route`。

### 2.2 组合式 API：`useRouter()` 和 `useRoute()`

```vue
<script setup>
import { useRouter, useRoute } from 'vue-router'

const router = useRouter()   // 相当于 $router
const route = useRoute()     // 相当于 $route

// 跳转
const goToAbout = () => {
  router.push('/about')
}

// 读取参数
console.log(route.params.id)
</script>
```

> `useRoute()` 返回的对象是响应式的，可以在 `watch` 中监听其变化。

### 2.3 常用方法示例

```javascript
// 字符串路径
router.push('/users')

// 命名路由 + params
router.push({ name: 'user', params: { id: 1 } })

// 带查询参数
router.push({ path: '/login', query: { redirect: '/dashboard' } })

// 替换当前记录（不产生历史记录）
router.replace('/home')

// 前进/后退
router.go(1)    // 前进一步
router.back()   // 后退一步
router.go(-2)   // 后退两步

// 获取当前完整路径
console.log(route.fullPath)   // 包含 query 和 hash
console.log(route.path)       // 不带 query 和 hash
```

## 3. History 模式 vs Hash 模式

### 3.1 基本原理

| 模式                | 实现原理                          | URL 示例                      |
| ------------------- | --------------------------------- | ----------------------------- |
| **hash 模式**       | 监听 `window.location.hash` 变化  | `http://example.com/#/user/1` |
| **history 模式**    | 利用 HTML5 History API (`pushState`, `replaceState`) | `http://example.com/user/1`   |

### 3.2 区别对比

| 特性         | hash 模式                     | history 模式                    |
| ------------ | ----------------------------- | ------------------------------- |
| **外观**     | 带有 `#` 符号，不太美观        | 正常路径，美观，像传统网站       |
| **服务器配置** | **不需要**特殊配置，所有请求都返回 `index.html` 即可 | **需要**配置 fallback（所有路由都指向 `index.html`） |
| **刷新行为** | `#` 后面部分不会被发送给服务器，刷新不会 404 | 直接刷新会向服务器请求当前路径，如无配置会 404 |
| **SEO 友好** | 较差（搜索引擎对 `#` 支持不好） | 友好，适合需要 SEO 的公开项目     |
| **兼容性**   | 支持所有浏览器（包括 IE）       | IE10+，现代浏览器都可            |
| **占用资源** | 无需服务端配合                  | 需要服务端 fallback 支持         |

### 3.3 配置方式

```javascript
import { createRouter, createWebHistory, createWebHashHistory } from 'vue-router'

// history 模式（推荐用于现代 Web 项目）
const router = createRouter({
  history: createWebHistory(),   // 默认基路径为 '/'
  routes
})

// 如果部署在非根目录，例如 https://example.com/app/
// 可传入 base 参数
const router = createRouter({
  history: createWebHistory('/app/'),
  routes
})

// hash 模式
const router = createRouter({
  history: createWebHashHistory(),
  routes
})
```

### 3.4 服务器配置示例（history 模式必需）

以 Nginx 为例：
```nginx
location / {
  try_files $uri $uri/ /index.html;
}
```

Node.js (Express)：
```javascript
const express = require('express')
const path = require('path')
const app = express()
app.use(express.static(path.join(__dirname, 'dist')))
app.get('*', (req, res) => {
  res.sendFile(path.join(__dirname, 'dist', 'index.html'))
})
```

如果不做配置，用户直接访问 `https://example.com/user/1` 刷新会返回 404。

### 3.5 如何选择？

- **hash 模式**：简单项目、内部系统、无需 SEO、不想折腾服务器配置时使用。
- **history 模式**：生产级应用、需要 SEO、追求更干净的 URL，并且可以配置服务器时强烈推荐。

## 4. 综合示例：一个带有参数获取和切换模式的组件

```vue
<template>
  <div>
    <h2>用户信息</h2>
    <p>ID (params): {{ userId }}</p>
    <p>标签 (query): {{ tab }}</p>
    <button @click="updateParams">切换到用户2</button>
    <button @click="addQuery">添加查询参数</button>
  </div>
</template>

<script setup>
import { useRoute, useRouter } from 'vue-router'
import { computed } from 'vue'

const route = useRoute()
const router = useRouter()

// 响应式获取参数
const userId = computed(() => route.params.id)
const tab = computed(() => route.query.tab || '无')

const updateParams = () => {
  // 保持当前查询参数，只改变路径参数
  router.push({
    name: 'user',
    params: { id: 2 },
    query: route.query
  })
}

const addQuery = () => {
  router.push({
    name: 'user',
    params: { id: route.params.id },
    query: { tab: 'profile', page: 1 }
  })
}
</script>
```

## 总结

- **`params` 用于路径中的动态段**，配合 `name` 使用；**`query` 用于可选参数**，配合 `path` 或 `name` 使用。
- 组合式 API 推荐 `useRouter()` 和 `useRoute()`，选项式 API 使用 `this.$router` / `this.$route`。
- **history 模式** URL 干净但需服务器配置；**hash 模式** 简单无配置但有 `#`，适合轻量级应用。
