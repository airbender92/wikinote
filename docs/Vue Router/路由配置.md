我们继续深入 **Vue Router 路由配置与基本操作**。以下内容基于 Vue 3 + Vue Router 4，涵盖从安装到各种实用特性的配置与实践。

---

## 1. 安装与基本配置

### 安装
```bash
npm install vue-router@4
```

### 基本配置 (`router/index.js`)
```javascript
import { createRouter, createWebHistory } from 'vue-router'
import HomeView from '../views/HomeView.vue'

const routes = [
  {
    path: '/',
    name: 'home',
    component: HomeView
  },
  {
    path: '/about',
    name: 'about',
    // 路由懒加载：只有访问时才加载对应组件
    component: () => import('../views/AboutView.vue')
  }
]

const router = createRouter({
  history: createWebHistory(),   // HTML5 模式，需要服务器配置支持
  routes                         // 简写
})

export default router
```

### 在 Vue 应用中注册 (`main.js`)
```javascript
import { createApp } from 'vue'
import App from './App.vue'
import router from './router'

createApp(App).use(router).mount('#app')
```

模板中使用 `<RouterView>` 作为页面出口。

## 2. 动态路由（多路径复用）

当多个路径需要对应同一个组件时，使用 **动态片段**（参数）。

```javascript
const routes = [
  // 动态段以冒号 : 开头
  { path: '/user/:id', component: UserView },
  // 可以包含多个参数
  { path: '/post/:postId/comment/:commentId', component: CommentView }
]
```

在组件中访问参数：
```vue
<script setup>
import { useRoute } from 'vue-router'
const route = useRoute()
console.log(route.params.id)   // 对应 :id
</script>
```

> 注意：同一组件实例会被复用，因此对参数变化需要 `watch` 响应。

---

## 3. 可选参数与全匹配语法

### 可选参数
使用 `?` 表示参数可选。
```javascript
{ path: '/user/:id?', component: UserView }
// 匹配 /user 和 /user/123
```

### 全匹配（捕获所有未匹配路径）
使用自定义正则 `(.*)` 或 Vue Router 4 推荐的语法：
```javascript
{ path: '/:pathMatch(.*)*', name: 'NotFound', component: NotFoundView }
// 匹配任意路径，如 /not/found/anything
```

`pathMatch` 参数会包含匹配到的完整路径，可用于重定向或展示 404 信息。

## 4. 嵌套路由（实现层级化 UI）

嵌套路由让页面内部可以有自己的子导航和出口，实现复杂布局。

```javascript
const routes = [
  {
    path: '/settings',
    component: SettingsLayout,   // 外层布局组件，包含 <RouterView>
    children: [
      {
        path: '',                // 匹配 /settings 时的默认子路由
        component: ProfileView
      },
      {
        path: 'profile',         // 匹配 /settings/profile
        component: ProfileView
      },
      {
        path: 'account',         // 匹配 /settings/account
        component: AccountView
      }
    ]
  }
]
```

**父组件模板** (`SettingsLayout.vue`)：
```html
<template>
  <div>
    <h2>设置中心</h2>
    <nav>
      <RouterLink to="/settings/profile">个人资料</RouterLink>
      <RouterLink to="/settings/account">账户安全</RouterLink>
    </nav>
    <RouterView />   <!-- 子路由组件在此渲染 -->
  </div>
</template>
```

## 5. 命名路由

为路由分配唯一名称，导航时使用名称而非硬编码 URL，更易维护。

```javascript
const routes = [
  {
    path: '/user/:username',
    name: 'user-profile',
    component: UserProfile
  }
]
```

**使用方式：**
- `<RouterLink :to="{ name: 'user-profile', params: { username: 'alice' } }">`
- 编程式导航：`router.push({ name: 'user-profile', params: { username: 'alice' } })`

---

## 6. 命名视图（多视图）

有时需要同时显示多个独立视图（例如主内容区 + 侧边栏）。用 **命名视图** 可以为 `<RouterView>` 指定名称。

```javascript
const routes = [
  {
    path: '/dashboard',
    components: {            // 注意是 components (复数)
      default: DashboardMain,  // 未命名的 RouterView
      sidebar: DashboardSidebar // 名为 sidebar 的 RouterView
    }
  }
]
```

**模板：**
```html
<RouterView />                <!-- 渲染 DashboardMain -->
<RouterView name="sidebar" /> <!-- 渲染 DashboardSidebar -->
```

## 7. 编程式导航

除了 `<RouterLink>`，还可以用 JavaScript 实现跳转。在 `setup` 或组合式 API 中：

```javascript
import { useRouter } from 'vue-router'
const router = useRouter()

// 字符串路径
router.push('/about')

// 对象，可配合 name / params / query
router.push({ path: '/user', query: { id: '123' } })
router.push({ name: 'user-profile', params: { username: 'john' } })

// 替换当前历史记录（无法返回）
router.replace('/home')

// 前进/后退
router.go(1)   // 前进一步
router.back()  // 后退一步
```

> 注意：如果提供了 `path`，`params` 会被忽略，需用 `name` 配合 `params`。

## 8. 重定向（Redirect）

将某个路径自动跳转到另一个路径。

```javascript
const routes = [
  { path: '/home', redirect: '/' },           // 字符串目标
  { path: '/old-page', redirect: { name: 'new-page' } }, // 命名路由
  { path: '/search/:query', redirect: to => {  // 动态返回目标
    return { path: '/results', query: { q: to.params.query } }
  }}
]
```

---

## 9. 别名（Alias）

别名让一个路由可以通过多个 URL 访问，但不会改变浏览器地址栏（不同于重定向）。

```javascript
const routes = [
  {
    path: '/users',
    component: UsersList,
    alias: ['/people', '/members']   // /people 和 /members 显示相同内容，但 URL 保持不变
  }
]
```

常用于：
- 兼容旧 URL
- 提供更友好的路径，但不希望跳转

## 综合示例：一个典型的路由配置

```javascript
// router/index.js
import { createRouter, createWebHistory } from 'vue-router'

const router = createRouter({
  history: createWebHistory(),
  routes: [
    {
      path: '/',
      name: 'home',
      component: () => import('@/views/Home.vue')
    },
    {
      path: '/user/:id',
      name: 'user-profile',
      component: () => import('@/views/UserProfile.vue'),
      props: true   // 将路由参数作为组件的 props
    },
    {
      path: '/docs',
      component: () => import('@/layouts/DocsLayout.vue'),
      children: [
        { path: '', redirect: 'getting-started' },
        { path: 'getting-started', component: () => import('@/views/GettingStarted.vue') },
        { path: 'api/:version?', component: () => import('@/views/ApiDoc.vue') }
      ]
    },
    {
      path: '/dashboard',
      components: {
        default: () => import('@/views/DashboardMain.vue'),
        sidebar: () => import('@/views/DashboardSidebar.vue')
      }
    },
    {
      path: '/old-home',
      redirect: { name: 'home' }
    },
    {
      path: '/members',
      alias: '/team',
      component: () => import('@/views/Team.vue')
    },
    {
      path: '/:pathMatch(.*)*',
      name: 'not-found',
      component: () => import('@/views/NotFound.vue')
    }
  ]
})
```

## 总结表

| 特性               | 语法示例                                        | 主要用途                   |
| ------------------ | ----------------------------------------------- | -------------------------- |
| 动态路由           | `path: '/user/:id'`                             | 复用组件，参数化路径       |
| 可选参数           | `/user/:id?`                                    | 参数可有可无               |
| 全匹配（404）      | `/:pathMatch(.*)*`                              | 捕获未定义路径             |
| 嵌套路由           | `children: [ ... ]`                             | 实现页面内嵌套导航         |
| 命名路由           | `name: 'profile'`                               | 避免硬编码 URL             |
| 命名视图           | `components: { default, sidebar }`              | 一个路由同时渲染多个视图   |
| 编程式导航         | `router.push({ name: 'profile', params: {} })`  | JS 控制跳转                |
| 重定向             | `redirect: '/'`                                 | 自动跳转到另一路径         |
| 别名               | `alias: ['/people']`                            | 多个 URL 访问同一页面      |
