## 性能优化核心：路由懒加载

**懒加载**（Lazy Loading）是指将路由组件分割成独立的代码块（chunk），仅在用户访问该路由时才异步加载对应的组件代码。通过 `import()` 动态导入语法，Vue Router 能够自动启用 Webpack / Vite 的代码分割功能，**显著减少首屏加载的 JavaScript 体积**，提升页面加载速度。

### 1. 懒加载的基本用法

不使用懒加载（全部打包到一个文件）：
```javascript
// ❌ 所有组件都在首屏加载
import HomeView from '@/views/HomeView.vue'
import AboutView from '@/views/AboutView.vue'
import UserView from '@/views/UserView.vue'

const routes = [
  { path: '/', component: HomeView },
  { path: '/about', component: AboutView },
  { path: '/user', component: UserView }
]
```

使用懒加载（推荐）：
```javascript
// ✅ 每个路由组件独立打包，按需加载
const routes = [
  { path: '/', component: () => import('@/views/HomeView.vue') },
  { path: '/about', component: () => import('@/views/AboutView.vue') },
  { path: '/user', component: () => import('@/views/UserView.vue') }
]
```

### 2. 为什么建议为所有路由启用懒加载？

| 对比项           | 不使用懒加载               | 使用懒加载                               |
| ---------------- | -------------------------- | ---------------------------------------- |
| **首屏请求体积** | 所有路由组件代码一次性下载 | 仅下载当前页面所需组件                   |
| **首屏加载时间** | 较慢（尤其路由数量多时）   | 显著加快                                 |
| **缓存利用**     | 整个 bundle 变动即失效     | 各 chunk 独立缓存，未变化路由可复用      |
| **用户体验**     | 白屏时间长                 | 页面切换可能有短暂加载，但首屏体验更好   |

**建议**：即使是小型项目，懒加载也几乎零成本，却能带来可感知的性能提升。对于中大型应用，懒加载是**强制最佳实践**。

### 3. Webpack / Vite 自动代码分割原理

- `import()` 返回 Promise，底层调用 JSONP 或现代浏览器的动态加载能力。
- 每个 `import()` 调用会被构建工具（Webpack、Vite）识别为**分割点**，生成独立的 chunk 文件（如 `HomeView.[hash].js`）。
- 用户首次访问 `/about` 时，浏览器只会请求 `AboutView.[hash].js`，不会加载其他未访问页面的代码。
- 配合 HTTP/2 多路复用，多个小 chunk 并发加载，性能更优。

### 4. 高级优化技巧

#### 将组件按组分块（命名 chunk）
使用 Webpack 的魔法注释 `/* webpackChunkName: "group-name" */` 将多个路由打包到同一个 chunk，减少 HTTP 请求（但可能增加初始未访问代码的体积，需权衡）。

```javascript
const routes = [
  {
    path: '/user',
    component: () => import(/* webpackChunkName: "user-group" */ '@/views/UserView.vue')
  },
  {
    path: '/profile',
    component: () => import(/* webpackChunkName: "user-group" */ '@/views/ProfileView.vue')
  }
]
```

Vite 中使用 `/* viteChunkName: "user-group" */` 或配置 `build.rollupOptions.output.manualChunks`。

#### 预加载与预获取（Prefetch / Preload）
为关键路由添加预加载，提升后续导航速度。

- **预加载（Preload）**：用于当前页面即将用到的资源（如入口路由）。
- **预获取（Prefetch）**：用于空闲时加载非关键路由。

在 Vite 中，可使用 `vite-plugin-prefetch` 或手动添加 `<link rel="prefetch">`。Vue CLI 生成的 Webpack 配置默认支持路由懒加载 + 预获取（通过 `webpackPrefetch: true` 注释）。

```javascript
component: () => import(/* webpackPrefetch: true */ '@/views/Dashboard.vue')
```

#### 将共享依赖提取为单独 chunk
构建工具会自动将 `node_modules` 中的大库提取为 `vendors` chunk，避免重复打包。也可以通过 `splitChunks` 优化。

#### 与 `<Suspense>` 结合（Vue 3）
配合 Vue 3 的 `<Suspense>` 组件，可以在异步组件加载时显示回退内容，提升交互体验。

```vue
<template>
  <Suspense>
    <template #default>
      <router-view />
    </template>
    <template #fallback>
      <div>加载中...</div>
    </template>
  </Suspense>
</template>
```

### 5. 注意事项与最佳实践

- **避免过度拆分**：极小页面（如404）可以保留懒加载，但几十个路由都独立 chunk 可能导致过多 HTTP 请求。可适当分组。
- **处理加载状态**：在路由守卫或组件内可以添加全局 Loading 指示器，因为懒加载有网络延迟。
- **错误处理**：懒加载可能失败（网络断开），可以捕获异常并重试或提示用户。
- **命名组件 + 懒加载**：命名路由组件依然可以静态 `import` 或动态加载，动态加载不影响路由功能。
- **测试环境**：开发时懒加载可能增加热更新延迟，但生产环境收益巨大。

### 6. 完整配置示例

```javascript
// router/index.js
import { createRouter, createWebHistory } from 'vue-router'

const router = createRouter({
  history: createWebHistory(),
  routes: [
    {
      path: '/',
      name: 'home',
      component: () => import(/* webpackChunkName: "home" */ '../views/HomeView.vue')
    },
    {
      path: '/about',
      name: 'about',
      // 路由懒加载 + 预获取（空闲时加载）
      component: () => import(/* webpackChunkName: "about", webpackPrefetch: true */ '../views/AboutView.vue')
    },
    {
      path: '/dashboard',
      name: 'dashboard',
      component: () => import(/* webpackChunkName: "dashboard" */ '../views/Dashboard.vue'),
      meta: { requiresAuth: true }
    },
    {
      path: '/:pathMatch(.*)*',
      name: 'not-found',
      component: () => import('../views/NotFound.vue')
    }
  ]
})

export default router
```

### 总结

- **所有路由都应该启用懒加载**，这是优化首屏加载时间最直接、最有效的手段之一。
- 使用 `() => import('@/views/...')` 语法，构建工具自动完成代码分割。
- 可配合 `webpackChunkName` 命名 chunk、`webpackPrefetch` 预获取，进一步提升性能。
- 大型应用建议结合 `<Suspense>` 和全局加载指示器，提升用户体验。

懒加载不是可选项，而是现代 Vue 单页应用生产环境的标准配置。
