## 导航守卫：三层级权限控制

Vue Router 的导航守卫用于**在路由跳转前后插入自定义逻辑**，例如：验证登录状态、检查权限、显示加载动画、记录页面访问等。守卫分为三个层级：**全局**、**路由独享**和**组件内**。

> ⚠️ **最关键的注意事项**：在 `beforeEach` 等前置守卫中，**必须调用 `next()` 函数**，否则导航会永远挂起，页面无响应！

---

### 1. 全局守卫

全局守卫作用于**所有路由**，在路由跳转的各个阶段触发。

| 守卫                | 触发时机                                       | 典型用途                         |
| ------------------- | ---------------------------------------------- | -------------------------------- |
| `beforeEach`        | 导航**触发时**，在所有守卫之前执行             | 全局登录校验、页面标题设置       |
| `beforeResolve`     | 导航**确认前**，所有组件内守卫和异步组件解析后 | 确保数据已准备完毕               |
| `afterEach`         | 导航**确认后**（无法改变导航）                 | 埋点统计、关闭加载动画、滚动处理 |

#### 使用示例

```javascript
// router/index.js
import router from './router'

// 1. beforeEach：必须调用 next()
router.beforeEach((to, from, next) => {
  // to: 目标路由对象
  // from: 来源路由对象
  const isLoggedIn = localStorage.getItem('token')
  
  if (to.meta.requiresAuth && !isLoggedIn) {
    // 跳转到登录页，并携带原目标路径
    next({ name: 'login', query: { redirect: to.fullPath } })
  } else {
    next() // ✅ 必须调用！
  }
})

// 2. beforeResolve：类似 beforeEach，但发生在所有异步组件解析后
router.beforeResolve(async (to, from, next) => {
  // 适合做最后的数据预加载检查
  next()
})

// 3. afterEach：无 next 参数
router.afterEach((to, from) => {
  // 修改页面标题
  document.title = to.meta.title || '默认标题'
  // 埋点上报
  analytics.sendPageView(to.fullPath)
})
```

**⚠️ 强烈警告**：忘记调用 `next()` 会导致导航永久挂起，页面看起来“点不动”。三种合法调用：
- `next()`：继续导航。
- `next(false)`：中断导航，回退到 `from` 路由。
- `next({ name: 'login' })`：跳转到新路由（可传 `path`、`params` 等）。

### 2. 路由独享守卫：`beforeEnter`

在单个路由配置中定义，只在进入该特定路由时触发，适合**权限拆分**。

```javascript
const routes = [
  {
    path: '/admin',
    component: AdminPanel,
    meta: { requiresAdmin: true },
    beforeEnter: (to, from, next) => {
      const userRole = store.state.user.role
      if (userRole === 'admin') {
        next()
      } else {
        next({ name: 'forbidden' })
      }
    }
  },
  {
    path: '/user/:id',
    component: UserProfile,
    beforeEnter: [checkAuth, checkUserId] // 可以传数组，按顺序执行
  }
]

function checkAuth(to, from, next) {
  // 复用逻辑
  next()
}
```

> `beforeEnter` 仅在直接进入该路由时触发，不会在 `params` 变化时再次触发（例如从 `/user/1` 到 `/user/2`）。如需监听参数变化，应使用组件内守卫或 `watch`。

---

### 3. 组件内守卫

定义在 Vue 组件内部，直接作用于当前组件。

| 守卫                    | 调用时机                                                                 |
| ----------------------- | ------------------------------------------------------------------------ |
| `beforeRouteEnter`      | 组件**还未创建**，无法访问 `this`                                        |
| `beforeRouteUpdate`     | 组件**已创建**，且路由参数变化（例如 `/user/1` → `/user/2`）时调用       |
| `beforeRouteLeave`      | 即将**离开**当前组件时调用，可用于阻止未保存的编辑                       |

#### 选项式 API 示例

```javascript
export default {
  data() {
    return { formData: {}, saved: false }
  },
  beforeRouteEnter(to, from, next) {
    // ❌ 不能使用 this，因为组件实例未创建
    // ✅ 可以通过 next 回调访问组件实例
    next(vm => {
      vm.fetchData(to.params.id)
    })
  },
  beforeRouteUpdate(to, from, next) {
    // ✅ 可以访问 this
    this.fetchData(to.params.id)
    next()
  },
  beforeRouteLeave(to, from, next) {
    if (!this.saved && this.formDataHasChanges) {
      const answer = window.confirm('有未保存的更改，确定离开吗？')
      answer ? next() : next(false)
    } else {
      next()
    }
  },
  methods: {
    fetchData(id) { /* ... */ }
  }
}
```

#### 组合式 API 示例（Vue 3）

组合式 API 中推荐使用 `onBeforeRouteUpdate` 和 `onBeforeRouteLeave`。

```vue
<script setup>
import { onBeforeRouteUpdate, onBeforeRouteLeave } from 'vue-router'
import { ref } from 'vue'

const saved = ref(false)

// 相当于 beforeRouteUpdate
onBeforeRouteUpdate(async (to, from, next) => {
  // 响应参数变化
  await fetchData(to.params.id)
  next()
})

// 相当于 beforeRouteLeave
onBeforeRouteLeave((to, from, next) => {
  if (!saved.value && hasUnsavedChanges()) {
    const confirm = window.confirm('确定离开？')
    confirm ? next() : next(false)
  } else {
    next()
  }
})
</script>
```

> 注意：组合式 API 中**没有** `beforeRouteEnter` 的等价写法，因为 `<script setup>` 在组件创建后立即执行。如需使用，可配合 `defineComponent` 和选项式 API。

---

### 4. 守卫执行顺序（完整流程）

1. **导航触发**（点击 `<RouterLink>` 或调用 `router.push`）
2. **组件内 `beforeRouteLeave`**（离开旧组件）
3. **全局 `beforeEach`**
4. **路由独享 `beforeEnter`**（如果有）
5. **组件内 `beforeRouteUpdate`**（如果复用组件且参数变化）或 **`beforeRouteEnter`**（如果是新组件）
6. **全局 `beforeResolve`**
7. **导航确认**
8. **全局 `afterEach`**
9. **触发 DOM 更新**（渲染新组件）
10. 调用 `beforeRouteEnter` 中的 `next` 回调（访问组件实例）

### 5. 实际应用：权限控制组合示例

```javascript
// router/index.js
import router from './router'
import store from './store'

// 全局前置守卫：统一拦截未登录访问
router.beforeEach((to, from, next) => {
  const token = localStorage.getItem('token')
  const needAuth = to.matched.some(record => record.meta.requiresAuth)
  
  if (needAuth && !token) {
    next({ name: 'login', query: { redirect: to.fullPath } })
    return
  }
  
  // 动态权限校验（后端返回角色）
  if (to.meta.roles) {
    const userRole = store.state.user.role
    if (!to.meta.roles.includes(userRole)) {
      next({ name: 'forbidden' })
      return
    }
  }
  
  next()
})

// 路由独享：管理员页面单独校验
{
  path: '/admin',
  component: () => import('@/views/Admin.vue'),
  meta: { roles: ['admin'] },
  beforeEnter: (to, from, next) => {
    // 可附加更细粒度的权限检查
    if (store.state.user.permissions.includes('manage_users')) {
      next()
    } else {
      next({ name: 'forbidden' })
    }
  }
}
```

### 6. 常见错误与最佳实践

| 错误                                         | 后果                       | 正确做法                                     |
| -------------------------------------------- | -------------------------- | -------------------------------------------- |
| **`beforeEach` 中忘记调用 `next()`**     | 页面假死，导航永远不执行    | 每条分支都调用 `next()`                      |
| 调用 `next()` 后还继续执行代码               | 可能产生重复的导航动作      | 调用 `next()` 后立即 `return`                |
| 在异步操作中未等待就调用 `next()`             | 校验逻辑不完整              | 在 Promise 或回调中调用 `next()`             |
| 滥用 `next('/login')` 造成无限循环           | 无限重定向                  | 检查目标路由是否已经是登录页，避免重定向自身 |

#### 安全模式示例

```javascript
router.beforeEach((to, from, next) => {
  const token = localStorage.getItem('token')
  
  if (to.name === 'login') {
    // 已在登录页，直接放行
    next()
    return
  }
  
  if (!token) {
    next({ name: 'login' })
    return
  }
  
  next()
})
```

---

### 总结

- **全局守卫**：`beforeEach`（必须 `next()`）、`afterEach`（常用于埋点）。
- **路由独享**：`beforeEnter` 用于特定路由的权限细分。
- **组件内守卫**：`beforeRouteEnter`（无 this）、`beforeRouteUpdate`（参数变化）、`beforeRouteLeave`（离开拦截）。
- **必须调用 `next()`** 是所有前置守卫的铁律。

合理组织三层守卫，可以构建安全、流畅的导航权限体系。
