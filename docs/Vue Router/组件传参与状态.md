在 Vue Router 中，除了通过路由参数（`params`/`query`）传递数据外，还可以利用 `<router-view>` 组件的 **props 属性** 向路由组件传递额外的数据。同时，结合 `<keep-alive>` 可以缓存路由组件的状态，避免重复渲染带来的性能开销和状态丢失。

---

## 1. 通过 `<router-view :props="$attrs">` 向组件传参

### 原理
`<router-view>` 是一个功能组件，它渲染当前匹配到的路由组件。我们可以像普通组件一样，向 `<router-view>` 传递 `props`，这些 `props` 会被**透传**给被渲染的路由组件。

如果使用 `v-bind="$attrs"`，则父组件中**所有未被显式声明为 props 的属性**都会自动传递下去，非常方便用于多层属性透传。

### 基本用法

**父组件（例如 App.vue / Layout.vue）**：
```vue
<template>
  <div>
    <!-- 传递一个静态 prop -->
    <router-view :pageTitle="'用户中心'" />
    
    <!-- 使用 $attrs 透传所有非 prop 属性 -->
    <router-view v-bind="$attrs" />
  </div>
</template>
```

**路由组件（例如 UserView.vue）**：
```vue
<script setup>
// 声明接收的 props
defineProps(['pageTitle'])
</script>

<template>
  <div>
    <h1>{{ pageTitle }}</h1>
    <!-- 组件内容 -->
  </div>
</template>
```

### 典型场景
- 向不同的路由组件传递相同的**环境变量**（如主题、语言、用户权限等）。
- 在嵌套路由中，父组件需要向下传递数据给子视图。

> 注意：如果 `<router-view>` 绑定了多个 prop，路由组件中必须声明对应的 `props` 才会接收。未声明的属性会被作为普通 HTML 属性渲染在根元素上（除非设置了 `inheritAttrs: false`）。

## 2. 使用 `<keep-alive>` 缓存组件状态

### 为什么需要缓存？
默认情况下，路由切换时，原组件会被销毁，新组件被创建。这会导致：
- 组件内部状态（如表单输入、滚动位置、数据加载状态）丢失。
- 重复执行数据获取逻辑，浪费资源。

使用 `<keep-alive>` 包裹 `<router-view>` 后，路由组件会被**缓存**，切换回来时不会重新创建，而是**激活**（触发 `activated` 钩子）。

### 基本用法

```vue
<template>
  <div>
    <keep-alive>
      <router-view />
    </keep-alive>
  </div>
</template>
```

### 缓存控制

| 属性        | 作用                                                                 |
| ----------- | -------------------------------------------------------------------- |
| `include`   | 只有名称匹配的组件会被缓存（支持字符串、正则、数组）                 |
| `exclude`   | 名称匹配的组件不会被缓存                                             |
| `max`       | 最多缓存多少个组件实例，超出时会销毁最久未访问的实例                |

**示例：只缓存 `UserView` 和 `ProductView`**
```vue
<keep-alive :include="['UserView', 'ProductView']">
  <router-view />
</keep-alive>
```

### 与路由结合的生命周期

- **被缓存组件的生命周期**：
  - 首次进入：`setup()` → `onMounted()` → **`onActivated()`**
  - 切换到其他路由：**`onDeactivated()`**（组件不会被销毁）
  - 再次切回：**`onActivated()`**（不再执行 `onMounted`）
  
```vue
<script setup>
import { onActivated, onDeactivated } from 'vue'

onActivated(() => {
  // 组件被激活（进入视图）
  console.log('组件激活，可刷新数据')
})

onDeactivated(() => {
  // 组件被停用（离开视图）
  console.log('组件停用，可暂停定时器等')
})
</script>
```

> 注意：使用了 `<keep-alive>` 后，`onMounted` 只会在组件**首次创建**时执行一次；`onUnmounted` 只有在缓存被清除（如超过 `max` 限制）时才会触发。

## 3. 组合使用：传递参数 + 缓存组件

```vue
<template>
  <div>
    <!-- 缓存 + 透传 props -->
    <keep-alive :include="cachedViews">
      <router-view :key="$route.fullPath" v-bind="$attrs" />
    </keep-alive>
  </div>
</template>

<script setup>
import { ref } from 'vue'

const cachedViews = ref(['UserView', 'SettingsView'])

// 父组件可以传入任何属性，比如：
// <RootComponent :theme="dark" :userId="123" />
// 这些属性会通过 $attrs 传递给当前激活的路由组件
</script>
```

### 小技巧：结合 `:key` 强制刷新
有时缓存会导致界面不更新（例如同一路由但 `params` 变化），可以给 `<router-view>` 添加 `:key="$route.fullPath"`，使路由路径变化时强制重新创建组件（即使有 `<keep-alive>` 也会重新渲染）。

```vue
<keep-alive>
  <router-view :key="$route.fullPath" />
</keep-alive>
```

## 4. 总结与最佳实践

| 场景                               | 推荐方案                                                                 |
| ---------------------------------- | ------------------------------------------------------------------------ |
| 向路由组件传递**外部数据**          | 使用 `<router-view :propName="value">` 或 `v-bind="$attrs"` 透传        |
| 保持表单输入、滚动位置等**临时状态** | 用 `<keep-alive>` 包裹 `<router-view>`，不设置 `key`                   |
| 同一路由参数变化时**强制刷新**      | 给 `<router-view>` 添加 `:key="$route.fullPath"`                        |
| 控制哪些组件需要缓存               | 使用 `include` / `exclude` 指定组件名称（组件需设置 `name` 选项）        |
| 缓存组件中访问路由参数             | 直接使用 `useRoute()`，因为 `$route` 是响应式，激活时会自动更新          |

通过合理运用 `<router-view>` 的 props 透传和 `<keep-alive>` 缓存，可以在不引入额外状态管理库（如 Pinia）的情况下，实现高效的组件间数据传递与状态保持。
