在构建现代Web应用时，Vue Router 是 Vue.js 生态中官方的路由管理器。要理解它，核心是掌握**单页应用（SPA）与客户端路由的原理**，以及三个关键概念：`RouterLink`、`RouterView` 和路由匹配规则。

### 1. SPA与客户端路由原理

- **传统多页应用**：每次点击链接，浏览器都会向服务器发送请求，服务器返回全新的HTML页面。这会导致页面刷新，用户体验不连续。
- **单页应用**：整个应用只加载一个HTML页面。用户交互时，页面**不会刷新**，而是通过JavaScript动态地替换页面中的内容。

**客户端路由**就是实现这种无刷新切换的关键。它的原理是：

1.  **监听URL变化**：通过监听浏览器地址栏URL的变化（`hash`模式或`history`模式）。
2.  **阻止默认请求**：当URL变化时，阻止浏览器向服务器发送请求。
3.  **渲染对应组件**：根据当前的URL，找到预先配置好的对应Vue组件，并将其动态渲染到页面的指定位置。

简单说，**前端路由就是URL与视图的映射关系**。

### 2. 核心组件：RouterLink 与 RouterView

这两个是Vue Router提供的全局组件，它们分工明确，配合完成路由的触发和渲染。

-   **`<RouterLink>`：导航链接**
    -   **角色**：替代HTML中的`<a>`标签。
    -   **作用**：生成一个可点击的链接，用于触发路由导航。点击它不会刷新页面，只会改变URL并触发视图更新。
    -   **关键属性**：
        -   `to`：指定目标地址，可以是字符串 (`to="/about"`) 或对象 (`:to="{ name: 'about' }"`)。
        -   `replace`：用新地址替换历史记录，而不是添加新记录（相当于不可返回）。
        -   `active-class`：链接匹配时应用的CSS类名，用于高亮当前菜单。

-   **`<RouterView>`：视图占位符**
    -   **角色**：路由出口/占位符。
    -   **作用**：放在组件的模板中，指明了与当前URL匹配到的**组件应该渲染在哪里**。当URL改变时，`<RouterView>`中的内容会自动被替换成新的组件。

**一个简单的示例模板：**
```html
<template>
  <div id="app">
    <nav>
      <!-- 点击后，URL变为 /about，但页面不刷新 -->
      <RouterLink to="/">首页</RouterLink>
      <RouterLink to="/about">关于</RouterLink>
    </nav>
    <!-- 匹配到的组件会显示在这里 -->
    <RouterView />
  </div>
</template>
```
在这个例子中，点击`RouterLink`改变URL，`RouterView`就会自动渲染出对应的首页或关于页面组件。

### 3. 路由匹配规则

路由匹配规则是在创建路由器时通过配置`routes`数组定义的，它告诉Vue Router“**当前URL对应渲染哪个组件**”。

```javascript
import { createRouter, createWebHistory } from 'vue-router'
import Home from './views/Home.vue'
import About from './views/About.vue'

const routes = [
  // 1. 精确匹配：URL为 / 时，渲染Home组件
  { path: '/', component: Home },
  // 2. 动态路径参数：以冒号:开头。匹配 /user/1, /user/abc 等
  { path: '/user/:id', component: User, props: true },
  // 3. 嵌套路由：通过children实现页面内的局部切换
  { 
    path: '/settings', 
    component: Settings,
    children: [
      { path: 'profile', component: Profile }, // 匹配 /settings/profile
      { path: 'account', component: Account }  // 匹配 /settings/account
    ]
  },
  // 4. 命名路由：给路由起个名字，方便跳转
  { path: '/profile/:username', name: 'user-profile', component: UserProfile },
  // 5. 重定向：访问 /home 会自动跳转到 /
  { path: '/home', redirect: '/' },
  // 6. 404 匹配：使用正则或自定义路径匹配未定义的路径
  { path: '/:pathMatch(.*)*', name: 'NotFound', component: NotFound }
]

const router = createRouter({
  history: createWebHistory(),
  routes, // 声明匹配规则
})
```

**关键匹配规则总结：**

-   **静态路径**：`path: '/about'` 匹配 `/about`。
-   **动态路径**：`path: '/user/:id'`，`:id`是参数。在组件中可通过`$route.params.id`获取。
-   **嵌套路由**：`children`中的路径**不应以斜杠开头**，会拼接父级路径。
-   **万能匹配**：`/:pathMatch(.*)*`是常规写法，用于捕获所有未匹配的路径，通常用来做404页面。

### 总结与工作流程

一个完整的客户端路由流程如下：

1.  用户点击 `<RouterLink to="/about">`。
2.  Vue Router**拦截**点击事件，阻止浏览器刷新页面。
3.  路由**改变URL**（从`/`变为`/about`）。
4.  Vue Router根据`routes`配置中的**匹配规则**，找到`path: '/about'`对应的`About`组件。
5.  自动**销毁**当前`<RouterView>`中的旧组件。
6.  **创建并挂载**`About`组件到`<RouterView>`所在位置。
7.  页面内容无缝更新，实现了无刷新的页面切换体验。
