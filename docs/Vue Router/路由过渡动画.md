## 路由过渡动画：为 `<router-view>` 添加页面切换动效

使用 Vue Router 配合 Vue 内置的 `<transition>` 组件，可以轻松为页面之间的切换添加平滑的过渡动画，极大地提升用户交互体验。

---

### 1. 基础用法：包裹 `<router-view>`

最直接的方式是用 `<transition>` 组件包裹 `<router-view>`，并定义 CSS 过渡类名。

```vue
<template>
  <div id="app">
    <transition name="fade" mode="out-in">
      <router-view />
    </transition>
  </div>
</template>

<style>
/* 定义 fade 过渡效果 */
.fade-enter-active,
.fade-leave-active {
  transition: opacity 0.3s ease;
}
.fade-enter-from,
.fade-leave-to {
  opacity: 0;
}
</style>
```

- **`mode="out-in"`**：先执行离开动画，完成后再执行进入动画。避免两个页面同时出现造成闪烁（最常用）。另一种模式是 `in-out`。

---

### 2. 关键点说明

| 属性/概念                   | 说明                                                         |
| --------------------------- | ------------------------------------------------------------ |
| **`name`**                  | 设置过渡类名前缀，例如 `name="slide"` 会应用 `slide-enter-active` 等类名。 |
| **`mode`**                  | 控制动画序列：`out-in`（推荐）、`in-out`。默认为 `out-in`。 |
| **纯 CSS 过渡**             | 适合简单淡入淡出、滑动等效果。                               |
| **CSS 动画 + 关键帧**       | 可以创建更丰富的效果（如缩放、旋转）。                       |
| **JavaScript 钩子**         | 通过 `@before-enter`、`@enter` 等钩子配合 GSAP 等库实现复杂动效。 |

---

### 3. 更丰富的过渡效果示例

#### 3.1 左滑/右滑（模拟原生 app 页面切换）

```vue
<template>
  <transition name="slide" mode="out-in">
    <router-view />
  </transition>
</template>

<style>
/* 页面从左向右滑入/滑出 */
.slide-enter-active,
.slide-leave-active {
  transition: transform 0.3s ease;
}
.slide-enter-from {
  transform: translateX(100%);
}
.slide-leave-to {
  transform: translateX(-100%);
}
</style>
```

> 注意：以上效果适合**独立页面**切换，如果页面有固定头部或底部，建议只对内容区做动画。

#### 3.2 缩放 + 淡入淡出

```vue
<style>
.zoom-fade-enter-active,
.zoom-fade-leave-active {
  transition: opacity 0.25s ease, transform 0.3s ease;
}
.zoom-fade-enter-from {
  opacity: 0;
  transform: scale(0.92);
}
.zoom-fade-leave-to {
  opacity: 0;
  transform: scale(1.08);
}
</style>
```

### 4. 基于路由的动态过渡

不同的路由可以使用不同的动画效果，常见的场景：列表页进入详情页使用左滑，返回时使用右滑。

#### 方案：监听 `$route` 并动态绑定过渡名称

```vue
<template>
  <transition :name="transitionName" mode="out-in">
    <router-view />
  </transition>
</template>

<script setup>
import { watch, ref } from 'vue'
import { useRoute } from 'vue-router'

const route = useRoute()
const transitionName = ref('fade')

watch(() => route.meta.transition, (newVal) => {
  transitionName.value = newVal || 'fade'
}, { immediate: true })
</script>

<style>
/* 定义多种过渡 */
.fade-enter-active,
.fade-leave-active { transition: opacity 0.3s; }
.fade-enter-from,
.fade-leave-to { opacity: 0; }

.slide-left-enter-active,
.slide-left-leave-active { transition: transform 0.3s; }
.slide-left-enter-from { transform: translateX(100%); }
.slide-left-leave-to { transform: translateX(-100%); }

.slide-right-enter-active,
.slide-right-leave-active { transition: transform 0.3s; }
.slide-right-enter-from { transform: translateX(-100%); }
.slide-right-leave-to { transform: translateX(100%); }
</style>
```

然后在路由配置中指定：

```javascript
const routes = [
  { path: '/list', component: List, meta: { transition: 'fade' } },
  { path: '/detail/:id', component: Detail, meta: { transition: 'slide-left' } }
]
```

#### 更智能的自动判断：根据路由深度或前后关系

```javascript
// 在全局守卫中或 watch 中计算
const depthDiff = to.meta.depth - from.meta.depth
transitionName.value = depthDiff > 0 ? 'slide-left' : (depthDiff < 0 ? 'slide-right' : 'fade')
```

### 5. 与 `<keep-alive>` 的结合

当 `<router-view>` 同时被 `<keep-alive>` 包裹时，过渡动画仍然正常工作，但注意 `<transition>` 应该作为 `<keep-alive>` 的**父级**，这样缓存组件的激活/停用也会触发过渡。

```vue
<template>
  <transition name="fade" mode="out-in">
    <keep-alive :include="cachedViews">
      <router-view />
    </keep-alive>
  </transition>
</template>
```

> **顺序很重要**：`<transition>` 必须在外层，因为 `keep-alive` 不会阻离开动画，但 `transition` 会监听内部元素的插入/移除。

---

### 6. 命名视图的多视图过渡

如果有命名视图（多个 `<router-view>`），可以分别为每个视图添加过渡，或者使用 `<transition-group>` 包裹多个视图（不推荐，复杂）。更简单的做法是单独包裹每个 `<router-view>`。

```vue
<template>
  <div class="layout">
    <transition name="fade" mode="out-in">
      <router-view name="sidebar" />
    </transition>
    <transition name="slide" mode="out-in">
      <router-view name="main" />
    </transition>
  </div>
</template>
```

### 7. 使用 JavaScript 钩子实现更高级动画（例如 GSAP）

```vue
<template>
  <transition
    @before-enter="beforeEnter"
    @enter="enter"
    @leave="leave"
    :css="false"
  >
    <router-view />
  </transition>
</template>

<script setup>
import gsap from 'gsap'

const beforeEnter = (el) => {
  el.style.opacity = 0
  el.style.transform = 'translateY(30px)'
}
const enter = (el, done) => {
  gsap.to(el, {
    opacity: 1,
    y: 0,
    duration: 0.5,
    ease: 'power2.out',
    onComplete: done
  })
}
const leave = (el, done) => {
  gsap.to(el, {
    opacity: 0,
    y: -30,
    duration: 0.4,
    ease: 'power2.in',
    onComplete: done
  })
}
</script>
```

设置为 `:css="false"` 让 Vue 跳过 CSS 检测，完全由 JS 控制动画，性能更好且无样式干扰。

### 8. 常见问题与注意事项

| 问题                           | 解决方案                                                     |
| ------------------------------ | ------------------------------------------------------------ |
| **动画不生效**                 | 确保 `<transition>` 包裹了 `<router-view>`，且 CSS 类名与 `name` 属性匹配。 |
| **页面切换时两个组件同时出现** | 设置 `mode="out-in"`。                                       |
| **新页面内容高度变化导致跳动** | 给页面容器设置 `min-height` 或使用绝对定位叠加动画。         |
| **与 `<keep-alive>` 共用动画卡顿** | 检查是否 `<transition>` 在 `<keep-alive>` 内部（错误），应调换顺序。 |
| **动态路由（参数变化）不触发动画** | 这是因为同一组件复用，需给 `<router-view>` 添加 `:key="$route.fullPath"` 强制触发过渡。 |
| **移动端性能**                 | 使用 `transform` 和 `opacity` 属性的动画性能最好，避免改变 `width`/`height`/`top`/`left`。 |

---

### 9. 完整示例：卡片式页面切换

```vue
<template>
  <transition name="card" mode="out-in">
    <router-view />
  </transition>
</template>

<style>
.card-enter-active,
.card-leave-active {
  transition: all 0.3s cubic-bezier(0.4, 0, 0.2, 1);
}
.card-enter-from {
  opacity: 0;
  transform: scale(0.96) translateY(20px);
}
.card-leave-to {
  opacity: 0;
  transform: scale(0.98) translateY(-10px);
}
</style>
```

---

### 总结

| 要点                                 | 说明                                                         |
| ------------------------------------ | ------------------------------------------------------------ |
| **核心结构**                         | `<transition><router-view /></transition>`                   |
| **推荐模式**                         | `mode="out-in"` 避免重叠                                    |
| **动态动画**                         | 根据路由 `meta` 或路由深度改变 `name`                        |
| **性能**                             | 优先使用 `transform` 和 `opacity` 动画，配合 `will-change`  |
| **与 keep-alive 共用**               | `<transition>` 包在 `<keep-alive>` 外层                       |
| **参数变化触发动画**                 | 给 `<router-view>` 添加 `:key="$route.fullPath"`             |

为你的 Vue Router 应用添加合适的过渡动画，能让页面切换更加自然流畅，给用户带来接近原生 app 的体验。根据项目风格选择淡入淡出、滑动或缩放效果，并合理控制动画时间和缓动曲线，避免过度动效影响操作效率。
