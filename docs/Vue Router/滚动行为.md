## 滚动行为：`scrollBehavior` 函数

在单页应用中，路由切换时默认**不会自动处理滚动位置**。例如从详情页返回列表页时，页面往往会停留在顶部，而非之前浏览的位置，这会导致糟糕的用户体验。Vue Router 提供了 **`scrollBehavior`** 函数，让你完全控制路由切换时的滚动逻辑。

---

### 1. 基本用法

在创建路由实例时配置 `scrollBehavior` 函数：

```javascript
const router = createRouter({
  history: createWebHistory(),
  routes: [...],
  scrollBehavior(to, from, savedPosition) {
    // 返回期望的滚动位置
    return { top: 0, left: 0 }
  }
})
```

#### 参数说明

| 参数            | 类型                  | 含义                                                         |
| --------------- | --------------------- | ------------------------------------------------------------ |
| `to`            | `RouteLocationNormalized` | 即将进入的目标路由对象                                 |
| `from`          | `RouteLocationNormalized` | 即将离开的源路由对象                                 |
| `savedPosition` | `{ x: number, y: number } \| null` | 仅当通过浏览器的**前进/后退**按钮触发导航时，此参数为之前保存的滚动位置；否则为 `null` |

#### 返回值类型

`scrollBehavior` 可以返回以下几种值：

- **坐标对象**：`{ top: 0, left: 0, behavior?: 'smooth' }`
- **选择器字符串**：`'#anchor'`（滚动到指定元素）
- **包含元素选择器的对象**：`{ el: '#main', top: 100, behavior: 'smooth' }`
- **`null` 或 `undefined`**：不做任何滚动处理
- **`Promise`**：异步解析出上述任一结果（用于等待数据加载后再滚动）

---

### 2. 常见滚动策略实现

#### 2.1 始终滚动到顶部（最常用）

```javascript
scrollBehavior(to, from, savedPosition) {
  return { top: 0 }
}
```

#### 2.2 前进/后退时恢复之前的滚动位置

```javascript
scrollBehavior(to, from, savedPosition) {
  if (savedPosition) {
    return savedPosition   // 浏览器前进/后退时，恢复原滚动位置
  } else {
    return { top: 0 }      // 普通导航跳转回到顶部
  }
}
```

#### 2.3 根据路由元信息定制滚动行为

```javascript
scrollBehavior(to, from, savedPosition) {
  // 如果路由 meta 中标记了 keepScroll，则尝试恢复保存的位置（需自行实现存储）
  if (to.meta.keepScroll && from.meta.keepScroll) {
    return { top: sessionStorage.getItem(`scroll-${to.path}`) || 0 }
  }
  // 回到顶部
  return { top: 0 }
}
```

#### 2.4 滚动到锚点元素（支持 hash 定位）

```javascript
scrollBehavior(to, from, savedPosition) {
  if (to.hash) {
    // 例如路由为 /about#contact，滚动到 id="contact" 的元素
    return {
      el: to.hash,          // 直接使用 CSS 选择器
      behavior: 'smooth'
    }
  }
  return { top: 0 }
}
```

#### 2.5 异步滚动（例如等待页面数据加载完成）

```javascript
scrollBehavior(to, from, savedPosition) {
  return new Promise(resolve => {
    // 假设有一个全局的 store 标记数据已就绪
    const unwatch = watch(
      () => store.state.dataReady,
      ready => {
        if (ready) {
          unwatch()
          resolve({ top: 0, behavior: 'smooth' })
        }
      },
      { immediate: true }
    )
  })
}
```

> 注意：返回 Promise 时，滚动会在 Promise resolve 后执行。常用于等待异步组件或 API 数据加载。

### 3. 高级技巧与注意事项

#### 3.1 平滑滚动

```javascript
scrollBehavior(to, from, savedPosition) {
  return { top: 0, behavior: 'smooth' }
}
```
现代浏览器支持 `behavior: 'smooth'`，实现平滑滚动效果。低版本浏览器会降级为瞬间跳转。

#### 3.2 偏移滚动位置（避开固定头部）

如果页面有固定顶栏（高度 60px），滚动到锚点时需要偏移：

```javascript
scrollBehavior(to, from, savedPosition) {
  if (to.hash) {
    return {
      el: to.hash,
      top: 60,     // 额外向下偏移 60px，避免被顶栏遮挡
      behavior: 'smooth'
    }
  }
  return { top: 0 }
}
```

#### 3.3 仅对某些路由生效

根据 `to.path` 或 `to.meta` 决定：

```javascript
scrollBehavior(to, from, savedPosition) {
  if (to.path === '/chat') {
    // 聊天页面需要滚动到底部
    return { el: '#chat-container', top: 999999 }
  }
  return { top: 0 }
}
```

#### 3.4 与 `<keep-alive>` 配合时的注意事项

如果使用了 `<keep-alive>` 缓存组件，组件的滚动位置默认不会丢失，但**返回时仍会触发 `scrollBehavior`**。你可以通过 `savedPosition` 来恢复，也可以依赖缓存组件的内部状态（不推荐混合）。

#### 3.5 滚动行为的局限性

- `scrollBehavior` 只在**路由跳转完成且新页面 DOM 渲染后**执行。若目标组件需要异步数据才能完全渲染，可能导致滚动过早。此时应使用异步滚动（返回 Promise）等待数据。
- **不支持嵌套滚动容器**：只能滚动 `window` 或指定的单个元素。如果需要控制多个滚动区域（如侧边栏和主内容区），需要手动在组件内监听路由变化并编写滚动逻辑。
- **移动端的性能注意**：频繁调用滚动可能导致重绘开销，可配合 `requestAnimationFrame` 优化。

### 4. 完整示例：典型生产级配置

```javascript
// router/index.js
import { createRouter, createWebHistory } from 'vue-router'

const router = createRouter({
  history: createWebHistory(),
  routes: [...],
  scrollBehavior(to, from, savedPosition) {
    // 1. 处理浏览器后退/前进：恢复滚动位置
    if (savedPosition) {
      return { ...savedPosition, behavior: 'smooth' }
    }
    
    // 2. 处理带有 hash 的锚点
    if (to.hash) {
      // 等待页面渲染完成（简单延迟，但较可靠）
      return new Promise(resolve => {
        setTimeout(() => {
          resolve({
            el: to.hash,
            top: 70,   // 固定头部高度
            behavior: 'smooth'
          })
        }, 100)
      })
    }
    
    // 3. 默认滚动到顶部
    return { top: 0 }
  }
})

export default router
```

---

### 5. 无法自动滚动的备选方案

如果 `scrollBehavior` 不能满足复杂需求（例如滚动到某个列表中的特定项），可以在组件内部手动处理：

```vue
<script setup>
import { watch } from 'vue'
import { useRoute } from 'vue-router'

const route = useRoute()
watch(() => route.path, (newPath, oldPath) => {
  if (newPath === '/list') {
    // 滚动到之前保存的某个位置
    const savedTop = sessionStorage.getItem('list-scroll')
    if (savedTop) window.scrollTo(0, parseInt(savedTop))
  }
}, { immediate: true })
</script>
```

---

### 总结

- **`scrollBehavior` 是提升路由切换体验的关键配置**，解决了 SPA 中常见的滚动位置丢失问题。
- 最简配置：`scrollBehavior: () => ({ top: 0 })`
- 生产级配置应支持：前进/后退恢复位置、锚点平滑滚动、避开固定头部。
- 对于异步渲染的内容，返回 Promise 等待数据加载完成。
- 复杂场景可结合组件内的手动滚动逻辑。

正确实现滚动行为，能让你的应用体验接近原生应用般流畅自然。
