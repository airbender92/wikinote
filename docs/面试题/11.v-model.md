# v‑model 原理
> 核心本质：**语法糖**
`v-model="xxx"` = `:value="xxx"` + `@input="xxx = $event"`

## 1、原生表单元素 v‑model
### 等价写法
```html
<!-- 简写 -->
<input v-model="msg">

<!-- 完全等价展开 -->
<input :value="msg" @input="msg = $event.target.value">
```

- `:value`：把数据**绑定到表单value**（数据 → 视图）
- `@input`：监听输入事件，把表单最新值赋值回变量（视图 → 数据）

> text / textarea：用 `value` + `input`
> checkbox / radio：特殊，用 `checked` + `change`
> select：`value` + `change`

### checkbox 单选框示例
```html
<input type="checkbox" v-model="checked">
<!--等价-->
<input type="checkbox" :checked="checked" @change="checked = $event.target.checked">
```

## 2、组件上使用 v‑model（Vue2）
Vue2 组件 v‑model 默认固定：`value` prop + `input` 事件
```vue
<!--父组件-->
<Child v-model="num" />

<!--等价于-->
<Child :value="num" @input="num = $event" />
```

子组件 Child.vue
```vue
<template>
  <div>
    <button @click="$emit('input', value + 1)">+1</button>
  </div>
</template>
<script>
export default {
  props: ['value'] // 接收value
}
</script>
```

> Vue2可以通过 `model` 选项修改prop名和事件名：
```js
export default {
  model: {
    prop: 'count',
    event: 'change'
  },
  props: ['count']
}
```
此时 `<Child v-model="num"/>` 等价：`:count="num"` + `@change="num=$event"`

## 3、Vue3 组件 v‑model ⚠️发生变化
Vue3 移除 `model` 配置；
**单个v‑model**：不再是`value` / `input`，改为 **`modelValue` prop + `update:modelValue` 事件**

父组件：
```vue
<Child v-model="num" />

<!--等价展开-->
<Child :model-value="num" @update:model-value="num = $event" />
```

子组件 Child.vue
```vue
<script setup>
const props = defineProps(['modelValue'])
const emit = defineEmits(['update:modelValue'])
</script>
<template>
  <button @click="emit('update:modelValue', props.modelValue + 1)">+1</button>
</template>
```

### ✨Vue3 支持**多个 v‑model**（Vue2做不到）
```vue
<User v-model:name="userName" v-model:age="userAge" />

<!--等价-->
<User 
  :name="userName" @update:name="userName=$event"
  :age="userAge" @update:age="userAge=$event"
/>
```

## 4、v‑model 修饰符原理
`.lazy`、`.number`、`.trim`

- `.lazy`：把 `input` 事件换成 `change`，失去焦点才更新
```html
<input v-model.lazy="msg">
<!--等价：:value="msg" @change="msg = $event.target.value" -->
```
- `.trim`：自动去除首尾空格
- `.number`：自动转数字，转失败保留原始字符串

> 自定义组件也可以拿到修饰符：Vue3通过 `modelModifiers` prop 获取修饰符。

## 📝面试简答速记
1. v‑model 是**语法糖**，本质：**属性绑定 + 事件监听**，实现双向绑定。
2. 原生input：`value` + `input`；checkbox使用`checked`+`change`。
3. Vue2组件v‑model：`value` prop + `input`事件，可通过model选项修改。
4. Vue3组件v‑model：`modelValue` prop + `update:modelValue`事件；**支持多v‑model**。
5. 修饰符：`.lazy`换change事件；`.trim`去空格；`.number`转数字。

> 注意：**v‑model不是响应式原理，只是视图和数据双向同步的语法糖**；底层还是依赖Observer/Proxy响应式。
