# Vue2 响应式核心 Observer 简易实现
> 核心原理：`Object.defineProperty` 递归遍历 data 对象，劫持每个属性的 `getter` / `setter`；
> - get：收集依赖（Dep 收集 Watcher）
> - set：数据变更，触发更新通知

完整拆分：**Observer（观测对象）、Dep（依赖管理器）、Watcher（观察者）**

## 1. Observer 类
遍历对象所有属性，给每个属性添加 `get/set`，遇到对象则递归观测。
```js
class Observer {
  constructor(data) {
    this.walk(data)
  }

  // 遍历对象所有属性
  walk(data) {
    if (!data || typeof data !== 'object') {
      return
    }
    Object.keys(data).forEach(key => {
      this.defineReactive(data, key, data[key])
    })
  }

  // 定义响应式，劫持get set
  defineReactive(obj, key, val) {
    // 每个属性拥有自己的Dep依赖容器
    const dep = new Dep()
    // 如果val是对象，递归劫持子属性
    this.walk(val)

    Object.defineProperty(obj, key, {
      enumerable: true,
      configurable: true,
      get() {
        // 读取数据时：收集依赖，当前存在Watcher就加入dep
        if (Dep.target) {
          dep.addSub(Dep.target)
        }
        return val
      },
      set(newVal) {
        if (newVal === val) return
        val = newVal
        // 如果新赋值也是对象，继续递归观测
        this.walk(newVal)
        // 数据修改：通知所有watcher更新
        dep.notify()
      }
    })
  }
}
```

## 2. Dep 依赖收集类
每个响应式属性对应一个 Dep，存放所有依赖这个属性的 Watcher；
`Dep.target` 是全局标记，标记当前正在执行的 watcher。
```js
class Dep {
  constructor() {
    // 存储watcher订阅者
    this.subs = []
  }

  // 添加watcher
  addSub(watcher) {
    this.subs.push(watcher)
  }

  // 通知全部watcher更新
  notify() {
    this.subs.forEach(watcher => {
      watcher.update()
    })
  }
}
// 全局静态属性，标记当前计算的Watcher
Dep.target = null
```

## 3. Watcher 观察者类
页面渲染/计算属性使用，当依赖数据变化，执行更新回调。
```js
class Watcher {
  constructor(vm, exp, cb) {
    this.vm = vm
    this.exp = exp // 属性名，例如 'msg'
    this.cb = cb // 更新回调函数
    // 触发getter，完成依赖收集
    this.get()
  }

  get() {
    // 将当前watcher挂载到Dep.target
    Dep.target = this
    // 读取vm数据，触发属性get，dep收集watcher
    const value = this.vm[this.exp]
    Dep.target = null // 收集完成清空
    return value
  }

  // 数据变动执行更新
  update() {
    const newValue = this.vm[this.exp]
    this.cb(newValue)
  }
}
```

## 4. 使用示例
```js
// 模拟Vue实例
const vm = {
  data: {
    name: '张三',
    info: {
      age: 18
    }
  }
}

// 把data代理到vm上，方便访问 vm.name
function proxyData(vm) {
  Object.keys(vm.data).forEach(key => {
    Object.defineProperty(vm, key, {
      get() {
        return vm.data[key]
      },
      set(v) {
        vm.data[key] = v
      }
    })
  })
}

// 初始化响应式
new Observer(vm.data)
proxyData(vm)

// 创建watcher监听name变化
new Watcher(vm, 'name', (val) => {
  console.log('name更新了：', val)
})

// 测试修改数据
vm.name = '李四' //控制台输出：name更新了：李四
vm.info.age = 20 // 递归劫持，也具备响应式
```

## Vue2 这套实现的缺陷（面试必背）
1. **只能劫持对象属性，无法监听数组下标修改**，所以Vue2重写数组7个变异方法 `push/pop/shift/unshift/splice/sort/reverse` 做数组响应式；
2. **新增/删除对象属性无法监听**，需要 `Vue.set / this.$set`；
3. 需要递归遍历全部对象，对象层级很深的时候初始化开销大。

## 关键流程梳理
1. `new Observer(data)` → 递归遍历data所有属性
2. `Object.defineProperty` 设置 get/set，每个属性实例化一个 `Dep`
3. 创建 `Watcher`，执行get()，赋值 `Dep.target = watcher`
4. 读取数据触发属性get → `dep.addSub(Dep.target)`，收集watcher
5. 修改数据触发set → `dep.notify()` → 遍历watcher执行 `update()` 更新视图
