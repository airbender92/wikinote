# React 懒加载

React 懒加载核心：**`React.lazy()` + `Suspense`**，实现代码分割，组件只有渲染的时候才下载 js，减小首屏包体积。

> 只支持默认导出；**服务端渲染不能用 React.lazy**，SSR 使用 `@loadable/component`。

## 基础用法

```
import React, { lazy, Suspense } from 'react';

// 懒加载组件，返回一个可渲染组件
const Home = lazy(() => import('./Home'));

function App() {
  return (
    {/* fallback：加载中显示的占位，loading、骨架屏 */}
    <Suspense fallback={<div>加载中...</div>}>
      <Home />
    </Suspense>
  )
}
```

## 结合 React Router 路由懒加载（最常用）

路由切换时才加载对应页面代码

```
import React, { lazy, Suspense } from 'react';
import { BrowserRouter as Router, Routes, Route } from 'react-router-dom';

const PageA = lazy(() => import('./pages/PageA'));
const PageB = lazy(() => import('./pages/PageB'));

function App() {
  return (
    <Router>
      {/* Suspense 包在外层，所有懒加载路由共用loading */}
      <Suspense fallback={<div>页面加载中...</div>}>
        <Routes>
          <Route path="/a" element={<PageA />} />
          <Route path="/b" element={<PageB />} />
        </Routes>
      </Suspense>
    </Router>
  )
}
```

## 处理懒加载出错（网络差，chunk 文件加载失败）

`React.lazy` 加载失败会抛出异常，需要**错误边界 ErrorBoundary**捕获，就是上一节 `getDerivedStateFromError`。

```
import React, {lazy, Suspense} from 'react';

// 错误边界
class ErrorBoundary extends React.Component {
  state = {hasError: false}
  static getDerivedStateFromError() {
    return {hasError: true}
  }
  render() {
    if(this.state.hasError) return <div>模块加载失败，请刷新</div>
    return this.props.children
  }
}

const Page = lazy(() => import('./pages/Page'))

function App() {
  return (
    <ErrorBoundary>
      <Suspense fallback={<div>loading...</div>}>
        <Page/>
      </Suspense>
    </ErrorBoundary>
  )
}
```

## 关键限制

1. `React.lazy` **仅支持默认导出 default export**；如果是命名导出，需要包一层中转

```
// 组件是命名导出 export const Demo = ()=>{}
const Demo = lazy(() => import('./Demo').then(mod => ({default: mod.Demo})))
```

2. **SSR不支持**，服务端渲染项目用 `@loadable/component`

```
npm i @loadable/component
```

```
import loadable from '@loadable/component'
const Demo = loadable(()=>import('./Demo'))
```

3. `Suspense.fallback` 必须写，不能省略；fallback 可以是骨架屏、loading动画。
4. Suspense 捕获的是**代码加载 promise**，不是组件内部业务报错。

## 手动预加载

某些场景提前加载组件（鼠标悬浮按钮时预拉取chunk）

```
const Page = lazy(()=>import('./Page'))
// 预加载函数，直接执行import，后台下载js
const preloadPage = () => import('./Page')

function App(){
  return <button onMouseEnter={preloadPage}>打开页面</button>
}
```

## 和普通import对比

- `import Comp from './Comp'`：打包时直接打进主bundle，首屏下载
- `lazy(()=>import('./Comp'))`：生成独立chunk，**用到才下载**

## 补充：React18 Suspense新行为

React18并发模式下，Suspense会**卸载旧UI，展示fallback**；17版本会保留旧界面。
如果希望保留旧页面不闪白，需要自己做缓存方案，或者使用 `@loadable/component`。
