二、Vue 核心

以下 8 题覆盖外包技术面 80% 的 Vue 提问。

1. 虚拟 DOM 是什么

JS 对象描述 DOM,diff 后最小化真实 DOM 操作;跨平台(uni-app);数据驱动视图。

2. 生命周期钩子

setup → onMounted(DOM 就绪:初始化库/请求)→ onUpdated → onUnmounted(清理定时器/事件/echarts,防泄漏)。

3. computed 和 watch 区别

computed:有缓存,派生值;watch:副作用(请求/异步),可 deep/immediate。口诀:派生用 computed,副作用用 watch。

4. Vue2 vs Vue3

defineProperty→Proxy;Options→Composition;diff 优化;TS 友好;状态管理用 Pinia。

5. 刷新后状态丢失怎么办

localStorage 持久化关键状态;刷新后重拉用户信息/权限;敏感数据不存本地。

6. 权限控制(银行必考)

① 登录得 token + 权限码;② 路由守卫校验,无 token 跳登录;③ 动态路由 addRoute 或 meta 控制;④ 按钮级 v-permission 指令;⑤ 前端只是体验,安全底线在后端二次校验。

7. nextTick 是什么

DOM 更新是异步批量的;nextTick 在更新后回调拿到最新 DOM。原理:微任务队列。

8. 跨域怎么解决

同源:协议/域名/端口。开发:proxy 代理;生产:Nginx 反代;CORS 配响应头。

三、JS 手写代码(笔试必考)

亲手敲 2 遍,面试官会要求边说边写。

1. 防抖(只执行最后一次)
function debounce(fn, d = 300) {
  let t;
  return function (...a) {
    clearTimeout(t);
    t = setTimeout(() => fn.apply(this, a), d);
  };
}
2. 节流(定期执行)
function throttle(fn, d = 300) {
  let last = 0;
  return function (...a) {
    const now = Date.now();
    if (now - last >= d) { last = now; fn.apply(this, a); }
  };
}
3. 深拷贝(含循环引用)
function deepClone(o, map = new WeakMap()) {
  if (o === null || typeof o !== 'object') return o;
  if (o instanceof Date) return new Date(o);
  if (map.has(o)) return map.get(o);
  const c = Array.isArray(o) ? [] : {};
  map.set(o, c);
  for (const k of Object.keys(o)) c[k] = deepClone(o[k], map);
  return c;
}
4. Promise.all
Promise.myAll = ps => new Promise((res, rej) => {
  const r = []; let n = 0;
  ps.forEach((p, i) => Promise.resolve(p).then(
    v => { r[i] = v; if (++n === ps.length) res(r); }, rej));
});
5. new
function myNew(Fn, ...a) {
  const o = Object.create(Fn.prototype);
  const r = Fn.apply(o, a);
  return (typeof r === 'object' && r !== null) || typeof r === 'function' ? r : o;
}
6. bind
Function.prototype.myBind = function (ctx, ...a) {
  const fn = this;
  return function (...r) { return fn.apply(ctx, [...a, ...r]); };
};
7. 数组去重
[...new Set(arr)];
arr.filter((v, i) => arr.indexOf(v) === i);
8. 事件循环顺序

同步 → 全部微任务 → 一个宏任务 → 全部微任务…。微任务:Promise.then;宏任务:setTimeout。

输出题:1, 3, 2(同步1、微任务3、宏任务2)。

9. this 指向

普通调用→window;对象方法→对象;new→实例;call/apply/bind→绑定值。箭头函数无 this,定义时确定。

10. 闭包

函数+词法作用域引用,变量不销毁。作用:封装私有变量。风险:内存泄漏;for+setTimeout(var) 输出 3,3,3,用 let 解决。

四、性能优化与工程化

1. 一次渲染 10 万条表格数据

分页/懒加载 → 虚拟滚动(只渲染可视区)→ 时间分片 requestIdleCallback。

2. 首屏加载优化

路由懒加载、gzip+CDN+强缓存、按需引入、图片优化、接口合并、骨架屏、preload。

3. 浏览器缓存

强缓存(Cache-Control,不发请求)+ 协商缓存(ETag,304)。index.html 短缓存,hash 资源长缓存。

4. URL 到渲染过程

DNS → TCP 三次握手 → 请求 → DOM/CSSOM → 渲染树 → 布局 → 绘制。script 阻塞,放底部/defer。

5. 错误监控

window.onerror + unhandledrejection + errorHandler;sourcemap 还原堆栈(不公开生产);采样去重批量上报。

6. Vite vs Webpack

Vite:原生 ESM,秒开、HMR 快;Webpack:生态成熟。新项目主流 Vite。

7. Git 协作

pull --rebase 保持线性;feature/develop/main 分支;commit 规范 feat:/fix: + commitlint。

8. 移动端适配

vw/vh 方案(主流)、rem 方案、媒体查询、安全区适配。

五、网络与前端安全(银行重点)

1. XSS 及防御

注入恶意脚本。防御:输出转义、v-html 慎用、HttpOnly cookie、CSP。

2. CSRF 及防御

利用已登录 cookie 伪造请求。防御:校验 Origin、CSRF Token、SameSite、关键操作二次验证。

3. 敏感数据脱敏(银行必考)

138****1234;能后端脱敏就不前端做;展示层过滤器兜底;敏感信息不进日志/localStorage。

4. token vs cookie

cookie 自动携带、HttpOnly、跨域受限;token 请求头携带、无跨域。银行方案:access + refresh 双 token,401 拦截刷新。

5. HTTPS 加密流程

服务器发证书(公钥)→ 客户端验证 → 生成对称密钥用公钥加密发送 → 私钥解密 → 对称加密通信。

6. HTTP 状态码

200/301/304/400/401(未认证)/403(无权限)/404/500/502/504。

7. axios 拦截器封装

请求拦截:注入 token;响应拦截:统一处理 code、401 跳登录、统一错误提示。加分:取消重复请求、耗时上报。

8. CSP 是什么

内容安全策略,限制脚本来源缓解 XSS。例:script-src 'self'。

六、银行业务场景题

1. 做"转账"页面考虑什么

防重复提交(置灰+幂等号)、表单校验、二次验证(短信/人脸)、HTTPS+脱敏、操作埋点审计。精髓:前端负责体验,资金安全靠后端事务+风控。

2. 银行系统与互联网开发差异

稳定优先(灰度/双人复核)、安全合规优先(脱敏/审计/数据不出行)、老浏览器兼容、流程规范文档齐全。

3. 为什么用 sendBeacon

页面卸载时普通请求会被浏览器中断,sendBeacon 异步且卸载时也能送达,埋点不丢。

4. ECharts 大数据量优化

sampling:'lttb' 降采样、large:true、按需引入、用后 dispose() 防泄漏、dataZoom。

5. 数字化转型了解吗

交行"数字化新交行"战略、大数据风控、AI 应用、信创国产化(前端兼容国产浏览器)、云原生。

6. 不熟悉的技术怎么快速上手

官方文档+最小 demo → 参考现有代码 → 自查(报错/断点)再问人 → 总结笔记。

7. 需求不清晰怎么办

列疑问清单逐条确认,关键逻辑白纸黑字;先对接口文档再联调;体现主动沟通、文档留痕。
