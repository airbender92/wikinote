# WeakMap
`WeakMap` 是 ES6 引入的**弱引用键值对集合**。
> 核心：**键必须是对象（不能是原始类型），值任意；键是弱引用，不阻止GC垃圾回收**。

## 基本语法
```js
const wm = new WeakMap()

const obj = { name: 'test' }

// 设置
wm.set(obj, '对应的值')
// 获取
wm.get(obj) // '对应的值'
// 判断是否存在
wm.has(obj) // true
// 删除
wm.delete(obj) // true
```

### ❗重要限制
1. **键只能是对象/Symbol，不能传数字、字符串、boolean等原始值**
```js
wm.set(123, 'xxx') // TypeError，报错
wm.set('abc', 1)   // TypeError
```
2. **不可遍历**：没有 `size`、没有 `keys()`/`values()`/`entries()`，不能 `for...of`，不能 `forEach`
3. **不可清空**：没有 `clear()`，只能一个个 `delete`

## 弱引用是什么（最关键）
普通 `Map`：如果把对象作为 key，Map 会持有这个对象的**强引用**。
只要 Map 还存在，对象就不会被垃圾回收，即使外面已经没有变量引用它。

```js
const map = new Map()
let obj = { a: 1 }
map.set(obj, 'data')
obj = null 
// 对象还在内存！Map还握着引用，GC不会回收
```

`WeakMap`：对 key 对象是**弱引用**。
> 当外部没有任何变量再引用这个 key 对象时，GC 会自动回收该对象，WeakMap 里对应的那一条键值对会自动消失。

```js
const wm = new WeakMap()
let obj = { a:1 }
wm.set(obj, 'data')
obj = null 
// 外部引用消失，对象会被GC回收，wm中这条记录自动消失
```

> ⚠️ 回收时机由 JS 引擎决定，我们无法观测、无法手动触发。

## 常见使用场景
### 1. 给对象附加私有/额外数据，不污染原对象，不造成内存泄漏
不需要修改原对象，额外存元数据，对象销毁数据自动跟着销毁。
```js
const userMeta = new WeakMap()

function setAge(userObj, age) {
  userMeta.set(userObj, age)
}
function getAge(userObj) {
  return userMeta.get(userObj)
}

const u = {}
setAge(u, 20)
console.log(getAge(u)) //20
u = null 
// userMeta里这条自动消失，没有内存残留
```

### 2. 缓存计算结果，对象销毁缓存自动清理
### 3. DOM元素关联数据（非常经典）
给DOM节点绑定数据，当DOM节点从页面移除，没有其他引用时，WeakMap里的数据自动释放，防止内存泄漏。
```js
const domData = new WeakMap()
const div = document.querySelector('#app')
domData.set(div, { clickCount: 0 })

// div被remove()移除，外部没有引用，domData自动丢掉这条记录
```

## WeakMap vs Map
| 特性 | Map | WeakMap |
|---|---|---|
| key类型 | 任意类型 | 只能对象/Symbol |
| 引用 | 强引用，阻止GC | 弱引用，不阻止GC |
| size | ✅ 有 | ❌ 无 |
| 可遍历（keys/values/for...of） | ✅ | ❌ |
| clear() | ✅ | ❌ |
| 内存泄漏风险 | 高（对象存key容易内存残留） | 低 |

## 补充：WeakSet
类似，存对象集合，弱引用，不可遍历。

## 面试高频考点
1. WeakMap 的 key 为什么不能是基本类型？
> 弱引用是针对堆上对象；原始类型存在栈，不存在GC回收，弱引用没有意义。

2. 为什么不能遍历 WeakMap？
> 键随时可能被GC回收，集合内容是动态变化的，引擎无法提供稳定可迭代列表。

3. Vue3 响应式原理用到 WeakMap：
`targetMap` 是 `WeakMap`，key 是目标对象，value 是依赖映射。当响应式对象销毁，自动回收依赖，避免内存泄露。
