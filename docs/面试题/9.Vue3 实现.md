# Vue3 响应式简易实现：Proxy + Reflect
> Vue3 使用 **Proxy** 代理**整个对象**，不是劫持单个属性；
> ✅ 天然支持：新增属性、删除属性、数组下标修改、数组长度修改
> ✅ 惰性代理：只有访问到子对象的时候才做代理，初始化不用深度递归遍历，性能优于 Vue2 Object.defineProperty
> ✅ 搭配 Reflect，保证 this 指向正确
> 依然保留：`Dep` 做依赖收集、`effect` 代替 Watcher，`track` 收集依赖、`trigger` 触发更新

## 核心概念对比
| Vue2 | Vue3 |
|---|---|
| Object.defineProperty | Proxy + Reflect |
| 劫持单个属性 | 代理整个对象 |
| 初始化递归全部属性 | 惰性代理，访问才代理子对象 |
| 不支持新增/删除属性、数组下标 | 原生支持 |
| Dep + Watcher | Dep + effect |

## 完整极简代码实现
```js
// 存放当前正在执行的副作用函数
let activeEffect = null

// Dep：依赖容器，key -> 副作用effect集合
const targetMap = new WeakMap()

/**
 * 收集依赖 track
 * @param target 目标对象
 * @param key 属性名
 */
function track(target, key) {
  if (!activeEffect) return
  // targetMap: target => Map(key => Set(effect))
  let depsMap = targetMap.get(target)
  if (!depsMap) {
    depsMap = new Map()
    targetMap.set(target, depsMap)
  }
  let dep = depsMap.get(key)
  if (!dep) {
    dep = new Set()
    depsMap.set(key, dep)
  }
  dep.add(activeEffect)
}

/**
 * 触发更新 trigger
 * @param target 目标对象
 * @param key 属性名
 */
function trigger(target, key) {
  const depsMap = targetMap.get(target)
  if (!depsMap) return
  const dep = depsMap.get(key)
  if (dep) {
    // 执行所有收集到的副作用
    dep.forEach(effectFn => effectFn())
  }
}

/**
 * 副作用函数 effect，相当于Vue2的Watcher
 * @param fn 回调函数
 */
function effect(fn) {
  activeEffect = fn
  fn() // 执行fn，内部读取数据，触发get，完成依赖收集
  activeEffect = null
}

/**
 * reactive 响应式函数，返回Proxy代理对象
 * @param target 原始对象
 */
function reactive(target) {
  return new Proxy(target, {
    get(target, key, receiver) {
      // Reflect保证this指向正确
      const res = Reflect.get(target, key, receiver)
      track(target, key) // 读取时收集依赖

      // ✨惰性代理：如果返回值是对象，才继续代理，不是初始化一次性递归
      if (typeof res === 'object' && res !== null) {
        return reactive(res)
      }
      return res
    },

    set(target, key, value, receiver) {
      const oldVal = Reflect.get(target, key, receiver)
      if (oldVal === value) return true
      const success = Reflect.set(target, key, value, receiver)
      trigger(target, key) // 修改、新增属性触发更新
      return success
    },

    // ✅ 原生支持删除属性，Vue2做不到
    deleteProperty(target, key) {
      const hasKey = Reflect.has(target, key)
      const res = Reflect.deleteProperty(target, key)
      if (hasKey && res) {
        trigger(target, key) // 删除触发更新
      }
      return res
    }
  })
}
```

## 使用测试示例
```js
// 原始数据
const state = reactive({
  name: '张三',
  info: {
    age: 18
  },
  list: [1,2,3]
})

// effect 相当于渲染函数，读取数据收集依赖
effect(() => {
  console.log('执行副作用：', state.name, state.info.age, state.list[0])
})

// 1. 修改已有属性
state.name = '李四'

// 2. ✅新增对象属性（Vue2需要$set，Proxy原生支持）
state.info.gender = '男'

// 3. ✅删除属性
delete state.info.age

// 4. ✅数组下标修改，原生支持
state.list[0] = 999

// 5. ✅修改数组length
state.list.length = 1
```

## Vue3 Proxy 关键优势总结
1. **代理整个对象**，不是单个属性，拦截能力完整：`get/set/deleteProperty/has`等13种捕获器
2. **天然支持**：对象新增属性、删除属性、数组下标修改、修改数组`length`，不需要像Vue2重写数组方法、不需要`$set`
3. **惰性代理**：初始化不会递归遍历所有嵌套对象；**只有访问子对象的时候，才对子对象做Proxy代理**，大对象初始化性能大幅提升
4. 使用`Reflect`配套操作，修复部分`this`指向问题

## Proxy 的局限性（面试点）
1. **不能代理原始类型**（string/number/boolean），所以Vue3用`ref`包装基本数据类型；
2. Proxy代理的是对象引用，原始对象和代理对象是两个东西；
3. IE浏览器完全不支持Proxy（Vue3放弃IE）。

## 响应式完整流程
1. `reactive(obj)` 创建 Proxy 代理对象
2. `effect(fn)` 设置 `activeEffect`，执行fn，fn内部读取代理对象属性
3. 触发 Proxy `get` → `track()`，把当前effect收集进`targetMap`依赖容器
4. 修改/新增/删除属性触发 Proxy `set` / `deleteProperty` → `trigger()`
5. 取出对应key所有effect，批量执行，完成更新
