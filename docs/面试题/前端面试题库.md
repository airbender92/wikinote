- **埋点(高频)**:代码埋点+无埋点;采集 PV/点击/业务事件/JS错误;节流批量+卸载 sendBeacon;用途:行为分析、异常监控、操作留痕审计、风控
- **组件传值**:Vue:props/$emit/v-model/provide-inject/$refs/EventBus/Pinia/插槽;React:props/回调/Context/Redux
- **白屏**:排查:JS报错、资源404、接口慢;优化:骨架屏、拆包、CDN、preload、兜底页

- **Redis/Swagger 缺点**:Redis 纯内存贵/非强一致/淘汰误删;Swagger 注解侵入/文档失真/生产须关闭

## 二、Vue 核心

1. **虚拟 DOM**:JS 对象描述 DOM,diff 最小化操作,跨平台
2. **生命周期**:setup → onMounted(DOM就绪) → onUnmounted(清理定时器/echarts 防泄漏)
3. **computed vs watch**:computed 缓存派生;watch 副作用。口诀:派生用 computed,副作用用 watch
4. **Vue2 vs Vue3**:defineProperty→Proxy;Options→Composition;Pinia
5. **刷新丢状态**:localStorage 持久化;刷新重拉用户信息;敏感数据不存本地
6. **权限(必考)**:token+权限码 → 路由守卫 → 动态路由/按钮级 v-permission → **后端二次校验才是安全底线**
7. **nextTick**:DOM 异步批量更新,nextTick 后拿最新 DOM
8. **跨域**:开发 proxy,生产 Nginx 反代,CORS

## 三、JS 手写(必考)

```js
// 防抖
function debounce(fn, d = 300) {
  let t;
  return function (...a) {
    clearTimeout(t);
    t = setTimeout(() => fn.apply(this, a), d);
  };
}
// 节流
function throttle(fn, d = 300) {
  let last = 0;
  return function (...a) {
    const now = Date.now();
    if (now - last >= d) {
      last = now;
      fn.apply(this, a);
    }
  };
}
// 深拷贝(循环引用)
function deepClone(o, map = new WeakMap()) {
  if (o === null || typeof o !== "object") return o;
  if (o instanceof Date) return new Date(o);
  if (map.has(o)) return map.get(o);
  const c = Array.isArray(o) ? [] : {};
  map.set(o, c);
  for (const k of Object.keys(o)) c[k] = deepClone(o[k], map);
  return c;
}
// Promise.all
Promise.myAll = (ps) =>
  new Promise((res, rej) => {
    const r = [];
    let n = 0;
    ps.forEach((p, i) =>
      Promise.resolve(p).then((v) => {
        r[i] = v;
        if (++n === ps.length) res(r);
      }, rej),
    );
  });
// new
function myNew(Fn, ...a) {
  const o = Object.create(Fn.prototype);
  const r = Fn.apply(o, a);
  return (typeof r === "object" && r !== null) || typeof r === "function"
    ? r
    : o;
}
// bind
Function.prototype.myBind = function (ctx, ...a) {
  const fn = this;
  return function (...r) {
    return fn.apply(ctx, [...a, ...r]);
  };
};
```

- **事件循环**:同步 → 全部微任务 → 一个宏任务…;微任务 Promise.then,宏任务 setTimeout;输出 `1,3,2`
- **this**:普通调用 window;对象方法→对象;new→实例;call/apply/bind→绑定。箭头函数无 this
- **闭包**:函数+词法作用域;封装私有变量;风险泄漏;for+setTimeout(var) 输出 3,3,3,用 let 解决

## 五、网络与安全(银行重点)

1. **XSS**:注入脚本;防:转义、v-html 慎用、HttpOnly、CSP
2. **CSRF**:伪造请求;防:校验 Origin、Token、SameSite、关键操作二次验证
3. **脱敏**:138****1234;**能后端脱敏就不前端做**;不进日志/localStorage
4. **token vs cookie**:cookie 自动携带、跨域受限;token 无跨域;双 token 方案,401 刷新
5. **HTTPS**:证书(公钥)→ 验证 → 对称密钥公钥加密 → 私钥解密 → 对称传输
6. **状态码**:200/301/304/400/401/403/404/500/502/504
7. **axios 拦截器**:请求注入 token;响应统一 code/401 跳登录/错误提示
8. **CSP**:限制脚本来源缓解 XSS
