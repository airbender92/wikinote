# 统一判空函数

需求：下面这些全部判定为**空**

> `''` 空字符串、`0`、`undefined`、`null`、`[]`空数组、`{}`空对象、`new Map()`空Map、`new Set()`空Set

非空：`false`、`NaN`、`' '`空格字符串、`[0]`、`{a:1}`、有元素的Map/Set 等

> 注意：业务经常有争议：`false`、`NaN`算不算空，按你题目要求：**不算空**。

## 完整工具函数

```js
/**
 * 判断是否为空
 * 空：''、0、undefined、null、[]、{}、空Map、空Set
 * 非空：false, NaN, ' ', [0] 等
 * @param {*} val
 * @returns {boolean} true=为空
 */
function isEmpty(val) {
  // 1. null / undefined
  if (val === null || val === undefined) {
    return true;
  }

  // 2. 空字符串、数字0
  if (typeof val === "string") {
    return val === "";
  }
  if (typeof val === "number") {
    return val === 0;
  }

  // 3. 数组
  if (Array.isArray(val)) {
    return val.length === 0;
  }

  // 4. 普通对象（自身无属性，不考虑原型链）
  if (Object.prototype.toString.call(val) === "[object Object]") {
    return Object.keys(val).length === 0;
  }

  // 5. Map
  if (Object.prototype.toString.call(val) === "[object Map]") {
    return val.size === 0;
  }

  // 6. Set
  if (Object.prototype.toString.call(val) === "[object Set]") {
    return val.size === 0;
  }

  // 其余全部不为空：false、NaN、Symbol、函数、'  '空格字符串等
  return false;
}
```

## 测试用例

```js
// ✅ 返回 true（为空）
console.log(isEmpty(null)); // true
console.log(isEmpty(undefined)); // true
console.log(isEmpty("")); // true
console.log(isEmpty(0)); // true
console.log(isEmpty([])); // true
console.log(isEmpty({})); // true
console.log(isEmpty(new Map())); // true
console.log(isEmpty(new Set())); // true

// ❌ 返回 false（不为空）
console.log(isEmpty(false)); // false
console.log(isEmpty(NaN)); // false
console.log(isEmpty(" ")); // false 空格字符串不是空
console.log(isEmpty([0])); // false
console.log(isEmpty({ a: 1 })); // false
console.log(isEmpty(new Map([[1, 2]]))); // false
console.log(isEmpty(new Set([1]))); // false
```

## 关键说明

1. **`Object.prototype.toString.call()` 精准区分类型**，不要用 `typeof` 判断对象、Map、Set，`typeof new Map()` 得到 `object`。
2. Map / Set 使用 `.size` 判断是否有元素；数组用 `.length`。
3. 普通对象这里只判断**自身属性** `Object.keys`；如果你需要同时检查原型链自定义属性，把对象判断那一段替换为上一轮的 `for...in` 判断。

### 如果需求：对象判空同时检查原型链自定义属性

把对象分支替换：

```js
// 普通对象：自身+原型链可枚举自定义属性
if (Object.prototype.toString.call(val) === "[object Object]") {
  for (const k in val) {
    return false;
  }
  return true;
}
```

## 常见坑点

1. `' '`（空格字符串）：`isEmpty(' ')` → false，它不是空字符串；如果业务想把全空格也算空，可以加 `val.trim() === ''`。
2. `0` 题目规定是空；但很多业务里面0是合法业务值，需要根据业务取舍。
3. `false`、`NaN`：本题不属于空；如果业务需要纳入空，自行增加条件。
4. 函数类型：函数直接返回false，不视为空。

## 面试简答

> 需要覆盖：null、undefined、空字符串、数字0、空数组、空对象、空Map、空Set。
>
> 1. 先处理null、undefined；
> 2. 区分string判断等于空串，number判断等于0；
> 3. Array判断length；
> 4. Map/Set用Object.prototype.toString.call识别类型，判断size；
> 5. 普通对象使用Object.keys看长度；如需检查原型链则改用for‑in遍历。
>    其余类型返回不为空。
