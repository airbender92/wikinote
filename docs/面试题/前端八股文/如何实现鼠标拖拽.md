# JS 实现鼠标拖拽

拖拽核心流程：

1. `mousedown`：鼠标按下，记录初始位置，标记拖拽开始
2. `mousemove`：鼠标移动，计算偏移量，更新元素位置
3. `mouseup`：鼠标抬起，结束拖拽

> 关键点：`mousemove`、`mouseup` 建议绑在 `document`，防止鼠标移出元素后拖拽失效。

## 最简原生 JS 示例

```
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>鼠标拖拽</title>
  <style>
    #box {
      width: 150px;
      height: 150px;
      background: #409eff;
      position: absolute;
      left: 50px;
      top: 50px;
      cursor: move;
    }
  </style>
</head>
<body>
  <div id="box"></div>

  <script>
    const box = document.getElementById('box');
    let isDrag = false;
    // 鼠标按下时的偏移：鼠标相对于盒子左上角
    let offsetX, offsetY;

    box.addEventListener('mousedown', (e) => {
      isDrag = true;
      // 鼠标坐标 - 盒子自身left/top
      offsetX = e.clientX - box.offsetLeft;
      offsetY = e.clientY - box.offsetTop;
      e.preventDefault(); // 防止选中文本等默认行为
    });

    document.addEventListener('mousemove', (e) => {
      if (!isDrag) return;
      // 新位置 = 当前鼠标位置 - 按下时的偏移
      const x = e.clientX - offsetX;
      const y = e.clientY - offsetY;
      box.style.left = x + 'px';
      box.style.top = y + 'px';
    });

    document.addEventListener('mouseup', () => {
      isDrag = false;
    });
  </script>
</body>
</html>
```

## 核心变量说明

- `clientX / clientY`：鼠标相对于**视口**坐标
- `offsetLeft / offsetTop`：元素相对于定位父级的位置
- `offsetX、offsetY`：保存鼠标在盒子内部的点击点，实现点哪拖哪，不会自动跳到左上角

## Vue3 版本（组合式API）

```
<template>
  <div
    ref="dragRef"
    class="drag-box"
    @mousedown="onMouseDown"
  ></div>
</template>

<script setup>
import { ref } from 'vue'
const dragRef = ref(null)
let isDrag = false
let offsetX = 0, offsetY = 0

const onMouseDown = (e) => {
  isDrag = true
  offsetX = e.clientX - dragRef.value.offsetLeft
  offsetY = e.clientY - dragRef.value.offsetTop
  document.addEventListener('mousemove', onMouseMove)
  document.addEventListener('mouseup', onMouseUp)
}

const onMouseMove = (e) => {
  if (!isDrag) return
  const x = e.clientX - offsetX
  const y = e.clientY - offsetY
  dragRef.value.style.left = `${x}px`
  dragRef.value.style.top = `${y}px`
}

const onMouseUp = () => {
  isDrag = false
  document.removeEventListener('mousemove', onMouseMove)
  document.removeEventListener('mouseup', onMouseUp)
}
</script>

<style scoped>
.drag-box {
  width:120px;
  height:120px;
  background:#67c23a;
  position:absolute;
  left:100px;
  top:100px;
  cursor:move;
}
</style>
```

## 边界限制（不让拖出屏幕）

在 `mousemove` 里增加边界判断：

```
const maxX = window.innerWidth - box.offsetWidth
const maxY = window.innerHeight - box.offsetHeight
let x = e.clientX - offsetX
let y = e.clientY - offsetY
x = Math.max(0, Math.min(x, maxX))
y = Math.max(0, Math.min(y, maxY))
box.style.left = x + 'px'
box.style.top = y + 'px'
```

## HTML5 原生拖拽 API（drag‑drop）

适合**元素之间拖拽交换**，不是自由拖动位置：
事件：`dragstart`、`drag`、`dragend`、`dragover`、`drop`

> 区别：
>
> - mousedown+mousemove：自由拖拽移动浮层弹窗
> - HTML5 drag：列表拖拽排序、跨容器投放
