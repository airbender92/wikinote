# 划词选中文本，自定义右键菜单

需求：鼠标**鼠标拖动选中一段文字（划词）**，右键点击选中区域，弹出自定义右键菜单，做复制、高亮、翻译等操作。

关键点：

1. 获取用户鼠标划词选中的文本：`window.getSelection()`
2. 拦截浏览器原生右键菜单：监听 `contextmenu` 事件，`e.preventDefault()`
3. 判断：**是否真的选中文本**（selection不为空），只有选中文字才展示自定义菜单
4. 菜单定位：用鼠标点击坐标 `e.clientX / e.clientY` 放置浮层
5. 点击空白、选中文本消失时，关闭菜单

> 注意：`getSelection()` 获取选中内容；`selection.toString()` 获取选中文字。

## 完整原生JS示例

```
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>划词自定义右键菜单</title>
  <style>
    body {
      padding: 30px;
      font-size:16px;
    }
    /* 自定义右键菜单 */
    .custom-menu {
      position: fixed;
      width:140px;
      background:#fff;
      border:1px solid #ccc;
      box-shadow: 0 2px 12px rgba(0,0,0,0.15);
      z-index:9999;
      display:none;
    }
    .custom-menu div {
      padding:8px 12px;
      cursor:pointer;
    }
    .custom-menu div:hover {
      background:#f5f5f5;
    }
  </style>
</head>
<body>
<div id="content">
这里是测试文本，你可以鼠标拖动选中这里任意一段文字，然后点击鼠标右键，唤起自定义菜单。
测试划词选中，选中我，右键。
</div>

<!-- 自定义右键菜单浮层 -->
<div class="custom-menu" id="menu">
  <div data-action="copy">复制选中文字</div>
  <div data-action="upper">转大写</div>
  <div data-action="translate">翻译选中内容</div>
</div>

<script>
const menuDom = document.getElementById('menu')
let selectText = ''

// 监听右键事件
document.addEventListener('contextmenu', async (e) => {
  // 获取页面选中对象
  const selection = window.getSelection()
  selectText = selection.toString().trim()

  // ✅没有选中文字：走浏览器原生右键，不拦截
  if (!selectText) {
    menuDom.style.display = 'none'
    return
  }

  // 有选中文字，阻止浏览器原生右键菜单
  e.preventDefault()

  // 定位菜单，鼠标点击位置
  let x = e.clientX
  let y = e.clientY

  // 边界判断：防止菜单超出视口
  const menuRect = menuDom.getBoundingClientRect()
  if(x + menuRect.width > window.innerWidth) {
    x = window.innerWidth - menuRect.width
  }
  if(y + menuRect.height > window.innerHeight) {
    y = window.innerHeight - menuRect.height
  }

  menuDom.style.left = x + 'px'
  menuDom.style.top = y + 'px'
  menuDom.style.display = 'block'
})

// 菜单点击事件
menuDom.addEventListener('click', async (e) => {
  const action = e.target.dataset.action
  if(!action) return

  switch(action){
    case 'copy':
      // 复制选中文本
      await navigator.clipboard.writeText(selectText)
      alert('已复制：' + selectText)
      break
    case 'upper':
      alert('转大写：' + selectText.toUpperCase())
      break
    case 'translate':
      alert('准备翻译：' + selectText)
      break
  }
  // 操作完成关闭菜单
  menuDom.style.display = 'none'
})

// 点击页面任意空白，关闭菜单
document.addEventListener('mousedown', (e) => {
  if(!menuDom.contains(e.target)){
    menuDom.style.display = 'none'
  }
})

// 选中文本取消的时候，关闭菜单
document.addEventListener('selectionchange', ()=>{
  const sel = window.getSelection().toString().trim()
  if(!sel){
    menuDom.style.display = 'none'
  }
})
</script>
</body>
</html>
```

## 核心API说明

1. **`window.getSelection()`**
   返回 Selection 对象，代表用户页面划词选中范围。

- `.toString()` 获取选中的纯文本
- `selection.rangeCount` 选中范围数量
- `selection.removeAllRanges()` 取消选中

2. **`contextmenu` 事件**
   鼠标右键触发；`e.preventDefault()` 阻止浏览器原生右键菜单。
3. **`selectionchange` 事件✨****选中状态变化触发**：鼠标取消划词、点击空白，选中消失，触发这个事件，可以用来关闭菜单。

## 两种交互模式区分

1. 上面代码：**划词选中文字 → 右键弹出菜单**（你当前需求）
2. 另一种常见：**划词选中文字立刻悬浮弹出小工具栏（不需要右键）**，监听 `selectionchange` 判断选中文本非空，直接展示悬浮按钮。

## Vue3简易封装版本

```
<template>
  <div>
    <div>测试文本，拖动选中文字右键</div>
    <div v-show="showMenu" class="menu" :style="menuStyle">
      <div @click="handleCopy">复制</div>
      <div @click="handleTest">处理文本</div>
    </div>
  </div>
</template>

<script setup>
import {ref, reactive, onMounted, onUnmounted} from 'vue'
const showMenu = ref(false)
const menuStyle = reactive({left:'0px', top:'0px'})
let selectText = ref('')

function onContextMenu(e){
  const sel = window.getSelection()
  const text = sel.toString().trim()
  selectText.value = text
  if(!text){
    showMenu.value = false
    return
  }
  e.preventDefault()
  menuStyle.left = e.clientX + 'px'
  menuStyle.top = e.clientY + 'px'
  showMenu.value = true
}

function onSelectionChange(){
  const text = window.getSelection().toString().trim()
  if(!text) showMenu.value = false
}

function onMouseDown(e){
  // 点击外部关闭菜单
}

function handleCopy(){
  navigator.clipboard.writeText(selectText.value)
  showMenu.value = false
}

onMounted(()=>{
  document.addEventListener('contextmenu', onContextMenu)
  document.addEventListener('selectionchange', onSelectionChange)
})

onUnmounted(()=>{
  document.removeEventListener('contextmenu', onContextMenu)
  document.removeEventListener('selectionchange', onSelectionChange)
})
</script>

<style scoped>
.menu {
  position:fixed;
  z-index:9999;
  background:#fff;
  border:1px solid #eee;
}
</style>
```

## ⚠️业务坑点

1. **input / textarea 内部选中文本**：`getSelection()` 拿不到输入框选中文字。
   输入框要拿选中文字需要：`input.selectionStart / selectionEnd` 单独处理。

> getSelection 拿的是**文档DOM选区**，不是表单内部选区。

2. 菜单边界：一定要判断视口边界，避免菜单跑到屏幕外看不见。
3. 安全：`navigator.clipboard` 只能在 http(s) 环境，本地file协议不生效。
4. `selectionchange` 高频触发，复杂逻辑建议加防抖。
5. iframe内部文本：父页面拿不到iframe里面选区，需要在iframe内部单独监听。

如果你不仅仅要文本，还需要拿到选中的DOM节点、位置、甚至高亮选中文字：

}
