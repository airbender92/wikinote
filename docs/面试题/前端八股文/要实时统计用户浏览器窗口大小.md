# 实时统计浏览器窗口大小

窗口大小两个概念要分清：

1. **`window.innerWidth / innerHeight`**：**视口大小**（包含滚动条，页面可视区域，业务最常用）
2. **`document.documentElement.clientWidth / clientHeight`**：视口，**不含滚动条**
3. `window.outerWidth / outerHeight`：整个浏览器窗口（包含标题栏、边框，几乎业务不用）

> 监听窗口变化事件：`window.resize`；也可以用 `ResizeObserver` 监听 `document.documentElement`。

## 方案1：window.resize 事件（最常用）

resize 事件**触发非常频繁**，浏览器拖动窗口时会高频执行，**一定要加防抖**，否则性能差。

```
// 获取当前视口大小
function getViewportSize() {
  return {
    width: window.innerWidth,
    height: window.innerHeight
  }
}

let timer = null
// 带防抖监听窗口变化
window.addEventListener('resize', () => {
  clearTimeout(timer)
  timer = setTimeout(() => {
    const size = getViewportSize()
    console.log('窗口尺寸变化：', size.width, size.height)
    // 这里做业务：上报、调整布局、重绘图表等
  }, 100)
})

// 组件销毁记得移除监听
// window.removeEventListener('resize', handler)
```

> 注意：resize 事件回调不能直接写业务逻辑，拖动窗口会几十毫秒触发一次，会造成大量重排重绘。防抖延迟一般 50‑150ms。

## 方案2：ResizeObserver 监听根元素 html（备选）

也可以监听 `document.documentElement`，也能拿到视口尺寸。
优势：回调批次合并，性能略好；缺点：为了窗口大小一般没必要，resize事件更直观。

```
const ro = new ResizeObserver((entries) => {
  const { width, height } = entries[0].contentRect
  console.log('视口', width, height)
})
ro.observe(document.documentElement)

// 销毁 ro.disconnect()
```

## Vue3 Hook 封装（开箱即用）

```
<script setup>
import { ref, onMounted, onUnmounted } from 'vue'

const viewportWidth = ref(0)
const viewportHeight = ref(0)
let timer = null

function updateSize() {
  viewportWidth.value = window.innerWidth
  viewportHeight.value = window.innerHeight
}

function onResize() {
  clearTimeout(timer)
  timer = setTimeout(updateSize, 100)
}

onMounted(() => {
  updateSize() // 初始化拿一次
  window.addEventListener('resize', onResize)
})

onUnmounted(() => {
  window.removeEventListener('resize', onResize)
  clearTimeout(timer)
})
</script>

<template>
  <div>窗口宽：{{ viewportWidth }}，高：{{ viewportHeight }}</div>
</template>
```

## 上报场景：采集用户窗口尺寸

结合之前性能上报，可以在页面、resize变化时采集，用 `sendBeacon` 上报。

```
// 上报窗口尺寸
function reportViewport() {
  const data = {
    viewportWidth: window.innerWidth,
    viewportHeight: window.innerHeight,
    devicePixelRatio: window.devicePixelRatio // 设备像素比
  }
  navigator.sendBeacon('/api/report-viewport', JSON.stringify(data))
}
```

## 关键坑点

1. **resize 高频触发，必须防抖**，不要在回调里面做大量DOM操作。
2. `innerWidth` 包含滚动条；`clientWidth` 不包含滚动条，根据业务选择。
3. 移动端旋转屏幕也会触发 resize 事件。
4. 组件销毁**务必要 removeEventListener**，否则内存泄漏，重复执行回调。
5. 初始化页面一定要手动调用一次获取初始尺寸，resize事件只有变化才触发。

## 三者对比

| 方式                                     | 用途                                     |
| ---------------------------------------- | ---------------------------------------- |
| window.resize                            | 监听浏览器视口窗口变化，统计窗口大小首选 |
| ResizeObserver(document.documentElement) | 也能监听视口，适合统一Observer体系       |
| ResizeObserver(某个dom)                  | 监听**普通DOM盒子**尺寸，不是浏览器窗口  |
