# 判断浏览器页签是否活跃

> 页签活跃：用户当前正在看这个标签页；失活：切到别的标签、最小化浏览器。

## API：`document.visibilityState`

- `visible`：页签可见、活跃
- `hidden`：页签隐藏（切页、最小化）

配合事件：`visibilitychange`，页签可见状态切换时触发。

### 完整示例

```
// 获取当前状态
function isTabActive() {
  return document.visibilityState === 'visible';
}

// 监听页签切换事件
document.addEventListener('visibilitychange', () => {
  if (document.visibilityState === 'visible') {
    console.log('页签激活，回到页面');
  } else {
    console.log('页签失活，切走/最小化');
  }
});

// 使用
console.log(isTabActive());
```

## 旧API（不推荐）

`document.hidden` 布尔值，已经逐步废弃，优先用 `visibilityState`。

## 和 `window.onblur` 的区别

- `visibilitychange`：**真正检测页签是否可见**，切其他标签页会触发；窗口只是失去焦点（弹窗弹出）不会变成 hidden。
- `window.blur / focus`：只是窗口焦点，弹出弹窗、点别的窗口就会blur，但页签本身还是可见。

> 想要判断用户有没有在看页面：用 `visibilitychange`；想要判断窗口是否获得焦点：用 `window.focus/blur`。

## Vue3 简单封装示例

```
<script setup>
import { onMounted, onUnmounted, ref } from 'vue'

const isActive = ref(true)

function handleVisibility() {
  isActive.value = document.visibilityState === 'visible'
}

onMounted(() => {
  document.addEventListener('visibilitychange', handleVisibility)
})

onUnmounted(() => {
  document.removeEventListener('visibilitychange', handleVisibility)
})
</script>
```

# 页签失活 ≠ 组件卸载

**`visibilitychange` 只是浏览器标签页可见性变化，Vue/React 组件完全还在内存里，不会销毁，不会执行 `onUnmounted / useEffect cleanup`。**

- 页签切走：`visibilityState = hidden` → **组件保留，内存还在，定时器、请求还在跑**
- 关闭页签：页面销毁 → 才会触发组件卸载、beforeunload

这是非常容易踩坑的点：切后台页签，组件依旧存活，定时器、轮询、websocket、动画继续执行，浪费性能。

## 两种状态区分

| 场景                   | visibilityState | 组件是否卸载 |
| ---------------------- | --------------- | ------------ |
| 当前页签打开，正在浏览 | visible         | 存活         |
| 切到其他浏览器页签     | hidden          | ✅ 仍然存活  |
| 浏览器窗口最小化       | hidden          | ✅ 仍然存活  |
| 弹窗盖住页面           | visible         | ✅ 仍然存活  |
| 关闭标签页/刷新页面    | beforeunload    | ❌ 组件销毁  |

## 业务常见处理方案（Vue3）

需求：**页签失活暂停轮询；页签重新激活恢复轮询；只有组件真正卸载才彻底销毁定时器**

```
<script setup>
import { ref, onMounted, onUnmounted } from 'vue'

const isTabVisible = ref(true)
let timer = null

// 页签可见性变化：只是暂停/恢复，不销毁定时器实例
const onVisibilityChange = () => {
  isTabVisible.value = document.visibilityState === 'visible'
  if (isTabVisible.value) {
    console.log('页签激活，恢复轮询')
    startPoll()
  } else {
    console.log('页签失活，暂停轮询')
    stopPoll()
  }
}

const startPoll = () => {
  stopPoll()
  timer = setInterval(() => {
    console.log('轮询请求')
  }, 2000)
}

const stopPoll = () => {
  if (timer) {
    clearInterval(timer)
    timer = null
  }
}

onMounted(() => {
  document.addEventListener('visibilitychange', onVisibilityChange)
  startPoll()
})

// 组件真正卸载：清除事件监听 + 销毁定时器
onUnmounted(() => {
  document.removeEventListener('visibilitychange', onVisibilityChange)
  stopPoll()
})
</script>
```

> 关键点：
>
> 1. `visibilitychange` 回调里**只做暂停、恢复，不要去销毁解绑事件**；事件监听要放到组件生命周期 `onMounted / onUnmounted` 中管理。
> 2. 切后台只是隐藏，组件还在内存，所以定时器只 clearInterval，不要 removeEventListener。
> 3. 只有组件卸载，才 removeEventListener，彻底释放。

## 容易踩的错误写法 ❌

```
// 错误！页签一切走就移除监听，切回来再也收不到事件
document.addEventListener('visibilitychange', () => {
  if(document.visibilityState === 'hidden'){
```

## 补充：如何区分【页签失活】和【组件卸载】

- 页签失活：触发 `visibilitychange(hidden)`，**不会执行 onUnmounted**
- 组件卸载：执行 `onUnmounted`，但**不会触发 visibilitychange**（除非同时关闭页签）
