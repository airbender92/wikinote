# 长文本溢出 展开/收起实现方案

常见两种方案：**CSS纯CSS方案（简单，有局限）**、**JS方案（可控，最常用）**，以最多展示3行举例。

## 一、纯 CSS 实现（适合简单场景）

> 优点：不用JS；缺点：无法判断文本是否真的溢出，不管长短都会显示展开按钮。

```
<div class="text-wrap">
  <input type="checkbox" id="expand">
  <div class="content">
    这里放很长很长的文本，超过3行就会截断。这里放很长很长的文本，超过3行就会截断。这里放很长很长的文本，超过3行就会截断。这里放很长很长的文本，超过3行就会截断。
  </div>
  <label for="expand" class="btn">展开</label>
</div>
```

```
.text-wrap {
  position: relative;
}
.content {
  display: -webkit-box;
  -webkit-line-clamp: 3; /* 显示行数 */
  -webkit-box-orient: vertical;
  overflow: hidden;
}
/* checkbox选中，取消行数限制 */
#expand:checked ~ .content {
  display: block;
}
#expand:checked ~ .btn::after {
  content: "收起";
}
.btn {
  color: #409eff;
  cursor: pointer;
}
.btn::after {
  content: "展开";
}
/* 隐藏checkbox */
#expand {
  display: none;
}
```

## 二、JS实现（生产推荐 ✅）

特点：**只有文本真正溢出的时候，才显示【展开/收起】按钮；文本很短，直接不显示按钮**。
原理：对比 `scrollHeight` 和 `clientHeight`，判断内容是否被截断。

### Vue3 示例

```
<template>
  <div class="text-container">
    <div ref="textRef" :class="{'text-clamp': !isExpand}">{{ text }}</div>
    <button v-if="showBtn" @click="isExpand = !isExpand" class="expand-btn">
      {{ isExpand ? '收起' : '展开' }}
    </button>
  </div>
</template>

<script setup>
import { ref, onMounted, watch } from 'vue'
const textRef = ref(null)
const isExpand = ref(false)
const showBtn = ref(false)
const text = ref('很长很长的文本......')

function checkOverflow() {
  const el = textRef.value
  if (!el) return
  // scrollHeight > clientHeight 代表内容溢出
  showBtn.value = el.scrollHeight > el.clientHeight
}

onMounted(()=>{
  checkOverflow()
})
// 如果text会动态变化，监听文本变化
watch(text, ()=>{
  isExpand.value = false
  setTimeout(checkOverflow,0)
})
</script>

<style scoped>
.text-clamp {
  display: -webkit-box;
  -webkit-line-clamp: 3;
  -webkit-box-orient: vertical;
  overflow: hidden;
}
.expand-btn {
  color:#409eff;
  border:none;
  background:none;
  cursor:pointer;
  margin-top:4px;
}
</style>
```

### 原生JS版本

```
<div class="box">
  <div class="text" id="txt">
    很长很长的文本......很长很长的文本......很长很长的文本......
  </div>
  <button id="btn" style="display:none">展开</button>
</div>

<style>
.text{
  display: -webkit-box;
  -webkit-line-clamp:3;
  -webkit-box-orient:vertical;
  overflow:hidden;
}
.text.all{
  display:block;
}
</style>

<script>
const txt = document.querySelector('#txt')
const btn = document.querySelector('#btn')
let expand = false

// 判断溢出
if(txt.scrollHeight > txt.clientHeight){
  btn.style.display = 'block'
}

btn.onclick = function(){
  expand = !expand
  if(expand){
    txt.classList.add('all')
    btn.innerText = '收起'
  }else{
    txt.classList.remove('all')
    btn.innerText = '展开'
  }
}
</script>
```

## 三、关键坑点

1. `-webkit-line-clamp` 只对 `display:-webkit-box`生效；收起状态用这个，展开要改成 `display:block`。
2. **动态文本**：数据异步回来后，要等DOM渲染完成再执行判断（nextTick / setTimeout），否则 `scrollHeight` 获取不准。
3. 行高、padding、字体大小会影响高度判断。
4. 部分旧浏览器兼容性，`-webkit-line-clamp` 是webkit私有属性，现代浏览器全部支持。

## 四、两种方案对比

| 方案                | 优点                     | 缺点                                 | 适用场景       |
| ------------------- | ------------------------ | ------------------------------------ | -------------- |
| 纯CSS checkbox      | 零JS，简单               | 无法检测真实溢出，短文本也会出现按钮 | 静态简单页面   |
| JS scrollHeight判断 | 精准，只有溢出才显示按钮 | 需要写JS逻辑                         | 业务项目，推荐 |
