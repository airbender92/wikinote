# 如何判断用户设备

# JS 判断用户设备类型

前端判断设备，主要通过 **`navigator.userAgent`**、`navigator.platform`、`window.screen`、`window.matchMedia` 实现；userAgent可以被篡改，只能做**业务层兼容，不能做安全校验**。

## 一、常用设备区分：手机 / 平板 / PC

### 1. 正则版（userAgent）

```javascript
/**
 * 判断设备类型
 * @returns {string} pc | mobile | tablet
 */
function getDeviceType() {
  const ua = navigator.userAgent.toLowerCase();
  const isMobile =
    /android|webos|iphone|ipod|blackberry|iemobile|opera mini/.test(ua);
  const isTablet = /ipad|android(?!.*mobile)/.test(ua);

  if (isTablet) return "tablet";
  if (isMobile) return "mobile";
  return "pc";
}

console.log(getDeviceType());
```

> 注意：iPad 新版Safari的userAgent伪装成Mac，UA判断会失效，需要额外判断触摸点：`navigator.maxTouchPoints > 1`

### 2. 媒体查询 matchMedia（推荐，优先用这个）

根据视口判断，更偏向布局适配，不受UA篡改影响：

```javascript
function isMobileByMedia() {
  // 768px 是常见移动端断点，可自定义
  return window.matchMedia("(max-width: 767px)").matches;
}

function isTabletByMedia() {
  return window.matchMedia("(min-width:768px) and (max-width:1024px)").matches;
}

console.log(isMobileByMedia() ? "手机" : "非手机");
```

## 二、判断操作系统：安卓 / iOS / Mac / Windows

```javascript
function getOS() {
  const ua = navigator.userAgent.toLowerCase();
  if (/iphone|ipad|ipod/.test(ua)) return "ios";
  if (/android/.test(ua)) return "android";
  if (/win/.test(ua)) return "windows";
  if (/mac/.test(ua)) return "mac";
  if (/linux/.test(ua)) return "linux";
  return "unknown";
}
```

### 新版iPad坑点

M系列 iPad，Safari UA输出Macintosh，此时要结合触摸点：

```javascript
const isIOS =
  /iphone|ipod/.test(navigator.userAgent.toLowerCase()) ||
  (navigator.platform === "MacIntel" && navigator.maxTouchPoints > 1);
```

## 三、判断浏览器

```javascript
function getBrowser() {
  const ua = navigator.userAgent;
  if (/Edg/.test(ua)) return "edge";
  if (/Chrome/.test(ua) && !/Edg/.test(ua)) return "chrome";
  if (/Firefox/.test(ua)) return "firefox";
  if (/Safari/.test(ua) && !/Chrome/.test(ua)) return "safari";
  if (/MSIE|Trident/.test(ua)) return "ie";
  return "unknown";
}
```

## 四、完整工具函数（整合）

```javascript
const DeviceUtil = {
  ua: navigator.userAgent.toLowerCase(),

  // 是否移动端
  isMobile() {
    return /android|webos|iphone|ipod|blackberry|iemobile|opera mini/.test(
      this.ua,
    );
  },

  // 是否平板
  isTablet() {
    return (
      /ipad|android(?!.*mobile)/.test(this.ua) ||
      (navigator.platform === "MacIntel" &&
        navigator.maxTouchPoints > 1 &&
        !this.isMobile())
    );
  },

  // 是否PC
  isPc() {
    return !this.isMobile() && !this.isTablet();
  },

  isIOS() {
    return (
      /iphone|ipad|ipod/.test(this.ua) ||
      (navigator.platform === "MacIntel" && navigator.maxTouchPoints > 1)
    );
  },

  isAndroid() {
    return /android/.test(this.ua);
  },

  // 是否触屏设备
  isTouchDevice() {
    return "ontouchstart" in window || navigator.maxTouchPoints > 0;
  },
};

// 使用
console.log(DeviceUtil.isMobile());
console.log(DeviceUtil.isIOS());
```

## 六、重要注意事项

1. **userAgent可以被浏览器插件、调试工具篡改，不能用于鉴权、安全校验，只做UI/业务适配**
2. iPad M系列芯片UA伪装Mac，**必须搭配 `maxTouchPoints` 判断**
3. 做响应式布局优先使用 `matchMedia` / CSS媒体查询，不要过度依赖JS UA判断
4. 小程序、WebView环境UA会追加自定义标识，可以额外判断

## 七、CSS层面判断设备（不需要JS）

```css
/* 移动端 */
@media (max-width: 767px) {
}
/* 平板 */
@media (min-width: 768px) and (max-width: 1024px) {
}
/* PC */
@media (min-width: 1025px) {
}
```
