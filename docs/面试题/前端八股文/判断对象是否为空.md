# 判断对象是否为空（包含检查原型链自定义属性/方法）

> 需求：不仅看对象自身属性，**还要检查原型链上有没有自定义的数据、方法**；只要原型链上存在自定义可枚举属性，就认为对象不为空。

先区分几个概念：

1. `{}` 字面量，原型是 `Object.prototype`；
2. 原型链上分为：**内置原生属性**（如 `toString`、`hasOwnProperty`）和**用户自定义添加的属性/方法**；
3. 我们目标：忽略 JS 原生内置原型成员，**只要原型链上存在用户自定义新增属性/方法，判定不为空**。

## 1. 常用错误方案（只能检查自身属性，不查原型）

```js
// ❌只检查对象自身，不会遍历原型链
Object.keys(obj).length === 0;
Object.getOwnPropertyNames(obj).length === 0;
JSON.stringify(obj) === "{}";
```

以上只会看对象**自身属性**，原型链上有自定义属性检测不到。

示例：

```js
function Person() {}
Person.prototype.foo = function () {}; // 原型上自定义方法
const p = new Person();

console.log(Object.keys(p).length); // 0，自身无属性；但原型有自定义foo，对象逻辑上不为空
```

## 2. for...in 遍历原型链（会遍历可枚举属性）

`for...in` 会遍历**自身 + 原型链上所有可枚举属性**，**跳过不可枚举内置属性**（原生 `toString` 等是不可枚举，不会出来）。

> ✔原生内置原型方法：`Object.prototype.toString` 是 `enumerable:false`，`for...in` 不会遍历；
> ✔用户手动给原型添加的属性/方法默认 `enumerable:true`，`for...in` 可以捕获。

### 实现函数

```js
/**
 * 判断对象是否为空
 * 自身无属性，并且原型链上没有【自定义可枚举属性/方法】返回true（为空）
 * 忽略JS原生内置原型成员
 * @param {object} obj
 * @returns {boolean} true为空；false不为空
 */
function isObjectEmpty(obj) {
  if (obj === null || typeof obj !== "object") return true;

  for (const key in obj) {
    // 只要for...in能循环到key，说明自身或者原型链存在自定义可枚举成员 → 对象不为空
    return false;
  }
  return true;
}
```

测试案例：

```js
// case1：纯空对象
const o1 = {};
console.log(isObjectEmpty(o1)); // true

// case2：自身有属性
const o2 = { a: 1 };
console.log(isObjectEmpty(o2)); // false

// case3：原型上自定义方法
function Person() {}
Person.prototype.foo = function () {};
const p = new Person();
console.log(isObjectEmpty(p)); // false ✔识别原型自定义方法

// case4：原生原型，无自定义扩展
const o3 = new Object();
console.log(isObjectEmpty(o3)); // true

// case5：原型上设置可枚举属性
Object.prototype.myProp = 123;
const o4 = {};
console.log(isObjectEmpty(o4)); // false ✔捕获原型链自定义属性
```

> 注意：`for...in` **只会遍历可枚举(enumerable:true)属性**。
> 如果用户给原型添加属性时手动设置 `enumerable:false`，`for...in` 发现不了。

```js
// 极端边界：原型定义不可枚举自定义属性
Object.defineProperty(Object.prototype, "hidden", {
  value: 999,
  enumerable: false,
});
const obj = {};
isObjectEmpty(obj); // true；for‑in无法发现这个不可枚举自定义成员
```

## 3. 极端完整版：连原型链上【不可枚举自定义属性】也检测

> 业务极少用到，但如果要极致严谨：沿着原型链逐层，用 `Object.getOwnPropertyNames()` / `Object.getOwnPropertySymbols()` 获取该原型全部属性（包含不可枚举），区分哪些是原生自带，哪些是用户新增。

思路：

1. 循环向上遍历原型链 `Object.getPrototypeOf(obj)`，直到 `null`；
2. 每一层原型拿到全部 own 属性名、Symbol；
3. 和**原生干净原型白名单对比**，如果出现不在原生白名单中的key，说明是用户自定义扩展，返回不为空。

```js
/**
 * 极致完整：检测自身 + 整条原型链，包含可枚举、不可枚举自定义属性/Symbol
 * 忽略JS原生内置成员
 * @param {any} obj
 * @returns {boolean} true为空
 */
function isObjectFullEmpty(obj) {
  if (obj === null || typeof obj !== "object") return true;

  let proto = obj;
  while (proto !== null) {
    // 获取当前原型层所有属性（含不可枚举）
    const keys = Object.getOwnPropertyNames(proto);
    const symbols = Object.getOwnPropertySymbols(proto);

    // 判断是否是原生Object.prototype
    const isNativeObjectProto = proto === Object.prototype;
    const isNativeArrayProto = proto === Array.prototype;

    for (const k of keys) {
      // 原生原型的内置成员放过；其余全部判定为用户自定义
      if (isNativeObjectProto || isNativeArrayProto) {
        // 原生原型白名单，跳过JS内置方法属性
        const nativeKeys = [
          "constructor",
          "__proto__",
          "toString",
          "toLocaleString",
          "valueOf",
          "hasOwnProperty",
          "isPrototypeOf",
          "propertyIsEnumerable",
        ];
        if (!nativeKeys.includes(k)) {
          return false;
        }
      } else {
        // 非原生内置原型，出现任何own属性，都视为用户自定义
        return false;
      }
    }
    if (symbols.length > 0) return false;

    proto = Object.getPrototypeOf(proto);
  }
  return true;
}
```

> ⚠️这个版本很重，**普通业务不要直接用**，绝大多数业务场景用 `for...in` 版本足够。

## 4. 各个方案对比总结

| 方案                               | 检查自身属性 | 检查原型链可枚举自定义 | 检查原型链不可枚举自定义 |
| ---------------------------------- | ------------ | ---------------------- | ------------------------ |
| `Object.keys(obj).length===0`      | ✅           | ❌                     | ❌                       |
| `JSON.stringify(obj)==='{}'`       | ✅           | ❌                     | ❌                       |
| `for...in`循环                     | ✅           | ✅                     | ❌                       |
| 逐层遍历原型链+getOwnPropertyNames | ✅           | ✅                     | ✅                       |

## 业务选型建议

1. **99%业务场景：使用 `for...in` 版本**
   绝大多数自定义原型扩展都会设置为可枚举；原生内置不可枚举方法不会干扰判断。

```js
function isEmpty(obj) {
  if (obj === null || typeof obj !== "object") return true;
  for (const k in obj) return false;
  return true;
}
```

2. 注意坑：

- `for...in` 会跳过不可枚举属性；
- 不要用 `JSON.stringify`，原型链属性不会被序列化；
- 不要用 `Object.keys`，不访问原型链；
- `null`、基础类型要提前做判断。

## 面试简答

> 如果需要同时检查对象自身以及原型链上的自定义可枚举属性，使用 **`for...in`**；它会遍历自身和原型链可枚举属性，JS原生内置原型方法不可枚举不会被遍历出来。
> 如果循环能进入，代表存在自定义成员，对象不为空。
> 如果需要检测原型链上不可枚举自定义属性，需要向上遍历原型链，使用 `Object.getOwnPropertyNames` 获取每层全部属性，排除原生内置成员做判断。
