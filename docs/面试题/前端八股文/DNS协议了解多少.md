# DNS 协议

DNS（Domain Name System，域名系统），**作用：把域名(www.baidu.com)翻译成IP地址**，计算机网络七层属于**应用层协议**，底层传输默认使用 **UDP 53端口**，大报文/区域传输用 TCP 53。

> 记忆：人记域名，机器认IP，DNS做二者映射。

## 两种查询方式

### 1. 递归查询（客户端→本地DNS服务器）

浏览器/操作系统向本地DNS服务器发请求，**本地DNS服务器全权负责把最终结果返回给客户端**，客户端不用再继续查其他服务器。

> 我们电脑配置的DNS(114.114.114.114、8.8.8.8)就是递归服务器。

### 2. 迭代查询（本地DNS → 根、顶级域、权威服务器）

本地DNS服务器向根服务器查询，根不会给最终IP，只会告诉你：去问顶级域名服务器；
本地再去问顶级域，顶级域告诉你去问权威服务器；
本地再查询权威服务器，拿到真实IP。

> 每一步返回下一台服务器地址，由本地DNS继续发起请求。

**完整域名解析流程（面试高频）**

1. 浏览器先查**浏览器DNS缓存**，有就直接用
2. 没有，查操作系统hosts文件（`C:\Windows\System32\drivers\etc\hosts`）
3. 都没有，向**本地DNS服务器**发起递归查询（UDP 53）
4. 本地DNS先查自己缓存；缓存失效，则开始迭代查询：
   1. 访问**根域名服务器** → 返回 `.com` 顶级域服务器地址
   2. 访问**.com顶级域名服务器** → 返回 baidu.com 的权威域名服务器地址
   3. 访问**baidu.com权威域名服务器** → 返回 www.baidu.com 对应的IP
5. 本地DNS把IP返回浏览器，同时存入自己缓存
6. 浏览器拿到IP，发起TCP三次握手建立连接

> 注意：根服务器不会直接返回业务IP，只返回下一级服务器地址。

## DNS报文结构

DNS报文不分请求、响应，同一个格式，通过标识位区分；分为：

1. **头部**：标识ID、标志位（递归、迭代、响应码）、问题数、回答数、授权数、附加数
2. **问题段**：要查询的域名、查询类型、查询类
3. **回答段**：返回的资源记录（IP等）
4. **授权段**：权威服务器信息
5. **附加段**：额外辅助信息

## 常见DNS记录类型（RR资源记录）

| 类型     | 作用                                             |
| -------- | ------------------------------------------------ |
| A记录    | 域名 → IPv4地址                                  |
| AAAA记录 | 域名 → IPv6地址                                  |
| CNAME    | 别名，域名指向另一个域名（www指向xxx.a.dns.com） |
| MX       | 邮件交换记录，邮箱服务器                         |
| NS       | 域名的权威域名服务器                             |
| TXT      | 文本记录，域名验证、SPF防垃圾邮件                |

## 缓存机制

各级都有缓存，TTL（Time‑To‑Live）生存时间，单位秒，TTL到期缓存失效：

1. 浏览器缓存
2. OS操作系统缓存
3. 本地DNS服务器缓存

> TTL是权威服务器下发，告诉缓存服务器这条记录可以存多久。

## DNS 协议细节考点

1. **端口：UDP 53**；当DNS报文超过512字节，会改用TCP 53；主从服务器区域同步也用TCP。
2. DNS劫持：篡改DNS返回错误IP，跳转到钓鱼网站。
3. DNS污染：本地DNS收到伪造的虚假响应。
4. 解决方案：**DNS over HTTPS(DoH) / DNS over TLS(Dot)**，加密DNS查询，防止劫持污染。
   - DoH：走HTTPS 443端口，HTTPs协议封装DNS
   - DoT：TLS加密，TCP 853端口
5. hosts优先级高于DNS解析，可以强制指定域名IP。

## 面试经典问题

### Q：为什么DNS优先用UDP？

解析大多短报文，UDP无连接，开销小、速度快；不需要建立三次握手，域名解析追求低延迟。报文过大再切TCP。

### Q：递归和迭代区别？

- 递归：**我只问一次，你给我最终结果**（客户端 ↔ 本地DNS）
- 迭代：**我问你，你告诉我下一个找谁，我自己继续问**（本地DNS ↔ 根/顶级域/权威）

### Q：DNS用的是TCP还是UDP？

默认UDP53；报文>512字节、区域传输、DoT用TCP。
