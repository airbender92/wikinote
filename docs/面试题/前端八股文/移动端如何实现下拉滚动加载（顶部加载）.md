# 移动端 顶部下拉刷新（下拉加载）实现方案

> 需求：手指**往下拉页面顶部**，释放后触发刷新/加载数据；常见App、小程序下拉刷新。

实现分3种方案：

1. **原生CSS overscroll‑behavior + JS 自定义下拉刷新（纯Web，H5）** ✅ 最常用
2. 使用浏览器原生下拉刷新（Chrome meta标签）
3. 第三方库：better‑scroll、vant‑pullRefresh（业务快速开发）

> 关键点：移动端滚动坑点：`touchstart / touchmove / touchend`、阻止默认滚动、橡皮筋回弹、ios橡皮筋效果、滚动穿透。

## 原理简述

1. 监听 `touchstart` 记录手指初始Y坐标
2. `touchmove` 计算手指移动距离；**只有滚动条在最顶部 scrollTop === 0**，才允许下拉效果
3. 手指向下滑动，位移大于阈值，显示下拉loading提示
4. `touchend`：判断下拉距离，如果超过阈值，触发加载；然后回弹复位。

> ⚠️坑：iOS自带橡皮筋回弹（overscroll），页面拉到顶部继续下拉，页面会被拖下去，这是系统默认行为，需要处理。

## 方案1：原生手写H5下拉刷新（完整可运行）

```
<!DOCTYPE html>
<html lang="zh-CN">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<style>
*{margin:0;padding:0;box-sizing:border-box;}
body{
  background:#f5f5f5;
  /* 关闭浏览器原生下拉橡皮筋效果 */
  overscroll-behavior-y: contain;
}
.wrap{
  height:100vh;
  overflow-y:auto;
}
/* 下拉头部提示区域，默认向上偏移隐藏 */
.pull-header{
  height:60px;
  line-height:60px;
  text-align:center;
  color:#666;
  transform: translateY(-60px);
  transition: transform 0.2s ease;
}
/* 内容区域 */
.content{
  background:#fff;
}
.item{
  height:80px;
  border-bottom:1px solid #eee;
  padding:0 16px;
  line-height:80px;
}
</style>
</head>
<body>
<div class="wrap" id="wrap">
  <div class="pull-header" id="pullHeader">
    <span id="tip">下拉刷新</span>
  </div>
  <div class="content" id="content">
    <div class="item">列表数据1</div>
    <div class="item">列表数据2</div>
    <div class="item">列表数据3</div>
    <div class="item">列表数据4</div>
    <div class="item">列表数据5</div>
    <div class="item">列表数据6</div>
  </div>
</div>

<script>
const wrap = document.getElementById('wrap');
const pullHeader = document.getElementById('pullHeader');
const tip = document.getElementById('tip');

// 配置
const THRESHOLD = 80; // 触发刷新阈值，下拉超过80px释放就刷新
let startY = 0;
let isPulling = false; // 是否正在下拉手势
let isLoading = false; // 是否正在加载中

// touchstart：记录手指初始位置
wrap.addEventListener('touchstart', (e)=>{
  // 只有滚动在最顶部，才开启下拉
  if(wrap.scrollTop !== 0 || isLoading) return;
  startY = e.touches[0].clientY;
  isPulling = true;
})

wrap.addEventListener('touchmove', (e)=>{
  if(!isPulling || isLoading) return;
  const moveY = e.touches[0].clientY;
  const diff = moveY - startY;

  // 手指向下滑动 diff>0；小于0向上滑动直接忽略
  if(diff <= 0) return;

  // 阻尼系数：越往下拉动，位移放大倍率降低，模拟真实下拉阻尼手感
  const offset = Math.floor(diff * 0.5);

  // 设置头部偏移
  pullHeader.style.transform = `translateY(${offset - 60}px)`;

  if(offset > THRESHOLD){
    tip.innerText = '释放立即刷新';
  }else{
    tip.innerText = '下拉刷新';
  }
  // 禁止页面原生橡皮筋滚动
  e.preventDefault();
},{passive:false})

wrap.addEventListener('touchend', async ()=>{
  if(!isPulling) return;
  isPulling = false;

  // 获取当前下拉偏移
  const transform = pullHeader.style.transform;
  const match = transform.match(/translateY\((.+?)px\)/);
  const currentOffset = match ? Number(match[1]) + 60 : 0;

  // 判断是否达到刷新阈值
  if(currentOffset > THRESHOLD){
    // 进入加载状态
    isLoading = true;
    tip.innerText = '加载中...';
    pullHeader.style.transform = `translateY(0px)`;

    // ========== 这里执行你的加载请求 ==========
    await loadData();

    // 加载完成回弹复位
    reset();
  }else{
    // 没到阈值，直接回弹回去
    reset();
  }
})

// 重置状态
function reset(){
  pullHeader.style.transform = `translateY(-60px)`;
  tip.innerText = '下拉刷新';
  isLoading = false;
}

// 模拟异步加载数据
async function loadData(){
  return new Promise(resolve=>{
    setTimeout(()=>{
      // 模拟追加顶部数据
      const content = document.getElementById('content');
      const div = document.createElement('div');
      div.className='item';
      div.innerText = '【新拉取】'+Date.now();
      content.prepend(div);
      resolve(true);
    },1200)
  })
}
</script>
</body>
</html>
```

### 关键细节说明

1. `overscroll‑behavior‑y: contain;`
   禁止浏览器原生下拉橡皮筋，不然ios下拉会同时出现系统橡皮筋+自定义下拉两层效果。
2. `touchmove` 设置 `{passive:false}`，才能调用 `e.preventDefault()`；passive:true 下禁止调用preventDefault。
3. **阻尼系数 `diff *0.5`**：下拉越往下，移动距离增益变小，模拟App手感，不会越拉越长。
4. 必须判断 `wrap.scrollTop ===0`：只有滚动条在最顶端，才触发下拉；列表往下滚动时，下拉手势不生效。
5. `isLoading` 锁：加载中屏蔽手势，防止重复触发多次刷新。

## Vue3 简易封装版本

```
<template>
  <div class="pull-refresh-wrap" ref="wrapRef">
    <div class="pull-header" :style="headerStyle">
      {{ tipText }}
    </div>
    <div class="content">
      <slot></slot>
    </div>
  </div>
</template>

<script setup lang="ts">
import {ref, computed} from 'vue'
const wrapRef = ref<HTMLDivElement|null>(null)
const startY = ref(0)
const isPulling = ref(false)
const isLoading = ref(false)
const offsetY = ref(0)
const THRESHOLD = 80

const tipText = computed(()=>{
  if(isLoading.value) return '加载中...'
  if(offsetY.value > THRESHOLD) return '释放立即刷新'
  return '下拉刷新'
})

const headerStyle = computed(()=>{
  return {
    transform: `translateY(${ offsetY.value - 60 }px)`,
    transition: isPulling.value ? 'none' : 'transform 0.2s ease'
  }
})

const touchStart = (e: TouchEvent)=>{
  const wrap = wrapRef.value!
  if(wrap.scrollTop !==0 || isLoading.value) return
  startY.value = e.touches[0].clientY
  isPulling.value = true
}

const touchMove = (e: TouchEvent)=>{
  if(!isPulling.value || isLoading.value) return
  const moveY = e.touches[0].clientY
  const diff = moveY - startY.value
  if(diff <=0) return
  offsetY.value = Math.floor(diff * 0.5)
  e.preventDefault()
}

const touchEnd = async ()=>{
  if(!isPulling.value) return
  isPulling.value = false
  if(offsetY.value > THRESHOLD){
    isLoading.value = true
    // 触发父组件事件
    emit('refresh')
  }else{
    offsetY.value = 0
  }
}

// 对外暴露结束刷新方法
const finishRefresh = ()=>{
  offsetY.value = 0
  isLoading.value = false
}

const emit = defineEmits(['refresh'])
defineExpose({finishRefresh})
</script>

<style scoped>
.pull-refresh-wrap{
  height:100vh;
  overflow-y:auto;
  overscroll-behavior-y: contain;
}
.pull-header{
  height:60px;
  line-height:60px;
  text-align:center;
  color:#666;
}
</style>
```

使用组件：

```
<PullRefresh @refresh="onRefresh" ref="pull">
  <!-- 列表内容 -->
</PullRefresh>
```

```
const pull = ref()
async function onRefresh(){
  // 请求顶部数据
  await fetchNewData()
  pull.value.finishRefresh() //结束下拉，回弹
}
```

## 方案2：浏览器原生下拉刷新（Web Experiments）

> 仅部分安卓Chrome支持，iOS Safari不支持，不适合业务。

```
<meta name="viewport" content="width=device-width, initial-scale=1.0, pull-to-refresh=yes">
```

不推荐，兼容性差。

## 方案3：成熟库（业务项目优先）

1. **Vant PullRefresh**（Vue2/Vue3），开箱即用，处理了全部移动端坑，企业项目首选。

```
<van-pull-refresh v-model="loading" @refresh="onRefresh">
  <!-- 列表 -->
</van-pull-refresh>
```

2. better‑scroll：老牌滚动库，支持下拉刷新、上拉加载更多，但是需要处理DOM高度。

## 高频踩坑清单

1. ❌忘记 `passive:false`，`touchmove` 调用 `e.preventDefault()` 会报错，无法阻止原生橡皮筋。
2. ❌没有判断 `scrollTop ===0`，列表滚动到中间也能触发下拉。
3. ❌没有loading锁，用户反复下拉，并发请求。
4. iOS橡皮筋回弹：`overscroll‑behavior‑y:contain` 一定要加。
5. 回弹动画：**手势拖拽过程要关闭transition，touchend回弹再开transition**，不然拖拽会卡顿。
6. 页面有弹窗浮层：下拉事件要阻止冒泡，避免弹窗时触发下拉刷新。

## 补充区分

- **下拉刷新（顶部）**：上面代码，手指往下拉，加载**最新数据到列表头部**
- **上拉加载更多（底部）**：监听scroll事件，滚动到底部加载下一页数据
