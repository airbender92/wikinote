# 前端水印

> 场景：后台系统、数据大屏、涉密页面，水印一般携带**用户ID、用户名、时间**，作用：威慑、泄露之后溯源，**纯前端水印不能真正防截图、防录屏，只能提高移除成本**。

分为：**明水印（肉眼可见）、暗水印（盲水印，肉眼看不见，算法提取信息）**。

## 一、明水印4种实现方案

### 1. DOM平铺水印

创建全屏fixed蒙层，内部批量生成大量div文本，旋转、半透明，铺满页面。

- 要点：`pointer‑events:none`，不阻挡页面点击；`user‑select:none`禁止选中水印文字。
  ✅优点：实现简单，文字清晰，动态修改文本方便
  ❌缺点：DOM节点多，性能差；开发者工具直接删除节点即可干掉水印，容易破解

### 2. CSS伪元素水印

利用`::after`伪元素 + background-repeat平铺。
✅最简单，无额外DOM节点
❌极易被调试工具删掉样式，生产很少用，仅简单内部页面使用。

### 3. Canvas水印（最常用）

1. 创建小canvas，绘制倾斜半透明水印文字
2. `toDataURL()`导出base64图片
3. 生成一个fixed全屏div，把图片设置为background‑image，repeat平铺铺满全屏。

```js
//核心伪代码
function createImg(text) {
  const canvas = document.createElement("canvas");
  canvas.width = 220;
  canvas.height = 160;
  const ctx = canvas.getContext("2d");
  ctx.rotate((-20 * Math.PI) / 180); //旋转
  ctx.fillStyle = "rgba(128,128,128,0.12)";
  ctx.font = "14px sans-serif";
  ctx.fillText(text, 20, 80);
  return canvas.toDataURL();
}
// 蒙层
const mask = document.createElement("div");
mask.style.cssText = `
position:fixed;top:0;left:0;right:0;bottom:0;
z-index:9999;pointer-events:none;
background-image:url(${createImg("张三 userId:10086")});
background-repeat:repeat;
`;
document.body.appendChild(mask);
```

✅优点：只有1个DOM节点，性能好；文字转图片，不能直接选中水印文字；项目主流方案
❌依然可以devtools删除这个div，水印消失。

### 4. SVG水印

和Canvas思路类似，直接生成svg字符串作为background背景。
✅矢量图，放大不会模糊；不需要JS绘图API；
❌同样DOM可删；复杂文本处理麻烦。

> 注意公共样式：`pointer‑events:none`，非常关键，否则水印层会拦截所有页面点击事件。

## 二、防删除加固手段（面试高频）

> 注意：**没有绝对安全，只能增加破解成本，用户关闭JS直接全部失效**。

1. **MutationObserver**
   监听DOM变化，监控水印节点：节点被删除、属性修改（display:none / opacity=0），立刻重新生成水印层。

```js
const ob = new MutationObserver((mutList) => {
  // 判断水印被删/样式被篡改，重建水印
});
ob.observe(document.body, { childList: true, subtree: true, attributes: true });
```

2. 定时巡检兜底
   MutationObserver可以被恶意JS调用`disconnect()`关闭；搭配定时器检查水印元素是否存在，双重保险。

3. 随机类名/随机id
   不要写固定class="watermark"，用随机字符串，防止攻击者直接通过选择器批量删除水印节点。

4. ShadowDOM
   把水印挂载到shadow dom内部，外部JS拿不到内部dom，难以直接删除；但依然可以删除整个shadow宿主节点。

5. 最大z-index，防止别的元素盖住水印。

## 三、暗水印（盲水印）

明水印可以PS抹除；暗水印把用户信息通过LSB最低有效位算法嵌入图片像素，**肉眼看不到，截图之后，通过算法可以提取出是谁泄露**。

- 前端做暗水印性能开销大；**工业一般后端处理图片打盲水印**。
- 局限：截图、压缩图片会破坏暗水印信息。

## 四、前端水印的致命短板（面试必答）

1. 用户**关闭JavaScript，水印直接消失**，所有JS加固全部失效。
2. 无法阻止系统截图、录屏（操作系统层面捕获画面，浏览器拦不住）。
3. 可以通过开发者工具、注入脚本删除/隐藏水印。

> ⚠️结论：**前端水印只是威慑+溯源，不能当做安全防护；敏感场景要后端配合：后端返回图片直接打上水印、接口日志记录访问人、权限管控**。

## 面试常问

### Q：pointer‑events:none 作用？

水印层fixed全屏覆盖，如果不加这个，页面所有点击、输入都会被水印层拦截失效；设置none，让鼠标事件穿透水印层，交给底层页面。

### Q：MutationObserver就能做到水印删不掉吗？

不能。攻击者可以执行`ob.disconnect()`把监听器关掉；也可以直接禁用JS。只能提升破解门槛，不能绝对防护。

### Q：Canvas水印和DOM水印对比？

- DOM：大量节点，性能差，文字可选中；
- Canvas：单节点，性能好，渲染为图片文本不可选中，业务首选。

### Q：为什么不能完全防截图？

截图是操作系统行为，发生在浏览器渲染管线之后，JS没有API阻止系统截图。
