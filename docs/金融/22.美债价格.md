这句话就是债券最核心的铁律：

# **美债价格 ↓ = 美债收益率 ↑**
完全**反向关系**，死死记住就行。

---

## 一句话原理
你用**100块**买一张债券，固定每年给你**4块利息**：
- 现在大家抢着买，价格涨到 **105块**
  → 你花更多钱，拿到同样4块利息
  → **收益率变低**

- 没人买，价格跌到 **95块**
  → 你花更少钱，拿到同样4块利息
  → **收益率变高**

所以：
**价格跌 = 更便宜买 = 收益率上行**
**价格涨 = 更贵买 = 收益率下行**

---

## 结合你前面看的：美债 + HY信用利差
1. **美债收益率上行**
   = 美债在跌，无风险利率变高
   = 全球所有资产的“地板价”抬高

2. **HY高收益信用利差**
   = HY债收益率 − 美债收益率

- 如果：**美债收益率上行，但HY利差不动**
  → 只是无风险利率涨，企业风险没变

- 如果：**美债收益率上行 + HY利差也走阔**
  → 无风险利率涨 + 企业违约风险上升
  → 双重压力，风险资产最难受

---

## 再结合日元套利
- 美债收益率上行 → 美债在跌
- 如果这时候叠加**日元快速升值**
  → 套利盘平仓，疯狂卖美债
  → 美债价格继续跌 → 收益率继续涨
  → 形成**踩踏式上行**

---

简单总结：
**债跌 → 收益率涨；债涨 → 收益率跌。
这是债券市场第一定律，不会变。**
