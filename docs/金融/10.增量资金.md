# 增量资金
**增量资金**：从股市体系**外面新流进市场的钱**，原本不在股票账户，通过银证转账、买基金、外资买入等方式进入A股，给市场带来新增流动性。
与之对应的是**存量资金**：已经在股市里面的钱，只在股票和账户现金之间来回切换，市场总资金没有变，属于“拆东墙补西墙”。

>简单一句话：
- **增量行情：外面的钱进来买，整体钱多，容易走出趋势上涨**
- **存量行情：场内钱互相倒腾，总量不变，板块跷跷板轮动，指数难走大行情**

## 一、增量资金主要来源
1. 居民储蓄搬家：散户把银行存款、理财拿出来买股票/买基金
2. 机构资金：新发基金、保险资金、养老基金入场建仓
3. 北向资金（外资）持续大额净流入
4. 两融余额持续抬升（杠杆资金进场）
5. 上市公司回购、产业资本增持

## 二、增量行情 vs 存量博弈（盘面特征）
|维度|增量资金行情|存量资金博弈|
|---|---|---|
|成交额|**连续、阶梯式放量**，站上更高量能台阶|成交额长期在固定区间，忽大忽小，没有持续抬升|
|指数表现|指数不断突破压力位，趋势向上|箱体震荡，突破容易回落|
|板块特征|多点开花，多个板块同步上涨|板块跷跷板；A涨B跌，快速轮动，只有局部热点|
|赚钱效应|普涨，低位票批量补涨|分化严重，只有少数题材赚钱|

>⚠️重点提醒：**单日放量不等于增量资金**。单日爆量很多只是场内存量资金剧烈换手、筹码交换，只有**连续多日维持更高成交量级别**，才更像增量入场。

## 三、实战怎么观察有没有增量资金
1. **两市总成交额**：看是否持续站上过去几个月的量能平台，而不是一两天脉冲放量。
2. **北向资金**：连续多日大额净流入，不是一日游。
3. **基金端**：权益基金新发回暖、宽基ETF持续净申购。
4. **两融余额**：融资余额稳步抬升，杠杆资金进场。
5. **盘面结构**：是不是多个板块一起走强，而不是只有一两个热点独舞。

## 四、交易启示
1. **增量资金主导市场时**：趋势行情更容易延续，持股、做主线性价比高，容错率高。
2. **存量博弈市场**：很难有全面大牛市，适合高抛低吸、轮动交易，不宜盲目追高，防守策略（吃股息、网格）会更友好。
3. 增量资金也分偏好：如果增量资金偏爱蓝筹红利，则权重走牛；如果偏爱成长小票，则小盘成长行情。
