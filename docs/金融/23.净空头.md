# 净空头（Net‑Short）
> 美债期货语境（CFTC COT报告，对冲基金/杠杆基金）：
**净空头 = 空头合约数量 − 多头合约数量 > 0**。
公式：
`净持仓 = 多头 − 空头`
- 结果＜0 → **净空头**；负值绝对值越大，空头押注越重。
- 结果＞0 → 净多头。

> 美债期货做空的含义：**赌美债价格下跌、美债收益率上行**（价格 ↔ 收益率反向）。

## 1、通俗解释
对冲基金在美债期货上：
- 开空头：卖出美债期货，赌**债价跌、收益率涨**。
- 开多头：买入美债期货，赌**债价涨、收益率跌**。

如果空头合约比多头多很多，就是**高净空头**：代表一大批投机资金押注美债收益率继续往上冲。

> ⚠️注意：这是**期货头寸**，不是直接卖手里现券；很多时候还包含**期现基差套利（basis trade）**，不完全是单纯看空利率，这点很容易被忽略。

## 2、两个层面解读（非常关键）
### ① 趋势层面：净空头继续扩大
越来越多对冲基金去做空美债期货。
市场在交易：通胀顽固、经济韧性强、美联储高利率维持更久、美债供给巨大，预期收益率继续上行，美债价格继续跌。

### ② 反向信号：**极端拥挤净空头（历史分位很高）**
当净空头冲到**多年历史极高位置**，属于拥挤交易：几乎想做空的投机资金已经全部进场，后续能继续追加空头的增量资金变少。
一旦出现一点点利好（通胀回落、就业走弱、美联储偏鸽）：
> 空头要平仓（买期货合约来平掉空头）→ **买盘集中涌入 →美债价格大涨，收益率快速下行**，也就是**空头挤压（Short‑Squeeze）**。

> 重点：**拥挤空头可以维持很久，不会马上反转，持仓只是情绪指标，不是直接买卖信号**，必须等催化事件才会反转。

## 3、和你前面整套体系串联
1. **高净空头 + 美债收益率上行**：趋势共振，空头顺风顺水。
2. **高净空头，但收益率不再创新高（价格止跌）**：警惕空头挤压风险，一旦反转，长端（10Y/30Y）波动会非常剧烈。
3. 如果空头大规模平仓：
   - 美债价格上涨、收益率下行；
   - 无风险利率下行，利好风险资产；
   - 同时要区分：是投机空头回补，还是基本面真的转鸽。

> 和日元套息的区分：
> 净空头是**期货投机盘赌利率上行**；日元套息是借日元买现货美债赚取利差，是两套资金。两者可以同向，也可以反向。

## 4、实操看盘要点（COT报告）
1. 看**杠杆基金（Leveraged Funds，对冲基金）**的净空头，不是全部交易者；
2. 优先看**历史分位**，而不是只看绝对手数；90%分位以上=极端拥挤；
3. COT是**周度滞后数据（截止周二，周五公布）**，有延迟，不能做短线直接信号；
4. 分开期限看：2Y、10Y、30Y净空头可以分化，例如长端高净空，短端空头下降，代表交易收益率曲线陡峭化。

## 极简口诀
> **净空头变大：赌债跌、收益率涨；
> 净空头极端拥挤：小心空头挤压，收益率随时可能跳水。**
