# 美债（美国国债 U.S.Treasury）
美国政府发行的债务，被视为**全球无风险资产基准**，全世界股票、企业债、高收益HY债、大宗商品全部拿美债收益率做定价底座。
> 核心公式：**企业债收益率 = 美债无风险收益率 + 信用利差**（前面讲的HY高收益债就是这个逻辑）

## 一、三大基础品种（按期限）
|简称|全称|期限|付息方式|市场定位|
|---|---|---|---|---|
|T‑Bill|短期国库券|1年以内（4‑52周）|贴现发行，无票息|看美联储政策、短期资金松紧|
|T‑Note|中期国库票据|2/3/5/7/**10Y**|每半年付息|**10Y美债：全球最重要定价锚，HY利差的基准**|
|T‑Bond|长期国债|20Y、**30Y**|每半年付息|久期最大，看远期通胀、美国财政赤字|

> 特殊品种：**TIPS通胀保值美债**，本金跟随CPI调整，用来拆出「实际利率」和「通胀预期」。

### 关键期限分工（记4个就够用）
1. **2Y美债**：紧密跟随美联储政策利率，反映**近1‑2年加息降息预期**。2Y↑=市场预期美联储继续加息。
2. **10Y美债**：全球资产锚；**美高收益HY信用利差 = HY收益率 − 10Y美债收益率**，**不用30Y做基准**。
3. **30Y美债**：超长期，久期巨大，对财政赤字、几十年维度通胀最敏感，波动最大。
4. **10Y‑2Y利差（2s10s）**：收益率曲线，著名衰退先行指标；**倒挂=2Y＞10Y，历史上多次预示美国衰退风险抬升**。

## 二、两个核心概念：收益率 vs 价格
> **债券价格和收益率反向**：收益率涨，债券价格跌；收益率跌，债券价格涨。
> 久期越大，价格波动越猛：30Y美债久期≈22，收益率上行1%，价格大约跌22%。

例子：TLT（跟踪20‑30Y美债ETF），美债收益率大涨时TLT会明显下跌。

## 三、美债收益率上行/下行代表什么
✅ **美债收益率上行**
- 原因：通胀顽固、美国经济过热、美联储维持高利率、财政发债供给暴增。
- 后果：全球资产估值被压制；成长股、港股、黄金承压；北向资金容易流出A股；美元走强。

✅ **美债收益率下行**
- 原因：衰退预期、通胀回落、市场交易美联储降息。
- 后果：风险资产估值修复，成长占优，黄金走强。

> 区分两件事，不要混淆：
1. **美债收益率变动**：代表**无风险利率**变化；
2. **HY高收益信用利差变动**：代表**企业违约风险**变化。
- 场景A：美债收益率大涨，但HY利差不动：只是无风险利率抬升，企业信用没有恶化。
- 场景B：美债收益率不动，但HY利差大幅走阔：企业违约风险爆发，信用危机。

## 四、美债 vs 国内信用利差（回顾你前面问题）
1. **美HY利差**：基准是**10Y美债**，看美国垃圾级企业违约风险；数据高频，全球风险风向标。
2. **国内信用利差**：基准是**中国国债收益率**，看国内产业债、城投债的信用风险。
> 两者可以反向走：美国信用收紧，国内信用可以宽松，互相不完全绑定。

## 五、极简盯盘清单（实操用）
1. 看货币政策预期：**2Y美债**
2. 全球定价锚、算HY利差：**10Y美债**
3. 看远期通胀财政、大久期交易：**30Y美债**
4. 衰退预警：**10Y‑2Y利差（2s10s）**
5. 企业违约风险：**美高收益HY信用利差**
