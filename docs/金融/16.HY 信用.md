# HY信用
HY信用有两层常见含义：**金融市场术语（HY=High‑Yield，高收益）**、**香港持牌放贷机构HY Credit（迅兴信贷）**。

## 一、金融术语：HY（High‑Yield）高收益信用（市场最常用）
HY = **High‑Yield，高收益，俗称垃圾债**，HY Credit即高收益信用市场（投机级信用债市场）。
1. **评级门槛**：标普/惠誉 BB+及以下、穆迪 Ba1及以下，不属于投资级(IG)债券。
2. **核心特征**：票息更高，用来补偿更高违约风险；经济下行周期违约率会明显抬升。
3. **HY Credit Spread**：高收益信用利差，是观察企业信用风险、衰退预警的关键指标，利差走阔代表市场担心违约风险上升。

> 对比：IG=Investment Grade 投资级信用债，风险低、收益率低。
