# 比特币（BTC）与美股（纳指/标普500）
> 核心结论：**比特币是高β的美元风险资产，不是避险资产**。多数时间和纳斯达克（科技成长）联动最强；危机时刻相关性飙升；但可以出现阶段性脱钩。联动不是固定常数，30日滚动相关系数在0~0.8之间来回跳变。

## 一、底层传导链条（和你前面整套宏观体系打通）
**源头：美债收益率、美元流动性、VIX、HY高收益利差、日元套息**
1. **美债收益率上行（无风险利率抬升）**
无息资产比特币的持有机会成本变高；同时压制美股成长股。
→ 美股跌，BTC更容易跌，BTC跌幅通常大于纳指。
> HY利差走阔（信用风险爆发）、VIX飙升恐慌阶段：**相关性直接拉到0.6‑0.8，股币双杀**，比特币跌得更狠。

2. **美债收益率下行、降息预期升温**
美元流动性宽松，风险偏好抬升。
→ 美股上涨，BTC弹性更大，涨得更多。

3. **日元套利的间接传导**
借日元买美元风险资产的资金池，既买美股科技，也买BTC。
- 套息扩张：USDJPY走高，日元贬值 → 给美股、BTC同时输血。
- **套息unwind平仓：日元快速升值** → 批量抛售美股、BTC换回日元还债，两者同步暴跌。

> 比特币没有利润、没有财报；美股有企业盈利。**美股可以靠业绩独立走强，比特币做不到**，它高度依赖资金流入（现货ETF、杠杆资金）。

## 二、两种市场状态
### 1、强联动（大多数危机/流动性拐点）
- 场景：美联储政策急转弯、通胀超预期、银行风险、VIX飙升、HY利差快速走阔。
- 表现：纳指跌3%，BTC经常跌6%‑10%；相当于**加杠杆的纳指**。
- 标的纽带：COIN（coinbase）、MSTR（大量持有BTC的美股公司），股票与币价互相强化反馈。

### 2、阶段性脱钩（相关性趋近0）
出现脱钩，一般满足下面至少一条：
1. **美股是AI主题独立行情**：上涨来自少数巨头企业盈利，不是全市场流动性宽松；资金只涌向AI，不流向加密资产。
2. **比特币自身独立事件驱动**：减半、ETF大额净流入/流出、美国监管重大变化。
3. **币圈杠杆大规模去完**：合约爆仓、未平仓量大幅萎缩，投机杠杆被清除，BTC对美股波动敏感度下降。
4. 传统市场波动很小，存量博弈，各自走自己逻辑。

> 注意：**脱钩是阶段性，不是永久**。一旦出现系统性流动性冲击，立刻重新绑定一起杀跌。

## 四、实操盯盘指标（承接前面的整套监控）
1. **10Y美债收益率**：无风险利率底座，同时影响美股与BTC。
2. **VIX恐慌指数**：VIX冲高，股币大概率同步杀跌。
3. **HY高收益信用利差**：利差快速走阔，代表美元风险资产整体收缩，BTC很难独善其身。
4. **USDJPY日元汇率**：警惕日元快速升值带来套息平仓，双重打击美股+BTC。
5. **BTC现货ETF净流**：BTC自己的独立变量；ETF持续大额流出，即便美股上涨，BTC也可能走弱。
6. **30日滚动相关系数**：>0.5代表强联动；接近0代表脱钩阶段。
