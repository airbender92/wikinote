# 日元套利（Yen Carry Trade，日元套息交易）
> 承接前面美债、HY高收益债知识：**借低成本日元，换成美元买美债/美股/HY高收益债，赚跨币种利差，带杠杆，是全球最重要的跨境杠杆来源**。

## 完整操作流程
1. **融资端**：借入日元，日本利率极低，融资成本很低。
2. **换汇**：把日元卖出，买入美元。
3. **投资**：拿美元买**10Y美债、30Y美债、美股、美高收益HY债、新兴市场资产**。
4. **平仓还款**：未来卖出美元资产，换回日元，归还日元贷款。

**收益公式**
> 净收益 = 美元资产收益率 − 日元融资利率 **− 日元升值带来的汇兑损失**

> 致命点：**利差是稳定的，汇率是爆炸风险源**。日元快速升值，几个交易日就可以把全年利差全部亏光，杠杆下直接爆仓。

举个简化例子：
- 借1亿日元，融资利率0.5%；汇率150，换成约66.67万美元；买入10Y美债收益率4.2%。
- 利差静态收益≈3.7%。
- 如果日元快速升值到140，**光汇兑损失就接近6.7%，直接把利差全部吃掉还倒亏**。

## 两大驱动条件（交易成立的前提）
1. **美日利差维持高位**：美国资产收益显著高于日本融资成本。
2. **日元不大幅快速升值**；市场波动率低，没有大规模避险。

> 两个条件只要破坏一个，就会出现**套息交易平仓（Unwind）**：机构集体抛售美债、美股，换回日元还债，形成负反馈踩踏。

## 平仓（Unwind）会发生什么（非常关键，连接美债/HY债）
平仓链条：
> 日本加息 / 市场避险 / 日元快速升值 → 套息仓位亏损止损 → **抛售美债、美股、HY高收益债 → 美债价格下跌，美债收益率上行；HY信用利差走阔；美元走弱、日元走强；全球风险资产普跌**。

- 卖美债：美债收益率往上冲，尤其长端30Y美债压力大。
- 卖HY高收益债：HY利差被动走阔，信用市场收紧。
- 流动性优先：先抛流动性最好资产，不一定只跌日本相关资产，美股、美债、新兴市场一起被砸。
> 历史案例：2008金融危机、2024年8月日本央行意外加息，都出现大规模unwind，全球股市债市同步震荡。

## 和你前面学的指标联动（重点）
1. **美日利差**：美10Y − 日10Y，利差扩大，套息交易吸引力上升；利差收窄，套息动力下降。
2. **USDJPY（美元兑日元）**：
   - USDJPY走高（日元贬值）：套息交易舒服，美元资产获得增量买盘。
   - USDJPY快速下跌（日元暴涨）：警惕套息unwind风险。
3. **美债**：日元套息是美债重要海外买方；当套息撤退，美债失去买盘，收益率上行压力加大。
4. **HY高收益利差**：大规模unwind时，资金从HY债出逃，**HY利差走阔**，属于流动性驱动的信用风险抬升。

> 区分两件事：
- 美债收益率上行，**不一定等于套息崩盘**，可以是美国经济过热；
- 但**美债收益率上行叠加日元快速升值+VIX飙升**，这是典型套息平仓信号。

## 两类参与者
1. **不做汇率对冲（裸敞口，对冲基金主流）**：赚利差，赌日元不升值；一旦日元暴涨巨亏，风险极高。
2. **做汇率对冲（日本寿险机构）**：通过交叉货币互换XCCY锁死汇率；对冲之后，实际可赚的利差会被互换基差吃掉一大块，很多时候对冲后几乎没有收益，这就是日本机构有时候不买美债的原因。

## 关键警示信号（看盘用）
1. USDJPY短时间快速下跌，日元单日升值>2%；
2. 日本央行释放加息信号，日债收益率上行；
3. VIX恐慌指数同步走高；
4. 美债长端收益率上行同时，HY信用利差同步走阔。
