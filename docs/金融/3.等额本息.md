# 等额本息，一句话说清：
**每个月还的钱，金额完全一样，月月不变。**

- 每月月供：**固定金额**
- 前面：**还的利息多、本金少**
- 后面：**还的利息少、本金多**

---

## 用你 100 万、30 年、3.6% 举例
- 月供：**4546.45 元**（30 年每个月都还这么多）

### 第 1 个月：
- 剩余本金：100 万
- 当月利息：1000000 × 0.3% = 3000 元
- 当月还本金：4546.45 − 3000 = **1546.45 元**

### 第 2 个月：
- 剩余本金变少了
- 利息变少一点
- 本金多还一点
- 但**月供还是 4546.45**

### 最后 1 个月：
- 利息几乎为 0
- 大部分还的是本金
- 月供依然：**4546.45**

---

## 它为什么叫“等额本息”？
- **等额**：每月还款额相等
- **本**：本金
- **息**：利息

合起来就是：
**每月本金 + 利息之和相等**

---

## 和另一种“等额本金”对比一下
- **等额本息**：每月钱一样，前期压力小，总利息稍多
- **等额本金**：每月越还越少，前期压力大，总利息少一点

你现在这套 100 万 30 年，就是典型的**等额本息**。

需要我给你算一下，如果换成**等额本金**，每个月分别还多少、总利息差多少吗？



分两种情况，完全不一样，我给你说最实用、最贴近现实的版本：

# 1. 如果你是 **固定利率房贷**
- 签合同利率多少，**30年永远不变**
- 不管市场利率涨还是跌，你的月供、总利息都不动

# 2. 如果你是 **LPR浮动利率**（现在绝大多数房贷都是这个）
- 利率 **会跟着市场变**
- 每年重定价一次（比如1月1日，或放款对应日）
- 利率一变，**月供马上重新算**
- 剩余本金、剩余年限不变，只用新利率重新走一遍等额本息公式

也就是说：
**利率涨 → 月供变多
利率跌 → 月供变少**

# 3. 关键：怎么变？不是随便乱变
举个例子你就懂：
- 原来年利率 3.0%
- 明年变成 3.2%
- 银行会按**剩余本金 + 剩余期数 + 新利率**
  重新算一个新的固定月供，直到下次利率再变

# 4. 最重要的结论
- 等额本息本身是**固定月供算法**
- 但**利率如果浮动，月供就会变**
- 变的时候，仍然按等额本息重新算，不是按过去的利息滚
