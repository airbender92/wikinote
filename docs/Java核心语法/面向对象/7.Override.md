```java
@Override
public void attack(Character target) {
    System.out.println("\n【攻击释放】" + getName() + " 挥剑猛击！");
    target.takeDamage(25);
}
```

# 1. @Override 是什么？
- 表示**重写**（覆盖）父类或接口里的方法
- 这里就是在**实现 Attackable 接口的 attack 方法**
- 不写也能运行，但写上更规范、编译器会帮你检查方法是否写对

# 2. public void attack(Character target)
- 这是接口规定的方法，**必须一模一样**
- `Character target`：
  表示**攻击目标是一个角色**（可以是战士、法师、任何继承Character的角色）

# 3. System.out.println(...)
- 输出一句提示：谁发动了什么攻击
- `getName()` 是父类 Character 里的 public 方法
- 因为 name 是 private，外面不能直接用 `.name`，只能用 `getName()`

# 4. target.takeDamage(25); 最关键一句
- `target`：被打的那个角色
- `takeDamage(25)`：调用目标的**受伤方法**
- 意思就是：
  > 让目标受到 **25 点伤害**

所以这句执行后：
- 目标的 hp 会减少 25
- 控制台会打印剩余血量

---

# 整体逻辑一句话总结
> 战士发动攻击 → 打印攻击提示 → 让被攻击目标掉 25 点血

法师的攻击也是一样的结构，只是伤害更高（40）、台词不同，这就是**多态**——同一个方法，不同职业表现不一样。
