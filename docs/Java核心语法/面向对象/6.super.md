这句代码我用最直白的方式给你讲清楚：

# 一句话解释
```java
public Warrior(String name) {
    super(name, 100);
}
```

这是 **Warrior 类的构造方法**，
里面的 `super(name, 100)` 意思是：
**调用父类的构造方法，把名字传过去，并且固定血量为 100。**

---

# 一步步拆开

## 1. 这是 Warrior 的构造方法
- 方法名和类名一样：`Warrior`
- 没有返回值
- 创建战士对象时执行：
  ```java
  new Warrior("亚瑟");
  ```

## 2. `super(...)` 是什么？
`super` = **父类**
在这里指的就是 `Character`。

## 3. 父类 Character 的构造是这样的：
```java
public Character(String name, int hp) {
    this.name = name;
    this.hp = hp;
}
```

## 4. 所以
```java
super(name, 100);
```

等价于：
```java
new Character(name, 100);
```

也就是：
- 名字 = 传进来的 name
- 血量 = 固定 **100**

---

# 最终效果
```java
Warrior w = new Warrior("亚瑟");
```

执行后：
- name = "亚瑟"
- hp = 100

---

# 对比法师你就彻底懂了
```java
public Mage(String name) {
    super(name, 70); // 法师血少，只有70
}
```

- 战士：`super(name, 100)` → 血厚
- 法师：`super(name, 70)`  → 血薄

这就是**不同职业不同初始属性**。

---

# 超简总结
`super(name,100)`
= **调用父类构造，给战士设置名字和100点血量**。
