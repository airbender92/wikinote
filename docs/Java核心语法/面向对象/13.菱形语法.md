这个写法叫 **菱形语法（Diamond Operator）**，Java 7 以后才支持的。

我用最简单的话给你讲清楚：
**`new Box<>()` 里的 `<>` 之所以不用写类型，是因为编译器能从左边自动推断出来。**

---

# 1. 完整写法（以前必须这么写）
```java
Box<String> box = new Box<String>();
```
前后都要写 `<String>`，很啰嗦。

---

# 2. 现在的简写（菱形语法）
```java
Box<String> box = new Box<>();
```
编译器看到左边是 `Box<String>`，
就自动知道右边 `<>` 里应该是 `String`。

所以：
**`<>` 不是不传类型，而是让编译器自动帮你填。**

---

# 3. 为什么不能直接写成 `new Box()`？
如果你写成：
```java
Box<String> box = new Box();
```
这叫 **原始类型（raw type）**，编译器会警告，而且不安全。

所以：
- `new Box()` ❌ 原始类型，警告
- `new Box<>()` ✅ 菱形语法，安全、简洁
- `new Box<String>()` ✅ 完整写法，兼容老版本

---

# 4. 一句话总结
`new Box<>()`
= 编译器**自动推断泛型类型**
= 省略重复写一遍类型
= 更简洁，不报错、不警告
