这句代码拆开讲，**超直白、一步到位看懂**：

# 1. 完整句子翻译
```java
class Warrior extends Character implements Attackable {}
```

> **战士类 继承 角色类 并且 实现 可攻击接口**

---

# 2. 拆成两部分理解

## ① extends Character
- `Warrior` **继承** 父类 `Character`
- 意味着：
  - 自动拥有 `name`、`hp` 属性
  - 自动拥有 `takeDamage()`、`isAlive()`、`getName()` 方法
  - 不用重复写一遍代码

## ② implements Attackable
- `Warrior` **实现** 接口 `Attackable`
- 意味着：
  - 必须重写接口里的 `attack(Character target)` 方法
  - 否则编译报错
  - 实现后，这个类就“拥有攻击能力”

---

# 3. 为什么要这么写？
- **extends**：复用角色通用属性和逻辑（血量、名字、受伤）
- **implements**：赋予攻击行为，符合统一规范

这样写就是典型的：
> **共性放父类，特性放接口/子类**

---

# 4. 完整对应关系
```java
interface Attackable {
    void attack(Character target);
}

abstract class Character { ... }

// 继承 + 实现
class Warrior extends Character implements Attackable {
    @Override
    public void attack(Character target) {
        // 战士自己的攻击逻辑
    }
}
```

---

# 5. 一句话总结
`Warrior` 是一个**角色**，并且**会攻击**，所以：
- 继承 `Character`（是角色）
- 实现 `Attackable`（能攻击）
