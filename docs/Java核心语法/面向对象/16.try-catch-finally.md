```java
private static void exceptionTest(){
    try{
        // 可能抛出异常

        // 捕获自定义异常
        System.err.println("捕获异常：" + e.getMessage());
        e.printStackTrace();
    } finally {
        // 必须执行：资源释放、日志记录等

    }
}
```

---

# 1. 方法定义语法
```java
private static void exceptionTest()
```
- `private`
  访问修饰符，表示**这个方法只能在当前类内部使用**，外部类不能调用。

- `static`
  静态方法，表示**不需要创建对象**，直接通过类名就能调用。

- `void`
  返回值类型，表示这个方法**执行完不返回任何数据**。

- `exceptionTest()`
  方法名，自己起的名字，代表“异常测试”。

---

# 2. try 块语法
```java
try{
    checkAge(-1);
}
```
- `try` 是 Java 异常处理的关键字
- 作用：**把“可能会抛出异常”的代码放在 try 里**
- 如果里面代码正常执行，就跳过 catch，直接走 finally
- 如果里面代码**抛出异常**，程序会立刻跳转到对应的 catch 块

这里 `checkAge(-1)` 会主动抛出 `AgeIllegalException`，所以一定会进 catch。

---

# 3. catch 块语法
```java
catch (AgeIllegalException e) {
    System.err.println("捕获异常：" + e.getMessage());
    e.printStackTrace();
}
```

### ① `catch (AgeIllegalException e)`
- `catch`：捕获异常的关键字
- `AgeIllegalException`：你**自定义的异常类型**
- `e`：异常对象的名字（随便起，一般叫 e）
- 含义：**只捕获这种类型的异常**，其他异常不会进这里

### ② `System.err.println(...)`
- `System.err`：错误输出流，打印内容一般**标红**（控制台里）
- `println`：换行打印
- `e.getMessage()`：调用异常对象的方法，**获取你写的异常提示文字**
  这里会得到：`年龄不能为负数：-1`

### ③ `e.printStackTrace()`
- 打印**异常堆栈信息**
- 会显示：异常类型 + 异常信息 + 出现在第几行
- 开发调试必备，能快速定位错误位置

---

# 4. finally 块语法
```java
finally {
    System.out.println("finally 块：资源清理");
}
```

- `finally`：异常处理里**一定会执行**的代码块
- 无论：
  - try 里正常执行完
  - try 抛出异常被 catch 捕获
  - 甚至 try 里 return 了
- finally **100% 会执行**
- 用途：关闭文件流、关闭连接、释放资源等

---

# 5. 配套方法的语法（你前面用到的）
```java
private static void checkAge(int age) throws AgeIllegalException {
    if (age < 0) {
        throw new AgeIllegalException("年龄不能为负数：" + age);
    }
}
```

### ① `throws AgeIllegalException`
- 写在**方法声明**上
- 意思：**本方法可能抛出这个异常，调用者需要处理（try/catch）**

### ② `throw new ...`
```java
throw new AgeIllegalException("年龄不能为负数：" + age);
```
- `throw`：手动**抛出一个异常对象**
- `new AgeIllegalException(...)`：创建异常对象
- 抛出后，程序立刻跳出当前方法，进入调用处的 catch

---

# 6. 自定义异常类语法（配套）
```java
class AgeIllegalException extends Exception {
    public AgeIllegalException(String message) {
        super(message);
    }
}
```

- `extends Exception`：继承标准异常类，成为**受检异常**
- `super(message)`：调用父类构造方法，把异常信息存进去
- 之后才能用 `e.getMessage()` 取出来

---

# 极简总结（记忆版）
- `try`：放可能出错的代码
- `catch`：捕获并处理异常
- `finally`：无论如何都执行，用于关资源
- `throw`：手动抛异常
- `throws`：方法声明可能抛异常
- `e.getMessage()`：拿异常提示
- `e.printStackTrace()`：打印错误详细信息
