好，我直接用**最简单、能看懂的对比例子**，一眼就懂。

先记住一句话：
- **非静态内部类**：必须先 `new 外部类()`，才能 `new 内部类()`
- **静态内部类（static class）**：可以直接 `new 内部类()`

---

# 1. 静态内部类（你现在用的 static class）
```java
public class Outer {

    // 静态内部类
    static class Box<T> {
        private T item;

        public T getItem() {
            return item;
        }

        public void setItem(T item) {
            this.item = item;
        }
    }

    public static void main(String[] args) {
        // ✅ 直接 new，不需要先创建 Outer 对象
        Box<String> box = new Box<>();
        box.setItem("张三");
        System.out.println(box.getItem());
    }
}
```

**特点：**
直接 `new Box<>()` 就行，不用管外部类 `Outer`。

---

# 2. 非静态内部类（不加 static）
```java
public class Outer {

    // 普通内部类（没有 static）
    class Box<T> {
        private T item;

        public T getItem() {
            return item;
        }

        public void setItem(T item) {
            this.item = item;
        }
    }

    public static void main(String[] args) {
        // ❌ 直接 new Box() 会报错！
        // Box<String> box = new Box<>();

        // ✅ 必须先创建外部类对象
        Outer outer = new Outer();

        // 再通过外部类对象创建内部类
        Box<String> box = outer.new Box<>();

        box.setItem("张三");
        System.out.println(box.getItem());
    }
}
```

**必须这样写：**
```java
Outer outer = new Outer();
Box<String> box = outer.new Box<>();
```

---

# 3. 最核心对比总结

| 类型 | 写法 | 是否需要外部类对象 |
|------|------|-------------------|
| 静态内部类 `static class` | `new Box<>()` | **不需要** |
| 普通内部类 `class` | `outer.new Box<>()` | **必须要** |

---

# 4. 为什么你代码要加 static？
因为你要在 `main` 方法里直接用：
```java
Box<String> box = new Box<>();
```
不加 static 就**编译报错**，必须先创建外部类。

所以：
**内部类想在 main 里直接用 → 加 static**
**内部类依赖外部类的成员变量 → 不加 static**
