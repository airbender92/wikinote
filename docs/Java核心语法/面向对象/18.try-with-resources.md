下面我**逐行逐语法**给你讲清楚这段 IO 代码的每一个 Java 语法点，保证你彻底看懂。

# 完整代码
```java
private static void ioFileReadWriteTest(){
    // 会自动关闭资源， 无需 finally
    try(BufferedReader br = new BufferedReader(new FileReader("input.txt"));
        BufferedWriter bw = new BufferedWriter(new FileWriter("output.txt"))
    ){
        String line;
        while((line = br.readLine()) != null){
            System.out.println("读取内容：" + line);
            bw.write(line);
            bw.newLine();// 换行
        }
        System.out.println("文件写入完成！");
    } catch(IOException e){
        // 异常不能空处理
        e.printStackTrace();
    }
}
```

---

# 1. 方法定义
```java
private static void ioFileReadWriteTest()
```
- `private`：只能当前类访问
- `static`：静态方法，不用 new 对象就能调用
- `void`：没有返回值
- `ioFileReadWriteTest`：方法名，意思“IO文件读写测试”

---

# 2. try-with-resources 语法（重点）
```java
try(BufferedReader br = new BufferedReader(new FileReader("input.txt"));
    BufferedWriter bw = new BufferedWriter(new FileWriter("output.txt"))
)
```

这是 Java 7+ 的 **try-with-resources** 语法，专门用来**自动关闭流资源**。

规则：
- 小括号 `()` 里声明并创建**实现了 AutoCloseable 接口的对象**（流、连接等）
- 代码执行完 try 块后，**会自动调用 close()**，不用写 finally
- 多个资源用 **分号 ;** 隔开

### 里面的 IO 类解释
- `FileReader("input.txt")`
  - 字节→字符转换，读取文本文件
  - 传入文件路径：`input.txt`

- `BufferedReader`
  - 缓冲字符输入流
  - 带缓冲区，**读文件效率更高**
  - 提供 `readLine()` 一次读一行，非常方便

- `FileWriter("output.txt")`
  - 写入文本文件
  - 文件不存在会自动创建

- `BufferedWriter`
  - 缓冲字符输出流
  - 写入效率高
  - 提供 `newLine()` 换行

---

# 3. try 代码块
```java
String line;
while((line = br.readLine()) != null){
    System.out.println("读取内容：" + line);
    bw.write(line);
    bw.newLine();
}
System.out.println("文件写入完成！");
```

### ① `String line;`
定义一个字符串变量，用来接收每一行内容。

### ② `while((line = br.readLine()) != null)`
这是经典的**读文件循环**：

- `br.readLine()`
  - 从文件读取**一行文本**
  - 读到文件末尾时返回 `null`

- `line = br.readLine()`
  - 先把读到的内容赋值给 line

- `!= null`
  - 判断是否还有内容
  - 不为 null → 继续循环
  - 为 null → 文件读完，结束循环

### ③ `bw.write(line)`
把读到的这一行字符串**写入输出文件**。

### ④ `bw.newLine()`
写入一个**换行符**，保证文件格式和原文件一致。

---

# 4. catch 块
```java
} catch(IOException e){
    e.printStackTrace();
}
```

- `IOException`
  - IO 操作的**父异常**
  - 文件找不到、权限不足、读写失败都会抛出它

- `e.printStackTrace()`
  - 打印异常堆栈
  - 开发中必须写，不能空 catch

---

# 5. 整体流程总结
1. 打开 `input.txt` 读，打开 `output.txt` 写
2. 一行一行读内容
3. 一行一行写到新文件
4. 读完自动关闭所有流
5. 中途出错进入 catch，打印错误信息

---

# 核心语法一句话记忆
- `try(...)`：自动关流，不用 finally
- `BufferedReader`：按行读文本
- `BufferedWriter`：按行写文本
- `readLine()` 读一行，返回 null 表示读完
- `IOException` 捕获所有 IO 异常
