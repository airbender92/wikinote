# 一、先一句话总纲
面向对象就是：**把现实世界的事物，抽象成“类”，再用“对象”去表示具体个体**，然后用**继承、多态、接口、抽象类**来组织代码，让程序**可复用、可扩展、好维护**。

---

# 二、类 & 对象（最基础）
## 1. 类（Class）
- **是什么**：模板、图纸、设计方案
- **包含什么**：
  - 属性（成员变量）：事物的特征
  - 方法：事物的行为

```java
class Person {
    // 属性
    String name;
    int age;

    // 方法
    void sayHello() {
        System.out.println("我是" + name);
    }
}
```

## 2. 对象（Object）
- **是什么**：根据类造出来的**具体实例**
- 类是图纸，对象是盖好的房子

```java
public class Test {
    public static void main(String[] args) {
        // 创建对象
        Person p = new Person();
        p.name = "张三";
        p.sayHello(); // 我是张三
    }
}
```

## 一句话总结
- **类 = 模板**
- **对象 = 实例**

# 三、继承（extends）
## 1. 作用
- **代码复用 + 扩展**
- 子类拥有父类所有非私有属性和方法，还能新增自己的

```java
// 父类
class Person {
    String name;
    void eat() {}
}

// 子类继承父类
class Student extends Person {
    int score;    // 子类独有属性
    void study(){} // 子类独有方法
}
```

## 2. 特点
- Java **单继承**：一个类只能有一个直接父类
- 子类可以重写（override）父类方法
- 用 `super` 访问父类成员

## 核心意义
**抽取共性到父类，个性留在子类**。

---

# 四、方法重写（Override）
继承里最重要的行为：**子类重新实现父类的方法**。

```java
class Person {
    void say() {
        System.out.println("人说话");
    }
}

class Student extends Person {
    @Override
    void say() {
        System.out.println("学生发言");
    }
}
```

规则：
- 方法名、参数列表必须相同
- 返回值可以是子类（协变返回）
- 权限不能更低
- 不能抛出更宽泛的异常

---

# 五、多态（Polymorphism）
## 1. 一句话
**父类引用指向子类对象**，调用方法时执行**子类重写后的版本**。

```java
Person p = new Student();
p.say(); // 输出：学生发言
```

## 2. 多态成立三要素
1. 有**继承**
2. 有**方法重写**
3. **父类引用指向子类对象**

## 3. 多态好处
统一调用风格，方便扩展。
比如：

```java
void feed(Person p) {
    p.eat();
}

feed(new Student());
feed(new Teacher());
```

不用写一堆重载方法。

# 六、抽象类（abstract class）
## 1. 作用
**专门当父类，不能实例化，强制子类实现某些方法**。

```java
abstract class Animal {
    abstract void run(); // 抽象方法：没有方法体
}

class Dog extends Animal {
    @Override
    void run() {
        System.out.println("狗跑");
    }
}
```

## 2. 特点
- 用 `abstract` 修饰
- 可以有**抽象方法**，也可以有**普通方法、属性、构造器**
- 不能 new 对象
- 子类必须实现所有抽象方法，否则子类也要变成抽象类

## 使用场景
**多个类有共同特征，但行为实现不一样**。

---

# 七、接口（interface）
## 1. 作用
**定义一套规范（契约），谁实现谁就要遵守**。

Java 8 以后接口功能很强：
- 抽象方法（默认 public abstract）
- 默认方法（default）
- 静态方法（static）
- 常量（public static final）

```java
interface Fly {
    void fly();
}

class Bird implements Fly {
    @Override
    public void fly() {
        System.out.println("鸟飞");
    }
}
```

## 2. 特点
- 一个类可以**实现多个接口**（弥补单继承）
- 接口不能有构造方法
- 接口可以继承多个接口

## 使用场景
**定义能力/规范，不关心是谁，只关心能不能做这件事**。

---

# 八、抽象类 vs 接口（面试必考）

| 对比项        | 抽象类                     | 接口                          |
|--------------|----------------------------|--------------------------------|
| 继承         | 单继承                     | 多实现、多继承                 |
| 构造器       | 有                         | 无                             |
| 成员变量     | 可以各种修饰符             | 只能 public static final（常量）|
| 方法         | 抽象+普通+静态都可以       | Java8+：抽象、default、static   |
| 设计思想     | **is-a**（是什么）| **can-do**（具备什么能力）|

一句话：
- **抽象类：模板，继承血缘**
- **接口：规范，扩展能力**

---

# 九、一张图串起所有概念
1. **类** → 造 **对象**
2. **子类 extends 父类** → 继承 + 重写
3. **父类引用 = 子类对象** → 多态
4. 想强制子类实现方法 → **抽象类 / 接口**
5. 要单继承、有属性、有构造 → **抽象类**
6. 要多实现、定规范、给能力 → **接口**
