我逐行**精讲这句代码里的所有 Java 语法**，每个关键字、符号、含义都讲清楚：

```java
private static void checkAge(int age) throws AgeIllegalException {
    if(age < 0) {
        // 手动抛出异常
        throw new AgeIllegalException("年龄不能为负数：" + age);
    }
}
```

---

## 1. 方法声明部分
```java
private static void checkAge(int age) throws AgeIllegalException
```

### ① `private`
- 访问修饰符
- 表示这个方法**只能在当前类内部使用**，外部类不能调用

### ② `static`
- 静态关键字
- 表示这是**静态方法**，可以直接通过类名调用，不需要 new 对象

### ③ `void`
- 返回值类型
- 表示这个方法**执行完不返回任何数据**

### ④ `checkAge(int age)`
- `checkAge`：方法名，自己定义的，意思“检查年龄”
- `int age`：**形式参数**
  - `int`：参数类型是整数
  - `age`：参数名，外面调用时传进来的值会存在这里

### ⑤ `throws AgeIllegalException`
- `throws`：Java 关键字，用在**方法声明上**
- 作用：**声明这个方法可能会抛出某种异常**
- 含义：
  > 我这个 `checkAge` 方法，有可能抛出 `AgeIllegalException` 异常，
  > 谁调用我，谁就必须处理这个异常（try-catch 或者继续 throws）

---

## 2. 方法体逻辑
```java
if(age < 0) {
    throw new AgeIllegalException("年龄不能为负数：" + age);
}
```

### ① `if(age < 0)`
- 条件判断语句
- 如果传入的年龄 **小于 0**，就执行大括号里的代码

### ② `throw`
- Java 关键字，用于**手动抛出异常对象**
- 一旦执行 `throw`，方法会**立即停止执行**，直接跳转到捕获该异常的地方

### ③ `new AgeIllegalException(...)`
- `new`：创建一个对象
- `AgeIllegalException`：你自定义的异常类
- `("年龄不能为负数：" + age)`：调用异常类的构造方法，传入异常提示信息
- 这行整体就是：**创建一个异常对象**

---

## 3. 整句连起来含义
```java
throw new AgeIllegalException("年龄不能为负数：" + age);
```

翻译成人话：
> 我现在**主动抛出一个异常**，
> 异常信息是“年龄不能为负数：xxx”，
> 程序立刻终止当前方法，去找 catch 处理。

---

## 4. 整体方法总结
```java
private static void checkAge(int age) throws AgeIllegalException {
    if(age < 0) {
        throw new AgeIllegalException("年龄不能为负数：" + age);
    }
}
```

功能：
1. 接收一个 int 类型年龄
2. 如果年龄 < 0，就**手动抛出自定义异常**
3. 方法声明 `throws`，告诉调用者：我可能抛异常，你要处理

对应的语法点：
- `private static` 方法修饰
- `void` 无返回值
- `int age` 方法参数
- `throws` 声明异常
- `if` 判断
- `throw` 手动抛异常
- `new` 创建异常对象
