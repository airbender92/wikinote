# 一、先讲清楚：接口里的 `Character` 是什么
## 1. 它不是Java自带类，是你自己定义的**抽象父类**
代码里这个 `Character`：
```java
interface Attackable {
    void attack(Character target);
}
```
方法参数 `Character target`，指的就是下面这段抽象角色类：
```java
// 你自己写的抽象类
abstract class Character {
    private String name;
    private int hp;
    // 构造、扣血、isAlive、getName 方法...
}
```

### 含义翻译
`void attack(Character target)`
= 攻击行为方法，接收**任意一个角色对象**作为被攻击目标。

## 2. 为什么参数写 Character，而不写 Warrior / Mage？
### 核心：多态 + 统一规范
1. `Warrior`、`Mage` 都 `extends Character`，都是 `Character` 的子类；
2. 只要是角色（战士、法师、以后加弓箭手、刺客），都属于 `Character`；
3. 如果写 `Warrior target`，那法师就只能打战士，不能打法师，代码写死、扩展性极差；
4. 用父类 `Character` 做参数：**所有角色都能互相攻击**，通用。

举个例子：
- 战士亚瑟 `Warrior` 是 `Character`
- 法师吉安娜 `Mage` 也是 `Character`
调用 `attack()` 时，传谁都行：
```java
warrior.attack(法师对象);
mage.attack(战士对象);
```

## 3. 类型关系梳理
```
抽象父类：Character
├─ 子类1：Warrior 战士（实现Attackable）
└─ 子类2：Mage 法师（实现Attackable）

接口：Attackable
  规定方法：attack(Character 任意角色)
```

# 二、完整对照代码，一眼看懂依赖关系
```java
package org.example;

// 抽象角色（attack方法里用到的Character就是它）
abstract class Character {
    private String name;
    private int hp;

    public Character(String name, int hp) {
        this.name = name;
        this.hp = hp;
    }

    public void takeDamage(int damage) {
        hp -= damage;
        System.out.println(name + " 受到 " + damage + " 伤害，剩余 HP：" + hp);
    }
    public boolean isAlive() { return hp > 0; }
    public String getName() { return name; }
}

// 攻击接口，方法参数类型是上面的抽象类 Character
interface Attackable {
    // target 必须是 Character 及其子类（战士/法师）
    void attack(Character target);
}

// 战士子类
class Warrior extends Character implements Attackable {
    public Warrior(String name) { super(name, 100); }
    @Override
    public void attack(Character target) {
        System.out.println(getName() + " 挥剑猛击！");
        target.takeDamage(25);
    }
}

// 法师子类
class Mage extends Character implements Attackable {
    public Mage(String name) { super(name, 70); }
    @Override
    public void attack(Character target) {
        System.out.println(getName() + " 施放火球术！");
        target.takeDamage(40);
    }
}
```

# 三、关键疑问解答
### 1. 接口能识别抽象类 Character 吗？
可以，同一个包下类、接口互相可见，不用额外导入。
接口只是**定义方法签名**，只关心参数是什么类型，不管这个类型是抽象类、普通类。

### 2. 如果我把参数改成 Attackable 会怎么样？
```java
// 错误示范，限制很大
void attack(Attackable target);
```
- 只有实现了攻击接口的单位才能被打；
- 假如以后加一个**不能攻击、只能挨打的NPC怪物**（只继承Character，不实现Attackable），就无法被攻击；
- 用 `Character` 做参数包容性更强：**所有角色，无论能不能攻击，都可以被攻击**。

### 3. 运行时底层逻辑
```java
Character target = new Mage("吉安娜");
warrior.attack(target);
```
1. `target` 编译类型是 `Character`；
2. 实际对象是 `Mage` 子类；
3. 调用 `target.takeDamage()` 时，执行父类Character里统一写好的扣血逻辑。

# 四、一句话总结
`attack(Character target)` 里的 `Character` 是你自定义的**抽象角色父类**，用来代表游戏里所有人物（战士、法师等），让攻击方法支持任意角色互殴，是面向对象「父类引用接收子类对象」多态的典型用法。
