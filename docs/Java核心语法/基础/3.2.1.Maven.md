配置Maven主要就两步：**解压**和**设置环境变量**。核心是为了让电脑能找到Maven的`mvn`命令。

我把详细步骤和可能出现的问题都整理在下面了，跟着操作就行。

### 📥 第一步：下载与解压

1.  **下载地址**：访问[Maven官网下载页](https://maven.apache.org/download.cgi)。
2.  **选择版本**：下载“`apache-maven-3.9.9-bin.zip`”这样的文件（注意必须是“bin”结尾）。
3.  **解压路径**：**路径中不能有中文或空格**。例如，解压到 `D:\Java\maven\apache-maven-3.9.9`，自己记住就行。

### ⚙️ 第二步：配置环境变量

这是关键，目的就是创建`MAVEN_HOME`变量，并把`bin`目录加到`Path`里，让系统能找到`mvn`命令。

1.  **打开设置窗口**：右键点击“此电脑” → “属性” → “高级系统设置” → “环境变量”。
2.  **新建 `MAVEN_HOME` 变量**：
    *   在 **“系统变量”** 区域，点击“新建”。
    *   **变量名**：输入 `MAVEN_HOME`
    *   **变量值**：粘贴你刚才解压的Maven根目录路径（例如，`D:\Java\maven\apache-maven-3.9.9`）。
    *   点击“确定”保存。
3.  **编辑 `Path` 变量**：
    *   在 **“系统变量”** 区域，找到并选中 `Path`，点击“编辑”。
    *   点击“新建”，输入 `%MAVEN_HOME%\bin`。
    *   一路点击“确定”，关闭所有设置窗口。

### ✅ 第三步：验证配置

1.  **打开命令提示符(cmd)**：按下 `Win + R` 键，输入 `cmd` 并回车。
2.  **执行验证命令**：在命令行窗口中输入 `mvn -v` 并回车。
3.  **检查输出**：如果看到类似下图的Maven和Java版本信息，就说明配置成功啦！

```text
Apache Maven 3.9.9 (...)
Maven home: D:\Java\maven\apache-maven-3.9.9
Java version: 17.0.12, vendor: Oracle Corporation, runtime: ...
```

如果提示 **`'mvn' 不是内部或外部命令`**，通常表示环境变量没配置好，请返回上一步检查；如果提示 **`JAVA_HOME` 相关错误**，请确保JDK已正确安装，且**`JAVA_HOME`环境变量也已配置**，它指向的是JDK的根目录，而不是`\bin`子目录。

### 🛠️ 第四步：（可选但推荐）后续优化

*   **修改本地仓库位置**：Maven默认将依赖包下载到C盘，长期使用会占用大量空间。建议修改到你空间较大的其他盘符。
    *   在Maven解压目录下找到 `conf/settings.xml` 文件，用记事本等文本编辑器打开。
    *   找到被 `<!-- -->` 注释掉的 `<localRepository>` 标签。
    *   将其移动到注释外，并修改为你想要的新路径，例如 `D:\Java\maven-repo`。
*   **配置国内镜像源**：为解决Maven官方仓库下载慢的问题，推荐配置国内的阿里云镜像。
    *   同样是编辑 `conf/settings.xml` 文件。
    *   找到 `<mirrors>` 标签，在其中添加以下阿里云镜像的配置：
        ```xml
        <mirror>
          <id>aliyunmaven</id>
          <mirrorOf>central</mirrorOf>
          <name>阿里云公共仓库</name>
          <url>https://maven.aliyun.com/repository/public</url>
        </mirror>
        ```

配置完成后，推荐在执行 `mvn -v` 的同一个命令行窗口里，再执行一次 `mvn help:system` 命令来最终测试一下。这条命令会触发Maven去下载一些必要的插件，可以验证你的本地仓库和阿里云镜像是否配置成功。

### 💎 总结

总而言之，整个过程就是：下载、解压、配置环境变量、验证。只要确保路径**没有空格和中文**，并且`JAVA_HOME`已正确配置，基本就不会出问题。配置成功后，你的Maven也就可以正常使用了。
