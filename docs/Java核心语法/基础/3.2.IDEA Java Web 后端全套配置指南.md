# IDEA Java Web/后端全套配置指南（社区版免费，Spring Boot/Servlet通用）
分三大块：**必装插件 → 全局环境配置(Maven/Tomcat) → 项目专属配置**，新手按顺序操作即可。
先区分：你装的是 **IDEA社区版（免费）**，没有内置Tomcat、Jakarta EE全套工具，所有Web相关插件都要手动装。

## 一、后端Web开发【必装插件】（File → Settings → Plugins → Marketplace搜索安装，重启IDEA生效）
### 1. Web运行必备（传统Servlet项目必须）
- **Smart Tomcat**（社区版唯一免费Tomcat运行插件）
  作用：绑定本地Tomcat，一键启动Web项目、热部署、访问页面，弥补社区版无官方Tomcat集成缺陷。

### 2. Spring Boot主流后台必备（90%企业后端用SpringBoot）
- **Spring Boot Helper**：yml/properties配置自动提示、快速跳转配置、端口/日志识别
- **MyBatisX**（MyBatis必装）
  Mapper接口与XML双向跳转、SQL高亮、一键根据数据库表生成Entity/Mapper/Service/Controller，解决MyBatis开发痛点。

### 3. 代码简化刚需（所有后端通用）
1. **Lombok**
   用`@Data/@Slf4j`自动生成get/set/toString/日志，少写上千行实体模板代码；
   安装后必须开启注解处理：Settings → Build → Compiler → Annotation Processors 勾选Enable。
2. **Maven Helper**
   可视化Maven依赖树，一键排查Jar包冲突、快速排除冲突依赖，解决`ClassNotFound`、版本冲突报错。

### 4. 接口测试神器（不用切Postman）
- **Restful Fast Request**
  自动扫描项目所有Controller接口，侧边栏直接填参数、发GET/POST请求、返回JSON格式化，内置接口调试工具。

### 5. 规范&排错工具
- **Alibaba Java Coding Guidelines**：阿里开发规范实时检测，自动修复不规范代码、空指针风险、魔法值问题。
- **Rainbow Brackets**：彩色分层括号，多层if/for嵌套不会看错括号匹配。
- **GsonFormatPlus**：粘贴JSON字符串，一键生成Java实体类，支持自动加Lombok注解。

### 可选效率插件（进阶）
- EasyCode：数据库表一键全套CRUD代码生成
- JRebel：热部署（修改代码不用重启服务，大型项目提速）
- Json Assistant：JSON格式化、转义、压缩
- JPA Buddy：Spring Data JPA开发增强（ORM项目使用）

## 二、全局环境配置（只配置一次，所有项目复用）
### 1. Maven配置（管理项目所有jar依赖，后端核心）
1. 下载Maven压缩包解压，配置环境变量`MAVEN_HOME`（可选，IDEA自带内嵌Maven，但推荐本地自定义）
2. IDEA配置：File → Settings → Build, Execution, Deployment → Build Tools → Maven
   - Maven home path：选择你本地解压的Maven目录（不用内嵌版，下载速度更快）
   - User settings file：指定maven/conf/settings.xml
   - 修改settings.xml两点：
     ① 自定义本地仓库路径（存放所有下载的jar包）
     ② 添加**阿里云镜像**，解决中央仓库下载慢：
     ```xml
     <mirror>
         <id>aliyunmaven</id>
         <mirrorOf>central</mirrorOf>
         <url>https://maven.aliyun.com/repository/public</url>
     </mirror>
     ```
3. 导入项目后，右侧Maven面板刷新，自动下载所有依赖。

### 2. Tomcat配置（传统Servlet/JSP项目需要；SpringBoot内置Tomcat可不用）
1. 先下载Apache Tomcat（解压到无中文无空格路径，如`D:\server\tomcat10`）
2. IDEA配置Smart Tomcat：右上角运行配置 → Add New → Smart Tomcat
   - Tomcat Server：选择本地Tomcat根目录
   - Deployment Directory：`$PROJECT_DIR$\src\main\webapp`（Web资源目录）
   - Context Path：`/`（访问地址localhost:8080，填项目名就是localhost:8080/项目名）
   - HTTP Port：默认8080，冲突可改成8081/8082

### 3. 数据库连接配置（MySQL/PostgreSQL必配）
1. 右侧边栏打开Database面板，点击+号添加数据源MySQL
2. 填入数据库地址、账号、密码，自动下载驱动
3. 配置完成后直接在IDEA写SQL、执行查询、查看表结构，配合MyBatisX生成代码。

### 4. JDK全局绑定
File → Project Structure → Project SDK，选择你之前安装的JDK17，统一所有项目JDK版本，避免版本报错。

## 三、分两种后端项目：新建项目后额外配置
### 方案A：Spring Boot后台（现在企业主流，无webapp，不用Tomcat外置）
1. 新建项目：New Project → Spring Initializr，选择JDK版本，勾选依赖：
   - Spring Web（Web接口必备）
   - MySQL Driver、MyBatis Framework（数据库）
   - Lombok（简化实体）
2. 核心配置文件`application.yml`：配置端口、数据库连接、MyBatis映射路径
3. 无需配置Smart Tomcat，右上角直接绿色三角启动内置Tomcat
4. Lombok生效：开启注解处理器（前文插件部分说明）

### 方案B：传统Java Web Servlet项目（带web.xml、jsp页面）
1. 新建Maven项目，archetype选`maven-archetype-webapp`
2. 配置Smart Tomcat运行环境（第二部分2小节）
3. 补全目录：手动创建`src/main/java`、`src/main/resources`并标记为源码根目录
4. pom.xml打包方式设为`war`，引入Servlet、JSP、MySQL依赖
5. 启动Smart Tomcat访问jsp页面

## 四、通用优化配置（必调，解决90%新手报错）
1. **自动导入Maven依赖**
   Settings → Build → Maven → Importing，勾选Import Maven projects automatically，修改pom自动加载jar。
2. **编码统一UTF-8**
   Settings → Editor → File Encodings，全部改为UTF-8，勾选透明native转换，解决中文乱码。
3. **自动编译**
   Settings → Build → Compiler，勾选Build project automatically；
   快捷键Ctrl+Shift+Alt+/ 打开Registry，勾选compiler.automake.allow.when.app.running，实现热编译。
4. 注释模板、类头作者信息
   Settings → Editor → File and Code Templates → Class，自定义作者、日期注释。

## 五、额外需要下载的外部工具（非IDEA插件，本地安装）
1. Maven：依赖管理工具（必须）
2. Apache Tomcat：传统Web项目容器（SpringBoot可省略）
3. MySQL/Navicat：数据库服务与可视化工具
4. Git：代码版本管理，团队开发必备
5. Postman（可选）：接口测试，搭配Restful Fast Request插件二选一

外部软件：Maven + MySQL（SpringBoot后台无需Tomcat）
