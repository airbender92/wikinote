这个报错信息已经把问题**直接说穿了**：
`wrong name: MyFirstApp`
意思是：**类的全限定名不对，你代码里带了包名，但运行时没按包名来。**

# 根本原因
你的代码 **第一行写了 package**，比如：
```java
package org.stream;

public class MyFirstApp {
    public static void main(String[] args) {
        System.out.println("Hello");
    }
}
```

但你现在：
- 直接把 `.java` 文件扔在某个文件夹里
- 直接 `javac MyFirstApp.java`
- 直接 `java MyFirstApp`

JVM 内部记录的类名是：
`org.stream.MyFirstApp`
而你运行时给的是：
`MyFirstApp`
名字对不上 → 报错 `wrong name`。

---

# 解决方法（二选一，推荐第一种）

## 方法1：按包结构运行（正确规范做法）
1. 新建文件夹结构，必须跟包名一致：
```
org/
   stream/
      MyFirstApp.java
```

2. 进入 **最外层目录**，编译：
```bash
javac org/stream/MyFirstApp.java
```

3. 仍然在**外层目录**，运行时**带上包名**：
```bash
java org.stream.MyFirstApp
```

这样就不会报 wrong name 了。

---

## 方法2：最简单粗暴（新手测试用）
直接**删掉代码里的 package 那一行**：

```java
// 删掉这一行
// package org.stream;

public class MyFirstApp {
    public static void main(String[] args) {
        ...
    }
}
```

然后重新编译运行：
```bash
javac MyFirstApp.java
java MyFirstApp
```

立刻就能跑起来。

---

# 一句话总结
你写了 `package org.stream;`，
就必须用 `java org.stream.MyFirstApp` 运行，
不能用 `java MyFirstApp`。
