在 Java 里引入其他类，主要就这 **3 种方式**，一看就会：

---

## 1. 最常用：用 `import` 导入（推荐）
```java
// 导入某个具体类
import java.util.ArrayList;
import java.util.List;

// 导入包下所有类（不推荐，可读性差）
import java.util.*;

public class Test {
    public static void main(String[] args) {
        // 直接用
        List<String> list = new ArrayList<>();
    }
}
```

---

## 2. 不导入，直接写**全类名**（临时用一次时）
```java
public class Test {
    public static void main(String[] args) {
        // 不用 import，直接写全包名+类名
        java.util.ArrayList<String> list = new java.util.ArrayList<>();
    }
}
```

---

## 3. 同一个包下的类：**不用 import**
比如：
```
com/example/
    A.java
    B.java
```
在 A 里可以直接 new B()，不需要导入。

---

## 4. 静态导入（导入静态方法/常量）
```java
// 导入 Arrays 里的所有静态方法
import static java.util.Arrays.*;

public class Test {
    public static void main(String[] args) {
        // 直接用，不用写 Arrays.
        int[] arr = {1,2,3};
        sort(arr);
    }
}
```

---

### 简单总结
- 要用别的类 → **import 全包名.类名**
- 同包 → **直接用**
- 不想写类名前缀 → **import static**
