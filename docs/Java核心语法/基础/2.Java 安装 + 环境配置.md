# Java JDK 安装+环境配置保姆级一步到位教程（Windows Win10/Win11 通用）
## 前置说明
1. **JDK 是什么**：Java开发工具包，包含运行+编译代码工具（必须装JDK，只装JRE只能跑程序不能写代码）
2. **版本选择**：企业主流长期支持版 **JDK8、JDK17、JDK21**，新手推荐 JDK17（免费开源、无版权风险）
3. **下载渠道（免费无授权限制）**：Eclipse Adoptium（推荐）https://adoptium.net/

## 一、下载 JDK 安装包
1. 打开 adoptium.net，选择版本：Java 17 LTS
2. 操作系统：Windows，架构 x64
3. 安装包类型：**Installer (.msi)** 图形安装程序（新手首选）
4. 点击下载，保存到本地

## 二、安装 JDK（关键：改安装路径）

1. 双击下载好的 `.msi` 文件，允许管理员运行
2. 许可协议：Next 下一步
3. **重点步骤：更改安装目录**
   - 不要用默认路径 `C:\Program Files\Java\xxx`（带空格容易报错）
   - 点击【更改】，设置纯英文无空格路径，示例：`D:\Dev\jdk17`
   - 记住这个路径，后面配置环境变量必须用！
   > ❌ 禁止路径含中文、空格、特殊符号：D:\软件\jdk、D:\JDK 17 全部不行
4. 可选组件：保持默认，公共JRE可取消勾选（JDK自带JRE）
5. 一路【下一步】等待安装完成，点关闭


## 三、配置环境变量（核心步骤，分4小步）
### 方式1：最快快捷入口（推荐）
按下 `Win + R`，输入 `sysdm.cpl` 回车 → 弹出系统属性窗口

### 方式2：鼠标右键打开
1. 桌面右键【此电脑】→【属性】
2. 页面找到【高级系统设置】
3. 右下角点击【环境变量】

### 步骤1：新建系统变量 JAVA_HOME
只操作窗口下半部分 **系统变量**（所有用户生效），不要改上方用户变量
1. 系统变量区域点【新建】
2. 变量名：`JAVA_HOME`（**全部大写，一个字母不能错**）
3. 变量值：粘贴刚才的JDK根目录 `D:\Dev\jdk17`
   > 注意：只写到jdk文件夹，**不能带 \bin**
4. 点击确定保存

### 步骤2：编辑 Path 变量
1. 在系统变量列表找到 `Path`，双击编辑
2. 点右侧【新建】，输入：
   ```
   %JAVA_HOME%\bin
   ```
3. 选中刚添加的这一行，点【上移】拖到列表最顶部（防止多JDK冲突）
4. 确定保存

### 步骤3：（可选，老项目兼容）配置 CLASSPATH
新JDK8+基本不需要，老框架报错再配：
系统变量→新建
- 变量名：`CLASSPATH`
- 变量值：`.;%JAVA_HOME%\lib\dt.jar;%JAVA_HOME%\lib\tools.jar`
> 最开头英文句号 `.` 不能丢，代表当前项目目录

### 步骤4：全部保存
所有弹窗依次点【确定】关闭，不要中途取消。

## 四、验证是否配置成功（必做！）
1. 完全关闭所有已打开的 CMD/PowerShell（旧窗口不加载新环境）
2. Win+R 输入 `cmd` 打开全新命令行
3. 依次输入3条命令，全部正常输出版本号即成功：
```bash
# 1. 查看Java运行版本
java -version

# 2. 查看编译器（javac是写代码必备，能输出版本说明JDK完整配置）
javac -version

# 3. 校验JAVA_HOME路径是否读取正确
echo %JAVA_HOME%
```
### 成功示例输出（JDK17）
```
java version "17.0.12" LTS
Java(TM) SE Runtime Environment (build 17.0.12+7-LTS)
Java HotSpot(TM) 64-Bit Server VM (build 17.0.12+7-LTS, mixed mode, sharing)

javac 17.0.12

D:\Dev\jdk17
```

### 常见报错排查
1. 'java' 不是内部或外部命令
   - 原因：JAVA_HOME写错 / Path没加 `%JAVA_HOME%\bin` / 没重启cmd
2. javac 命令找不到
   - 只装了JRE没装JDK，重新下载Installer安装包
3. 版本显示旧JDK
   - Path里旧Java路径在最上方，把`%JAVA_HOME%\bin`上移到顶部

## 附：macOS 极简配置（补充）
1. 下载 `.dmg` 安装包双击安装
2. 打开终端，编辑环境配置文件
```bash
# M系列/新版mac默认zsh
vim ~/.zshrc
# Intel旧版bash
vim ~/.bash_profile
```
3. 文件末尾添加两行
```bash
export JAVA_HOME=$(/usr/libexec/java_home)
export PATH=$PATH:$JAVA_HOME/bin
```
4. 生效配置
```bash
source ~/.zshrc
# 验证
java -version
javac -version
```

## 附：Linux（Ubuntu/CentOS）极简配置
1. 解压jdk压缩包移动到 `/usr/lib/jvm`
```bash
sudo tar -zxvf jdk-17_linux-x64_bin.tar.gz -C /usr/lib/jvm/
```
2. 编辑全局环境
```bash
sudo vim /etc/profile
```
3. 文件末尾添加
```bash
export JAVA_HOME=/usr/lib/jvm/jdk-17.0.12
export PATH=$PATH:$JAVA_HOME/bin
```
4. 生效并验证
```bash
source /etc/profile
java -version
```
