# Java 入门介绍（超通俗版）
## 1. Java 是什么？
Java 是一门**面向对象、跨平台、强类型**的编程语言，由 Sun 公司（后被甲骨文收购）在 1995 年推出。
特点一句话总结：
> **一次编写，到处运行（Write Once, Run Anywhere）**

只要装了 Java 运行环境（JVM），Windows、macOS、Linux、服务器、手机、嵌入式设备都能跑。

---

## 2. 为什么学 Java？
- 应用极广：后端开发、安卓开发、大数据、金融系统、电商网站
- 就业岗位多，生态成熟，资料最全
- 语法严谨，适合编程入门，学会 Java 再学其他语言很轻松
- 稳定、安全、性能好，大企业最爱用

---

## 3. Java 核心组成
### JDK、JRE、JVM 区别
- **JVM（Java 虚拟机）**：真正运行 Java 代码的虚拟计算机
- **JRE（Java 运行环境）** = JVM + 核心类库 → 只能跑写好的程序
- **JDK（Java 开发工具包）** = JRE + 编译器(javac) + 开发工具 → 用来写代码、编译代码

**学开发必须装 JDK**。

---

## 4. Java 基础语法结构
最简单的 Java 程序：
```java
public class Hello {
    public static void main(String[] args) {
        System.out.println("Hello Java!");
    }
}
```

要点：
- 一个 `.java` 文件对应一个公开类（`public class`）
- 程序入口固定是：`public static void main(String[] args)`
- 语句以 `;` 结尾
- 严格区分大小写

---

## 5. 入门必学基础内容
按顺序学最轻松：
1. 环境安装（JDK + IDEA/Eclipse）
2. 变量、数据类型（int、double、String、boolean 等）
3. 运算符（+ - * / % 等）
4. 流程控制：if-else、for、while、switch
5. 数组
6. 面向对象：类、对象、方法、构造方法
7. 封装、继承、多态
8. 常用集合：List、Map
9. 异常处理、文件 IO、简单项目

## 7. 学习路线建议
1. 先看懂基础语法，能写简单计算、循环
2. 做小练习：计算器、猜数字、成绩统计
3. 理解面向对象思想
4. 进阶学：集合、IO、多线程、数据库
5. 最后做项目：图书管理系统、学生管理系统等
