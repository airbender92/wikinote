在 Java 里 **`->`** 只有一个用途：
**Lambda 表达式的箭头符号**

简单说就是：**用来简写函数式接口的匿名内部类**。

---

## 1. 长啥样
```java
(参数) -> { 代码 }
```

## 2. 用来干嘛
用来**快速写一个“小方法”**，不用写 class、不用写方法名。

### 例子 1：最简单
```java
() -> System.out.println("Hello");
```
意思：没有参数，执行一句打印。

### 例子 2：带参数
```java
(int a, int b) -> a + b;
```
意思：接收 a 和 b，返回 a+b。

### 例子 3：多行代码
```java
(s) -> {
    System.out.println(s);
    return s.length();
};
```

---

## 3. 真实使用场景（最常见）
### 遍历集合
```java
List<String> list = List.of("A", "B", "C");

list.forEach(s -> System.out.println(s));
```
这里的 `s -> System.out.println(s)` 就是 Lambda。

### 线程
```java
new Thread(() -> {
    System.out.println("线程运行");
}).start();
```

---

## 4. 一句话记住
- **`->` = Lambda 箭头**
- 左边：参数
- 右边：要执行的代码

# switch 里的 -> 箭头语法（JDK14+正式特性）
## 一、核心作用
1. 替代传统 `case :` 冒号写法；
2. **自动跳出分支，不用写 break**，彻底避免 case 穿透（fall-through）；
3. switch 可以变成**表达式，直接返回值赋值给变量**。

## 二、传统冒号 vs 箭头写法对比
### 老式（容易忘 break，会穿透）
```java
int week = 1;
switch (week) {
    case 1:
        System.out.println("周一");
        break; // 必须写，否则会执行下一个case
    case 2:
        System.out.println("周二");
        break;
    default:
        System.out.println("无效");
}
```

### 新式 -> 箭头（无break，执行完自动结束）
```java
int week = 1;
switch (week) {
    case 1 -> System.out.println("周一");
    case 2 -> System.out.println("周二");
    default -> System.out.println("无效");
}
```

## 三、高级用法1：一个case匹配多个值
逗号分隔多个条件，共用一段逻辑
```java
int week = 6;
switch (week) {
    case 1,2,3,4,5 -> System.out.println("工作日");
    case 6,7 -> System.out.println("周末");
    default -> System.out.println("错误");
}
```

## 四、高级用法2：switch 作为表达式（能返回值）
整体可以赋值给变量，日常最常用
```java
int week = 3;
String res = switch (week) {
    case 1,2,3,4,5 -> "工作日";
    case 6,7 -> "周末";
    default -> "未知星期";
};
System.out.println(res);
```

## 五、箭头右侧多行代码块：用 yield 返回值
如果分支需要多行代码，用 `{}` 包裹，用 `yield` 代替 return 返回结果
```java
int score = 85;
String level = switch (score / 10) {
    case 9,10 -> "优秀";
    case 8 -> {
        System.out.println("分数良好");
        yield "良好"; // 返回值
    }
    case 6,7 -> "及格";
    default -> "不及格";
};
```

## 六、关键规则总结
1. `->` 只在 JDK14 及以上可用，JDK8/11 不支持；
2. 箭头分支执行完毕**自动退出switch**，不会穿透；
3. 单行逻辑直接写，多行代码必须加大括号，返回值用 `yield`；
4. switch 表达式必须覆盖所有情况，要有 `default`，否则编译报错；
5. Lambda 的 `->` 和 switch 的 `->` 符号一样，但完全是两套独立语法，不要混淆。
