我用最直白、新手一下就懂的方式，给你讲清楚 **package 包名** 到底干嘛、怎么写、为什么要写 `org.example`。

# 一、包（package）有什么用？
简单说 3 个作用：

1. **分类管理代码**
   项目大了，几百个类，不分类会乱成一锅粥。
   包就像电脑里的**文件夹**，把相关的类放一起。

2. **避免类名冲突**
   你写一个 `User` 类，别人也写一个 `User` 类。
   有了包：
   - `org.example.User`
   - `com.baidu.User`
   就不会冲突。

3. **控制访问权限**
   不写 `public/private/protected` 时，默认**同包才能访问**。
   包是 Java 权限体系的一部分。

---

# 二、怎么定义包？
就是在 **.java 文件最顶部** 写：
```java
package org.example;
```

规则：
- 必须是文件**第一行代码**（注释可以在它上面）
- 结尾**不加分号**也能运行，但规范要加
- 只能字母、数字、点 `.`、下划线 `_`
- 一般**全部小写**

---

# 三、`org.example` 是什么意思？
这是**域名反写**的规范，全球通用：

- `org`：组织、非盈利机构
- `example`：项目名/公司名

比如：
- 百度：`com.baidu`
- 阿里：`com.alibaba`
- 你的项目：`org.example`

点 `.` 对应文件夹层级：
```
src/
└── org/
    └── example/
        └── 你的.java文件
```

你写 `package org.example;`
Java 就会要求：**这个文件必须放在 org/example/ 目录下**，否则报错。

---

# 四、一个完整示例
文件路径：
```
src/org/example/Test.java
```

Test.java 内容：
```java
package org.example;

public class Test {
    public static void main(String[] args) {
        System.out.println("我在 org.example 包下");
    }
}
```

---

# 五、新手最容易犯的错
1. 包名写在类中间/下面 → 报错
2. 包名和文件夹不一致 → 报错
3. 包名用大写、空格、中文 → 不规范，容易错

---

# 六、一句话总结
- **package 包名 = 文件夹 + 命名空间**
- `package org.example;` 表示这个类放在 `org/example/` 目录下
- 作用：分类、防重名、控权限
