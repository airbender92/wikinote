# Maven Java项目目录结构完整分析
这是一个标准 **IDEA + Maven** 管理的Java基础项目，整体分为「Maven配置目录、业务源码目录、测试目录、编译输出目录、IDE配置目录」五大块，逐段拆解：

## 一、项目根目录：my-first-java
项目名称，存放整个工程所有文件，路径：`D:\wybD\Codes\demos\javademo\my-first-java`
根目录下核心文件：
1. **pom.xml**
    Maven核心配置文件，定义项目JDK版本、依赖包、打包方式、插件等，整个项目的构建、依赖管理全靠它。
2. **.gitignore**
    Git忽略文件，配置哪些文件不提交到代码仓库（target、.idea、编译缓存等）。

## 二、IDE专属配置文件夹（仅IDEA使用）
### 1. .idea
IDEA编辑器的本地配置文件夹，**不需要提交git**，存放：
- 代码高亮、窗口布局、运行配置、插件缓存、模块配置等；
- 换电脑/换编辑器可直接删除，不影响代码逻辑。

### 2. .mvn
Maven包装器目录，内含mvnw脚本：
不用本地安装Maven，直接用项目自带的Maven版本构建，保证所有人构建环境统一。

## 三、核心源码目录 src（Maven标准源码根）
### 1. src/main（业务主代码，上线运行代码）
#### 1.1 src/main/java
**Java业务代码存放位置**，遵循包结构 `org.example`
- 包：`org.example` 是默认Maven生成的基础包，所有类都放在这个包下：
  - `Main`：项目入口主类，带`main()`方法，程序启动入口；
  - `Student.java`：实体类（学生实体，封装属性、get/set）；
  - `TestVariable/TestOperator/TestControl/TestArray/TestMethod`：分模块测试类，分别练习变量、运算符、流程控制、数组、方法；
  - `TestAPI`：Java常用API测试类（字符串、工具类等）。
#### 1.2 src/main/resources
**静态资源目录**，存放配置文件：
properties、yml、xml、图片、文本等资源文件，编译后会复制到classpath，程序运行时可读取。当前为空，说明还没用到配置文件。

### 2. src/test（单元测试代码）
存放测试代码（JUnit单元测试），和main目录代码隔离，打包上线时不会被打进jar包，目前为空，还没写单元测试。

## 四、target：编译输出目录
Maven自动生成，执行编译/打包命令后产生，**可随时删除，会自动重建**：
1. 存放编译后的 `.class` 字节码文件；
2. 打包后的jar/war程序包；
3. 编译日志、测试报告、资源副本；
日常开发不用手动修改里面内容。

## 五、侧边栏辅助项（IDEA视图）
1. **外部库**：Maven下载的所有第三方依赖jar包（JDK、工具类依赖等）；
2. **临时文件和控制台**：IDEA运行日志、程序输出控制台窗口。

# 结构特点总结
1. **标准Maven规范**：严格遵循 `main业务代码 / test测试代码 / resources资源` 分层，行业通用规范；
2. **学习型项目**：类名全是`TestXXX`，按知识点拆分，搭配实体类Student，属于Java基础入门练习项目；
3. 分离设计：IDE配置(.idea)、构建产物(target)、业务源码完全隔离，便于版本管理和多人协作。
