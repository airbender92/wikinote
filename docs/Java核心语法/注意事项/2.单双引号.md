在 Java 里**单引号 `' '` 和双引号 `" "` 完全不是一回事**，你这段代码写得是对的，我给你讲清楚规则：

---

### 1. 单引号 `' '`
- 只能放 **一个字符**
- 对应类型：`char`

```java
char grade = 'A';   // ✔ 正确
char c = '中';      // ✔ 正确（一个汉字也是一个 char）
char wrong = 'ab';  // ❌ 错误，单引号里只能有一个字符
```

---

### 2. 双引号 `" "`
- 放 **一串字符（字符串）**
- 对应类型：`String`

```java
String name = "张三";  // ✔ 正确
String s = "A";       // ✔ 正确
String s = 'A';       // ❌ 错误，String 必须用双引号
```

---

### 简单记忆
- **单个字符 → char → 单引号 `' '`**
- **多个字符 → String → 双引号 `" "`**

你原来的代码：
```java
char grade = 'A';
String name = "张三";
```
**完全标准、正确。**
