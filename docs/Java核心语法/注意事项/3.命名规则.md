Java 文件名必须严格遵守规则，否则**编译/运行会报错**，核心就这几条：

# 1. 核心规则
- **文件名必须和 `public class` 类名完全一致**
  包括大小写，一个字都不能差。
- 后缀必须是 `.java`

例：
```java
public class Hello { ... }
```
文件名必须叫：**Hello.java**

---

# 2. 命名字符规则
- 只能用：**字母、数字、下划线 _、美元符 $**
- **不能以数字开头**
- 不能是 Java 关键字：`public`、`class`、`static`、`int` 等
- 建议：**见名知意，大驼峰**（每个单词首字母大写）
  如：Student.java、UserLogin.java

---

# 3. 常见错误示例
- 类名 `Demo` → 文件名 `demo.java` ❌ 大小写不一致
- 文件名 `1Hello.java` ❌ 数字开头
- 文件名 `public.java` ❌ 关键字
- 文件名 `my class.java` ❌ 有空格

---

# 4. 小知识点
- 一个 `.java` 文件里可以有多个 class，但**只能有一个 public class**
- 没有 public class 时，文件名可以随便，但**不推荐**

---

简单记：**文件名 = public 类名 + .java，大小写完全一样**。
