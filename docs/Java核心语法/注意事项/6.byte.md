在 Java 里，**byte** 就是**最小的整数类型，占 1 个字节**。

# 1. 基本信息
- 关键字：`byte`
- 占用空间：**1 字节（8 位）**
- 取值范围：**-128 ~ 127**
- 默认值：`0`

# 2. 怎么用
```java
byte age = 18;
byte temperature = -5;
byte max = 127;   // 最大
byte min = -128;  // 最小
```

# 3. 注意点
- 超过范围会报错：
  ```java
  byte b = 128;  // ❌ 编译错误
  ```
- byte 在运算时会**自动提升为 int**
```java
byte a = 10;
byte b = 20;
// byte c = a + b; ❌ 错误，a+b 变成 int 了
int c = a + b;    // ✔ 正确
```

# 4. 用来干嘛？
- 读写**文件、网络数据、图片、视频**
- 处理二进制流时大量使用
- 内存特别紧张时用来省空间
