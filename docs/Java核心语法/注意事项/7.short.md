# short（短整型）
- 占用空间：**2 字节（16 位）**
- 取值范围：**-32768 ～ 32767**
- 关键字：`short`
- 用途：存不大不小的整数，省内存

示例：
```java
short a = 100;
short b = -200;
short max = 32767;
short min = -32768;
```

---

# 快速对比（必背）
| 类型    | 字节 | 大致范围              |
|---------|------|-----------------------|
| byte    | 1    | -128 ~ 127            |
| short   | 2    | -32768 ~ 32767        |
| int     | 4    | -21亿 ~ 21亿          |
| long    | 8    | 超大范围              |

日常开发里：
- 一般整数直接用 **int**
- 内存紧张/数组很大时用 **short**
- 存文件/网络数据用 **byte**
