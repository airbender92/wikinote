必须写在 **包名后面，类定义前面**

### 正确顺序（固定死的）
1. **package 包名;** （第一行有效代码）
2. **import ...;**
3. **class 类 { ... }**

---

### 正确示例
```java
package org.example;   // 1. 包名必须最前面

import java.util.Arrays;  // 2. import 放中间

public class Test {       // 3. 最后才是类
    public static void main(String[] args) {
        int[] arr = {1,2,3};
        Arrays.sort(arr);
    }
}
```

---

### 错误写法
```java
import java.util.Arrays;  // ❌ import 不能在 package 前面
package org.example;
```

### 一句话记死
**package 第一，import 第二，class 第三**
