我用**最通俗、最直观**的方式给你讲懂：
**空指针 = 你想调用一个东西，但这个东西根本不存在。**

---

# 1. 什么是 null？
`null` 就是 **“啥也没有”**
- 没有对象
- 没有值
- 没有内存
- 就是个空壳

比如：
```java
User user = null;
```
意思是：
我声明了一个叫 `user` 的变量，但**它不指向任何用户对象**。

---

# 2. 什么是空指针异常（NullPointerException）？
当你写出这种代码：
```java
user.getName();
```

但 `user` 是 `null`，根本没有这个对象，
程序就会崩溃，报错：
> NullPointerException 空指针异常

就好比：
- 你让一个**不存在的人**说话
- 你打开一个**根本没有的房间**
- 你拨一个**空号码**

Java 会说：**我找不到这个对象，我崩了。**

---

# 3. 为什么 Optional 能解决它？
```java
Optional.ofNullable(user)
        .map(User::getName)
        .orElse("未知");
```

它的逻辑是：
- 如果 user 是 null → 不执行 getName()
- 直接跳到 orElse，给你一个默认值
- **不会崩溃**

相当于：
> 如果人不存在，就别让他说话了，直接返回“未知”。

---

# 4. 一句话总结
- **null = 没有对象**
- **空指针 = 你对不存在的对象做操作**
- **Optional = 帮你自动判断有没有，避免崩溃**
