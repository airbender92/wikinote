# Java 关键字（最核心版）

## 1. 访问修饰符（控制谁能访问）
- **public**：公开，谁都能用
- **private**：私有，只有自己类里能用
- **protected**：子类、同包能用
- **default**（不写就是）：同包能用

## 2. 类、对象、接口相关
- **class**：定义一个类
- **interface**：定义接口
- **implements**：类实现接口
- **extends**：类继承父类 / 接口继承接口
- **new**：创建对象
- **this**：代表当前对象自己
- **super**：代表父类
- **instanceof**：判断对象是不是某个类的实例
- **abstract**：抽象类/抽象方法
- **final**：最终的，不能改
  - final 变量 = 常量
  - final 方法 = 不能重写
  - final 类 = 不能继承

## 3. 方法、静态相关
- **void**：方法没有返回值
- **return**：方法返回结果
- **static**：静态的，属于类，不属于对象
- **native**：本地方法（调用底层 C/C++）
- **synchronized**：同步，多线程安全用

## 4. 数据类型关键字（基本类型）
- **byte**：字节
- **short**：短整型
- **int**：整数
- **long**：长整数
- **float**：单精度浮点数
- **double**：双精度浮点数
- **char**：单个字符
- **boolean**：布尔（true/false）

## 5. 流程控制（判断、循环）
- **if**：如果
- **else**：否则
- **switch**：多分支选择
- **case**：switch 里的分支
- **default**：switch 默认分支
- **for**：for 循环
- **while**：while 循环
- **do**：do-while 循环
- **break**：跳出循环/switch
- **continue**：跳过本次循环
- **return**：退出方法并返回

## 6. 异常处理
- **try**：尝试执行可能出错的代码
- **catch**：捕获异常
- **finally**：无论如何都执行
- **throw**：手动抛出异常
- **throws**：方法声明可能抛出异常

## 7. 包与导入
- **package**：声明包名
- **import**：导入其他类

## 8. 其他常用
- **null**：空对象
- **true**：布尔真
- **false**：布尔假
- **enum**：枚举
- **assert**：断言（调试用）
- **transient**：序列化时忽略
- **volatile**：多线程可见性
