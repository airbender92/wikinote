## 🧭 Java 基础语法学习路线（建议顺序）

### 1. 程序入口与 Hello World
你已经写过了，但再巩固一下：

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, Java!");
    }
}
```

- `public class 类名` → 类名必须与文件名一致。
- `public static void main` → 固定写法，程序从这里开始。
- `System.out.println` → 打印并换行。

### 2. 变量与基本数据类型
Java 是强类型语言，变量必须先声明类型。

| 类型 | 关键字 | 举例 |
|------|--------|------|
| 整数 | `int` | `int age = 18;` |
| 小数 | `double` | `double price = 99.5;` |
| 布尔 | `boolean` | `boolean isPass = true;` |
| 字符 | `char` | `char grade = 'A';` |
| 字符串 | `String` | `String name = "张三";` |

```java
int a = 10;
double b = 3.14;
boolean flag = true;
String msg = "Hello";
System.out.println(msg + a); // 字符串拼接
```

### 3. 运算符
- 算术：`+ - * / %`
- 比较：`> < >= <= == !=`
- 逻辑：`&& || !`
- 赋值：`= += -=` 等

```java
int x = 5;
int y = 2;
int sum = x + y;     // 7
boolean result = (x > y) && (y > 0); // true
```

### 4. 控制流
#### if-else 条件判断
```java
int score = 85;
if (score >= 90) {
    System.out.println("优秀");
} else if (score >= 60) {
    System.out.println("及格");
} else {
    System.out.println("不及格");
}
```

#### switch 语句（Java 17 支持表达式）
```java
int day = 3;
String dayName = switch(day) {
    case 1 -> "周一";
    case 2 -> "周二";
    default -> "其他";
};
System.out.println(dayName);
```

#### 循环：for / while / do-while
```java
// for 循环
for(int i = 0; i < 5; i++) {
    System.out.println(i);
}

// while 循环
int count = 0;
while(count < 3) {
    System.out.println("count=" + count);
    count++;
}
```

### 5. 数组
```java
// 声明并初始化
int[] nums = {10, 20, 30};
// 访问
System.out.println(nums[0]); // 10
// 遍历
for(int i = 0; i < nums.length; i++) {
    System.out.println(nums[i]);
}
// 增强 for 循环
for(int n : nums) {
    System.out.println(n);
}
```

### 6. 方法（函数）
将重复代码封装起来。

```java
public class Main {
    public static void main(String[] args) {
        int result = add(5, 3);
        System.out.println(result); // 8
    }

    // 定义方法：返回类型 int，参数两个 int
    public static int add(int a, int b) {
        return a + b;
    }
}
```

- 修饰符 `public static` 先照写，后面学面向对象再理解。
- 方法可以无返回值 (`void`)。

### 7. 面向对象基础（核心）
#### 类与对象
```java
// 定义类
class Student {
    String name;
    int age;

    void study() {
        System.out.println(name + " 正在学习");
    }
}

// 使用类
public class Main {
    public static void main(String[] args) {
        Student s = new Student();
        s.name = "小明";
        s.age = 18;
        s.study(); // 小明 正在学习
    }
}
```

#### 构造方法
```java
class Student {
    String name;
    // 构造方法，名字与类相同，无返回值
    Student(String n) {
        name = n;
    }
}
// 创建对象：Student s = new Student("李华");
```

#### 封装、继承、多态（稍后深入，先知道概念）

### 8. 常用 API
- `String`：`length()`, `charAt()`, `substring()`, `equals()`, `contains()` 等。
- `Math`：`Math.random()`, `Math.abs()`, `Math.max()` 等。
- 数组工具 `Arrays`：`Arrays.toString()`, `Arrays.sort()`。

```java
String str = "hello";
System.out.println(str.length());   // 5
System.out.println(str.toUpperCase()); // HELLO

int[] arr = {3,1,4};
Arrays.sort(arr);
System.out.println(Arrays.toString(arr)); // [1,3,4]
```
