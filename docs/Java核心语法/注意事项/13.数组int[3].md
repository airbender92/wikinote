放少了 **完全可以！没问题！**

我给你一句话说清：

- `new int[3]` 意思是：
  **最多只能放 3 个，不是必须放满 3 个**

你不放满，Java 会自动用 **0** 帮你填满。

---

# 举个例子

```java
int[] arr = new int[3];
```

你只给第 0 个赋值：
```java
arr[0] = 10;
```

那数组里实际是：
```
arr[0] = 10
arr[1] = 0
arr[2] = 0
```

**不会报错，完全合法。**

---

# 总结规则
- **长度 3 = 容量固定 3**
- 可以放 **0 个、1 个、2 个、3 个**
- 就是**不能 ≥4 个**
- 没赋值的位置，整数数组默认是 **0**

所以：
- 放少 ✅ 没问题
- 放超 ❌ 报错（越界）
- 放满 ✅ 正常
