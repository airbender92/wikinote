# IDEA新建Java项目上传GitHub 保姆级完整教程
## 前置准备（必须先做）
1. 电脑安装 **Git** 工具：https://git-scm.com/downloads
2. 注册GitHub账号：github.com
3. IDEA自带Git、GitHub插件，无需额外安装

## 一、IDEA配置Git本地程序
1. Windows：顶部 `File → Settings`；Mac：`IntelliJ IDEA → Settings`
2. 找到 `Version Control → Git`
3. Path to Git executable 选择Git安装目录下的 `git.exe`
   Windows默认路径：`C:\Program Files\Git\bin\git.exe`

4. 点击 `Test`，弹出版本号=配置成功，点OK保存

## 二、IDEA登录GitHub账号（两种方式，推荐浏览器登录）
1. 设置界面 `Version Control → GitHub`
2. 点击 `Add account` → `Log in via GitHub`

3. 自动跳转浏览器，登录你的GitHub账号，授权IDEA访问仓库
4. 授权完成切回IDEA，显示你的用户名即绑定成功

## 三、最简一键上传（新手首选：Share Project on GitHub）
不用手动在GitHub网页建仓库，IDEA自动创建远程仓库并上传代码

1. 打开你的Java项目，顶部菜单 `Git → GitHub → Share Project on GitHub`
2. 弹窗配置：
   - Repository name：仓库名（默认项目名，可修改）
   - Private：勾选=私有仓库，不勾选=公开仓库
   - Description：项目简介（可选）
3. 下方Share by选择你登录好的GitHub账号，点击 `Share`

4. 等待自动执行3步：
   ① 初始化本地Git仓库 ② 提交全部代码 ③ 创建GitHub远程仓库并推送
5. 右下角提示成功，打开GitHub网页刷新就能看到代码

### 常见报错：unable to auto-detect email address
1. IDEA底部打开Terminal终端
2. 执行两行命令（替换成你GitHub注册的用户名、邮箱）
```bash
git config --global user.name "你的GitHub用户名"
git config --global user.email "你的GitHub注册邮箱"
```
3. 重新执行Share Project

## 四、手动分步上传（适合已在GitHub建好仓库的场景）
### 步骤1：本地项目初始化Git仓库
1. 顶部 `VCS → Create Git Repository`
2. 选中**当前项目根文件夹**，确定
3. 项目全部文件变红：未加入版本控制



### 步骤2：Add文件（加入暂存区）
右键项目根目录 → `Git → Add`
文件变绿色，代表已暂存



### 步骤3：提交代码到本地仓库
快捷键 `Ctrl+K`，弹出提交窗口
1. 全选所有文件
2. Commit Message填写备注（必填，例：初始化Java基础代码）
3. 点击 `Commit`
文件变白，本地仓库保存完成



### 步骤4：GitHub网页新建空仓库
1. GitHub右上角 `+ → New repository`
2. 仓库名和本地项目名保持一致
3. ❗**不要勾选Initialize this repository with a README**（本地已有代码，勾选会冲突）
4. 点击Create repository，复制HTTPS仓库地址

### 步骤5：IDEA关联远程仓库并推送
1. IDEA顶部 `Git → Manage Remotes`
2. 点`+`，Name填`origin`，URL粘贴刚才复制的GitHub地址 → OK
3. 推送代码：快捷键 `Ctrl+Shift+K`
4. 分支默认`main`，勾选Push，点击Push
5. 推送完成后，刷新GitHub网页即可看到全部代码

## 五、必加.gitignore（过滤垃圾文件，不传到GitHub）
Java/IDEA项目必须忽略这些文件，否则仓库杂乱
1. 项目根目录新建文件，命名 `.gitignore`
2. 复制下面内容粘贴保存
```
# IDEA配置文件
.idea/
*.iml
out/
target/

# 编译class文件
*.class

# 日志、缓存
*.log
.DS_Store
```
3. Add并提交这个文件再推送，后续不会上传编译缓存、IDEA配置

## 六、后续修改代码更新到GitHub流程
1. 修改代码后 `Ctrl+K` 提交本地
2. `Ctrl+Shift+K` Push推送到远程GitHub

## 七、高频问题解决
1. 'git' 不是内部命令：Git没装/IDEA没配置Git路径
2. 推送401授权失败：重新走Setting→GitHub登录授权
3. 推送冲突：远程README和本地冲突，改用一键Share方式最省心
4. 文件上传后一堆.idea文件夹：添加.gitignore过滤即可
