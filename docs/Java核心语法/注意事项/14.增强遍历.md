这叫 **增强 for 循环（foreach）**，专门用来**遍历数组 / 集合**，不用写下标。

---

### 1. 语法长这样
```java
for (元素类型 变量名 : 数组或集合) {
    // 每次循环，变量就是当前元素
}
```

你写的：
```java
int[] nums = {10, 20, 30};

for (int n : nums) {
    System.out.println(n);
}
```

执行结果：

```
10
20
30
```

---

### 2. 它在干嘛？
- 依次把 `nums` 里的**每一个元素**拿出来
- 赋值给 `n`
- 然后执行循环体

相当于自动帮你做：
```java
int n = nums[0];
int n = nums[1];
int n = nums[2];
```

---

### 3. 优点缺点
✅ 优点：
- 代码超级简洁
- 不用管下标、长度
- 不会出现越界错误

❌ 缺点：
- 只能**从头到尾遍历**
- 不能修改数组本身
- 不知道当前是第几个（拿不到 index）

---

### 4. 和普通 for 对比
```java
// 普通 for
for (int i = 0; i < nums.length; i++) {
    System.out.println(nums[i]);
}

// 增强 for
for (int n : nums) {
    System.out.println(n);
}
```
效果**完全一样**，只是写法更简单。
