这个错误很常见，意思就是：
> **java.io.FileNotFoundException: input.txt (系统找不到指定的文件。)**
程序想去读项目里的 `input.txt`，但根本没找到这个文件。

---

# 一、为什么会报错？
你这段代码：
```java
new FileReader("input.txt")
```
它会在 **当前项目的根目录** 去找 `input.txt`，找不到就抛这个异常。

---

# 二、最简单解决方法（2 选 1）

## 方法1：直接在项目根目录新建文件
在你 Java 项目**最外层文件夹**（和 src 同级），新建一个文本文档：
- 名字：`input.txt`
- 里面随便写几行内容，比如：
```
hello java
this is a test
文件读写测试
```
然后再运行，就不会报错了。

---

## 方法2：写绝对路径（最稳，不会找不到）
把文件名改成你电脑上真实存在的文件路径，例如：

Windows：
```java
new FileReader("D:\\test\\input.txt")
```

Mac/Linux：
```java
new FileReader("/Users/xxx/Desktop/input.txt")
```

---

# 三、代码里可以加个小判断，更健壮
```java
File file = new File("input.txt");
if (!file.exists()) {
    System.out.println("文件不存在，即将创建");
    file.createNewFile(); // 自动创建空文件
}
```

这样就不会再报 `FileNotFoundException` 了。
