# 一、集合框架整体概览
Java 集合就是**用来装多个对象的容器**，分为三大体系：

1. **Collection** 单列集合（存一个个对象）
   - List：有序、可重复
   - Set：无序、不可重复
2. **Map** 双列集合（存 key-value 键值对）
3. **工具类**：Collections、Arrays

---

# 二、List 接口（有序、可重复、可通过索引访问）
## 1. ArrayList（最常用）
### 底层结构
- **数组实现**（动态数组）

### 特点
- 查询快（随机访问快）
- 增删慢（需要移动元素）
- 线程不安全
- 默认容量 10，满了自动扩容 1.5 倍

### 适用场景
- **大量查询、遍历**，少量增删
- 单线程环境下优先使用

### 示例
```java
List<String> list = new ArrayList<>();
list.add("a");
list.get(0);  // 快
```

---

## 2. LinkedList
### 底层结构
- **双向链表**

### 特点
- 查询慢（要从头遍历）
- 增删快（只改指针，不用移动元素）
- 线程不安全
- 实现了 Deque 接口，可以当队列、栈用

### 适用场景
- **频繁插入、删除**
- 做队列、双端队列、栈

### 示例
```java
LinkedList<String> list = new LinkedList<>();
list.addFirst("first");
list.removeLast();
```

---

## 3. Vector（老古董，基本不用）
### 底层结构
- 数组实现

### 特点
- 线程安全（方法加 synchronized）
- 效率低
- 扩容 2 倍

### 适用场景
- **几乎不用**
- 要线程安全用 `CopyOnWriteArrayList` 或 `Collections.synchronizedList`

---

# 三、Set 接口（无序、不可重复、无索引）
作用：**去重**

## 1. HashSet
- 底层：**HashMap**
- 无序、不可重复、线程不安全
- 插入、查询极快
- 允许存一个 null

**场景**：只需要去重，不关心顺序

## 2. TreeSet
- 底层：TreeMap
- 可**自动排序**
- 不可重复
- 线程不安全

**场景**：需要自动排序 + 去重

## 3. LinkedHashSet
- 底层：LinkedHashMap
- 有序（保持插入顺序）
- 去重

**场景**：既要去重，又要保持插入顺序

---

# 四、Map 接口（key-value，key 唯一）
## 1. HashMap（最常用）
### 底层结构
- JDK 1.8：**数组 + 链表 + 红黑树**
- 链表长度 ≥8 转红黑树，≤6 转回链表

### 特点
- key 唯一，可存一个 null key，多个 null value
- 无序
- 线程不安全
- 性能极高

### 适用场景
- 单线程下**存储键值对**，90% 场景用它

### 示例
```java
Map<String, Integer> map = new HashMap<>();
map.put("a", 1);
map.get("a");
```

---

## 2. ConcurrentHashMap（高并发必备）
### 底层结构
- JDK 1.7：分段锁（Segment）
- JDK 1.8：**CAS + synchronized** 锁结点，性能大幅提升

### 特点
- 线程安全
- 不允许 null key / null value
- 高并发下性能远超 HashTable

### 适用场景
- **多线程高并发环境**
- 必须线程安全的 Map

---

## 3. Hashtable（不用）
- 线程安全（全表 synchronized）
- 效率极低
- 禁止 null key/value

**场景**：基本废弃，用 ConcurrentHashMap 替代

---

## 4. LinkedHashMap
- 继承 HashMap
- 保持**插入顺序**或访问顺序
- 适合做缓存 LRU

---

# 五、Collections 工具类（必须会用）
是**操作集合的工具类**，方法都是 static。

## 常用方法
1. **排序**
   ```java
   Collections.sort(list);
   ```
2. **打乱顺序**
   ```java
   Collections.shuffle(list);
   ```
3. **获取最大/最小值**
   ```java
   Collections.max(list);
   Collections.min(list);
   ```
4. **线程安全包装**
   ```java
   Collections.synchronizedList(new ArrayList<>());
   Collections.synchronizedMap(new HashMap<>());
   ```
5. **空集合**
   ```java
   Collections.emptyList();
   ```
6. **反转**
   ```java
   Collections.reverse(list);
   ```

# 六、终极选择指南（面试/开发直接背）
## 选 List
- 要**查询快、遍历多** → **ArrayList**
- 要**频繁增删、做队列** → **LinkedList**
- 高并发线程安全 → **CopyOnWriteArrayList**

## 选 Set
- 只去重 → **HashSet**
- 要排序 → **TreeSet**
- 去重+保持插入顺序 → **LinkedHashSet**

## 选 Map
- 单线程键值对 → **HashMap**
- 多线程高并发 → **ConcurrentHashMap**
- 要有序 → **LinkedHashMap**
- 要排序 → **TreeMap**

## Vector、Hashtable
- **一律不用**，过时低效

---

# 七、一句话总结（最强记忆版）
- **ArrayList**：数组，查快改慢，单线程首选
- **LinkedList**：链表，改快查慢，适合队列
- **HashMap**：键值对，单线程无敌
- **ConcurrentHashMap**：并发安全，高并发首选
- **Set**：去重用
- **Collections**：集合工具类，排序、安全包装
