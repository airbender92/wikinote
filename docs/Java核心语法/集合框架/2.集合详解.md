# Java 里的「集合」到底是什么？
用最通俗的话讲：
**集合 = 用来装一堆对象的“容器”**
类似数组，但比数组好用、功能更强。

---

## 1. 集合 vs 数组
你之前代码里出现过：
```java
int[] locations = {randomNum, randomNum+1, randomNum+2};
```
这是**数组**。

集合长这样：
```java
ArrayList<Integer> locations = new ArrayList<>();
```

### 区别
- **数组**
  - 长度固定，一旦创建不能变
  - 可以存基本类型（int、double…）
  - 功能少，只能赋值、取值

- **集合（如 ArrayList）**
  - 长度**可变**，想加就加、想删就删
  - **只能存对象，不能直接存基本类型**
  - 有很多方法：add、remove、get、size、contains…

---

## 2. 为什么集合不能用 int，只能用 Integer？
规则很死：
**集合只收“对象”，不收基本数据类型。**

- `int` 是一个数字，不是对象
- `Integer` 是把 int 包装成的对象

所以：
```java
ArrayList<int> list;  // ❌ 错误
ArrayList<Integer> list; // ✅ 正确
```

---

## 3. 你代码里用到的集合操作
```java
ArrayList<Integer> locationCells;
```

### 常用方法
1. **添加元素**
   ```java
   locationCells.add(3);
   locationCells.add(4);
   ```

2. **获取元素**
   ```java
   int num = locationCells.get(0); // 拿到第一个数
   ```

3. **获取长度**
   ```java
   int size = locationCells.size();
   ```

4. **删除元素**
   ```java
   locationCells.remove((Integer)3);
   ```
   这里必须转成 `Integer`，否则会按**下标**删，而不是按**数值**删。

---

## 4. 简单总结
- **集合** = Java 里装多个对象的容器
- 最常用的就是 `ArrayList`
- 集合**不能存 int**，只能存 `Integer`
- 你那个“打战舰”游戏，就是用 `ArrayList` 存战舰的位置
