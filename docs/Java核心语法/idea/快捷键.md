这里整理了 **IntelliJ IDEA 最常用、最实用的快捷键**，按功能分类，Windows / macOS 都给你标好，直接上手就能用。

# 一、通用基础
- **复制行**：Ctrl + D / Cmd + D
- **删除行**：Ctrl + Y / Cmd + Delete
- **剪切行**：Ctrl + X / Cmd + X
- **撤销**：Ctrl + Z / Cmd + Z
- **重做**：Ctrl + Shift + Z / Cmd + Shift + Z
- **保存**：Ctrl + S / Cmd + S
- **全选**：Ctrl + A / Cmd + A
- **查找文件**：Double Shift / Double Shift
- **全局搜索**：Ctrl + Shift + F / Cmd + Shift + F
- **替换**：Ctrl + R / Cmd + R
- **全局替换**：Ctrl + Shift + R / Cmd + Shift + R

# 二、代码编辑
- **代码格式化**：Ctrl + Alt + L / Cmd + Option + L
- **自动导包/优化导入**：Ctrl + Alt + O / Cmd + Option + O
- **自动补全**：Ctrl + Space / Ctrl + Space
- **智能提示（更全）**：Ctrl + Shift + Space / Cmd + Shift + Space
- **生成代码（构造器、get/set）**：Alt + Insert / Cmd + N
- **重命名**：Shift + F6 / Shift + F6
- **抽取变量**：Ctrl + Alt + V / Cmd + Option + V
- **抽取方法**：Ctrl + Alt + M / Cmd + Option + M
- **上下移动行**：Alt + Shift + ↑/↓ / Option + Shift + ↑/↓

# 三、导航与查看
- **跳转到定义**：Ctrl + 鼠标左键 / Cmd + 鼠标左键
- **返回上一步**：Ctrl + Alt + ← / Cmd + [
- **前进下一步**：Ctrl + Alt + → / Cmd + ]
- **查看类结构**：Ctrl + F12 / Cmd + F12
- **最近打开文件**：Ctrl + E / Cmd + E
- **查找用法**：Alt + F7 / Option + F7
- **快速切换文件**：Ctrl + Tab / Ctrl + Tab

# 四、运行与调试
- **运行**：Shift + F10 / Ctrl + R
- **调试**：Shift + F9 / Ctrl + D
- **单步跳过**：F8 / F8
- **单步进入**：F7 / F7
- **强制进入**：Alt + Shift + F7 / Option + Shift + F7
- **跳出方法**：Shift + F8 / Shift + F8
- **恢复程序**：F9 / Cmd + Option + R
- **打断点**：Ctrl + F8 / Cmd + F8
- **查看断点**：Ctrl + Shift + F8 / Cmd + Shift + F8

# 五、窗口与界面
- **隐藏/显示侧边栏**：Ctrl + Shift + F12 / Cmd + Shift + F12
- **切换终端**：Alt + F12 / Option + F12
- **关闭当前标签**：Ctrl + F4 / Cmd + W
- **关闭所有标签**：Ctrl + Shift + F4 / Cmd + Shift + W
- **快速切换主题**：Ctrl + ` / Ctrl + `

# 六、Git 常用（内置）
- **提交**：Ctrl + K / Cmd + K
- **更新项目**：Ctrl + T / Cmd + T
- **推送**：Ctrl + Shift + K / Cmd + Shift + K
