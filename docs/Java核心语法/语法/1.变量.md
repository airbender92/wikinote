我直接给你**完整可运行的 Java 文件代码**，你复制到 IDEA 里就能直接运行，一步到位。

### 完整代码（TestVariable.java）
```java
public class TestVariable {
    public static void main(String[] args) {
        // 1. 整数类型
        int age = 18;
        
        // 2. 小数类型
        double price = 99.5;
        
        // 3. 布尔类型
        boolean isPass = true;
        
        // 4. 字符类型
        char grade = 'A';
        
        // 5. 字符串类型
        String name = "张三";

        // 你给的示例变量
        int a = 10;
        double b = 3.14;
        boolean flag = true;
        String msg = "Hello";

        // 打印输出
        System.out.println("年龄：" + age);
        System.out.println("价格：" + price);
        System.out.println("是否通过：" + isPass);
        System.out.println("等级：" + grade);
        System.out.println("姓名：" + name);

        System.out.println("------------------------");

        // 字符串拼接
        System.out.println(msg + a);
        System.out.println("数字a：" + a);
        System.out.println("小数b：" + b);
        System.out.println("布尔flag：" + flag);
    }
}
```
