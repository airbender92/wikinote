`Collectors.groupingBy` 是 Stream 里**分组聚合**的核心方法，一共**3 种重载**，参数从简单到复杂，我给你一次性讲透，一看就懂。

---

## 一、最常用：1 个参数
```java
groupingBy(Function<? super T, ? extends K> classifier)
```

- **参数作用**：**分组依据（分类器）**
- 传入一个 `Function`：以什么字段分组
- 返回：`Map<K, List<T>>`

示例：
```java
Map<String, List<Employee>> map = employees.stream()
    .collect(Collectors.groupingBy(Employee::getDept));
```
按部门分组，key=部门名，value=该部门员工列表。

---

## 二、常用：2 个参数
```java
groupingBy(Function classifier, Collector downstream)
```

- 第1个参数：**分组字段**（同上）
- 第2个参数：**下游收集器**（对每组再做一次收集/聚合）
- 返回：`Map<K, U>`，U 是下游收集器的结果

示例：求每个部门平均薪资
```java
Map<String, Double> avgMap = employees.stream()
    .collect(Collectors.groupingBy(
        Employee::getDept,               // 1.按什么分
        Collectors.averagingDouble(Employee::getSalary) // 2.每组做什么
    ));
```

常见下游收集器：
- `Collectors.counting()`：计数
- `Collectors.summingDouble()`：求和
- `Collectors.averagingDouble()`：平均值
- `Collectors.mapping(...)`：先映射再收集
- `Collectors.toList()`：转列表（默认就是这个）

---

## 三、完整：3 个参数（最灵活）
```java
groupingBy(Function classifier, Supplier mapFactory, Collector downstream)
```

- 第1个：classifier 分组字段
- 第2个：**map 工厂**，指定返回哪种 Map（如 LinkedHashMap、TreeMap）
- 第3个：downstream 下游收集器

示例：按部门分组，保证顺序，求每组总薪资
```java
Map<String, Double> sumMap = employees.stream()
    .collect(Collectors.groupingBy(
        Employee::getDept,
        LinkedHashMap::new,        // 指定 Map 类型，保持插入顺序
        Collectors.summingDouble(Employee::getSalary)
    ));
```

---

## 一句话总结参数
```
groupingBy(
    按什么分组(key),
    用什么Map存(可选),
    每组怎么聚合(可选)
)
```

- 1参：只分组 → `Map<K, List<T>>`
- 2参：分组 + 聚合 → `Map<K, U>`
- 3参：分组 + 指定Map类型 + 聚合
