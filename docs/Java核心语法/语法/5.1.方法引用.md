`Employee::getSalary` 叫 **方法引用**，你可以直接理解成：

**“拿到员工的工资这个字段”**
**“用员工的 getSalary() 方法来取值”**

---

## 1. 它是什么？
完整写法是：
```java
Employee::getSalary
```

对应你类里的这个方法：
```java
public double getSalary() {
    return salary;
}
```

所以：
- `Employee::` → 针对 Employee 这个类
- `getSalary` → 调用它的 `getSalary()` 方法

---

## 2. 放在 comparingDouble 里是什么意思？
```java
Comparator.comparingDouble(Employee::getSalary)
```

翻译成人话：

> 比较两个员工时，
> **分别调用它们的 getSalary()，拿到工资，再比较大小**

---

## 3. 它的 lambda 等价写法
看不懂 `::` 没关系，它就是下面这段的简写：
```java
e -> e.getSalary()
```

所以下面两句是**完全一样**的：
```java
Comparator.comparingDouble(Employee::getSalary)

Comparator.comparingDouble(e -> e.getSalary())
```

一个是**方法引用**写法，一个是 **lambda** 写法。

---

## 4. 再举几个同类例子你就彻底懂了
```java
Employee::getName       →  e -> e.getName()
Employee::getDept       →  e -> e.getDept()
Employee::getAge        →  e -> e.getAge()
```

只要是 **getXxx**，都能写成 **类名::getXxx**

---

## 一句话总结
`Employee::getSalary`
= 告诉排序器：
**按“员工的工资”这个字段来排序**
