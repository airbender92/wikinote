这两句合在一起，就是**把员工工资一个个取出来，然后累加求和**。
我拆成最通俗的话给你讲。

---

## 1. 整段作用
```java
mapToDouble(Employee::getSalary)
 .reduce(0, Double::sum);
```

**作用：计算所有员工的工资总和。**

---

# 2. 逐句解释

## ① `mapToDouble(Employee::getSalary)`
- `map` = 转换、映射
- `mapToDouble` = 把对象 **转成 double 数值**
- `Employee::getSalary` = 取每个员工的工资

所以这句的意思是：
> 把员工流 → 变成**工资流**（一串数字：9500, 12000, 10000...）

原来：
员工对象 → 员工对象 → 员工对象…

经过 mapToDouble 后：
9500.0 → 12000.0 → 10000.0 → 7500.0 → 15000.0 → 8500.0

---

## ② `reduce(0, Double::sum)`
`reduce` 叫 **归约**，简单说就是：
**把一堆值，合并成一个值**。

### 两个参数：
1. **0**
   初始值（总和从 0 开始加）

2. **Double::sum**
   两个数字怎么合并？
   → 就是**相加**
   等价于：`(a, b) -> a + b`

### 执行过程：
```
0 + 9500 = 9500
9500 + 12000 = 21500
21500 + 10000 = 31500
31500 + 7500 = 39000
39000 + 15000 = 54000
54000 + 8500 = 62500
```

最终返回：**62500.0**

---

# 3. 完整代码放一起看
```java
double totalSalary = employees.stream()
        .mapToDouble(Employee::getSalary)
        .reduce(0, Double::sum);
```

结果就是：**所有员工工资总和**

---

# 4. 超简记忆口诀
- `mapToDouble`：**把对象转成数字**
- `reduce(0, Double::sum)`：**从0开始，挨个相加**
- 合起来：**求和**

---

# 5. 拓展：更简单的求和写法
其实 stream 已经自带 `sum()`，效果完全一样：
```java
double total = employees.stream()
                .mapToDouble(Employee::getSalary)
                .sum();
```

`reduce` 是更底层、更灵活的写法，`sum()` 是它的简化版。
