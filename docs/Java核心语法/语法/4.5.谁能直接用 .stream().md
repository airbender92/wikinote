**只有“集合”才能直接调用 `.stream()`**
不是所有类型都可以。

# 1. 谁能直接用 `.stream()`？
只有 **Collection 体系的集合**：
- **List**（ArrayList、LinkedList…）
- **Set**（HashSet、TreeSet…）
- **Queue** 等

你写的：
```java
employees.stream()
```
能成功，就是因为 `employees` 是 **List**。

# 2. 谁 **不能** 直接 `.stream()`？
- **数组** → 不行
- **普通对象** → 不行
- **Map** → 不行
- **基本类型变量**（int、double…）→ 不行

# 3. 那数组想 Stream 怎么办？
数组不能直接 `.stream()`，要这样：
```java
Employee[] array = ...;

// 数组 → 流
Stream<Employee> stream = Arrays.stream(array);
```

# 4. Map 想 Stream 怎么办？
Map 不是 Collection，要先转成 keySet / entrySet / values：
```java
Map<String, Employee> map = ...;

// key 流
map.keySet().stream();

// value 流
map.values().stream();

// 键值对流
map.entrySet().stream();
```

# 5. 一句话总结
- **Collection（List/Set）** → 可以直接 `.stream()`
- **数组** → 用 `Arrays.stream(数组)`
- **Map** → 先拿 keySet/values/entrySet 再 stream
- **单个对象/基本类型** → 根本不需要 stream

你现在这句能跑，完全是因为 `employees` 是 **List**。
