这两句是 **Java 里最常见的导包语句**，我用最通俗的方式给你讲清楚它们干嘛用的。

---

## 1. `import java.util.*;`
```java
import java.util.*;
```

- `java.util` 是 Java 自带的一个**工具包**
- `*` 表示：**把这个包里所有的类一次性全部导入**

常用到的类都会在这一批里进来，比如：
- `ArrayList`、`LinkedList`（集合、列表）
- `HashMap`、`HashSet`（键值对、集合）
- `Date`、`Calendar`（时间日期）
- `Scanner`（读取输入）

优点：省事，不用一个个写全类名。
缺点：导入了一堆你可能根本用不上的类，但不影响运行。

---

## 2. `import java.util.stream.Collectors;`
```java
import java.util.stream.Collectors;
```

- 这是 **Java 8+ 才有的 Stream 流工具**
- 专门用来做**集合的流式处理**，比如：
  - 过滤
  - 排序
  - 映射
  - 分组、统计
  - 把流转回 List / Set / Map

最常用的就是：
```java
list.stream()
    .filter(...)
    .collect(Collectors.toList());
```

如果不导入这一句，上面代码就会报错，找不到 `Collectors`。

---

## 简单总结
- `import java.util.*;`
  → 导入**常用集合、工具类**一整套

- `import java.util.stream.Collectors;`
  → 专门导入**Stream 流的收集工具**，用来把处理完的流变回集合
