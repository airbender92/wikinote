在 Java 里，**`collect()`** 是 Stream 流最常用的终止方法，用来把流收集成 **List、Set、Map、字符串、统计值** 等。

最核心的工具是 **`Collectors`** 工具类。

---

## 1. 最常用用法

### 转 List
```java
List<String> list = stream.collect(Collectors.toList());
```

### 转 Set
```java
Set<String> set = stream.collect(Collectors.toSet());
```

### 转 Map
```java
Map<Integer, String> map = list.stream()
    .collect(Collectors.toMap(
        User::getId,    // key
        User::getName   // value
    ));
```

### 拼接字符串
```java
String str = list.stream()
    .collect(Collectors.joining(", ", "[", "]"));
```

### 分组（Group By）
```java
Map<Integer, List<User>> groupByAge = list.stream()
    .collect(Collectors.groupingBy(User::getAge));
```

### 分区（true / false 两组）
```java
Map<Boolean, List<User>> isAdult = list.stream()
    .collect(Collectors.partitioningBy(user -> user.getAge() >= 18));
```

---

## 2. 统计相关
```java
// 总数
long count = stream.collect(Collectors.counting());

// 总和
int sum = stream.collect(Collectors.summingInt(User::getAge));

// 平均值
double avg = stream.collect(Collectors.averagingInt(User::getAge));

// 最大/最小
Optional<User> max = stream.collect(Collectors.maxBy(Comparator.comparing(User::getAge)));
```

---

## 3. Java 16+ 简化写法
```java
// 直接转不可变 List
List<String> list = stream.toList();
```
