下面给你一个**优雅处理 Java 空指针（NPE）**的完整 Demo，包含现代 Java 最推荐的写法：
- Optional 正确使用
- 链式调用 + 默认值
- 避免层层 `if (obj != null)`
- 函数式风格，代码干净易读

## 完整 Demo（可直接运行）
```java
import java.util.Optional;

/**
 * 优雅避免 NullPointerException 示例
 */
public class NullPointerGracefulDemo {

    // 模拟业务实体
    static class User {
        private String name;
        private Address address;

        // getter / setter
        public String getName() { return name; }
        public void setName(String name) { this.name = name; }
        public Address getAddress() { return address; }
        public void setAddress(Address address) { this.address = address; }
    }

    static class Address {
        private String city;
        private Street street;

        public String getCity() { return city; }
        public void setCity(String city) { this.city = city; }
        public Street getStreet() { return street; }
        public void setStreet(Street street) { this.street = street; }
    }

    static class Street {
        private String streetName;

        public String getStreetName() { return streetName; }
        public void setStreetName(String streetName) { this.streetName = streetName; }
    }

    public static void main(String[] args) {
        // 1. 正常有值的情况
        User normalUser = buildNormalUser();
        String normalStreet = getStreetNameGracefully(normalUser);
        System.out.println("正常用户街道：" + normalStreet);

        // 2. 某一层为 null 的情况（不会 NPE）
        User nullAddressUser = buildUserWithNullAddress();
        String nullStreet = getStreetNameGracefully(nullAddressUser);
        System.out.println("地址为空时街道：" + nullStreet);

        // 3. 完全 null 的用户
        String nullUserStreet = getStreetNameGracefully(null);
        System.out.println("用户为 null 时街道：" + nullUserStreet);
    }

    /**
     * 核心：优雅获取 streetName，全程不抛 NPE
     */
    private static String getStreetNameGracefully(User user) {
        return Optional.ofNullable(user)
                .map(User::getAddress)
                .map(Address::getStreet)
                .map(Street::getStreetName)
                .orElse("未知街道");
    }

    // 构造正常用户
    private static User buildNormalUser() {
        Street street = new Street();
        street.setStreetName("张江高科技园区博云路");

        Address address = new Address();
        address.setCity("上海");
        address.setStreet(street);

        User user = new User();
        user.setName("张三");
        user.setAddress(address);
        return user;
    }

    // 构造 address 为 null 的用户
    private static User buildUserWithNullAddress() {
        User user = new User();
        user.setName("李四");
        user.setAddress(null); // 地址为空
        return user;
    }
}
```

---

# 一、优雅思路：用 Optional 替代 if != null
传统丑陋写法（容易漏判、NPE）：
```java
// 地狱级嵌套判空
if (user != null) {
    if (user.getAddress() != null) {
        if (user.getAddress().getStreet() != null) {
            return user.getAddress().getStreet().getStreetName();
        }
    }
}
return "未知";
```

优雅写法（链式 + 函数式）：
```java
return Optional.ofNullable(user)
        .map(User::getAddress)
        .map(Address::getStreet)
        .map(Street::getStreetName)
        .orElse("未知街道");
```

---

# 二、Optional 常用优雅 API
## 1. 安全获取值，为空给默认值
```java
String name = Optional.ofNullable(user.getName()).orElse("匿名用户");
```

## 2. 为空时抛出指定异常
```java
User u = Optional.ofNullable(user)
        .orElseThrow(() -> new BusinessException("用户不存在"));
```

## 3. 不为空才执行逻辑（ifPresent）
```java
Optional.ofNullable(user).ifPresent(u -> {
    // 业务逻辑
    System.out.println(u.getName());
});
```

## 4. 过滤条件
```java
Optional.ofNullable(user)
        .filter(u -> u.getAge() > 18)
        .ifPresent(u -> sendMessage(u));
```

---

# 三、防止 NPE 的通用最佳实践
1. **返回集合不要返回 null**，返回空集合 `Collections.emptyList()`
2. **入参尽量加非空校验**
   ```java
   public void setName(String name) {
       this.name = Objects.requireNonNull(name, "name 不能为空");
   }
   ```
3. **使用 @Nullable / @NonNull 注解** 提前提示
4. 少用 `null` 表示“无数据”，优先用空对象/空集合
5. 链式调用一律用 `Optional.map()`

---

# 四、极简工具方法（可直接复制）
```java
public static <T> T getOrDefault(T value, T defaultValue) {
    return value != null ? value : defaultValue;
}

public static <T> Optional<T> opt(T value) {
    return Optional.ofNullable(value);
}
```

使用：
```java
String city = opt(user).map(User::getAddress).map(Address::getCity).orElse("未知");
```
