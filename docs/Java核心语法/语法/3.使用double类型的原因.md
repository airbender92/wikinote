在 Java 里写 `private double salary;`，**本质原因就是：工资是带小数的数字，用 double 能存整数也能存小数**。

我给你讲得更细一点，一看就明白：

---

## 1. 为什么不用 int？
`int` 只能存**整数**：
- 3000、5000、10000 没问题
- 但工资经常是：3500.50、9999.99、12345.67

`int` 存不了小数点，所以**不能用 int 表示工资**。

---

## 2. 为什么用 double？
`double` 是 Java 里的**浮点类型**，可以存：
- 整数：5000.0
- 小数：5000.50、8888.88

写业务代码时，最方便、最常用的就是 `double`，所以教程、示例里几乎都这么写。

---

## 3. 真实开发里的小知识点（进阶）
虽然教程里都用 `double`，
但**真正做支付、工资、财务系统时，不会用 double**。

原因：
- `double` 是二进制浮点，会有**精度丢失**
  比如：0.1 + 0.2 可能不等于 0.3

正规写法会用：
```java
private BigDecimal salary;
```
`BigDecimal` 专门用来做**精确的金钱计算**。

---

## 一句话总结
- 初学/写练习：用 `double`，因为**能存小数，简单方便**
- 真实项目/金钱计算：用 `BigDecimal`，避免算错钱

简单直接说结论：
**double 适合对精度要求不高、只需要大概数值的场景；
凡是跟钱、金额、计费、财务相关的，一律不能用 double。**

下面分情况给你讲清楚，一看就知道什么时候该用、什么时候绝对不能用。

---

# 一、适合用 double 的场景
这些场景**允许一点点微小误差**，或者人眼根本感觉不到：

1. **物理计算、科学计算**
   - 重力加速度、速度、距离、温度
   - 误差 10⁻¹⁵ 级别完全不影响

2. **游戏开发**
   - 坐标、角度、血量百分比、伤害浮动值
   - 一点点精度误差完全无所谓

3. **统计数据、图表、指标展示**
   - 平均值、比率、百分比、增长率
   - 展示给用户看时四舍五入一下就没了

4. **日常业务里非金额的小数**
   - 身高、体重、年龄小数、时长
   - 误差可以忽略

5. **学习、写 Demo、练习题**
   - 学校作业、简单测试代码
   - 图方便，不用处理复杂类型

一句话：
**只要不是“算钱”，double 基本都能用。**

---

# 二、绝对不能用 double 的场景
只要涉及**精确计算、钱、计费、财务**，一律禁止使用 double：

1. **工资、薪资计算**
   - 你的 `salary` 字段，真实项目必须用 `BigDecimal`

2. **订单金额、支付、退款**
   - 100.00 - 99.99 理论是 0.01
   - 但 double 可能算出 0.01000000000000002 这种诡异值

3. **税费、利率、利息**
   - 银行、理财、贷款，差一点都不行

4. **库存数量、计费单位**
   - 1.25 米布料、0.5 千克商品
   - 必须精确，不能模糊

5. **任何需要精确到分、厘的金融数值**

---

# 三、为什么 double 会不准？
因为 double 是**二进制浮点**，
就像十进制里 1/3 = 0.33333… 永远写不完，
二进制里 0.1 也无法精确表示，只能近似。

所以：
```java
double a = 0.1 + 0.2;
System.out.println(a); 
```
结果可能不是 0.3，而是类似
0.30000000000000004

钱一旦这么算，早晚出问题。

---

# 四、正确替代方案
**金融、金额、工资 → 必须用 BigDecimal**

```java
private BigDecimal salary;
```

加减乘除都用它的方法：
```java
salary = salary.add(other);    // 加
salary = salary.subtract(other); // 减
salary = salary.multiply(other); // 乘
salary = salary.divide(other, 2, RoundingMode.HALF_UP); // 除，保留2位小数
```

---

# 五、超简总结（你记这个就够）
- **用 double**：科学计算、游戏、物理、统计、展示类小数
- **不用 double**：工资、金额、支付、税费、财务、精确计量
- **真实开发规范**：
  → 钱 → BigDecimal
  → 普通小数 → double

你现在写的 `salary`，
**教程里用 double 是为了简单，真实企业一定是 BigDecimal。**
