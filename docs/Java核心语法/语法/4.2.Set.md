# Set 你可以直接理解成：
**一个不允许重复、没有顺序、没有下标 的“集合”**

跟你刚才的 **List（列表）** 正好是一对反义词。

---

# 1. 最核心特点（记住这3个就够）
1. **不允许重复**
   放进去重复的元素，会自动被干掉，只留一个。
2. **无序**
   你放进去的顺序 ≠ 取出来的顺序。
3. **没有下标**
   不能用 `set.get(0)` 这种写法。

---

# 2. 最简单例子
- List 可以这样：
  ```java
  [张三, 李四, 张三, 王五]
  ```
  允许重复，顺序不变。

- Set 这样放：
  ```java
  [张三, 李四, 张三, 王五]
  ```
  最终会变成：
  ```java
  [张三, 李四, 王五]
  ```
  **重复的自动没了**。

---

# 3. 数组 / List / Set 一句话对比
- **数组**：固定长度、有序、有下标、可重复
- **List**：动态长度、有序、有下标、可重复 → **常用列表**
- **Set**：动态长度、**无序**、**无下标**、**不可重复** → **用来去重**

---

# 4. 什么时候用 Set？
只要你有一个需求：
**我不想要重复的数据**

比如：
- 存所有不重复的部门名称
- 统计访问过的用户 ID（不能重复统计）
- 快速去重一个 List

示例：
```java
List<String> list = Arrays.asList("A", "B", "A", "C");
Set<String> set = new HashSet<>(list);
// 结果：[A, B, C] 重复自动没了
```

---

# 超简总结
- **List = 有序可重复的列表**
- **Set = 无序不重复的集合**
- 日常存数据、遍历、筛选 → 用 **List**
- 要去重、判重、存唯一值 → 用 **Set**
