**Map 就是“键值对”，专门用来做：查字典、存配置、一对一映射**

# 一句话理解
- **Map = 钥匙 + 锁（key - value）**
- 一个 **key（键）** 对应一个 **value（值）**
- key 不能重复，value 可以重复

---

# 核心特点
1. **存的是一对数据**
   `key → value`
2. **key 唯一，不能重复**
   放重复 key，新的会覆盖旧的
3. **无序**（大部分实现类）
4. **通过 key 快速查 value**，速度极快

---

# 举个最直观的例子
你现在的员工数据，如果用 Map 存：
- key：员工姓名
- value：员工对象

```java
Map<String, Employee> employeeMap = new HashMap<>();

employeeMap.put("张三", new Employee("张三", "技术部", 9500));
employeeMap.put("李四", new Employee("李四", "技术部", 12000));
```

想拿张三的信息：
```java
Employee zhangsan = employeeMap.get("张三");
```

就像**查字典**：输入拼音 → 直接出字，不用从头翻。

# 数组 / List / Set / Map 终极对比

| 类型 | 结构 | 顺序 | 重复 | 典型用途 |
| --- | --- | --- | --- | --- |
| 数组 | 单个元素 | 有序 | 可重复 | 固定长度数据 |
| **List** | 单个元素 | **有序** | 可重复 | 列表、记录、业务数据 |
| **Set** | 单个元素 | 无序 | **不可重复** | 去重、唯一集合 |
| **Map** | **key-value** | 无序 | key不重复 | 字典、映射、快速查找 |

---

# 简单总结
- **List：有序列表，用来存一串数据**
- **Set：无重复集合，用来去重**
- **Map：键值对，用来快速查找、映射关系**
