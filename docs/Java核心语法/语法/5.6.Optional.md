`Optional.ofNullable(user)` 是 Java 8 用来**优雅处理空指针（NullPointerException）**的工具类，一句话概括：
**把一个对象包进 Optional 里，如果是 null 也不会报错，只是变成一个“空的 Optional”。**

---

## 1. 它到底做了什么？
```java
Optional<User> optUser = Optional.ofNullable(user);
```

执行逻辑：
- 如果 `user != null`
  → 返回一个**包含这个 user**的 `Optional<User>`
- 如果 `user == null`
  → 返回一个**空的 Optional**（`Optional.empty()`）

**关键点：不会抛空指针！**

对比一下：
```java
Optional.of(user);       // 如果 user 是 null，直接 NPE 报错
Optional.ofNullable(user); // 如果 user 是 null，返回空 Optional，不报错
```

---

## 2. 为什么要用它？
以前你写代码要这样判空：
```java
if (user != null) {
    String name = user.getName();
}
```

有了 Optional 可以链式写，**不用一堆 if (xx != null)**：
```java
String name = Optional.ofNullable(user)
                      .map(User::getName)
                      .orElse("未知");
```

---

## 3. 常用搭配（实战写法）
### ① 有值就用，没值给默认值
```java
User u = Optional.ofNullable(user).orElse(new User());
```

### ② 有值才执行，没值拉倒
```java
Optional.ofNullable(user).ifPresent(u -> {
    System.out.println(u.getName());
});
```

### ③ 链式获取深层属性，避免空指针
```java
// 即使 user 或 user.getAddress() 为 null 都不会崩
String city = Optional.ofNullable(user)
                      .map(User::getAddress)
                      .map(Address::getCity)
                      .orElse("未知城市");
```

---

## 4. 简单总结
- `Optional.ofNullable(对象)`
  = **安全包装对象，null 也不抛异常**
- 用来替代繁琐的 `if (obj != null)`
- 配合 `map / orElse / ifPresent` 实现优雅判空

如果你愿意，我可以给你整理一套 **Optional 最常用 5 种写法**，工作里直接照搬。


因为 **`Optional.ofNullable(user)` 执行完，返回的是一个 `Optional` 对象**，
而 `Optional` 类**本身就有 `map()` 方法**，所以才能 `.map()` 一直点下去。

我给你用最简单、最本质的方式讲清楚：

---

# 1. 关键一句话
**ofNullable → 返回 Optional
map → 是 Optional 里的方法**

所以链式调用：
```java
Optional.ofNullable(user).map(...)
```

就像：
```java
list.stream().map(...)
```
是一个道理——**前一个方法返回什么，后面就能点什么方法。**

---

# 2. map 到底干了啥？
`map` 接收一个**函数**，作用是：

- 如果 Optional **有值**
  → 把里面的值取出来，执行你给的函数
  → 把结果再包回 Optional 里返回
- 如果 Optional **是空的（null 包装的）**
  → 什么都不做，直接返回空 Optional

伪代码理解：
```java
public <R> Optional<R> map(Function<T, R> mapper) {
    if (当前Optional有值) {
        R result = mapper.apply(值);
        return Optional.ofNullable(result);
    } else {
        return Optional.empty();
    }
}
```

所以你写：
```java
.map(User::getName)
```

等价于：
```java
if (user != null) {
    String name = user.getName();
}
```

---

# 3. 为什么要这样设计？
为了**链式安全取值，不写一堆 if != null**。

比如：
```java
String city = Optional.ofNullable(user)
                      .map(User::getAddress)
                      .map(Address::getCity)
                      .orElse("未知");
```

任何一步为 null 都不会 NPE，直接走到 orElse。

---

# 4. 超简总结
- `Optional.ofNullable()` → 返回 `Optional` 对象
- `map()` 是 `Optional` 提供的方法
- 作用：安全地从里面“取出东西、转换一下、再包回去”
- 全程不会空指针
