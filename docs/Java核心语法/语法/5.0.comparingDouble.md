`comparingDouble` 就是 Java 给你提供的一个**专门用来比「小数」的排序工具**，专门处理 `double` 类型字段。

# 一句话记住
- **`Comparator.comparingDouble(取哪个double字段)`**
- 作用：**按这个数字从小到大排序**

# 为什么要有 comparingDouble？
因为员工工资是 `double` 类型：
```java
private double salary;
```

所以比较的时候要用 **`comparingDouble`**：
```java
Comparator.comparingDouble(Employee::getSalary)
```

如果是其他类型，要用对应的方法：
- 比较 `int` → `comparingInt()`
- 比较 `long` → `comparingLong()`
- 比较 **对象、字符串** → 普通 `comparing()`

# 举个对比一看就懂
## 1）比较 double 工资 ✔
```java
comparingDouble(Employee::getSalary)
```

## 2）比较 String 姓名
```java
comparing(Employee::getName)
```

## 3）比较 int 年龄
```java
comparingInt(Employee::getAge)
```

# 完整用法在你代码里
```java
// 按工资升序（低 → 高）
.sorted(Comparator.comparingDouble(Employee::getSalary))

// 按工资降序（高 → 低）
.sorted(Comparator.comparingDouble(Employee::getSalary).reversed())
```

# 超简总结
- `comparingDouble` = **专门比较 double 类型**
- 后面接 `.reversed()` = **反过来从大到小**
- 对应你这里就是：**按工资排序**
