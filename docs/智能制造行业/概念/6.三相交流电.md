# 三相电完整讲解（结合你这台三相断路器图纸）
## 一、什么是三相交流电
我们工业常用**三相380V交流电**，由三根独立相线（L1、L2、L3）组成：
1. 三根导线电压相位互相错开120°；
2. 任意两根相线之间电压 = 380V（线电压）；
3. 任意一根相线+零线 = 220V（相电压，家用照明）；
4. 主要给电机、空压机、机床等大功率设备供电，就是图里断路器上方三根进线。

## 二、图里的三相结构对应
图纸最上方三根竖线就是**三相电源进线L1/L2/L3**：
1. 三个主触点2，分别串在A、B、C每一相线路上；
2. 合闸时三根相线同时导通，断电时三相同步切断；
3. 电磁脱扣线圈6串联在其中一相，监测整路短路电流；
4. 欠压脱扣线圈11**并联在任意两根相线之间**，直接采集380V线电压，用来判断电网电压高低。

## 三、三相电两大核心优势
1. **动力强、省线材**
同等功率下，三相电机体积更小、转矩平稳，输送相同电能比单相电线损耗更低，工厂大功率设备全部用三相。
2. **运行平稳无抖动**
单相电电流周期性归零，电机震动大；三相三组电流交替出力，电机转动顺滑。

## 四、和单相电对比
| 类型 | 导线 | 电压 | 用途 |
| ---- | ---- | ---- | ---- |
| 三相 | 3根相线（可加零线/地线） | 相间380V | 电机、机床、空压机、大功率控制柜 |
| 单相 | 1根相线+1根零线 | 220V | 家用插座、照明、小型220V电器 |

## 五、三相电路常见故障（断路器对应保护）
1. **相间短路**：两根相线直接碰在一起，短路电流极大，电磁脱扣器6瞬时跳闸；
2. **欠压/失压**：三相电网电压暴跌或断电，并联的欠压线圈11磁力消失，断路器分闸；
3. **三相过载**：电机长时间超负荷，三相电流同步变大，双金属片12发热延时跳闸；
4. **缺相**：断一根相线，电机电流异常升高，长时间运行会过载烧毁，断路器热脱扣会动作。

## 六、结合你之前疑问：欠压线圈为何并联三相两根线
欠压脱扣要检测**三相电网的整体供电电压**，所以直接跨接两根相线（并联），实时获取380V线电压：
- 三相全部断电、电压大幅下跌 → 线圈电压不足，磁力消失，跳闸；
- 只要三相供电正常，线圈持续带电吸合，断路器保持合闸。
如果串联在某一相里，它只能检测电流，根本感知不到电网电压变化，无法实现欠压保护。

## 七、补充考点
三相低压断路器特点：三相同步分合闸，一相故障脱扣，三相同时断开，避免电机缺相带病运行。
