# 把这个逻辑拆开，你一下就能想通
先分清两条**完全独立、互不连通**的线路，千万不要混在一起：
## 线路1：【主回路（大功率强电）】
顺序：电源 → 断路器 → **交流接触器主触点** → 热继电器发热元件 → 电动机
✅这条回路：输送电能给电机，里面走的是几十安的工作电流。
> 这里的接触器主触点、热继双金属片，都属于**主回路器件**。

## 线路2：【控制回路（小电流弱电）】
这条线路**不从主回路取电**，是单独的一条小电路，典型接线顺序：
控制电源 → 停止按钮 → 启动按钮（自锁触点并联） → **热继电器常闭辅助触点** → **交流接触器线圈** → 回到控制电源零线
✅这条回路：只用来控制「接触器能不能吸合」，电流很小，一般不到1A。

# 关键回答你的疑问
> 主回路顺序是接触器在前、热继在后，热继怎么反过来控制接触器？

因为：
**热继电器的【常闭辅助触点】不在主回路上！它属于控制回路的元件。**
二者只是物理上安装在相邻位置，电气上属于两套独立电路：
1. 电机过载 → 电流流过**主回路里的热继双金属片**，发热弯曲；
2. 机械连杆动作，同步带动**热继自带的辅助触点（常闭）**断开；
3. 辅助触点一断 → **接触器线圈失电**；
4. 接触器线圈没电 → **接触器内部的主触点自动弹开**，切断前面的主回路。

### 形象比喻
- **接触器主触点**：家里墙上的电源总闸（主回路通路）
- **接触器线圈**：拉动总闸的电磁铁
- **热继双金属片**：监控电机电流的传感器
- **热继常闭触点**：串在电磁铁供电线上的开关

哪怕“总闸（主触点）”在传感器前面，只要切断**拉动总闸的电磁铁电源**，总闸照样断开，和前后位置无关！

# 考试核心要点
1. 热继电器**主发热元件串入主回路**（接触器负载侧），用来检测电机电流；
2. 热继电器**常闭辅助触点串联在接触器线圈的控制回路**；
3. 两条回路电气隔离，依靠**机械联动**实现保护：电流过热→机械动作→切断线圈供电；
4. 主回路接触器和热继的前后安装顺序，**不影响控制回路的逻辑**。
