# 一、三相之间380V电压怎么来（分发电机+变压器两层讲，通俗易懂）
## 1. 源头：三相发电机（电压产生根源）
发电机内部有**三组完全独立、规格相同的线圈绕组**，均匀固定在定子铁芯上，三组线圈空间位置互相错开120°（一圈360°，三等分），分别叫A(L1)、B(L2)、C(L)三相绕组。
转子是永磁体/励磁电磁铁，外力（水轮机、柴油机）带动转子匀速旋转，磁场切割三组线圈：
- 导体切割磁感线，根据**电磁感应**，每组线圈独立感应出交流电；
- 因为三组线圈位置错开120°，所以产生的交流电**相位相差120°**；
- 单组线圈自身感应出来的电压就是**相电压**（发电机绕组两端电压）。

## 2. 两种接线方式：星形(Y)、三角形(△)，决定线电压（相线间电压）
发电机、配电变压器绕组有两种接法，工业电网全部用**星形接法**：
### （1）星形接法（主流）
把三组绕组的**一端全部接在一起，公共点叫中性点**，从中引出零线N；
绕组另外三个出头就是三根相线L1、L2、L3。
- 单根相线 ↔ 零线：**相电压 220V**（家用照明）
- 任意两根相线之间：**线电压 380V**

### 电压数值推导（核心）
三相相电压大小相等、相位差120°，通过矢量叠加计算：
线电压 = √3 × 相电压
220 × 1.732 ≈ 380V
这就是L1/L2、L2/L3、L1/L3三根相线之间存在380V电压的根本数学原因。

简单理解：两相的交流电不会同时达到峰值，两者电压差值始终稳定在380V。

### （2）三角形接法
三组绕组首尾依次相连，无中性点、没有零线，三根引出线就是相线；
此时线电压=相电压，工厂小型电机内部绕组常用。

## 3. 电网输送过程：变压器维持380/220
电厂发电机发出高压三相电（10kV、35kV等），通过升压变压器远距离输电，到小区/工厂后，**配电降压变压器**再次采用星形接法，输出标准三相四线：三根相线+一根零线，依旧满足相间380、相对零220V。

# 二、通俗举例理解相位差与线电压
假设某一瞬间：
L1电压到达最大值+220V，
L2、L3相位滞后120°，此时电压只有-110V；
两者相减：220 - (-110) = 330V；
不同时刻叠加平均值稳定为380V，任意两根相线之间永远存在电位差，**有电位差=存在电压**。

电压本质：两点存在电位差，就会产生电压。三根相线电位时刻不同，所以相间必然有电压。

# 三、关键总结
1. 产生源头：三相发电机三组错开120°绕组，电磁感应生成三路相位差120°交流电；
2. 电位差：三根相线瞬时电位永远不相等，因此相线之间存在电压；
3. 数值关系：星形配电系统中，线电压（相间）=√3倍相电压（相线对零线），220V相电压对应380V线电压；
4. 无零线的三角形绕组：相间电压等于绕组自身相电压。

# 补充配套知识点（结合你前面学的断路器）
三相断路器欠压脱扣线圈并联两根相线，利用的就是相线之间380V线电压供电，一旦电网电压下跌，线圈电位差变小，磁力不足，断路器跳闸保护。
