# 电场中某点**场强方向**的标准定义
电场中某点的**电场强度方向**，规定为：
**正检验电荷在该点所受到的静电力的方向。**

---

## 更完整、考试标准写法
1. 电场强度 $\vec{E}$ 是矢量，既有大小，又有方向。
2. 电场中**任意一点**的场强方向，定义为：
   **把一个带正电的点电荷放在该点，它所受电场力的方向，就是该点场强的方向。**

---

## 两个重要推论（必背）
1. **负电荷受力方向与场强方向相反**
   负电荷在电场中受力方向 = 场强的**反方向**。

2. **电场线的切线方向 = 场强方向**
   电场线某点的**切线方向**，就是该点的电场强度方向。

---

## 一句话极简记忆
**场强方向 = 正电荷受力方向。**
