# 脱扣等级 Class 10A 完整解析（JR16热继电器参数）
## 一、关键误区先澄清
**10A不是电流10安培**，是IEC国标规定的**脱扣时间等级代号**，用来定义电机堵转/严重过载时热继电器的动作延时特性。

## 二、标准定义（冷态基准条件）
从设备完全冷却的冷态开始，通入**7.2倍整定电流**（模拟电机堵转、卡死故障）时：
- Class 10A：脱扣动作时间范围 **2s ~ 10s**
对比同级系列：
| 脱扣等级 | 7.2倍整定电流下脱扣时间（冷态） |
|--------|----------------------------|
| Class 10A | 2～10 s |
| Class 10 | 4～10 s |
| Class 20 | 6～20 s |
| Class 30 | 9～30 s |

## 三、电气含义与工作逻辑（结合结构图）
1. **适用场景**
Class 10A属于**短延时快速保护**，适配**轻载、启动时间很短**的电机：水泵、风机、小型输送电机。
电机启动电流约5~7倍额定电流，启动时长一般＜2s，10A等级刚好躲过正常启动冲击；一旦电机堵转，2秒内即可快速分断，防止绕组烧毁。

2. 和热继电器结构对应
图中A/B/C三相双金属片为发热元件，堵转时7.2倍大电流快速发热，双金属片迅速弯曲推动推杆、连杆机构，快速断开8/9常闭触点，切断接触器线圈回路。
Class10A的双金属片形变响应速度更快，相比Class10，最短脱扣时间缩短一半。

3. 不同过载倍数的延时规律
- 1.2倍整定电流（轻微长期过载）：数十秒缓慢脱扣，保护长期过热；
- 7.2倍整定电流（堵转故障）：最快2秒就动作，实现短路级快速保护。

## 四、选型对比（实操要点）
1. **Class10A**：启动快、堵转风险高的小型电机，优先选用；
2. **Class10**：普通风机、水泵，标准通用型；
3. **Class20/30**：重载启动设备（空压机、球磨机、大型皮带机），电机启动时间可达10~25秒，需要更长延时躲过启动电流。

## 五、考试简答背诵版
脱扣等级10A（Class 10A）是热继电器过载延时特性标准代号，并非额定电流；冷态通入7.2倍整定电流时，脱扣动作时间为2~10秒，属于快速保护等级，适用于启动时间短、堵转风险需快速切断的三相异步电动机，兼顾躲过电机正常启动电流与故障快速保护。
