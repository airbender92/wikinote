# 欠电压（结合《零起步学PLC》教材讲解）
## 一、定义
电网/设备实际工作电压**低于额定标准电压**，就叫欠电压。
工业380V三相系统、家用220V单相系统，电压大幅下跌都属于欠电压故障。

## 二、产生原因
1. 大功率设备集中启动，瞬间拉低电网电压；
2. 供电线路过长、导线截面太小，线路压降大；
3. 变压器负荷过重、供电容量不足；
4. 电网故障、零线断线、单相缺相等。

## 三、欠电压带来的危害
1. **三相异步电机最明显**
电机转矩和电压平方成正比，电压降低，输出转矩大幅下降。带负载时电机转速变慢、电流急剧升高，长时间过热烧毁绕组；空载也容易抖动无力。
2. **接触器/继电器无法可靠吸合**
接触器线圈供电不足，电磁吸力不够，衔铁反复吸合、释放，触点频繁抖动，打火烧蚀，甚至直接断开，设备中途停机。
3. 照明、温控、PLC、变频器等弱电设备工作异常：灯光昏暗、仪表失灵、PLC模块误动作、变频器报低压故障停机。

## 四、教材中欠电压保护相关内容
1. **接触器自带欠压保护**
电机自锁启停电路依靠KM实现失压/欠压保护：
电压过低或断电时，KM线圈吸力不足释放，自锁触点断开；电网电压恢复后，不会自动启动电机，防止设备突然运转伤人。
2. **低压断路器QF**
内置欠压脱扣器，电压低于设定值时，断路器自动跳闸切断电源。
3. **欠电压继电器KV**
专门监测电源电压，电压不足时触点动作，切断控制回路并报警。

## 五、失压与欠电压区分
- 欠电压：有电，但电压偏低；
- 失压（零压）：完全断电；
二者保护逻辑一致，工业上常合并称为**失欠压保护**。

## 六、解决办法
1. 加粗供电线缆，缩短供电距离，减少线路压降；
2. 大功率设备错峰启动，避免同时上电；
3. 加装稳压器、补偿电容稳定电压；
4. 控制回路配置接触器、欠压脱扣断路器做安全保护。
