# 核心结论
**充电宝能对外供电/充电，本质就是：**
接通回路 → 正负极有电压差 → 产生电场 → 电场力推动电子，从**负极经过外部电路流回正极**。

---

# 1. 电场是怎么来的？
充电宝内部（电池）：
- 正极：缺电子 → 带正电
- 负极：多电子 → 带负电

正负电荷分开 → 两极之间**一直存在电场**
电场方向：**正极 → 负极**

---

# 2. 电子为什么会动？
电子带**负电**，受力方向与电场方向**相反**：
- 电场：正极 → 负极
- 电子受力：**负极 → 正极**

所以电子会：
**从充电宝负极出发 → 走导线/负载 → 回到充电宝正极**

这就是**电流的来源**。

---

# 3. 回路是必须的吗？
必须。
没有回路，电子流到一半没路走，瞬间就堆积，电场抵消，电流立刻停止。
**只有闭合回路，电子才能持续循环流动。**

---

# 4. 能量是怎么消耗的？
电子流过负载（手机、灯泡、电机）时：
- 受到阻碍
- 把电场给的动能转化为**热、光、化学能**
- 然后继续流回充电宝正极

电子本身没消失，只是**把能量传递给了负载**。
