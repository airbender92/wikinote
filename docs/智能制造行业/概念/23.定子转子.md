结合你之前看的**电机、热继电器**这些电气内容，我用最直白、好记的方式讲：

# 定子、转子是什么
一句话：
**定子 = 不动的部分
转子 = 转动的部分**

---

# 详细一点
## 1. 定子（Stator）
- 固定在电机外壳上，**完全不转**
- 里面绕着**线圈**，通电后产生**旋转磁场**
- 作用：**负责“拉”转子转起来**

可以理解成：
**电机的“磁场发动机”，站着不动，负责发力。**

## 2. 转子（Rotor）
- 在定子中间，**能自由旋转**
- 被定子的磁场感应、吸引、推动
- 带着轴一起转，输出动力带动风扇、水泵、机器等

可以理解成：
**电机的“干活轮子”，被磁场拖着转。**

---

# 最简单类比（电风扇）
- 电风扇**后面固定不动的线圈部分** = 定子
- **前面转的风叶+中心轴** = 转子
