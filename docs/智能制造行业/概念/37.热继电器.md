# 热继电器装在交流接触器下端（负载侧）的原因
先理清标准接线顺序：
**电源 → 断路器 → 交流接触器主触点 → 热继电器 → 电动机**

## 1. 最核心：保护范围全覆盖
接触器下端（负载侧）→ 电机之间全部线路都经过热继电器。
- 电机本体过载
- 电机接线盒、电机电缆过载发热
只要电流异常，热继电器都能检测。
> 如果反过来：热继接在接触器**上端（电源侧）**
> 接触器主触点到电机这段线路，依然受保护，这点电流检测上差别不大，但会引出下面一系列实操问题。

## 2. 检修安全（最重要的实操理由）
停机检修电机时：断开接触器，**接触器下端全部失电**。
热继电器跟着电机一同处于无电状态，人员触摸、拆电机接线更安全。
设想反过来接线（热继在接触器上方）：
接触器断开后，上端一直带电 → **热继电器接线端子仍然带电**，检修电机时容易发生触电风险。

## 3. 减少热继电器长期带电，延长寿命
接触器断开停机时：
✅ 标准接法：接触器断开 → 热继电器不带电，发热元件不通电，长期停机不会承受电压。
❌ 反接：设备停机，热继电器始终长期带电，绝缘、元件持续承受电网电压，加速老化。

## 4. 方便统一调试与维护
控制柜布线惯例：
接触器负责电源通断，其后紧跟保护元件，走线规整；
热继紧贴电机回路，调节电流、更换元件时，不需要接触电源侧带电端子。

## 5. 补充两个常见误区
1. **能不能只看电流检测？**
单纯检测电流，上下位置理论上都能采集电机电流。**电气原理可行，但不符合安全规范与施工习惯，工程上不推荐。**

2. 热继电器**不能实现短路保护**
无论装上端还是下端，短路保护依靠断路器/熔断器，热继只做过载保护。

## 极简背诵版（适合考试）
热继电器接于交流接触器负载侧（下端），接触器分断后热继电器与电机一同失电，保障检修人员安全；同时使电机整条负载线路纳入过载保护范围，停机时元件不带电，延缓器件老化。
