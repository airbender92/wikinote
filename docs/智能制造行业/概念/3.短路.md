# 短路（结合《零起步学PLC》教材内容讲解）
## 一、定义
短路指**电源两极、三相相线之间不经过负载，直接用导线导通**，电流不再经过电机、线圈、电阻等用电设备，形成无阻抗/极低阻抗回路。
正常电路：电源→负载→电源；
短路故障：电源直接连通，跳过负载。

## 二、短路核心特点
短路回路电阻极小，根据欧姆定律，**短路电流会急剧飙升，远大于设备额定电流**，可达额定电流十几、几十倍。
巨大危害：
1. 瞬间产生大量热量，烧毁导线绝缘、电器元件；
2. 产生高温电弧，引燃油污粉尘，引发火灾；
3. 强大电动力会炸碎触点、烧毁接触器；
4. 三相短路会造成电网电压骤降，同回路所有设备无法正常工作。

## 三、常见短路类型
1. **相间短路（三相电路L1/L2/L3任意两相直接接触）**
    电机、接触器主回路最危险，会瞬间炸坏元器件，书中正反转电路重点靠互锁避免KM1、KM2同时吸合造成两相短路。
2. **对地短路**
    相线破皮碰到金属柜体、设备外壳，属于漏电+短路，极易触电、跳闸。
3. **直流正负极短路**
    PLC直流24V、直流继电器线路，线芯触碰就会烧毁电源、模块。
4. 元件内部短路：线圈击穿、元器件内部线路粘连。

## 四、书中对应的短路保护电器
1. **熔断器FU**
    短路大电流瞬间熔断熔体，切断电路，切断故障回路；缺点：三相短路可能只断一相，造成电机缺相运行。
2. **低压断路器QF（空气开关）**
    内置电磁脱扣器，短路瞬时跳闸，三相同时断开，相比熔断器更安全，控制柜总电源常用。
3. 接触器互锁保护：电气+双重互锁，杜绝正反转两个接触器同时吸合，从根源防止主回路相间短路。

## 五、短路和过载区分（易混淆）
1. 短路：故障突发，电流瞬间超大，设备立刻烧毁，保护元件瞬时动作；
2. 过载：负载长时间超过额定电流，电流仅小幅超标，发热缓慢，靠热继电器FR保护（热继电器**不能做短路保护**，因为热惯性，来不及快速切断短路大电流）。

## 六、常见短路产生原因
1. 电线绝缘层破损、挤压、老化，线芯裸露相碰；
2. 接线错误，接线端子两根相线搭在一起；
3. 元器件进水、积灰导电；
4. 维修、布线操作失误，线头搭接；
5. 电机绕组击穿短路。

# 短路产生大量热量的原理（结合欧姆定律、焦耳定律+教材知识点讲解）
## 1、核心两条基础公式
1）欧姆定律：$I=\frac{U}{R}$
$U$=电源电压（基本固定不变），$R$=回路总电阻
正常电路：串联电机、线圈、负载，**总电阻很大**；
短路时：导线直接连通电源，几乎跳过所有负载，只有导线极小的电阻，$R$趋近于0。
电压不变、电阻极小 → 电流$I$瞬间暴增几十上百倍，出现巨大短路电流。

2）焦耳定律：$Q=I^2Rt$
$Q$=产生的热量；$I$=电流；$R$=线路电阻；$t$=通电时间
热量和**电流的平方成正比**，这是关键！
电流扩大10倍，热量会变成原来100倍；电流扩大50倍，热量直接2500倍。
短路瞬间超大电流流过导线、触点，短时间内释放巨量热能。

## 2、通俗举例
比如380V三相电路，正常电机工作电流10A；
发生相间短路时，回路电阻只有导线的零点几欧，短路电流能达到几百安。
正常发热：$Q=10^2×Rt$
短路发热：$Q=500^2×Rt$
热量差距几百倍，一瞬间导线外皮融化、触点烧熔。

## 3、补充教材重点区分：短路 vs 过载发热
1. **短路发热**：瞬时爆发，几秒甚至零点几秒就高温起火，靠熔断器、断路器瞬时保护；
2. **过载发热**：电流只超出额定一点，热量缓慢积累，升温慢，所以热继电器只能做过载保护，无法保护短路（热惯性来不及快速发热动作）。

## 4、实际危害对应书中内容
短路产生的高温会：
① 熔化导线绝缘皮，引燃油污粉尘，引发火灾；
② 烧蚀接触器、断路器金属触点，粘连报废；
③ 高温电弧飞溅，击穿电器外壳，造成触电、设备彻底烧毁；
所以电气线路必须配备熔断器、断路器做短路保护，正反转电路增加互锁，避免两个接触器同时闭合造成相间短路。
