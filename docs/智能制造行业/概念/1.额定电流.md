# 额定电流（结合《零起步学PLC》教材内容讲解）
## 1. 基础定义
额定电流指电气元件、电气设备**长期安全连续工作**时，允许通过的标准最大电流，是厂家设计规定的标称工作电流。
设备在额定电流下运行，发热、损耗、绝缘老化都在设计允许范围内，不会损坏元件。

## 2. 核心规律
1. 实际电流 ＝ 额定电流：设备正常长期工作，温升正常，寿命达标；
2. 实际电流 ＞ 额定电流（过载）：元件发热加剧，绝缘快速老化，长期过载会烧毁线圈、触点、导线；
3. 实际电流 ≪ 额定电流：设备空载/轻载，能安全运行，但设备功率利用率低。

## 3. 书中各类元件额定电流举例
### （1）熔断器（RL1螺旋式）
额定电流2A、4A、25A等，熔体只能长期承受对应电流；电机回路熔体额定电流要选电机额定电流2.5～4倍，防止启动大电流熔断熔丝。
### （2）交流接触器CJ10-20
额定电流20A，代表主触点最多长期通过20A电流，超过会烧蚀触点。
### （3）热继电器JR16-20
整定电流匹配电机额定电流，超过额定电流长期运行，热元件发热动作，切断电路保护电机。
### （4）三相异步电动机Y112M-4
额定电流8.8A，电机持续带负载不能超过该电流，否则过载烧毁绕组。
### （5）导线、端子排
导线标1.5mm²、2.5mm对应固定载流量（额定电流），端子排标注10A，代表接线允许长期最大电流。

## 4. 区分两个易混概念
1. **额定电流（长期稳态）**：持续通电允许电流；
2. **分断/接通电流**：短时分合闸、启动瞬间承受的冲击电流（如电机启动4～7倍额定电流，仅短时存在，不能长期维持）。

## 5. 实际选用原则（教材原文要点）
选型时设备额定电流 ≥ 负载正常工作最大电流，预留一定余量，避免长期过载，保障电气系统安全稳定运行。
