# 常闭触点（结合《零起步学PLC》教材讲解）
## 一、基础定义
常闭触点文字符号：**NC**，图形符号为断开样式的横线（教材标准画法）。
常态（元件线圈**不通电、不受外力**）时触点**自动闭合**，电路导通；
当线圈得电 / 外力按压（按钮、行程开关），触点立刻断开，切断回路。

## 二、通俗理解
常态=没动作→接通；动作后→断开
记忆口诀：**常闭，平常是闭合的**。

## 三、分两类元件举例
### 1. 按钮/行程开关（靠外力动作）
停止按钮、限位开关的常闭触点：
- 没按按钮：触点闭合；
- 按下按钮：触点断开。
电机启停线路里，停止按钮用常闭，紧急断电更安全，断线也能停机。

### 2. 接触器、继电器（靠线圈通电动作）
接触器KM、中间继电器KA的常闭辅助触点：
- 线圈没电：触点闭合；
- 线圈得电吸合，机械机构带动常闭触点分开。

## 四、典型应用（教材经典电路）
### 1. 电机正反转互锁电路
KM1（正转）、KM2（反转）的常闭触点互相串在对方控制回路：
KM1得电→自身常闭断开，KM2回路断电，杜绝两相短路，这就是**电气互锁**。

### 2. 启停控制停止按钮
停止SB采用常闭触点：通电回路串联，按下直接切断接触器线圈，安全可靠。

### 3. PLC梯形图里的常闭触点
X、M、T、C都有常闭触点（指令LDI），输入X无信号时常闭导通，有信号断开。

## 五、和常开触点对比
| 类型 | 常态（无动作） | 动作后状态 |
| ---- | -------------- | ---------- |
| 常开(NO) | 断开 | 闭合 |
| 常闭(NC) | 闭合 | 断开 |

## 六、补充动作顺序（教材知识点）
复合按钮、接触器动作规律：
外力/线圈动作时，**常闭先断开，常开再闭合**；
复位松开后，常开先断开，常闭再闭合。
这个时序是互锁电路安全的关键，防止电源短路。
