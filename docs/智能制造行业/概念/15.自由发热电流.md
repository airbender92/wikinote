# 自由发热电流（标准名称：**约定自由发热电流 / Ith**，俗称自由发热电流）
## 一、标准定义
在规定环境温度、无强制风冷、自然散热（自由散热）条件下，电器元件**长期连续通电、温升不超过国标限值、不发生永久损坏**的最大电流，代号$\boldsymbol{I_{th}}$。
针对你图中的JR16热继电器，分两类：
1. **主回路（热元件）约定自由发热电流**：型号末尾数字，如JR16-20 → 主回路自由发热电流20A；
2. **辅助触点（常闭/常开触点）约定自由发热电流**：统一为5A，代表控制回路触点长期允许的最大电流。

## 二、核心条件“自由发热”含义
- 自由散热：无风扇、无水冷，仅依靠外壳自然空气对流散热；
- 长期工作制：持续通电数小时，温度稳定不再上升；
- 温升约束：通电后最高温度不超过产品允许极限，绝缘、双金属片不会老化变形。

## 三、和整定电流、额定工作电流的区分（JR16举例）
| 参数 | 含义（JR16-20） |
|------|----------------|
| 自由发热电流 Ith=20A | 热元件长期能扛住的最大电流，是继电器本体硬件上限 |
| 整定电流（调节范围） | 面板旋钮可调的保护动作电流，如3.2~5A、4.5~7.2A，必须**小于Ith** |
| 电机额定电流 | 被保护电机的额定工作电流，整定电流匹配此值 |

### 举例：JR16-20
自由发热电流20A，代表这台继电器内部发热元件、导电铜件在自然通风下，最多长期通20A；
你只能选用内部适配3.2~16A区间的热元件，不能超过20A硬件上限。

## 四、电气应用意义
1. **选型限制**
电机额定电流不能超过热继电器的约定自由发热电流，否则长期运行会过热烧毁继电器。
2. **区分短时/长期**
短时冲击电流（电机启动）可短时超过Ith，但持续通电电流必须低于Ith。
3. **触点回路约束**
热继电器95/96常闭触点自由发热电流5A，控制接触器线圈回路电流必须≤5A，否则触点烧蚀粘连。

## 五、和你结构图的关联

## 补充考试简答版
约定自由发热电流（自由发热电流）：在自然通风、无强制冷却环境中，电器长期连续通过，温升不超过规定限值、不产生永久性损伤的最大电流，用于限定热继电器主回路与辅助触点长期工作的电流上限。
