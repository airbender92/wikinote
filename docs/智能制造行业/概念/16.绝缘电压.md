# 绝缘电压690V 完整解析（适配JR16热继电器）
## 一、标准名称：额定绝缘电压 $U_i=690\mathrm{V}$
### 定义
指电器内部绝缘材料、外壳、相间、触点之间，**长期可承受的最高工频耐压**，代表绝缘系统的绝缘等级上限，是划分电器绝缘安全等级的核心参数。

## 二、690V的适用场景
1. **低压配电标准分级**
    低压系统档位：380/400V、660/690V；
    $U_i=690\mathrm{V}$ 的热继电器可安全用于：
    - 三相380V通用电机回路（工厂最常见）
    - 井下、矿山、大功率设备660V供电系统
2. **安全冗余逻辑**
    主回路实际工作电压380V，远低于690V绝缘限值，留有充足绝缘裕量，避免电压波动、操作过电压击穿绝缘。

## 三、和额定工作电压的区别
| 参数 | 额定绝缘电压690V | 额定工作电压（JR16常规660V） |
|------|----------------|--------------------------|
| 作用对象 | 绝缘材料、塑料壳体、相间隔离 | 导电回路、触点正常工作电压 |
| 物理意义 | 绝缘能扛住的最大电压（绝缘上限） | 设备长期正常运行的标准电压 |
| 大小关系 | $U_i \ge$ 额定工作电压 | 实际回路电压 ≤ 额定工作电压 |

## 四、对图中热继电器结构的对应说明
1. **相间绝缘（A/B/C三相双金属片之间）**
    内部隔板、内/外导板绝缘件，绝缘耐压按690V设计，三相之间不会发生爬电、击穿短路；
2. **主回路对地绝缘（金属外壳与内部导电件）**
    外壳、绝缘垫圈、基座绝缘材料，耐受690V工频电压，防止漏电触电；
3. **主回路与辅助触点隔离**
    常闭触点（8、9）控制回路和三相主回路之间绝缘隔离满足690V等级，强弱电互不击穿干扰。

## 五、电气选型与安全要点
1. **选型规则**
    设备供电电压 ≤ 额定绝缘电压，380V、660V电机回路都可选用690V绝缘等级的JR16；若设备使用1000V系统，则必须选用更高绝缘电压型号。
2. **耐压试验标准**
    出厂耐压测试：690V绝缘等级电器，会施加2500V工频电压1min无击穿，验证绝缘可靠；
3. **使用限制**
    不可长期接入高于690V的回路，否则绝缘加速老化，出现爬电、短路、漏电伤人风险。

## 简答背诵版（考试适用）
额定绝缘电压690V，表示该热继电器的绝缘结构在规定条件下，长期能够承受的最高工频电压为690V，用于衡量电器相间、对地、主辅回路之间的绝缘能力，适用于380V、660V低压电机配电回路，保障绝缘不被工作电压、操作过电压击穿。
