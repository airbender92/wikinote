# 分步讲明白，先不用复杂数学符号，结合你这张阴极射线图
公式：
$$\boldsymbol{F}=q\boldsymbol{v}\times\boldsymbol{B}$$
## 1. 先搞懂每个符号含义
- $\boldsymbol{v}$：电荷**速度矢量**（电子向右运动 → $\boldsymbol{v}$ 水平向右）
- $\boldsymbol{B}$：**磁感应强度矢量**（磁场方向，本图垂直纸面向里）
- $\times$：**矢量叉乘**（不是普通乘法！普通乘法是数字相乘；叉乘作用在两个方向上，输出一个**垂直于两者的新方向**）
- $q$：电荷电量。电子 $q$ 是**负数**

> 核心规则：
> $\boldsymbol{v}\times\boldsymbol{B}$ 先算出一个方向；
> 再乘 $q$：
> - $q>0$（正电荷）：力方向 = $\boldsymbol{v}\times\boldsymbol{B}$ 的方向
> - $q<0$（电子）：力方向 **与 $\boldsymbol{v}\times\boldsymbol{B}$ 相反**

## 2. 怎么判断叉乘 $\boldsymbol{v}\times\boldsymbol{B}$ 的方向：右手螺旋定则（叉乘专用右手！⚠️不是左手）
### 右手叉乘操作步骤
1. 伸出**右手**
2. 四指从第一个矢量 $\boldsymbol{v}$，沿着**小于180°的角度**弯向第二个矢量 $\boldsymbol{B}$
3. **大拇指指向 = $\boldsymbol{v}\times\boldsymbol{B}$ 的方向**

代入你图里条件：
- $\boldsymbol{v}$：向右
- $\boldsymbol{B}$：垂直纸面向里

操作：
右手四指从【向右】转向【向里】
👉大拇指指向：**竖直向上**
也就是：$\boldsymbol{v}\times\boldsymbol{B}$ 的方向 **向上**

## 3. 带上电子的负电荷 q
$$\boldsymbol{F}=q(\boldsymbol{v}\times\boldsymbol{B})$$
电子 $q<0$
正数方向向上 × 负数 → 整体方向**反向，向下**
✅ 洛伦兹力向下，和图里电子向下弯曲完全对应。

# 4. 重点区分两套手定则，千万别混
1. **矢量叉乘 $\boldsymbol{v}\times\boldsymbol{B}$：右手（只用来算方向，纯数学运算）**
2. **洛伦兹力受力判断：左手定则（直接一步得到电荷受力）**

### 对照演示（同一道题两种方法，结果统一）
#### 方法A 左手定则（直接求受力，做题首选）
对象：电子（负电）
1. 磁感线穿手心：磁场向里 → 手心对着纸面
2. 四指 = **正电荷运动方向**；电子向右跑，四指朝**左**
3. 大拇指向下 → 受力向下

#### 方法B 叉乘方式（物理理论底层逻辑）
1. 右手算出 $\boldsymbol{v}\times\boldsymbol{B}$：向上
2. 电子带负电，方向翻转 → 受力向下
两套方法结论完全一致。

# 5. 通俗理解叉乘最重要特性
两个矢量叉乘得到的新矢量，**永远同时垂直于原来两个矢量**
$\boldsymbol{v}$向右、$\boldsymbol{B}$向里，这两个方向构成一个平面；
叉乘结果只能垂直这个平面，也就是只能向上/向下，不可能往左往右、向里向外。
这正好对应之前讲的：
**洛伦兹力永远垂直速度、垂直磁场，只能侧向推电荷！**

## 6. 补充一个对照例子帮你巩固
假设是质子（正电荷，$q>0$），同样向右飞、磁场向里
1. 右手叉乘 $\boldsymbol{v}\times\boldsymbol{B}$ 向上
2. $q>0$，不用反向
👉质子受力向上，轨迹向上弯曲，和电子正好相反。
