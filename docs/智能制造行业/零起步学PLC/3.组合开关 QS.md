# 组合开关 QS（图里的QS）
## 1、名称全称
**组合开关（也常叫转换开关、HZ系列组合开关）**
电路图符号：**QS**

## 2、在这个实训电路里的作用
回路顺序：三相电源 L1、L2、L3 → **QS组合开关** → FU熔断器 → 端子排 → 三相电机
1. **手动接通/切断三相主电路**，直接控制电机启动、停机（这是无接触器的最简单手动控制线路）
2. **隔离电源**：断开开关之后，后端电路和电网隔开，方便检修。

> ⚠重要考点：
组合开关**不适合频繁启停电机**，容量有限；大功率电机一般不会直接用它通断，只做隔离。

## 3、结构原理（结合图）
图里是**三极组合开关**，内部有三组独立动、静触点，手柄旋转联动内部触点：
- 手柄旋至**合闸位置**：三组触点同时闭合，L1/L2/L3三相同时导通；
- 手柄旋至**分闸位置**：三组触点同时断开，三相电源全部切断。

## 4、和断路器、闸刀开关简单区分
1. 闸刀开关：上下直推；
2. **组合开关QS：旋转手柄操作**；
3. 断路器：自带过载、短路脱扣保护；
✅ 本图QS**只有通断功能，没有保护**；短路保护依靠后面的熔断器FU。

## 5、考试简答精简版
QS为组合开关，作为电源总开关，通过旋转手柄实现三相电路同时接通与分断，控制异步电动机启停，同时起到电源隔离作用；本线路短路保护由熔断器FU承担。

## 补充思考题
如果调换QS出线端两根相线，电机发生什么变化？（答案：三相相序改变，电机反转）
