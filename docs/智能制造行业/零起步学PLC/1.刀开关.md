结合《零起步学PLC》书中瓷底胶盖刀开关内容，分两部分讲瓷底座、胶盖各自作用：
# 一、瓷底座（刀开关基座）
瓷为绝缘陶瓷，核心作用：
1. **超强绝缘**
陶瓷不导电，熔丝、触刀、接线端子全部安装在瓷底座上，带电部件之间、带电部件与安装金属板完全隔离，防止漏电、相间短路，保障操作安全。
2. **耐高温、抗电弧**
开关分合会产生电弧，熔丝熔断时会产生高温火花；陶瓷耐热、不燃烧、不易熔化，塑料底座容易被电弧烧熔起火，陶瓷可耐受高温，避免起火隐患。
3. **耐腐蚀、不易老化**
车间潮湿、有油污粉尘环境下，陶瓷不会氧化、变形，使用寿命远优于塑料底座。

# 二、胶盖（配套防护盖子）
胶一般是绝缘硬塑料，作用：
1. **防触电保护**
遮盖内部带电触刀、熔丝，操作人员手不会误触带电金属，避免触电事故。
2. **隔绝电弧飞溅**
开关合闸、分闸、熔丝熔断产生的电弧、金属熔渣被胶盖封闭在内部，不会向外飞溅，防止灼伤操作人员，同时避免电弧引燃周边粉尘、油污引发火灾。
3. 防尘防水，减少内部金属氧化，延长开关寿命。

# 三、补充书中安装配套要求
瓷底胶盖刀开关有配套使用规范：
1. 必须竖直安装，手柄朝上；
2. 电源进线接上端，负载接下端；
3 胶盖不能拆除使用，拆掉后失去安全防护，属于违规操作。

# 四、总结设计逻辑
陶瓷负责底座绝缘耐高温，胶盖做外层安全防护，二者搭配兼顾绝缘、防火、防触电，成本低，适合民用、小型机床普通隔离配电，也是最常见的小型隔离刀开关结构。
