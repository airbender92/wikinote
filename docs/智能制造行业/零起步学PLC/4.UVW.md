# U11、V11、W11 标识完整解读（对照你这张手动电机原理图）
## 1、编号含义
在三相电机控制回路里标准标号规则：
- **L1、L2、L3**：三相电源进线（电源侧）
- **U11、V11、W11**：**组合开关QS的出线端**（开关之后、熔断器FU之前）

电流走向：
$\boldsymbol{L1\rightarrow QS\rightarrow U11}$
$\boldsymbol{L2\rightarrow QS\rightarrow V11}$
$\boldsymbol{L3\rightarrow QS\rightarrow W11}$

然后继续向后：
$\boldsymbol{U11、V11、W11 \rightarrow 熔断器FU进线端}$

## 2、配套对应标号
熔断器下端标号是 **U12、V12、W12**
规则记忆：
- **11：开关后侧、保护元件前**
- **12：熔断器后侧，负载方向**

线路完整链路：
L1/L2/L3 → QS组合开关 → **U11 V11 W11** → FU熔断器 → **U12 V12 W12** → 端子排 → 电机U、V、W

## 3、为什么要用U/V/W，不用A/B/C？
国标规范：
- 电源进线：L1、L2、L3
- 开关、保护器件之后去往电机的线路：统一使用 **U、V、W** 系列编号

## 4、考试重点
1. U11、V11、W11 属于**组合开关QS负载侧引出线**；
2. 三根线分别对应三相，绝对不能相互短接，否则造成三相短路；
3. 如果互换其中任意两根（比如U11、V11互换），电机供电相序颠倒，电机**反转**。

## 极简背诵
U11、V11、W11是三相组合开关QS输出端编号，连接熔断器进线；U12、V12、W12是熔断器输出端，通向电动机。
