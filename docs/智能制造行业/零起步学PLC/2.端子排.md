### 1、右下角元件名称
右下角这个元件叫 **接线端子排（端子台/接线板）**
作用：实训平台布线中转枢纽，方便导线转接、整理线路；
端子排向外引出三根线，直接接到三相异步电动机的 **U、V、W接线柱**。

### 2、熔断器FU出线的接线流向
对照左侧原理图：
三相熔断器FU上端：接转换开关QS输出（U11、V11、W11）
三相熔断器FU下端出线端子：**U12、V12、W12**
导线从FU下端 → 接入【端子排】 → 端子排出线 → 三相电机M

完整主回路线路梳理：
三相电源 L1/L2/L3 → 组合开关QS → 熔断器FU → 接线端子排 → 三相异步电动机

### 补充要点（做题重点）
1. FU是**短路保护元件**，当电机线路发生短路故障时，熔丝熔断切断电源；
2. 这个电路是**最基础的手动直接启停电路**，没有交流接触器、没有热继电器，依靠手动扳动QS开关控制电机启停；
3. 端子排本身不具备任何保护功能，仅作为导线转接支架。
