先说结论，一句话记死：
**地理北极 ≈ 地磁南极（S极）
地理南极 ≈ 地磁北极（N极）
所以磁场线是：从**地理南极附近**穿出，从**地理北极附近**穿入地球。**

---

## 1. 为什么地理北极是地磁 S 极？
因为**指南针的N极指向地理北极**。
而磁场规律是：
**异名磁极相吸**
- 指南针N极 → 被地磁S极吸引
- 指南针S极 → 被地磁N极吸引

所以：
能把指南针N极吸过去的地方，一定是地磁**S极**
→ 地理北极 ≈ 地磁**S极**

---

## 2. 磁场线方向为什么是“南极→北极”？
磁场线统一规定：
**从 N 极出发，回到 S 极**

地球内部相当于一块大磁铁：
- 地磁 N 极 ≈ 地理**南极**附近
- 地磁 S 极 ≈ 地理**北极**附近

所以磁场线路径：
1. 从地磁N极（地理南极）**穿出地球表面**
2. 在空中弯向地磁S极（地理北极）
3. 从地理北极**穿入地球内部**
4. 在地球内部从地理北极 → 地理南极

**外部看起来：磁场从地理南极指向地理北极**

---

## 3. 超简记忆口诀
- 指南针N指北 → 北边是地磁**S**
- 磁场线：N→S
- 所以：**地理南极 → 地理北极**

## 4. 一个小提醒
地磁南北极和地理南北极**不完全重合**，有一个小夹角叫**磁偏角**，但考试和理解时可以近似认为：
**地理北极 ≈ 地磁S
地理南极 ≈ 地磁N**
