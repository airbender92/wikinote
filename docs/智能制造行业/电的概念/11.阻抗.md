# 交流电中电感、电容阻抗完整梳理
先分清核心概念：
电阻：**耗能元件**
电感L（线圈）、电容C：**储能元件**，交流下产生「电抗」，电抗和电阻合称为**阻抗**

## 一、符号汇总
$f$：交流电频率（Hz）
$\omega=2\pi f$：角频率
$L$：电感(H)；$C$：电容(F)

## 1、电感线圈 → 感抗 $X_L$
公式：
$$\boldsymbol{X_L=\omega L=2\pi f L}$$
### 规律
1. **频率越高，感抗越大**
直流（$f=0$）：$X_L=0$ → 线圈通直流近似短路
高频交流电：线圈阻碍作用极强
2. 物理本质：楞次定律，电流变化时线圈产生自感电动势阻碍电流变化。

### 电压电流相位
**电压超前电流 90°**

## 2、电容 → 容抗 $X_C$
公式：
$$\boldsymbol{X_C=\dfrac{1}{\omega C}=\dfrac{1}{2\pi f C}}$$
### 规律
1. **频率越高，容抗越小**
直流（$f=0$）：$X_C\to\infty$ → 电容**隔断直流电**
高频交流：电容容易导通
2. 物理本质：依靠反复充放电形成交流通路。

### 电压电流相位
**电流超前电压 90°**

## 3、直观对比表
|元件|电抗公式|频率特性|直流特性|相位关系|
| ---- | ---- | ---- | ---- | ---- |
|电阻R|$R$|和频率无关|正常导通|电压、电流同相|
|电感L（线圈）|$X_L=2\pi fL$|$f↑，X_L↑$|直通（近似短路）|电压超前电流90°|
|电容C|$X_C=\dfrac{1}{2\pi fC}$|$f↑，X_C↓$|阻断（开路）|电流超前电压90°|

## 4、RLC串联总阻抗（最重要公式）
电阻、电感、电容串联时
总阻抗大小：
$$\boldsymbol{Z=\sqrt{R^2+(X_L-X_C)^2}}$$
- $X_L>X_C$：电路呈**感性**，整体电压超前电流
- $X_L<X_C$：电路呈**容性**，整体电流超前电压
- $X_L=X_C$：$Z=R$，发生**串联谐振**；电抗相互抵消

## 5、通俗大白话记忆
✅电感线圈：**阻高频、通直流**
✅电容：**通交流、隔直流；通高频、阻低频**

## 6、配套应用举例
1. 直流电机线圈：直流稳态只体现导线电阻；通电瞬间，感抗阻碍电流突然变大
2. 滤波电路：用电容旁路高频干扰；用电感阻挡高频噪声
3. 工频50Hz市电：同样大小电感，低频下阻碍作用不大

## 补充一个极易混淆点
$X_L、X_C$ 叫作**电抗**；
$Z$ 才叫**阻抗**；
电抗不消耗有功功率，只进行能量来回吞吐；只有电阻消耗电能发热。
