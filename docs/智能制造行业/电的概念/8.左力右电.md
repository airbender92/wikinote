这个问题问到**物理本质**了，我用最直白、不绕弯的逻辑讲清楚：
**为什么电动机用左手，发电机用右手？
因为它们的因果关系完全相反。**

# 一句话分清
- **电动机：先有电 → 才有力 → 左手定则**
- **发电机：先运动 → 才生电 → 右手定则**

---

# 1. 电动机（左手）：电 → 力
结构：
磁场 B 存在
导线里**先通入电流 I**
导线在磁场里**受力 F 运动**

因果：
**电流 + 磁场 → 产生力**
力是“结果”。

所以用**左手**：
磁感线穿手心
四指 = 电流方向
大拇指 = 受力方向

---

# 2. 发电机（右手）：运动 → 电
结构：
磁场 B 存在
导线**先被外力拖动切割磁感线（运动 v）**
导线里**感应出电流 I**

因果：
**运动 + 磁场 → 产生电流**
电流是“结果”。

所以用**右手**：
磁感线穿手心
大拇指 = 运动方向
四指 = 感应电流方向

---

# 3. 为什么不能搞反？
因为物理世界**因果不对称**：

- 通电导线在磁场里**一定受力**（电动机）
- 运动导线在磁场里**一定生电**（发电机）

这两个过程方向相反，
为了不搞混，就规定：
**力用左手，电用右手。**

---

# 4. 超级记忆口诀（考试必背）
**左力右电**
- 左手：力（电动机）
- 右手：电（发电机）

电动机是**电能 → 机械能**，受力是结果 → 左手
发电机是**机械能 → 电能**，电流是结果 → 右手
