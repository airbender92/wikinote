# 核心结论先说
**电场线方向是人为规定的：电场线上某一点的切线方向 = 正试探电荷在该点受到的电场力方向。**
这是物理学的统一约定，我们结合点电荷受力解释：

## 1、正点电荷 $+Q$（左图）
把一个**很小的正试探电荷**放到 $+Q$ 旁边：
同种电荷相互**排斥**，正试探电荷会被向外推开。
按照规定：电场力向外 → **电场线向外辐射**。

## 2、负点电荷 $-Q$（右图）
把**正试探电荷**放到 $-Q$ 旁边：
异种电荷相互**吸引**，正试探电荷会朝着负电荷靠近。
电场力指向负电荷 → **电场线指向负电荷（向内）**。

## 3、补充两条考试要点
1. 电场线**起始于正电荷，终止于负电荷**（无穷远等效）
   - 正电荷：电场线从电荷出发向外延伸到无穷远处
   - 负电荷：电场线从无穷远处汇聚、终止在负电荷上
2. 如果你放的是负试探电荷，受力方向和电场线方向**相反**，但电场线方向的定义不变，不会跟着试探电荷改变。

## 通俗一句话记忆
规定：跟着**正电荷受力方向**画电场线。
正电荷推正试探电荷→向外；
负电荷吸正试探电荷→向内。
