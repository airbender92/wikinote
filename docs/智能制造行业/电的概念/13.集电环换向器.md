# 核心区别：**滑环（集电环） vs 换向器（整流子）**
线圈在磁场里旋转时，**线圈内部永远产生交流电**。
输出是交流还是直流，完全取决于转轴上的导电部件。

## a）交流发电机：**集电环（两个完整圆环）**
1. 结构：转轴上两个互不连通、完整的金属圆环，线圈两头分别固定在两个环上；电刷一直贴合固定的圆环。
2. 工作过程：
线圈旋转半圈 → 导线切割磁场方向反转 → 线圈感应电动势**极性颠倒**。
因为线圈端头始终连着同一个滑环，滑环跟着线圈一起翻转极性。
👉 外部电刷输出的电压方向来回改变 → **交流电**
波形：上下交替的标准正弦波。

## b）直流发电机：**换向器（分成两半的缺口圆环）**
换向器 = 一个圆环切开成两个绝缘的半环，线圈两端分别接这两个半环。
关键逻辑：
线圈转半圈，线圈内部电压极性已经反过来；
但**与此同时，两个半环跟着线圈一起转动，自动交换和两个电刷的接触对象！**

举个直观过程：
- 前半圈：左电刷接正极半环、右电刷接负极半环
- 转过180°（后半圈）：线圈里面电流反向，但是两半环也转了半圈；
  原本的负极半环转到左边、接触左电刷；正极半环转到右边。

结果：
**外部电刷上，电压的方向永远不变！**
线圈内部依旧是交流电，换向器把负半周“翻折到横轴上方”
波形：脉动直流（始终≥0，不出现负电压）。

# 一张要点对比
|项目|交流发电机（集电环）|直流发电机（换向器）|
| ---- | ---- | ---- |
|转轴零件|完整**两个集电环**|切开两半的**换向器**|
|线圈内部|交流电|交流电（线圈里面永远是交流！）|
|对外输出|交流电（极性来回翻转）|脉动直流电（极性不变）|
|波形|正弦波，有正有负|全部在0以上，馒头状脉动波形|

## 超级通俗总结
线圈旋转产生的电本来都是交流电。
1. **集电环：原样把线圈交流电引出去 → 交流发电机**
2. **换向器：每转半圈自动调换接线，把反向那一半波形“掰上来” → 对外输出直流**

## 拓展小知识点
这个换向器是双向的：
- 发电模式：交流线圈 → 换向器 → 输出直流（直流发电机）
- 通电模式：外部直流 → 通过换向器交替给线圈供电（**直流电动机**，你之前学习的电机原理）
