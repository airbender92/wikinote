简单说清楚：
**质子 + 中子 = 原子核**
电子在原子核外面绕圈。

## 1. 质子（Proton）
- 带 **正电（+）**
- 数量 = **原子序数**
  比如氢有1个质子，就是1号元素；
  碳有6个质子，就是6号元素。
- 质子数决定**这是什么元素**。

## 2. 中子（Neutron）
- **不带电**，中性
- 质量和质子差不多，比质子略重一点
- 中子数可以变，**中子数不同 = 同位素**
  比如：
  - 普通氢：1质子 + 0中子
  - 重氢（氘）：1质子 + 1中子
  还是氢元素，只是“版本”不同。

## 3. 三者关系（超关键）
- **原子核 = 质子 + 中子**
- 原子整体不带电：
  **质子数 = 电子数**

## 4. 一句话区分
- **质子：决定你是什么元素，带正电**
- **中子：稳住原子核，不带电，决定同位素**

你刚才问的 K 层电子，就是绕在这个原子核外面的。
