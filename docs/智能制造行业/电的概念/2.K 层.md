# K层（电子层）通俗讲解
## 1、定义
K层就是**原子核外第1层电子轨道（第一层电子壳层）**
科学家用大写字母依次命名电子层：
**第1层 = K层**
第2层 = L层
第3层 = M层
第4层 = N层
第5层 = O层……

## 2、关键规则
每层最多容纳电子数量公式：$\boldsymbol{2n^2}$
$n$=电子层数
- K层：$n=1$ → 最多 $2\times1^2=\boldsymbol{2}$ 个电子
👉 氢原子只有1个电子，就在K层；氦原子2个电子，填满K层。

## 3、结合图里氢原子
氢原子核外只有**1个电子**，这个电子运行在离原子核最近的轨道，这个轨道就叫 **K层**。

## 4、补充小知识
为什么不从A开始，而是K开头？
历史早期研究X光光谱，最初预留命名空间，直接从K开始编号，这套命名就一直沿用至今。

## 极简总结
**K层 = 离原子核最近的第一层电子轨道。**
