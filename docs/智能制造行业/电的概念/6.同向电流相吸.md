# 核心结论
**同向电流相吸，反向电流相斥。**

---

# 原理（一步一步来）
## 1. 每根通电导线，都会在周围产生**环形磁场**
电流向上 → 磁场是**逆时针**环绕导线（右手螺旋定则）

## 2. 把两根导线放一起
左边导线电流向上，右边导线电流也向上。

- 左边导线产生的磁场，**在右边导线的位置是垂直纸面向里**
- 右边导线处于左边导线产生的磁场中

## 3. 右边导线的电流，在磁场中会受力
用**左手定则**：
- 磁感线穿手心（向里）
- 四指指向电流方向（向上）
- 大拇指指向**向左** → **被吸向左边导线**

同理，左边导线也会被右边导线的磁场推向右边。

→ 最终表现：**两根导线相互吸引**

---

# 超级简单记忆版
1. 电流同向 → 它们产生的磁场在中间**方向相反、相互抵消减弱**
2. 磁场弱的地方，导线会被**推向磁场弱的区域**
3. 所以两根导线**往中间靠 → 相吸**

反过来：
电流反向 → 中间磁场**叠加变强** → 导线被推开 → **相斥**

---

# 一句话终极总结
**同向电流：中间磁场减弱，相互吸引
反向电流：中间磁场增强，相互排斥**
