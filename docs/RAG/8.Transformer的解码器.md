# Transformer 解码器（Decoder）
就是 Transformer 里**负责一步步生成文本**的核心结构，你平时用的大模型聊天、写代码，全靠它。

---

## 一句话定位
- **Encoder（编码器）**：理解输入，做阅读理解、分类、向量化
- **Decoder（解码器）**：生成输出，做翻译、写文章、对话

现在主流大模型（GPT、Llama、Qwen 等）基本都是**纯 Decoder 结构**。

---

## 解码器内部在干嘛（极简版）
每一层 Decoder 主要有两个关键模块：

1. **掩码多头自注意力（Masked Multi-Head Attention）**
   - 只能看**当前 token 及之前**的内容
   - 看不到未来 token，保证生成是**从左到右逐字生成**
   - 这里就会产生你前面问的：**时间步 KV Cache**

2. **前馈网络（FFN）**
   - 对特征做加工、整合信息
   - 不改变序列长度，只强化语义

如果是翻译那种 Encoder-Decoder 结构，还会多一个：
**交叉注意力（Cross Attention）**
- 去看 Encoder 理解好的输入内容
- 比如翻译时盯着原文生成译文

---

## 和你前面问的概念串起来
- **时间步 KV**：就是 Decoder 在每一步生成时，缓存历史 token 的 K、V
- **显存**：Decoder 层数越多、上下文越长，KV Cache 越占显存
- **生成过程**：Decoder 每走一个时间步，输出一个 token → 循环直到结束
- **RAG/Agent**：是外部逻辑，Decoder 只负责“生成”这件事

---

## 超直观总结
- Transformer **Encoder = 看书理解**
- Transformer **Decoder = 动笔写作**
- 我们现在说的大模型，基本就是**堆叠了很多层的 Decoder**。
