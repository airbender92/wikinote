# Agent
**智能体 / AI Agent**，可以理解为：**能自主思考、规划、调用工具、一步步完成复杂任务的 AI**。

## 一句话理解
普通大模型只是“回答问题”，
Agent 是**自己做任务**：会思考、会查资料、会写代码、会调用工具、会自己修正错误，直到完成目标。

## 核心特点
1. **自主规划**
   接到复杂任务后，自己拆解成步骤：先做什么、再做什么。

2. **工具调用（Tool Use）**
   可以调用外部能力：
   - 搜索（联网）
   - 计算器
   - 代码解释器
   - 数据库 / API
   - RAG 知识库
   - 文件读写

3. **记忆与反思**
   记住之前做过什么，发现错了会重新调整，而不是一直错下去。

4. **自主决策**
   不需要你一步步指令，它自己判断下一步该干嘛。

## 典型工作流程（ReAct 范式）
1. **Thought**：思考现在要干嘛
2. **Act**：调用工具/执行动作
3. **Observe**：观察结果
4. **Repeat**：循环直到完成任务

## Agent 和 RAG 的关系
- **RAG**：负责**“查准资料”**，是静态知识增强
- **Agent**：负责**“自动做事”**，是动态决策执行
- 实际落地常常是：**Agent + RAG + 工具调用** 一起用

## 常见应用
- 自动写代码、改 Bug、做数据分析
- 自动写方案、做调研、整理报告
- 智能客服、自动化办公助手
- 自动驾驶、机器人控制、游戏 AI
