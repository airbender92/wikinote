# 数据集（Dataset）
在大模型、RAG、训练、评测里，**数据集就是一堆按一定格式整理好的数据样本集合**。

你可以把它理解成：**AI 的学习资料 / 考试题库**。

---

## 一、按用途分几类（最常用）
### 1. 预训练数据集（Pre-training）
- 给模型“打底子”，学语言规律、世界知识
- 内容：海量文本、书籍、网页、百科、代码等
- 特点：无标注，只需要干净、高质量、无偏见

### 2. 微调数据集（SFT / DPO / RLHF）
- 让模型对齐人类偏好、听话、会聊天、会任务
- 常见格式：
  - 指令-回答：`{"instruction":"...","input":"...","output":"..."}`
  - 多轮对话：`[ {"role":"user",...}, {"role":"assistant",...} ]`

### 3. RAG 数据集
- 给检索系统用的**外部知识库**
- 内容：文档、手册、合同、法规、产品说明、历史对话等
- 处理后变成：文本块（chunk）+ 向量

### 4. 评测数据集（Evaluation）
- 用来算：准确率、召回率、流畅度、幻觉率
- 常见：
  - 客观题：选择、判断
  - 主观题：开放问答、摘要、翻译
  - 检索评测：query - 标准答案文档 对

---

## 二、按有没有标注分
- **有标注数据集（Labeled）**
  带标准答案，用于微调、评测
  例：问题 → 正确回答

- **无标注数据集（Unlabeled）**
  只有原始文本，用于预训练、向量化知识库

---

## 三、和你前面问的概念串一下
- 训练模型 → 吃**预训练/微调数据集**
- RAG 检索 → 吃**知识库数据集**
- 算召回率 → 用**评测数据集（query + 标准答案）**
- KV Cache、显存 → 是跑模型时的硬件消耗，和数据集是“数据 vs 硬件”关系

---

## 四、你可能接下来会用到的
如果你在做项目，一般会用到这几种数据集：
1. **自建知识库**（RAG 专用）
2. **指令微调集**（让 Agent 听话）
3. **测试集**（评估召回率、回答准确率）

需要的话我可以给你一个**可直接用的数据集格式模板**（JSON/JSONL），比如 RAG 测试集或微调样本。
