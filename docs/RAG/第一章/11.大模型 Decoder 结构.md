# 大模型 Decoder 结构（通俗+完整版）
Decoder（解码器）是当前主流大语言模型（GPT、LLaMA、Qwen 等）**最核心的结构**，这类模型也常被统称为**Decoder-only 架构**。

下面用清晰、好理解的方式讲清楚它的整体结构、内部组件与工作原理。

---

## 一、整体结构概览
Decoder 模型 = 堆叠 N 层 **Decoder Block** + 输入嵌入 + 位置编码 + 输出层（线性+Softmax）

典型结构：
```
输入 Token Embedding
+ 位置编码 Positional Encoding
→ N × Decoder Block
→ LayerNorm
→ Linear Projection
→ Softmax → 输出下一个 Token 概率
```

---

## 二、单个 Decoder Block 内部结构
标准 Transformer Decoder（GPT 类）每层包含：
1. **Masked Multi-Head Self-Attention（掩码多头自注意力）**
2. **Layer Normalization**
3. **Feed Forward Network（FFN，前馈网络）**
4. 残差连接（Residual Connection）

简化顺序（LLaMA 等现代架构）：
```
输入 → LayerNorm → Masked MHA → 残差相加
→ LayerNorm → FFN → 残差相加 → 输出到下一层
```

---

## 三、关键组件详解

### 1. Masked Multi-Head Self-Attention（掩码自注意力）
这是 Decoder 最关键的部分，**保证生成时只能看前面的词，不能偷看后面**。

- **Mask（掩码）**
  用一个上三角矩阵把未来位置的注意力权重强制设为 -∞，Softmax 后变为 0，实现**因果自回归**。

- **Multi-Head（多头）**
  把 Q/K/V 切成多组，并行学习不同类型的语义关系（语法、指代、逻辑等）。

- 计算流程：
  1. 输入 → 投影得到 Q、K、V
  2. `Attention = Softmax( Q·Kᵀ / √d_k + Mask ) · V`
  3. 多头拼接 → 线性投影输出

### 2. Layer Normalization（层归一化）
- 对每个样本的特征做归一化，稳定训练
- 现代大模型普遍使用 **Pre-LN**（归一化放在注意力/FFN 之前）

### 3. Feed Forward Network（FFN）
两层线性变换，中间加激活函数：
```
FFN(x) = Linear2( SiLU( Linear1(x) ) )
```
常见激活：
- GPT：GELU
- LLaMA / Qwen：SwiGLU（更高效）

FFN 负责**建模复杂语义、事实知识、模式记忆**，参数量通常占模型大头。

### 4. Residual Connection（残差连接）
注意力/FFN 输出直接与输入相加，防止深层网络梯度消失。

---

## 四、Decoder 与 Encoder-Decoder、Encoder 的区别
| 结构 | 典型模型 | 特点 |
|------|----------|------|
| **Decoder-only** | GPT、LLaMA、Qwen | 单向注意力，擅长文本生成 |
| **Encoder-only** | BERT、RoBERTa | 双向注意力，擅长理解/分类 |
| **Encoder-Decoder** | T5、BART | 双向编码+单向解码，擅长翻译、摘要 |

Decoder-only 大模型之所以强，是因为**自回归生成任务天然适配大规模无监督预训练**。

---

## 五、现代大模型 Decoder 的优化（LLaMA 系）
现在主流大模型在标准 Decoder 上做了大量简化与升级：
1. **去掉偏置项 bias**，减少参数
2. **RoPE 旋转位置编码**，替代绝对位置编码
3. **SwiGLU 升级 FFN**
4. **Pre-LN 结构**
5. **Grouped-Query Attention (GQA) / Multi-Query Attention (MQA)**
   减少 KV 缓存，提升推理速度
6. **FlashAttention**
   优化显存与速度，支持更长上下文

---

## 六、Decoder 工作流程（生成一句话）
1. 输入文本 → Token 化
2. 嵌入 + 位置编码
3. 逐层通过 Decoder Block
4. 最后一层输出 → 线性映射到词表维度
5. Softmax 得到下一个词概率
6. 采样（Greedy / Top-K / Top-P）
7. 将新词拼回输入，**循环 autoregressive 生成**

---

## 七、极简总结
Decoder 结构的本质：
- **掩码自注意力**：只能看前文，保证生成顺序
- **残差+层归一化**：保证深度可训练
- **FFN**：存储与加工知识
- **多层堆叠**：形成强大的语义与逻辑建模能力
