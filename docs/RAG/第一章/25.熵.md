# 熵（Entropy）
在大模型里，**熵 = 不确定性、混乱程度、信息量的度量**，直接用来控制模型回答是“胡编乱造”还是“死板确定”。

和你前面问的 **生成序列、Decoder、可解释性** 强相关。

---

# 一、直观一句话
- **熵越小**：模型越确定、越保守、回答越固定、越重复
- **熵越大**：模型越不确定、越随机、越多样、越容易发散

你可以简单记：
**熵 = 模型的“犹豫程度”**

---

# 二、在大模型里的具体含义
模型每一步生成 token，都会输出一个**概率分布**，比如：
-  tokenA: 90%
-  tokenB: 5%
-  tokenC: 5%

熵就是对这个分布的计算：
- 某个 token 概率接近 1 → 熵很小（很确定）
- 所有 token 概率差不多均匀 → 熵很大（很混乱）

---

# 三、和生成参数的关系
### 1. temperature（温度）
- 温度 ↓ → 分布更尖锐 → **熵 ↓** → 回答固定、严谨
- 温度 ↑ → 分布更平滑 → **熵 ↑** → 回答多样、创意、容易幻觉

### 2. top_k / top_p
- 限制候选 token → 降低随机性 → **熵变小**

所以：
**控制生成风格，本质就是在控制输出分布的熵。**

---

# 四、其他常见用途
### 1. 衡量模型困惑度（Perplexity）
- 困惑度 ∝ 熵
- 困惑度越低，模型对文本预测越准
- 缩放法则里的 Loss 下降，就是模型熵在下降

### 2. 幻觉检测
- 模型回答某一部分**熵突然变大**
→ 概率分布很平，模型在瞎猜
→ 高概率是幻觉
→ 可解释性 + 熵 = 自动识别不靠谱内容

### 3. 主动学习 / 标注筛选
优先挑**熵高**的句子给人工标注
→ 模型最不确定、最需要学习的样本

---

# 五、极简总结（面试/理解都够用）
- **熵 = 模型输出概率分布的混乱程度**
- 熵小 → 确定、保守、重复
- 熵大 → 随机、多样、易幻觉
- temperature 本质就是调节熵
- 熵高的地方，往往就是幻觉和胡说八道的重灾区
