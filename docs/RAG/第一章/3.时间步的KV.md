# 时间步的 KV（KV Cache / 时序KV缓存）
先明确术语：**时间步 = 自回归解码的每一轮 token 生成步骤**，$\(t=1,t=2,t=3...\)$；
**时间步KV** = 在每个时序步骤中，保存**历史所有token对应的Key、Value向量**，也就是大家常说的 **KV Cache**。



## 一、基础背景：两种阶段（Prefill / Decode）
GPT类Decoder-only模型生成分为两段：
1. **Prefill（预填充，初始时间步）**
输入完整prompt，一次性并行计算**所有prompt token**的 $K_1,K_2...K_T$、$V_1,V_2...V_T$，存入缓存。
> 时序维度：缓存 `seq_len` 轴一次性铺满prompt全部时间步。

2. **Decode（逐token生成，循环时间步）**
每一个**时间步 t**，只输入**上一步刚生成的1个token**。
- 朴素方案：每次把全部历史序列重新前向，**重复计算全部历史K/V** → 复杂度 $O(T^2)$，越长越慢。
- KV缓存方案：**历史时间步的K/V永久保留不复算**，只计算当前最新token的Q、K、V。

## 二、逐时间步推演（最直观例子）
假设序列时序：`[A, B, C]`，依次生成：
- **t=1：输入A，预测B**
计算 $Q_1,K_1,V_1$；缓存 $\boldsymbol{K_{cache}}=[K_1],\boldsymbol{V_{cache}}=[V_1]$
- **t=2：输入B，预测C**
只算当前token B：$Q_2,K_2,V_2$
历史 $K_1,V_1$ 直接从缓存读取，不再重算；
缓存拼接更新：$\boldsymbol{K_{cache}}=[K_1,K_2],\boldsymbol{V_{cache}}=[V_1,V_2]$
- **t=3：输入C，预测下一个token**
只算当前token C：$Q_3,K_3,V_3$
复用 $K_1,K_2;V_1,V_2$；缓存继续向后拼接。

> 核心公理：**某个时间步的token一旦处理完毕，它的K、V永远不变，不受未来token影响**。
> 所以可以永久缓存，这是KV Cache成立的根本前提。

## 三、张量维度视角：时间步对应哪个维度？
标准多头KV缓存张量形状（单层）：
`[batch, num_heads, seq_len(时间步维度), head_dim]`
- `seq_len` = **时序维度**：每一个位置对应一个时间步token的K/V
- 每新增1个时间步，在`seq_len`维度尾部**追加新k、v**

> 为什么只缓存K、V，不缓存Q？
Q永远是**当前时间步单独token**生成的，每一轮都不一样，无法复用；
K/V是历史所有时间步集合，可以持续复用。

## 四、注意力计算简化对比
不带缓存（每一时间步全量重算）
$$\text{Attn}(Q_{1:t},K_{1:t},V_{1:t})$$

带时间步KV缓存（标准增量解码）
$$\text{Attn}(Q_t,\;[K_{\text{cache}};K_t],\;[V_{\text{cache}};V_t])$$
$Q_t$：当前时间步Query
$K_{\text{cache}},V_{\text{cache}}$：所有历史时间步KV
$K_t,V_t$：当前时间步新生成KV，计算完成并入缓存

## 五、关键痛点（工程重点）
1. **显存随时间步线性上涨**
每多生成一个token，KV缓存占用持续增加；超长对话极易OOM。
公式参考：
$$\text{KV显存} \approx 2 \times \text{layers} \times \text{batch} \times \text{heads} \times \text{seq\_len} \times \text{head\_dim} \times \text{bytes}$$

2. **时序维度持续拼接引发内存碎片**
每时间步追加张量，频繁拷贝；优化方案：PagedAttention（分页KV缓存）

3. 衍生优化方向（都围绕「时间步KV」）
- KV压缩：FP8 KV、KV量化
- 时序剪枝：丢弃远期不重要时间步KV（LongContext场景）
- MLA（多头潜在注意力）：压缩时序维度KV，降低显存

## 六、容易混淆概念区分
- **RAG**：外部文档检索，静态知识库；和时序无关
- **Agent**：自主规划+工具调用，高层业务逻辑
- **时间步KV(KV Cache)**：Transformer推理底层加速原语，**时序自回归生成必备基础设施**

## 七、极简代码示意（伪代码）
```python
# Prefill阶段：初始化时间步KV缓存
hidden = model.forward(prompt_tokens)
past_kv = model.get_kv_cache() # 存入所有prompt时间步K/V

# Decode循环：每个时间步迭代
while not eos:
    # 只传入上一步生成的单token + 历史时间步KV
    hidden, past_kv = model.forward(next_token, past_kv=past_kv)
    next_token = sample(hidden)
    # past_kv内部自动在时间维度追加当前token KV
```
