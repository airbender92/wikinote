# RAG（检索增强生成）
**Retrieval-Augmented Generation**，检索增强生成，是大模型最常用、最实用的优化技术之一。

## 一句话解释
先从**外部知识库/文档**里检索相关信息，再把这些信息喂给大模型，让模型**基于真实资料回答**，而不是只靠自身训练知识瞎编。

## 核心解决什么问题
1. **大模型幻觉**：减少胡说八道、编造事实
2. **知识过时**：模型训练数据截止后新信息也能用
3. **私有知识问答**：企业内部文档、个人资料、专业知识库
4. **长文本处理**：突破模型上下文长度限制

## 典型流程
1. 文档切分（Chunk）
2. 向量化（Embedding）
3. 存入向量数据库
4. 用户提问 → 检索相似片段
5. 把问题 + 检索结果拼 Prompt
6. 大模型生成最终答案

## 常见应用场景
- 企业智能客服/内部知识库问答
- 法律/医疗/金融专业问答
- 文档总结、论文解读
- 长文档对话机器人

## 简单对比
- **纯 LLM**：靠记忆回答，易幻觉、知识旧
- **RAG + LLM**：先查资料再回答，更准确、可更新、可控
