# 向量化（Embedding）
简单说：**把文字、图片、语音等，变成一串数字（向量），让计算机能看懂、能计算相似度**。

在你关心的 RAG 里，它就是**检索的核心技术**。

---

## 一、一句话理解
- 文字：`"人工智能"`
- 向量化后：`[0.12, -0.35, 0.78, ...]`（通常几百到几千维）

含义：
- **语义相近的句子，向量距离近**
- **语义无关的句子，向量距离远**

这样计算机就能做：**相似度检索**。

---

## 二、在 RAG 里的完整流程
1. 把知识库文档切成一段段 chunk
2. 对每个 chunk 做**向量化**
3. 把向量存入**向量数据库**
4. 用户提问 → 同样向量化
5. 计算问题向量与所有 chunk 向量的**相似度**
6. 召回最相似的 Top-K 片段 → 给大模型生成答案

这就是 RAG 召回的本质。

---

## 三、关键指标
- **维度（dim）**：如 768、1024、1536
  维度越高，表达越细，但**占显存、占存储越大**
- **向量长度**：固定长度，不管句子长短，向量长度一样
- **相似度计算**：
  - 余弦相似度（最常用）
  - 点积
  - Euclidean 距离

---

## 四、和你前面知识串起来
- 向量化 → 产生向量
- 向量 → 存在向量库 / 显存
- 检索召回率 → 很大程度由**向量化模型质量**决定
- KV Cache 是推理时的缓存，和 Embedding 是两回事
