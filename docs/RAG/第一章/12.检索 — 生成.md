# 检索‑生成（RAG，Retrieval‑Augmented Generation）
结合上一节 **Decoder‑only大模型**：RAG不是修改Decoder内部结构，而是**在Decoder大模型外部增加一套检索流水线**，给生成器喂外部实时知识，解决大模型**知识截止、幻觉、私有数据不可知**问题。



> 对比：
> - 纯Decoder：知识全部固化在模型参数（预训练时学到）；
> - RAG = **检索器Retriever + Decoder生成器Generator**，外部知识库提供非参数化知识。

## 两大阶段：离线建库、在线问答
### 阶段1：离线索引构建（提前做，用户不感知）
```
原始文档(PDF/MD/网页)
→ 清洗 → Chunk分片（切小块，避免超长）
→ Embedding模型向量化（文本→高维向量）
→ 向量+原文存入向量数据库(Milvus/FAISS/Chroma)
```
- Chunk：分片大小很关键，过小丢失上下文，过大混入噪声；
- Embedding模型：独立于Decoder大模型，专门做语义编码；
- 向量库：做**ANN近似最近邻搜索**，快速做语义匹配，不是关键词匹配。

### 阶段2：在线「检索‑生成」推理链路（用户提问时实时跑）
```
用户Query
↓
1.查询处理（改写/扩展）→ Query向量化
↓
2.召回：向量库搜索，返回Top‑N候选片段（快、粗筛）
↓
3.重排Rerank：Cross‑Encoder模型二次打分，筛选Top‑K最相关片段（慢、精筛）
↓
4.上下文增强Prompt组装
Prompt模板 = 【参考资料：{检索片段}】 + 【用户问题：{query}】 + 指令
↓
5.送入Decoder‑Only大模型（GPT/LLaMA/Qwen）
↓
Decoder自回归生成输出答案
```

> ⚠️ Naive‑RAG就是直接拼接检索片段进Prompt；高级RAG增加查询改写、多路召回、文档压缩、Fusion‑in‑Decoder等技术。

## 检索器 vs 生成器（Decoder）分工
|模块|角色|核心技术|
|---|---|---|
|**检索器Retriever**|找资料，负责外部知识|Embedding、向量库、重排、关键词混合检索|
|**生成器Generator(Decoder‑Only)**|阅读理解+写答案，不改动模型权重|Masked自注意力、多层Decoder Block、自回归token生成|

> 关键点：**标准RAG不微调Decoder**；只是把检索到的资料当成上下文塞进输入Prompt，Decoder内部运行逻辑和普通对话完全不变。

## RAG和微调的区别
|方案|RAG（检索‑生成）|微调Fine‑tune Decoder|
|---|---|---|
|知识存放|外部向量库，可随时增删改知识|固化进模型权重，改知识要重新训练|
|是否改模型参数|❌不改Decoder权重|✅修改Decoder参数|
|适合场景|知识经常变动、私有文档、需要溯源引用|改变输出风格、能力对齐、少量样本任务|
|成本|低，不需要GPU训练|高，需要算力、训练数据|

## 两种融合范式（检索信息如何喂给Decoder）
1. **Prompt拼接（最常用，Naive‑RAG）**
把检索文档文本直接拼在Prompt头部，一起送入Decoder输入层。
> 缺点：占用上下文窗口；检索噪声会直接干扰生成。

2. **Fusion‑in‑Decoder(FiD)**
每一篇检索文档**独立过Encoder**，再把所有文档编码隐状态送入Decoder一起参与注意力计算，不把文档文本全部塞进输入token序列。
> 优点：支持更多参考文档，节省上下文token；架构复杂，工业界落地少。

## RAG存在的典型问题
1. **检索漂移**：检索出来的文档和问题无关，Decoder会“一本正经复述错误资料”；RAG上限由检索质量决定。
2. **噪声注入**：混入无关片段，大模型被误导。
3. **上下文窗口上限**：检索返回太多片段会超出Decoder最大上下文。
4. **幻觉依旧存在**：即使给了参考资料，Decoder依然可能不引用资料，使用模型内部旧知识编造答案。

## 和你上一节Decoder结构串联完整视图
```
用户提问 → RAG检索流水线(Retriever) → 组装Prompt
→ Token Embedding + RoPE位置编码
→ N层Decoder Block(Masked MHA + Pre‑LN + FFN +残差)
→ LayerNorm → Linear→Softmax→采样输出token
```
> Decoder本身完全不变，RAG是**外部前置系统**，只改变送入Decoder的输入上下文。
