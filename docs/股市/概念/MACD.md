# 一、MACD绿柱在哪看（所有炒股软件通用）
1. 打开个股**K线图**（日线/60分钟都可以）；
2. K线（主图）下方有一块独立小窗口，这个窗口就是**MACD副图**；
3. 窗口中间有一条横向0轴分界线：
   - 柱子长在**0轴下方、向下延伸** = **绿柱**
   - 柱子长在**0轴上方、向上延伸** = 红柱



窗口里一共三样东西：
- 白线DIF（快线）、黄线DEA（慢线）；
- 中间横线=0轴；
- 上下竖条柱子=MACD能量柱，负值就是绿色。

# 二、调出MACD的操作（找不到就这么做）
PC通达信/东方财富/同花顺：
K线页面直接键盘输入 `MACD`，回车，下方自动调出指标。
手机APP：个股K线→点下方“指标”→选择MACD。

# 三、绿柱基础含义（配合你口诀用）
1. 出现绿柱 = DIF在DEA下方，**空头力量更强**；
2. 绿柱越来越长：下跌动能加大，别抄底；
3. 绿柱慢慢缩短：空方力量衰竭，容易走出**MACD金叉**（对应你“前大后小，金叉就搞”的买点）；
4. 零轴下方绿柱消失、翻红柱，就是金叉确认信号。

# 四、结合你之前的口诀配套用法
上车「前大后小，金叉就搞」完整量价+MACD逻辑：
1. 上涨阶段成交量放大（前大）；
2. 回调缩量（后小），同时MACD**绿柱持续缩短**；
3. DIF白线从下往上穿过DEA黄线（金叉），绿柱彻底消失变红柱，入场。

我给你用最直白、不绕弯的话讲清楚：

# 1. MACD 是“慢指标”，看的是一段走势
- 今天这一根 K 线，**影响不了 MACD 太多**
- MACD 反应的是**最近几天、甚至几周**的资金动能
- 绿柱变大、变小、金叉、死叉，都是**几天慢慢走出来的**

所以你理解的非常对：
**“前大后小”是对比前几天、前一段的绿柱，不是只看今天。**

# 2. 你口诀里的“前大后小”到底比的是什么？
- **前大**：前几天下跌时，绿柱很长、很大
- **后小**：这几天再跌，绿柱反而越来越小

这是**几天的对比**，不是当天一分钟的变化。

# 3. 金叉也不是“突然当天就叉”
MACD 金叉，通常是：
1. 绿柱缩了好几天
2. 白线慢慢靠近黄线
3. 某一天收盘后，正式交叉

它是**多日酝酿出来的反转信号**，不是日内玩心跳。

# 4. 和你尾盘战法怎么搭配？
- **尾盘选股**：看当天分时、量比、换手、涨幅 → 找当天强势
- **“前大后小，金叉就搞”**：看几天的 K 线、MACD、均线 → 找趋势拐点

两个合在一起就是：
**当天强势 + 多日趋势反转共振 = 最稳买点**

一句话总结：
**MACD 看的是“最近一段日子”，不是当天；
金叉是趋势转强，不是日内小游戏。**
