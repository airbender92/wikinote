# 买在分歧，卖在一致（结合你均线趋势战法，通俗讲透）
这句话是短线、波段核心情绪心法，完整完整版是：**买在分歧转一致，卖在一致转分歧**

## 一、先分清：什么是分歧、什么是一致
### 1. 分歧（多空打架，看法两极）
所有人观点不统一，有人疯狂砸、有人疯狂抄，盘中剧烈震荡
**K线/量能特征**：
- 宽幅震荡、长上下影、涨停反复炸板、大跌后快速拉回
- 成交量明显放大（放量换手）
- 股吧、市场一半看多一半看空，利空恐慌、利好犹豫

**两种分歧，只买第一种**
1. **上涨中途分歧（机会）**
趋势完好（60日线向上、均线多头），第一次回调、回踩5/20/60日线，短期情绪恐慌砸盘，但基本面、行业逻辑没坏。
就像今天大盘大跌，优质赛道错杀，属于**良性分歧低吸点**。
2. **高位末端分歧（风险）**
股价大幅翻倍后放量震荡，主力偷偷出货，散户抄底接盘，越震荡越危险，不能买。



### 2. 一致（市场观点完全统一）
#### 看多一致（加速上涨，卖点）
所有人闭眼看多，没人愿意卖出，股价直线拉升、缩量大涨、连板加速，全网吹票、散户疯狂追高。
特征：缩量连阳、跳空大阳线、上涨角度陡峭，情绪到极致。
逻辑：所有人都进场后，没有新资金接力，行情马上见顶，这就是**卖出时机**。

#### 看空一致（全线大跌，回避）
所有人恐慌割肉，无量阴跌、连续大阴线，没有承接，坚决不抄底。

## 二、买在分歧：什么时候敢下手？（贴合你的均线体系）
### 入场硬性条件缺一不可
1. 中期趋势向上：60日均线持续向上，股价整体在60日线上方；
2. 属于**上涨第一次分歧**：回踩5/20/60日线，短期情绪杀跌，属于洗盘；
3. 盘中有承接：大跌后能拉回，放量但跌不穿关键均线支撑；
4. 行业/个股核心逻辑没崩塌，只是短期情绪、消息扰动。

**举例**：工业富联长期均线多头，今天受Meta消息分歧大跌，回踩短期均线，属于上涨途中分歧；若明天资金回流、企稳，就是分歧转一致买点。

## 三、卖在一致：什么时候必须离场？
1. 股价连续加速拉升，K线陡峭、缩量大涨，市场全部唱多；
2. 高位放出天量，一致看多后资金开始兑现；
3. 短期严重脱离5日线，大幅透支行情；
4. 情绪达到顶峰，身边普通人都在跟风买入。

一致上涨是最后的狂欢，一致之后必然分歧大跌，所以要在全民乐观时卖出。

## 四、散户最容易犯的反向错误
散户天然反着做：
- 分歧大跌、恐慌割肉（该买的时候卖）
- 一致大涨、狂热追高（该卖的时候买）
这就是大部分人亏损的根源。

## 五、极简实战口诀（搭配均线一起用）
1. 趋势完好、回踩均线放量分歧 → 低吸买入（买分歧）
2. 连续加速、全民看多缩量一致 → 分批止盈（卖一致）
3. 高位放量分歧、60日线拐头 → 规避出货分歧
4. 下跌趋势全线看空一致 → 绝不抄底
