# 前大后小
- **前大**：前面那根阳线（或上涨波段）**成交量要大**，资金进场实锤
- **后小**：后面回调、回踩的时候**成交量要小**，说明没人砸盘、抛压轻

合起来就是：
**上涨放量、回调缩量 → 健康洗盘，马上要拉**

# 金叉就搞
这里一般指两个常用金叉，满足一个就可以动手：
1. **均线上的金叉**：5日线金叉10日线，短线趋势转强
2. **MACD金叉**：快慢线在0轴附近金叉，反弹信号确认

出现金叉 = 调整结束，资金要再次进攻
→ **直接上车，不犹豫**

# 整句连起来就是
**前面放量涨，后面缩量调，
指标一出金叉，直接干进去！**
