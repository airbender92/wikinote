# 清晰区分两个概念，二者完全不是一回事
## 1. 涨停价（当日最高价）
是价格数字，是交易所规定的**当天股价能涨到的最高价位**，比如个股10元涨停，涨停价就是11元，这是固定价格上限。

## 2. 封单
是**挂在涨停价上的买入委托单子**，是资金挂单的数量，不是价格：
- 位置：分时盘口「买一」那一栏的巨额买单；
- 本质：一堆等着在涨停价买入股票的委托，用来托住价格不让涨停打开；
- 单位：手/万元，用来衡量资金护盘力度。

## 举个直白例子
某股现价10元，涨停价11元（当日最高价）；
主力在11元挂5万手买单，这5万手就是**封单**，11元才是当日最高价。

## 关联逻辑
封单必须挂在**当日最高价（涨停价）** 才能封住涨停，但封单本身≠这个最高价，一个是挂单量，一个是价格上限。

## 结合你笔记里的缩量封涨停
主力在当日最高价挂巨量封单，场内卖出筹码很少，成交持续萎缩，才形成强势缩量封板形态；如果封单撤掉、被卖单砸穿，涨停就会打开，股价就会低于当日最高价。
