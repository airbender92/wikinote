4、成交量萎缩后，新低点连续2天不再出现时，量的打底已可确认，可考虑介入

这句话就是在教你**怎么确认底部真正成立**，非常实战，我给你讲得清清楚楚：

# 第四条原则白话解读
## 1. 先有缩量
成交量已经缩得很小，说明**没人卖了**，抛压基本没了。

## 2. 关键条件：**连续2天不再创新低**
- 第一天：没创新低
- 第二天：还是没创新低

这就说明：
**跌不动了，底部被托住了，不再往下砸了。**

## 3. 什么叫“量的打底已可确认”？
就是：
**成交量缩到最低 + 股价不再创新低 = 底部已经筑好**
主力吸筹完成，准备往上拉了。

## 4. 结论：可以考虑介入
满足上面两点，就不是瞎抄底，
而是**底部确认后的安全买点**。

- 量越来越小（前大后小）

- 确认底部 → 可以买
