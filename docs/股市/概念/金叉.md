# 金叉，通俗说就是：**短线要转强的信号，往上拐头交叉**

最常用、最实用的就两种，一看就懂：

## 1. 均线金叉（最稳）
- **5日均线 从下往上 穿过 10日均线**
- 两条线交叉后，开口向上
代表：短期资金开始重新进场，趋势由弱转强
→ 这就是你说的 **“金叉就搞”**

## 2. MACD金叉（辅助确认）
- MACD 里的**快线上穿慢线**
- 两条线在低位交叉向上
代表下跌动能耗尽，要反弹拉升

---

# 简单记
**金叉 = 两条线 从下往上交叉 + 开口向上**
死叉 = 从上往下交叉，要跌

配合你的口诀：
- **前大后小（上涨放量、回调缩量）**
- **再出金叉**
→ 就是标准上车点。
