# 进场口诀：前大后小，金叉就搞
## 1. 前大后小（核心：底背离 + 跌不动了）
- **前大**：前面一段下跌，MACD 绿柱**比较长、比较大**
- **后小**：后面股价再创新低，但 MACD 绿柱**反而变短、变小**

这就是经典的：
**股价新低 → 绿柱不新低 → 底背离**
说明：**抛压衰竭、跌无可跌，马上要反转**

## 2. 金叉就搞（双重金叉共振，最佳上车点）
两个金叉同时出现，就是最强买点：
1. **MACD 金叉**：白线 DIF 上穿黄线 DEA，绿柱翻红
2. **均线金叉**：5 日均线上穿 10 日均线

→ **双线共振金叉 = 正式启动信号，直接上车**

## 三、配套离场口诀对照（形成完整交易闭环）
离场口诀：**前高后低，放量就跑**

3. 优势：放量信号比MACD死叉提前出现，能更早规避下跌回撤。
