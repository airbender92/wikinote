3、在下跌过程中，若成交量不断萎缩，在某天量缩到“不可思意”的程度，而股价跌势又趋缓时，就是买入的时机

这句话说得很直白，我给你用最通俗、最实战的话讲透：

# 第三条成交量买卖原则解读
## 1. 什么叫“量缩到不可思议的程度”？
就是成交量**小到几乎没人买卖了**，量柱变得特别矮，
比之前下跌过程中的量还要小很多，几乎快没量了。

## 2. 为什么这时候是买入时机？
- 成交量不断萎缩 = 想卖的人越来越少
- 缩到极致 = 割肉的人已经割完了，抛压几乎没了
- 股价跌势趋缓 = 跌不动了，快要止跌企稳

这就是典型的**空头衰竭**，
再往下砸也没人卖了，稍微一点买盘就能拉起来。

## 3. 对应你前面学过的量价形态
完全就是：
**价跌量缩 → 价平量缩（极致缩量） → 即将反转**
也就是你口诀里说的：
**前大后小，金叉就搞**

## 4. 实战要注意一点
不是一缩到极致就马上满仓冲，
而是：
- 先看是不是**低位**
- 再看是不是真的**跌不动了**
- 等后面稍微放量、企稳、出现小阳线再买更安全

一句话总结这条原则：
**跌的时候量越缩越小，小到几乎没人卖，就是快见底了，可以准备买。**
