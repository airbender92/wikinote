# 成交量配套买卖原则第一条深度解读（结合你「逆势放量」量价法则）
## 一、核心逻辑
操作的前提先看大盘整体环境，大盘处于下跌、破位、走弱行情时，原则上空仓观望，不主动开新仓；哪怕盘中有个股逆势放量拉升，也不能跟风参与。

## 二、为什么不能碰逆市上涨个股
1. **逆势拉升大多是诱多出货**
对应你笔记里的「逆势放量」法则：大盘走弱、个股逆势放量上涨，基本是主力借恐慌氛围拉高出货，制造强势假象吸引散户抄底接盘，反弹持续性极弱，追进去很容易被套。
2. **顺势行情赚钱概率远高于逆市**
大盘向好时，绝大多数股票跟随上涨，资金集体做多，放量上涨、缩量回调的良性形态会大量出现，容错率高；
大盘走弱时市场整体资金出逃，场内做多资金稀缺，逆势个股没有持续资金接力，短期冲高后会快速补跌。
3. **规避系统性风险**
大盘下跌阶段，绝大多数个股都会跟随调整，就算个股短期逆势走强，后期也会跟随大盘补跌，没必要为小概率行情承担大面积亏损风险。

## 三、实战落地标准
1. 入场前提：大盘放量企稳、走出上升趋势，赚钱效应扩散，再依据量价法则选股操作；
2. 大盘走弱处理：持仓个股逢反弹减仓，不新开仓；遇到逆势放量拉升的个股直接跳过，不抱有侥幸心理；
3. 特殊区分：仅极少数长期底部低位、持续价平量增的中线标的，可小仓位底仓持有，绝不短线追高逆势票。

## 四、和整套量价体系联动
这条原则是**选股大前提**，所有低位放量、回调缩量、缩量封涨停等做多信号，只有在大盘环境向好时，信号可靠性才会大幅提升；
大盘弱势环境下，哪怕个股出现看似良性的放量上涨，也属于「逆势放量」陷阱，直接放弃操作。

信息仅供参考，不构成投资建议。
