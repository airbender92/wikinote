# 长啥样才算 MACD 金叉？
在 K 线下面的 MACD 窗口里：
1. 原来的 **绿柱慢慢变短，快要没了**
2. 白色线（DIF）**从下往上穿过** 黄色线（DEA）
3. 交叉之后，两根线一起向上走

满足这三点，就是标准金叉。

---

# 对应你的实战用法
- 前面已经 **放量上涨（前大）**
- 回调时 **缩量（后小）**
- 现在 MACD 出金叉
→ **这就是标准买点，可以进**

# 一个关键提醒（非常重要）
不是所有金叉都能搞：
- **0轴下方的金叉**：弱势反弹，快进快出
- **0轴上方的金叉**：强势拉升，可靠性最高
- **无量金叉**（像邮储银行那种）：假信号，别格局，有赚就走

完全对应你之前那套强势股筛选系统。
