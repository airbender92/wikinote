# 离场口诀：前高后低，放量就跑
## 1. 前高后低（核心：顶背离，涨不动了）
- **前高**：前面一段上涨，MACD 红柱很高、很长
- **后低**：后面股价再创新高，但红柱**反而越来越短、越来越低**

典型信号：
**股价新高 → 红柱不新高 → 顶背离**
说明：**上攻动能衰竭，主力开始悄悄出货，随时跳水**

## 2. 放量就跑（最后逃命信号）
- 高位一旦放出**巨量**
- 或者高位收长上影、大阴线放量
- 不管有没有死叉，先跑再说

主力出货最明显的特征就是：
**价格不怎么涨，成交量却暴增**
