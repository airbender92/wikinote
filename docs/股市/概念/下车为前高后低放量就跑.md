# 前高后低，放量就跑
- **前高后低**：股价创出近期高点，但**MACD、量能、均线力度开始走弱**（顶背离），看着创新高，其实动能已经不行了。
- **放量就跑**：高位放巨量不涨、或者高位大阴线放量，说明主力在疯狂出货、抛压炸了，这时候别犹豫，直接跑。

合起来意思就是：
**股价到前高但动能减弱，一旦高位放量滞涨或杀跌，立刻止盈离场。**

# 整套口诀连起来就是完整进出规则
上车：**前大后小，金叉就搞**
下车：**前高后低，放量就跑**

再配上你前面的：
- 尾盘筛选
- 均线多头
- 买在分歧，卖在一致

不是分时图，也**不是当天就跑**，我给你一次性说清楚，不绕弯：

# 1. “前大后小，金叉就搞”
**看的是：日K线（日线图）**
- 前大：前面**日K上涨放量**
- 后小：后面**日K回调缩量**
- 金叉：5日/10日均线金叉 或 MACD金叉（都是日线级别）

属于**短线波段信号**，不是日内超短。

# 2. “前高后低，放量就跑”
**也是看日K**
- 前高：股价到前期高点
- 后低：MACD、量能开始走弱（顶背离）
- 放量就跑：高位放量大阴线/放量滞涨，**日线级别卖出**

# 3. 那到底是当天跑，还是拿几天？
- 你前面那套 **14:30尾盘选股 → 当天买 → 明天卖**
  → 这是**超短（隔日超短）**

- 现在这句 **“前大后小，金叉就搞；前高后低，放量就跑”**
  → 这是**短线波段（拿3～7天左右）**

# 一句话区分
- **尾盘战法：当天买，明天冲高卖（隔日）**
- **口诀战法：金叉买，放量破位卖（拿几天）**

两个可以搭配用：
**尾盘选出的股，再用“前大后小、金叉就搞”确认买点，更稳。**
