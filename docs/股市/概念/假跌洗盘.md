这两个最关键，我用**最简单、最实用**的方式给你分清楚，一看就懂：

# 一、假跌 = 洗盘（后面还要涨）
主力故意砸盘吓散户，**跌是假的，想涨是真的**。

典型特征：
1. **跌得快，拉得更快**
   上午大跌，下午直接拉回去，K线收长下影线。
2. **下跌不放量，或者放量很快缩量**
   没多少人真卖，只是吓一吓。
3. **关键支撑位不破**
   重要均线、前期低点碰一下就弹起来，不有效跌破。
4. **大盘跌它跌，大盘企稳它立刻反弹**
   明显是借势洗盘，不是自身出问题。
5. **板块没崩，个股基本面没问题**
   只是情绪杀，不是逻辑杀。

一句话：
**跌得吓人，但跌不下去，很快收回 → 洗盘。**

---

# 二、真跌 = 要大跌（后面还要跌）
主力真出货、资金跑路，**跌是真的，还要继续跌**。

典型特征：
1. **阴跌不止，每天跌一点**
   天天新低，没有像样反弹。
2. **下跌持续放量**
   大资金一直在往外跑，卖盘源源不断。
3. **关键支撑位直接跌破**
   均线、箱体、前低全部跌破，站不回去。
4. **反弹无力，每次反弹都是逃命机会**
   拉一点就被砸下来，重心不断下移。
5. **有利空、板块崩、基本面恶化**
   不是情绪问题，是逻辑问题。

一句话：
**跌了就起不来，越跌越低 → 真跌。**

- 单日猛跌吓死人 → 多半洗盘
- 慢慢跌天天新低 → 多半真跌
