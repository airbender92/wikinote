如何做长线？长线筛选好公司，方法相对比较复杂。不过有2个指标可以轻松筛选做长线的好公司，这是入门级标准。大家都知道，股价的长期上涨，是由业绩驱动的，业绩增长是股价上涨的发动机，那么什么公司业绩才会好呢？最基础的指标，就是ROE，净资产收益率，也是股东回报。一家包子铺，投入了10W成本，每年纯利润是2W，那么ROE是20%，长期来看，股价每年的上涨幅度平均也会是20%，正常情况下资金给公司的PE估值也会到20倍，但是公司的合理估值会是5倍，因为5年回本，看吧，就这么简单。那么ROE又和什么有关呢？最主要的是毛利率，净利率。一个包子成本1元，卖2元，毛利率是50%，除去面粉，人力，电费等成本，净赚0.5元，净利率是25%。所以，毛利率高，净利率也高的公司，大概率是个好公司，他们必须挂钩起来，缺一不可。但需要注意两点，毛利率高，不一定净利率也高，有可能赚的是辛苦钱。比如公司的销售费用太高了，就是需要卖出去一个2元的包子，需要花1元的成本去打广告，去吆喝。而毛利率低的，净利率一定不高。净利率都不高，长期业绩的增长大概率也不高，股价自然也很难涨。只有这毛利率，净利率都高了，其他各项长线指标，比如业绩增速，ROE，股东回报，偿债能力，自由现金流，周转率才能高。所以这是筛选长线股的2个基本门槛。



## 一、长线底层核心逻辑
长线股价上涨的唯一核心驱动力是**持续稳定的主业业绩增长**，业绩是股价长期上涨的底层发动机；短线看资金情绪、中线看箱体突破，长线看企业真实盈利能力，三者底层逻辑完全区分开。

## 二、两大入门级筛选门槛（毛利率+净利率+ROE联动）
### 1. 核心指标1：ROE（净资产收益率，股东真实回报）
#### 通俗举例（原文包子铺模型）
投入本金10万，年纯利2万，ROE=20%；长期维度，企业股价年化涨幅会趋近长期平均ROE。
- 含义：衡量股东投入自有资本的赚钱效率，是价值投资核心标尺；
- 估值逻辑：年化20%回报，静态5年回本，对应合理估值区间；
- 关键前提：**高ROE必须由高净利率支撑**，而非靠高负债杠杆堆出来的虚假高ROE。

### 2. 核心指标2：毛利率、净利率（ROE质量的过滤网）
#### 指标定义
- 毛利率：产品本身溢价能力（包子成本1元、售价2元，毛利率50%），代表产品护城河、定价权；
- 净利率：扣除原材料、人工、销售广告、税费后最终留存利润（包子净赚0.5元，净利率25%），代表企业完整经营管控能力。
#### 原文核心辩证关系
1. **高毛利率≠高净利率**
若销售、广告等费用极高，产品毛利再高，最终净利会被消耗。例：包子卖2元，营销推广花1元，看似高毛利，实际净利大幅缩水，属于“赚辛苦钱”，长期无法支撑稳定高ROE。
2. **低毛利率一定低净利率**
产品本身没有溢价空间，再怎么压缩费用，最终纯利上限极低，长期业绩增长乏力，股价很难走出长牛行情。
3. 二者必须**同步长期维持高位**，才是优质长线标的基础门槛。

### 3. 连锁传导逻辑
高毛利率+高净利率 → 持续稳定高ROE，同时带动业绩增速、股东回报、现金流、资产周转、偿债能力同步改善；
只要毛利、净利双低，后续所有长线财务指标都会同步走弱，直接排除长线持仓资格。

## 三、长线、短线、中线三套体系完整对比
| 周期 | 核心思路 | 选股核心标准 | 风控规则 | 盈利来源 |
| ---- | ---- | ---- | ---- | ---- |
| 短线 | 博弈资金情绪，只做最强标的 | 近期有涨停、创新高、放量5倍以上，回踩介入 | 1/5~1/10小仓位，严格止损，快进快出 | 短期资金炒作、连板拉升 |
| 中线 | 箱体转折右侧突破，做波段行情 | 长期横盘整理，末端放量向上突破箱体，叠加热点板块 | 分仓布局，8%止损，20%+止盈 | 中期主力主升浪波段 |
| 长线 | 企业业绩复利成长，价值投资 | 连续高毛利+高净利，稳定高ROE，主业持续盈利 | 长期持有，分批逢低布局，跟踪年报基本面 | 企业每年业绩增长带来的股价长期抬升 |

## 四、原文实操避坑要点
1. **拒绝单一指标选股**
只看ROE会踩坑：部分企业靠举债加杠杆拉高ROE，看似回报高，实则负债风险极大；必须先用毛利、净利率过滤盈利质量，再看ROE持续性。
2. **动态跟踪而非静态筛选**
长线不是买入躺平，每年财报要复核毛利、净利率是否持续下滑，一旦产品定价权消失、净利持续萎缩，即使ROE短期好看，也要减仓离场。
3. **区分一次性收益与主业利润**
计算净利率、ROE时，剔除变卖资产、政府补贴等非经常性收益，只看主营业务真实盈利，避免被短期账面利润误导。

## 五、整体交易体系总结（枫林实盘完整三层框架）
1. **短线抓爆发力**：强势涨停股回踩低吸，小仓位博弈短期资金行情；
2. **中线抓确定性波段**：横盘箱体突破右侧入场，盈亏比清晰，胜率更高；
3. **长线抓复利成长**：财务指标筛选优质核心资产，依靠企业长期业绩增长实现稳定收益。
三套体系互不冲突，可根据市场环境搭配使用，完整覆盖短、中、长全部行情机会。
