# 首阴反包（短线核心分歧战法，搭配你均线体系一起用）
## 一、基础定义
### 1. 首阴
主线强势龙头连续大涨/连板后，**上涨途中第一根阴线**（第一次分歧），主力借下跌洗浮筹，不是出货。
### 2. 反包
首阴次日，一根大阳线/涨停，**实体完全包住前一天阴线**，收复全部跌幅，多空彻底反转，分歧转一致。



完整K线组合：**连阳拉升 → 首阴洗盘 → 放量大阳反包**，N字结构，对应你说的「买在分歧，卖在一致」。

## 二、合格首阴硬性条件（缺一不可，过滤陷阱）
1. **趋势前提（结合你的均线）**
5/10/20/60日均线多头向上，股价全程在5日线上方，首阴**不能有效跌破5日线**；60日线向上代表中期趋势完好，洗盘而非见顶。
2. **只做第一次阴线**
二阴、三阴直接放弃，多次阴线代表资金逐步兑现，反包成功率大幅下降。
3. **跌幅温和**
单日跌幅-3%~-7%最佳；跌停、天地板大阴线=承接崩溃，不是洗盘，放弃。
4. **量能匹配**
- 前一天缩量涨停加速 → 首阴温和放量换手
- 前一天放量换手板 → 首阴缩量
**严禁放出阶段历史天量阴线**（天量=主力跑路）
5. **分时承接强**
盘中不创新低，尾盘有资金翘尾，下跌缩量、反弹放量，恐慌盘被资金接住。

## 三、两种买点（分保守/激进）
### 买点1：首阴当日尾盘低吸（分歧买入，对应买在分歧）
条件：尾盘站稳5日线、全天不创新低、跌幅可控；
逻辑：当天分歧充分换手，博弈次日反包。
止损：跌破首阴最低点/收盘跌破5日线无条件离场。

### 买点2：次日确认反包再介入（胜率更高）
1. 高开2%以上，早盘量能达到昨日首阴60%；
2. 快速站稳分时均线，拉升吞没阴线实体；
3. 板块同步走强，龙头带动跟风上涨。

## 四、卖点（卖在一致）
1. 反包涨停封不住、冲高放量滞涨，分批止盈；
2. 股价大幅脱离5日线，上涨角度陡峭，情绪一致看多；
3. 次日再次放量收阴，第二次分歧直接离场。

## 五、和你之前均线体系联动用法
1. 大趋势：60日线向上、均线多头排列，才有资格做首阴；
2. 短线生命线：首阴不破5日线=洗盘；有效跌破5日线=行情结束；
3. 波段支撑：若首阴回踩20/60日线企稳，属于中级分歧，反包空间更大。

## 六、致命坑（千万别碰）
1. 高位翻倍后、天量大阴线的首阴，主力出货，不存在反包；
2. 下跌趋势（股价长期在60日线下方）的阴线，越抄越套；
3. 板块退潮、跟风杂毛股首阴，只有龙头才有反包溢价；
4. 首阴直接放量跌破60日线，中期趋势走坏，放弃博弈。
