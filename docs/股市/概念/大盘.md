# 大盘通俗完整解释
## 1. 基础定义
我们日常说的**大盘**，一般指两个核心指数，代表整个市场整体涨跌：
1. **上证指数（沪市大盘）**
代码000001，包含上海交易所绝大多数股票，平时大家口中说的“大盘涨/跌”，大多指它。
2. **深证成指（深市大盘）**
代码399001，代表深圳交易所全部个股整体走势。

简单讲：**大盘 = 整个股票市场的平均涨跌水平**，能直观看到当下市场整体赚钱还是亏钱。

## 2. 和你这条买卖原则的关联
1. 大盘大涨、指数稳步走高：市场整体资金进场，绝大多数股票跟着涨，此时做票容错率高；
2. 大盘大跌、指数持续走弱：市场资金集体出逃，大部分股票同步下跌，也就是原则里说的「大盘不好不要做」；
3. 逆势股：大盘在跌，唯独某只股票单独拉升，就是你笔记里的**逆势放量**，主力诱多出货的概率极大，不能追。

## 3. 直观举例
- 大盘涨30点：两市大部分股票收红，良性放量上涨的个股变多，适合按照量价法则选股操作；
- 大盘跌50点：两市超三千只股票下跌，就算有一两只逆势涨停，大多是短期诱多，后续容易补跌，直接空仓观望。

## 4. 补充小知识
还有沪深300、创业板指这类细分指数，大家口语里统称“大盘”，判断环境优先看上证指数整体趋势即可。
