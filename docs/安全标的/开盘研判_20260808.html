五、今日核心变量排序 与 "大家没想到的点"

风险事件排序

  1. ① 8/12美国7月CPI（20:30）——"一票否决"级：非农爆冷后市场赌"不加息"，若CPI反弹，定价被推翻，高位科技首当其冲（概率最高的尾部风险）。
  2. ② 存储链补跌（今日盘中）——美股续跌（希捷-4.71%/闪迪-3.68%）+伯恩斯坦"涨价斜率放缓"，A股存储8/7逆势上涨是背离，今日高开即兑现，不接飞刀。
  3. ③ 油价方向——WTI周跌7.67%（美伊和平进展），若协议落地续跌：石油链承压（中海油/石化低吸窗口）、航空/化工成本受益；若伊朗反悔：通胀压力回升。
  4. ④ 中国7月CPI/PPI（8/9-10）——国内通胀与政策空间。
  5. ⑤ 中报"延期披露"雷扩散——双汇前例（8/12→8/29），消费股中报期留意同类公告，出现即降级。
  6. ⑥ 美联储官员讲话（8/13-14）——内部分歧大，加息预期来回修正。
1. 美股存储"业绩炸裂、股价暴跌"的定价逻辑松动，但A股8/7却逆势上涨——这个背离迟早修复一个方向。闪迪Q4营收+372%、毛利率84.6%、数据中心+1298%，但下季指引中值105.5亿低于市场最高111.6亿，股价照样跌。市场从"沾AI就涨"转向苛求"持续超预期"。A股深科技/长电/中芯的逆势，要么是错杀修复、要么是补跌前兆——今天高开就是检验，别赌单边。
2. 谷歌是七巨头里唯一下跌的（-0.96%，"AI人事巨震"）——AI叙事内部开始分化。英伟达+2.27%、特斯拉+2.83%新高，谷歌却在跌。这对A股的映射是：算力硬件（富联/PCB）与AI应用/软件（部分TMT）的分化会加剧，资金抱团会越来越集中在少数硬逻辑。

4. 油价周跌7.67%被大多数人忽略了——它才是"不加息"定价的隐藏支撑。周五美股大涨的官方解读是"非农弱→不加息"，但油价周线暴跌（美伊和平进展）同样在压低通胀预期。若8/12 CPI因此低于预期，宽松交易强化；若伊朗反悔、油价反弹，通胀压力立刻回来——石油链（中海油/石化）是少数"受益当下、对冲未来"的方向，回踩低吸区可布局。
