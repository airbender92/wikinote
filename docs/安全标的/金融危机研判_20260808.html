2. 债市在悄悄预警，股市还在创新高——股债背离。30Y美债5.16%站上2007年危机前水平、HY利差周内走阔12bp至2.80%，这是"市场对美债偿债能力信心动摇"的底层信号（雪球：突破3%就该警惕）。股市定价的是"AI未来"，债市定价的是"债务现实"——两个市场总有一个是错的。
3. 全球最脆弱的杠杆点不在美国、不在中国，在韩国。韩股广义杠杆271万亿韩元、三星+SK海力士贡献超七成指数涨幅、每30名适龄人口就有1人收追保、20-30岁爆仓占62%。韩国散户爆仓→抛三星/海力士→存储链→A股存储"时差背离"修复——这是今天离你最近的一条风险传导链。
4. 日元：史上最大干预（约528亿美元）治标不治本。干预后日元又贬回160+，只要美日利差在，套息交易就继续（净空头116.5亿美元近两年高位）。日央行"鹰派暂停"+最早10月加息至1.25%——这是下一根导火索的计时器，2024年8月崩盘剧本的引信还在。
