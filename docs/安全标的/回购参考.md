## 三、做T铁律（沿用《分批建仓与做T操作手册_20260810.html》）

1. **往返成本 ≤ 价差1/3**：1手往返成本≈10~16元固定+0.05%印花。价差低于0.5元/股（高价股1.5元）不值得动手。
2. **当日闭环**：当天卖出必须当天接回（或当天买入必须当天卖出），不留隔夜T仓。
3. **T仓 ≤ 底仓1/3~1/2**：做T仓位严禁超过底仓一半；当前满仓状态下T仓资金优先用已回收现金，不新增占用。
4. **单日 ≤ 1次**：每只每天最多做一轮，做错即停，不追加摊薄。
5. **防守位优先**：跌破低位区下沿（各股防守位）立即停止做T，按持仓纪律处理，不做"越跌越买"。
6. **事件日/数据日减半或不做**：PCE/非农/财报/发布会当天波动无规律，做T胜率下降。
7. **未持仓标的**（歌尔/富联/亨通/深科技/万华化学/牧原股份）不持仓则不参与，区间仅作观察与重新进场参考；深科技处于下行趋势，须等"不再创新低"才可考虑。
