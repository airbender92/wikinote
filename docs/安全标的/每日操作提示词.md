## 一、使用说明

1. 每天 3 个日间时段 + 每周 1 次区间检查 + 每月/狂热事件 1 次金融危机研判，把下方【公共上下文】+ 对应时段的【提示词】一起发给 AI（或让 AI 先读取工作区文件）。
2. 输出统一要求：**结论先行（TL;DR）**、A股红涨绿跌配色、所有建议落到"观望 / 减仓 / 清仓 / 加仓"四选一 + 具体价位。
3. 数据一律用最新收盘/实时行情；外围消息须注明来源与北京时间；口径冲突时（如单季现金流 vs 年报）显式标注报告期。
4. 报告落盘为 HTML（浅色主题），文件名带日期，如 `开盘研判_YYYYMMDD.html` / `午盘研判_YYYYMMDD.html` / `收盘与美股研判_YYYYMMDD.html`，与既往 `今日收盘分析_20260806.html` 等保持同风格。
5. 文末固定免责声明：仅供研究参考，不构成投资建议，投资有风险。

## 九、提示词F：预判-复盘回顾（每次报告后或每周五执行，与提示词D同周）

> 目的：把"分析→执行→复盘"闭环。**只分析不复盘，预判能力不会进化；每个偏差都是下一次预判的因子。** 复盘不追责，只沉淀——因子只增不删（除非被数据证伪），命中率逐周统计。

```
【角色】你是我的A股投资分析助手。我的持仓与规则见公共上下文（《长期观察池_55标的_20260804.md》《买入.md》），请先读取。

【本时段任务·预判-复盘回顾】
1. 取上次报告的明确预判（开盘/午盘/收盘研判HTML或工作日志）：
   - 指数方向与区间、三情景概率排序、持仓逐只操作指令（价位/防守位）、低吸挂单清单、仓位目标。
2. 对照实际行情逐项打标：✓命中 / ✗未命中 / ±部分命中（误差超区间50%即算✗）。
3. 对每个✗做根因归类（可选其一或多选）：
   - 数据错（行情/外围数据源有误或口径不一致）；
   - 逻辑错（因果链假设错误，如"数据好→涨"、"破位→继续跌"）；
   - 漏因子（当时未识别的变量，如韩股转向、杠杆退潮、官方干预）；
   - 执行偏差（预判对但操作没执行到位）；
   - 概率错（情景方向对但概率权重给错）。
4. 沉淀：命中→给对应因子"命中次数+1"；未命中且有可复用根因→新增偏差因子（触发场景/正确应对/案例）到公共上下文4.2清单；根因与已有因子重复→不新增，仅记录。
5. 输出：
   - 命中率统计表（区间命中/方向命中/指令执行命中，累计命中率）；
   - 本次偏差明细（预判vs实际vs根因）；
   - 偏差因子清单变更说明（新增/加权）；
   - 对下次预判的具体修正建议（如"美债30Y新高时偏空概率直接≥50%"）。
6. 纪律：复盘只改"因子清单"与"下次预判权重"，不追责、不改历史；命中率连续3周≥70%的因子标记"稳定"，连续2次被证伪的因子标记"待证伪"。
7. 产出HTML报告《预判复盘_YYYYMMDD.html》，浅色主题、红涨绿跌，含命中率折线与偏差归因表。
```

## 十、提示词G：每周复盘·自我纠偏（每周五收盘后执行，与D/F同周，优先级最高）

> 目的：D是"低吸区间校准"、F是"预判vs实际命中率+因子沉淀"，G是更高一层的**元认知纠偏**——诊断"分析者本身"的系统性缺陷（方向性偏差/概率偏差/遗漏偏差/情绪偏差/框架偏差），输出下周分析框架的修正处方。**F修具体因子，G修分析框架本身。**
> 铁律：复盘对象是"分析框架"不是"行情"——若本周框架判断没错但行情本身极端（黑天鹅），不算偏差，不强行纠偏（避免过度拟合）；纠偏处方必须具体到可执行（禁止空话）。

```
【角色】你是我的A股投资分析助手。我的持仓与规则见公共上下文（《长期观察池_55标的_20260804.md》《买入.md》），请先读取。

【本时段任务·每周复盘自我纠偏】
1. 收集本周全部分析产物：每日开盘/午盘/收盘研判HTML、工作日志、《预判复盘》命中率（若有）。
2. 周度命中率汇总：方向命中率 / 指数区间命中率 / 持仓指令执行命中率（口径与提示词F累计一致，附本周vs历史累计对比）。
3. 系统性偏差扫描（5项诊断，每项输出"症状→证据→处方"）：
   a. **方向性偏差**：本周预判是否系统性偏乐观或偏保守？（如连续多日高估开盘价、低估跌幅；对照因子①美债共振是否每次都事后才给足概率）
   b. **概率分布偏差**：极端情景（偏空/偏多）概率是否总给30%以下？命中是否过度集中在基准情景（=逃避判断、和稀泥）？基准情景是否恒为50%？
   c. **遗漏偏差**：是否有反复被忽略的信号类别？（对照偏差因子清单的命中记录：韩股转向/美债长端/量能结构/事件日历等，哪些因子"事后才发现、事前没想到"）
   d. **情绪偏差**：浮亏时是否倾向"找理由持有"、浮盈时是否"提前兑现"？本周实际操作与预判指令的背离点逐一列出（执行偏差归这里，不是归F）。

   - 概率分布规则修正（例：极端情景概率下限25%、基准情景上限60%；命中因子≥2时基准≤40%）；
   - 新增强制检查项（例：开盘前必查KOSPI盘中方向；美债30Y>5.3%时偏空≥50%）；
   - 偏差因子清单变更（新增/加权/标记待证伪）；
   - 下周"自我提醒"≤3条（一句话一条，具体可执行）。
5. 产出HTML报告《每周复盘_YYYYMMDD.html》，浅色主题、红涨绿跌，含：周度命中率表、5项偏差诊断表、纠偏处方清单、因子清单变更。
6. 同步更新：《每日操作提示词.md》中受影响的纪律表述（概率规则/检查项）与版本记录；MEMORY.md"预判-复盘闭环"节。
```
