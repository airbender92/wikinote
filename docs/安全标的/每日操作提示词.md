# 每日操作分析提示词包（2026-08-06 版）

> 用途：把"个人持仓 + 55只长期观察池 + 低吸区间校验v2 + 外围变量"的完整分析流程固化为提示词，分**早晨开盘前 / 中午午盘前 / 晚间美股**三个时段执行。
> 数据基准：《长期观察池_55标的_20260804.md》《买入.md（区间校验v2）》《低吸区间全面校验_20260806》。

---

## 一、使用说明

1. 每天 3 个时段，把下方【公共上下文】+ 对应时段的【提示词】一起发给 AI（或让 AI 先读取工作区文件）。
2. 输出统一要求：**结论先行（TL;DR）**、A股红涨绿跌配色、所有建议落到"观望 / 减仓 / 清仓 / 加仓"四选一 + 具体价位。
3. 数据一律用最新收盘/实时行情；外围消息须注明来源与北京时间；口径冲突时（如单季现金流 vs 年报）显式标注报告期。
4. 报告落盘为 HTML（浅色主题），文件名带日期，如 `开盘研判_YYYYMMDD.html` / `午盘研判_YYYYMMDD.html` / `收盘与美股研判_YYYYMMDD.html`，与既往 `今日收盘分析_20260806.html` 等保持同风格。
5. 文末固定免责声明：仅供研究参考，不构成投资建议，投资有风险。

- 结论倾向：**非农等重大事件前保留30%~35%现金**；周五尾盘不加仓、只减不追。

### 2. 分析资产与规则

- **55只观察池**：51只长期观察 + 4只降级观察（中兴通讯/牧原股份/中国建筑/汇川技术，等信号）；**5只已排除勿碰**（三安光电/五粮液/中国西电/紫光股份/兴业证券）。
- **低吸区间校验v2规则**（周末/区间更新时校验52周分位）：
  - 52周分位 <70% 才算低吸区；>85% 列"高位勿追"；70~85% 中高位下修区间；
  - 距52周高点 <5% = 情绪高位，不接第一波；>30% = 深跌区，须区分"错杀"与"逻辑破坏"；
  - PE中位数以上 + 位置>70% 双过滤移除；
  - 涨出区间的强势股：区间上修后"等回踩"，严禁追高。
- **现金流偏好**：低吸标的须经营现金流为正（2025年报口径54/55为正，仅广发证券为负）；单季为负≠全年为负（回款集中Q4），默认给年报/TTM口径。
- 优先参考《买入.md》最新版区间；行情代码格式：沪 sh600519、深 sz000001、创业 sz300750、科创 sh688981。

### 3. 分析框架与纪律

- **数据源**：腾讯行情接口（qt.gtimg.cn，批量20只/批，GBK解码）、westock-data、联网搜索（财联社/中新经纬/证券时报/上证报/新浪财经）。
- **A股归因框架**：指数与量能（缩量=虚涨信号）、板块结构（谁拉指数谁在跌）、涨跌家数与涨停/跌停、资金轮动方向。
- **外围框架**：隔夜美股（三大指数+费半+英伟达/AMD/谷歌/存储链/SpaceX）、日韩及亚太、美联储官员表态与加息概率、非农/CPI等数据日历（标注北京时间）、中东与油价、黄金、国内政策（财税/产业）。
- **必须给"大家没想到的点"**：市场盲区（时差补跌、预期差陷阱、政策滞后定价、两套定价体系等）单列一节。
- **55只分层方法**：补跌风险 / 惯性冲高（勿追） / 高位分歧（兑现） / 超跌反抽 / 双杀压制（等企稳） / 防御持有。
- **明日预判**：三情景（基准/偏空/偏多）+ 概率排序 + 各情景操作含义。
- **输出格式**：TL;DR（5~6条）→ 分节详述 → 持仓逐只决策 → 低吸挂单清单 → 风险提示。

## 三、提示词A：早晨开盘前（建议 8:45~9:10 执行）

```
【角色】你是我的A股投资分析助手。
   我持有：
     工业富联2手@51.066、
     中兴通讯3手@33.309、
     云南白药4手@50.685、
     歌尔股份1手@4.045、
     招商证券8手@19.256。
     （亨通光电已于8/7上午58.30清仓）
     
     我的长期观察池与低吸规则见工作区《长期观察池_55标的_20260804.md》《买入.md（区间校验v2）》，请先读取这两份文件再分析。

【本时段任务·开盘前研判】
1. 联网获取并汇总（标注北京时间）：
   - 隔夜美股三大指数/费半收盘，关键个股：英伟达、AMD、谷歌Alphabet、SpaceX、闪迪/西部数据及存储链；
   - 今早日韩及亚太股市早盘表现；
   - 今日重要日程：非农/CPI/美联储官员讲话/财报/解禁/国内政策，按影响排序；
   - A股盘前消息面（政策/产业/公司公告，注明来源）。
2. 输出（结论先行）：
   - 今日大盘开盘预期：高开/低开/平开 + 区间（如上证3880~3930）；
   - 今日核心变量与风险事件排序（含"大家没想到的点"）；
   - 持仓6只逐只操作计划：减/持/加 + 触发价位 + 防守位；
   - 低吸挂单清单：具体价位（依据买入.md区间校验v2，注明"等回踩/等不再创新低"等触发条件）；
   - 盘中必须盯盘的信号位（指数关口、个股关键价、量能阈值）。
3. 纪律：周五/数据公布日控制仓位；不追高；留30%~35%现金。
4. 产出HTML报告《开盘研判_YYYYMMDD.html》，浅色主题、红涨绿跌、含1张指数/关键价位图。
```

```
【角色】你是我的A股投资分析助手。我的持仓与观察池规则同开盘前（见《长期观察池_55标的_20260804.md》《买入.md》），请先读取。

【本时段任务·午盘研判】
1. 获取上午行情（实时接口/联网）：
   - 大盘：上证/深成/创业板/科创50、半日量能（与昨日同期对比）、涨跌家数、涨停/跌停；
   - 持仓6只：午盘价、涨跌幅、分时强弱；
   - 上午板块轮动主线与消息面变化（与开盘预判对照）。
2. 输出（结论先行）：
   - 上午复盘：是否验证开盘预判？哪里超预期/低于预期？
   - 持仓逐只午后指令：减仓触发了吗？低吸挂单到价了吗？到价是否执行（如宁德355~360等"等不再创新低"条件是否满足）？

3. 纪律：只减不追、低吸只等区间内触发、不因踏空追高；数据公布前不加仓。
4. 产出HTML报告《午盘研判_YYYYMMDD.html》，红涨绿跌，含持仓午盘涨跌图。
```

## 五、提示词C：晚间美股（建议收盘后 / 21:30 后执行）

```
【角色】你是我的A股投资分析助手。我的持仓与观察池规则同前（见《长期观察池_55标的_20260804.md》《买入.md》），请先读取。

【本时段任务·收盘复盘 + 美股研判 + 明日策略】
1. 获取：
   - A股收盘：三大指数/科创50、成交额与环比、涨跌家数、涨停/跌停、板块涨跌结构（谁拉指数谁在跌）；
   - 观察池55只收盘表现（批量行情，标注涨跌幅与是否进出低吸区间）；
   - 美股：美东当天盘中/收盘（三大指数+费半+关键个股），今晚至明晨将公布的数据（非农/CPI/美联储讲话），日韩预期；
   - 重要外部变量：美联储加息概率、中东/油价、黄金、国内政策新公告。
2. 输出（结论先行）：
   - 今日复盘：结构诊断（资金轮动方向）、55只分层（补跌/惯性冲高/超跌反抽/双杀压制/防御持有）；
   - 明日预判：三情景（基准/偏空/偏多）+ 概率排序 + 各情景下的操作含义；
   - 持仓明日操作计划：逐只"观望/减仓/清仓/加仓" + 具体价位 + 防守位；
   - 低吸清单更新：明日可挂单价位与触发条件；
   - 单独一节"大家没想到的点"（市场盲区，如时差补跌、预期差、政策滞后定价等）；
   - 周五/数据日前夜：明确给出仓位建议（留多少现金）。
3. 纪律：非农等重大数据在A股收盘后公布时，周五盘中是"盲猜日"，真正变盘在下周一——周五是卖的时间窗口不是买的。
4. 产出HTML报告《收盘与美股研判_YYYYMMDD.html》，红涨绿跌，含：全球指数对比图、55只涨跌条形图、持仓浮盈亏图。
```

```
按当前北京时间自动判断并执行：
- 8:45~9:10 → 执行【开盘前研判】：隔夜美股/日韩/今日日程/盘前消息 → 开盘预期+持仓操作计划+低吸挂单+盯盘信号；
- 11:00~11:30 → 执行【午盘研判】：上午复盘+持仓午后指令+低吸触发检查；

若当前时间不在上述窗口，则输出最近一个时段应执行的任务与要点，供我补跑。
全部输出遵循：结论先行、红涨绿跌、"观望/减仓/清仓/加仓"四选一+具体价位、外围消息标注北京时间与来源、文末免责声明。
```
