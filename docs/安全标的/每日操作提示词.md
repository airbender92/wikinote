## 一、使用说明

1. 每天 3 个日间时段 + 每周 1 次区间检查 + 每月/狂热事件 1 次金融危机研判，把下方【公共上下文】+ 对应时段的【提示词】一起发给 AI（或让 AI 先读取工作区文件）。
2. 输出统一要求：**结论先行（TL;DR）**、A股红涨绿跌配色、所有建议落到"观望 / 减仓 / 清仓 / 加仓"四选一 + 具体价位。
3. 数据一律用最新收盘/实时行情；外围消息须注明来源与北京时间；口径冲突时（如单季现金流 vs 年报）显式标注报告期。
4. 报告落盘为 HTML（浅色主题），文件名带日期，如 `开盘研判_YYYYMMDD.html` / `午盘研判_YYYYMMDD.html` / `收盘与美股研判_YYYYMMDD.html`，与既往 `今日收盘分析_20260806.html` 等保持同风格。
5. 文末固定免责声明：仅供研究参考，不构成投资建议，投资有风险。

  - ③ **HY信用利差破3%**（现2.80%，周内走阔12bp中）；

- **必须给"大家没想到的点"**：市场盲区（时差补跌、预期差陷阱、政策滞后定价、两套定价体系等）单列一节。

- **明日预判**：三情景（基准/偏空/偏多）+ 概率排序 + 各情景操作含义。
- **输出格式**：TL;DR（5~6条）→ 分节详述 → 持仓逐只决策 → 低吸挂单清单 → 风险提示。

## 六、提示词D：每周低吸区间同步检查（建议周五收盘后 / 周六周日执行）

> 目的：低吸区间是"活的"。原区间以 8/4 价格锚定，若不每周重算，强势股会涨出区间（机械套旧区间=追高）、弱势股会跌进错杀区（漏掉机会）。8/6 已确立"每周末校验52周分位"纪律，本提示词把它固化为可执行流程。

```
【角色】你是我的A股投资分析助手。数据基准见《长期观察池_55标的_20260804.md》《买入.md（区间校验v2）》《低吸区间全面校验_20260806.html》，请先读取这3份文件。

【本时段任务·每周低吸区间同步检查】
1. 取数（55只逐只，批量行情接口一次≤20只）：
   - 现价、52周最高/最低、PE(TTM)、PB、股息率、距高点%、区间涨跌幅；
   - 标注数据时点（周五收盘价或当周最新）。
2. 计算与过滤（每只必须过3关）：
   - ① 52周分位 = (现价−52周低)/(52周高−52周低)；<70% 低吸区、70~85% 中高位下修、>85% 高位勿追；
   - ② 距52周高点：<5% 情绪高位不接第一波；>30% 深跌区须区分"错杀"vs"逻辑破坏"；
   - ③ 估值交叉：PE处历史中位以上 + 分位>70% 双过滤直接移除。
3. 区间更新动作（对照《买入.md》逐只给结论）：
   - 涨出区间（现价>上沿≥5%）→ 区间上修，标"等回踩"；
   - 位置过高（分位>70%/距高点<6%）→ 区间下修或降级"等回踩"；
   - 跌入错杀区（低分位+估值合理+逻辑未破坏）→ 维持或新纳入；
   - 维持不变 → 标"维持"；风险变化（财报/公告/舆情）→ 单独标注。
4. 输出：
   - 结论先行：本周新增可低吸 / 失效标的 / 区间上修与下修清单（各列具体价位）；
   - 全量明细表（55只）：现价/分位/距高点/PE/原区间/新区间/结论；
   - 52周分位分布图（红=高位、绿=低吸区，标注85%/70%两条线）；
   - 已进低吸区间、接近区间、勿追三个清单；
   - 与上次校验（8/6 v2）的差异点：哪些标的结论变了、为什么。
5. 落盘：
   - 更新《买入.md》区间（覆盖旧区间，标注修订日期）；
   - 产出《低吸区间全面校验_YYYYMMDD.html》，浅色主题、红涨绿跌；
   - 若持仓新增标的进/出区间，同步提示更新《每日操作提示词.md》持仓表的关键操作位。
6. 纪律：区间更新只做"记录与提示"，不代做交易决定；重大区间变化（如某持仓标的分位从30%跳到80%）须在下次开盘研判中重点提示。
```

## 七、提示词E：金融危机研判（"狂热监测"，每月 / 狂热事件触发）

> 目的：**金融危机很少按部就班地"慢慢来"——它往往在市场最狂热、所有人最乐观的时候突然爆发**（2008次贷、2015杠杆牛、2021抱团股均是如此）。本提示词把**狂热度**作为第一监测对象（杠杆、成交、新基金、开户数、全民情绪），辅以信用/流动性信号，形成三档触发（绿灯/黄灯/红灯），**在黄灯（狂热期）就提前降杠杆，而不是等红灯（危机显性化）再反应**——宁可卖早，不可卖晚。
> 触发时机：① 每月固定 1 次（如每月第一个周末）；② 出现狂热事件后 24 小时内——两市成交连续天量（>3万亿）、融资余额创新高、新基金爆款/秒光、单日开户数暴增、指数创新高但股吧/雪球热度沸腾、媒体开始吹"牛市起点"等，任一发生即触发。

