- **机制**：《每日操作提示词.md》新增公共上下文4（偏差因子清单8条）+ 提示词F（预判-复盘回顾，每次报告后/每周五）+ **提示词G（每周复盘·自我纠偏，每周五收盘后执行、优先级最高）**。每日三时段提示词强制对照因子清单+写"预期差"三分支。分工：D校准低吸区间、F沉淀具体因子、**G诊断分析者本身的系统性偏差（方向性/概率分布/遗漏/情绪/框架5项诊断）→输出下周纠偏处方（概率分布规则+强制检查项+自我提醒≤3条）**，修"分析框架"而非"行情"。
- **8条偏差因子**（详见提示词.md，核心案例）：①美债长端创新高共振（8/19暴跌-2.4%预判仅-0.8%）；②KOSPI/海力士日内转向（8/18存储高开低走）；③半日量能推算全天失真（8/26午盘推2.2~2.4万亿实际1.81万亿）；④破位次日放量收回=空头陷阱（招商8/25破17.7→8/26+5.21%）；⑤事件日历双情景（歌尔中报前+6.27%抢筹/恒瑞中报不派息-6%见光死）；⑥预期差定价（PCE超预期美股回落）；⑦官方干预=修复窗口（8/20美购债扩容A股修复）；⑧杠杆资金退潮（8/26韩杠杆爆仓外溢）；**⑨财报指引超预期倍数（8/30新增：英伟达2028指引+70% vs 预期45%→纳指+1.57%但A股8/28低开）**；**⑩利好前置兑现（8/30新增：隔夜大涨+A股前日已涨≥1%→次日高开≤30%，8/28预判高开0.3~0.8%实际低开-0.16%案例）**。
- **铁律**：因子只增不删（除非证伪）；命中因子≥2时必须调低基准情景概率；命中率逐周统计，连续3周≥70%标记"稳定"。
- **2026-08-30 每周复盘G（第1期）**：周方向命中~~70%/区间~~80%/指令~85%。**5项诊断主病灶=方向性偏差（8/26~8/28连续3日高估开盘，对"利好前置兑现"压制力度低估）+概率分布偏差（基准情景恒为震荡=和稀泥，极端情景从未≥40%）**；次病灶=遗漏偏差（因子事后归因>事前对照）、情绪偏差（浮盈提前兑现+浮亏找理由持有并存，8/28用户加仓恒瑞=执行偏差）、框架偏差（三情景+警报线框架未覆盖风格切换）。**纠偏处方已写入提示词A纪律区**：基准≤50%（命中因子≥2时≤40%）+极端情景下限25%+开盘前强制4查（KOSPI/事件落地日/资金风格/警报线→偏空≥50%）+自我提醒3条。因子②连续3次命中（8/18/8/26/8/28）→9/4再命中标"稳定"。
