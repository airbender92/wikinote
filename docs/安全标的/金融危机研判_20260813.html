六、大家没想到的8个点（狂热期盲区）

1. 放量2.55万亿 + 4309家下跌——这不是进攻，是出货。8/13成交较前日放量3985亿，指数却冲高回落收绿，超4300只个股下跌、62涨停/4跌停。量在放大、价在回落、面在收窄（赚钱效应恶化）——教科书式的"高位出货量"特征。如果下周继续"放量滞涨/放量下跌"，基本可以确认资金在借热点轮动出逃。
2. 存储警报线"向上修复"是双刃剑——SK海力士+5.92%当天，A股深科技-1.98%。8/13日韩存储大涨、KOSPI重回技术牛市，警报线④解除"补跌"风险——但A股存储链当天却逆势下跌（深科技-1.98%/长电-0.46%），说明A股存储资金在日韩大涨时反而借机兑现。时差背离从"反向"变为"同向但A股滞涨"，一旦日韩见顶回落，A股存储仍会补跌——方向标没变，只是节奏换了。
3. 债市慢变量继续累积：30Y美债5.256%再创2007年前新高。股市定价"CPI温和→暂缓加息"，债市定价"通胀黏性+赤字扩张"——两个市场总有一个是错的，且债市体量更大、纠错更慢但更猛。HY利差2.8%贴着3%警戒线，这是"引信已装上"的慢变量，8/8我就提示过，现在它没有解除，只是没引爆。
4. 两融新开户环比-22% + 科创板两融回落——增量在退潮，存量在抱团。7月两融新开户13.94万户同比虽+12.78%但环比大降22%，科创板两融8/11环比-15.5亿。散户增量资金开始离场，而热点却缩圈到医药/电力/银行——这是"存量资金防御化抱团"，历史上常见于行情后段而非起点。
