1. 锂电池消费税恢复征收——7/16的公告，今天才发酵，市场定价严重滞后。财政部/海关总署/税务总局公告（2026年第20号，7/16发文）：9/1起锂离子蓄电池等按2%征收消费税、2027/9/1升至4%；钠电/固态/燃料电池免税至2028年底。宁德今天-4.24%被归因为"花旗锂价+46%"，但消费税是更确定的政策利空（"油电同权"第三击：购置税减半→车船税免征取消→电池消费税恢复）。实际利润影响有限（9月才实施且减半），但估值与情绪压制是持续的——宁德355~360首仓区可能被"锂价+消费税"双杀砸到，挂单从"等回调"升级为"可能被迫接"，务必等不再创新低。
2. 日韩暴跌 vs A股存储逆势上涨 = 时差补跌陷阱。SK海力士-10.37%、三星-6.30%，A股深科技+3.13%、长电涨停——市场今天的解读是"A股存储独立强势"，但历史上A股半导体与日韩的背离几乎从不以"A股赢"结束，只以"补跌"结束。明天存储链（深科技/长电/中芯）是最明确的减仓对象。
3. ADP爆冷(4.4万) vs 非农预期(8.3万) 的预期差陷阱。市场容易看到ADP走弱就转鸽，但经济学家预期官方非农8.3万、高于6月的5.7万——若实际非农接近预期，反而是"强数据"（ADP和非农经常背离），9月加息概率（仍54.9%过半）将反弹。周五是"数据前别赌方向"，而不是"已经知道方向"。
4. 动力煤（内盘）≠ 布油（外盘），两套定价体系。伊朗-阿曼协议若周末敲定→国际油价跌，但国内煤炭是独立逻辑：CCI指数上调+高温用电+供给收缩（-1.9%）。别把"油价跌利空煤炭"套到A股；反过来，周五石油链（海油/石化）若因协议再跌，与煤炭无对冲关系——两者资金逻辑不同。
5. SpaceX史上最大解禁（1000亿美元）+ 谷歌AI人事地震，是美股科技的两个"尾部雷"。SpaceX 8/6解禁9.1亿股仍在消化；Alphabet因Jeff Dean离职创业、Hassabis交权一日蒸发1800亿美元——AI巨头的人事/解禁风险会随时传导到A股算力/光通信情绪（亨通/富联/中兴的映射源头）。
6. 今天8/6是本周"出金日"。T+1取现下，今天卖出的资金才能周五取现，所以今天是本周资金面最紧的一天；明天（周五）出金压力反而缓解——但周五A股收盘后非农才公布，所以"出金日已过"不代表能安心持股过周末，风险在周末不在周五。
7. 黄金破4300是"6月18日以来首次"，短线超买。隔夜伦敦金+4%、银+5%后亚洲早盘直接破4300——两天内贵金属涨幅过大，明日黄金股（紫金等）惯性冲高后回落风险高于继续上攻，追高黄金=接盘。
