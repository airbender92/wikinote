核心结论（TL;DR）

  • 建仓铁律：三批法 + 首仓最小。每只票的建仓资金=单票仓位上限（防御15%≈1.5万 / 成长10%≈1万 / 试探5%≈0.5万），分三批：首批25%~30%（进区间试仓）→ 二批30%~35%（区间中段）→ 三批35%~45%（下沿/错杀区或右侧确认）。永不一笔买满。
  • 首仓手数 = 计划仓位 × 25% ÷ 股价 ÷ 100，向下取整。但你的资金体量下，股价决定一切：<10元股可买6~8手精确分批；10~30元股每批1手；40~90元股首仓被迫=1手（比例被动抬到33%~50%）；>100元股（茅台1250/北方华创615/汾酒111/片仔癀126/药明123）当前资金买不起1手或1手即严重超配 → 一律只观察、不建仓。
  • 做T先算账：往返成本 = 佣金（每边最低5元）+ 印花税0.05% + 过户费。小仓低价做T是"给券商送钱"——中车1手往返成本率1.78%，白做；中兴1手0.35%，要振幅>1%才有肉；招商6手仅0.14%，最适合做T。做T最低门槛：预计价差收益≥往返成本的3倍，否则不做。
  • 做T铁律：只做有底仓的熟票、T仓≤底仓1/3~1/2、单日≤1次、当日必须闭环（不留T仓过夜）、方向错了1%即认错。你的持仓里：招商6手=首选（倒T兼降杠杆）、中兴2手=可正T、中车/白药/南瑞/歌尔=不做。
  • 首仓1手≠没操作空间——想做T的票按"3手起步"规划：首仓25%是"试错上车"比例，不是"做T底仓"。做T最低2手（1手T仓+留1手底仓），推荐≥3手。按你的资金：≤20元的票够凑4手+（歌尔/南瑞/中车=做T主力）、40元+的票凑不满3手别硬T；当前持仓里招商6手=唯一常态T标的、中兴2手=顺减仓做正T，其余不做T（详见第五章）。
  • 8月布防期降档执行：新开仓只允许完成首批（≤计划的1/3），二批三批等8/12 CPI落地、四条警报线（日债3%/日元178~180/HY利差3%/存储背离）未触发再推进；黄灯触发→停新开仓、做T只做倒T；红灯→全停。现金始终≥40%（布防期目标45%）。
测算基准：总资产≈98,350元（8/10尾盘口径）；若资金变化，用文内公式重算，勿机械套用手数。仅供研究参考，不构成投资建议。

1. 单票仓位上限（先定上限，再谈买多少）

标的类型单票仓位上限按总资产≈10万折算适用对象
防御型≤15%≤1.5万元白药/中车/南瑞/长电/神华/建行/华能/川投/国投等低波动高股息

为什么首仓最小：进区间≠见底。区间上沿附近买的首批，如果直接买满，跌到区间下沿就没了补仓子弹，成本全在上沿。首仓只解决"上不上车"的问题，剩下的子弹留给更低的价。确定性越差（试探型/高位回踩），首批比例越低（取20%）。

2. 首仓手数公式

首仓手数 = 取整向下[ 单票计划仓位 × 首批比例(25%) ÷ 股价 ÷ 100 ]　｜　若结果 = 0 手 → 该股对你"一手门槛过高"，见下文分档表
最关键的约束——"一手门槛"：1手=100股。若 1手金额（股价×100）＞ 单票计划仓位 × 首批比例，你的"首批1/3"根本买不出来，实际首仓被迫=1手（比例被动抬高）。若 1手金额 ＞ 单票计划仓位甚至＞总资产的10%，则该股在当前资金体量下不适合建仓。这不是技巧问题，是资金量级的硬约束。

2. 两种T模式（T+1制度下）

模式操作适用风险
正T（先买后卖）低开/急跌到支撑位先买入T仓，当日反弹后卖出等量底仓 → 底仓数量不变、成本下降底仓被套想降本；看好中期但短期震荡（如中兴）买入后不反弹 → T仓变加仓（必须当日止损闭环）
倒T（先卖后买）高开/急拉到压力位先卖出底仓，当日回落接回等量 → 落袋差价、成本下降仓位过重想减（如招商6手）；高位高波动期卖出后不回落 → 踏空（必须当日追回或认错）

3. 做T信号（分时+量能）

  • 买点（正T）：低开急跌至低吸区间下沿 + 分时缩量企稳（不再创新低）→ 挂单接；大盘恐慌急杀后V反，个股跟T。
  • 卖点（倒T）：高开冲高至压力位/前高 + 分时放量滞涨（量在价不涨）→ 挂单抛；或指数冲关乏力个股跟卖。
  • 不做T的信号：缩量阴跌（无波动=白做）、单边下跌趋势（正T越T越套）、单边上涨趋势（倒T必然T飞）、事件日（CPI/非农/财报/解禁前一日停手——8/12美国CPI前尤其注意）。
  • 工具：分时均价线（股价站上/跌破均价线为强弱切换点）、开盘15分钟高低点（日内波动框）、挂单不用市价（防滑点）。

4. 做T铁律（违反任何一条=停止做T）

① T仓≤底仓的1/3~1/2（如招商6手，一次只T 2手以内；中兴2手，一次只T 1手）；
② 单日最多1次，做完收手，不追加；
③ 当日必须闭环：正T当天卖出等量、倒T当天买回等量——绝不把T仓留过夜（留过夜=性质变成加减仓，纪律就破了）；
④ 止损无例外：方向错了1%（或跌穿设定支撑）立即认错平仓，T仓不拖、不摊；
⑤ 只做有底仓的熟票，不T新标的；
⑥ 事件日/警报线触发日/数据公布前一天不做T。

失败预案买入后跌破33.3（止损1%）且午后不收回33.5收盘前卖T仓@33.2认错亏约47元，绝不把T仓留过夜变成3手持仓——T仓过夜=变相加仓，纪律即破
两个案例的共同点：① 买卖点都在"支撑/压力 + 量能确认"处，不是拍脑袋；② 全程挂单、到价成交、不追价；③ 都建立在"本来就想买/想卖"的价位附近（招商18.5本就是减仓计划、中兴33.5本就是防守位）——做T是顺手降本，不是凭空多交易；④ 失败预案比成功更重要，正T失败=认错卖出、倒T失败=接受减仓，都有台阶下。
做T的本质：赚的是波动，不是赚方向。它的唯一目的是"降低持仓成本"，不是"预测涨跌"。当你发现自己开始赌"明天会涨还是会跌"时，那已经不是做T了，是短线投机——在8月布防期尤其危险。

五、首仓1手没操作空间？——想做T就按"3手起步"规划

先正面回答你的疑问：对，首仓只有1手时确实没有做T空间。做T最低需要2手（1手T仓 + 至少留1手底仓），推荐≥3手（2手底仓 + 1手T仓）。但关键要分清两个概念：首仓25%是"试错上车"用的，不是为做T准备的——它的职责是"用最小的钱确认这只票能不能拿"。所以正确的问法不是"首仓买几手"，而是先问：这只票，我打算做T吗？
打算建仓设计典型标的（你的池子）
不T（纯防御/吃股息）维持三批法，首仓1手完全OK——分批只是为了降低买入均价，不需要T空间白药/长电/神华/建行/中车（低波动，本就T不动）
想T按"底仓≥3手"规划：单票计划仓位必须≥3手金额；首仓直接买足2手（1手试错+1手T仓基础），二批补到第3手，之后"第三批"不再死等更低价，而是作为T仓弹药滚动高抛低吸歌尔/南瑞/深科技等20~33元票；或现有大仓票（招商6手）
仓位凑不满3手该股自动失去"做T资格"，只做波段/持有——硬T=每笔都在喂手续费万华（2手）/比亚迪（1手）/40元+的票

按你的资金（总资产≈10万）快速判定"够不够3手"

单票上限股价≤多少才够3手实际含义
防御型 1.5万股价 ≤ 50元（15,000÷3÷100）白药50→刚好3手（可T下限）；神华40.8→3手✓；平安49.5→3手✓；万华69→2手✗
成长型 1.0万股价 ≤ 33元（10,000÷3÷100）南瑞23→4手✓；歌尔21.6→4手✓；深科技34.8→2手✗；立讯52.5→1手✗
试探型 0.5万股价 ≤ 16元试探仓本就不该T，是"等信号"的观察位
落地结论：你的资金体量下，做T的主力 = 20元以下的低价活跃票 + 现有大仓票（招商6手）。歌尔若回补到3~4手（约6,500~8,700元）就是理想T标的；白药/中车/南瑞即使手数够也不T（波动太小）；40元以上的票（平安/万华/比亚迪）凑不满3手，直接告别日内T。"没有T空间"不是坏事——它自动帮你淘汰了不该做T的票，省下的手续费就是收益。

六、与8月布防 + 危机监测的衔接（降档执行）

情景建仓动作做T动作

红灯（信贷骤停/全球-10%级/上证破3800/个股集体破防守位）全部停止；只留白药/中车/南瑞/歌尔防御底仓，等右侧企稳再谈建仓全停，防守位执行不加犹豫
一句话：8月是布防月——建仓只做"首批试仓"，做T只为"降本+降杠杆"，现金40~45%是总目标。任何一次买入（无论建仓还是正T）都会占用现金，先问自己：买完之后现金还在45%吗？不在→不买。

七、"大家没想到的点"

① 一手门槛是最大隐形约束：10万资金下，100元+的股票（茅台/北方华创/汾酒/片仔癀/药明）根本无法精细分批，甚至买不起1手。很多人研究"茅台低吸区间"，却忽略了自己连1手都买不起——先算单手金额，再谈建仓方案。
② 最低5元佣金 = 低价小仓做T的死穴：1手中车做T往返成本率1.78%，意味着你得赌它单日波动5.3%才刚回本——这不是做T，是送钱。散户做T失败的第一个原因不是技术，是没算手续费。
③ 高价股"首仓最小"纪律自动失效：公式想让你首仓买1/3，但白药1手=5,000元=计划的34%，比亚迪1手=计划86%——股价越高，你越买不出"小仓试错"，第一笔就是重仓。所以10万资金正确的打法：低价股做精细分批，高价股要么放弃要么只买1手当底仓。
④ T仓过夜 = 变相加仓：做T的铁律"当日闭环"反过来说就是：一旦T仓过了夜，你的"做T"已经变质成一次没有计划的加仓/减仓——那才是套牢和踏空真正的来源。留过夜的T仓，等于给自己留了一个仓位炸弹。
⑤ 分批建仓≠越跌越买：三批法的前提是"区间下沿=错杀不是逻辑破坏"。如果跌下去的原因是基本面变坏（如中兴利润连降、双汇延期披露），跌破下沿3%不收就是纪律，不是胆小——低吸区间校验v2的"错杀vs逻辑破坏"判断要先于一切加仓。
⑥ 8月的特殊规则优先级最高：所有建仓/做T建议，都要先过"布防期"这一关：警报线触发→降档；现金低于45%→不动。宁可少赚，不可重仓进入Q4窗口（2026Q4~2027H1日本高危窗口）。
