# 时间复杂度

## 一、定义

**时间复杂度**：衡量算法运行时间随输入数据规模 `n` 增长的**增长趋势**，只关注最高阶项，忽略常数、低阶项，记作 **$\(O()\)$（大O表示法）**。

> 不是代码实际运行秒数，是渐进复杂度。

## 二、常见复杂度排序（从快到慢）

$$
\(O(1)\) < O(\log n) < \(O(n)\) < O(n\log n) < O(n^2) < O(n^3) < O(2^n) < \(O(n!)\)
$$

### 1. $\(O(1)\)$ 常数复杂度

执行次数固定，和输入`n`无关

```python
a = arr[0]
```

例子：数组随机访问、四则运算

### 2. $O(\log n)$ 对数复杂度

每次循环规模缩小一半

```python
while n > 1:
    n = n // 2
```

典型：二分查找

### 3. $\(O(n)\)$ 线性复杂度

循环遍历一遍数据

```python
for x in arr:
    print(x)
```

典型：单循环遍历数组

### 4. $O(n\log n)$ 线性对数

外层n次，内层logn
典型：快速排序、归并排序、堆排序

### 5. $O(n^2)$ 平方复杂度

两层嵌套循环

```python
for i in range(n):
    for j in range(n):
        pass
```

典型：冒泡排序、双重循环暴力枚举

### 6. $O(2^n)$ 指数复杂度

递归每次分出两个分支
典型：暴力递归求斐波那契

### 7. $\(O(n!)\)$ 阶乘复杂度

全排列暴力枚举，极慢

## 三、计算规则（大O化简）

1. 只保留**最高次项**
   $O(n^2+3n+5) \Rightarrow O(n^2)$
2. **去掉常数系数**
   $O(5n) \Rightarrow \(O(n)\)$
3. 多个独立循环相加：取最大
   ```
   for() # \(O(n)\)
   for() # O(n²)
   ```
   总复杂度 $O(n^2)$
4. 嵌套循环相乘
   一层\(O(n)\)，一层\(O(\log n)\) → $O(n\log n)$

## 四、最好/最坏/平均时间复杂度

- **最坏复杂度**：输入最差情况（日常分析默认用这个）
- **最好复杂度**：运气最好的输入，参考意义小
- **平均复杂度**：所有输入概率平均

示例：快速排序
最坏：$O(n^2)$；平均：$O(n\log n)$

## 五、易混补充

- **空间复杂度 $\(O()\)$**：衡量额外开辟内存空间大小，和时间复杂度概念类似。
- 注意：递归算法的递归栈深度会算进空间复杂度。

# $O(\log n)$ 对数时间复杂度

## 1. 核心含义

**每一轮处理，把问题规模缩小一半（或按比例持续缩小）**，循环次数远远小于 n。

> $\log n$ 默认底数是 **2**（算法界约定），$\log_2n$。
> 公式理解：
> $$2^k = n \quad\Rightarrow\quad k=\log_2 n$$
> $k$ 就是循环执行次数。

举个例子：
$\(n=1024\)$
$\log_2 1024 = 10$
只需要循环 10 次，而不是遍历 1024 次。

## 2. 典型代码模板（二分查找）

```python
left = 0
right = n - 1
while left <= right:
    mid = (left + right) // 2
    if arr[mid] == target:
        return mid
    elif arr[mid] < target:
        left = mid + 1
    else:
        right = mid - 1
```

每次把查找区间砍掉一半 → $O(\log n)$

## 3. 为什么复杂度不写底数？

大O表示法只看**增长趋势**：
$\log_2n、\log_{10}n、\ln n$ 之间只差常数倍数，直接简写为 $O(\log n)$。

## 4. 常见易混对比

- $\(O(n)\)$：数据扩大一倍，循环次数扩大一倍
- $O(\log n)$：数据扩大一倍，循环次数**只多1次**

| n     | $\log_2n$ |
| ----- | --------- |
| 8     | 3         |
| 16    | 4         |
| 1024  | 10        |
| 100万 | ≈20       |

## 5. 衍生：$O(n\log n)$

外层循环 n 次，内层每次二分 $\log n$：
快速排序、归并排序，就是 $n \times \log n$。

## 6. 快速判断技巧

看到下面特征，大概率是 $\log n$：
✅ 不断 `n = n // 2`
✅ 二分查找、二叉搜索树查询
✅ 循环变量不是逐次+1，而是区间折半

## 练习题

```python
n = 100
while n > 1:
    n = n // 2
```

时间复杂度：**$O(\log n)$**

# $\(\(\boldsymbol{\(\(\boldsymbol{\(O(1)\)}\)\)}\)\)$ 常数时间复杂度

## 1. 定义

**算法执行次数固定，不随输入规模 $n$ 变化**。
无论 $n$ 多大，操作次数基本不变，所以叫常数复杂度。

> 大O规则：所有常数统一记作 $\(\(\boldsymbol{\(\(\boldsymbol{\(O(1)\)}\)\)}\)\)$
> $O(5)、O(100)、O(3000)$ 全部简化为 $\boldsymbol{\(\(\boldsymbol{\(\(\boldsymbol{\(O(1)\)}\)\)}\)\)}$

## 2. 典型例子

```python
# 1. 数组随机访问
arr = [1,2,3,4]
x = arr[2]

# 2. 简单四则运算
a = 1 + 2 * 3

# 3. 获取链表头结点
head = link_list.head

# 4. if判断、交换两个变量
t = a; a = b; b = t
```

不管数组长度是10还是10000，`arr[2]` 都是一步到位。

## 3. ❌ 容易踩坑的误区

### 误区1：循环次数少就是 \(\(\boldsymbol{\(\(\boldsymbol{\(O(1)\)}\)\)}\)\)

```python
for i in range(5):
    print(i)
```

循环上限固定、和n无关 → **$\(\(\boldsymbol{\(\(\boldsymbol{\(O(1)\)}\)\)}\)\)$**

```python
for i in range(n):
    print(i)
```

循环次数随n变化 → **$\(O(n)\)$**

### 误区2：嵌套循环一定不是\(\(\boldsymbol{\(\(\boldsymbol{\(O(1)\)}\)\)}\)\)

```python
for i in range(10):
    for j in range(10):
        pass
```

两层循环上限固定，和n无关 → 依旧 $\(\(\boldsymbol{\(\(\boldsymbol{\(O(1)\)}\)\)}\)\)$

## 4. 和其他复杂度直观对比

| 复杂度                                               | 特点                     |
| ---------------------------------------------------- | ------------------------ |
| $\(\(\boldsymbol{\(\(\boldsymbol{\(O(1)\)}\)\)}\)\)$ | 数据变大，耗时几乎不变   |
| $O(\log n)$                                          | 数据翻倍，循环只多1次    |
| $\(O(n)\)$                                           | 数据翻倍，耗时差不多翻倍 |

## 5. 常见数据结构操作复杂度（笔试高频）

- 数组：随机访问 → $\boldsymbol{\(\(\boldsymbol{\(\(\boldsymbol{\(O(1)\)}\)\)}\)\)}$
- 链表：访问第k个元素 → $\(O(n)\)$
- 哈希表（HashMap）：查找、插入、删除（理想情况）→ $\boldsymbol{\(\(\boldsymbol{\(\(\boldsymbol{\(O(1)\)}\)\)}\)\)}$

## 一句话口诀

**操作次数跟输入数据量 n 没关系，就是 \(\(\boldsymbol{\(\(\boldsymbol{\(O(1)\)}\)\)}\)\)**
