## 从非官方源（镜像源）安装依赖

当无法访问 npm 官方源时，可以使用镜像源进行安装。

### 方式1：单次安装临时指定镜像源

执行安装命令时增加参数 `--registry`，仅当前命令生效：

```bash
npm install underscore --registry=http://registry.url
```

### 方式2：配置全局默认镜像源

所有 npm 命令统一使用该镜像，永久生效：

```bash
npm config set registry http://registry.url
```

## 配套常用查询/恢复命令（建议一并写入文档）

```bash
# 查看当前生效的源地址
npm config get registry

# 恢复官方默认源
npm config set registry https://registry.npmjs.org
```

## ⚠️ 企业项目重点风险提示（结合你前面关心的 license 合规）

1. **镜像源只是加速中转，不改变包本身**
   镜像只是缓存转发，下载的包文件、开源许可证、代码内容和官方源完全一致；不会因为换镜像就规避开源协议审查。
2. **私有镜像仓库（如Verdaccio、JFrog）额外注意**
   如果是公司内部私有npm仓库，除了配置registry，还可能需要配置鉴权（token、账号密码）；
3. **安全风险**
   不要使用来路不明的公共镜像；优先选用可信镜像（国内常用：npmmirror），防止投毒包。

## 国内标准示例（可直接替换模板里的 registry.url）

```bash
# 单次使用淘宝镜像
npm install underscore --registry https://registry.npmmirror.com

# 全局设置淘宝镜像
npm config set registry https://registry.npmmirror.com
```
