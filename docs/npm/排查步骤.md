找到问题了！在 `.npmrc` 配置中：

```
@hatech:registry = " http://10.1.110.166:4873/ "
```

`@hatech` 这个 scope 的 registry 被设置成了错误的地址 `10.1.110.166`，而正确的应该是 `10.27.3.166`。

## 解决方案：

修改 `C:\Users\yambo\.npmrc` 文件，将 `@hatech:registry` 改为正确的地址：

### 方法1：使用命令行修改
```bash
npm config set @hatech:registry http://10.27.3.166:4873/
```

### 方法2：直接编辑 .npmrc 文件
打开文件 `C:\Users\yambo\.npmrc`，找到这一行：
```
@hatech:registry = " http://10.1.110.166:4873/ "
```

改为：
```
@hatech:registry = " http://10.27.3.166:4873/ "
```

### 方法3：删除错误的配置（让 @hatech 使用全局 registry）
```bash
npm config delete @hatech:registry
```
