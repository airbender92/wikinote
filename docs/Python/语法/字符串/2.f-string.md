# 2.3.2 f-string 格式化字符串（AI Agent 写提示词核心语法）
## 一、核心概念：f 字符串（格式化字符串）
语法规则：
字符串引号**前面加字母 `f`**，字符串内部用 `{变量名}` 嵌入变量，Python 会自动把大括号替换成变量真实值。
```python
first_name = "ada"
last_name = f"lovelace"
full_name = f"{first_name} {last_name}"
print(full_name)
# 输出：ada lovelace
```

## 二、关键特性：大括号内可以直接调用字符串方法
`{变量.方法()}` 直接在占位符里处理文本，不用提前单独处理变量：
```python
first_name = "ada"
last_name = "lovelace"
full_name = f"{first_name} {last_name}"
# 直接在{}调用title()格式化姓名
print(f"Hello, {full_name.title()}!")
# 输出：Hello, Ada Lovelace!
```

## 三、标准写法：先组装完整消息存入变量
工程化写法（写Agent提示词必用，代码整洁）：
```python
first_name = "ada"
last_name = "lovelace"
full_name = f"{first_name} {last_name}"
# 把完整提示/消息存入变量，方便后续传给大模型
message = f"Hello, {full_name.title()}!"
print(message)
```

## 四、为什么这个语法对你做AI Agent极其重要
写智能体时，**所有提示词(Prompt)都靠 f-string 拼接**，举实战例子：
```python
# AI Agent 真实场景示例
role = "企业文档分析助手"
user_query = "如何导出月度报表"
doc_path = "./data/公司制度.pdf"

# 动态拼接发给大模型的prompt
prompt = f"""
你是{role}，只能基于文档回答用户问题。
参考文档路径：{doc_path}
用户提问：{user_query}
"""
print(prompt)
```
输出效果：
```
你是企业文档分析助手，只能基于文档回答用户问题。
参考文档路径：./data/公司制度.pdf
用户提问：如何导出月度报表
```

## 五、补充优势（对比老式拼接）
不用 `+` 号拼接字符串，不会频繁类型报错（数字、列表都能直接放`{}`）
老式麻烦写法（不推荐）：
```python
# 难读、复杂拼接容易出错
msg = "Hello, " + full_name.title() + "!"
```
