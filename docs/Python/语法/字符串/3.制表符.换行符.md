# 2.3.3 制表符 `\t`、换行符 `\n` 完整讲解
## 一、两个转义字符作用
1. `\t` = 制表符，相当于键盘 Tab 键，缩进一段空白，实现对齐
2. `\n` = 换行符，光标直接跳到下一行开头

## 二、基础示例（交互式直接运行）
### 1. 单独制表符 \t
```python
print("Python")
print("\tPython")
```
输出：
```
Python
    Python
```

### 2. 单独换行符 \n
```python
print("Languages:\nPython\nC\nJavaScript")
```
输出：
```
Languages:
Python
C
JavaScript
```

### 3. 组合使用 `\n\t`（换行+缩进）
换行后自动缩进，列表排版超整齐：
```python
print("Languages:\n\tPython\n\tC\n\tJavaScript")
```
输出：
```
Languages
    Python
    C
    JavaScript
```

## 三、对你AI Agent的实用场景
1. **格式化Prompt提示词**
给大模型传递结构化指令时，用`\n\t`分层排版，模型更容易读懂格式要求：
```python
prompt = f"""请整理用户需求：
\t1. 读取本地文档
\t2. 提取关键数据
\t3. 生成总结报告
用户问题：如何统计月度数据
"""
print(prompt)
```

2. **控制台打印工具列表、对话日志**
Agent运行日志分层展示，方便排查工具调用记录。

## 四、补充小知识点
`\t` 和 `\n` 属于**转义字符**，反斜杠`\`是标记，不会直接打印出来；
如果想输出单纯的`\`，需要写`\\`。

## 随堂练习代码
