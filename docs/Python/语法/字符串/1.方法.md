# 2.3 字符串完整讲解（结合AI Agent实战场景）
## 一、字符串基础定义
1. **定义**：由一系列字符组成，Python中单引号`' '`、双引号`" "`包裹的内容都是字符串。
2. 引号灵活用法：
    - 字符串内部包含双引号，外层用单引号；
    - 字符串内部包含撇号`'`，外层用双引号，避免语法报错。
```python
# 示例1：内部带双引号
msg1 = 'I told my friend, "Python is my favorite language!"'
# 示例2：内部带单引号/撇号
msg2 = "One of Python's strengths is its diverse community."
```

## 二、三大大小写处理方法（核心方法）
### 1. `title()`：每个单词首字母大写，其余小写
适合处理人名、角色、指令名称（Agent对话格式化常用）
```python
name = "ada lovelace"
print(name.title())
# 输出：Ada Lovelace
```

### 2. `upper()`：全部转为大写
```python
name = "Ada Lovelace"
print(name.upper())
# 输出：ADA LOVELACE
```

### 3. `lower()`：全部转为小写
**AI项目高频用法**：统一用户输入、提示词大小写，消除大小写差异干扰匹配
```python
user_input = "Hello Agent"
# 统一小写后再做关键词匹配
clean_input = user.lower()
print(clean_input)
# 输出：hello agent
```

### 关键知识点：字符串方法不会修改原变量
所有大小写操作只会**返回新字符串**，原始字符串保持不变，如果需要永久修改必须重新赋值：
```python
text = "python"
text.upper()
print(text)  # 还是输出 python，原数据没变
# 正确永久修改写法
text = text.upper()
print(text)  # PYTHON
```

## 三、拓展：后续本节剩余核心方法（书本后面小节，提前梳理）
### 1. f-string 格式化（拼接变量，写提示词必备）
```python
agent_name = "办公助手"
prompt = f"你是{agent_name}，负责整理文档"
print(prompt)
```
### 2. 空白处理 `strip()` / `lstrip()` / `rstrip()`
清理用户输入前后多余空格（用户提问清洗刚需）
### 3. `removeprefix()` / `removesuffix()`
删除固定前后缀，比如剔除URL前缀、文件后缀

## 四、适配你学习AI Agent的实用场景
1. **用户提问清洗**：拿到用户输入后统一`lower()`小写，避免大小写导致关键词识别失败；
2. **提示词组装**：大量使用f-string拼接模型指令、变量、上下文；
3. **输出格式化**：人名、标题用`title()`规范展示；
4. 文件、路径处理：使用前后缀方法截取文件名。
