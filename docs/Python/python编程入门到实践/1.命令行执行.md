# 一、完整操作步骤（Windows系统）
## 1. 打开命令窗口
按下 `Win + R`，输入 `cmd` 回车，打开**命令提示符**。

## 2. 进入Python交互式终端
输入命令并回车：
```
python
```
出现 `>>>` 提示符，代表进入Python会话。

## 3. 执行示例代码
直接输入：
```python
print("Hello Python interpreter!")
```
按回车，终端立刻输出：
```
Hello Python interpreter!
```

## 4. 退出交互式终端两种方法
方法1（代码退出）：
```python
exit()
```
方法2（快捷键）：先按 `Ctrl + Z`，再按回车键，直接退回cmd窗口。

# 二、macOS / Linux 补充区分
这两个系统终端输入命令是 `python3`，不是 `python`：
1. 打开终端，输入
```python3
```
2. 同样输入 `print("Hello Python interpreter!")` 测试
3. 退出：`exit()` / `Ctrl + D`

# 三、作用说明
这种 `>>>` 交互环境叫**Python解释器会话**，适合：
- 临时测试单行小段代码，不用新建`.py`文件
- 快速验证语法、简单计算（你前期练语法神器）
缺点：关闭后代码全部消失，复杂程序还是要新建`.py`文件用VS Code保存运行。

# 四、新手常见报错解决
输入`python`提示不是内部命令：
原因安装Python时**没勾选Add Python to PATH**
解决方案：重新运行Python安装包，勾选PATH选项修复安装。
