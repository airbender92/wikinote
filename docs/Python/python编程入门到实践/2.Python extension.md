# VS Code Python 插件分三类推荐（适配你：初学Python+后期做AI Agent）
## 一、【必装核心，缺一不可】（安装Python主插件会自动附带Pylance）
### 1. Python（ms-python.python）微软官方
所有Python开发根基，自动配套：
- Pylance：极速代码补全、语法报错、函数跳转、类型检测（写Agent库LangChain/OpenAI时巨好用）
- Python Debugger：断点调试，排查工具调用、RAG报错必备
功能：识别Python环境、终端运行、单元测试、文件语法高亮

### 2. Code Runner
新手神器，一键运行代码，不用输终端命令，适合书本小片段、交互式测试
快捷键右键Run Code，直接输出结果，对应你书上`print("xxx")`练习

### 3. Ruff（替代Pylint，速度拉满）
代码检查+格式化二合一，自动找出语法漏洞、不规范代码，写Agent工程避免低级bug
安装后保存自动纠错，比传统工具快几十倍

### 4. Black Formatter
统一代码格式，保存自动对齐缩进、空行，团队/开源项目标准，不用手动调排版
搭配Ruff使用，代码永远整洁规范

### 5. isort
自动整理import导入语句，做Agent时会装大量库（langchain、openai、milvus），自动排序导入，文件不乱

## 二、【AI Agent刚需，中后期必装】（等学完基础语法再装）
### 1. Jupyter
写LLM/Agent实验专用，交互式单元格，分段测试提示词、RAG流程、工具调用，调试大模型代码必备
### 2. autoDocstring
函数注释自动生成，写Agent工具函数、自定义智能体时一键生成参数说明，工程化必备
### 3. Path Intellisense
文件路径自动提示，RAG读取文档、加载向量库文件不会写错路径

## 三、【国产AI辅助插件（免费，新手强烈推荐）】
### 通义灵码
中文代码补全、报错解释、代码重构，看不懂报错、写Agent示例直接问，国内网络稳定不用翻墙
### CodeGeeX
开源免费AI编码助手，可生成Function Calling、RAG完整代码，适合快速搭Agent Demo

## 四、【锦上添花，可选，按需安装】
1. Better Comments：注释彩色区分，TODO/警告一目了然
2. Error Lens：行内直接标红报错，不用切终端看日志
3. GitLens：后期做项目、上传代码看修改记录（入门阶段不用装）

# 最简安装清单（初学阶段只装这5个，不冗余）
1. Python（自动带Pylance）
2. Code Runner
3. Ruff
4. Black Formatter
5. 通义灵码

## 安装小提示
1. 打开VS Code左侧扩展图标，搜索插件全称一键安装；
2. 装完Black/Ruff后，设置开启**保存自动格式化**；
3. 前期只学书本语法不用装Jupyter，学到大模型、LangChain再补。
