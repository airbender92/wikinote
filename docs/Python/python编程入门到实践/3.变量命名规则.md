# 2.2.1 变量命名规则 完整拆解+示例+避坑（适配你AI Agent学习）
## 一、硬性规则（违反直接报错，必须遵守）
### 规则1：字符限制，只能字母、数字、下划线
开头**只能是字母 / 下划线**，**不能以数字开头**
✅ 合法示例：
`msg`、`user_age`、`_tool_name`、`data1`
❌ 非法示例：
`1_data`（数字开头）、`user-name`（横杠非法）、`user name`（有空格）

### 规则2：不能用Python内置关键字/函数名当变量
像`print`、`if`、`for`、`list`、`str`、`input`这些是系统预留词，拿来当变量会直接覆盖原有功能，程序崩溃。
错误示范：
```python
print = "测试文字"  # 把print覆盖，后面再也无法打印内容
print(123)  # 直接报错
```

### 规则3：不能包含空格
多单词必须用**下划线`_`**分隔（Python标准命名：蛇形命名法）
✅ `agent_memory`（智能体记忆）
❌ `agent memory`（空格报错）

### 规则4：慎用`l`、`O`单个字母
小写l像数字1，大写O像数字0，阅读代码极易看错：
不推荐：`l = 5`、`O = "key"`
替代：`line_num = 5`、`order_key = "key"`

## 二、可读性规范（不报错，但写代码必须养成习惯）
1. **见名知意，简短清晰**
适合AI Agent场景举例：
- 差命名：`d`、`n`
- 好命名：`doc_data`（文档数据）、`llm_prompt`（大模型提示词）、`tool_list`（工具列表）
2. 全部使用**小写字母**（变量/函数统一规范）
大写一般留给常量，比如`MAX_TOKEN = 8000`（最大上下文长度）

## 三、实战区分：合法/非法代码对照
### 合法变量
```python
# 智能体相关规范命名
agent_name = "办公助手"
tool_call_count = 3
_user_secret = "密钥"
chunk1 = "分段文本1"
```

### 非法变量（运行报错）
```python
1_chunk = "文本"    # 数字开头
agent name = "客服" # 带空格
print = "测试"       # 使用内置函数当变量
llm-name = "gpt"    # 横杠非法
```

## 四、针对你学AI Agent的命名小建议
后面写智能体、RAG、工具调用代码，统一这套命名习惯：
1. 普通变量：全小写+下划线
`user_query` 用户提问、`vector_db`向量库、`function_list`工具函数列表
2. 固定常量（模型最大长度、API地址）：全大写
`API_KEY = "xxx"`、`CHUNK_SIZE = 512`
3. 私有临时变量（仅内部使用）：下划线开头
`_temp_context` 临时对话上下文
