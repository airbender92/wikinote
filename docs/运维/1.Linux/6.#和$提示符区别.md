# `#` 和 `$` 提示符区别（WSL/Linux）

```
root@xxx:~#      ← # 井号
yambo@xxx:~$     ← $ 美元符号
```

## 1. `#` → root超级管理员账号

- 代表**当前是root用户，最高权限**
- 几乎可以干任何事：删系统文件、改配置、装软件、新建用户，没有权限拦截
- 风险大：输错命令可以直接搞坏系统，**日常尽量不要用#干活**

## 2. `$` → 普通用户（你创建的 yambo）

- 普通受限账号，大部分系统文件不能直接修改
- 需要管理员权限的时候，命令前面加 `sudo`

```bash
sudo nano /etc/wsl.conf
```

输入自己的用户密码，临时拿到root权限执行这一条命令。

---

## 对比表格

| 提示符 | 用户          | 权限     | 使用建议                                    |
| ------ | ------------- | -------- | ------------------------------------------- |
| `#`    | root          | 最高权限 | 只用来改系统配置，不要日常敲命令            |
| `$`    | 普通用户yambo | 受限     | **日常开发全部用$，安全**，需要特权加`sudo` |

### 你遇到的现象对应解释

1. `su - root` 失败：WSL默认root锁死，所以普通用户下切不进去。
2. `sudo xxx`：`$`环境下临时借root权限，不用切换到`#`。
3. PowerShell执行 `wsl -d Ubuntu -u root`，一进去就是 `#`，不需要密码。

### 实操小例子

✅ 正确（yambo用户，提示符`$`）：

```bash
sudo apt update
sudo nano /etc/wsl.conf
```

❌ 不推荐：长期待在`#`提示符下面敲日常命令。

### 快速看当前是谁

```bash
whoami
```

输出 `root` 就是#；输出`yambo`就是$。

> 你的目标：以后打开WSL默认进来就是 `yambo@wangyunbo:~$`，只有改系统的时候才用`sudo`临时提权，不要长期待在#环境。
