# 关键词

`sudo`：以管理员（root）权限执行命令
`apt`：Ubuntu/Debian 的包管理工具
`update`：**更新软件源索引，不是升级软件本身**
`upgrade`：根据刚刚 update 获取到的索引，升级本机已经安装的所有软件包到源里最新版本
`-y`：所有交互提问自动回答 yes，**不用手动敲 y 确认**，自动化执行
`apt install`: apt 包管理器的安装子命令，用于安装软件包。
`nano tree`: 一次性同时安装两个包，空格分隔：

- `nano`：轻量终端文本编辑器，简单易用，替代 vi/vim，适合新手改配置文件
- `tree`：目录树打印工具，终端把文件夹以树形结构展示文件层级

`whoami`: 输出当前登录的系统用户名
`usermod`: 修改用户账户属性命令

`-aG`:

- `-G`：追加附属组（附加组）
- `-a`：**append 追加**，⚠️ 不加 `-a` 会把用户从其他附属组全部移除，只保留 sudo 组，会出事故！

`sudo`：sudo 用户组，在 Ubuntu/Debian 里，属于该组的用户可以使用 `sudo` 获取管理员权限

# 命令

```bash
# 刷新索引 访问配置的软件源服务器，下载最新软件包清单，告诉本地系统：哪些软件有新版本、版本号是多少。
sudo apt update


# 升级已装软件 注意：`apt upgrade` 默认**不会删除旧包**，不会移除冲突软件 如果你需要处理需要删除旧包的重大版本升级，用 `apt full-upgrade`。
sudo apt upgrade -y

# 允许升级时自动移除不再需要的旧依赖包，适合大版本系统更新
sudo apt full-upgrade -y

# 输出当前登录的系统用户名
whoami

# PowerShell 启动 WSL 直接进入 yambo 用户
wsl -u yambo

# 将用户yambo追加加入sudo组，使其拥有sudo管理员权限；-a必须带上表示追加，不要漏掉
usermod -aG sudo yambo
```
