**WSL不是双系统，重启电脑依旧进Windows，Ubuntu只是一个软件窗口**。

我给你讲明白区别，消除你的恐惧：

1. **双系统**：电脑开机屏幕会选 Windows / Ubuntu，选哪个就完整跑哪个系统，二选一。这个会接管开机。
2. **WSL2（我们用的）**：Windows本身还是主系统。Ubuntu只是**Windows里面的一个应用程序**，类似微信、VS Code。重启电脑还是正常进Windows桌面，只是多了一个Ubuntu的小黑窗口可以点开用。

> 重启之后：开机 → Windows桌面，有可能自动弹出一个Ubuntu黑色命令行窗口，你关掉这个窗口，你就回到Windows，啥也不影响。关掉窗口，Linux就停止运行了。

---

## 第一步：装WSL2 Ubuntu（练命令、写shell脚本用）

1. 开始菜单搜 `PowerShell` → **右键，以管理员身份运行**
2. 输入命令

```powershell
wsl --install
```

3. 执行完，**重启电脑**
   ✅重启后：依旧是Windows桌面。可能弹出一个黑色Ubuntu小窗口（仅仅是个软件），让你设置Linux用户名、密码。

> 如果你不想用Ubuntu，直接把这个窗口叉掉，就完事，电脑完全是Windows。
> 以后想用Ubuntu：开始菜单搜索 `Ubuntu`，点击打开，就弹出命令行黑框。

> WSL2能干啥：敲Linux命令、写shell脚本、awk/sed。
> WSL2干不了：LVM磁盘扩容、完整firewalld防火墙。**这些实验交给VMware里的CentOS**。

## 第二步：安装VMware Player（免费软件，Windows软件）

这也是Windows上的一个普通软件，像QQ。
在Windows里面点开VMware软件，在软件内部跑CentOS虚拟机。

- Windows是宿主
- CentOS跑在VMware软件窗口里面。
  电脑开机永远进Windows，**不会开机直接进CentOS**。
  你不想用虚拟机，把VMware软件关掉就行。

---

## 验证WSL是否正常（Windows PowerShell里面敲）

```powershell
wsl -l -v
```

会看到Ubuntu，STATE可以是Running或者Stopped。

- Running：Ubuntu后台正在运行
- Stopped：已经停止。

关闭WSL全部实例：

```powershell
wsl --shutdown
```

执行完，Ubuntu就彻底停掉，没有任何后台。
