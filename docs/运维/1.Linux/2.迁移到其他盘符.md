明白，就是把WSL‑Ubuntu整个系统，从C盘挪到D盘，**你的账号yambo、所有配置全部保留**，不是重装。

> ⚠️全部命令在**Windows管理员PowerShell**运行，不要在Ubuntu黑窗口输入。

### 1、关闭WSL

```powershell
wsl --shutdown
```

### 2、D盘新建文件夹

D盘手动建立这两个目录：

- `D:\wsl_backup` 存放备份压缩包
- `D:\wsl_ubuntu` 存放Ubuntu实际系统文件

### 3、导出备份（把C盘的Ubuntu打包）

```powershell
wsl --export Ubuntu D:\wsl_backup\ubuntu.tar
```

等待跑完，会在D:\wsl_backup生成ubuntu.tar文件。

### 4、注销C盘旧实例（C盘空间释放，数据已经备份）

```powershell
wsl --unregister Ubuntu
```

### 5、导入到D盘位置

```powershell
wsl --import Ubuntu D:\wsl_ubuntu D:\wsl_backup\ubuntu.tar --version 2
```

### 6、修复默认登录用户（必须做！不然打开是root）

你的用户名是`yambo`

```powershell
ubuntu config --default-user yambo
```

### 7、验证

PowerShell输入

```powershell
wsl
```

提示符出现：`yambo@wangyunbo:~$`
✅迁移完成，系统本体现在放在D:\wsl_ubuntu，不再占用C盘。

> 确认一切正常后，可以删除 `D:\wsl_backup\ubuntu.tar`，释放D盘备份文件空间。

1. 不要手动复制文件夹，必须用export/import这套命令，手动拷贝会损坏WSL。

# 怎么确认WSL已经真正跑在D盘

WSL的真实磁盘文件是一个叫 `ext4.vhdx` 的虚拟磁盘文件，整个Ubuntu系统全部装在这个文件里面。

## 方法1：直接看D盘文件夹

打开资源管理器，进入：

```
D:\wsl_ubuntu
```

里面能看到一个很大的文件 **`ext4.vhdx`**（大小大概1.2G左右）
✅看到这个文件 = WSL本体就在D盘。

> C盘不会再有这个vhdx文件了，因为我们执行过`wsl --unregister Ubuntu`，旧C盘的虚拟磁盘已经被删除，C盘空间已经释放。

> ⚠️注意：WSL里面看到的 `/mnt/c` `/mnt/d` 只是访问你Windows硬盘，**不是WSL系统存放位置**，不要搞混。
>
> - `/mnt/c`：访问Windows的C盘（Windows硬盘）
> - WSL Linux系统本身：封装在D:\wsl_ubuntu\ext4.vhdx

## 方法2：PowerShell命令查看真实存放路径（最权威）

管理员PowerShell执行这一整段复制：

```powershell
Get-ChildItem HKCU:\Software\Microsoft\Windows\CurrentVersion\Lxss\ | ForEach-Object { Get-ItemProperty $_.PSPath } | Select-Object DistributionName,BasePath
```

输出示例：

```
DistributionName BasePath
---------------- --------
Ubuntu           D:\wsl_ubuntu
```

✅`BasePath`显示`D:\wsl_ubuntu`，代表WSL系统本体存放D盘。

## 容易混淆的点

1. 你打开WSL之后，提示符里面的 `/mnt/c/WINDOWS/system32`，这个只是**挂载读取Windows C盘**，不等于Linux系统装在C盘。
   Linux系统本身全部打包在D盘那个`ext4.vhdx`文件。

2. 备份文件`D:\wsl_backup\ubuntu.tar`，确认D:\wsl_ubuntu里面有ext4.vhdx，并且命令输出BasePath是D盘，就可以删掉这个tar备份包。

## 当前现状总结

