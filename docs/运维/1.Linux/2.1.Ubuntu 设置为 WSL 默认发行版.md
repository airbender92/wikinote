# 切换进入 Ubuntu WSL

你现在PowerShell里看到：

```
  NAME              STATE           VERSION
* docker-desktop    Stopped         2
  Ubuntu            Stopped         2
```

`*` 代表**默认发行版是docker‑desktop**，两个都处于停止状态。

## 方式1：直接启动Ubuntu（推荐）

PowerShell执行：

```powershell
wsl -d Ubuntu
```

就会直接进入Ubuntu终端。

## 方式2：把Ubuntu设置为WSL默认发行版，之后直接wsl就进Ubuntu

```powershell
wsl --set-default Ubuntu
```

设置完之后，直接敲

```powershell
wsl
```

就默认打开Ubuntu，不再进到docker‑desktop。

## 补充常用命令

1. 停止全部wsl：

```powershell
wsl --shutdown
```

2. 查看列表：

```powershell
wsl -l -v
```

> 小提示：如果启动卡住，可以先执行`wsl --shutdown`关闭所有WSL，再重新启动Ubuntu。

# 问题：Permission denied 权限不足

`/etc/wsl.conf`属于系统配置文件，普通用户`yambo`没有写入权限，直接nano保存报错。

## 操作步骤

1. 先按 `Ctrl+X` 退出nano，**不要保存**。

2. 使用sudo管理员权限打开这个配置文件：

```bash
sudo nano /etc/wsl.conf
```

输入你的Ubuntu用户密码（输入时屏幕不显示字符，输完回车）。

3. 把下面完整配置粘贴进去，覆盖原有全部内容

```ini
[boot]
systemd=true

[user]
default=yambo

[automount]
enabled = true
options = "metadata,uid=1000,gid=1000"
mountFsTab = false

[interop]
appendWindowsPath = false
```

4. 保存退出：
   `Ctrl+O` →回车确认写入 →`Ctrl+X`退出

5. 回到Windows PowerShell，关闭WSL使配置生效

```powershell
wsl --shutdown
```

6. 重新进入Ubuntu

```powershell
wsl -d Ubuntu
```

> 验证：重启后不会再导入Windows PATH，`Failed to translate`报错就消失。

### 补充提醒

开启`appendWindowsPath=false`之后，WSL内部不能直接调用windows程序，比如`code .`打开VS Code会失效。
如果后续你需要这个功能，就把 `appendWindowsPath = true`，改用方案B，手动在`.bashrc`里写WSL格式flutter路径。
