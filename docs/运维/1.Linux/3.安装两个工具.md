## 第一步：先把基础环境做好

打开WSL(yambo用户)，执行更新：

```bash
sudo apt update && sudo apt upgrade -y
```

输入你的密码（输入密码屏幕不显示，正常），等待全部更新完成。

## 第二步：安装两个工具，学习要用

```bash
sudo apt install nano tree -y
```

- nano：简单文本编辑器（刚才用的）
- tree：目录树查看工具，练习看文件夹很方便

## 第三步：开始第1周练习（逐条复制敲，感受Linux）

```bash
pwd          # 看当前在哪个目录
ls           # 列出文件
ls -lah      # 详细列出所有文件
cd ~         # 回到自己家目录（推荐在这里写练习脚本，不要待在/mnt/c这种Windows目录）
pwd
mkdir test01 # 创建练习文件夹
cd test01
pwd
ls
touch a.txt  # 创建空文件
ls
tree         # 看目录结构
```

> ⚠️重点：**尽量在 `~` 家目录写脚本，不要在 `/mnt/c` Windows目录写shell脚本！**
> Windows目录换行符CRLF，写shell脚本会报错，这个是新手高频踩坑。

### 怎么在WSL家目录用VS Code打开写脚本

在WSL里面（yambo用户，在test01文件夹）直接敲：

```bash
code .
```

会自动打开VS Code，**此时就是WSL远程模式，保存脚本默认换行符LF，不会出现CRLF坑**。

> 脚本保存的时候右下角确认行尾是 **LF**，不要CRLF。
