# 家目录 `~`

`~` 波浪号就是**当前登录用户的专属个人文件夹**。

## 1. 不同用户家目录不一样

- root 用户（提示符#）：家目录 = `/root`

```bash
cd ~
pwd
#输出 /root
```

- yambo普通用户（提示符$）：家目录 = `/home/yambo`

```bash
cd ~
pwd
#输出 /home/yambo
```

> `~` 是一个简写符号，自动指向你当前这个用户的家目录。
> 你是谁，`~`就代表谁的家目录。

## 2. 家目录里面放什么

- 你的代码、脚本、配置文件、文档，**自己的东西全部放这里**
- 权限隔离：yambo只能随便读写 `/home/yambo`，不能随便修改 `/root`、`/etc`这些系统目录
- WSL里，这个目录是**Linux原生文件系统**，不是Windows磁盘。

## 3. 和 `/mnt/d` 的关键区别（重点！）

- `/mnt/d`、`/mnt/c`：这是**挂载进来的Windows D盘、C盘**。
  Windows文件系统，性能差，Linux权限支持不完善，写脚本、编译项目容易出各种奇怪bug。
- `/home/yambo`（`~`）：**WSL Linux本地磁盘**，完整Linux权限，IO速度快，写代码、跑脚本首选位置。

### 实操演示，你可以敲一遍

```bash
# 回到家目录
cd ~
# 看当前绝对路径
pwd
# 创建一个测试脚本文件夹
mkdir code_demo
cd code_demo
pwd
```

你现在路径就是 `/home/yambo/code_demo`，在这里写脚本、练习，环境最稳。

## 快速记忆口诀

> root住 `/root`
> 普通用户住 `/home/用户名`
> `~` 等价于你的家目录，`cd ~`一键回家。

### 小坑提醒

不要在 `/mnt/d/ubuntu_test` Windows目录下做Linux开发练习，复制到 `~/`下面再跑，会少很多权限、编译报错。
