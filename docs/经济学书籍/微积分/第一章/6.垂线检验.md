# 垂线检验（一句话记住：一个 x 只能对应一个 y）
## 1. 什么是垂线检验？
在坐标系里随便画一条**竖直线（垂线）**：
- 如果这条垂线**和图像最多只交 1 个点** → 是函数图像
- 如果这条垂线**和图像交 2 个或更多点** → **不是函数图像**

原因很简单：
函数要求**同一个 x 只能有唯一的一个 y**，
如果一条竖线上有两个点，就说明同一个 x 对应了两个 y，违反函数定义。

---

## 2. 经典例子：圆
方程：\(x^2+y^2=9\)
随便取一个中间的 x，比如 x=0：
- 对应 y=3 和 y=-3 两个点
一条竖线交了两个点 → **不是函数**

---

## 3. 怎么把圆变成函数？
只保留**上半圆**或**下半圆**：
- 上半圆：\(y=\sqrt{9-x^2}\)
- 下半圆：\(y=-\sqrt{9-x^2}\)

这时候任何竖线都只交一个点，**通过垂线检验，就是函数**。

---

## 4. 超简口诀
**竖线一划只一点，才是函数；交两点，就不是函数。**
