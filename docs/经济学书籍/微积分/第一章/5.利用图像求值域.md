我用**最直观、好理解**的方式，把这段“用图像求值域”的方法给你讲透：

---

# 一、核心思想：影子法
把函数图像画出来，
想象**有一束水平的光，从左往右、从右往左照向 y 轴**。
图像在 y 轴上投下的**影子范围**，就是**值域**。

- 影子覆盖到的 y 值 → 能取到 → 在值域里
- 影子没覆盖到的 y 值 → 取不到 → 不在值域里

---

# 二、例子：F(x) = x²，定义域 [-2, 1)
函数规则是平方，但**x 只能从 -2 到 1，不包含 1**。

我们看平方曲线 y = x² 在这段上的图像：
- 左边：x 从 -2 到 0
- 右边：x 从 0 到 1（不包含 1）

### 1. 左边影子（x ∈ [-2, 0]）
x=-2 时 y=4
x=0 时 y=0
所以左边影子覆盖：**[0, 4]**

### 2. 右边影子（x ∈ [0, 1)）
x=0 时 y=0
x 接近 1 时 y 接近 1
所以右边影子覆盖：**[0, 1)**

### 3. 合起来
两段影子合在一起，最大范围还是 **[0, 4]**

所以：
\[
\text{值域} = [0, 4]
\]

---

# 三、关键结论
1. **规则相同、定义域不同 → 函数不同，值域也可能不同**
2. 用图像求值域 = 看**y 轴上的投影（影子）**
3. 影子覆盖到哪里，值域就是哪里

---
