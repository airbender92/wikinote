核心就一个：
**市场怎么定义，没有唯一标准答案，完全看你想达到什么目的。**

展开成三层逻辑：

1. **定义市场的宽窄，直接影响“市场份额”大小**
   - 市场定义得**窄** → 企业份额看起来就**大**
   - 市场定义得**宽** → 企业份额看起来就**小**

2. **不同立场的人，会故意选对自己有利的定义**
   尤其在反垄断（反托拉斯）里：
   - 政府反对合并 → 把市场定义得**很窄**，让企业份额显得超标
   - 企业想合并 → 把市场定义得**很宽**，让份额显得很小，躲过监管

3. **举例子说明**
   斯托夫公司想和雀巢合并：
   - 企业说：我们是做“冷冻便当”的 → 市场很大，份额小
   - 司法部说：你们是做“高价特色主菜”的 → 市场很小，份额大

4. **最终结论**
   不存在“唯一正确的市场定义”，
   **怎么定义市场，完全看你的目的是什么。**
