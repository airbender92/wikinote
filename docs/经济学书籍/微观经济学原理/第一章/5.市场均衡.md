## 核心就三件事
1. **只有在均衡价格（这里是6美元）**
   买方想买的数量 = 卖方想卖的数量
   双方都满意，谁都不难受。

2. **价格 > 均衡价（比如8美元）**
   - 卖方想多卖
   - 买方不想买那么多
   → 卖不出去，东西剩下来
   → 这叫 **过剩 / 过度供给**

3. **价格 < 均衡价（比如4美元）**
   - 买方抢着买
   - 卖方不愿多卖
   → 不够买，抢不到
   → 这叫 **短缺 / 过度需求**

---

## 一句话记牢
- 价太高 → 卖不动 → **过剩**
- 价太低 → 不够抢 → **短缺**
- 价正好 → 供需相等 → **市场均衡**

就是这个意思，完全理解了就没问题。
