# 二、阶段1：数学打底（经济专业真正的门槛）
经济不是文科，是**数学+逻辑**。
你不需要学到高数多难，但下面必须会：

### 必学内容
1. 单变量微积分（导数、极值、积分）
2. 基础线性代数（矩阵、向量）
3. 基础概率论与统计（期望、方差、回归直觉）

### 最适合自学的书
- 《普林斯顿微积分读本》（通俗易懂）
- 《数理统计学导论》（看前半部分就行）
- 或者更简单：**《经济学中的数学》卡尔·P·西蒙**（专门给经济学生写的）

> 不学数学也能懂“道理”，但达不到**本科水平**，只能算常识。

---

# 三、阶段2：经济学本科核心（真正的主干）
## 1）微观经济学（个人、企业、市场如何运行）
**核心：价格、供需、成本、竞争、博弈**

### 最经典、最好自学
- **《微观经济学》罗伯特·弗兰克**（通俗，案例多）
- **《微观经济学》平狄克**（标准本科教材，全球通用）

想更硬核一点：
- **《中级微观经济学》范里安**（国内考研/本科顶级教材）

## 2）宏观经济学（国家经济、GDP、通胀、利率、汇率）
**核心：经济增长、货币、财政政策、周期**

### 最好自学
- **《宏观经济学》曼昆**（全球最流行本科教材，语言友好）
- **《宏观经济学》多恩布什**（更深一点）

## 3）计量经济学（用数据验证经济理论，本科必备）
不学计量，不算正经经济科班。

### 入门
- **《计量经济学基础》古扎拉蒂**
- **《应用计量经济学》伍德里奇**（硕士级别入门）

---

# 四、阶段3：金融 + 市场 + 投资（你最关心的部分）
学完微观宏观，你就能理解**股市、债市、汇率、央行政策**。

## 必学
### 1. 货币银行学
- **《货币银行学》易纲**（国内最权威，理解中国经济必看）

### 2. 国际金融
- **《国际经济学》克鲁格曼**（汇率、贸易、全球经济逻辑）

### 3. 投资学 / 公司金融（股票、估值、财报）
- **《公司理财》斯蒂芬·罗斯**（全球金融本科圣经）
- **《投资学》博迪**（证券、基金、风险全讲透）

### 4. 财务会计基础（看懂财报必备）
- **《会计学》戴维·Spiceland** 或国内简化版

# 五、阶段4：研究生级别深度（形成完整体系）
达到**硕士知识结构**，你需要理解：
不同学派为什么打架（凯恩斯、货币主义、新古典、理性预期…）

## 高级宏观
- **《高级宏观经济学》罗默**（标准硕士教材）

## 高级微观
- **《微观经济理论》杰里/瑞尼**（硕士级）

## 当代经济流派
- **《宏观经济学：现代方法》巴罗**
- **《货币、权力与人》翟东升**（理解中国与全球格局）

# 六、最精简“速成路线”（不想学太多就按这个）

学完 = **正经经济本科水平**
再加罗默《高级宏观》 = **硕士结构**
