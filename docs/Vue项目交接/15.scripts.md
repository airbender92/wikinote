## `scripts/icon.ts` — 图标生成脚本

### 功能
用于**生成图标的配置文件**，供项目中的图标选择器（`IconPicker`）组件使用。

### 执行流程

1. **读取本地图标库** — 从 `node_modules/@iconify/json` 中读取 `collections.json`，获取所有可用的图标集列表（如 FontAwesome、Material Design 等）。

2. **交互式选择** — 使用 `inquirer` 在命令行中提供一个交互列表，让开发者选择一个图标集（如 `mdi`、`fa`、`carbon` 等）。

3. **生成图标数据文件** — 根据选择的图标集：
   - 读取对应的 JSON 文件（如 `json/mdi.json`）
   - 提取图标前缀（prefix）
   - 遍历所有图标，拼接成 `prefix:icon-name` 格式
   - 写入到 `src/components/IconPicker/src/data/` 目录，生成 `icons.{prefix}.ts` 文件

### 输出示例

选择 `mdi` 图标集后，会生成：
```
src/components/IconPicker/src/data/icons.mdi.ts
```
内容格式为：
```ts
export default { name: "Material Design Icons", prefix: "icon-prefix-mdi", icons: ["icon-prefix-mdi:home", "icon-prefix-mdi:account", ...] }
```

### 依赖的常量
- `ICON_PREFIX` — 从 `src/constants` 引入，用于统一图标前缀

### 使用方式
通常通过 npm script 调用，例如：
```bash
npx ts-node scripts/icon.ts
# 或
pnpm run icon  # 如果 package.json 中配置了该脚本
```

简单来说，这是一个**辅助工具脚本**，帮助开发者在项目中按需引入 @iconify 的图标集，生成对应的配置文件，供图标选择器组件使用。

## 图标生成后的使用方式

整体流程：**脚本生成数据 → IconPicker 展示选择 → Icon 组件渲染展示 → 通过名称引用**

### 1️⃣ 核心渲染组件：`<Icon>`

项目中所有图标统一通过 `src/components/Icon/src/Icon.vue` 组件渲染，使用方式：

```vue
<Icon icon="vi-ep:home-filled" :size="18" color="#333" />
```

**参数说明：**
| 参数 | 类型 | 说明 |
|------|------|------|
| `icon` | string | 图标名称，格式为 `{前缀}:{图标名}` |
| `size` | number | 图标大小，默认 16 |
| `color` | string | 图标颜色 |
| `hoverColor` | string | 鼠标悬停颜色 |

### 2️⃣ 图标名称格式

由 `ICON_PREFIX` + 图标集 prefix + 图标名称 组成：

```
vi-ep:home-filled
│  │       │
│  │       └─ 图标名
│  └───────── 图标集（ep = Element Plus）
└─────────── 全局前缀（ICON_PREFIX = 'vi-'）
```

你看到的已有数据文件有：
- `icons.ep.ts` → 前缀 `vi-ep`（Element Plus 图标）
- `icons.ant-design.ts` → 前缀 `vi-ant-design`（Ant Design 图标）
- `icons.tdesign.ts` → 前缀 `vi-tdesign`（腾讯 TDesign 图标）

### 3️⃣ 在业务中直接引用

在所有 Vue 模板/JSX 中直接使用 `<Icon>` 组件：

```vue
<!-- 按钮图标 -->
<BaseButton type="primary">
  <Icon icon="vi-ep:upload-filled" /> 上传
</BaseButton>

<!-- 菜单图标（路由 meta 中配置） -->
<Icon :icon="item.meta.icon" />

<!-- 带颜色和尺寸 -->
<Icon icon="vi-ant-design:exclamation-circle-filled" :size="18" color="#e6a23c" />

<!-- 纯展示 -->
<Icon icon="vi-ep:close" :size="24" />
```

### 4️⃣ 路由菜单图标使用

在路由配置的 `meta.icon` 中填写图标名称：

```ts
{
  path: '/system',
  meta: {
    title: '系统管理',
    icon: 'vi-ep:setting'   // 直接填图标名
  }
}
```

菜单组件会自动渲染：
```tsx
<Icon icon={meta.icon}></Icon>
```

### 5️⃣ 在表单中使用 `IconPicker` 组件

当需要让用户**选择图标**时（如菜单管理页面的图标选择），使用 `IconPicker`：

```vue
<IconPicker v-model="formData.icon" />
```

它已注册到 `Form` 组件的组件映射中，也可以直接在表单 schema 中使用：

```ts
{
  field: 'icon',
  label: '图标',
  component: 'IconPicker'
}
```

`IconPicker` 渲染效果：
- 左侧：输入框显示当前选中的图标名称
- 右侧：图标预览
- 点击弹出选择面板，支持按图标集 Tab 切换、搜索、分页

### 6️⃣ 离线/在线模式

- **离线模式**（默认）：`VITE_USE_ONLINE_ICON=false`，UnoCSS 在构建时会从 `@iconify/json` 提取图标 CSS 类，页面通过 `<div class="vi-ep:home-filled iconify">` 渲染
- **在线模式**：`VITE_USE_ONLINE_ICON=true`，使用 `@iconify/vue` 的 `<Icon>` 组件动态加载

生成的脚本数据文件（`icons.ep.ts` 等）主要是给 `IconPicker` 组件提供可选的图标列表，而实际渲染时由 `Icon.vue` 根据模式选择不同方式。

---

**总结**：生成后只需在需要的地方写 `<Icon icon="vi-{图标集}:{图标名}" />` 即可使用，不需要额外引入。
