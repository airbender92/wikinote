这段配置是 **Vite 中对 Less 预处理器的全局变量/样式注入配置**，我给你完整解释+优化写法，方便你直接用。

# 完整可复制 vite.config.ts / vite.config.js
```ts
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'

export default defineConfig({
  plugins: [vue()],
  css: {
    preprocessorOptions: {
      less: {
        // 全局注入变量文件，每个组件都会自动引入
        additionalData: '@import "./src/styles/variables.module.less";',
        // 开启 Less 内联 JavaScript 语法（必须，否则很多 UI 库会报错）
        javascriptEnabled: true
      }
    }
  }
})
```

# 作用说明
1. **`additionalData`**
   - 会在**每个 Less 文件顶部自动注入**这段代码
   - 相当于你不用在每个组件里手动 `@import` 变量文件，就能直接用 `@color-primary` 这类变量

2. **`javascriptEnabled: true`**
   - 允许 Less 中使用 `@{var}`、`color(~'@{color}')` 这类 JS 语法
   - 用 Element Plus、Ant Design Vue 等组件库**必开**，否则会编译报错

# 常见问题与优化
## 1. 路径找不到？建议用绝对路径
更稳的写法：
```ts
additionalData: `@import "@/styles/variables.module.less";`,
```
同时在 `vite.config` 配置别名：
```ts
resolve: {
  alias: {
    '@': path.resolve(__dirname, 'src')
  }
}
```

## 2. 多个 less 文件要注入？
```ts
additionalData: `
  @import "@/styles/variables.less";
  @import "@/styles/mixins.less";
`
```

## 3. 为什么用 `.module.less`？
- `.module.less` 是 **CSS Modules** 命名
- 如果你只是全局变量，建议改成 `variables.less` 更规范
