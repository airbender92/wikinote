### 二、开发启动链路详解

#### `pnpm dev`

```
┌──────────────────────────────────────────────────────────────────────────┐
│ pnpm dev                                                                 │
│   → pnpm vite --mode dev                                                 │
│                                                                          │
│ 步骤1: vite.config.ts 被加载                                             │
│   → ConfigEnv: { command: 'serve', mode: 'dev' }                        │
│   → isBuild = false (因为command === 'serve')                            │
│                                                                          │
│ 步骤2: 加载环境变量                                                       │
│   → 读取 .env.dev 文件                                                   │
│   → 解析逻辑（关键！有两个分支）：                                         │
│                                                                          │
│     if (!isBuild) {   ← 开发环境走这个分支                                │
│       // process.argv 示例:                                              │
│       //   ['node', 'vite', '--mode', 'dev']                            │
│       //   索引:    0       1        2       3                           │
│       env = loadEnv(process.argv[3], root)                               │
│       // → loadEnv('dev', 项目根目录)                                    │
│       // → 合并 .env + .env.dev + .env.local.dev                         │
│     } else {                                                             │
│       env = loadEnv(mode, root)  // 构建模式走这里                        │
│     }                                                                    │
│                                                                          │
│ 步骤3: 从 env 提取关键变量                                                │
│   → VITE_API_BASE_PATH          → API 代理前缀                           │
│   → VITE_BASE_PATH              → base路径 ('/' 或子路径)                │
│   → VITE_APP_TITLE              → 页面标题（注入 index.html）             │
│   → VITE_USE_MOCK               → 是否启用 mock                         │
│   → VITE_USE_PERMISSION         → 是否启用权限控制（在 auth.ts 中读取）   │
│   → VITE_USE_ALL_ELEMENT_PLUS_STYLE → Element Plus 样式引入策略          │
│                                                                          │
│ 步骤4: 启用开发专属插件                                                    │
│   → ServerUrlCopy()       ✓    (enableUrlCopy = !isBuild = true)        │
│   → EslintPlugin()        ✓    (enableViteEslint = !isBuild = true)     │
│   → viteMockServe({ localEnabled: true })  ✓  (如果 VITE_USE_MOCK=true) │
│   → 禁用 legacy 插件（默认）                                              │
│                                                                          │
│ 步骤5: 启动 dev server                                                   │
│   → port: 4000                                                           │
│   → host: '0.0.0.0'                                                     │
│   → proxy 配置：                                                         │
│       [/dr/front/api/ 或 /front/api/] → http://10.1.130.93:8080/        │
│       [/ws]                   → ws://10.1.130.93:8080/  (WebSocket)     │
│                                                                          │
│ 步骤6: HTML 模板渲染                                                     │
│   → ViteEjsPlugin 将 <%- title %> 替换为 env.VITE_APP_TITLE              │
│                                                                          │
└──────────────────────────────────────────────────────────────────────────┘
```

**开发启动时 `argv[3]` 的坑**（来自源码注释）：

```typescript
// vite.config.ts 第32行
if (!isBuild) {
  // 注意：开发模式时是通过 process.argv 直接取，而非 ConfigEnv.mode
  // pnpm vite --mode dev 的 argv 是:
  //   [0] node.exe
  //   [1] 脚本路径
  //   [2] '--mode'
  //   [3] 'dev'
  // 所以取 process.argv[3] === 'dev'
  env = loadEnv(process.argv[3] === '--mode' ? process.argv[4] : process.argv[3], root)
}
```

### 三、构建链路详解

#### `pnpm build:pro` / `pnpm build:test` / `pnpm build:dev`

```
┌──────────────────────────────────────────────────────────────────────────┐
│ pnpm build:pro                                                           │
│   → node --max-old-space-size=8192 ./node_modules/vite/bin/vite.js build │
│        --mode pro                                                        │
│                                                                          │
│ --max-old-space-size=8192: 增大 Node.js 堆内存到 8GB（应对大项目编译）     │
│                                                                          │
│ 步骤1: vite.config.ts 被加载                                             │
│   → ConfigEnv: { command: 'build', mode: 'pro' }                        │
│   → isBuild = true                                                       │
│                                                                          │
│ 步骤2: 加载环境变量                                                       │
│   → env = loadEnv(mode, root)  ← 直接从 ConfigEnv.mode 取 'pro'         │
│   → 读取 .env.pro 文件                                                   │
│                                                                          │
│ 步骤3: 环境变量驱动的构建行为                                              │
│                                                                          │
│   变量                     │ 影响                                        │
│   ─────────────────────────┼────────────────────────────────────────     │
│   VITE_BASE_PATH           │ base URL (部署子路径)                       │
│   VITE_OUT_DIR             │ 输出目录，默认 'dist'                       │
│   VITE_SOURCEMAP           │ 是否生成 sourcemap                         │
│   VITE_DROP_CONSOLE        │ true 则 esbuild.pure 移除 console.log      │
│   VITE_DROP_DEBUGGER       │ true 则 esbuild.drop 移除 debugger         │
│   VITE_USE_CSS_SPLIT       │ false 则合并 CSS                           │
│   VITE_USE_BUNDLE_ANALYZER │ true 则启用 visualizer 包分析              │
│   VITE_USE_LEGACY          │ true 则启用 @vitejs/plugin-legacy          │
│   VITE_USE_MOCK            │ true + VITE_ENABLE_BUILD_MOCK=true 则构建  │
│                            │   产物中包含 mock 服务                      │
│   VITE_USE_ALL_ELEMENT_PLUS_STYLE │ false 则按需引入样式                  │
│                                                                          │
│ 步骤4: 构建专属插件处理                                                    │
│   → ServerUrlCopy()       ✗    (isBuild=true, enableUrlCopy=false)      │
│   → EslintPlugin()        ✗    (isBuild=true, enableViteEslint=false)   │
│   → viteMockServe({ prodEnabled: true })  ✓  (如果 VITE_USE_MOCK=true   │
│        && VITE_ENABLE_BUILD_MOCK=true)                                  │
│   → progress()             ✓    显示构建进度条                           │
│   → legacy()               ✓/✗  (取决于 VITE_USE_LEGACY)                │
│   → visualizer()           ✓/✗  (取决于 VITE_USE_BUNDLE_ANALYZER)        │
│                                                                          │
│ 步骤5: Rollup 构建                                                        │
│   → target: 'es2015'                                                     │
│   → outDir: VITE_OUT_DIR || 'dist'                                      │
│   → 代码分割 (manualChunks):                                              │
│       ├─ vue-chunks    → vue, vue-router, pinia, vue-i18n               │
│       ├─ element-plus  → element-plus                                   │
│       ├─ wang-editor   → @wangeditor/editor, @wangeditor/editor-for-vue │
│       └─ echarts       → echarts, echarts-wordcloud                     │
│   → cssTarget: ['chrome31']                                             │
│   → cssCodeSplit: true (除非 VITE_USE_CSS_SPLIT=false)                  │
│                                                                          │
└──────────────────────────────────────────────────────────────────────────┘
```

### 四、环境文件加载逻辑详解

#### 4.1 环境文件优先级

Vite `loadEnv(mode, root)` 的加载顺序（从低到高覆盖）：

```
.env                      # 通用（所有模式都加载）
.env.local                # 通用本地（被 gitignore）
.env.[mode]               # 环境特定（如 .env.dev）
.env.[mode].local         # 环境特定本地（被 gitignore）
    ↑ 后加载的覆盖前者
```

本项目存在三个环境文件：
- `.env.dev`  → `loadEnv('dev', root)`
- `.env.test` → `loadEnv('test', root)`
- `.env.pro`  → `loadEnv('pro', root)`

#### 4.2 开发 vs 构建的 env 加载差异

| 对比项 | 开发 (`pnpm dev`) | 构建 (`pnpm build:pro`) |
|-------|-------------------|----------------------|
| **mode来源** | `process.argv[3]` (手动解析) | `ConfigEnv.mode` (Vite自动传入) |
| **loadEnv调用** | `loadEnv(process.argv[3], root)` | `loadEnv(mode, root)` |
| **具体值** | `loadEnv('dev', ...)` | `loadEnv('pro', ...)` |
| **环境文件** | `.env` + `.env.dev` | `.env` + `.env.pro` |

#### 4.3 env 变量的传递路径

```
环境文件 (.env.dev / .env.pro / .env.test)
    │
    ▼
vite.config.ts 中 loadEnv() → env 对象
    │
    ├──→ vite build 配置（base, outDir, proxy, esbuild 等）
    │
    ├──→ ViteEjsPlugin → index.html (<%= title %> → VITE_APP_TITLE)
    │
    └──→ import.meta.env.VITE_*  (vite 自动注入到客户端)
              │
              ├──→ src/axios/service.ts  (VITE_API_BASE_PATH)
              ├──→ src/axios/index.ts    (VITE_API_BASE_PATH)
              ├──→ src/utils/auth.ts     (VITE_USE_PERMISSION)
              ├──→ src/store/modules/app.ts (VITE_APP_TITLE)
              ├──→ src/axios/service.ts  (VITE_USE_MOCK)
              └──→ src/main.ts           (通过用户store间接读取)
```

**注意**：`import.meta.env.VITE_*` 在构建时会被**静态替换**（编译期注入），不是运行时读取。

### 五、Jenkins / CI 中的构建

`Jenkinsfile` + `Dockerfile.dev` 构成 CI 构建链路：

```dockerfile
# Dockerfile.dev
FROM node:18.0.0
WORKDIR /app
RUN npm install -g pnpm@8.1.0
COPY package.json .
RUN pnpm install
COPY . .
CMD [ "pnpm", "run", "dev" ]
```

Jenkins CI 中的特殊逻辑（来自 vite.config.ts）：
```typescript
const isCI = process.env.CI === 'true' || typeof process.env.JENKINS_URL === 'string'
// CI 环境下会：
// 1. 关闭 viteMockServe 的 logger（避免日志过多）
// 2. 不影响其他构建行为
```

```bash

pnpm i

# 开发（访问 http://localhost:4000）

# 预览构建产物
pnpm serve:pro     # 预览生产构建（需先 build）

# 类型检查
pnpm ts:check

# 代码检查
pnpm lint:eslint
pnpm lint:format
pnpm lint:style

# 单元测试
pnpm test
pnpm test:coverage

# 其他
pnpm clean         # 删除 node_modules
pnpm npm:check     # 检查依赖更新
```
