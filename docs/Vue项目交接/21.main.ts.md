这段是**Vue3 项目的入口主文件 `main.ts`**，我给你加**完整精简注释**，并讲清楚整体逻辑，方便你看懂和修改。

```typescript
import 'vue/jsx'

// 引入 UnoCSS（原 Windi CSS）
import '@/plugins/unocss'

// 全局 SVG 图标注册
import '@/plugins/svgIcon'

// 国际化 i18n
import { setupI18n } from '@/plugins/vueI18n'

// Pinia 状态管理
import { setupStore } from '@/store'
import { useUserStoreWithOut } from '@/store/modules/user'
import { NO_REDIRECT_WHITE_LIST } from '@/constants'

// 全局公共组件
import { setupGlobCom } from '@/components'

// Element Plus 全局注册
import { setupElementPlus } from '@/plugins/elementPlus'

// 全局样式
import '@/styles/index.less'

// animate.css 动画
import '@/plugins/animate.css'

// 路由
import { setupRouter } from '@/router'

// 权限指令（按钮级权限 v-permission 之类）
import { setupPermission } from '@/directives'

import { createApp } from 'vue'
import App from './App.vue'

// 引入路由权限守卫（就是你上一段发的那个 beforeEach/afterEach）
import './permission'

// 统一初始化所有插件
const setupAll = async () => {
  const app = createApp(App)

  // 1. 国际化
  await setupI18n(app)

  // 2. 挂载 Pinia
  setupStore(app)

  // 3. 启动时校验登录态（不在白名单才校验）
  const currentPath = (window.location.hash || '#/')
    .replace(/^#/, '')
    .split('?')[0] || '/'

  // 当前路径不在免登录白名单 → 强制和后端对齐登录状态
  if (NO_REDIRECT_WHITE_LIST.indexOf(currentPath) === -1) {
    const userStore = useUserStoreWithOut()
    // 刷新页面时，强制校验后端登录态，避免本地旧缓存导致权限错误
    await userStore.ensureUserInfo(true).catch(() => {})
  }

  // 4. 注册全局组件
  setupGlobCom(app)

  // 5. 注册 Element Plus
  setupElementPlus(app)

  // 6. 挂载路由
  setupRouter(app)

  // 7. 注册权限指令
  setupPermission(app)

  // 8. 挂载到页面
  app.mount('#app')
}

// 执行启动
setupAll()
```

# 核心逻辑总结
1. **启动顺序**
    创建 app → 国际化 → Pinia → **校验登录态** → 全局组件/ElementPlus → 路由 → 权限指令 → 挂载

2. **最关键的一段逻辑**
    ```typescript
    const currentPath = ...
    if (不在白名单) {
      await userStore.ensureUserInfo(true)
    }
    ```
    - 作用：**页面刷新时，强制向后端校验是否登录**
    - 避免：本地 Pinia 还有旧用户信息，但后端 Session 已过期，导致页面显示异常
    - 白名单（登录页、404等）不校验，防止无限重定向

3. 和你上一段 `permission.ts` 的关系
    - `main.ts`：**项目启动时全局校验登录**
    - `permission.ts`：**每次路由跳转时做守卫**
    两者配合，实现：
    - 刷新页面自动恢复登录态
    - 跳转页面自动鉴权
    - 未登录自动跳登录页

# 你可能会用到的常见修改点
1. **白名单路径**
   在 `@/constants` 里修改 `NO_REDIRECT_WHITE_LIST`，添加不需要登录就能访问的页面。

2. **启动时不强制校验后端**
   把 `ensureUserInfo(true)` 改成 `ensureUserInfo()` 或直接注释，适合开发时不想频繁调接口。

3. **路由模式从 hash 改 history**
   去 `@/router` 里把 `createWebHashHistory` 改成 `createWebHistory`。
