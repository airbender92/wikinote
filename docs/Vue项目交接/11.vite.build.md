# 关键点说明

## 1. target: 'es2015'
- 编译到 **ES6**，兼容非常老的浏览器
- 缺点：代码体积会变大，现代浏览器（Chrome、Edge、Firefox、Safari 近年版本）完全不需要
- 如果你不需要兼容 IE / 极老浏览器，建议改为：
  ```js
  target: 'modules' // 支持 ES 模块的现代浏览器，更小、更快
  ```

## 2. reportCompressedSize: false
- 关闭 gzip 大小计算，**能明显加快打包速度**
- 你这么写没问题，很合理

## 3. brotliSize: false
- 已废弃，Vite 新版本已移除该配置
- 直接删掉就行

## 4. rollupOptions.plugins
```js
plugins: env.VITE_USE_BUNDLE_ANALYZER === 'true' ? [visualizer()] : undefined
```
- 这里有个小坑：**不能给 undefined**
- rollup 要求 plugins 必须是数组
- 应该改为：
  ```js
  plugins: env.VITE_USE_BUNDLE_ANALYZER === 'true' ? [visualizer()] : []
  ```

## 5. manualChunks 手动拆包
你目前是**对象形式**手动分包：
```js
manualChunks: {
  'vue-chunks': ['vue', 'vue-router', 'pinia', 'vue-i18n'],
  'element-plus': ['element-plus'],
  ...
}
```
优点：
- 稳定、清晰
- 第三方依赖长期不变，有利于**浏览器缓存**

潜在问题：
- 如果包体积过大，会导致单个 chunk 很大
- 对象形式不支持复杂逻辑

更灵活的是**函数形式**，但你目前这样完全够用。

## 6. cssCodeSplit
```js
cssCodeSplit: !(env.VITE_USE_CSS_SPLIT === 'false')
```
意思：
- 默认开启 CSS 代码分割（按路由/组件拆分成多个 CSS）
- 当 `VITE_USE_CSS_SPLIT=false` 时，打包成**单个 CSS**

写法没问题，略绕一点而已。

## 7. cssTarget: ['chrome31']
- 非常老的 Chrome 版本
- 会导致内联的 CSS 变量、`rgba()` 等被降级处理
- 现代项目建议至少：
  ```js
  cssTarget: 'es2015'
  // 或
  cssTarget: 'chrome80'
  ```
