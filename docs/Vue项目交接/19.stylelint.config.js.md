# 配套安装依赖
```bash
npm install -D stylelint stylelint-config-standard stylelint-config-html stylelint-order postcss-html
```

# 常用命令（package.json）
```json
{
  "scripts": {
    "lint:style": "stylelint src/**/*.{vue,css,scss}",
    "lint:style:fix": "stylelint src/**/*.{vue,css,scss} --fix"
  }
}
```

# 配置作用总结
- 支持 **Vue scoped style + deep/global** 穿透语法
- 支持 **SCSS** 混合宏、条件语句
- 支持 **rpx** 兼容小程序/移动端
- 强制 **CSS 属性顺序统一**，便于团队协作
- 自动忽略 JS/TS，只校验样式文件
- 对 Vue/HTML 做单独兼容处理

如果你需要，我可以再给你配一份 **.stylelintignore** 或者和 **prettier 兼容**的版本。
