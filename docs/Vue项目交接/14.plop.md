## 完整代码解读

### 整体架构

这是基于 **Plop.js** 的代码生成器，分为两个生成器：**component**（组件）和 **view**（视图页面）。每个生成器包含：
- `prompt.cjs` — 配置交互式问答和生成逻辑
- `*.hbs` — Handlebars 模板文件，定义生成代码的骨架

---

### 1. `plopfile.cjs` — 入口注册文件

```js
const viewGenerator = require('./plop/view/prompt.cjs')
const componentGenerator = require('./plop/component/prompt.cjs')

module.exports = function (plop) {
  plop.setGenerator('view', viewGenerator)
  plop.setGenerator('component', componentGenerator)
}
```

- 导出 Plop 配置函数，接收 `plop` 实例
- `.setGenerator('名称', 配置对象)` 注册两个生成器，名称就是运行时用户选择的选项

---

### 2. `plop/component/prompt.cjs` — 组件生成器逻辑

| 部分 | 说明 |
|------|------|
| `toUpperCase` 工具函数 | 将字符串首字母大写：`"hello" → "Hello"` |
| `description` | 生成器描述，运行时显示为 `"Create vue component"` |
| `prompts` | 交互问题列表：询问用户输入组件名称（如 `"button"`） |
| `actions` | 生成动作，接收用户输入，创建 **2个文件** |

**生成的文件结构：**
```
src/components/{UpperFirstName}/
├── src/
│   └── {UpperFirstName}.vue    ← 组件模板
└── index.ts                    ← 导出入口
```

**示例：** 输入 `button`，则：
- 创建 `src/components/Button/src/Button.vue`
- 创建 `src/components/Button/index.ts`

---

### 3. `plop/component/component.hbs` — 组件 Vue 模板

```vue
<script setup lang="ts">
import { useDesign } from '@/hooks/web/useDesign'
const { getPrefixCls } = useDesign()
const prefixCls = getPrefixCls('{{ name }}')
</script>

<template>
  <div :class="`${prefixCls}-{{ name }}`">{{ upperFirstName }}</div>
</template>
```

- `{{ name }}` 和 `{{ upperFirstName }}` 是 Handlebars 插值语法，会被用户输入替换
- 集成了项目的 `useDesign` 样式前缀 hook（通常用于 BEM 命名空间）
- `prefixCls` 示例值：`"vab-button"`，最终 class 变成 `"vab-button-button"`（这里的命名实际有点重复，但设计如此）

---

### 4. `plop/component/index.hbs` — 组件导出入口模板

```ts
import {{ upperFirstName }} from './src/{{ upperFirstName }}.vue'
export { {{ upperFirstName }} }
```

- 生成标准的组件导出文件
- **示例输出：** 
  ```ts
  import Button from './src/Button.vue'
  export { Button }
  ```

---

### 5. `plop/view/prompt.cjs` — 视图页面生成器逻辑

| 部分 | 说明 |
|------|------|
| `prompts` | 两个交互问题：① 路径（默认 `"views"`）② 模块名称 |
| `actions` | 创建 **1个文件** |

**生成的文件结构：**
```
src/{path}/{UpperFirstName}.vue
```

**示例：** 路径输入 `views/dashboard`，名称输入 `index`，则：
- 创建 `src/views/dashboard/Index.vue`

---

### 6. `plop/view/view.hbs` — 视图页面模板

```vue
<script setup lang="ts">
import { ContentWrap } from '@/components/ContentWrap'
</script>

<template>
  <ContentWrap title="{{ upperFirstName }}"> {{ name }} </ContentWrap>
</template>
```

- 使用了项目的 `ContentWrap` 布局组件包裹页面内容
- `title` 属性显示首字母大写的名称，插槽内显示原始小写名称

---

### 总结

| 生成器 | 生成文件数 | 用途 |
|--------|-----------|------|
| **component** | 2 个（`.vue` + `index.ts`） | 快速创建可复用的通用组件 |
| **view** | 1 个（`.vue`） | 快速创建路由视图页面 |

这套模板通过 **一问一答 + 模板填充** 的方式，让开发者无需手动复制粘贴基础代码，就能快速生成符合项目规范的组件和页面骨架。
