## `IconPicker.vue` 组件完整解读

这是一个**图标选择器**组件，提供可视化界面让用户从多个图标集中选择和预览图标。下面从结构到逻辑逐层分析：

---

### 一、组件整体布局

```
┌───────────────────────────────────────────┐
│  [vi-ep:home-filled      ]  [🏠]          │  ← 输入框(显示名称) + 图标预览(触发按钮)
└───────────────────────────────────────────┘
         ↓ 点击图标预览区域，弹出 Popover
┌───────────────────────────────────────────┐
|  [🔍 搜索图标                     ]       |  ← 搜索输入框 (过滤图标)
|───────────────────────────────────────────|
| Element Plus  │  🏠 ⚙️ 📁 🖊️ 📄 ...      |  ← 左: Tabs (图标集切换)
| Ant Design    │  🗑️ ⭐ 🚀 💡 🔔 ...      |    右: 图标网格
| TDesign       │  📦 🔧 🎯 🔗 📋 ...      |
|───────────────────────────────────────────|
|  ← 1 2 3 ... →  共 368 个                |  ← 分页栏 (固定在底部)
└───────────────────────────────────────────┘
```

---

### 二、数据来源

```ts
import epIcons from './data/icons.ep'
import antIcons from './data/icons.ant-design'
import tIcons from './data/icons.tdesign'

const icons = [epIcons, antIcons, tIcons]
```

三个数据文件对应三个图标集，每个结构如下：
```ts
{
  name: 'Element Plus',     // 图标集显示名称
  prefix: 'vi-ep',          // 图标前缀
  icons: ['vi-ep:home-filled', 'vi-ep:setting', ...]  // 所有图标列表
}
```

---

### 三、核心逻辑

#### 1. `init()` — 初始化定位

```ts
const init = async (icon?: string) => {
  if (!icon) return
  const iconInfo = icon.split(':')         // "vi-ep:home-filled" → ["vi-ep", "home-filled"]
  iconName.value = iconInfo[0]             // 设置当前 Tab（如 "vi-ep"）
  const wrapIndex = icons.findIndex((item) => item.prefix === iconInfo[0])
  const index = filterItemIcons(icons[wrapIndex].icons).findIndex((item) => item === icon)
  await nextTick()
  currentPage.value = Math.ceil((index + 1) / unref(pageSize))  // 计算所在页码
}
```

**作用**：当已有选中的图标时，自动定位到它所在的**图标集 Tab 和页码**，让用户打开弹窗时直接看到之前选择的图标。

#### 2. `v-model` 双向绑定

```ts
const modelValue = defineModel<string>()
```

使用 Vue 3.4+ 的 `defineModel`，外部通过 `v-model` 绑定值：
```vue
<IconPicker v-model="selectedIcon" />
```

#### 3. 图标大小自适应

```ts
const iconSize = computed(() => {
  return unref(size) === 'small'    ? 'var(--el-component-size-small)'
       : unref(size) === 'large'   ? 'var(--el-component-size-large)'
                                   : 'var(--el-component-size)'
})
```

根据全局配置的组件尺寸（small/large/default），动态计算图标显示区域大小。

#### 4. `iconSelect()` — 选择/取消图标

```ts
const iconSelect = (icon: string) => {
  if (icon === unref(modelValue)) {
    modelValue.value = ''     // 再次点击已选中的图标 → 取消选择（清空）
    return
  }
  modelValue.value = icon      // 选中新图标
}
```

**交互细节**：点击同一个图标相当于"取消选择"（清空值），点击不同图标则切换选择。

#### 5. `search` — 图标搜索过滤

```ts
const search = ref('')
const filterItemIcons = (icons: string[]) => {
  return icons.filter((item) => item.includes(unref(search)))
}
```

简单的字符串包含匹配，输入 `home` 会匹配到所有包含 `home` 的图标名称。

#### 6. `filterIcons()` — 分页切分

```ts
const pageSize = ref(49)      // 每页 49 个（7x7 网格）
const currentPage = ref(1)

const filterIcons = (icons: string[]) => {
  const start = (unref(currentPage) - 1) * unref(pageSize)
  const end = unref(currentPage) * unref(pageSize)
  return icons.slice(start, end)
}
```

将当前 Tab 下（搜索过滤后）的图标列表按页切分。

#### 7. `tabChange()` — 切换 Tab 重置页码

```ts
const tabChange = () => {
  currentPage.value = 1
}
```

切换到不同图标集时，回到第一页。

#### 8. `popoverShow()` — 弹窗打开时初始化

```ts
const popoverShow = () => {
  init(unref(modelValue))
}
```

每次打开弹窗时，重新定位到已选图标的位置。

### 四、模板渲染流程

```
ElInput (显示当前值, 禁用编辑)
  └─ ElPopover
       ├─ #reference → 图标预览区域 (点击触发弹窗)
       │    └─ Icon :icon="modelValue"  (渲染选中的图标)
       │
       └─ Popover 内容
            ├─ ElInput (搜索框)
            ├─ ElScrollbar (滚动容器)
            │    └─ ElTabs
            │         └─ ElTabPane × N (图标集)
            │              └─ 图标网格
            │                   └─ div × N (单个图标)
            │                        └─ Icon (渲染图标)
            └─ ElPagination (固定在底部分页)
```

**样式亮点**：
- 输入框右侧圆角为 `0`，与图标预览区域无缝拼接
- 选中的图标边框高亮（`var(--el-color-primary)` 主题色）
- 搜索框使用了 UnoCSS 原子类：`mb-20px`、`h-[calc(100%-50px)]!` 等

---

### 五、完整数据流

```
外部 v-model 传入
    ↓
watch → init() → 定位到对应 Tab 和页码
    ↓
弹窗打开 → popoverShow → init() 再次定位
    ↓
用户搜索 → filterItemIcons 过滤 → filterIcons 分页 → 渲染网格
    ↓
点击图标 → iconSelect → 更新 modelValue
    ↓
外部收到新的图标值
```

# 图标选择器组件完整代码解读
这是一个基于 **Vue3 + TypeScript + Element Plus** 实现的**图标选择器（IconPicker）业务组件**，支持多图标库切换、搜索、分页、选中回填，常用于后台系统表单配置图标场景。

## 一、整体功能概览
1. 集成 **Element Plus / Ant Design / TDesign** 三套图标库
2. 点击输入框右侧图标区域弹出选择浮层
3. 支持图标搜索、标签页切换图标库、分页展示
4. 选中图标后自动回填到输入框，再次点击可清空
5. 自适应项目尺寸配置（small/default/large）
6. 样式与项目主题、命名空间完全对齐

---

## 三、模板部分 <template> 结构解析

### 1. 主体布局
```vue
<div :class="prefixCls" class="flex...">
  <ElInput disabled v-model="modelValue" clearable />
  <ElPopover>
    <template #reference>
      <div :style="iconWrapStyle">
        <Icon v-if="modelValue" :icon="modelValue" />
      </div>
    </template>
  </ElPopover>
</div>
```
- 左侧禁用输入框（只展示）
- 右侧小方块作为浮层触发点，显示当前选中图标

### 2. 浮层内容
```vue
<ElScrollbar>
  <ElInput v-model="search" placeholder="搜索图标" />
  <ElTabs tab-position="left" v-model="iconName">
    <ElTabPane v-for="item in icons">
      <div class="flex flex-wrap">
        <div
          v-for="icon in filterIcons(filterItemIcons(item.icons))"
          @click="iconSelect(icon)"
        >
          <Icon :icon="icon" />
        </div>
      </div>
    </ElTabPane>
  </ElTabs>
</ElScrollbar>
```
- 搜索框 + 左侧标签切换图标库
- 网格布局展示图标，选中高亮主色边框

### 3. 分页
```vue
<ElPagination
  v-model:current-page="currentPage"
  layout="total, prev, pager, next, jumper"
  :total="filterItemIcons(...).length"
/>
```
- 底部固定分页，总数随搜索结果动态变化
