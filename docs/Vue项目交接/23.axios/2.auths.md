这份是项目里**Axios 权限相关的常量 + 工具函数**，主要用来**统一处理 401 登录失效**，我给你逐行讲清楚。

```typescript
import type { AxiosResponse } from './types'

// 401 未授权状态码
export const UNAUTHORIZED_STATUS = 401

// 不需要做登录失效处理的接口（登录、登出）
export const AUTH_SKIP_URLS = [
  '/auth/login',
  '/auth/logout',
  '/logout',
  '/mock/user/loginOut'
]

/**
 * 判断当前接口是否跳过 401 重定向处理
 * 主要用于：登录、登出接口报错 401 时不跳登录页
 */
export const shouldSkipAuthHandling = (url?: string) => {
  if (!url) return false

  // 只要 URL 包含其中任意一个，就跳过
  return AUTH_SKIP_URLS.some((skipUrl) => url.includes(skipUrl))
}

/**
 * 判断响应是否是未授权（登录过期）
 * 兼容两种情况：
 * 1. HTTP 状态码 = 401
 * 2. 业务 code = 401
 */
export const isUnauthorizedResponse = (
  response?: Pick<AxiosResponse, 'status' | 'data'>
) => {
  return (
    response?.status === UNAUTHORIZED_STATUS ||
    response?.data?.code === UNAUTHORIZED_STATUS
  )
}
```

---

# 核心作用一句话总结
- 在**axios 响应拦截器**里用
- 遇到 **401 未登录 / 登录过期** 时：
  - 如果是**登录/登出接口**：不跳转，直接报错提示
  - 如果是**其他接口**：自动跳转到登录页

# 典型用法（你后面会在 request.ts 里看到类似代码）
```ts
if (isUnauthorizedResponse(response)) {
  if (shouldSkipAuthHandling(config.url)) {
    // 登录接口 401：直接提示账号密码错误
    message.error('账号或密码错误')
  } else {
    // 其他接口 401：登录过期，跳登录页
    userStore.logout()
    router.push('/login')
  }
}
```

# 关键点
1. `AUTH_SKIP_URLS`
   登录、登出接口报错 401 是**正常业务错误**，不能直接踢到登录页，所以要排除。

2. `isUnauthorizedResponse`
   兼容了**HTTP 401** 和 **业务 code 401** 两种后端返回习惯，非常通用。
