这是你项目里 **Axios 的默认全局拦截器配置**，是整个网络请求的核心处理逻辑，我给你逐行看懂+讲清用途。

```typescript
import { AxiosResponse, InternalAxiosRequestConfig } from './types'
import { ElMessage } from 'element-plus'
import qs from 'qs'
import { SUCCESS_CODE, TRANSFORM_REQUEST_DATA } from '@/constants'
import { objToFormData } from '@/utils'
import { isUnauthorizedResponse, shouldSkipAuthHandling } from './auth'

/**
 * 提取接口报错信息
 * 优先取 msg / message，兜底提示“操作失败”
 */
const resolveResponseErrorMessage = (response: AxiosResponse) => {
  const candidateList = [response?.data?.msg, response?.data?.message]

  for (const candidate of candidateList) {
    const text = String(candidate ?? '').trim()
    if (text) {
      return text
    }
  }

  return '操作失败'
}

/**
 * 默认请求拦截器
 * 处理：post 表单、form-data、get 请求自动加时间戳防缓存
 */
const defaultRequestInterceptors = (config: InternalAxiosRequestConfig) => {
  // post form 表单序列化
  if (
    config.method === 'post' &&
    config.headers['Content-Type'] === 'application/x-www-form-urlencoded'
  ) {
    config.data = qs.stringify(config.data)
  }

  // post form-data 自动把对象转 FormData
  else if (
    TRANSFORM_REQUEST_DATA &&
    config.method === 'post' &&
    config.headers['Content-Type'] === 'multipart/form-data' &&
    !(config.data instanceof FormData)
  ) {
    config.data = objToFormData(config.data)
  }

  // get 请求自动加 tmp 时间戳，防止浏览器缓存
  if (config.method === 'get') {
    let url = (config.url as string).replace(/[?&]+$/, '')
    const searchParams = new URLSearchParams()

    if (config.params) {
      for (const key of Object.keys(config.params)) {
        const value = config.params[key]
        if (value !== void 0 && value !== null) {
          Array.isArray(value)
            ? value.forEach(v => searchParams.append(key, String(v)))
            : searchParams.set(key, String(value))
        }
      }
      config.params = {}
    }

    // 加时间戳
    searchParams.set('tmp', Date.now().toString())
    const qsStr = searchParams.toString()
    if (qsStr) url += (url.includes('?') ? '&' : '?') + qsStr
    config.url = url
  }

  return config
}

/**
 * 默认响应拦截器
 * 处理：成功返回、文件 blob、401 登录过期、错误提示
 */
const defaultResponseInterceptors = (response: AxiosResponse) => {
  // 文件下载直接返回
  if (response?.config?.responseType === 'blob') {
    return response
  }

  // 业务成功：code === 成功码（一般是 200 / 0）
  else if (response.data.code === SUCCESS_CODE) {
    return response.data
  }

  // 业务失败
  else {
    // 401 且不是登录/登出接口 → 外层统一跳转登录页
    if (isUnauthorizedResponse(response) && !shouldSkipAuthHandling(response?.config?.url)) {
      return Promise.reject(response?.data || response)
    }

    // 其他错误：弹出提示
    ElMessage.error(resolveResponseErrorMessage(response))
    return Promise.reject(response?.data || response)
  }
}

export { defaultResponseInterceptors, defaultRequestInterceptors }
```

# 核心功能总结（非常关键）
## 1. 请求拦截器做了 3 件事
1. **post form 表单**
   自动用 `qs.stringify` 序列化
2. **form-data 上传**
   普通对象自动转 `FormData`
3. **get 请求防缓存**
   自动在 URL 末尾加 `?tmp=时间戳`

## 2. 响应拦截器做了 4 件事
1. 文件下载（blob）直接放行
2. 接口成功：直接返回 `response.data`
3. 401 未授权：
   - 登录/登出接口报错不跳转
   - 其他接口 401 → 外层跳转登录页
4. 其他错误：自动弹出 `ElMessage.error` 提示
