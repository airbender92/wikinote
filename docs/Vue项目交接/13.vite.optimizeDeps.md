# 作用是什么
Vite 在开发启动时，会把这些第三方包**提前编译成 ESM 并缓存**，目的：
1. 提高**首次启动 / 热更新速度**
2. 解决部分包 **CommonJS → ESM** 兼容问题
3. 避免页面加载时才去编译，导致卡顿或闪烁
4. 防止某些深层导入的包（如 Element 语言包）找不到模块

简单说：
> 把容易出问题、体积大、深层导入的包，提前打包好。

# 每一类为什么要加
- **vue / vue-router**：核心包，提前预编译更稳更快
- **element-plus 语言包**：属于深层 esm 导入，Vite 有时扫描不到，必须手动 include
- **@vueuse/core / axios / qs / dayjs**：常用工具库，提升开发体验
- **echarts / echarts-wordcloud**：大包，提前编译避免首次加载卡顿
- **@wangeditor/editor**：富文本编辑器，依赖复杂，容易出现热更新卡顿
- **vue-json-pretty / cropperjs / qrcode**：UI 类组件，提前处理更稳
- **@zxcvbn-ts/core**：密码强度库，CJS 模块，预构建避免报错
