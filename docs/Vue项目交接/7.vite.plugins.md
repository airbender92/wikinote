# 1. Vue
```ts
Vue({
  script: {
    defineModel: true
  }
})
```
- 插件来源：`@vitejs/plugin-vue`（Vite 官方）
- 核心作用：
  - 让 Vite 能识别、编译 `.vue` 单文件组件
  - 处理 `<template>` / `<script setup>` / `<style>`
  - 提供 Vue 组件热更新 HMR
- 你配置里的关键：
  - `defineModel: true`：开启 Vue3.4+ 双向绑定语法糖 `defineModel()`
- 环境：**始终启用**

# 2. VueJsx
```ts
VueJsx()
```

- 环境：**始终启用**

# 3. ServerUrlCopy
```ts
enableUrlCopy ? ServerUrlCopy() : undefined
```
- 插件：`vite-plugin-url-copy`
- 作用：
  - Vite 启动成功后，**自动把本地访问地址复制到剪贴板**
- 你的开关逻辑：
  - `enableUrlCopy = !isBuild`
  - 仅开发环境 `dev` 启用
  - 打包 `build` 关闭
- 效果：启动完直接粘贴就是 `http://localhost:4000`

# 5. createStyleImportPlugin
```ts
env.VITE_USE_ALL_ELEMENT_PLUS_STYLE === 'false'
  ? createStyleImportPlugin({
      resolves: [ElementPlusResolve()],
      libs: [
        {
          libraryName: 'element-plus',
          esModule: true,
          resolveStyle: (name) => {
            if (name === 'click-outside') return ''
            return `element-plus/es/components/${name.replace(/^el-/, '')}/style/css`
          }
        }
      ]
    })
  : undefined
```
- 插件：`vite-plugin-style-import`
- 作用：
  - **Element Plus 组件样式按需引入**
  - 你在代码中 `import { ElButton } from 'element-plus'`
  - 插件自动帮你引入对应组件的 css，不用手动 import
- 关键细节：
  - 排除 `click-outside`：它没有样式，避免报错
  - 自动去掉 `el-` 前缀，拼接真实路径
- 开关：
  - `VITE_USE_ALL_ELEMENT_PLUS_STYLE=false` 才启用
  - 为 true 则全量引入 `index.css`，不启用插件

# 6. EslintPlugin
```ts
enableViteEslint
  ? EslintPlugin({
      cache: false,
      failOnWarning: false,
      failOnError: false,
      include: ['src/**/*.vue', 'src/**/*.ts', 'src/**/*.tsx']
    })
  : undefined
```
- 插件：`vite-plugin-eslint`
- 作用：
  - 开发时**实时运行 ESLint 代码检查**
  - 在终端输出代码规范错误、警告
- 配置含义：
  - `cache: false`：不使用缓存，每次都全量检查
  - `failOnWarning: false`：有警告不中断服务
  - `failOnError: false`：有错误也不中断启动/打包
  - `include`：只检查 src 下的 vue/ts/tsx
- 开关：
  - `enableViteEslint = !isBuild`
  - 仅开发环境启用，打包关闭

---

# 7. VueI18nPlugin
```ts
VueI18nPlugin({
  runtimeOnly: true,
  compositionOnly: true,
  include: [resolve(__dirname, 'src/locales/**')]
})
```
- 插件：`@intlify/unplugin-vue-i18n/vite`
- 作用：
  - 对 `vue-i18n` 多语言文件进行**编译时优化**
  - 自动加载 `src/locales` 下的语言包（json/yml 等）
- 配置含义：
  - `runtimeOnly: true`：使用运行时版本，不打包编译器，体积更小
  - `compositionOnly: true`：只支持 `<script setup>` + `useI18n`
  - `include`：自动扫描多语言文件目录
- 环境：**始终启用**

# 8. createSvgIconsPlugin
```ts
createSvgIconsPlugin({
  iconDirs: [pathResolve('src/assets/svgs')],
  symbolId: 'icon-[dir]-[name]',
  svgoOptions: true
})
```
- 插件：`vite-plugin-svg-icons`
- 作用：
  - 批量加载 `src/assets/svgs` 下所有 SVG 图标
  - 自动合并为 symbol，使用 `<use href="#icon-xxx"/>`
- 配置含义：
  - `iconDirs`：图标所在目录
  - `symbolId`：生成的 ID 规则，带文件夹名+文件名
  - `svgoOptions: true`：开启 SVG 自动压缩
- 环境：**始终启用**

# 10. viteMockServe
```ts
enableBuildMock
  ? viteMockServe({
      ignore: /^\_/,
      mockPath: 'mock',
      localEnabled: !isBuild,
      prodEnabled: isBuild,
      supportTs: true,
      logger: !isCI,
      injectCode: `
        import { setupProdMockServer } from '../mock/_createProductionServer'
        setupProdMockServer()
      `
    })
  : undefined
```
- 插件：`vite-plugin-mock`
- 作用：
  - 本地开发模拟后端接口，无需联调
  - 可配置**生产环境也打包 Mock 逻辑**（演示版专用）
- 配置含义：
  - `mockPath: 'mock'`：从 `/mock` 目录读取接口
  - `ignore: /^\_/`：忽略下划线开头的工具文件
  - `localEnabled: !isBuild`：开发环境启用
  - `prodEnabled: isBuild`：打包后也可注入 mock
  - `supportTs: true`：支持 TS 编写 mock
  - `logger: !isCI`：CI/Jenkins 构建不打印日志
  - `injectCode`：生产环境自动注入 mock 启动代码
- 开关：
  - 由 `VITE_USE_MOCK` 和 `VITE_ENABLE_BUILD_MOCK` 控制

# 13. legacy
```ts
env.VITE_USE_LEGACY !== 'true'
  ? undefined
  : legacy({
      targets: ['Chrome >= 64', 'Edge >= 79', 'Firefox >= 67', 'Safari >= 12'],
      modernPolyfills: true
    })
```
- 插件：`@vitejs/plugin-legacy`
- 作用：
  - 为**低版本浏览器**生成兼容包（ES5 + polyfill）
  - 现代浏览器仍使用现代 ES Module 包
- 配置含义：
  - `targets`：设定最低兼容浏览器版本
  - `modernPolyfills: true`：为现代 API 自动补齐垫片
- 开关：
  - 默认不启用
  - `VITE_USE_LEGACY=true` 才开启（企业内网兼容专用）
