### 二、所有 scripts 启动/打包命令详解

#### 1️⃣ 安装快捷指令

| 命令 | 等价操作 | 说明 |
|------|---------|------|
| `pnpm i` | `pnpm install` | 一键安装所有依赖 |

#### 2️⃣ 本地开发启动

| 命令 | 等价操作 | 说明 |
|------|---------|------|
| `pnpm dev` | `pnpm vite --mode dev` | 启动 Vite 开发服务器，**环境模式 = dev**，支持 HMR |

#### 3️⃣ 打包构建（三种环境）

| 命令 | 等价操作 | 说明 |
|------|---------|------|
| `pnpm build:dev` | `node --max-old-space-size=8192 ... vite build --mode dev` | **开发环境** 打包 (8GB 堆内存) |
| `pnpm build:test` | `node --max-old-space-size=8192 ... vite build --mode test` | **测试环境** 打包 (8GB 堆内存) |
| `pnpm build:pro` | `node --max-old-space-size=8192 ... vite build --mode pro` | **生产环境** 打包 (8GB 堆内存) |

> ⚠️ 注意：`build:dev` ≠ 开发服务器，而是"以 dev 模式构建产物"用于部署 dev 站点。

#### 4️⃣ 预览已构建产物

| 命令 | 说明 |

| `pnpm serve:pro` | 预览生产构建产物 (`vite preview --mode pro`) |
| `pnpm serve:dev` | 预览开发构建产物 |
| `pnpm serve:test` | 预览测试构建产物 |

### 六、包管理器锁定分析

| 字段 | 值 | 结论 |
|------|----|------|
| **`packageManager`** | `pnpm@9.15.3` | ✅ **强制锁定 pnpm**，且版本必须为 `9.15.3` |
| **scripts 全部使用 `pnpm`** | 所有命令都以 `pnpm`/`pnpx` 开头 | ✅ **禁止使用 npm / yarn** |

> 🔒 **结论：本项目强制使用 pnpm (v9.15.3)，npm/yarn 不可用。**

### 七、版本约束 & Engines 要求

```json
"engines": {
  "node": ">=18.0.0",
  "pnpm": ">=8.1.0"
}
```

| 约束 | 要求 | 说明 |
|------|------|------|
| **Node.js** | `>= 18.0.0` | 至少 Node 18+（Vite 6 + 新工具链的最低要求） |
| **pnpm** | `>= 8.1.0` | 但实际 `packageManager` 指定了 `9.15.3` |

#### 精确锁定（无 `^` / `~` 前缀）的包

| 包名 | 锁定版本 | 原因推测 |
|------|---------|---------|
| `vue` | `3.5.13` | 框架核心，防止大版本意外升级 |
| `vite` | `6.0.7` | 构建核心，v6 初期版本稳定性控制 |
| `element-plus` | `2.13.1` | UI 组件库，需精确匹配主题/样式 |
| `vue-i18n` | `11.0.1` | 国际化依赖版本敏感 |
| `typescript` | `5.7.3` | 类型检查版本严格一致 |

其余依赖均使用 `^`（兼容 minor 版本升级）。
