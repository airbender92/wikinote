这段代码实现：
1. 页面加载进度条（NProgress）
2. 页面 loading 状态控制
3. 用户登录状态校验
4. 动态路由（前端/后端/静态三种模式）
5. 登录后跳转回原页面
6. 白名单页面无需登录可访问

# 带详细注释版
```ts
// 导入路由实例
import * as routerModule from '@/router'
const router = routerModule.default

// Pinia 状态仓库
import { useAppStoreWithOut } from '@/store/modules/app'
import { usePermissionStoreWithOut } from '@/store/modules/permission'
import { useUserStoreWithOut } from '@/store/modules/user'

// 类型
import type { RouteRecordRaw } from 'vue-router'
import type { RouteLocationNormalizedLoaded } from 'vue-router'

// 工具 Hooks
import { useTitle } from '@/hooks/web/useTitle'
import { useNProgress } from '@/hooks/web/useNProgress'
import { usePageLoading } from '@/hooks/web/usePageLoading'

// 不需要重定向的白名单（如登录、404 等）
import { NO_REDIRECT_WHITE_LIST } from '@/constants'

// 进度条
const { start, done } = useNProgress()
// 页面 loading
const { loadStart, loadDone } = usePageLoading()

/**
 * 获取路由守卫要跳转的目标路径
 * 处理登录后返回原页面逻辑
 */
const getRouteGuardRedirectPath = (
  from: RouteLocationNormalizedLoaded,
  to: RouteLocationNormalizedLoaded
) => {
  // 兜底路径：访问 / 则去 /home，否则去当前路径
  const fallbackPath = to.path === '/' ? '/home' : to.path

  // 如果从登录页过来，且有 redirect 参数，则解析为跳转目标
  const redirectPath =
    from.path === '/login' && typeof from.query.redirect === 'string'
      ? decodeURIComponent(from.query.redirect)
      : ''

  // 如果 redirect 不合法，使用兜底路径
  if (
    !redirectPath ||
    redirectPath === '/' ||
    redirectPath === '/login' ||
    redirectPath === '/404'
  ) {
    return fallbackPath
  }

  return redirectPath
}

// 全局前置守卫
router.beforeEach(async (to, from, next) => {
  // 开启进度条 & 页面 loading
  start()
  loadStart()

  const permissionStore = usePermissionStoreWithOut()
  const appStore = useAppStoreWithOut()
  const userStore = useUserStoreWithOut()

  // 是否有本地用户信息（已登录）
  const hasLocalUserInfo = Boolean(userStore.getUserInfo)
  // 是否在白名单（不需要登录）
  const shouldSkipRedirect = NO_REDIRECT_WHITE_LIST.includes(to.path)

  // 无本地信息且不在白名单 → 尝试通过接口恢复登录态
  const hasRemoteSession =
    !hasLocalUserInfo && !shouldSkipRedirect ? await userStore.ensureUserInfo() : false

  // ==========================================
  // 已登录（本地有信息 或 会话有效）
  // ==========================================
  if (hasLocalUserInfo || hasRemoteSession) {
    // 已登录再访问登录页 → 重定向到首页
    if (to.path === '/login') {
      next({ path: '/' })
    } else {
      // 路由已生成过 → 直接放行
      if (permissionStore.getIsAddRouters) {
        next()
        return
      }

      // 获取用户角色路由
      const roleRouters = userStore.getRoleRouters || []

      // 根据配置生成动态路由
      if (appStore.getDynamicRouter) {
        // 后台返回路由 / 前端筛选路由
        appStore.serverDynamicRouter
          ? await permissionStore.generateRoutes('server', roleRouters as AppCustomRouteRecordRaw[])
          : await permissionStore.generateRoutes('frontEnd', roleRouters as string[])
      } else {
        // 静态路由模式
        await permissionStore.generateRoutes('static')
      }

      // 动态添加路由到 router 实例
      permissionStore.getAddRouters.forEach((route) => {
        router.addRoute(route as unknown as RouteRecordRaw)
      })

      // 计算最终跳转地址
      const redirect = getRouteGuardRedirectPath(from, to)
      const nextData = to.path === redirect ? { ...to, replace: true } : { path: redirect }

      // 标记路由已加载
      permissionStore.setIsAddRouters(true)
      next(nextData)
    }
  }
  // ==========================================
  // 未登录
  // ==========================================
  else {
    // 白名单页面直接放行
    if (shouldSkipRedirect) {
      next()
    } else {
      // 其他页面 → 跳转到登录，并带上 redirect 参数
      next(`/login?redirect=${to.path}`)
    }
  }
})

// 全局后置守卫
router.afterEach((to) => {
  // 更新页面标题
  useTitle(to?.meta?.title as string)
  // 结束进度条 & loading
  done()
  loadDone()
})
```

# 核心流程简图（最关键）
```
进入页面 → 开启进度条
  ↓
判断是否登录 / 会话有效
  ↓
├── 已登录
│     ├── 访问登录页 → 去首页
│     └── 未生成动态路由 → 生成并添加路由 → 跳转目标页
└── 未登录
      ├── 在白名单 → 放行
      └── 不在白名单 → 跳登录页，带回跳地址
```

# 常见使用场景说明
- 适用于 **Vue3 + Vite + Pinia + VueRouter** 后台管理系统
- 支持三种路由模式：
  1. `server`：后端返回路由表
  2. `frontEnd`：前端根据角色筛选路由
  3. `static`：全部路由都加载
- 登录后会自动跳回之前想访问的页面
- 重复刷新页面也能恢复登录态
