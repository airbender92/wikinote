这是项目的**根组件 `App.vue`**，是整个后台系统的最外层容器，我给你完整看懂+注释+说明作用。

# 完整带注释版
```vue
<script setup lang="ts">
import { computed } from 'vue'
import { useAppStore } from '@/store/modules/app'
// 全局配置组件（控制全局组件尺寸、国际化等）
import { ConfigGlobal } from '@/components/ConfigGlobal'
// 样式命名空间 Hook
import { useDesign } from '@/hooks/web/useDesign'

const { getPrefixCls } = useDesign()
// 生成样式前缀，比如：admin-app
const prefixCls = getPrefixCls('app')

const appStore = useAppStore()

// 全局组件尺寸（default / small / large）
const currentSize = computed(() => appStore.getCurrentSize)
// 是否灰色模式（整站变灰）
const greyMode = computed(() => appStore.getGreyMode)

// 初始化主题（暗黑模式、色号、灰色模式等）
appStore.initTheme()
</script>

<template>
  <!-- 全局配置：统一控制 element-plus 尺寸 -->
  <ConfigGlobal :size="currentSize">
    <!-- 路由出口：所有页面都在这里渲染 -->
    <RouterView :class="greyMode ? `${prefixCls}-grey-mode` : ''" />
  </ConfigGlobal>
</template>

<style lang="less">
// 样式命名空间，避免全局污染
@prefix-cls: ~'@{adminNamespace}-app';

.size {
  width: 100%;
  height: 100%;
}

// 全局样式重置 + 铺满屏幕
html,
body {
  padding: 0 !important;
  margin: 0;
  overflow: hidden;
  .size;

  #app {
    .size;
  }
}

// 灰色模式：整站灰度
.@{prefix-cls}-grey-mode {
  filter: grayscale(100%);
}
</style>
```

---

# 核心作用
## 1. 作为整个系统的根容器
- `<RouterView />` 是所有页面的出口
- 所有页面都会嵌套在它里面

## 2. 全局尺寸控制
通过 `ConfigGlobal` + `currentSize` 统一控制：
- 按钮、输入框、表格等组件大小
- 一般对应后台系统设置里的「紧凑模式」「默认大小」

## 3. 全局灰色模式
```less
.@{prefix-cls}-grey-mode {
  filter: grayscale(100%);
}
```
- 开启后**整个网站变成黑白色**
- 常用于公祭日、悼念日等场景

## 4. 基础样式初始化
- 清除默认内外边距
- 禁止页面滚动（滚动交给内部布局组件）
- 让 html / body / #app 百分百宽高铺满屏幕

## 5. 主题初始化
```ts
appStore.initTheme()
```
项目启动时就执行：
- 读取本地缓存主题
- 设置暗黑模式 / 主题色 / 灰色模式 / 侧边栏模式等
