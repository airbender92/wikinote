# 1. 接口与默认配置
```ts
interface TreeHelperConfig {
  id: string
  children: string
  pid: string
}
const DEFAULT_CONFIG: TreeHelperConfig = {
  id: 'id',
  children: 'children',
  pid: 'pid'
}

const getConfig = (config: Partial<TreeHelperConfig>) => 
  Object.assign({}, DEFAULT_CONFIG, config)
```
- 定义树结构默认字段：`id`、`children`、`pid`
- `getConfig` 用于合并用户配置，没有传的就用默认

# 2. listToTree 扁平数组 → 树形结构
```ts
export const listToTree = <T = any>(list: any[], config: Partial<TreeHelperConfig> = {}): T[] => {
  const conf = getConfig(config) as TreeHelperConfig
  const nodeMap = new Map()
  const result: T[] = []
  const { id, children, pid } = conf

  // 第一次遍历：把所有节点放进 map
  for (const node of list) {
    node[children] = node[children] || []
    nodeMap.set(node[id], node)
  }
  // 第二次遍历：给每个节点找爹
  for (const node of list) {
    const parent = nodeMap.get(node[pid])
    // 有爹丢爹的 children，没爹丢顶层
    (parent ? parent.children : result).push(node)
  }
  return result
}
```
- 两遍循环完成转树
- 用 Map 快速找父节点，性能高
- 最后返回顶层节点数组

# 3. treeToList 树 → 扁平数组
```ts
export const treeToList = <T = any>(tree: any, config: Partial<TreeHelperConfig> = {}): T => {
  config = getConfig(config)
  const { children } = config
  const result: any = [...tree]

  for (let i = 0; i < result.length; i++) {
    // 如果有子节点，拆开放到自己后面
    if (!result[i][children!]) continue
    result.splice(i + 1, 0, ...result[i][children!])
  }

  return result
}
```
- 深度优先展平
- 利用 `splice` 把子节点插进当前节点后面
- 最终得到一个顺序展开的数组

# 4. findNode 查找第一个满足条件的节点
```ts
export const findNode = <T = any>(
  tree: any, func: Fn, config: Partial<TreeHelperConfig> = {}
): T | null => {
  config = getConfig(config)
  const { children } = config
  const list = [...tree]

  for (const node of list) {
    if (func(node)) return node
    // 把子节点推进队列继续找
    node[children!] && list.push(...node[children!])
  }
  return null
}
```
- 广度优先遍历
- 找到第一个符合条件就返回
- 没找到返回 null


# 6. findPath 查找节点路径（返回从根到目标的数组）
```ts
export const findPath = <T = any>(
  tree: any, func: Fn, config: Partial<TreeHelperConfig> = {}
): T | T[] | null => {
  config = getConfig(config)
  const path: T[] = []
  const list = [...tree]
  const visitedSet = new Set()
  const { children } = config

  while (list.length) {
    const node = list[0]
    if (visitedSet.has(node)) {
      // 回退：出栈
      path.pop()
      list.shift()
    } else {
      visitedSet.add(node)
      // 子节点放前面
      node[children!] && list.unshift(...node[children!])
      path.push(node)
      // 找到就返回当前路径
      if (func(node)) {
        return path
      }
    }
  }
  return null
}
```
- 深度优先 + 回溯
- `path` 记录当前路径
- 找到满足条件节点，返回整条路径：[根 → 父 → 子]

# 7. findPathAll 查找所有满足条件的节点路径
```ts
export const findPathAll = (tree: any, func: Fn, config: Partial<TreeHelperConfig> = {}) => {
  config = getConfig(config)
  const path: any[] = []
  const list = [...tree]
  const result: any[] = []
  const visitedSet = new Set(),
    { children } = config

  while (list.length) {
    const node = list[0]
    if (visitedSet.has(node)) {
      path.pop()
      list.shift()
    } else {
      visitedSet.add(node)
      node[children!] && list.unshift(...node[children!])
      path.push(node)
      // 满足就存一份路径副本
      func(node) && result.push([...path])
    }
  }
  return result
}
```
- 遍历整棵树
- 所有满足条件的节点，都存下它的完整路径
- 返回一个路径数组的数组

# 8. filter 过滤树（保留满足条件或有符合子节点的分支）
```ts
export const filter = <T = any>(
  tree: T[], func: (n: T) => boolean, config: Partial<TreeHelperConfig> = {}
): T[] => {
  config = getConfig(config)
  const children = config.children as string

  function listFilter(list: T[]) {
    return list
      .map((node: any) => ({ ...node })) // 浅拷贝
      .filter((node) => {
        // 递归过滤子节点
        node[children] = node[children] && listFilter(node[children])
        // 自己满足 或 子节点有剩的，就保留
        return func(node) || (node[children] && node[children].length)
      })
  }

  return listFilter(tree)
}
```
- 递归过滤
- 自己符合条件 → 保留
- 自己不符合，但子节点有符合 → 也保留（保证路径完整）
- 自己不符合且子节点都不符合 → 删除

# 9. forEach 遍历树（可中断）
```ts
export const forEach = <T = any>(
  tree: T[], func: (n: T) => any, config: Partial<TreeHelperConfig> = {}
): void => {
  config = getConfig(config)
  const list: any[] = [...tree]
  const { children } = config

  for (let i = 0; i < list.length; i++) {
    // 回调返回 true 就停止遍历
    if (func(list[i])) {
      return
    }
    // 子节点插进后面继续遍历
    children && list[i][children] && list.splice(i + 1, 0, ...list[i][children])
  }
}
```
- 深度优先遍历
- 回调 return true 可**中断遍历**，用于大数据量优化

# 10. treeMap / treeMapEach 转换树结构
```ts
export const treeMap = <T = any>(
  treeData: T[], opt: { children?: string; conversion: Fn }
): T[] => {
  return treeData.map((item) => treeMapEach(item, opt))
}

export const treeMapEach = (
  data: any, { children = 'children', conversion }
) => {
  const haveChildren = Array.isArray(data[children]) && data[children].length > 0
  const conversionData = conversion(data) || {}

  if (haveChildren) {
    return {
      ...conversionData,
      [children]: data[children].map((i) =>
        treeMapEach(i, { children, conversion })
      )
    }
  } else {
    return { ...conversionData }
  }
}
```
- 递归遍历整棵树
- 对每个节点执行 `conversion` 转换
- 返回一棵结构相同、节点被改造后的新树

# 11. eachTree 递归遍历树（带父节点）
```ts
export const eachTree = (treeDatas: any[], callBack: Fn, parentNode = {}) => {
  treeDatas.forEach((element) => {
    const newNode = callBack(element, parentNode) || element
    if (element.children) {
      eachTree(element.children, callBack, newNode)
    }
  })
}
```
- 最普通的递归遍历
- 回调能拿到**当前节点 + 父节点**
- 常用于修改节点、打标记、加字段
